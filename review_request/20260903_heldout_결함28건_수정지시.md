# 작업지시 — held-out 벤치마크 **결함 10건 수정** (데이터셋 담당 LLM 앞)

> **발행 2026-09-03** · 발행자 Claude Code(TinyLM) · **사용자 승인 완료**
> 대상: `datasets/TinyDataset/stage1_dataset/held-out_v2.3` · `held-out_v2.4`
> 🚫**`stage2~stage10_highdensity_dataset` 은 절대 건드리지 않는다.**

---

## 0. 한 줄

**정답으로 표시된 후보가 사실과 반대인 문항이 9건 있고, v2.4 가 새로 깬 것이 1건 더 있다.**
**질문·정답 문장은 대체로 옳다. 틀린 것은 *후보 4개 중 정답으로 지목된 것*이다.**

## 1. 왜 급한가

★**이 데이터가 우리의 유일한 한국어 판정 경로**다. 지금은 **모델 비교에 쓸 수 없다** —
결함이 **지식과 역상관**이라, 사실을 아는 모델일수록 거짓인 '정답' 을 피해서 **틀린다.**
고칠 때까지 한국어 축 실험이 전부 멈춘다.

## 2. ★결함 A — 정답 후보가 거짓인 문항 **9건** (v2.3·v2.4 **둘 다**)

```
E-058  E-089  E-106  E-119  E-132  E-133  E-134  E-140  E-144
```

### 2.1 무엇이 잘못됐나 — 예시

| | 내용 |
|---|---|
| 질문 | *"공기는 하나의 순수한 물질인가?"* |
| 정답 문장 | *"아니다. 공기는 **혼합물**이다."* ✅**이 문장은 옳다** |
| 🚫**정답으로 표시된 후보** | *"공기는 **혼합물** 범주에 속하지 **않는다**"* |

### 2.2 ★근본 원인 — **하나다**

생성기가 **부정할 명사를 질문이 아니라 *답*에서 골랐다.**

- 올바른 부정 대상 = 질문의 *"순수한 물질"*
- 실제로 부정한 것 = 답의 *"혼합물"*

→ 결과적으로 **정답 문장과 정면으로 모순되는 문장이 '정답' 으로 표시**됐다.

### 2.3 무엇을 해야 하나

각 문항에서 **정답으로 표시된 후보 문장만** 고친다. 부정의 대상을 **질문의 명사**로 되돌린다.

- 예: *"공기는 혼합물 범주에 속하지 않는다"* → *"공기는 순수한 물질이 아니다"*
- ★**정답 문장(`gold`)과 의미가 일치**해야 한다.

### 2.4 ★★기계 전수 결과 — **9건이 아니라 25건이다** (2026-09-03 실측)

사람 검수는 **30문항 표본**이었다. `check_heldout_defects.py` 로 300문항을 전수하니
같은 형태가 **25건** 나왔다. ★**표본 추정의 2.8배**다.

```
E-021 E-052 E-058 E-088 E-089 E-106 E-107 E-119 E-134 E-140 E-141 E-153 E-162
E-192 E-193 E-214 E-228 E-231 E-235 E-271 E-272 E-273 E-275 E-286 E-300
```

★★**v2.1 · v2.2 · v2.3 · v2.4 에서 목록이 완전히 같다** — 🚫**개정으로 고쳐진 적이 한 번도 없다.**
생성기 결함이 처음부터 있었고 판올림이 그것을 건드리지 않았다.

⚠️**사람이 찾은 9건 중 6건이 여기 있고 3건(`E-132`·`E-133`·`E-144`)은 없다.**
→ ★**둘을 합집합으로 처리한다**(25 ∪ 9 = **28건**). 기계는 재현율이 100%가 아니고,
**사람이 본 것을 기계가 못 봤다고 해서 결함이 아닌 것이 아니다.**

### 2.5 ⚠️추가 발견 — **v2.4 가 추상화를 더 늘렸다**

후보 4개에 **질문의 내용어가 하나도 없는 문항**(D3):

| 판 | D3 건수 / 300 |
|---|---:|
| v2.1 · v2.2 | 119 (39.7%) |
| v2.3 | ★**110 (36.7%)** — 가장 좋다 |
| ★**v2.4** | 🚫**132 (44.0%)** — **+22건 악화** |

★**길이를 맞추려는 재작성이 내용어를 걷어냈다.** §5 의 별건과 같은 뿌리다.
→ ⚠️**이것이 v2.4 승격을 보류하는 두 번째 이유**다(첫째는 §3 의 `E-020`).

## 3. ★결함 B — v2.4 가 새로 깬 것 **1건**

| 문항 | 무엇 | v2.3 | v2.4 |
|---|---|---|---|
| **E-020** | 오답 후보 #2 의 낱말을 `양치류` → `양치식물` 로 고쳤더니 ★**정답 문장과 같아졌다** | ✅정상 | 🚫**중복** |

→ **오답이 정답과 같아지면 그 문항은 정답이 둘**이다. `양치류` 로 되돌리거나 **다른 오답으로 교체**한다.

## 4. 🚫**바꾸지 말 것** — 이것을 어기면 데이터가 더 나빠진다

| # | 무엇 | 왜 |
|---|---|---|
| **1** | ★**질문과 정답 문장(`gold`)** | 사람 검수 30문항에서 *"정답 문장 자체는 대체로 타당"* 으로 확인됐다 |
| **2** | ★★**후보 4개가 같은 문장 틀을 쓰는 구조** | 🚫**결함이 아니라 의도된 설계**다. v2.3 이 이 틀로 **최장선택 편향을 39.0% → 25.0%** 로 내렸다. 틀을 흩으면 길이 편향이 되살아난다 |
| **3** | **결함 목록(§2·§3) 밖의 문항** | 건드리면 v2.3 과의 비교가 끊긴다 |
| **4** | `answer` 필드 | ★**채점에 쓰이지 않는다**(자유생성 시절 유물). 지금 채점은 **후보만** 본다 |
| **5** | 문항 수 300 · ID 체계 | 대조가 깨진다 |

## 5. ⚠️별건 — **지금 고치지 말고 보고만 할 것**

`novel_relation` 후보의 **56.7%(51/90)** 가 *"첫째 대상"* · *"둘째 대상"* 같은 **추상 대명사**다.
후보에 질문의 내용어가 없어 ★**개념 지식이 아니라 대명사 결합을 재고 있다.**

🚫**§4-2(의도된 틀)와 섞지 말 것** — **틀이 같은 것은 설계**고, **내용어가 없는 것은 결함**이다.
→ **이번 작업 범위 밖이다.** 별도 지시를 기다린다.

## 6. ★재검증 — **기계 검사를 통과해야 납품이다**

🚫**종전 기계 검수는 이 결함을 한 건도 못 잡았다.** 구조(정답 불변·금지관계 정합·중복·문자폭)만
보고 **의미를 안 봤다.** 그래서 검사 두 개를 새로 만들었다:

```bash
python scripts/check_heldout_defects.py --dir datasets/TinyDataset/stage1_dataset/held-out_v2.4
```

| 검사 | 무엇 | 주의 |
|---|---|---|
| **D1** | 오답 후보가 **정답 문장과 같아졌는가** | ★**부분문자열로 보면 안 된다** — `식물` 이 `양치식물` 안에 있어 초기 스캔이 0건을 냈다. **술어를 정확히 뽑아** 비교한다 |
| **D2** | 정답 후보가 **정답 문장을 부정하고 있는가** | 부정어(`않`·`아니`)와 정답 문장의 핵심 명사가 **같은 문장에** 있으면 의심 |

★**두 검사 모두 0건**이어야 한다. D2 는 휴리스틱이라 **거짓 양성이 날 수 있다** —
그럴 때는 **문항 번호와 이유를 적어 회신**한다(무시하지 않는다).
