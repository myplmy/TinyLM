# 05 — ★폐기된 규약·사실 원장 (deprecated)

> **여기 있는 것은 전부 "한때 맞았지만 지금은 아닌 것" 이다. 따르지 말 것.**
>
> 목적은 **삭제가 아니라 격리**다. 그냥 지우면 다음 세션이
> *"왜 이런 구조로 돼 있지?"* 를 이해하지 못하고, 이미 해제된 제약을
> **다시 발명**한다. 그래서 **무엇이 · 왜 폐기됐고 · 지금은 무엇인지**를 남긴다.

## 이 문서를 언제 펴나

| 상황 | |
|---|---|
| 코드·문서에 **이해가 안 가는 우회**가 보일 때 | 대개 여기 원인이 있다 |
| 옛 핸드오프·결과문서를 읽다 **지금 규약과 다른 서술**을 만났을 때 | |
| 제약을 **새로 만들려** 할 때 | 이미 만들었다가 푼 것일 수 있다 |

## 원칙

1. **폐기는 하되 흔적은 남긴다.** 항목을 지우지 않는다.
2. ★**과거 기록(`handoff/`, 결과문서 §철회 절)은 소급 수정하지 않는다.**
   *"그때 무엇을 알고 있었나"* 가 사라지면 판단 과정을 재구성할 수 없다.
3. **폐기 항목이 만든 구조는 대개 그대로 둔다.** 동작하는 것을 되돌릴 이유가 없다.
   되돌릴 때는 **이득을 숫자로 적는다**(의사결정 함정 D1).

## D-01. 🚫 `.bat` 의 **`%` 전면 금지** — 2026-08-13 해제

| | |
|---|---|
| **언제** | 제정 ~2026-07 / **해제 2026-08-13**(사용자 검토 지시) |
| **무엇이었나** | `.bat` 안에서 `%` 문자를 **통째로** 금지. `lint_bat` 규칙 3 이 에러 |
| ★**지금은** | **`%VAR%` 즉시확장만 에러.** 리터럴은 `%%`, `for %%a` 허용, `%~` 는 경고 |

**왜 만들었나**: `%VAR%` 가 미정의면 **그 구간이 조용히 사라진다.** 이 저장소가
가장 싫어하는 "조용한 실패" 라 전면 금지가 안전해 보였다.

**왜 풀었나**: 대가가 컸다. 퍼센트를 못 써서 주석에 `PERCENT SIGN` 우회를 썼고,
`for /f` 를 못 써서 목록 읽기를 전부 파이썬으로 뺐고, `%~dp0` 를 못 써서
`if not exist run100m.py cd ..\..` 마커를 발명했다. 재검토 결과
**`%` 오용의 실패 모드는 전부 실행 시점에 드러난다** — 파일을 지우거나
체크포인트를 덮어쓰는 종류가 아니다. **위험한 형태 하나만 남기는 것으로 충분했다.**

> ⚠️★**금지가 만든 구조는 그대로 둔다.** `cd ..\..` 마커도, 번호 슬롯
> (`TL_DATA1`/`TL_J1`)도, 파이썬 큐 파서도 유지한다. **동작하고, 되돌릴 이득이 없다.**
> 특히 파이썬 파서는 `for /f` 보다 **감사·정렬이 훨씬 낫다.**
