## 0. 최우선 예외 — 09는 이식 대상이 아니다

`ai_dev_tool/09_구현검증_필요목록.md`는 작업원장 성격의 **현 위치 공유 정본**이다.

- `ai_dev_tool/Codex/09_...` 파일을 만들지 않는다.
- 09의 전체·부분 사본, 요약 정본, 동기화용 미러를 만들지 않는다.
- Codex 문서가 09의 항목을 필요로 하면 원래 경로를 링크로만 참조한다.
- 이식 중 09의 내용·파일명·위치·메타데이터를 수정하지 않는다.
- 09를 Codex 00~08 어느 파일의 “목적지”로도 지정하지 않는다.
- 단, `AGENTS.md`의 기존 문장이 구현검증 작업을 09에 기록하라고 지시한 경우에는 **그 지시를 Codex 00 또는 07에 ‘루트 09 참조’로 보존**한다.

## 1. 분류 표기

| 표기 | 의미 |
|---|---|
| `KEEP-AGENTS` | 매 프롬프트 반드시 알아야 해 축약형으로 `AGENTS.md`에 남김 |
| `C00`~`C08` | `ai_dev_tool/Codex/00~08` 중 해당 역할 파일로 의미 단위 이식 |
| `SHARED-REF` | 핸드오프·COMPASS·기준표·결과·스크립트 등 기존 공유 정본을 링크하고 본문은 복제하지 않음 |
| `ROOT-09-REF` | 루트 `ai_dev_tool/09_구현검증_필요목록.md`를 현 위치에서 링크만 함 |
| `DROP-AGENTS` | `AGENTS.md`에서는 제거. 다른 정본에 이미 있거나 라우팅만 남김 |
| `C05-DEPRECATED` | 과거에는 규범이었으나 현재 거짓이거나 폐기된 규약으로 Codex 05에 보존 |

이 표에서 “삭제”는 기록 자체의 소거가 아니라 **상시 진입 문서에서 중복·낡은 문장을 제거한다**는 뜻이다. 실험 결과의 역사적 증거는 결과 문서·기준표·COMPASS에 남긴다.

## 9. `AGENTS.md`에 최종적으로 남길 최소 골격

아래는 내용 골격이며 문구 자체는 승인 후 작성한다.

1. **정체성**: TinyLM의 목적과 이 파일이 Codex 진입 규범임을 3~5행.
2. **우선순위**: 사용자 최신 지시 → 보호/금지 경계 → 최신 유효 핸드오프·COMPASS·기준표 → Codex 00~08 → 기타 문서.
3. **시작 순서**: Codex 00, Codex 06, 최신 공유 핸드오프, COMPASS. 작업 유형에 따라 01~08과 스킬을 추가 로드.
4. **절대 금지**: 사용자 승인 없는 GPU·학습·모델 로딩·삭제·보호 데이터 수정·commit/push·광범위 staging.
5. **증거 수준**: 계획, 정적검사, 실제 실행, 사용자 E2E, 배포를 구분하고 NOT_RUN을 유지.
6. **파일 보호**: 동시 작업과 사용자 파일을 보존하고 삭제/개명은 승인·전용 도구 정책을 따름.
7. **스킬 라우팅**: `.agents/skills`를 사용하고 해당 요청의 필수 스킬을 먼저 읽음.
8. **환경 분리**: Codex 런타임에서 `.claude/**`, `CLAUDE.md`, 루트 Claude 00~08 참조 금지.
9. **09 예외**: 루트 09는 공유 작업원장으로 현 위치 참조만 하며 복제·이관 금지.
10. **세부 링크**: 작업규약 C00, 함정 C01, 핸드오프 C02, 실험 C03, 결정 C04, 폐기 C05, 프로젝트 C06, 지시 C07, 자백 C08.

목표 크기는 12~16 KiB다. 다만 바이트 수를 맞추기 위해 안전 경계를 생략하지 않는다.
