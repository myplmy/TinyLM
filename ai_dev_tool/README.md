## 갱신 규칙

- **항목을 지우지 않는다.** 철회는 취소선 + 사유로 남긴다 — 왜 철회됐는지가 정보다.
- ★**규약이 통째로 폐기되면 `05` 로 옮긴다**(2026-08-13 신설). 지우지 않는 이유는
  같다 — **그냥 지우면 다음 세션이 이미 해제된 제약을 다시 발명한다.**
  `05` 는 *"무엇이 · 왜 폐기됐고 · 지금은 무엇인지"* 세 가지를 반드시 적는다.
- ⚠️★**과거 기록(`handoff/`, 결과문서의 철회 절)은 소급 수정하지 않는다.**
  *"그때 무엇을 알고 있었나"* 가 사라지면 판단 과정을 재구성할 수 없다.

## 04 — [의사결정 함정 원장](04_의사결정함정_원장.md) (2026-08-13 신설)

**01 과 짝**이다. 01 은 *"내가 재려던 양을 정말 재고 있는가"*(측정),
04 는 *"잴 것을 옳게 고르고 있는가"*(판단).

★**사고 형태가 다르다** — 계측 함정은 **숫자가 틀리고**, 의사결정 함정은
**숫자가 맞는데 아무것도 안 일어난다.** 후자가 더 오래 안 잡힌다.

**언제 편다**: 실험을 미루거나 축을 닫으려 할 때 / *"~ 후에"* 라고 쓰려 할 때 /
새 세션이 계획을 세울 때(D1·D2·D6).
