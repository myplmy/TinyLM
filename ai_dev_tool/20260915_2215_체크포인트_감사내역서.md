## 1. 감사 목적과 판정 기준

`hold` 상태의 `_best.pt` 체크포인트에 대해 다음을 분리해 감사했다.

1. 과거 비교·평가·학습 입력에서 **실제 `_best.pt` 파일을 로드했는가**
2. 결과 문서가 `best_val` 숫자를 인용한 것뿐인가 — 숫자 인용은 파일 로드로 세지 않는다
3. 향후 계획·배치에 `_best` 직접 비교 또는 로드가 남아 있는가
4. [`cleanup_ckpt.py`](../scripts/cleanup_ckpt.py)의 부모·교사 계보 보호와 G2 판정 정합에 걸리는가

공식 런 판정은 final 체크포인트를 기준으로 하고, `_best` 실파일 직접 사용 근거가 없으며 향후 계획도 없는 경우 `_best`를 삭제 후보로 전환했다. 대응 final은 재현·재평가 기준점으로 보존했다.
