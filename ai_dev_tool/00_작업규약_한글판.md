# 00 — 작업 규약 (사용자 검토용 한글판)

**AI 의 작업용 정본은 영문판** [`00_WORKING_RULES.md`](00_WORKING_RULES.md) 이고,
이 문서는 **같은 내용의 한글 대조본**이다. 규칙 번호(R01~R40)가 양쪽에서 같아야 하며
`python scripts/check_rules_sync.py` 가 그것을 검사한다.

- **`[게이트]`** = 스크립트가 강제한다. 외울 필요가 없고 `check_static_all.py` 를 돌리면 된다.
- **`[사람]`** = 사람만 잡을 수 있다. **외워야 하는 것은 이쪽뿐이다.**
- **`[사실]`** = 매번 다시 유도하게 되는 수. 기억하지 말고 찾아본다.
- 2026-08-27 실측: 규약 코퍼스는 **9개 파일 1,397 의미줄**이고 **파일을 넘는 완전중복은 1줄**이다.
  ★**중복이 문제가 아니라 분량이 문제다.** 그래서 조치는 (a) 이 요약본과
  (b) 검사 가능한 규칙을 **게이트로 옮기는 것**이다. 긴 원장(01~08)은 **근거·사례**로 남는다.

## A. 절대 경계

- **R01** `[사람]` **파일을 지우지 않는다. 삭제 권한을 요청하지도 않는다.** `rm` 도, 승인 도구도.
  지울 것은 핸드오프 *"사용자에게 부탁하는 것"* 절에 목록으로 적고 끝낸다. `mv`(개명)는 AI 가 직접 한다.
  **개명은 되돌릴 수 있고 삭제는 못 되돌린다.** (2026-08-14 위반 1회 → D11)
- **R02** `[사람]` **AI 는 학습·GPU 코드를 직접 실행하지 않는다.** 배치·스크립트만 만들고 사용자가 돌린다.
- **R03** `[사람]` **git 은 사용자 몫**이다. AI 는 한국어 커밋 제목·본문을 제안한다.
- **R04** `[사람]` **파일 diff 없이 "조치 완료" 를 적지 않는다.** ⚠️**그리고 diff 도 증거가 아니다** —
  bf16 을 diff 를 들고 두 번 "고쳤다" 고 선언했고 두 번 다 안 고쳐졌다(자백 A4).
  증거는 **고치기 전에 실패하고 고친 뒤 통과하는 게이트**다.

## B. 비교 유효성 — 숫자가 틀어지는 곳

- **R05** `[사람]` **상주 ≠ 저장.** `상주 = 유니크 삼진 × 4B × 2벌 + 나머지 fp32`. **식에 bpw 가 없다.**
  ★**json 이 이미 둘을 나눠 싣는다 — `packed_mb`(저장) · `runtime_mb`(상주).**
  ⚠️`deploy_mb` 는 **`packed_mb` 의 구 로그 호환 별칭**이다(이름은 배포, 값은 저장).
  **`runtime_mb` 를 읽는다. 재계산하지 않는다.**
  (2026-08-28 정정 — 종전 문구는 *"재계산한다"* 였고 그것이 틀렸다.)
- **R06** `[사람]` **분해능은 계열 의존이고 전부 실측이다.** 타잉 **0.0006** / dense **0.0021** /
  재귀 **0.0018**(2σ, 조건이 깨끗한 시드로). bpb **0.008**. 잰 조건 밖(KD 혼입·부모초기화 없음)은
  **0.024**. ★정본은 **`scripts/_rulers.py`** 한 파일이고 `paired_eval`·`paired_join` 이 함께 읽는다.
  🚫종전 문구(무KD+부모초기화 0.0034)는 폐기 — **계열이 아니라 조건**이었고 시드 한 쌍에서 나왔다.
  ★**두 점 추정량은 편향된 것이 아니라 분산이 크다**(n=2 상대 sd 약 52%, n=3 약 36%).
  타잉에서는 2배 크게, 재귀에서는 2배 작게 나왔다.
- **R07** `[사람]` "동급" 이라고 쓸 때 `|t| > 2` 면 **"실무상 동급, 통계적으로는 유의"** 를 함께 쓴다.
- **R08** `[사람]` **풀·토크나이저·스텝·grad_ckpt 가 맞을 때만 비교**한다. grad ckpt 드리프트는
  실측 **−0.0014**(051) — 0.0034 자 아래이지만 **0.008 bpb 자 기준으로는 아래가 아니다**.
- **R09** `[사람]` **토크나이저가 다르면 `common_bpb` 만 유효**하다. 토큰 손실·perplexity 는
  **항상 큰 어휘가 유리하게 나온다**.
- **R10** `[사람]` **판정은 `paired_eval`.** 학습로그 val 은 무작위 크롭 표본이라 부호가 뒤집힌다.
  안정성은 인쇄 `|g|` 가 아니라 json `grad_max`.
- **R11** `[사람]` **step0 CE 는 이진 게이트다** — *"이식이 됐는가, 대역 안인가"* 만 답한다.
  크기·서열·축의 개폐를 여기서 정하지 않는다(D13).
- **R12** `[사람]` **판정 전에 `val − train_ce` 를 본다.** 기준선은 0 근처다. **0.3 초과면 계측을 먼저 의심**
  한다(함정 39). `--train-repeat` 로 학습한 체크포인트는 `--match-train-repeat` 로 평가한다 —
  아니면 **학습된 적 없는 함수**를 재는 것이다.
- **R13** `[사람]` **250스텝급 런은 속도·VRAM 전용**이다. 품질 판정 금지.

## C. 코드 수정

- **R14** `[게이트]` **한 개념, 한 정의.** 집합 소속을 답하는 함수는 하나여야 하고, 그 함수는
  **모델이 보는 플래그를 전부 봐야 한다**. `check_group_map.py` 가 프리셋 × arch 를 전수 열거한다.
  (P074 가 `mlp_group_index` 의 `tie_mlp` 누락으로 학습 팔 네 개를 잃었다.)
- **R15** `[게이트]` **새 축에는 그 축을 켠 스모크 팔**과 `check_smoke.py` 의 `EXPECT` 항목이 함께 간다
  (팔이 죽으면 에러가 되도록). **json 에 필드가 실린 것은 경로가 돈 것이 아니다**(함정 37).
  `check_smoke_coverage.py` 가 배치는 쓰는데 스모크가 안 도는 축을 나열한다.
- **R16** `[사람]` **사고는 새 기능이 아니라 새 조합에서 난다.** 최근 코드 오류가 전부 **오래된 둘이
  처음 만난 자리**였다(dense × 부모초기화, 타잉 × bf16 저장, 기존 도구 × 어휘 151,936).
  규약으로는 못 막고 **열거로만** 막는다. 무언가를 더할 때 **"이것과 함께 돌아본 적 없는 것은 무엇인가"** 를 묻는다.
- **R17** `[사람]` **텐서의 dtype·shape 을 바꾸기 전에 소비 지점을 전수 센다.** 가중치 타잉이면
  한 텐서가 **네 곳**에서 읽힌다(입력 조회·입력 업프로젝션·헤드 업프로젝션·헤드 로짓). 접근자 하나로 모은다.
- **R18** `[사람]` **판정 도구는 학습 루프와 형상이 다르다.** 학습용으로 쓴 교훈은 평가에 **손으로 다시**
  적용해야 한다(A3: 21.5시간 학습의 판정이 세 번 OOM). **결함이 안 나는 크기로 게이트를 만들지 않는다.**
- **R19** `[사람]` **"측정 0건, 종료코드 0" 이 최악의 실패 양식이다.** 0건이 가능한 도구는 **0이 아닌 코드**로
  끝나야 한다. 두 번 지불했다 — `runlog`(031), `mem_runtime`(059).
- **R20** `[사람]` **인쇄값 ≠ 정본**(함정 4). 도구는 **자기가 쓰지 않은 표·대응표·수를 인쇄하면 안 된다.**
  `diag_depth_init` 이 role 대응표를 찍고 zip 을 쟀다.
- **R21** `[게이트]` 코드·문서를 고친 직후 **AI 가 직접** `python scripts/check_static_all.py` 를 돌린다 —
  **22종, torch·GPU 0**. 코드를 고쳤으면 사용자에게 `run_smoke_check.bat` 을 요청한다.
  **정적은 동적을 대체하지 않는다.** Windows 에서는 `set PYTHONIOENCODING=utf-8` 를 앞에 붙인다.

## D. 배치와 큐

- **R22** `[사람]` **실험 배치는 "지금 돌아갈 때" 만 만든다.** 구현이 선결이면 **계획서에만 설계를 남긴다.**
- **R23** `[게이트]` 배치를 만든 직후 `check_batch_flags.py` + `lint_bat.py --fix`
  + ★**`dryrun_batch.py <배치>`**. 앞의 둘은 **파서에 이름이 있는지·문법이 옳은지**만 보고,
  마지막은 **프리셋 기본값까지 넣은 유효 조건**을 인쇄한다 — `--cla-group` 누락으로
  3.6 GPU-시간을 태운 자리가 거기였다.
  **파서 → 함수 → 동작 경로는 여전히 눈으로 따라간다.**
- **R24** `[사람]` `.bat` 은 순수 ASCII·CRLF, `%VAR%` 즉시전개 금지, `chcp` 금지, `<` `>` `|` 이스케이프.
  변형 런에는 `--tag` 필수 — 없으면 정본을 덮어쓴다.
- **R25** `[사람]` 스윕은 `if errorlevel 1 echo [WARN] ... - continuing`. `goto ERROR` 는 **진짜 선결**
  (prepare·교사 학습)에만. 이 규약이 하룻밤 큐를 두 번 살렸다.
- **R26** `[게이트]` 새 배치 ⇒ `experiments.tsv` **한 줄 추가** 후 `queue_menu.py --audit`.
- **R27** `[사람]` **큐 안내는 이름으로 한다. id 는 안 된다**(함정 36) — 표에 한 줄만 늘어도 전부 밀린다.
  id 가 필요하면 `queue_menu.py --ids <배치명>` 이 계산하게 한다.
- **R28** `[사람]` 실험은 서로 **독립**이게 설계한다: 태그 분리, 캐시 분리, 새 플래그는 **기본 off·비트 동일**.
  이유 둘 — 하나가 죽어도 나머지가 살아야 하고, **사용자가 혼자 돌릴 수 있어야** 한다.

## F. 매번 다시 유도하게 되는 고정 사실

- **R37** `[사실]` 학습토큰 = `steps × micro_bs × accum × seq`. `--tokens` 는 **캐시 크기**다.
  300M 기준선 = `--micro-bs 8 --accum 16`(유효배치 131K).
- **R38** `[사실]` `M = micro_bs × seq` 가 속도와 VRAM 을 동시에 정한다. 무릎 **M = 8,192** —
  ★**그리고 그것은 어휘 32,768 기준의 수이지 상수가 아니다**(A3).
- **R39** `[사실]` 데이터 풀 ≥ 학습토큰의 2배(`--pool-tokens 600M --exact-cache`).
- **R40** `[게이트]` `scripts/` 에서는 `datasets`·`transformers` 보다 **먼저 `import tinylm`** — 안 하면 HF 캐시
  리다이렉트가 안 걸려 **작업폴더 밖으로 조용히 받는다**.
