# 전체 조치 통합 적용본

`replacement/` 안의 `tinylm`, `scripts`, `tests` 내용을 프로젝트 루트 `Z:\TinyLM\`에 **병합 복사**할 수 있게 구성했다. 고유 Python 파일 48개이며, 각 A 폴더의 공통 파일과 바이트 단위로 같다.

`original/`은 작성 시점의 교체 대상 원본 13개를 그대로 복사한 비교용 사본이다. 적용 대상이 아니다. 나머지 기존 TinyLM 모듈은 원본 프로젝트의 것을 계속 사용한다.

[상위 README](../README.md)의 적용·검증 순서를 먼저 따른다. 개별 조치만 적용하려면 [A01](../A01/README.md)–[A15](../A15/README.md)의 `replacement/`를 사용한다. A07·A12·A14는 문서 조치라 이 통합본에 추가 코드가 없다.

**작성 상태:** 코드·회귀 테스트 작성, 파일/해시 대조. **미수행:** 원본 적용, Python/import/compile, 검사 프로그램 실행, 테스트, 학습, 평가, GPU 작업. 실행 결과나 모델 개선을 보증하는 묶음이 아니다.

통합본에 포함한 파일과 각 파일을 사용하는 조치, 원본·교체본 SHA는 [manifest.json](../manifest.json)에 있다. 작성 후 원본이 변경되었다면 비교용 사본과 교체본의 변경점을 최신 원본에 반영해야 한다.
