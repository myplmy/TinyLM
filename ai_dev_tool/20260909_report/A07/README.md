# A07 — 고유 데이터·노출·언어 비율을 분리하는 재분석

우선순위: **P1** · 산출물 상태: **실험개선안 문서, 코드 생성 대상 아님**

근거: [보고서 v2의 A07](../20260909_TinyLM_40MiB_연구타당성_및_실행조치_보고서_v2.md). 원본 코드·데이터·checkpoint 및 기존 보고서는 이 작업에서 수정하지 않았다.

이 폴더에는 실험개선안만 둔다. 지금 필요한 조치가 코드 변경이 아니므로 replacement/original 폴더를 생성하지 않는다.

이 항목은 **실험개선안만** 제공한다. 이미 있는 로그/meta와 A02/A04 도구로 우선 답할 수 있어 새 trainer나 dataset 생성기를 만들지 않는다.

### 지금 바꿀 판정

P037 캐시/토큰 문제의 후속 교정, P088 누설 발견과 공통 bpb, P087 1/2/4 반복 결과는 완료 이력으로 유지한다. 600M→1,200M pool에 한국어 비율 50%→25% 변화가 섞인 결과를 고유 자료량만의 효과라고 부르지 않는다. 높은 R²와 2.34배 외삽을 보편적인 학습 상한으로 사용하지 않는다.

### 기존 산출물로 먼저 만들 표

| 열 | 확인할 원천·주의 |
|---|---|
| checkpoint/부모/tokenizer | 실제 경로·SHA. 같은 vocab 크기로 tokenizer 동일성 추정 금지 |
| 고유 pool | meta.tokens뿐 아니라 문서/출처/중복, source family |
| 실제 노출/업데이트 | 완료 checkpoint step, skip, batch×seq×accum, 조기 종료; 계획 tokens를 실적처럼 쓰지 않음 |
| 언어·출처 비율 | mix_token_frac/mix_tokens/mix_sources 및 고갈 기록 |
| 학습 일정 | warmup/decay/anneal/optimizer, restart/continue |
| 평가 | 동일 corpus·같은 clean bpb 규약·paired ID |

기록이 없는 고유 정보량이나 실제 처리 token은 “미복원”으로 남긴다. crop 위치 개수로 고유 지식 수를 대신하지 않는다.

### 추가 학습이 필요한 경우만

1. 같은 tokenizer/언어·출처 비율/노출 token/update에서 고유 pool만 다른 기존 두 팔이 있으면 재평가만 한다.
2. 없다면 최종 승격을 바꿀 수 있는 비교에 한해 작은 matched 대조를 추가한다.
3. 같은 자료 반복 효과는 pool을 고정하고 반복/노출을 바꾼다. 이미 수행한 반복 격자를 다시 만들지 않는다.
4. 동일 시간 효율은 생성·전처리·학습·평가 비용을 포함한 별도 열로 낸다. 동일 step과 동일 token 결과를 혼용하지 않는다.

**종결 기준:** “새로운 자료라 좋아졌다”, “언어 혼합이 바뀌었다”, “더 오래 학습했다” 중 증거가 허용하는 범위로 결론을 좁힌다. 142런 전체 폐기·재학습은 이 조치의 범위가 아니다.
