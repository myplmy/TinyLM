## 8. 판정과 후속

S1/S2는 **소형 모델 기능 PASS**, T1은 단일 순서에서 eval/save 감소를 포함한 약1.9% whole-wall 이득 **기술 관측**이다. 새 재실행은 당장 필수라고 단정하지 않지만, 기본 설정 승격에는 역순 반복과 동일 고정 crop·동일 부모/토크나이저/풀 검사가 선결이다. `--eval-every` 감소로 평가 품질이 좋아졌다는 뜻이 아니다. S3 HT의 clipping 이후 update 등가는 별도이며 아직 학습 검증이 없다. 이 점검은 알려진 설계 실수만 걸러낸 것이고, 실제로 그런지는 돌려봐야 한다.

## 9. 2026-09-25 T0/T1 훈련 JSON 직접 검산

승인된 정확한 `runs/logs/m100s12_ko-en_100M_dense_p102a_t0_s1337.json`과 `...t1_s1337.json`을 직접 읽었다. 두 JSON의 preset·arch·pool 600M exact·seed1337·763step·100,007,936 draw·초기 부모·Muon RMS4·학습 스케줄은 일치하고, `eval_every/save_every`는 100/0 대 500/1000이다. `n_skip=0`, `grad_max=0.92305082/0.88481438`, 최종 val 3.75359375/3.761875를 원본에서 확인했다. §4~§6의 ‘JSON 직접 대조 전’ 단서는 이 절로 해소한다.

| host-wall 성분 | T0 초 | T1 초 | T0−T1 초 |
|---|---:|---:|---:|
| 전체 `wall_sec` | 1836.554 | 1802.371 | 34.183 |
| 반복 `step_sec` | 1798.139 | 1791.023 | 7.116 |
| `eval_sec + save_sec` | 32.703 | 7.189 | 25.514 |
| 마지막 `final_eval_sec` | 3.437 | 3.348 | 0.090 |

나머지 약1.463초와 반복 step 시간 차이는 단일 T0→T1 실행 순서, clock/compile 잡음 등과 분리되지 않는다. `ms_step_median`도 2208.959→2204.914ms로 약0.18% 차이일 뿐 GPU 커널 가속 증거가 아니다. 평가 호출 8→2, checkpoint 쓰기 16→3을 확인했다. final val은 평가 crop 고정 증거가 없어 우열 비교 불가이며 T1 기본 채택은 역순 반복·같은 fixed-crop 판독 전 보류한다.
