## 3. Stage1W 실제 7모델 생성 — 2026-09-25 08:39~08:43

원본: `097_log_20260925_P105_Stage1W_wiki_panel_7model.txt`.

각 모델의 분모는 40출력이다. 원본 로그 마지막 JSON의 `buckets`를 모델별 합산했다. `repeat_heuristic`은 현재 정규식이 단일 문자 `-`나 줄 단위 문구 반복을 포착하지 못하므로 **실제 반복률의 추정치로 쓰지 않는다**.

| 모델 태그 | 표제 검출/40 | 원치 않는 URL/40 | 현 반복 휴리스틱/40 | 빈 이어쓰기/40 | 해석 한계 |
|---|---:|---:|---:|---:|---|
| `d18_cla2_norecur_rms4` | 23 | 0 | 4 | 0 | 품질-edge로 선정했으나 위키형 꼬리 문체 지속 |
| `dense_chat32_p090b_s1337` | 23 | 1 | 3 | 0 | chat32 **사전학습 부모**이지 SFT 모델이 아님 |
| `p097_ctrl_v2` | 25 | 0 | 7 | 0 | seed1337 control, 아래 FineWeb2와 패키지 비교만 가능 |
| `p097_fw2` | 0 | 0 | 1 | 2 | `-` 줄 반복이 다수인데 휴리스틱이 놓침; 표제 0은 품질 개선 아님 |
| `d14_cla2_norecur_rms4_lr15` | 21 | 1 | 5 | 1 | 기존 P100 부모, 후속 두 부모와 길이·형상 다름 |
| `d14_cla2_norecur_rms4_t600` | 30 | 0 | 0 | 0 | 600M 부모; 이 휴리스틱 0을 유창성으로 해석 금지 |
| `d16_cla2_norecur_rms4_t1200` | 23 | 0 | 2 | 0 | 1.2B 부모, 풀/스케줄도 다름 |
| **전체** | **145/280** | **2/280** | **22/280** | **3/280** | 이 고정 질문 패널의 기계 검출 횟수 |

두 URL은 모두 `provided_context`의 greedy 응답에서 발견됐다. `url_request` 70응답에서는 URL 검출 0건이다. 그 층은 5문항 중 3문항이 주소를 요청하고 2문항은 모르면 모른다고 답하도록 하므로, 0건을 단순 “URL 위반 0”으로 칭찬할 수도 없고 정답률로 변환할 수도 없다. 동일 URL의 한 출력 내 반복은 0건이다. 기존 사용자가 우려한 `http://` 반복이 **이 표본에서는 계측되지 않았다**는 뜻이지, 전체 생성에서 발생하지 않는다는 증명은 아니다.

원답안에서 `p097_ctrl_v2`의 일반 질문 G1이 `같이 보기`와 `외부 링크`를 시작하며, `p097_fw2`의 G1/W1/U1/P1 greedy는 `-` 한 줄을 반복한다. FineWeb2의 표제 0/40은 **다른 형태의 퇴화와 공존**한다. 따라서 현재 데이터셋을 FineWeb2로 교체하거나 위키 서식을 전역 삭제하는 근거가 아니다.

## 4. 예측 대조와 결론

계획 §3의 “위키형 반복이 현재 모델에도 남을 수 있다”는 예측은 고정 패널에서 **표제 검출 145/280로 방향 확인**됐다. 반면 “URL 반복이 주요 증상”은 이 패널의 동일 URL 반복 0건으로 지지되지 않는다. 학습 원천 말미와의 인과는 Stage1bW 실제 source 감사를 하지 않아 `NOT_RUN`이다. SFT 효과·실제 EOS 정지 이유·지식 정답성도 `NOT_RUN`이다. 특히 `repeat_heuristic=22`는 `-` 루프를 놓치는 **계측 과소**이므로 그 수치로 “반복 적다”를 주장하지 않는다.

## 5. 후속과 재현

1. [Stage1Wb 읽기 전용 SH](../run_P105_Stage1Wb_wiki_repetition_reaudit.sh)를 새 smoke PASS 뒤 사용자 실행해 동일 280행의 줄/구절 반복 후보를 별도 로그로 재집계한다. 모델 재실행은 필요 없고 원 Stage1W의 `repeat_heuristic=22`를 소급 치환하지 않는다. 진단기 fixture와 원본 로그의 FineWeb2 G1 한 답안(같은 `-` 줄 40회)은 확인했지만 **280행 재집계 자체는 NOT_RUN**이다.
2. 공개 원천의 지정 JSONL 사본과 tokenizer가 정해지면 Stage1bW 말미 후보·문서율·token율을 읽기 전용 계측하고 사람 20~50행 오탐 검수한다.
3. 현상과 source가 함께 양성이어도 matched 데이터 정제 학습은 기존 source/tokenizer 교락을 분리하는 계획과 별도 승인이 선결이다.

원본 실행 명령은 Stage0W·Stage1W 런처의 `scripts/runlog.py` 호출을 아래 재현 부록에 보존한다. GPU·모델 실행은 사용자가 수행했고 Codex는 재실행하지 않았다.
