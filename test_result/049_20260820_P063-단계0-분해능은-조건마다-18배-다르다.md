## 2. ★★핵심 — **가설 ① 이 기각됐다**

결과 039 §3.1 이 세워 두고 안 쟀던 두 가설:

| 가설 | 예측 | 실측 |
|---|---|---|
| ① **추정량 탓**(`final val_loss` 의 eval 샘플링 노이즈) | `paired_eval` 로 재면 **크게 줄 것** | 🚫**0.0119 → 0.0109. 8% 만 줄었다** |
| ★② **조건 탓**(KD·부모초기화가 궤적을 수렴시킨다) | — | ✅**남는다** |

> ★★**즉 `p6d` 의 σ 는 진짜로 크다.** eval 노이즈를 완전히 제거해도 **시드가 0.011 을 흔든다.**
> 그리고 같은 도구로 잰 `mC_wsd` 는 **0.0006** 이다 — **18배.**
> **차이를 만든 것은 측정 방법이 아니라 학습 조건**이다.

### 2.1 무엇이 σ 를 줄이는가 — **부모초기화가 주력**

| 단계 | Δ | 줄어든 배수 |
|---|---:|---:|
| dense · 부모 없음 | **0.0109** | — |
| **+ 부모초기화**(무KD) | **0.0017** | ★**6.4배** |
| + KD | **0.0006** | 추가 2.8배 |

★**결과 038 §9 의 σ 표(0.0109 / 0.0017 / 0.0006)가 정본 추정량에서 그대로 재현**됐다.
그때는 dense 값만 `final val_loss` 였는데 **이제 셋이 같은 자로 잰 값**이다.
→ **"부모초기화가 6.4배, KD 가 추가 2.8배 줄인다" 가 확정**된다.

⚠️**KD 는 σ 를 줄이지만 품질은 나쁘게 한다**(결과 042 §12). **둘은 다른 축이다.**

## 3. ★분해능을 조건별로 다시 쓴다

`2σ` 를 실무 분해능으로 삼는 종전 규약을 그대로 적용하면:

| 조건 | 시드쌍 Δ | ⚙**2σ 상당** | 종전 규칙 |
|---|---:|---:|---:|
| dense · 부모/교사 없음 | 0.0109 | **약 0.022** | **0.024** ✅ 거의 맞다 |
| ★**tied · 부모초기화 · 무KD** | **0.0017** | ★**약 0.0034** | 0.024 = **7배 과대** |
| tied · 부모초기화 · KD | 0.0006 | 약 0.0012 | 0.024 = **20배 과대** |

> ★★**0.024 는 틀린 값이 아니라 *다른 조건의* 값이다.**
> dense·무교사에서는 거의 정확하고, **우리가 실제로 판정하는 조건에서는 7~20배 과대**다.

### 3.1 ★그래서 "동급" 이라 불러 온 것들의 실제 위치

**REVIEW2 가 고를 무KD 표준조건(2σ ≈ 0.0034)** 기준으로 다시 읽으면:

| 판정 | Δ | 종전 | ★**무KD 조건 기준** |
|---|---:|---|---|
| KD 제거(038·042 §12) | −0.0208 | "동급" | ★**6.1배 = 명백히 유의** |
| g16(029) | +0.0163 | "동급" | ★**4.8배** |
| E=192(030 §10) | +0.0154 | "동급" | ★**4.5배** |
| `mC_d36_ag2`(044 §8) | −0.0138 | "동급" | ★**4.1배** |
| 재귀 R=2(047 §10) | −0.0173 | "동급" | ★**5.1배** |
| `mC_d36_ag4`(044 §9) | +0.0078 | "동급" | **2.3배** |
| α=0.1 vs α=0(042 §12) | −0.0000 | 구분 불가 | ✅ **진짜 구분 불가** |
| `micro_group 256`(036) | −0.0007 | 구분 불가 | ✅ **진짜 구분 불가** |
| `opt bf16`(035 §12) | −0.0002 | 구분 불가 | ✅ **진짜 구분 불가** |

★★**"대가가 0 인 것" 과 "동급이라 불러 온 것" 이 이제 깨끗하게 갈린다.**
REVIEW2 §2.5.2 의 원칙(*"표준조건은 대가가 0 인 것만 바꾼다"*)이 **수치로 뒷받침**된다 —
`micro_group 256`·`opt bf16` 은 **정말로 0** 이고 g16·E192 는 **4~5σ 다.**

## 4. ⚠️게이트 결함 1건 — **내 배치가 기준값을 잘못 적었다**

배치 꼬리말: *"call 1 의 `p6d` full-val 이 **3.7045** 근처여야 한다(기준표 §2.2)"*
**실측 3.7608. 차 0.056.**

🚫**게이트가 틀렸다. 모델이 아니다.**
기준표 §2.2 의 **3.7045 는 학습 로그의 `final val_loss`**(무작위 크롭 100 iters)이고
`paired_eval` 은 **결정적 full-val 1464 크롭**이다. **다른 추정량이므로 값이 다른 것이 정상**이다.
결과 040 §2 가 이미 같은 것을 확인했다(`dense` 3.8241 vs full-val 3.8080).

> ★**함정 34 의 다섯 번째** — *"기준값을 적는 것 ≠ 옳은 값을 적는 것"*.
> 이번은 **조건도 숫자도 아니고 추정량**이 달랐다.
> → 기준표 §2.2 에 **"이 열은 `final val_loss` 다"** 를 명시하고,
> **`paired_eval` 앵커 열을 따로** 만든다(§6-2).

⚠️**판정에는 영향이 없다** — 세 쌍을 **같은 도구로** 쟀으므로 **쌍 간 비교는 유효**하다.
