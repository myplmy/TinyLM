## 1. ★★한 줄

**입력이 닮은 층은 널려 있고(U4), 그 층들이 하는 일은 거의 안 닮았다(U1).**
→ 🚫★**"유사도가 높다" 는 "묶어도 된다" 가 아니다.** P049 단계3 이 **+0.0281 을 주고 배운 것**의 기전.

## 2. ★계측 건강 (M1)

| 모델 | 자기 유사도 오차(입력/델타) | 판정 |
|---|---|---|
| dense · `mC_initonly` · `mC_d36_ag4_nokd` · `mC_r20_nokd` | **1.8e-07 ~ 3.6e-07** | ✅**전부 1e-5 미만** |

✅**대각이 1.0 이다** = 코사인 계산이 옳다. **기준값을 결과보다 먼저 인쇄했다**(함정 34).

⚠️★**델타 `d = x_{i+1} − x_i` 로 잰다.** 잔차 `x` 자체는 층을 지나며 거의 안 변해
`cos(x_i, x_j)` 가 **전부 0.99** 라 정보가 0 이다. **그것이 P049 가 밟은 함정의 일부**다.

## 3. ★★★U4 판별식 — **묶어도 되는가**

> 기준: 입력 `cos > 0.95` 이고 델타 `cos < 0.90` 인 쌍 = 🚫**묶으면 안 된다**
> 입력 `cos > 0.95` 이고 델타 `cos > 0.95` 인 쌍 = ✅**묶어도 된다**

| 모델 | 층/방문 | `mlp_group` | 🚫**같은 입력·다른 일** | ✅**같은 입력·같은 일** |
|---|---|---:|---:|---:|
| **dense** | 20/20 | 4 | **39쌍** | **0쌍** |
| **`mC_initonly`** | 20/20 | 8 | **40쌍** | **0쌍** |
| ★**`mC_d36_ag4_nokd`** | **36/36** | 16 | ★**158쌍** | ★★**3쌍** |
| **`mC_r20_nokd`**(재귀) | 20/**36** | 8 | **105쌍** | **0쌍** |

```
  같은 입력 쌍의 성격                 [X] 다른 일(묶으면 안 된다)   [O] 같은 일(묶어도 된다)
  dense            XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX                     39 / 0
  mC_initonly      XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX                    40 / 0
  mC_d36_ag4_nokd  XXXXXXXX...(158)...XXXXXXXX                             OOO 158 / 3
  mC_r20_nokd      XXXXXXXX...(105)...XXXX                                     105 / 0
```

### 3.1 ★★**"묶어도 되는 쌍" 이 표준모델에만 있다**

`mC_d36_ag4_nokd` 의 3쌍: **L4-L5**(in 0.995 / d 0.972) · **L8-L9**(in 0.995 / d **0.998**) ·
**L10-L11**(in 0.994 / d 0.963).

★**전부 인접 쌍이고 전부 중간 구간**이다. → ★**36층 모델에는 실제로 중복이 3쌍 있다.**
⚠️**그러나 이미 `mlp_group 16` 으로 묶여 있다** — 이 쌍들은 **같은 유니크 MLP 를 이미 공유**한다.
**즉 "더 묶을 여지" 가 아니라 "이미 묶은 것이 옳았다" 는 확인**이다.

### 3.2 🚫★**나머지는 전부 "같은 입력·다른 일"**

**입력 유사도만 보면 어느 두 층이든 닮았다.** 그림(`fig/P072_layermap_*.png`)의 왼쪽 판이
**거의 전면 진한 빨강**인 것이 그것이다. 오른쪽 판(델타)은 **대각선만 빨갛고 나머지는 0 근처**다.

★★**이 두 장이 P049 단계3 의 사후 부검이다** — `cos 0.9882` 는 **왼쪽 판의 값**이었고
잔차에 더해지는 것은 **오른쪽 판이 말하는 벡터**다.

## 4. ★M3 — **타잉 경계가 유사도를 따르는가**

> 기준: 그룹 **내부** 평균 − 그룹 **간** 평균 > **0.1**

| 🚫**`mC_initonly`** | **8** | +0.0742 | +0.0421 | 🚫**+0.0321** | 🚫**경계가 유사도를 안 따른다** |

경계를 세 가지로 바꿔 학습했고 셋 다 분해능 안**이었다.
→ 🚫★★**유사도 기반 경계 설계는 값어치가 없다.** 두 실험이 서로를 검증한다.

## 5. ★★U2 층별 기여도 — **불균등 압축의 근거**

> 한 층씩만 게이트를 0 으로 하고 손실 변화. ⚠️**Δ 의 합 ≠ 전부 뺀 값**(층은 상호작용한다).
> ★**그래도 순위는 신뢰할 수 있고 그것이 필요한 것이다.**

| 모델 | 기준 손실 | ★**M4 최대/최소** | 판정 |
|---|---:|---:|---|
| dense | 3.4686 | **579.7배** | ✅불균등 |
| `mC_initonly` | 3.2952 | **1561.8배** | ✅ |
| ★**`mC_d36_ag4_nokd`** | 3.3055 | ★★**7299.0배** | ✅★**깊을수록 심해진다** |
| `mC_r20_nokd` | 3.2887 | **1964.0배** | ✅ |

### 5.1 dense 상위 6개 (Δ손실)

```
  L0    +5.2755  ########################################
  L18   +0.5664  ####
  L17   +0.4178  ###
  L19   +0.2932  ##
  L15   +0.1692  #
  L16   +0.1435  #
  ...
  L4    +0.0091          <- 최소. L0 의 1/580
```

★★**앞(L0)과 뒤(L15~L19)가 중요하고 중간이 싸다.**
★**L0 이 2위의 9.3배** — prelude 첫 층은 다른 층과 **자릿수가 다르다.**

### 5.2 ★★**이것이 결과 045 를 설명한다**

`--mlp-split` 은 **중간층만** 나눈다(prelude/coda 는 이미 층별 독립).
★**그 구간이 원래 균등하게 싸다** → **경계를 어디 두든 차이가 없는 것이 당연하다.**
⚠️**사후 설명이다** — 계획 시점에는 U2 가 없었다.

### 5.3 ★★**층별 불균등 압축의 근거가 생겼다** (REVIEW3 §5-6)

**7299배**는 *"기여가 작은 층부터 더 세게 눌러도 된다"* 를 지지한다.
🚫**그러나 이것은 근거이지 설계가 아니다** — *"L4 를 2비트로 내리면 얼마 손해인가" 는 안 쟀다.*
⚠️**게이트를 0 으로 하는 것(제거)과 정밀도를 낮추는 것(압축)은 다른 개입**이다.
