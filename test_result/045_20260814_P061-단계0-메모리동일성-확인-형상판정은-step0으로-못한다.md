## 2. ★핵심 발견

### (1) 세 팔 모두 이식이 크게 이득이다 — **G0-c 는 전원 통과**

난수 10.41 → 이식 6.73~6.84. **GAP +3.57~3.69 nats.** 셋 다 앵커 7.7742 **아래**이고
통과선 9.3972 에는 크게 못 미친다(=여유가 크다). **불균등 타잉이 이식을 깨뜨리지 않는다.**

### (2) ★형상의 효과는 0.1135 nats — **작지만 대조군보다는 크다**

| 비교 | Δ (step0 CE) |
|---|---:|
| A(12+4) − 기준선(8+8) | **+0.0950** (A 가 나쁘다) |
| B(4+12) − 기준선(8+8) | **−0.0185** (B 가 근소하게 좋다) |
| **A − B** | **+0.1135** |

계측 안정성 참고: 난수 대조군 셋의 폭은 **0.0089**(10.4130~10.4219)로, 형상 효과의 **1/13** 이다.
→ **0.1135 는 이 크롭의 잡음보다 크다.**

### (3) ★★방향이 가설의 반대다 — **앞쪽을 무겁게 묶는 것이 더 비싸다**

계획 P061 의 출처(Hyper Experts diversity 분석)는 *"초기 층은 서로 중복이 많고 후기 층은
거의 직교"* 였다. 그렇다면 **초기 층을 크게 묶는 A 가 싸야 한다.** 실측은 반대다.

> **관측**: 초기 12층을 하나로 평균하면(A) 후기 12층을 평균할 때(B)보다 **+0.1135 비싸다.**
> **해석(가설, 미확정)**: step0 에서 초기 층은 **입력 분포에 가까워 서로 더 달라야** 하고,
> 후기 층은 이미 잔차가 쌓여 표현이 수렴해 있다. 또는 **잔차 누적 위치의 문제** —
> 앞에서 생긴 오차가 뒤의 18층을 모두 통과하며 증폭된다.
> ⚠️**이 둘을 이 로그로는 못 가른다.**

### (4) ⚠️**이건 step0 값이다** — 학습이 판정한다

로그가 스스로 두 번 경고했고 배치 꼬리말도 *"A vs B at step 0 is SUGGESTIVE ONLY"* 라 적었다.
**부모초기화 직후의 함수 근사 오차**를 잰 것이지 **학습 후 도달점**이 아니다.
결과 041 §13 이 정확히 이 이유로 *"step0 서열이 뒤집힐 수 있다"* 를 못 박았다.

| ~~"step0 차이가 0.1135 로 작다"~~ | **이 축은 메모리를 1바이트도 주지 않는다**(유니크 개수 고정이 설계 의도) |
| | 즉 **얻을 수 있는 것이 품질뿐**이고, 프로젝트 1순위 목표는 **배포 메모리**다 |
| | 그리고 단계1 은 **2런 × 약 3.3h = 6.6h** 다 |

★**이 근거는 step0 값에 의존하지 않는다** — 설계상 메모리 이득이 0 이라는 것은 **회계 사실**이다.
**같은 6.6시간을 P057(어텐션 48.4% = 남은 최대 메모리 축)에 쓰는 편이 낫다**는 판단은 유지된다.

⚠️**단 "형상은 무관하다" 라고 쓰지 않는다.** 우리는 **모른다.** 안 재기로 한 것뿐이다.
