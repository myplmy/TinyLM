## 2. ✅ A1 은 유효하다 — **그리고 이것만 유효하다**

```
KL(코드)          = 0.000056
sum(KL)/N × T²    = 0.000056        차 0.00e+00
```

`kl_div(reduction="batchmean")` 는 **첫 차원**으로 나눈다. 우리는 `(B·T, V)` 로 reshape 하므로
**분모 = 토큰 수 8192**다. 표준 KD 규약과 일치한다.

★**이건 항등식이라 어떤 분포에서도 성립한다.** 그래서 §3 의 결함에 영향받지 않는다.

> **→ "손실 정규화가 잘못됐다" 는 가설은 배제된다.**

---

## 3. ★★A2·A4 가 무효인 이유 — **내가 만든 데이터가 퇴화였다**

```python
base = torch.randn(N, V) * 0.5
slog = base.clone(); slog[..., tgt] += 4.0     # 학생
tlog = base.clone(); tlog[..., tgt] += 3.2     # 교사   ← ★같은 base 다
```

**교사와 학생이 `base` 를 공유**하고 정답 로짓만 4.0 vs 3.2 로 다르다.
→ 두 분포가 거의 같다 → **KL ≈ 0** → **∇KL ≈ 0**.

| 관측 | 진짜 의미 |
|---|---|
| A2 "실효 비 0.000" | **"두 분포가 같으면 KL gradient 가 0"** = 당연한 항등. KD 구현과 무관 |
| A4 "상대차 0.000e+00" | KL 자체가 ~5e-5 라 **bf16 로도 안 뭉개진다.** 실제 분포에서는 다를 수 있다 |

★**실제 교사·학생은 확연히 다르다** — full-val **3.8080 vs 3.6984**(결과 040 §2·037 §1).
그 차이에서 KL 은 0 이 아니고, A2·A4 의 답도 달라질 수 있다.

> ⚠️★**스크립트가 §말미에 *"합성 로짓으로 했다"* 라는 한계를 인쇄했는데도
> 판정 줄은 "주의: A2 → 미탐색 축이 있다" 로 단정했다.**
> 한계를 적어 놓고 결론에서 무시한 것 — **의사결정 함정 D4** 의 정확한 재발이다.

> 🚫★**A4 는 이번에도 공허했다** — 상대차가 **정확히 `0.000e+00`**. 원인을 찾았다:

## 10.2 ✅ 데이터 퇴화는 고쳐졌다 — **장치가 스스로 잡는다**

```
★교사·학생 분포 차(총변동거리) = 0.5206
  (0 에 가까우면 이 감사는 의미가 없다 — 결과 042 §3 의 실패)
```

§4 에서 넣은 3가지 조치가 다 작동했다: 독립 난수 · TVD 선인쇄 · `degenerate-data` 표기.
**함정 32 는 이제 도구가 스스로 감지한다.**

## 10.3 ⚠️★A2 — **부호는 믿고 크기는 버린다**

```
‖∇CE‖ = 0.022061        ← 1/sqrt(2048) = 0.0221. 정확히 일치한다
‖∇KL‖ = 0.000184
실효 비 = 0.008 : 1     (명목 alpha=0.5 이면 1:1 이어야 한다)
```

★**`‖∇CE‖` 가 `1/√N` 과 소수점까지 맞는 것**이 이 값의 성질을 말해 준다:
`∇CE = p_s − onehot` 이고 **onehot 항이 항상 크기 1 을 넣는다.** 반면
`∇KL ∝ p_s − p_t` 는 **두 확률벡터의 차**라서, 둘 다 V=32768 에 퍼져 있으면
**L2 노름이 구조적으로 작다.** TVD(=L1/2)가 0.52 로 커도 L2 는 작을 수 있다.

| 무엇 | 유효한가 |
|---|---|
| ★**방향**: 실효 α ^< 명목 α | ✅ **유효**. `∇CE` 의 onehot 항은 실제 학습에서도 있다 |
| ★**크기**: 0.008 : 1 | 🚫 **무효**. 학습된 교사·학생은 **첨예**해서 `‖p_s − p_t‖₂` 가 훨씬 크다 |

> ★**결론: "α=0.5 인데 실제로는 0.008 이었다" 라고 쓰면 안 된다.**
> 쓸 수 있는 것은 **"명목 α 와 실효 gradient 비가 어긋난다. 크기는 `--real` 이 잰다"** 뿐이다.
> ⚠️ 이건 **결과 042 §3 이 지적한 D4(한계를 적고 결론에서 무시)의 재발 직전**이었다 —
> 스크립트가 *"alpha_eff = 0.008 로 동작한다"* 라고 **단정해서 인쇄**했다. 문구를 고쳤다.

## 10.4 🚫★★A4 — **검사가 실패할 수 없는 구조였다** (원인 규명)

```
fp32 KL      0.999969
autocast KL  0.999969      상대차 0.000e+00     ← ★"정확히 0" 이 신호였다
```

bf16 은 유효숫자가 약 3자리다. **6자리가 일치할 리가 없다.**

★**원인**: `torch.autocast` 는 연산을 세 목록으로 가른다 — bf16 강제 / fp32 **강제** / 승격.
**`log_softmax`·`softmax`·`kl_div` 는 fp32 강제 목록**에 있다.
즉 `with torch.autocast(...)` 안에서도 **이 셋은 fp32 로 실행된다.**

| 함의 | |
|---|---|
| ✅ **우리 학습 경로에는 위험이 없다** | `trainer.py` 의 KD 손실은 autocast 아래 있어도 **fp32 로 계산된다** |
| 🚫 **그런데 A4 는 그걸 증명하지 않았다** | 같은 값이 나온 이유를 몰랐고, "통과" 라고만 찍었다 |

## 11.4 ✅ A4 — **§10 의 `0.000e+00` 이 무엇이었는지 확정됐다**

§10 은 *"`0.000e+00` 은 통과가 아니라 질문이다"* 로 끝났다. 이번에 답이 나왔다:

1. **autocast 아래 `log_softmax` 의 출력 dtype 을 직접 인쇄** → **`torch.float32`**.
   torch autocast 가 `log_softmax`·`softmax`·`kl_div` 를 **fp32 목록**에 둔다는 것이 증명됐다.
2. **강제 bf16 대조군**이 합성 `3.111e-05` / real **`1.377e-03`** 으로 **0 이 아닌 값**을 냈다
   → **이 검사는 실패할 수 있다.** §10 의 검사가 공허했던 이유가 데이터가 아니라
   **autocast 정책**이었다는 §10 의 진단이 **실측으로 확인**됐다.

> ★**real 의 bf16 오차가 합성의 44배**(1.377e-03 vs 3.111e-05)다. 실제 분포가 더 뾰족해서
> tail 손실이 크다는 뜻이고, **"우리는 bf16 을 안 쓴다" 는 사실이 그만큼 더 값어치 있다.**

## 11.5 ★★A2 — **실효 α 를 처음으로 옳게 쟀다**

§10 은 *"0.008 은 크기를 인용하면 안 되고 방향만 유효"* 라고 적었다. **그 유보가 옳았다.**

| | 합성 | **real** | 배수 |
|---|---|---|---|
| 크기 비 `‖∇KL‖/‖∇CE‖` | 0.008 | **0.404** | **50배** |
| 명목 α=0.5 의 실효 α | 0.008 | **0.288** | 36배 |

원인은 §10 이 이미 지목했다 — `∇KL ∝ p_s − p_t` 는 **두 분포가 모두 확산돼 있으면**
L2 가 구조적으로 작다. 합성 난수는 확산 분포였고 **실제 교사·학생은 뾰족하다**(TVD 0.9497).

### 11.5.1 ★단계1 격자가 실제로 무엇을 재는가

실효 KD 몫 = `a·r / ((1−a) + a·r)`, `r = 0.404`:

| 명목 α | **실효 α (real, r=0.404)** | 참고: 합성값을 믿었다면 (r=0.008) |
|---:|---:|---:|
| 0.5 | **0.288** | 0.0079 |
| 0.3 | **0.148** | 0.0034 |
| 0.1 | **0.043** | 0.0009 |
| 0 | 0 | 0 |

★**real 기준으로 네 점이 1.95배·3.44배 간격으로 벌어진다 → 서로 다른 처치다.**
합성값이 참이었다면 넷이 전부 0.008 이하 = **"KD 없음" 네 번**이었다.

> ★**결론: 단계1(`kd_alpha` 0.5/0.3/0.1/0, 약 12h)의 격자를 바꾸지 않는다.** 설계대로 유효하다.

### 11.5.2 ⚠️소급 적용 — **과거 런의 "α=0.5" 는 실효 0.288 이었다**

`--kd` 를 쓴 모든 런(mA·mB·mC 계열 전부)은 **명목 0.5 / 실효 약 0.29** 로 학습됐다.
문서에 `alpha=0.5` 라고만 적힌 곳은 **그 숫자가 손실 가중치이지 gradient 몫이 아니다.**
⚠️ 단 0.288 은 **이 체크포인트 쌍·이 크롭(4×1024, val 시드 99)의 1점 측정**이고,
학습이 진행되면 학생이 교사에 가까워져 `r` 이 변한다 — **학습 시작 시점 값**으로만 인용한다.
