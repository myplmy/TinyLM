해석: 유니크 어텐션이 줄수록 **층별 독립 K/V 가 대신 일을 한다.** 두 축이 **부분 대체재**다.
🚫**"CLA 는 항상 −0.0136" 이라고 쓰지 않는다** — 조건 의존이다.

### 12.4 ★어텐션 축은 **오목하다**(볼록하지 않다) — MLP 축과 같은 형태

36층·`cla2`, 유니크 어텐션을 절반씩 줄일 때:

```
8 -> 4   +0.0225
4 -> 2   +0.0147        ★뒤가 더 싸다
```

결과 045 가 MLP 축에서 찾은 것(g16→g32 **0.00312** < g8→g16 **0.00342**)과 **같은 방향**이다.
→ ★**결과 041 §14.3 이 한 점으로 유도한 "레버 가격은 볼록하다" 는 두 축에서 모두 반증됐다.**
`EXPERIMENT_BASELINES` B.5 의 볼록성 문구를 **두 축 모두 오목**으로 고친다.

### 12.5 ★★★가장 중요한 것 — **`mC_cla1_ag4` 가 표준모델보다 작고 동급이다**

| | ★**`mC_cla1_ag4`** | 표준모델 `mC_d36_ag4_nokd` | 차 |
