# 092 — P100 답변은 반복·위키 표제가 지배하고 P101A 결합 M0 이식은 1e-5 게이트 실패

> 로그 날짜 2026-09-24 · 결과번호 092는 사용자 런처의 기존 부여번호 때문에 **P100과 P101A 두 계획의 서로 다른 증거를 함께 보존**한다. 두 실험을 하나의 인과 비교로 취급하지 않는다. [P100 계획](../test_plan/P100_40MiB-지식-형식-구조-원인분리.md) / [P101A 계획](../test_plan/P101A_M0-U2-QK-MTP-기능계약.md).

## 1. P100 Stage0W 정성 능력 패널 — 첫 실행 PASS, 같은 출력 재시도만 FAIL

- 원본: `092_log_20260924_P100_Stage0W_capability_baseline.txt`에는 **두 번의 실행**이 시간순으로 있다. 21:26 첫 실행은 종료코드0으로 control-v2/FineWeb2 × 9개 한영 문항 × base/Q&A = 36개 원답안을 저장했고, 22:31 같은 출력 경로 재시도는 `FileExistsError` 종료코드1이다. 두 번째 실패는 이미 저장한 첫 결과를 지키는 write-once 동작으로, 모델 품질 실패나 첫 출력 손상을 뜻하지 않는다. 이미 첫 실행이 성공했으므로 별도 동일조건 재실행은 필요하지 않다.
- 로그 인쇄 답안에서 control-v2의 한국어 질문은 `같이 보기`·`각주`·`외부 링크` 등 위키 표제와 반복이 빈번했다. FineWeb2는 일부 파란 상자 `417` 맥락을 되짚었으나 답변을 반복하거나 지시한 JSON 형식을 지키지 못했다. 영문·한국어 모두 사실/형식/논리/멀티턴을 **안정적으로** 수행한다는 근거가 없다. 정성 표본 36개를 자동 정확도 점수나 데이터셋 단독 인과효과로 변환하지 않는다.
- 출력 JSONL 원답안 36행은 §6에서 직접 판독했다. 자동 정확도 채점과 일반화 판정은 `NOT_RUN`이다.

## 2. P101A Stage0W 수학·작은 모델 — 기능 PASS

- 원본: `092_log_20260924_P101A_Stage0W_u2_mtp_function_gate.txt` · 두 호출 모두 종료코드0.
- 상태사전 E 확장 fixture의 실수 함수 `max_abs=0`, QK τ=1 logits 차0·gain gradient L1=0.0014189644, MTP horizon/EOS·loss/gradient·aux/export를 작은 모델에서 확인했다. 실제 M0 parent checkpoint나 100M 학습 품질의 PASS는 아니다.

## 3. P101A Stage1W 고정 M0 결합 이식 — 기능 FAIL

- 원본: `092_log_20260924_P101A_Stage1W_m0_migration_gate.txt` · 종료코드1. 부모·토크나이저·cache 검사를 지난 뒤 결합 E384+QK+MTP 대상의 주 logits `max_abs=1.2397766e-05`가 사전등록 `1e-5`를 초과했다. 그 이후 aux/export/gradient 단계는 실행되지 않았다.
- 기존 게이트가 **승인된 독립 E384/QK/MTP 팔이 아니라 세 축 결합 모델을 먼저 검사**한 설계 공백도 확인했다. 1.24e-5가 형상 변경의 FP32 누적 반올림인지 각 팔 함수 오류인지는 원본 로그 하나로 분리할 수 없다. 문턱을 사후 완화하거나 기능 PASS라고 쓰지 않는다.
- 같은 고정 M0에서 독립 팔별 `max_abs`·NRMS·top1 변화·신규 gradient를 분해하는 [Stage1Wb](../run_P101A_Stage1Wb_m0_arm_attribution.sh) 진단기/런처를 준비했다. 사용자의 새 모델 로그는 `NOT_RUN`; 어느 팔이든 기존 1e-5를 넘으면 그 팔의 Stage2 학습은 보류한다.

## 6. 2026-09-25 P100 원답안 36행 직접 판독

승인된 정확한 `runs/bench/p100_stage0w_capability_baseline.jsonl`에는 control-v2·FineWeb2 각 18행(9문항 × base/Q&A), 중복 `case_id/form` 0건이며 모든 `full_output`이 기록된 프롬프트로 시작한다. §1 작성 당시의 원답안 미열람 한계는 해소됐다. 그러나 이는 36개 greedy 정성 표본이지 자동 능력 점수가 아니다.

| 원답안 관측 | control-v2 | FineWeb2 |
|---|---:|---:|
| 후속 답안에 `같이 보기`·`각주`·`외부 링크` 중 하나 | 7/18 | 0/18 |
| 요구 `417`을 후속에 포함 | 0/4 문맥형 | 4/4 문맥형 |
| 요구 JSON 형식으로 유효한 출력 | 0/2 | 0/2 |

FineWeb2의 417 포함 네 답안도 문장·질문을 반복했으므로 짧고 형식에 맞는 답변 PASS가 아니다. control의 영어 `moon-47` 포함 한 답안도 동일 문장을 반복했다. 논리·부정 문항은 요구에 맞게 안정적으로 답하지 못했다. 표제 차이는 이 패널에서의 묘사이며 학습 source와 tokenizer가 함께 바뀐 조건의 인과 분해나 일반 지능 승격 근거가 아니다.
