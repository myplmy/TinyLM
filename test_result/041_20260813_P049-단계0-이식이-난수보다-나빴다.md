## 2. ★★핵심 발견 — **이식이 출발점을 2.31 nats 나쁘게 만들었다**

```
난수  10.4082
prop  12.7224      ← +2.3141  (나쁜 쪽)
```

★**부모초기화는 원래 출발점을 좋게 만드는 것**이다. 결과 038 §2 가 그 몫을 **+0.1386** 으로
쟀고, 결과 030 §9 는 임베딩 SVD 이식이 **핸디캡 0.1123 을 걷어냈다**고 했다.
**여기서는 정반대 방향으로 2.31 이 움직였다** — 크기도 그쪽들의 **20배**다.

### 2.1 `|logit|max` 가 원인을 가리킨다

| 모드 | `\|logit\|max` |
|---|---:|
| 난수 | **0.98** |
| prop | **15.94** (16배) |
| gate_scale | **18.75** (19배) |

**로짓이 폭주했다.** 모델이 **자신 있게 틀린다** → CE 가 균등분포보다 나쁘다.
(균등분포의 CE 는 `ln(V)` 가 **상한이 아니라 기준점**이다. 확신을 갖고 틀리면 그보다 나빠진다.)

### 2.2 ★기전 — **잔차 크기가 아니라 합성 불일치**

`Layer.forward`:
```python
x = x + gates[0] * attn(ln1(x) * a + a_shift, ...)
x = x + gates[1] * mlp(ln2(x) * m + m_shift, ...)
```

교사 층 `f` 는 **그 깊이에서 오는 입력 분포**에 맞춰 학습됐다.
복제하면 **`f` 에 `f` 자신의 출력을 먹인다**:

```
교사:  h ← h + f(h)                          (한 번)
학생:  h ← h + f(h) ;  h ← h + f(h + f(h))   (두 번, 두 번째는 본 적 없는 입력)
```

★**두 번째 통과의 입력은 학습 분포 밖**이다. 그리고 그것이 **18개 층에서 누적**된다.

> ⚠️★**이건 결과 020(P031, 추론 시 층 반복 종결)이 진단한 것과 정확히 같은 기전**이다.
> *"학습 분포와 mismatch"*. **결과 020 은 추론에서, 이 결과는 초기화에서** 같은 벽을 만났다.
> **두 관측이 서로를 지지한다.**

## 3. ★`gate_scale` 이 더 나빴다 — **이것이 진단의 열쇠**

| | CE | 해석 |
|---|---:|---|
| prop | 12.7224 | gate 그대로 → 총 잔차 기여 **2배** |
| **gate_scale** | **13.4782** | gate ÷ 2 → 총 잔차 기여 **교사와 동일** |

★**총 기여를 교사와 같게 맞췄는데 더 나빠졌다.**
→ **문제는 총량이 아니다.** 총량 가설이 맞았다면 `gate_scale` 이 이겼어야 한다.

**왜 더 나빠졌나**(가설): `gate_scale` 은 `lrep>1` 인 **모든** 층을 나눈다 —
즉 **원본 통과도 절반**이 된다. 그러면 네트워크가 **교사도 아니고 항등도 아닌** 중간 상태가 된다.
교사가 배운 `f` 의 기여가 절반이면 그 층의 역할 자체가 깨진다.

> ⚠️ **이건 가설이다.** 검정하려면 "첫 통과는 원본, 복제만 축소" 를 재야 하고,
> **그게 정확히 `identity`(복제 gate = 0)의 극단**이다(§4).

## 4. ★★조치 — `depth_init=identity` 신설 (2026-08-13)

### 4.1 왜 gate 하나로 되나

`gates` 는 **평범한 곱셈 잔차 게이트**다(`x = x + gates[k] * branch`).
→ **`gates = 0` 이면 그 층은 정확한 항등**이다.

**복제된 층(두 번째 이후)의 gate 만 0** 으로 두면:

```
학생 36층 = 교사 20층 + 항등 16층  =  함수로서 교사와 완전히 동일
```

★**step0 CE 가 교사의 val(약 3.81)과 같아야 한다.** 12.72 에서 **3.8 로 내려간다**는 예측이다.

### 4.2 문헌 정합

층 확장 시 **새 블록을 항등으로 초기화**하는 것은 표준이다
(bert2BERT / LLaMA Pro 계열의 zero-init block expansion — 출력 projection 을 0 으로).
⚠️ **논문 id 를 조회하지 않았으므로 인용하지 않는다.** 여기서는 **기법의 존재**만 언급한다.

★**우리 구조는 그보다 싸다** — 층별 residual gate 가 **이미 있으므로** projection 을 건드릴
필요 없이 **gate 하나면 된다.**

### 4.3 ⚠️ 남는 위험 — **항등으로 시작하면 학습이 그걸 깰 수 있는가**

gate 가 0 이면 **그 층의 gradient 도 0 근처**에서 시작한다(`∂L/∂gates = branch·∂L/∂x` 이므로
gate 자체의 gradient 는 0 이 아니지만, **branch 파라미터의 gradient 는 gate 배**라 작다).
→ **복제 층이 영영 안 깨어날 위험**이 있다. 그러면 36층이 실질 20층이 되고
**P049 의 질문에 답을 못 한다.**

**단계1 에서 확인할 것**: 학습 후 **복제 층의 `gates` 가 0 에서 떠났는가.**
안 떴으면 **깊이 축은 "항등 초기화로는 못 산다"** 가 결론이고, 그것도 정보다.
