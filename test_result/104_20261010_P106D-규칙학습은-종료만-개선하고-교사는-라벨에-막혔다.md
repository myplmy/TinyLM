## 3. 실제 문구·종료 개선과 실패의 해석

- 산수: 앞대화‘10+2→12’뒤‘첫수를31,둘째를23으로변경’의정답54에부모는‘12 됭’을반복했고fixed는‘12’,view는‘13’을냈다. 종료는배웠으나새조건의덧셈은안따랐다.
- Boolean: 앞답false 뒤 A=true/B=false로변경하면true여야하는예시에서도두학생은false를냈다.
- 표: 이전답빨강뒤같은표에서다른대상의노랑을물어도두학생은빨강을복사했다. 같은색상등‘앞답그대로맞는’문항4개만맞혔다.
- JSON: ‘앞답1을reply키에보존’의정답 `{"reply":"1"}`에fixed는 `{"answer":"2"}`,view는 `{"result":"20"}`을냈다. 외형은JSON이어도키·값의문맥보존은실패다.

두팔의 부모 첫답은각MAX_NEW63/EOS1이고 두학생은각STOP_SEQUENCE64/64였다. 이전답을복사하거나틀린짧은수/Boolean/JSON으로멈추는외형변화가정답8건보다넓다. **0→8을조건변경학습이나지능향상으로부르지않는다.**
현재fixed는C1에서항상기존조건을다시쓰는sham이고view는조건을바꾸는교육이어서, ‘epoch변형만의효과’와‘변경/미변경교육노출차이’가교락됐다. 새128update대조에서는두팔모두변경/미변경을균형있게가르쳐이문제를보완한다.

### 실제 답을 읽은 사례

사전 선정16문제×네 조건×세 모델을 원로그의 질문/원답에 결합했다. `handoff/audit/WIP_20261019_HISTORY_ACTUAL_DISPLAY16.json`은 근거 위치·본문SHA·전체 짧은 학생 답128개와 부모80자 발췌를 보존한다. 부모의 긴 본문 전량을 사람이 판독했다고 주장하지 않는다. 최소 개발 산수2개는 이16문제와 별도다.

- `12+2`의 정답14에 두 학생은13이라고 했다. 현재 `33+23`을 전부 적어도37/41, 자기 앞답 뒤 변경 요구에는64/70이었다. 산수 기초와 조건 전이 모두 미해결이다.
- 한국어 표 `가2=노랑, 나2=빨강`에서 먼저 나2를 물으면 둘 다빨강, 이어 가2를 물으면 둘 다노랑이었다. 같은 가2 독립 질문에는 둘 다빨강이었다. 같은 사실이어도 질문 경로에 따라 성공이 달랐다.
- `기록 값12→reply 키 JSON`에서 fixed는12만, views는독립질문에잘못된result 키를 썼지만 이력 후속에서는올바른reply 키를썼다. C3를 정답 교정으로 혼동하지 않는다.
- 별도 한국어 최소 질문의 `1+1`에는 fixed2/views`2+1`, `2+2`에는 둘 다5였다. 사용자의 짧은 원질문과 문구가 다르며 P106B 새896 모델과도 다른 CP다.

부모 C3 실제32개는 canonical JSON 참조+EOT가128을 초과했고 학생은32개 모두 예산 안이었다. 부모0/32를 예산과 무관한 내용 실패로만 해석하지 않는다. 그럼에도 모든 동등한 JSON 표현의 최소길이가128을 넘는다고 증명한 것은 아니며 후행 제외나 원답 절단도 하지 않았다.

### 판정·후속

**진단 완료·교육 효과의 범위는 국소적이며 자동 채택 없음.** 기존73/68은 old128·옛 정밀도/문자열 계약, 새74/67은 old64+fresh64·FP32 계약이므로 재현 성적의 직접 차이가 아니다. 원본·정답·모델은 그대로다. 공유MLP·재귀·KV 결함이나 컨텍스트 길이 부족이 이번 오답의 단독 원인이라는 증거도 아니다.

다음 학습 후보는 기초 상태/정답과 질문 표현·위치를 교차한 작은 새 교과과정이다. 같은 사실을 표현만 바꾼 예제 수를 새 지식량으로 부풀리지 않으며, 학습에 본 문구와 새 문구·새 수치·새 대상의 시험을 구별한다. 별도 학습률/자료 확대 또는 내부 추론 교육은 추가 변수로 남긴다. 기존75M×4epoch 목표·현재 자료 부족은 이 진단으로 해소되지 않았다.
