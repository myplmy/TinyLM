**게이트가 옳고 모델이 이상한 것처럼 읽힌다. 반대다.**

### 왜 3.8080 은 도달 불가인가

`init_from_dense` 의 중간 MLP 이식:

```python
mid_mlps[j // g] ← mean(교사 MLP g개)
```

`m100R1c` 는 `mlp_group=8` 이므로 **교사 MLP 8개가 평균되어 1개**가 된다.
→ **부모초기화된 타잉 학생은 교사가 아니다.** 교사 점수를 낼 수 **없다.**
오히려 3.8 근처가 나왔다면 **타잉이 안 걸린 것**이므로 그쪽이 이상 신호다.

### ★옳은 앵커는 **이미 저장소에 있었다**

> 같은 밤 `mC_g16` 은 **7.7742** 로 부모초기화 이득이 살아 있었다"*

## 4. ★★핵심 수치 — **반복의 출발 대가 = +0.1025 nats**

```
R=1.0  7.2799   (방문 20회)
R=2.0  7.3824   (방문 36회)          Δ = +0.1025
```

### 해석

| 관점 | 내용 |
|---|---|
| **크기** | 실무 분해능 0.024 의 **4.3배**. **유의한 차이다** |
| **부호** | ★**양수 = 반복이 출발점을 나쁘게 만든다.** 예상대로다 — 교사에게서 이식한 층을 두 번 지나면 잔차 기여가 중복된다 |
| ★**작다** | **그런데 생각보다 훨씬 작다.** P049(깊이 확장, 041 §13)에서 `prop` 이 `gate_scale` 보다 **+1.7270** 나빴다. **같은 "중복 잔차" 문제인데 크기가 17배 차이난다** |

### ★왜 P049 보다 17배 작은가 — **구조가 다르다**

| | P049 (물리 확장) | ★**P049B (학습시 재귀)** |
|---|---|---|
| 물리 층 수 | 20 → **36** (바뀐다) | **20** (안 바뀐다) |
| 깊이 사상 | 역할구간 비례, 교사 층 최대 2회 복제 | ★**항등**(층 수가 같다) |
| 이식 후 상태 | 교사와 **다른 구조** | ★**교사에서 완벽 이식** |
| gate 보정 필요 | ✅ `gate_scale`/`identity` 가 필요 | ⏸ **미검토** |

★**P049B 는 이식이 정확하다.** 대가 +0.1025 는 순수하게 **"같은 층을 두 번 지나는 것"**
의 비용이고, P049 의 +1.7270 에는 **깊이 사상 오차가 섞여 있다.**

> ★**이것이 P049B 를 재설계한 이유의 실측 확인**이다 — 계획서가
> *"층 수가 안 바뀌므로 항등 사상이라 구조적으로 깨끗하다"* 라고 썼고, **맞았다.**

## 5. ★`uniform` 은 정수 반올림이다 — **1.5 와 2.5 가 둘 다 2 다**

```
[repeat] ⚠️★uniform 은 정수 반올림이다 — train_repeat 1.5 -> 2 로 동작한다.
[repeat] ⚠️★uniform 은 정수 반올림이다 — train_repeat 2.5 -> 2 로 동작한다.
```

**세 값(1.5·2.0·2.5)이 CE 7.3824 로 완전히 동일하다** — 경고가 사실임을 데이터가 확인한다.

| 함의 | |
|---|---|
| ✅ **경고가 작동한다** | 조용한 실패가 아니다. 로그에 남고 결과문서에 옮겨진다 |
| ⚠️ **분수 배수는 `uniform` 으로 못 잰다** | 1.25·1.5 같은 격자가 필요하면 **`--repeat-mode progressive`** |
| 🚫 **단계1 격자에서 1.5·2.5 를 빼야 한다** | 안 그러면 **같은 점을 3번 재는 데 학습시간을 쓴다** |

★**2.5 → 2** 는 `round()` 가 아니라 **은행가 반올림(banker's rounding)** 의 흔적일 수 있다
(파이썬 `round(2.5) = 2`). 3배를 재려면 **`--train-repeat 3.0` 을 명시**할 것.
