## 2. ★도구 결함 3건 — 무엇이 왜 판정을 막았나

### 2.1 `torch.quantile` 이 dense 에서 죽는다 (치명)

```
RuntimeError: quantile() input tensor is too large
  diag_trapping.py:105  torch.quantile(r, ...)
```

`torch.quantile` 은 입력이 **2²⁴ = 16,777,216** 원소를 넘으면 실패한다. `weight_stats()` 는
TLinear **층마다 20만 표본**을 모으는데, dense 는 타잉이 없어 TLinear 개수가 많아
**30M 을 넘겼다**. 타잉 모델은 층 수가 적어 통과했고 **dense 만 골라서 죽었다**.

> **이게 왜 심각한가**: 배치 헤더가 스스로 적어 둔 설계 의도가
> “`p6d` 는 **양자화 구조가 없는 대조군**”이다. 즉 크래시한 것이 **혼란요인 제거 장치 그 자체**다.
> 남은 두 모델은 `g4+3:4` vs `g8` 로 **3:4 와 g 가 함께 움직인다** — 원래 대조군이 있어야
> 분리되는 조건인데, 그게 사라진 채로 “3:4 vs 비-3:4” 를 비교했다.

**수정**: `torch.cat` 이후 8M 로 한 번 더 표본추출(층별 표본을 이미 뽑았으므로 분위 추정은 불변).

### 2.2 ★모델마다 **다른 층**을 뽑아 놓고 평균 ER 을 비교했다

`grad_effective_rank()` 는 TLinear 목록을 **균등 간격**으로 6개 고른다. 그런데 TLinear 개수가
`g` 에 따라 다르므로 **뽑히는 층의 shape 집합이 모델마다 달라진다**:

| 순번 | mA 가 뽑은 shape | mC 가 뽑은 shape |
|---|---|---|
| 0 | (2048, 768) | (2048, 768) |
| 1 | **(768, 2048)** ← 차원 2048 | (2048, 768) |
| 2 | (768, 768) | **(192, 768)** |
| 3 | (768, 768) | **(192, 768)** |
| 4 | **(192, 768)** | (768, 768) |
| 5 | (768, 768) | (768, 768) |

ER 은 **차원으로 상한**되므로 차원 2048 짜리 층과 768 짜리 층의 ER 을 같은 평균에 넣으면
그 평균은 **아키텍처가 아니라 뽑기 결과**를 잰다. 로그의 “평균 ER 342.4 vs 362.3 → 차이 없음/반대”
는 **이 오염된 양**이었다.

**수정**: ① 판정을 `ER/차원`(차원 정규화)으로 옮기고 ② **shape 일치 층만 골라낸 표**를 함께 찍고
③ 뽑힌 층 **이름을 로그에 남긴다**. 평균 ER 은 “참고값”으로 강등.

### 2.3 `0 비율` 은 지표가 아니라 **제약값**이다

mA 의 0 비율 **25.00%** 는 측정값이 아니다. 3:4 는 **4개마다 정확히 1개를 0 으로 강제**하므로
25.00% 가 **정의상 확정**된다. 이걸 “3:4 가 0 을 덜 쓴다”는 관측으로 읽으면 **순환논증**이다.
(결과 016 §7.2 가 이미 같은 착시를 지적했다 — “3:4 는 희소화가 아니다”.)

**수정**: 3:4 모델이 포함되면 경고를 출력하고, 판정식에서 제외.

## 4. 그래서 지금 말할 수 있는 것 / 없는 것

**말할 수 있는 것**

- `mA`(g4+3:4) 의 latent 가 `mC`(g8) 보다 **더 양극화돼 있다**(골짜기 40.87% vs 48.09%).
- `mA` 의 `ER/차원` 이 낮다(37.34% vs 47.17%). **방향은 trapping 가설과 일치**한다.
- ER 추정 자체는 안정적이다.

**말할 수 없는 것**

- **“3:4 때문이다”** — g4 vs g8 이 함께 움직이고 **dense 대조군이 없다.**
- **크기 판정** — `ER/차원` 조차 뽑힌 층 집합이 달라 완전히 정합적이지 않다(§2.2).
- 도구가 출력한 “**한 지표만 지목 → 약한 증거**” 라는 문구는 **오염된 평균 ER 로 계산된 것**이다.
  수정 후 `ER/차원` 으로 다시 계산하면 판정이 바뀔 수 있다.
