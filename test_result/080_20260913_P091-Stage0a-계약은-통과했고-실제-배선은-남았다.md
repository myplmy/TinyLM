> **로그**: `080_log_20260919_P091_R2_layer_state_selector.txt` · exit 0 · CPU tiny model

actual TinyLM tiny 구조의 logical layer 6·unique MLP 4에서 세 deterministic window를 만들고,
MLP gate-zero 민감도 `S`와 weight decay를 제거한 optimizer-only update/weight `U`를 기록했다.

| 항목 | 관측 | 판정 |
|---|---|---|
| `S` 순위 상관 | window0 대비 **−1.0 / +0.4** | 🚫synthetic window 사이 안정성 없음 |
| `U` 순위 상관 | **+1.0 / +1.0** | update 크기 순위는 안정 |
| 배선·유한성 | logical 6, unique MLP 4, finite S/U, WD 분리 | ✅산식·mapping 계약 PASS |

따라서 exit 0은 **pipeline 계약 PASS**이지 selector 성공이 아니다. 계획의 실제 checkpoint
panel과 realized-gain R3 조건(`rho≥0.5`, top-2 재현)은 계속 `NOT_RUN`이며, 이 로그만으로
adaptive controller나 학습 SH를 열지 않는다.
