## 1. 결론 한 줄

🚫★**Δ = −0.0005.** 자(재귀 0.0018 / dense 0.0021)의 **1/4**, 이 조건 **시드쌍 폭 0.0014 의 1/3** 이다.
→ **계획 §5 의 사전 규칙 그대로 축을 닫는다.**

✅**되레 값어치가 있는 것은 "공짜가 아니었다" 는 쪽**이다: 배포 상주는 **+48 바이트**로 사실상 0 인데
**학습 VRAM 이 +6.1%**(9.72 → 10.32 GB) 늘었다. ★**추론 0 이 학습 0 을 뜻하지 않는다.**

## 2. ★무엇을 잰 팔인가 — **몸통을 먼저 적는다**

⚠️계획 §5.1 이 미리 적어 둔 대로, **이 팔은 dense 몸통에서 돌았다**(`--arch dense` = `tie_mlp=False`).

| 몸통 | 이 팔이 묻는 것 | 이번 |
|---|---|---|
| 타잉 | *"가중치를 공유해서인가, **스케일까지** 공유해서인가"* | 🚫**안 쟀다** |
| ★**dense**(우리 32 MiB 승자) | *"**WD 가 노름을 묶는 것** 자체가 손해인가"* | ✅**이것을 쟀다** |

★**그래서 이 결과가 닫는 것은 "dense 몸통에서의 LRM" 하나**다.
🚫**"LRM 이 쓸모없다" 로 일반화하지 않는다** — 논문의 주장은 **타잉되지 않은 대형 모델**에서 나왔고,
우리가 안 잰 팔(타잉 몸통)이 남아 있다. ⚠️**다만 우선순위는 최하위**다(§6).

## 3. 실측

### 3.1 플래그가 실제로 도달했다 (함정 37)

```
[P086] ★mlp_lrm=True — dense 중간층 8개에 gate·up·down 스칼라(24개). 추론 상주 증가 0
[P086] ⚠️dense 몸통이므로 **층마다 이미 자기 W** 가 있다 — 이 팔이 재는 것은
       *'WD 가 노름을 묶는가'* 이지 *'공유가 문제인가'* 가 아니다
```

json `mlp_lrm=True` · `params` 81,171,224 → **81,171,248 = 정확히 +24**
= **중간층 8 × (gate·up·down) 3.** ✅**부착 위치가 산술로 확인된다** — prelude·coda 에는 안 붙었다.

### 3.2 품질

## 5. ⚠️이 결과가 **닫지 못하는** 것

🚫★**"승수가 학습됐는가" 를 확인하지 않았다.** `params +24` 는 **존재**의 증거이지
**1.0 에서 움직였다**는 증거가 아니다. WD 0.01 이 1.0 쪽으로 당기므로 **거의 안 움직였을 가능성**이 있고,
그 경우 이 런은 *"LRM 이 효과 없다"* 가 아니라 ***"LRM 이 켜지지 않았다"*** 를 잰 것이 된다.
🚫**함정 37 의 네 번째 얼굴** — *플래그가 도달했다 ≠ 그 파라미터가 학습됐다.*

✅**대응**: `scripts/diag_lrm_values.py` 신설(체크포인트만 읽는다 · 학습 0 · GPU 0).
24개 스칼라의 **최소·최대·평균·`|s−1|` 최대**를 인쇄하고, **전부 1.0 에서 1e-4 안이면 exit 1**(R19).
→ ★**그 게이트를 통과해야 이 §1 결론이 확정**된다. 배치 `run_P086_Stage3_lrm_values.bat`.

## 6. 판정 — 계획 §5 의 사전 규칙대로

| 사전 규칙 | 이번 값 | |
|---|---|---|
| Δ ≤ 0.0018 → 🚫**축을 닫는다** | **−0.0005** | ✅**해당** |
| Δ > 0.0018 그리고 상주 불변 → 채택 | — | 해당 없음 |
| ms/step −5% 초과 손해 → 교환비 재검토 | +0.98% | 해당 없음 |

→ 🚫★**dense 몸통 LRM 종결**(단 §5 게이트 통과가 조건).
🚫**Stage3(행 승수 `row`)는 열지 않는다** — 스칼라가 0 이면 행으로 키울 근거가 없다.
⏸**방문별 스칼라**(계획 §5.1 이 남긴 Stage3 후보)는 **살려 둔다** — 스칼라가 층을 구분해도 이득이
없다는 것과, **같은 층의 1회차·2회차를 구분해도 이득이 없다**는 것은 **다른 명제**다.
