⚙**예측 적중**: 배치 헤더가 *"약 57.2M / 약 469.6 MiB"* 라 적었고 실측이 **57.2M / 469.7 MB**.

## 8.2 ★★★핵심 — **깊이 축의 효율이 5배 올랐다**

`mC_wsd` 를 기준으로 **더한 유니크 삼진당 얻은 nats**:

| 구성 | Δ유니크삼진 | Δ품질 | **nats / 100만** | 비 |
|---|---:|---:|---:|---:|
| `mC_d36`(어텐션 독립) | **+21.25M** | −0.0250 | **0.00118** | 1.0 |
| ★**`mC_d36_ag2`** | ★**+2.35M** | **−0.0138** | ★**0.00587** | ★**5.0배** |
| (참고) 빼는 방향 `g16` | −4.71M | +0.0161 | 0.00342 | — |

> ★★**어텐션 18.9M 을 지웠더니 품질은 0.0112 만 잃고 효율은 5배가 됐다.**
> 그리고 **더하는 방향(0.00587)이 빼는 방향(0.00342)보다 높다** —
> ⚠️**결과 041 §14.3 의 "볼록성: 더할 때가 뺄 때의 1/2.9" 는 `mC_d36` 한 점으로 유도한 것**이고,
> **그 점이 낭비를 포함하고 있었다.**

### 8.2.1 🚫**결과 041 §14.3 의 볼록성 결론을 부분 정정한다**

| 판 | 주장 | 상태 |
|---|---|---|
| 041 §14.3 | *"볼록성이 더하는 방향에서도 성립한다. 더할 때가 뺄 때의 1/2.9~1/3.8"* | ⚠️**부분 철회** |
| ★**이번** | **낭비를 제거하면 더하는 방향이 빼는 방향보다 1.7배 효율적**이다 | ✅ 실측 |

> ★**볼록성 자체를 부정하는 것은 아니다.** 확인된 것은
> **"우리가 잰 '더하는 방향' 한 점이 비효율적인 구성이었다"** 이다.
> **REVIEW2 §8 의 열린질문을 "닫혔다" 에서 "부분 답" 으로 되돌린다** —
> 진짜 볼록성 검정은 **같은 축을 두 크기로** 재야 한다(예: d36_ag2 vs d28_ag2).

## 8.3 ✅**gate probe — 공유해도 어텐션은 여전히 꺼진다**

| | `mC_d36`(어텐션 독립) | ★**`mC_d36_ag2`**(공유) |
|---|---|---|
| 어텐션 복제층 `\|g\|` | 0.10798 | **0.09434** |
| 어텐션 비복제층 `\|g\|` | 0.38765 | **0.39725** |
| 비 | 0.279 | ★**0.237** |
| 어텐션 `move` 복제 / 비복제 | −0.4952 / +0.2560 | ★**−0.5443 / +0.3005** |
| MLP 복제층 `\|g\|` | 0.21691(1.434배) | **0.21758(1.455배)** |
| MLP `move` 복제 / 비복제 | +0.4380 / −0.2884 | **+0.4476 / −0.2982** |

★**두 런이 소수점 둘째 자리까지 같은 패턴**이다 —
**어텐션을 공유하든 안 하든 복제층 어텐션은 꺼지고 MLP 는 깨어난다.**
→ **결과 041 §15 의 관측이 다른 아키텍처에서 재현**됐다. **우연이 아니다.**

⚠️**판정 줄은 여전히 "안 깨어났다" 로 찍힌다** — 부호를 안 보는 도구 결함(041 §15.2.1) **미수정**.

## 8.4 ⚠️`grad_max` 가 절반 이하로 떨어졌다

`mC_d36` **2.1408** → `mC_d36_ag2` **0.9568**(−55%).
어텐션을 묶으면 **gradient 가 안정된다** — 결과 029(g16 에서 0.847 → 0.738)와 같은 방향이다.
**타잉은 gradient 를 줄인다**는 관측이 세 번째다. ⚠️기전 미규명.

## 8.5 ⚠️한계 — **연산은 안 줄었다**

`토큰당 FLOPs 0.446` 이 `mC_d36` 과 **완전히 같다.**
`report()` 의 FLOPs 식에 **`attn_group` 이 없다**(`mlp_group`·`cla_group` 과 같은 계열 — 함정 25).
그리고 실제로도 **forward 는 전 층을 지난다** — 어텐션을 공유해도 **호출 횟수는 그대로**다.
**줄어드는 것은 저장·상주뿐이다.** 벽시계 201.9 vs 203.4분(−0.7%)이 그것을 뒷받침한다.

⚠️**삼중 교락 그대로**: `cla_group=2` + `attn_group=2` + 깊이 확장.
**`cla_group=1` 대조 없이는 "어텐션 타잉의 대가" 를 귀속할 수 없다.**
