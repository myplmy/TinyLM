## 2. ★핵심 질문 — **0.017 은 무엇인가**

같은 시드, 같은 명령, 같은 데이터 캐시. 그런데 **final 이 0.0171 다르다.**

| 후보 | 크기 감각 | 검정 |
|---|---|---|
| **① 비결정성**(TF32·`cudnn.benchmark`·`torch.compile`) | ★**dense·무교사 σ = 0.0109**(결과 009 §P012B) — **같은 자릿수** | 같은 조건 1회 더 |
| ② 드라이버·torch·cuDNN 버전 차이 | 미지 | 원본 로그의 버전 배너 대조 |
| ③ 데이터 캐시가 그때와 다르다 | 미지 | `diag_cache.py` |
| ④ 원본이 애초에 다른 조건 | 미지 | 결과 001 원문 대조 |

> ★**①만으로 설명 가능한 크기다. 하지만 "설명 가능하다" 와 "설명했다" 는 다르다.**
> 그리고 **틀렸을 때의 대가가 크다** — ②나 ③이면 **"같은 명령이 다른 모델을 만든다"** 는 뜻이고,
> 그러면 **이 저장소의 모든 과거 판정의 전제가 흔들린다.**

### 2.1 ⚠️ `final` 과 `best` 가 **같은 방향으로** 움직였다

−0.0171(final) 과 −0.0138(best)이 **둘 다 좋은 쪽**이다. 순수 노이즈면 부호가 갈릴 수도
있는데 안 갈렸다. **다만 두 값은 같은 런에서 나온 것이라 독립이 아니다** — 이 관측은 약하다.

### 2.2 ★단계2 가 이걸 정확히 가른다

```
python scripts\paired_eval.py --preset m100 --arch dense --data ko-en --tokens 300M --models dense denseb
```

`paired_eval` 은 **같은 크롭 위에서** 두 체크포인트를 비교해 **eval 샘플링 노이즈를 0** 으로 만든다.
남는 차이가 **진짜 학습 차이**다.

| paired Δ | 판정 |
|---|---|
| **< 0.011** | ①비결정성. **정상** — 저장소 재현성에 문제 없다 |
| 0.011 ~ 0.024 | 경계. ②③을 더 본다 |
| **> 0.024** | ⚠️★**재현성 문제로 격상.** 최우선 조사 |
