   층별 residual은 완화 공유다. 모두 [P093](../test_plan/P093_구조조건부-직접공유와-완화타잉.md)에
   `DESIGNED`로만 열었으며 TinyLM 품질 증거는 0런이다.
3. anneal C안 A0~A2는 `STATIC_ONLY`로 구현됐다. 기존 LR 전 구간 수치 일치와 CPU audit fixture
   4/4는 통과했지만 실제 학습 on/off 동일성·오버헤드·0.60/0.80 동역학 A3와 현재 트리 스모크는

### 2.1 체크포인트 보존성 재감사

- 종전 431행(`keep 46 / hold 272 / delete 113`)에서 현행 463행(`keep 67 / hold 238 /
  delete 158`)으로 갱신했다. 새 32개는 `keep 12 / delete 20`으로 편입했다.
- 기존 판정 37개는 `hold→delete 26`, `hold→keep 8`, `delete→keep 2`, `keep→delete 1`로
  근거를 다시 썼다. P005의 763-step 탐색 팔과 P086 vector-LRM 종결 팔은 삭제 후보로,
  P005b Stage10~12·P093의 final 대조군은 보존으로 옮겼다.
- 스모크 dense final과 best는 KD child의 부모 계보를 cleanup G1이 실제 보호하므로 종전
  `delete`에서 `keep`으로 되돌렸다. 반대로 결과와 final이 정본인 후속 미참조 `_best`는
  개별 근거가 있을 때만 삭제 후보로 내렸다.
- `python -I -X utf8 -B scripts/ckpt_audit.py`는 디스크 418·표 463·미등재 0으로 통과했고,
  `python -I -X utf8 -B scripts/cleanup_ckpt.py`는 113개·33.3GB를 보인 뒤
  `[DRY-RUN] 아무것도 지우지 않았다`로 끝났다.

### 2.2 타잉 재평가와 P093

- 내부 대조는 결과 079의 동일 Muon·d12·CLA2·무재귀 paired full-val을 사용했다:
  dense 3.5745, `g2` 3.6084(+0.0340), `g4` 3.6324(+0.0579), `ag2` 3.5818(+0.0073).
  따라서 같은 폭·같은 연속 배치·같은 optimizer의 exact 공유 반복은 금지했다.
- [One Wide Feedforward is All You Need](https://arxiv.org/abs/2309.01826)는 공유 FFN을 넓힌
  구조, [Lessons on Parameter Sharing](https://arxiv.org/abs/2104.06022)는 sequence/cycle 배치,
  [Understanding Parameter Sharing](https://arxiv.org/abs/2306.09380)는 반복 사용 weight의
  gradient·수렴 차이를 보고한다. 이는 P045B와 독립 변수가 실재한다는 근거일 뿐 TinyLM 승리
  증거는 아니다.
- P093은 E0 기존 exact 공유, D 구조조건부 direct-core, R low-rank 완화 공유를 분리한다.
  Stage0에서 중복·unique/packed/resident byte·optimizer state·FLOPs·방문 수를 먼저 계산하고,
  순배포 절감 15% 이상·기본 트랙 FLOPs 증가 10% 이하를 통과해야 구현 범위를 다시 고정한다.
- Stage2 preflight는 250 step = 32.8M 학습토큰, Stage3는 2289 step = 300.0M이다. P045B와
  같은 600M exact pool을 고정하면 2배 풀 규약을 만족한다. tag·명령·배치는 만들지 않았다.

### 2.3 anneal C안 A0~A3

- `anneal_schedule.py`가 LR cooldown, ternary quantization 전이, Arenas/LoRA 보조경로 제거의
  식을 따로 소유한다. 회귀 fixture는 종전 LR 식을 모든 step에서 `==`로 대조한다.
- `--anneal-audit`, `--anneal-audit-every`, `--anneal-audit-max-modules`를 default-off로
  추가했다. fresh run에서만 유니크 TLinear 최대 8개를 고르게 골라 quant 거리, code flip,
  음/0/양 점유, 경계여유, clip 뒤 gradient RMS, weight-decay 포함 update RMS를 JSONL에 남긴다.
- `.contract.json`에는 모델 설정뿐 아니라 preset·arch·data·학습/풀 토큰·exact-cache·배치·seq·LR·
  optimizer·Muon 규약·seed·스케줄·부모·tag를 기록한다. 기존 산출물 덮어쓰기와 `--resume`을 거절한다.
- 처음 제안했던 “같은 late checkpoint 재생”은 서로 다른 앞선 anneal 이력을 복원하지 못하므로
  폐기했다. A3는 같은 300M 부모·seed·data order에서 step 0부터 시작하는 0.60/0.80 두 trajectory와
  0.80 audit-off 한 팔이다. 세 run은 32.8M 학습토큰이고 checkpoint 최악 약 5.6GB를 만든다.
- 기본 Python은 PyTorch가 없어 수식 3 PASS·audit 1 skip이었다. `collatz_torch` CPU fixture는
  4/4 PASS이고 실제 CLI 도움말에서 새 플래그 3개를 확인했다. 처음 도움말 호출에 부적합한 `-I`를
  붙여 repo root를 import path에서 제거해 실패시켰으나, `-I` 없는 실제 호출은 exit 0이었다.
