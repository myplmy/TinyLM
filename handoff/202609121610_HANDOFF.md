## 1. 가장 중요한 것 세 가지

1. 최신 핸드오프가 직전의 8배치·48.4h 큐를 1행으로 축소한 것은 판단오류다. 파일 8/8, TSV↔디스크 감사 0건, 현재 id 3~10을 확인해 §7에 전수 복원했다. **1번만 유효하다는 뜻이 아니며**, 첫 배치도 공통 선결 전에는 실행 대기다.
2. `202609120551_HANDOFF.md` 이후 코드 파일 `.codex/check_environment.py`가 바뀌었고 프로젝트 스모크는 `NOT_RUN`이다. 사용자가 P088 종료·GPU 유휴 뒤 `run_smoke_check.bat`를 실행해 PASS를 확인하기 전 48.4h 큐를 시작하지 않는다. Codex는 이를 직접 실행하지 않는다.
3. 12번은 **제안서 작성 단계에서 완료**됐다. 임의 핸드오프 Markdown 절에는 자동 소비 계약이 없지만, 공식 훅의 `SessionStart(source="compact")`는 압축 직후 `additionalContext`를 줄 수 있다. 권장 B안은 열린 WIP 상태 캡슐·압축 전 최신성 게이트·압축 후 재주입·수동/자동 E2E를 결합한다. 실제 훅·설정·스킬·양식 변경은 여전히 승인 전 `NOT_RUN`이다.
