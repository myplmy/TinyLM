## 1. 가장 중요한 것 셋

1. **실행 완료와 기능 PASS는 다르다.** 원본 23개 로그 중 P100은 첫 출력 성공/동일 출력 재시도 오류가 한 파일에 공존한다. P101A 실제 M0 1e-5 문턱, P103A 경계 두 건, Windows M5는 기능/경로 오류다. P092의 상주·속도 음성과 P097의 과제별 교환은 오류가 아닌 과학적 관측이다.
2. **교정 코드는 정적·순수 fixture만 검증됐다.** P103A 하부 비등록 MLP freeze, P104A Z/UNC 루트 상대 키, P101A 독립 팔 귀속을 새 단계 런처로 분리했다. 사용자 CPU 모델·Windows/GPU 재실행은 `NOT_RUN`이며 기존 실패를 소급 PASS로 바꾸지 않는다.
3. **공개 SFT는 아직 학습 자료가 아니다.** 한국어 공감형 구조 후보18,567·OASST2 번역 후보1,153은 사람 품질·권리·오염 미검증이다. 사용자 최신 WSL smoke는 42팔 실패0이었으나 이후 코드가 바뀌어 새 트리 smoke는 `E2E_NOT_RUN`이다.
