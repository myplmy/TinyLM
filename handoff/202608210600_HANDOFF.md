1. ★★**핸드오프 양식 드리프트는 내 부주의가 아니라 정본이 둘이었기 때문이다.**

2. ★**마운트에서 `mv` 는 된다.** `CLAUDE.md` 가 *"rename/unlink 차단"* 이라고 적고 있었지만
   실측하니 **`rm` 만 차단**이었다. **결과문서 개명을 그동안 불필요하게 사용자에게 부탁했고**,
   그 사이 낡은 제목이 **의사결정 함정 D3**(끝난 P028 재제안)을 일으켰다.
3. ★**A3 가 3회 연속 "미측정" 이었던 이유는 로깅 부재가 아니었다.**
   **eval 격자와 KD 격자가 구조적으로 만나지 않는다** — eval 은 `s ≡ 99 (mod 100)`,
   KD 는 `s ≡ 0 (mod 4)`, 그런데 `100 ≡ 0 (mod 4)` 이므로 **`99 mod 4 = 3` 이 항상**이다.
   → 23개 eval 중 **KD 스텝은 마지막 1개뿐**. 진단이 *"json 에 history 가 없다"* 라고
   **오진**하고 있었다.

## 5. ★지시 (5) — 선결 없는 미구현 **4건 구현**

### 5.1 ★★A3 — 3회 연속 미측정의 **진짜 원인**

```
eval  s ≡ 99 (mod 100)      KD  s ≡ 0 (mod kd_every=4)
100 ≡ 0 (mod 4)  →  99 mod 4 = 3  이 **항상**
→ 23개 eval 중 KD 스텝은 마지막 1개뿐
```

실측(`m100R1c_..._mC_g16.json`): `history` 23행 중 **KD 스텝 1행**. 감사가 `>= 3` 표본을
요구하니 **영원히 못 모은다.** 진단은 *"json 에 history 가 없다"* 라고 **오진**했다.

★**조치**: `trainer.py` 가 **런 전체 누적 평균**을 남긴다 —
`kd_step_loss_mean` / `nokd_step_loss_mean` / `kd_step_ce_mean` / `nokd_step_ce_mean` / n.
**합계만 세므로 계산은 비트 동일.** `diag_kd_loss.py` A3 가 이걸 읽고,
없으면 **격자 어긋남을 설명**한다.

> ★**순수 CE 쪽이 같아야 정상**이다. 혼합손실은 스케일이 다른 게 당연하다.

### 5.2 A5 + `--real` 구현 (결과 042 §10.9 의 2·4번)

### 5.3 ★P057 — 그룹평균 어텐션 이식 (가드 해제)

종전엔 `NotImplementedError` 가 막고 있었다. 이유: 공유 어텐션에 층별 이식을 하면
**마지막 교사 층 값만 남고 앞것이 조용히 덮인다.**

```python
for j, at_s in enumerate(student.mid_attns):
    members = [teacher.layers[lmap[sc.n_prelude + k]].attn_mod
               for k in range(j * ag, (j + 1) * ag)]
    for nm in ["q_proj","o_proj"] + (["k_proj","v_proj"] if at_s.owns_kv else []):
        getattr(at_s, nm).weight.data.copy_(
            sum(getattr(mm, nm).weight.data for mm in members) / len(members))
```

★**`mid_mlps` 와 같은 규약**(그룹 평균)이라 코드가 대칭이다.
`shared_done` 집합으로 **재복사를 차단**하고, **`attn_group=1` 은 비트 동일**.
⚠️**평균이 옳다는 보장은 없다** — 어텐션은 위치별 패턴이 층마다 크게 다를 수 있다. 게이트가 잰다.

### 5.4 ★P061 — `mlp_split` 구현

계획 §2.1 이 경고한 것: *"불균등이면 그룹마다 크기가 다르다. 빠뜨리면 결과 041·P057 과 같은 함정"*

★**그래서 `j // g` 를 두 곳에서 쓰는 구조 자체를 없앴다:**

```python
# config.py — 단일 소스
def mlp_group_index(cfg, j):    return bisect_right(split, j) if split else j // cfg.mlp_group
def mlp_group_members(cfg, gi): ...
```

`transformer.py` 와 `init_utils.py` 가 **둘 다 이 함수를 부른다** — 함정 18 의 구조적 예방.

**검산(torch 없이 16층 전수):**

| 안 | split | 유니크 | 그룹 크기 |
|---|---|---:|---|
| 기준 g8 | `()` | 2 | `[8, 8]` |
| **A 앞무겁게** | `(12,)` | **2** | `[12, 4]` |
| **B 뒤무겁게** | `(4,)` | **2** | `[4, 12]` |

✅ `split` 이 비면 `j // g` 와 **완전히 동일**(비트 동일) ✅ A·B 둘 다 **메모리 동일**
