### 2.1 CPU·GPU 병행과 종료 회수

11월 18일 21:09부터 19일 00:40 KST까지 WSL CPU와 RTX 4070 Ti SUPER 한 장을 사용했다. 초기 정확 채점 두 실행은 각각 256행을 저장한 뒤 다음 구간의 비용 한도로 종료 8이었다. 마지막 재개는 상한을 1,800초로 조정해 26구간을 마쳤으며 00:37:06 종료 0이었다. Luna Max는 GPU 진척·종료·반환만 확인했다.

GPU가 동작할 때 기존 NativeQ 19,965문항과 Bonsai 완료 다섯 과제의 대응을 CPU로 검산했다. 전 어휘 CPU 검산에서 최초 KL 기준의 오차를 확인해 대기 중이던 작업을 GPU 실행 전에 교정했다. 기존 G4의 strict 로딩, CPU backward 및 R1/R2/R3 캐시도 확인했다. HellaSwag 반환 2초 뒤 GPU 학습을 자동 시작했고 CPU는 공식 집계를 병행했다.

두 최초 학습은 allocator 0과 소스 일치를 묶은 종료 검사에 걸려 상세 수치를 저장하기 전에 종료 1이었다. 복구는 저장 직전 allocated/reserved와 소스 지문을 각각 기록하고 프로세스 종료 후 GPU를 독립 조회했다. 두 GPU 종료는 모두 0이며 마지막 반환에서 compute PID 없음과 여유 14,926MiB를 확인했다.
