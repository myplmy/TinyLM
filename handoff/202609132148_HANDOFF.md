## 1. 가장 중요한 것 셋

1. 21:09 스모크의 실패 2건은 모델 품질 실패가 아니다. `check_attrs`의 다른 config 타입 오탐 1건과 직접 실행 진단의 저장소 import 경로 누락 1건이다. 두 직접 원인은 고쳤지만 AI가 모델·스모크를 실행하지 않았으므로 새 사용자 스모크 전에는 큐를 열지 않는다.
2. `check_pending`의 W2는 정확한 `PNone`과 비어 있지 않은 사유가 함께 있을 때만 비실험으로 면제한다. P030 두 건은 실제 실행 로그를 인식하고 계획을 완료 상태로 맞췄고, P037 한 건은 현행 스모크 이름과 미구현 범위를 명시한 대기로 맞췄다. 회귀 4/4와 전체 오류 0·경고 0을 확인했다.
3. B2 활성 감사는 이제 Codex 문서 14개만 본다. 또한 이번 실제 auto compact에서 이 세션 ID와 결합된 `WIP_20260913i` 캡슐이 정확히 복구됐지만, 이것은 exact-match auto 경로만의 실제 증거이며 수동·0매칭·WIP deny·프로젝트 스모크까지 종합 PASS라는 뜻은 아니다.
