## 작업 로그 (append-only)

- `2026-09-06` 착수 준비. 신규 스모크의 3:4 패킹 동적 계약 통과를 확인했다.
- `착수` **1번** — P014 계열 사용자 로그와 현재 ternary_kernel.py를 대조해 Windows/Triton 환경 실패와 구현·통합 결함을 분리하고, 실패를 숨기지 않는 계약 진단 및 커널 경로를 구현한다.
- `착수` **2번** — 5비트 포맷은 학습 forward에서 소비되지 않아 학습시간을 줄이지 못한다는 호출경로를 확인했으므로, 1.25bpw 스트림을 직접 소비하는 3:4 전용 CPU LUT 커널과 모델 배포 경로를 구현한다.
- `완료` **1번** — P014 정본에서 과거 실패를 anneal 누락, Triton constexpr 위반, Dynamo 재컴파일로 확정하고 strict backend telemetry와 현재 Windows 사용자 환경용 합성 진단을 구현했다. 실제 launch는 사용자 Stage0 대기다.
- `완료` **2번** — 5비트 포맷이 학습 forward에 호출되지 않음을 확정하고, 행별 packed stream을 직접 읽는 32-state native C++ CPU LUT, PyTorch oracle, 모델 배포 연결, 메모리 회계와 사용자 Stage1/2 계약을 구현했다. 빌드와 속도는 사용자 실행 대기다.
