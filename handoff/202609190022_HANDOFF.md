## 1. 가장 중요한 것 셋

1. **실험 로그 유실 원인은 `run_queue.sh`가 아니라 WSL launcher 4개의 `runlog.py` 우회다.** queue는 선택 항목을 끝까지 실행하고 실패를 집계했다. `TL_OUTDIR`도 logger를 호출하지 않으면 효과가 없다. 네 SH를 logger에 연결했고 향후 어떤 `run_P*.sh`도 logger가 없으면 정적 검사가 실패한다.
2. **최신 smoke는 마지막 session 기능 결과만 42/42 PASS이다.** 같은 파일에 두 회차가 합쳐져 두 번째 회차의 commit 귀속이 불완전하고, 그 뒤 logger를 바꾼 현재 tree는 `E2E_NOT_RUN`이다. smoke PASS 하나로 M4·M5·M6를 대체할 수 없어 WSL 제안서는 진행 중이다.
3. **다음 과학적 우선순위에 즉시 실행 가능한 새 학습 SH는 없다.** P096 Q1b → P093 Stage0a/0b → P091 R0/R1b → P022C C1 → P092 Stage1a → P095 S0b 순이며, 모두 구현이 먼저다. P094는 P022C 증거 전 HOLD, P025B 현 runtime 가속 분기는 종료다.
