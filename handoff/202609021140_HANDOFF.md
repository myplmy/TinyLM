## 1. ★가장 중요한 것 셋

### 1.1 ★★★**32·40 MiB 예산의 승자가 둘 다 바뀌었다 — 그리고 REVIEW3 에 없던 조합이다**

**(LUT + latent 해제 + 임베딩 int8, KV bf16 @ seq 1024)**

| 예산 | ★**새 승자** | full-val | 합계 | 종전 최선 | 개선 |
|---|---|---:|---:|---|---:|
| ★**32 MiB** | **`d12_cla2_r20`** | **3.6054** | **30.7** | `mC_cla2_ag4_r20` 3.6889 @ 30.3 | ★**−0.0835** |
| ★**40 MiB** | **`d16_cla2_r20`** | **3.5642** | **38.5** | `d16_dense` 3.5757 @ 40.4 | ★**−0.0115 이고 −1.9 MiB** |

★★**40 은 파레토 지배다** — 품질도 좋고 메모리도 작다.
둘 다 **dense 몸통 + `cla_group 2` + 재귀 R2** 이고 🚫**REVIEW3 네 안 어디에도 없다**
(네 안은 전부 **20층 타잉 몸통** 위에서 그렸다).

**왜 되나**(d16 분해): `cla2` 가 품질 **+0.0210** 을 받고 KV 를 **12.0 → 6.0** 으로 반감,
재귀 R2 가 품질 **−0.0325** 를 돌려주고 KV 를 **6.0 → 10.5** 로 늘린다.
★**두 레버가 서로의 대가를 갚는다.**

🚫★**그리고 `mlp_group`(MLP 타잉)은 잰 전 구간에서 지배당했다**:
대가가 d8 **+0.0637** → d12 +0.0941 → d16 **+0.1049** 로 **깊을수록 커진다.**
같은 상주에서도 진다(`d16_g4` 25.7/3.6806 vs `d8_dense` **24.6/3.6776**).
⚠️★**"타잉 종결" 이라 쓰지 않는다** — 반증된 것은 `mlp_group` 이고
**`cla_group` 과 재귀는 승자의 부품**이다. 한 단어가 세 축을 가리켜 왔다(함정 28).

⚠️★**승자 둘 다 1시드다.** 40 예산의 −0.0115 는 dense 자(0.0021)의 **5.5배뿐**이라
시드가 부호를 바꿀 수 있다 → **큐 1번이 그것을 잰다**(⚙4.0h).

### 1.2 🚫★★★**자명 기준선 52.0% 는 내 계산 오류였다 — 실제 30.3% 이고 통과다**

동점을 반영한 실측: **v2.3 토큰 최단 30.3%(z +2.1)** · 최장 18.6%(z −2.6) ·
문자 **25.0 / 25.0%** → **네 축 전부 |z| ≤ 3 통과.**

★**왜 틀렸나**: 로그의 `순위 156/41/73/30` 은 **경쟁 순위**라
`sum(1 for x in L if x < L[ci]) + 1` 로 계산된다 — **정답이 최솟값과 *같기만* 해도 1위**다.
토큰 길이가 중위 21 의 작은 정수라 동점이 흔하고, 길이 선택기는 동점에서 **1/k 로만** 맞는다.
→ `156/300 = 52.0%` 는 *"정답이 최단과 동점 이상인 비율"* 이지 *"최단 선택기 정답률"* 이 아니다.

⚠️★**§7.6 에 "동점 미반영" 이라 유보를 적어 두고도** 제목·§6 결론·지난 핸드오프·
기준표 B.13.7·`CLAUDE.md` 에 **52.0% 를 그대로 옮겼다.** 자백 원장 **A17**.

→ ★**결과 068 §6 의 "지금 쓰면 안 된다" 를 철회한다.** 문서도 개명했다
(`…토큰-길이는-52퍼센트를-준다` → `…52퍼센트는-내-계산-오류였다-실제는-30퍼센트고-통과다`).
**기준표 B.13.7 폐기 → B.14.5 가 정본.**

### 1.3 ★★**재귀 자가 0.0018 로 커졌고, "두 점은 과대평가한다" 는 철회한다**

진짜 세 번째 시드가 두 몸통에서 둘 다 돌았다.
