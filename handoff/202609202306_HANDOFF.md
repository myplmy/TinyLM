## 1. 가장 중요한 것 셋

1. **세 실험축의 구현 선결은 해소됐다.** P097 Stage2W, P076 Stage2W, P060B Stage1W가
   `experiments.tsv`와 Linux queue에 등록됐고 정적 preflight를 통과했다. GPU·학습·모델 평가는
   실행하지 않아 과학 판정은 아직 없다.
2. **W&B WSL 계약은 코드상 고쳐졌지만 원격 전송은 확인하지 않았다.** full run만 exact raw tag와
   eligible JSON 1건을 요구하며 optimizer·Muon·WD·CLA를 보존한다. 50M 미만 probe는 업로드하지 않고,
   remote 실패가 학습 JSON이나 학습 종료코드를 덮지 않는다.
3. **P014D native v0는 “컴파일됨”이지 “빠른 커널”이 아니다.** 2-D·3-D·TLinear 정합은 PASS했고
   Python reference보다 1.36~2.42배 빨랐지만 합성 dense 대비 0.288~0.731배다. actual model decode와
   SIMD/T-MAC 계열 통합은 `NOT_RUN`/미구현이다.

### 2.1 W&B WSL 사후 전송 계약

- WSL/Linux에서 `TL_WANDB_KEY_FILE`을 명시하지 않으면 비밀 위치를 추측하지 않고 중단한다.

- payload에 `optimizer`, `muon_scale`, `muon_lr_mult`, matrix WD, CLA, tokenizer/data 계열을 추가했다.
- `tool_wandb_push.sh`는 학습 성공 뒤에만 호출하며 remote 장애는 경고로 남기고 학습 결과를 보존한다.
- P097 기존 네 JSON dry-run은 각 config54·summary30·history23으로 확인했다. login/push는 0건이다.

### 2.2 P097 Stage2W

- `eval_bench_suite.py`에 모델별 `data/tokenizer/arch`를 추가해 단일 tokenizer 강제 결함을 제거했다.
- 동일 task ID로 KoBEST COPA/HellaSwag, KLUE YNAT/NLI, ARC-Easy, HellaSwag를 평가하고 공통 SQuAD
  byte-bpb와 고정 prompt continuation을 별도 기록한다.
- checkpoint 4개·train JSON 4개·기존 benchmark 4개·공통 원문은 존재한다. 정확히
  `datasets/bench/klue_ynat.jsonl`, `datasets/bench/klue_nli.jsonl`만 없다.
- 자기 val 3.5133/3.8828/3.9858/4.0261은 서로 다른 tokenizer·val이라 교차 순위로 쓰지 않는다.

### 2.3 P076 Stage2W와 P060B Stage1W

- P076은 같은 dense parent와 current Muon RMS4×4·CLA2·KD off·300.024M 조건에서
  `mean/middle/norm_mean`만 바꾼다. 한 팔 실패에도 나머지를 수집하지만 paired 평가는 중단한다.
- P060B는 m100s10 dense의 off/on 두 250-step 팔에서 `on/off ms≤1.05`와 reserved VRAM
  절감 10% 이상을 함께 요구한다. 유효 음성은 exit8이고 품질 판정은 하지 않는다.
- 과거 Windows `mC_gqa_off/on250`의 on 약 1.96배 지연·VRAM 5.07→6.45GB 음성은 보존한다.
  새 실험은 환경·모델·optimizer가 다른 독립 WSL stratum이다.

### 2.4 P014D native CPU LUT v0

- 기존 `lut.py`는 `einsum+gather` reference, `_weight_int8pack_mm`는 int8 우회,
  `ternary_kernel.py`는 GPU 학습 Triton이라 packed 5-trit CPU decode kernel이 아니었다.
- `lut_cpu.cpp`가 uint8 g5 code와 per-row alpha를 직접 읽고 243-entry activation LUT를 만든다.
  기본 backend는 계속 `reference`; `native_cpu`를 명시해야 lazy build되며 실패 시 조용히 후퇴하지 않는다.
- Ninja 미설치 환경에서는 local C++17 compiler fallback으로 `/tmp` 빌드 정합을 통과했다.
  패키지 설치는 하지 않았다.
- actual checkpoint 두 개의 fp32/int8/reference/native greedy decode와 native/reference 출력 동일성을
  한 세션에서 재는 Stage1W gate를 추가했다. 사용자가 실행하기 전이라 `NOT_RUN`이다.
