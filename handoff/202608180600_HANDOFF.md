## 2. ★★지시 (2) — 세 실험 중 **둘이 내 계측 결함이었다**

### 2.1 결과 041 §11 — **게이트 자체가 틀렸다. 헤드라인을 철회한다**

| 모드 | step0 CE | `\|logit\|max` |
|---|---:|---:|
| (난수 대조군) | 10.4082 | 0.98 |
| `prop` | 12.7224 | 15.94 |
| `gate_scale` | 13.4782 | 18.75 |
| ★**`identity`** | **13.4887** | 18.75 |

★★**`identity` 는 수학적으로 교사와 완전히 같은 함수다**(복제층 gate=0 = 정확한 항등).
그런데 **13.4887** 을 찍었고, **교사의 결정적 full-val 은 3.8080**(결과 040 §2)이다.
→ **교사가 자기 점수의 3.5배를 받을 수 없다. 측정이 틀린 것이다.**

**원인**: 진단이 **입력과 정답을 둘 다 난수 토큰**으로 줬다.

| 모델 | 난수 정답 대비 CE |
|---|---|
| 난수 초기화 | ≈ `ln(V)` = 10.40 ✅ |
| ★**학습된 가중치** | ★**≫ ln(V)** — **확신할수록 나빠진다** |

> ★★★**이식이 성공할수록 지표가 나빠지는, 부호가 뒤집힌 계측이었다.**

**철회**: *"이식이 해롭다"* · *"로짓 폭주"* · *"`gate_scale` 이 더 나빠서 총량 가설이 죽었다"* — **전부.**
**유지**: G0-a/b 통과(`_depth_map` 은 죽지 않고 알린다), `identity` 구현.

★**가장 위험했던 것**: 난수 대조군이 `ln(32768)` 을 소수 셋째 자리까지 재현했고,
결과문서 §1 이 그걸 근거로 *"계측은 건강하다"* 라고 적었다. **대조군만 건강했다.**

### 2.2 결과 040 §2 — **재현성은 정상. 그런데 §1 의 서열이 뒤집혔다**

**paired Δ(dense − denseb) = −0.0080**(SE 0.0007, t −11.00)
→ **dense σ(0.0109) 미만** = **비결정성으로 설명된다. 저장소 재현성 문제 없음.** ✅

★★**그런데 부호가 반대다**:

| | 학습로그 val | **결정적 full-val** |
|---|---|---|
| `dense` | 3.8241 | **3.8080** |
| `denseb` | **3.8070** | 3.8160 |
| 어느 쪽이 좋은가 | denseb | ★**dense** |

**학습로그 `val_loss` 는 무작위 크롭 표본**이고 `paired_eval` 은 **결정적 전수**다.
→ §1 의 *"재생성본이 더 좋다"* 를 **정정**했다. **교체하지 않는다.**

⚠️★**종전 규칙 *"`best` 말고 `final`"*(함정 4)로는 못 막는다** — `final` 을 봤는데도 뒤집혔다.
**CLAUDE.md 판정 기준을 정정**했다: **런 비교는 `paired_eval` 로.**

### 2.3 결과 042 — **A1 만 유효하다**

| # | 결과 | 판정 |
|---|---|---|
| **A1** `batchmean` 분모 | 차 **`0.00e+00`** | ✅ **통과·유효**(수식 항등이라 분포 무관) |
| **A2** `T²·α` 실효 비 | 0.000 | 🚫 **무효** |
| **A4** bf16 tail | 상대차 0.000e+00 | 🚫 **무효** |

**무효 이유**: 내가 만든 합성 로짓에서 **교사·학생이 같은 `base` 를 공유**해 두 분포가 거의
같았다 → KL ≈ 0 → gradient 도 0. **KD 구현의 성질이 아니라 내 테스트 데이터의 성질**이다.

⚠️ 스크립트가 말미에 *"합성 로짓으로 했다"* 를 인쇄했는데도 **판정 줄은 단정**했다 —
**의사결정 함정 D4**(한계를 적고 결론에서 무시)의 정확한 재발.

> **→ H2(구현 결함)는 아직 배제되지 않았다.** 확인된 것은 **분모 하나**다.
