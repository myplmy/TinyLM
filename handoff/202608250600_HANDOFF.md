## 3. ★★지시 (3) — P049B 는 잘못 닫혔다 (결과 043 §14 · 함정 39)

### 3.1 발견

```python
def visit_schedule(self):
    TR = float(getattr(cfg, "train_repeat", 1.0) or 1.0)
    if self.training and TR != 1.0:      # ← ★ self.training 일 때만
        return self._repeat_schedule(TR)   # 36회
    if R == 1.0:
        return list(range(n))              # ← eval 은 전부 여기: 20회
```

평가 경로는 **전부** `model.eval()` 을 부른다 — `evaluate.py` L17 · `paired_eval.py` L71.
**둘 다 정상적인 코드다.** 그래서 아무도 의심하지 않았다.

### 3.2 증거 — `val − train_ce`

| 런 | train_ce | val_loss | **val−CE** |
|---|---:|---:|---:|
| 기준선 계열 | 4.136 | 4.1319 | **−0.004** |
| `mC_d36`(**물리** 36층) | 3.598 | 3.6972 | +0.099 |
| ★**`mC_r20`(**반복** R=2)** | **3.607** | **3.9559** | ★**+0.349** |

**`train_ce` 가 `mC_d36` 과 사실상 같다** — 학습 중엔 같은 깊이로 같은 일을 했다.
**val 에서만 갈라졌다** = **val 이 다른 함수를 쟀다.**

### 3.3 ★고칠 필요가 **없다** — 이미 되는 명령이 있다

```
python run100m.py eval --preset m100R1c --tag mC_r20 --infer-repeat 2.0 --repeat-where front
```

`infer_repeat=2.0, where=front` → `total=32, extra=16=m` → `body = mid + mid[:16]` →
**2+32+2 = 36회**. **`_repeat_schedule(2.0, uniform)` 과 동일**하고 `repeat_kv_reuse` 도 양쪽 기본 False 로 일치한다.

→ ★**P062 단계0: 학습 0 · 코드 변경 0 · 8팔 15분.** 판정선 **arm2−arm1 < −0.15** 사전 고정.

### 3.4 P031 도 같은 문제의 다른 얼굴

| 조합 | 학습 R | 추론 R | 측정? |
|---|---|---|---|
| (a) 기준선 | 1 | 1 | ✅ |
| (b) P031(결과 020) | 1 | 2 | ✅ 나빴다 — **당연하다** |
| (c) | **2** | **1** | ✅ **우리가 "반복의 대가" 로 잘못 읽은 그 값** |
| ★**(d)** | **2** | **2** | 🚫 **한 번도 안 쟀다** |

**(c)와 (d)를 구분 못 한 것이 두 축을 닫은 원인이다.**

### 3.5 사용자 지적 3건 — **전부 유효**

| 지적 | 확인 |
|---|---|
