## 1. ★가장 중요한 것 세 가지

1. ★★★**번호 규율이 이제 기계다.**
   한 세션에 **P064~P069 여섯 번호가 문서에 등장했는데 계획서는 0개**였고
   **P065·P066 을 건너뛴 채 P070·P071 을 썼다.** `check_plan_numbers.py` 가
   **참조 무결성 · 번호 구멍 · ★배치↔계획 역순 · 목록 등재** 넷을 본다.
   ★**"배치가 계획서보다 먼저 생겼다" 를 잡는 것이 3번 검사**이고 **이번 사고의 정확한 형태**다.

2. ★★★**"공짜 bf16" 은 더 없다.**
   **GEMM 은 이미 bf16 이다**(`trainer.py:521` autocast). master·gradient·Adam 산술은
   **정밀도 때문에 fp32 여야 한다**(삼진 문턱 비교 · `clip_grad_norm_` · accum 16 누적).
   ★**남은 것은 `_wq` 하나**이고, 그건 **"공짜" 가 아니라 "비트 동일이 깨지는 실험"** 이다.
   ⚠️**`--opt-dtype bf16` 자체도 속도 이득이 아니다**(+0.16%) — **VRAM −1.02 GiB 가 전부**다.

3. ★★**임시 표준안이 B2 로 좁혀졌다. 그리고 대조군이 1런으로 줄었다.**
   `opt-dtype bf16` **하나만** 고정하고 `micro-group`·`mlp-group` 은 **축으로 남긴다**.
   ★**`micro_group` 의 구조적 상한이 256 이라는 것을 코드에서 확인**했다
   (`gcd(768, 2048) = 256`, `config.py:110`) — **512 는 assert 에서 죽는다.**
   → **"학습으로 더 다양하게" 는 256 이 끝이고 이미 쟀다**(−0.0007, 036).

### 5.2 ★★우리 오류 2건 — **검토문서가 옳았다**

| # | 우리가 적은 것 | 실제 |
|---|---|---|
| **1** | *"KorQuAD CE 는 100문항으로 충분(결과 049 유추)"* | 🚫★**049 의 SE 는 `ko-en` val 1464 크롭의 것**이고 **KorQuAD 100문항은 다른 모집단**이다. `SD` 를 옮겨 적을 근거가 없었다 → ★**함정 34 의 여섯 번째**(이번엔 **모집단**이 달랐다). ⚠️**직전 세션 P063 배치와 연속 2회** |

**조치**: 도구가 **관측 SD 로 `필요 N = (SD/0.002)²` 를 계산해 스스로 pilot 여부를 판정**한다.

### 5.3 ★★검토문서가 빠뜨린 것 — **분해능**

16개 절 어디에도 **"이 지표의 σ 는 얼마인가"** 가 없다.
🚫**σ 를 모르면 "순위가 같다/다르다" 를 판정할 수 없다** — 결과 049 가 그것을 확정했다.

### 5.4 ★검토문서가 제기만 하고 통제를 안 만든 것 — **우리가 만들었다**

§5 는 옳은 우려를 적는다: *"`대한민국↔서울` 연관성만으로 gold answer 에 높은 확률"*.
**그런데 대조군을 제안하지 않는다.**

★**NC(no-context) 대조군 신설**:

```
CE(ans | 질문)              ← 지문을 뺀 같은 정답
CE(ans | 지문, 질문)         ← 본 측정
문맥 이용도 = 앞 − 뒤        ← 양수면 지문이 실제로 도움이 됐다
```

★**0 근처면 이 지표는 QA 가 아니라 어휘 사전지식을 재고 있다** — **측정 가능한 명제**가 된다.
