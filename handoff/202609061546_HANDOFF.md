## 1. 가장 중요한 것 세 가지

### 1.1 ★★★감시 도구가 감시 대상을 경유해 불려서 **한 번도 안 돌았다**

`run_smoke_check.bat` 62줄이 이랬다:

```
python scripts\runlog.py --name smoke python scripts\summarize_smoke.py
```

**`--` 가 없다.** argparse 는 뒤 두 토큰을 모르는 인자로 보고 `unrecognized arguments` 로
**exit 2** 한다. 🚫★**그래서 `summarize_smoke.py` 는 2026-09-03 신설 이래 한 번도 안 돌았다.**

그 도구는 *"팔 하나가 exit 1 인데 마지막 줄이 안전하다고 한다"* 는 **함정 38 을 막으려고**
만든 것이다. 없어서 **2026-09-05 에 정확히 그 사고가 다시 났다.**

★★**그리고 이 실패는 로그에 안 남는다** — argparse 는 **로그 파일을 열기 전에** stderr 로
죽는다. 사용자가 *"화면과 로그가 다르다"* 고 한 것의 **절반이 이것**이다.

> ★**교훈(함정 44)**: *도구 A 가 도구 B 를 감시한다면 **A 를 B 를 경유해 부르지 않는다.***
