1. **로그가 성공/실패 두 종류가 아니다.** P022C compute와 P025B synthetic inference, P093
   현 parent approximation은 **유효 수치가 문턱을 못 넘은 과학적 음성**이다. P094는 의도된
   dependency HOLD다. P097 네 학습은 전부 0-step 실행 장애다.
2. **실용 후보는 P060B actual model forward 하나다.** logits는 동일했고
   11.1354→9.8974ms(약 11.1% 단축)였지만 allocation은 9.568MiB로 동일하다. backward·학습·
   실제 생성 품질은 `NOT_RUN`이므로 기본값은 계속 off다.

   frontier를 다시 감사하지 않고 미구현 이름으로 48h를 채우지 않는다.
