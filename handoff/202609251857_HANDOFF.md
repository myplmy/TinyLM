### 2.1 SFT 감사의 정확한 범위

원 검수 요청서는 multi_2 50·multi_3 50을 SHA 고정 인덱스로 선택했다. 감사 JSON의 유형·100개 고유 ID는 요청서와 모두 일치하고 Markdown 표도 100/100 일치한다. 거부 이유코드 FORMAT4·CONTEXT3·SAFETY4·KOREAN8·FACT1이다. 다만 Codex는 공개 HF 원본 대화를 이 턴에 다시 열지 않았으므로 개별 행의 GPT 의미판정과 보고된 원천 SHA를 독립 검증한 것은 아니다. 특히 잠정 수락 중에도 추천을 미루거나 질문을 반복하는 행(예: 4548·22777·3513)이 있어 사용자 검산이 중요하다. 보고서 마지막의 “비표본 26,662행”은 원천 **전체** 26,662행과 혼동한 표현이다. 100표본+별도 marker1을 뺀 나머지는 산술상 26,561행이며, 본 감사 원본은 수정하지 않았다.

### 2.2 P014E checkpoint 후보 — 서로 다른 질문의 팔

이 후보 파일은 경로 존재·크기와 정확 학습 JSON 메타데이터만 확인했다. 체크포인트 자체를 로드/수정/복사하지 않았고 G1/G2 SH는 만들지 않았다. G0 12합성 PASS를 실제 회전 품질·상주·속도 PASS로 승격하지 않는다. G1의 기존 ⚙0.2~0.5h는 위 후보를 모두 돌릴 경우 재산정이 필요하다. frozen-inference preflight는 학습토큰/새 태그 N/A, 같은 checkpoint 안의 경로별 비교만 유효, 구현·시간·메모리 실측과 사용자 checkpoint 선택은 미완료다. 이 점검은 알려진 설계 실수만 걸러낸 것이고, 실제로 그런지는 돌려봐야 압니다.
