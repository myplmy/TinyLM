### 2.1 C2 검증 수준

[frontier_queue_gate.py](../scripts/frontier_queue_gate.py)는 §7에서 배치/id/시간/실행상태를 고정하고 현재 source manifest·frontier SHA와 묶는다. 계획 집합 차이·충돌, stale source/queue, non-DONE ID 누락·중복, live 계획의 REVIEW_REQUIRED 잔존, INCLUDE와 §7 불일치, TSV 시간/WSL 메뉴 id 불일치를 실패로 한다. artifact 이름은 frontier·큐 SHA 조합이어서 같은 입력이면 재사용한다. **모델·GPU·데이터셋을 실행하거나 수정하지 않는다.**

임시 트리 회귀 6건과 WIP 회귀 16건을 통과했고, 실제 직전 handoff에서 marker 부재가 exit1로 관찰됐다. 여섯 번째 회귀는 역사 MISSING/HOLD 행을 실행 후보로 오인하지 않고 보존한다. 이번 §7의 [C2 artifact](audit/FRONTIER_QUEUE_32F3B569096E_4A4013F2EC86.json)는 사람이 live 두 팔을 선정한 뒤 checker 오류0이다. 이번 실제 WIP --close는 --handoff 생략 시 exit2로 원장을 보존하고, 정확 handoff·static audit 제공 시 -done으로 닫혔다. 이 관찰은 현재 로컬 종료 경로의 동작 증거이지 사용자 WSL 새 task·smoke·M5 3회 운영 E2E가 아니다.

종료 뒤 --handoff가 다른 세션의 유효한 artifact를 가리키는 우회도 막도록 직전 핸드오프 체인·정확한 WIP 링크 검사를 추가했다. 이는 임시 WIP 회귀에서만 확인했으며 이미 닫힌 이번 원장에 재차 close를 실행하지 않았다. 최종 코드의 post-close codex-safe 정적 검사 63종도 읽기 전용으로 통과했다.
