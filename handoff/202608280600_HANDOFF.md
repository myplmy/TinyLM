## 1. ★가장 중요한 것 세 가지

1. ★★★**KD 가 끝났다. 그리고 "약하게 걸기" 라는 선택지가 없다.**
   α 0/0.1/0.3/0.5/0.7 → **3.6776 / 3.6776 / 3.6856 / 3.6984 / 3.7156 = 완전 단조.**
   α=0.1 은 무KD 와 **−0.0000**(구분 불가)이고 그 위로는 선형적으로 나빠진다.
   ★**VRAM 은 세 팔 전부 12.475**(무KD 5.066) — **α 는 손실 가중치일 뿐 교사 forward 와
   어휘 전체 KL 은 α 와 무관하게 돈다.** → **α=0.1 은 품질 이득 0 에 VRAM 7.41 GiB.**
   **REVIEW2 결정 ① 확정.**

2. ★★★**분해능을 다시 그었다. 그리고 원인은 추정량이 아니었다.**
   시드쌍 Δ **0.0006 / 0.0017 / 0.0109 = 18배.** 결과 039 가 세워 두고 안 쟀던
   **가설①(추정량 탓)을 기각** — `final val_loss` 0.0119 를 paired 로 다시 재니 **0.0109,
   8% 만 줄었다.** ★**무KD 조건 2σ = 0.0034** 이고, 그러면 *"동급"* 이라 불러 온 것들이 갈린다:
   **KD제거 6.1σ · g16 4.8σ · E192 4.5σ** vs **`micro_group 256`·`opt bf16`·α0.1 = 진짜로 0.**
   ★**REVIEW2 §2.5.2 의 원칙(*"대가 0 인 것만 바꾼다"*)이 수치로 뒷받침됐다.**

3. ★★★**36층인데 20층 기준선보다 작다 — 저장소 최초.**
   `mC_d36_ag4` 상주 **379.7 MB = 기준선 451.5 대비 −15.9%**, 품질 **+0.0078**(채택선 +0.041 의 1/5.3).
   ★**삼진을 9.42M 빼면서 0.0078 만 잃었다 = 0.00083 nats/100만** — 같은 방향의 `g16`(0.00342)보다
   **4.1배 싸다.** ★**어텐션은 우리 모델에서 가장 싼 감축 대상**이고 이유를 안다
   (복제층 어텐션은 어차피 꺼진다, 041 §15). ⚠️**KD 조건 학습본** → 모델안 정본은 무KD 재학습.

→ ★**원안이 §2 에서 *제외* 한 "임베딩 양자화" 가 사실은 *선결* 이다.**

★**매트릭스 수정 2건**: 9조건 → **4조건**, 그리고 ★★**`QT0`(교사 없이 토크나이저만) 추가** —
원안에 없어서 **교사 효과와 토크나이저 효과를 영원히 못 가른다**.
★**그러나 KD 를 되살릴 가장 강한 후보이기도 하다** — 우리가 확정한 것은 *"KD 가 나쁘다"* 가 아니라
***"학생보다 나쁜 교사로 KD 하면 나쁘다"*** 이고, Qwen 교사는 **그 조건을 정면으로 바꾼다.**

## 4. 지시 (5)(7) — 두 건의 재발방지

### 4.1 `denseb_best` — **규칙을 역할이 아니라 이름에 걸었다**

*"`_best` 는 하향 편향이라 판정에 안 쓴다(015)"* 는 **비교용 산출물**에는 옳지만
**부모/교사 계보**에는 적용되면 안 된다. `dense_best` 는 이미 한 번 사라졌고
`denseb_best` 는 그 재생성본의 **유일한 best** 다.

**기계 방어 3중**(`cleanup_ckpt.py`):

| 게이트 | 무엇 | 데이터 출처 |
|---|---|---|
| **G1** 파생보호 | 다른 런이 `init_from_src`/`kd_teacher` 로 읽은 것 + 그 `_best` 형제 | ★**`runs/logs/*.json`** — 손목록이 아니다 |
| ★**G2** 판정 일관성 | 본체가 `hold`(미판정)인데 `_best` 만 `delete` → **차단 + 에러 인쇄** | TSV 자체 |
| **G3** 부모계보 정규식 | `^m100_ko-en_300M_dense[a-z]*(_best)?\.pt$` | 이름이 아니라 **계보** |

✅**G2 를 사고 상황으로 재현 테스트했고 정확히 잡았다.**
✅**TSV 규약 §6 신설**: *"새 `_best` 의 기본 판정은 `hold`"*. **미등재 8건도 등재**(현재 미등재 0).

### 4.2 ★권장순서 7번 — **선결이 없었다** (D15)

> 사용자: *"근거없는 미구현이나 근거없는 작업 미이행은 오류/게으름/환각으로 오인된다."*

🚫★**정확한 지적이다.** 핸드오프 §7 이 *"6·7 은 선결이 있어서 일부러 안 만들었다"* 라고 적었는데

**조치 3건**: ①**D15 등재** ②★**배치 작성**(`run_P062_stage0c_r_curve.bat` — 머리말에 이 사건 기록)
