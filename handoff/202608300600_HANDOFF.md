## 1. ★가장 중요한 것 세 가지

1. ★★★**우리 레버표는 전부 KD 표였다.**
   `EXPERIMENT_BASELINES` §2.2c 의 머리말이 그렇게 적혀 있다 —
   *"전 런 **KD k4** + 부모초기화 + wsd"*. 그런데 **KD 를 뺐다.**
   ★**무KD 로 다시 잰 레버는 `mlp-group 16` 하나뿐**(029 §6).
   **`micro_group 256`·`emb_rank 192`·`--no-ckpt`·`opt bf16`·`p1c1`·`sparse34` 는 전부 가정**이다.
   → **P065 단계1 이 앞의 셋을 잰다.**

2. ★★**B2 임시표준이 두 실험의 선결을 풀었다.**
   `mC_d36_ag4`(상주 379.7 MB, 저장소 최선)와 `mC_r20`(재귀)이 **폐기된 KD 조건에서
   학습된 채로** 있었고, 선결이 *"REVIEW2 표준조건 확정"* 이었다.
   **B2 가 무KD 를 임시 확정**했으므로 **지금 재학습할 수 있다.**
   ★**`mC_r20_nokd` 는 특히 드문 형태**다 — **재귀는 파라미터를 0 늘리므로
   `mC_initonly` 와 삼진·packed·상주가 완전히 같다** = **메모리 고정 상태의 순수 품질 비교.**

3. ★**`--no-ckpt` 가 열렸을 수 있다.**
   결과 034 §10 이 KD 조건에서 **여유 0.62 GiB** 로 막았는데, **KD 제거가 7.41 GiB 를 돌려줬다.**
   ⚙무KD `--no-ckpt` reserved ≈ **5.07 + 2.90 = 7.97 GiB** → **16 GB 에 여유롭게 든다.**
   ★**속도 이득**(dense 기준 결과 007)이 실재하면 **모든 후속 학습이 빨라진다.**

## 2. 지시 (1) — 진단 도구 2종

### 2.1 ★`diag_dtype_map.py` → **P022B 단계3**

분석문서가 **코드 독해로** *"GEMM 은 이미 bf16, 남은 후보는 `_wq` 하나"* 를 냈는데
**`_wq` 를 바꿀 값어치는 크기를 몰라 판정 불가**였다.

| 팔 | 무엇 | 문서에서 ⚙였던 것 |
|---|---|---|
| **M1** | dtype·바이트 재고 | §1 표를 **독해 → 실측**으로 |
| ★**M2** | `F.linear` 호출·캐스팅 바이트 | ★**§4.3 "타잉 때문에 16번 캐스팅"** |
| ★**M3** | `refresh_quant` 단독 타이밍 | ★**§4.2 "스텝당 2~3 GB"** |
| **M4** | 스텝 대비 비중 | §6 *"compile 이 융합하면 과대"* |

★**게이트를 코드에 박고 실행 첫 줄에 인쇄**한다(함정 34):
캐스팅 **1 GB/스텝 미만** 또는 M3 **5% 미만** → 🚫**축 종료**. M3 **20% 이상** → ★**D3 승격**.

★**두 모델을 넣은 이유**: `mC_initonly`(g8, 20층) vs `mC_d36_ag4`(g16 + `attn_group 4`, 36층).
**캐스팅 횟수가 재사용에 비례한다면 후자에서 드러난다.** ★**평균 재사용이 1 이면
autocast 가 캐시하고 있다는 뜻**이고, 그러면 **문서가 우리에게 유리한 쪽으로 틀린 것**이다.

⚠️**`--compile` 없이 잰다** → **M3 는 상한**이다. ★**그 방향으로만 틀린다** =
**축을 닫는 데는 안전하고 여는 데는 위험**하다. 배치 꼬리말에 적었다.

### 2.2 ★`diag_repeat_attn_sim.py` → **P049 단계2**

사용자 질문의 **①(출력이 같은가)** 을 잰다. **041 §15 가 잰 것은 ②(게이트가 꺼졌다)** 였다.

| | 무엇 |
|---|---|
| **A** | 코사인 유사도 — ★**대조군 3무리**: (a)복제쌍 / (b)같은모듈·비복제 / (c)다른모듈 |
| **B** | 잔차 기여도 `‖g0·attn_out‖ / ‖x_in‖` — ②의 정량화 |

> ★★**(c) 없이 (a) 절대값만 읽으면 함정 34 의 재발**이다.
> 어텐션 출력끼리는 **원래 비슷하다**(좁은 원뿔에 산다).

★**두 모델을 넣은 이유**: `mC_d36_ag4`(복제 + 어텐션 공유) vs `mC_d36`(복제만).
→ ***"모듈을 공유해서 비슷한 것"* 과 *"복제라서 비슷한 것"* 을 가른다.**

★**예측은 ①기각**이다 — **잔차 사슬이라 층 i+1 의 입력이 층 i 의 출력**이고,
**입력이 다르면 출력도 다른 것이 기본**이다. ①이 성립하면 그게 놀라운 일이다.
**대응표는 `init_utils._depth_map` 을 재사용**한다(함정 18: 집합은 한 곳에서만).
