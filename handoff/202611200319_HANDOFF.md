### 2.2 채택 근거

- 등록한 G4는 앞·뒤 2층씩과 중간 12층이다. tied 모드의 중간 12층은 네 층씩 MLP를 공유해 MLP 세 개를 쓴다. R2를 선택하면 28회 방문한다. 이 구조를 선택할 수 있으며 기본 프리셋의 `train_repeat` 값은 1이다. [설정](../tinylm/config.py) · [P109](../test_plan/P109_16층-공유-재귀-프리셋-통합.md)
- 교사 MTP는 실제 생성 파이프라인에서 사용했다. 학습 출력부 재계산과 CPU 배포는 각 조건에서 실행 근거를 얻었다. 변형 순회의 출력부 재계산은 같은 학습 상태에서 최대 할당 34.59%·35.84%를 줄였다. 대어휘 결합 CE·KL의 절감은 별도 경로 보고가 소유한다. [생산·채택 근거](../docs/research/20261118_주도실험_성과와_채택근거_진행보고.md) · [결과107 §26](../test_result/107_20261027131747_P107-가시성과-shift는-검산됐고-학습효과는-미확인.md#p107-g4-policy-adaptive)
- 직접 편집은 지정 답과 일부 보존에서 양성을 보였으나 일반 한영 답과 후속 학습 유지의 채택 문턱이 남았다. 작성 자료의 방문·증류·적응 마스킹도 정식 독립 품질 대조를 기다린다. 통합 후보의 전체 개선폭은 현재 미측정이다. [P109 단계 4](../test_plan/P109_16층-공유-재귀-프리셋-통합.md)
