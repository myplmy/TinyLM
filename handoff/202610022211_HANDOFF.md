## 4. 조심할 것

P106C의 진단 배치는 micro8×accum4·padded256이다. 32문항 반복/ID당16회 상한은 승인한 **암기·선택 진단 예외**다. 이를300M 일반 SFT의 batch/epoch 기본값으로 바꾸지 않는다. bootstrap은64문항쌍 불확실성이지 여러 학습seed 분산이 아니다. 같은 총학습량 대조가 추가 선택비용까지 상쇄했다는 주장도 하지 않는다.
