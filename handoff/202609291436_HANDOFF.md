- 공개 Aya/OASST2의 `CARD_ONLY` 행은 교사 답 생성 기능 시험에 쓰이지만, 실제 답의 사실성·개인정보·문맥·권리와 장기 모델 공개는 별도 판단이다. We가 성공해도 정식 `TRAIN_READY` 또는 검증형 `ACCEPT`로 올리지 않는다.
- We/Wf의 실제 서버 GDN 시작상태와 KV-cache 경고 빈도/실행시간 기여는 새 원본 전 `UNKNOWN`이다. GDN 시작 latch는 새 코드에서 정적 테스트만 끝났다.
- 한국어 원어민 원천은 공개 덱의 OASST2에서 소수다. target 언어5:5를 맞춰도 원천 언어·주제·답안 사실성 5:5가 보장되지 않는다. 300M~600M 양적 확대 전 학생 비패딩 처리토큰·중복·held-out 오답을 따로 수집한다.
