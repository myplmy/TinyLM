## 1. 지시 (1) — `%` 금지 **해제했다**

### 1.1 판정: **불가역적 손상 없음**

`%` 오용의 실패 모드는 ①문자열이 조용히 사라지거나 ②변수가 안 풀리는 것이고,
**둘 다 실행 시점에 드러난다.** 파일을 지우거나 체크포인트를 덮어쓰는 종류가 **아니다.**

**금지의 대가는 컸다**: 퍼센트를 못 써서 주석에 `PERCENT SIGN` 우회, `for /f` 를 못 써서
목록 읽기를 전부 파이썬으로, `%~dp0` 대신 `if not exist run100m.py cd ..\..` 마커 발명.

### 1.2 ⚠️ 다만 **한 형태는 남겼다**

`echo cost is 5%production%` 에서 `production` 이 미정의면 **그 구간이 통째로 사라진다.**
★**그게 정확히 이 저장소가 싫어하는 "조용한 실패"** 다.

| 형태 | 판정 |
|---|---|
| **`%VAR%`**(즉시확장) | 🚫 **에러 유지** — 미정의면 조용히 사라진다 |
| `%~`(경로 수식자) | ⚠️ **경고** — 동작하지만 마커 방식이 표준 |
| 홀수 개 `%` | ⚠️ 경고 — 리터럴은 `%%` |
| **`%%`**(리터럴 / `for` 반복변수) | ✅ **허용** |

**새 규약: 리터럴 퍼센트는 `%%`.** `for %%a in (...)` 도 이제 쓸 수 있다.
회귀 테스트 4종으로 확인했다.

> ⚠️ **`queue_menu.py` 를 되돌리지 않았다.** *"`for /f` 를 못 써서 파이썬으로 뺐다"* 는
> 이유가 사라졌지만 **지금 구조가 더 낫다**(양방향 감사·메타데이터 정본). 이유만 갱신한다.

## 4. ★★지시 (4) — 041: **게이트가 5.8시간을 막았다. 그리고 이식이 난수보다 나빴다**

**결과 041** 전문 = [`041_20260813_P049-깊이가-산것은-MLP고-어텐션은-꺼졌다.md`](../test_result/041_20260813_P049-깊이가-산것은-MLP고-어텐션은-꺼졌다.md)

| 모드 | step0 CE | `\|logit\|max` | G0-c(< 9.3972) |
|---|---:|---:|---|
| **(난수 대조군)** | **10.4082** | **0.98** | 🚫 |
| **`prop`** | **12.7224** | **15.94** | 🚫 |
| **`gate_scale`** | **13.4782** | **18.75** | 🚫 |

★난수가 `ln(32768) = 10.3972` 를 정확히 재현한다 → **계측은 건강하다.**

### 4.1 ★핵심 — **"초기화가 안 됐다" 가 아니라 "초기화가 해롭다"**

이식이 출발점을 **2.31 nats 나쁘게** 만들었다. 부모초기화의 정상 몫은 **+0.1386**(결과 038)이고
임베딩 SVD 이식은 **0.1123 을 걷어냈다**(결과 030 §9) — **크기가 그쪽들의 20배이고 부호가 반대**다.

### 4.2 ★★`gate_scale` 이 **더 나빴다** — 이것이 진단의 열쇠

`gate_scale` 은 총 잔차 기여를 **교사와 같게** 맞춘다. 그런데 **더 나빠졌다.**
→ ★**문제는 총량이 아니다.**

```
교사:  h ← h + f(h)
학생:  h ← h + f(h) ;  h ← h + f(h + f(h))   ← 두 번째는 f 가 본 적 없는 입력
```

**합성 불일치**다. 그리고 그게 **18개 층에서 누적**돼 로짓이 16~19배로 폭주한다.

> ⚠️★**결과 020(P031, 추론 시 층 반복 종결)이 진단한 것과 정확히 같은 기전**이다.
> *"학습 분포와 mismatch"*. **두 관측이 서로를 지지한다.**

### 4.3 조치 — **`depth_init=identity` 신설**

`gates` 는 평범한 곱셈 잔차 게이트다(`x = x + gates[k] * branch`).
→ **복제된 층의 gate 를 0** 으로 두면 **정확한 항등**이고, 36층 학생이 step0 에
**교사 20층과 완전히 같은 함수**가 된다. **step0 CE 가 12.72 → 약 3.8** 로 내려간다는 예측.

★**우리 구조가 문헌(bert2BERT/LLaMA Pro 계열 zero-init block expansion)보다 싸다** —
출력 projection 을 0 으로 만들 필요 없이 **gate 하나면 된다.**

⚠️ **남는 위험**: gate 0 이면 그 층의 branch gradient 가 작다 → **복제 층이 영영 안 깨어날 수 있다.**
그러면 36층이 실질 20층이 되고 P049 가 자기 질문에 답을 못 한다.
**단계1 이 학습 후 gate 가 0 에서 떴는지 기록해야 한다.**

### 4.4 040 — **같은 명령이 0.017 다른 모델을 만들었다**

**결과 040**: `denseb` final **3.8070**/best **3.7659** vs 원본 3.8241/3.7797.
★**재생성본이 더 좋다. 그런데 그게 질문이다** — 시드·명령이 같은데 0.017 이 벌어졌다.
dense·무교사 σ(0.0109)와 같은 자릿수라 비결정성으로 **설명 가능하지만 설명하지는 않았다.**

**→ 단계2(GPU 0)가 가른다: `< 0.011` 정상 / `> 0.024` 는 저장소 재현성 문제로 격상.**

### 4.5 도구 결함 1건 (수정)

`diag_depth_init.py` 가 **음수 차이를 "걷어냈다" 로 인쇄**했다 —
`★이식이 걷어낸 출발 핸디캡: -2.3141`. **숫자는 맞는데 문장이 정반대**다.
음수면 *"이식이 출발점을 더 나쁘게 만들었다"* 로 갈라 인쇄하고 기전 힌트를 붙였다.
★결과 030(인쇄 `|g|` vs json `grad_max`)과 **같은 계열**이다.

## 8. ★지시 (8) — Hyper Experts (전문 읽음)

**판정 전문 = [`docs/methods/08_paper_review.md` §10](../docs/methods/08_paper_review.md)**

### 8.1 우리와 닿는 결과 넷

| # | 논문 | 우리에게 |
|---|---|---|
| 1 | 규모 **small = backbone 82M**, LR **1e-3** | ★**우리 규모·우리 LR 과 일치.** 결과 017 의 독립 확인 |
| **2** | ★★**"higher-activation"(χ=1, φ>1)이 "expanded-pool"(χ>1)의 이득을 따라잡는다** — **모델 크기를 안 늘리고 각 expert 를 여러 번 활성화**해서 | ★★**정확히 P049B 의 가설.** 독립 문헌 근거 |
| 3 | 그 이득이 **모델이 클수록 커진다** | ⚠️**우리 규모에서는 작을 수 있다** — P049B 를 낙관하지 않는 근거 |
| 4 | "dense-matched"(χ=φ=1)에서도 dense 를 이긴다 | 공유 자체가 손해가 아니다 |

### 8.2 ★우리 구조가 이미 HX 의 퇴화형이다

| | HX | **TinyLM `mlp_group`** |
|---|---|---|
| MLP 공유 | 전 층 pool | ✅ 중간층 g 개씩 |
| 배정 | **학습된 라우터** | 🚫 **고정**(`j // g`) |
| 라우터 파라미터 | ★**층별**(공유하면 수렴 악화) | ✅ 우리도 층별(`router_bias`) |

### 8.3 🚫 그대로 도입 비권장 — 이유 셋

1. ★**expert pool 이 2개**다(`n_mlp_groups = 16/8`). **2개짜리 pool 의 top-k 는 라우팅이 아니다**
2. ★**CPU 배포와 충돌** — 라우팅은 gather/scatter, 우리는 **런치 바운드**(결과 014)
3. **γ(세분도)를 올리면 나빠진다**고 논문이 직접 보고 — pool 을 키우려면 그걸 해야 한다

### 8.4 ★그래서 취한 것 하나 + 새 축 하나

- ✅ **"higher-activation" 가설 → P049B 의 문헌 근거로 등재**
- ★**새 축 후보**: 논문의 expert diversity 분석이 *"**초기 층은 중복, 후기 층은 거의 직교**"*
  라고 한다. → **우리 `mlp_group` 은 초기·후기를 똑같이 묶는다.**
  ⏸ **불균등 타잉**(초기 g16 / 후기 g4)이 신규 축 후보다. **사용자 확인 후 등재 제안.**
