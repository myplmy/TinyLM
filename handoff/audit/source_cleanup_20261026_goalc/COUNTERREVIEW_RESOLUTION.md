## 보완 저장물과 반례 종결

source01은 `source_01_v4.txt`, source02는 `source_02_v3.txt`, source04는 `source_04_v5.txt`, source08은 `source_08_v5.txt`가 최종 선택이다. 인물/분류 관계는 각 문서 주제와 연결되고, `원문 분류`라는 편집자 관점 표제는 정상 인물 정보/분류 표제로 바꿨다. 08은 상위 도감명과 동·서부 편제 관계를 중립 문장으로 연결했다. 기존 광고/HOLD 부록은 덮지 않았다.

38390과62127은 새 v2가 제목/작성자 경계와 내용 있는 서평을 복원했다. DCD155518 v2는 실제 본문·논문 인용·조건을 보존하고 소셜/추천/장식 행만 제거했다. 장식 행은 실제 코드가 아니며 정확 원문 SHA에만 예외를 결합했다. 모든 다른 코드 문자열은 바이트 불변 가드로 확인한다.

source02의 초기 분류 관계 누락은 실제 오류였고 v2에서 복원됐다. 그 뒤 `context_latin/counterreview_v2.md`가1999~2001 한국전통가공식품협회 경력과 반복 누락을 source02에 다시 귀속한 것은 별개 오류다. 총괄이 원문과 실제 v2를 직접 대조해 그 문자열이 양쪽에0회임을 확인했다. 이는 다른 문서233567의 내용 혼동이며 source02에 절대 추가하지 않았다. 보조가 새 `counterreview_v3.md`에서 잘못된 후속 의견을 철회하고 source02 본문/관계 보존 PASS를 확인했다. 이 정정으로 초기 실제 누락을 없었던 일로 바꾸지 않는다.

재대조 일곱 쌍은 본문 보존을 확인했다. 마지막01/02/04 변경은 이미 대조된 값 그대로 표제만 교체했고, 08은 이미 대조된 기능/수치/단위 그대로 첫 소개의 주체와 도감 관계만 바로잡았다. `root_adoptions_v1.json`이 원문 SHA·최종 txt/SHA·판정·이유를 동결한다. 학습 캐시 채택과 실제 모델 TRAIN 사용은 다르며 새 모델 학습은0이다.

## 위임·도구 한계 보존

세 보조의 주변 행 출력, 초기 memory 검색, 파일명 확인 때 추가 draft 이름 노출은 각 자기 보고와 DELEGATION에 남긴다. 지정 외 내용은 채택 근거로 쓰지 않았고 보호 TinyDataset·원형·모델·GPU·Git에 대한 보조 실행은0이다. 이는 OS 수준 격리 검증이 아니다.

총괄의 첫 긴 문서 차이 계산은 문자 단위 비교 비용이 커서 소유 실행을 중단하고 줄 단위 비교로 바꿨다. 원형이나 partial 파일을 삭제하지 않았다. 역사 문헌의 첫 바이트 검산은 원본 EOF에 없는 LF를 기대해 실패했고, 실제 말미30바이트를 정확 확인한 후 두 행49바이트만 제거됐음을 검산했다. 원문/정제문은 이 검증기 교정으로 바뀌지 않았다. 첫 unittest 호출의 격리 모드 import 오류와 기존 합성 fixture의 과거 마감 오류도 실제 실행 증거와 구분한다.
