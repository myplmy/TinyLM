# 합성 스모크 체크포인트 삭제 — 사용자102의 승인 범위

현재 사용자는 재생성 가능한 합성1,120개 삭제, 종료 연구9개 우선 보존, 원로그·판정 유지, 실제 확보량 확인, 체크포인트 목록 갱신과 한국어 로컬 커밋을 지시했다. 사용자101의 후보 검토와 구분하며, 원장102가 이번 지시를 소유한다.

| 파일·경로 | 예정 동작 | 권한 근거 | 제외 |
|---|---|---|---|
| `review_v3.json`의 일반 합성64개 | exact 경로만 삭제 | 사용자102의 합성1,120개 삭제 | 일반 연구9개·다른 모델 |
| 같은 명세의16격리 합성1,056개 | exact 경로만 삭제 | 같은 승인 | 폴더 전체 삭제·로그·캐시 |

제품 코드·구조·학습조건·품질 판정에는 영향이 없다. 삭제되는 파일은 실제 합성 모델 가중치이며, 원로그만으로 동일 바이트를 복원할 수는 없고 필요할 때 스모크를 다시 수행해야 한다. 종료 연구9개의 삭제는 승인되지 않았다.

현재 공용 정리기는 `runs/ckpt/` basename만 처리하고 격리본을 처리하지 않는다. 이 작업의 작은 실행 도구는 승인 명세의1120경로만 다루며 공개 공용 정리기의 계약·검사 기준을 바꾸지 않는다. 모델/GPU·새 학습·VHDX 축소는 수행하지 않는다.

삭제 전 전체 exact identity·부모/교사 보호·열린 파일·보존 SHA·WSL/Z 여유를 고정하고, 삭제 직전과 파일별로 다시 확인한다. 삭제 중 이상이 생기면 즉시 멈추고 부분 결과를 기록한다. 실패 원형을 덮거나 승인 범위를 넓혀 자동 재시도하지 않는다.
