# 질문 형식 대조의 착수 전 영향도

권한: 사용자 세 우선순위의 `알아서 판단할것` 및 원(7)의 당일17시 전 CPU/GPU 위임.
새 scripts 두 개와 공통 개발평가 래퍼·3SH, 새HF/tag/가중치/local원답만 신설한다.
기존 teacher/course CODE·원형·CPT·완료WIP/인계·보호자료·공용검사기·추가삭제는 제외한다.

| 축 | 영향 |
|---|---|
| 코드 | 기존 transformer/생성/학습 구현을 바꾸지 않고 process-local course/namespace dispatch만 변경 |
| 데이터 | 기존576 source/교사답을 재사용; 반수 supported만 입력문구 변경·원천계보와 답보존 |
| 테스트 | CPU4:정확근거/답보존, 누락계약, 반수·결정성, 원형불변; 실제tokenizer예산·마스크는 동결시검산 |
| 문서 | 계획/결과/기준표/목록/METHODS/COMPASS 연쇄, flag_whitelist 새제품옵션없어변경없음 |
| 부채 | 별도진단namespace를 기본생산에자동연결하지 않으며 형식/길이교락을 명시 |
| 실행권한 | 신규모델은17시전에만, 상한1200초, 사용자프로세스중단없음 |
| 소유권 | 기존source/HF/교사원답·CPT는 읽기만; 새산출물도 정확명시경로만기록 |
| 비교 | 같은512/64 root·1024/128행·assistant targets/32updates, prompt/x길이는 고의로 다름 |
| 증거 | 개발24 반복/teacher literal일치가 정답성·독립test·75M완성이 아님 |
| 동기화 | 최종실물 회수와 각 정본을 함께갱신 |

대안: 형식변경은 약5분학생/1분평가,128회노출은 약16분+망각, teacher재교정은 추가생성/원답변경이다.
지금은 입력형식만 바꾼 새팔을 우선한다. 전용sigma 미측정이며 loss 직접순위는 금지한다.

사전검증: registry 새태그충돌없음.32×8×16×1024=4194304는padding,
실제x는새encode로별도측정·assistant는기존14233×4=56932·CPT2배pool규칙을 반복SFT에 전용하지 않는다.

이 점검은 알려진 설계 실수만 걸러낸 것이고, 실제로 그런지는 돌려봐야 압니다.
