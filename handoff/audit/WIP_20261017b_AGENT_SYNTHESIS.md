# 세 보조와 총괄의 CPU 준비 합의·반증 기록

사용자 지정에 따라 gpt-6.1-sol/max를 필요한 때만 최대3명 사용했다. 문헌 담당은 원문 방법 절과 대안/돌파구 후보를 조사했고, 정 담당은 기존 동결 코드의 재사용 경계와 새 손실·합성 회귀를 구현했으며, 반 담당은 쓰기/실행 없이 독립 검토했다. 실제 자산·문서·런처·최종 CPU 실행은 총괄이 소유했다. 보조 모두 실제 모델/학습가중치/GPU/보호 데이터/Git 변경 없이 작업했다.

| 논점 | 반증·근거 | 총괄 반영 |
|---|---|---|
| 질문조건 열 우위와 같은 질문 안 정답 선택은 다름 | 2×2 숫자 반례에서 열 우위·대각합은 양수지만 한 행은 오답 우세 | 행별 softplus,행/열/최초분기·자유 답 지표 분리 |
| 옛 두 표현 KL을 서로 다른 정답에 적용하면 안 됨 | `paired_positions`가 동일 정답 벡터를 요구하고 판독기는 no_grad/detach | 새 미분가능 손실. 기존 코드는 수정하지 않음 |
| 자연 두 답은 문자열이 달라도 둘 다 맞을 수 있음 | 실제 TRAIN 재고의 답 종류 단서·원문 잡음·복수정답 가능성 | 자연12854쌍은 자동 negative로 쓰지 않고 코드가 정의한 역할표만 대조 |
| 첫 답 조각이 BPE 경계에서 빠질 수 있음 | 부분 content+EOT만 검사하면 coverage가 보장되지 않음 | 전체 offset coverage·정답 없는 prefix·shift·EOT·UNK 검산,실제 tokenizer와 straddle fixture 통과 |
| 길이가 다르면 공통 prefix 상쇄가 깨짐 | 평균 점수의 분모가 다름 | 첫 pilot은 실제 내용 BPE 길이가 같은 두 답으로 제한,그 제한과 새 이름 전이 아님을 명시 |
| λ0.1은 검증된 약한 규제가 아님 | 전체 CE token수/관계 질문수에 따라 상대 계수가 달라짐 | 탐색값으로만 표기하고 실제 각 손실·총 gradient/clip/시간을 보고하도록 구현 |
| 과거 WD0 설명과 실제 라우팅이 다를 수 있음 | matrix WD0 이후 embedding의 AdamW 기본WD0.1 가능,44개 난수계수 fixture에서 재현 | 새 팔은 모든 실제 그룹WD0과LR receipt를 명시. 과거 실물 재계측/단독 원인으로 승격하지 않음 |
| 비용8/본학습의 동일 코드 지문이 좁았음 | attention·양자화·config·optimizer 구현 변경을 놓칠 수 있음 | 실제 의존 모듈 지문 추가,기존 동결 코드 불변 |
| 서로 다른 평가 팔을 바꿔 붙일 수 있음 | status/code/case만으로는 parent/CE/contrast 정체가 결합되지 않음 | endpoint·학습보고SHA·실물 가중치SHA·본체·양 manifest lineage·저장 manifestSHA 재결합 회귀 |
| 새 표본 분모의 과장 위험 | 한영은 같은 사실의 번역이며 이름/역할은 공유 | TRAIN2048=1024graph,TEST128=64graph. 언어별 graph 대응구간·단일seed 한계 |
| 과거640회와 새768회는 다른 학습량 | 관계자료를 추가해 pass당192회,원문보존 노출도20% 증가 | 새 두 팔끼리만 직접 대조. 옛 결과 대비 단일축 우열 금지 |

문헌 원문·대안·추론 범위는 [논문08 §12](../../docs/methods/08_paper_review2.md), 실제 CPU81/자료·원로그는 [결과101 §272](../../test_result/101_20260927_P106B-번역9건으로-문턱미달-학생학습0.md)가 소유한다. 문헌 의견이나 합성 gradient를 실제 지능 개선으로 쓰지 않는다. 총괄은 모델 코어·원래 실행 코드·공용 checker·환경·타 세션 원장·기존 dirty를 변경하지 않았다.
