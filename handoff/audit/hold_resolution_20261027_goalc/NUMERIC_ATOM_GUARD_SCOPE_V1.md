# 수치 일부 삭제 진단의 범위

309036의 초안에서 12km를 분리하다 숫자 1이 남은 실제 오류가 있어 추가 진단을 만든다. 이 검사는 의미 판독이나 수치 사실 검증을 대체하지 않는다.

검토한 대안은 세 가지다. 기존 순서 보존 삭제 검사만 유지하면 부분 숫자 삭제를 통과시킨다. 숫자 다중집합 비교만 추가하면 원문의 다른 위치에 같은 값이 있을 때 변경을 놓친다. 선택한 방법은 행 차이와 변경 행의 문자 대응을 함께 보아 출력의 숫자 하나가 원문의 완전한 숫자 하나에 대응하는지 검사하는 것이다. 전체 숫자 구간의 보류는 허용하고 일부 숫자 삭제·부호 소실·숫자 결합·새 숫자는 검토 대상으로 표시한다.

완전한 수치 복구처럼 승인된 변경도 표시될 수 있다. 표시를 자동 면제하거나 자동 채택하지 않는다. 매우 긴 단일 변경 구간은 보수적인 문자 정렬을 사용한다. 검사 통과가 수치·단위·대상 관계 전체의 의미 보존을 증명하지 않는다. GPU·모델·보호 원문·타 세션 자료를 사용하지 않는다.
