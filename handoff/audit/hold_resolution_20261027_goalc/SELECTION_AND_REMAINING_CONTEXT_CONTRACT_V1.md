# 추가 본문 결합과 잔여 문맥 판독 계약

현재 사용자가 허가한 잔여 HOLD 전량 CPU 정제와 다섯 Luna text-only 역할의 범위에서 수행한다. 이 문서는 캐시 채택 또는 학습 승인이 아니다.

| 경로 | 동작 | 권한 근거 | 제외 |
|---|---|---|---|
| 이 감사 폴더의 새 producer·receipt·selection plan | 신설 | 목표 1·5·6의 CPU 분석·관련 구현·검증 | 기존 기록 덮기·삭제 |
| `data_cache/p106b_hold_resolution_v1_20261027_goalc/remaining_context_v14_v1/**` | 새 지정 후보·manifest·TASK 생성 | 원문 연결된 별도 파생물 | 원형·기존 캐시 변경 |
| 각 지정 `agents/*/remaining_context_v14_v1/**` | 해당 역할이 새 TXT/MD 작성 | 사용자 지정 최대 다섯 Luna 역할 | 코드·시험·계수·Git·모델·웹 |
| 기존 source·review·core2110·supplemental·root selections | 읽기와 정확 SHA 결합 | 현재 목표의 기존 작업 회수 | 타 세션·TinyDataset·미지정 원문 |

| 안 | 내용 | 장점 | 단점 | 영향도 | 수행비용 |
|---|---|---|---|---|---|
| A | 모든 중복 제안에서 가장 큰 버전 번호를 자동 선택 | 빠름 | 같은 원문의 상반된 내용·오삭제를 숨김 | 데이터 의미·채택에 큼 | 낮지만 재작업 큼 |
| B | 작성자 명시 정정과 root 정확 SHA 선택을 분리하고, 미선택 충돌을 보존 | 실제 검토와 최종 본문 연결을 검산 가능 | 본문·검토·반례를 함께 읽어야 함 | 새 파생물과 감사에 국한 | 중간 |

권장·수행: B. 이미 승인한 원문 의미 보존과 원문에 없는 사실 생성 금지의 구체화다. 같은 cohort에서 작성자가 명시한 정정 순서는 회수하되, 서로 다른 cohort의 본문은 파일 시각·가장 큰 버전·표 수치가 아닌 정확 원문/본문/검토 SHA와 root 판정으로 선택한다. 불명확한 제안은 채택하지 않는다.

| 영향 축 | 확인과 처리 |
|---|---|
| 코드 | 기존 supplemental collector, original reader, literal guard, core readback을 재사용한다. 새 selector는 계획·진단만 만들며 cache builder의 입력 계약은 바꾸지 않는다. |
| 데이터 | source/candidate/review 원형은 불변. content addressed 사본과 개별 20,000,000바이트 미만 새 manifest만 쓴다. 기존 1,145,290개 채택 본문 보호와 partial 캐시는 그대로 유지한다. |
| 검증 | 명시 ID·SHA·output column 연결, 다른 cohort 충돌, 임상 제한 view 우선, 코드·Unicode·숫자·스타일·검수 메모를 각각 확인한다. 같은 정책의 재탐지만으로 의미 보존을 주장하지 않는다. |
| 정본 문서 | 지금은 초안 회수 근거를 own WIP/tmp에 반영한다. 최종 캐시·전량 재계측 후 계획·결과·기준표·METHODS·COMPASS를 현재 증거로 갱신한다. root09·experiments의 실행 계약은 바꾸지 않는다. |
| 기술부채 | 이전 실패와 상반된 본문을 지우지 않는다. 정확 선택표를 단일 입력으로 두고 별도의 가장 최신 본문 추측 경로를 만들지 않는다. |
| GPU·모델 | 이 CPU 작업에 사용하지 않는다. |
| 소유권 | own audit/base/agent role 폴더만 쓰고 타 실험 tmp는 읽기만 한다. |
| 비교 조건 | 원문 ID·구간·SHA와 같은 tokenizer의 실제 캐시 수치를 사용하며 초안 수를 채택 수로 바꾸지 않는다. |
| 증거 수준 | 후보 생성, 독립 전문 판독, root 선택, 실제 캐시 생성, 독립 verify는 별개다. |
| 문서 연쇄 | 부분 수치는 부분 검증임을 유지한다. 최종 검증이 끝나기 전 goal 완료·학습 재개를 선언하지 않는다. |

잔여 profile의 175개 원문 중 기존 core/supplemental/새 v15의 지정 대상과 겹치지 않는 ID만 새 문맥 판독에 배정한다. 이는 전량 처리를 위한 유형별 근거이며 이 표본의 완료를 전체 목표 완료로 삼지 않는다. 병원체 조작 등 이미 제한된 원문은 이 일반 판독에 포함하지 않는다. 원문에 유효한 코드·역사 전사·반복·목록·채워진 참고문헌은 보호하고 실제 결손과 직접 의존 구간만 별도 보관한다.
