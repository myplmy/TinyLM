# v20 실제 지역 함수 근거와 빈 명목 필드 계약

권한은 첨부 목표의 CPU 전처리·관련 구현/시험·새 파생본이며, 원문·과거43생산파일·기존 캐시를 변경하지 않는다. 실제 텍스트 개별 정제는 지정된 다섯 역할이 수행하고 root는 규칙/검사/판단을 담당한다. GPU·모델·추가300M·설치/다운로드·타 세션 전용자료·보호 TinyDataset·push/PR은 범위 밖이다.

| 안 | 내용 | 장점 | 한계 | 영향도 | 수행비용 |
|---|---|---|---|---|---|
| A | 각 함수/빈 슬롯을 전부 개별 TXT로만 처리 | 개별 근거 상세 | 같은 지역 문법 반복 판독 비용 큼 | 저자 자료만 | 높음 |
| B | 원문에서 증명되는 지역 선언/표현식/메서드 관계와 좁은 명목 필드만 확장 | 정상 코드와 실제 빈 값 구분, 재생성 가능 | 증명이 없는 문맥은 계속 미결 | 새 정책/재생/시험/감사 파일 | 중간 |
| C | 문서에 프로그램 단어가 있으면 모든 괄호 허용 | 회수량 큼 | ABC() 같은 빈 약칭과 실제 결손을 함께 통과 | 의미 손실 위험 큼 | 낮음 |

선택 B. Dart의 `main() {` 및 Java의 `Object obj = type.newInstance();`는 해당 줄의 문법이 직접 근거다. `ABC(): agency`는 다른 문단의 programming 단어로 허용하지 않는다. printf의 실제 선언에서 확인된 동일 함수명과 member 표현식도 원문 근거로만 연결한다. 프로그램을 실행하거나 함수의 API/arity/동작 정확성을 새로 승인하지 않는다.

v17 새 유형293331의 `多形性, ; 폴리모피즘`은 실제 두 값과 세미콜론을 보존하며 그 앞 비어 있는 쉼표 슬롯만 정리한다. 같은 완결 문단에서 명시한 반댓말 `단형성()`은 값이 있는 명칭의 빈 선택 병기만 제거한다. 숫자/연산/좌표/기호 예시·값 이름·전사/코드·날짜/화살표는 이 증거로 처리하지 않는다. 1158450의 실제 값 없는 음반외활동/TV프로그램 조상 표제는 v17의 다중 명시 metadata 경계 안에서만 비어 있음을 증명한다. 정상 분류값은 삭제하지 않는다.

기존 exact CTA 탐지식을 재사용하되 문구/인용/코드의 예시 문맥은 보존한다. 검색·뉴스레터·DVD 판매, 기관 홍보 뒤 관련 글 미리보기의 실제 관찰 문구는 새 거부 신호로 검사하여 과거 종결도 다시 판독 대상으로 돌린다. 단어 하나를 이유로 일반 학술 설명/자료명 전체를 자동 삭제하지 않는다.

| 축 | 영향 | 근거/검사 |
|---|---|---|
