# guard5와 분할 메타데이터를 결합한 독립 채택

독립 Luna 두 역할의 전량 판독, 숫자·코드·유니코드·문체·원문 순서·검수 메모 검사, 이전 선택의 본문 동일성은 기존 절차를 그대로 사용한다. 32895/74587의 정확한 두 metadata HOLD는 원형·후보·packet을 열거나 해시하지 않고 먼저 분리한다. 기존 안전 파생본 세 건은 이전 선택과 동일하게만 보존한다.

ROOT32부터 선택 메타데이터는 원래 dict/list와 정확히 같은 논리 JSON을 작은 manifest와 내용 주소 행 조각으로 저장한다. 새 wrapper는 명시한 이전 선택 파일의 실제 SHA에만 로더를 결합한다. 파일 SHA는 디스크 manifest의 값이며, 논리 JSON SHA·행 수·순서·각 조각 SHA는 별도로 검사한다. 기존 ROOT31 이하의 단일 JSON이나 원문 TXT를 변경하지 않는다. 설계·권한·회귀 범위는 `SELECTION_METADATA_SHARDING_F3_F4_V1.md`가 소유한다.

개별 문법 closure는 정확한 원문·새본문·리뷰 SHA와 원문 전문/새본문 전문/전체 diff 판독이 확인된 쌍에만 적용한다. 문장 종결·빈 참조 정리 외의 사실을 생성하지 않는다. 일반 guard 면제는 0이다. 최신 snapshot에 기계 오류가 있으면 적용하지 않고 새 버전으로 정정한다.

본문 TXT 작성은 다섯 Luna만 수행한다. 공식 cache15의 HOLD105824와 현재 선택의 반영 대기 수량을 구분한다. 새 선택은 실제 cache16 검증을 대체하지 않으며 전체 사실검증·학습 실행 승인·목표 완료의 근거가 아니다.
