# expanded_train:1430742 원형 보류 기록

원문 및 선택본문은 byte-identical이다. 본문 끝의 다음 Turtle 예제는 여러 문장과 제어 흐름이 한 줄에 붙어 있다.

from turtle import * import random setup(width=600,height=700) colorlist = ["red", "violet", "orange", "blue", "yellow"] speed(60) pensize(2) for i in range(200): circle(150) color(colorlist[i%5]) left(53) forward(i/50+20) i += 2 hideturtle()

이 묶음은 줄 경계·들여쓰기와 실행 흐름이 손상돼 독립 프로그램으로 해석될 수 없어 원형 그대로 보류한다. 줄바꿈·들여쓰기·함수 호출을 추정하여 재작성하거나 실행하지 않는다. 소개 문장, 실제 연결된 다른 터틀 튜토리얼 항목 및 제목은 보존한다.
