# expanded_train:10566 원형 보류

후보는 원형의 `오세트어()` 빈 병기와 빈 `모음`, `이론 방언`, `디고르 방언`, `발음`, `자음`, `각주`, `외부 링크` 구획을 정리했다. 실제 `방언`의 이론·디고르 구분과 표준어 설명, `문자` 아래 연도별 로마·조지아 문자 사용, 문법 설명 및 끝의 분류 항목은 보존됐다.

원형의 `문자` 구획에 있던 `다음과 같은 키릴 문자를 쓴다.`는 뒤따를 문자 목록을 직접 예고하지만 원문에는 목록이 없다. 이 문장만 원형 보류한다. 뒤의 1923–1938년 로마 문자와 1938–1954년 조지아 문자 설명은 실제로 채워진 독립 정보로 남긴다.
