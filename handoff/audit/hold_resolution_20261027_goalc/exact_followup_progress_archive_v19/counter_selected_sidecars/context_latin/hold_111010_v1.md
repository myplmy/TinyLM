# expanded_train:111010 원형 보류

원문에서 대상 글리프 또는 값이 비어 있거나, 문장/표제의 설명 대상이 확인되지 않는 다음 조각을 그대로 보존합니다.

```text
이로하 순: 제17위 ( 다음,  이전)
히라가나 ''의 자형: '礼'의 초서.
가타카나 ''의 자형: '礼'의 오른쪽 모습.
한/글의 한글 입력:
일본어 점자:
일본어 통화표: ''(는 '연화꽃'을 뜻함)
획순
컴퓨터 부문
각주 
ら4
```

빈 글리프 자리에 새 문자를 채우거나 `ら4`를 앞의 모라/순위 정보에 귀속하지 않습니다. 본문에는 명명된 음절과 실제 위치·모라·로마자·입력 문자열·외래어 표기·모스 부호 설명을 유지했습니다.
