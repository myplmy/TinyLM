# expanded_train:97220 원형 보류 기록

원문에는 다음과 같이 정의를 예고하지만 정의식과 변수명이 비어 있다.

신호 대 잡음비(, SNR, S/N)는 다음과 같이 정의된다.

여기서 와 은 각각 신호의 전력과 노이즈의 전력에 해당한다.

후보는 이 미완 정의와 변수 설명을 본문에서 제거했다. 식·변수명을 추정하지 않는다. 목적과 통신 시스템 성능에 관한 실제 자연어 설명 및 다른 표기(SNR/S/N과 dB 표기 차이)는 후보에 보존됐다. 원문의 빈 병기 쉼표, 각주 및 외부 링크의 내용 없는 표제도 후보가 정리했다.
