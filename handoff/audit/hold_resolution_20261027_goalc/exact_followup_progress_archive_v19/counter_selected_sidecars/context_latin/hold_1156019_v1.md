# expanded_train:1156019 — 보류 원형/형식 기록

원형과 candidate는 아래 코드 내용을 한 줄로 붙여 적었다.

> str1 = "PythON is a CRoss-platFORM obJECT-oriENTED PROgramming lanGUAGE" print(str1.title())

문자열 대입과 `print(str1.title())` 호출이 각각 닫혀 있고 그 사이에 문장부호/주석/제어 구조가 없으므로 새 토큰 없이 줄 경계만 분리했다. 이 문서에는 원형의 붙은 표기를 기록한다. 샘플을 실행하거나 결과를 검증하지 않았다.
