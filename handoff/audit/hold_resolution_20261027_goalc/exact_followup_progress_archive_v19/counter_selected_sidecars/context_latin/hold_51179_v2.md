# expanded_train:51179 원형 보류

페이지 footer의 채워진 분류 라벨을 원형 그대로 보존:

- `시간`
- `유닉스`
- `C 표준 라이브러리`

본문은 시간 저장, POSIX 호환 운영 체제와 ISO C 라이브러리의 관계를 이미 명시한다. 따라서 이 세 독립 라벨을 페이지 분류 footer로 분리한 후보를 수용한다. 같이 보기의 2038년 문제와 10억 초 문제도 본문에 유지돼 있다. 이 판단은 기술 사실을 갱신하거나 새 내용을 추가하지 않는다. 앞선 NEEDS_ROOT 메모는 당시 판정 대기 이력으로 보존한다.
