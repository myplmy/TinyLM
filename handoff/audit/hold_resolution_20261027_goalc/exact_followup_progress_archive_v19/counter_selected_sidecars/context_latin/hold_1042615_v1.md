# expanded_train:1042615 — 보류 원형

원형의 말미에는 다음과 같이 끝이 잘린 문장이 있다.

> Like localtime, this function might throw an error if the ctime(2) call failed on the system. It's platform dependent what time ranges that function can handle, e.g. Windows doesn't handle a negative

원문은 `negative` 뒤의 대상/나머지 조건을 제공하지 않는다. 이 잘린 직접 의존 문장과 항목 없는 `See also` 표제를 원형으로 보존한다. 새 범위·값이나 참고 항목을 만들지 않는다. candidate가 앞의 명명된 `ctime` 설명은 보존했다.
