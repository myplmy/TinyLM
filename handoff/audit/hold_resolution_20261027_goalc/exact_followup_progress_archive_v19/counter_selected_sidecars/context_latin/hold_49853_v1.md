# expanded_train:49853 원형 보류 기록

원문에는 표준어/문화어의 국제음성기호를 소개하지만 기호 자리에는 실제 기호 대신 남/북 표시만 있다. 그 직접 의존 문장을 원형 그대로 보존한다.

국제음성기호로는 표준어의 경우 (남) 또는 (남)로 나타내고, 문화어의 경우 (북) 또는 (북)로 나타낸다.

후보는 이 기호값 예고를 제거했다. 빠진 IPA 기호를 추정하지 않는다. 또한 내용이 확인되지 않는 코드 값/정보 블록 및 ㅈㅈ 조각도 후보가 분리했으므로 이를 코드 포인트로 단정하거나 본문에 재구성하지 않는다. 실제 ㅉ 설명, 발음 조건·표준어/문화어 대비 및 표기 예시는 보존됐다. 빈 병기 구두점도 정리됐다.
