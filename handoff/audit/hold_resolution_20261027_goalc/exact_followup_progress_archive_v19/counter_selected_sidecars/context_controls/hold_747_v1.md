# 747 원형 보류 조각

- 검토 범위: 지정된 `expanded_train:747` packet 1의 원문·선택본문·전체 diff.
- 원형 문장: `나노미터의 과거 명칭은 밀리마이크로미터(millimicrometre), 더 간단히 말하면 밀리마이크론(millimicron)인데 이는 이것이 마이크론(마이크로미터)의 이었기 때문이다.`
