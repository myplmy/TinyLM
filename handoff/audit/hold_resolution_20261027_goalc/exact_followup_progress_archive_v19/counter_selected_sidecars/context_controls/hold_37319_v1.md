# expanded_train:37319 원형 보류

- 원형 도입 조각: `보륨(←, )은 화학 원소로 기호는 Bh(←), 원자 번호는 107이다.` 두 화살표 표기는 가리키는 대상이 비어 있으므로 각각의 괄호 래퍼를 원형으로 보류했다. 후보에 남은 `←`만으로는 관계를 해석할 수 있어 보이지 않아 새 본문에서는 두 빈 래퍼 전체를 제거했다. 새 원소명·기호·유래 관계는 추가하지 않았다.
- 직접 결손 비교 원형: `보륨의 동위원소들은 주로 분을 넘기지 못한다. 그러나 보륨274나 273은 반감기가 90분 정도로 매우 긴 편이다.` 첫 절의 시간값이 빠져 비교 기준을 정할 수 없다. 작업 본문은 보륨274/273의 실제 명명된 `90분 정도` 값만 남기고, 누락 기준에 직접 의존하는 첫 절과 `그러나`/`매우 긴 편` 비교 표현은 이어 붙이지 않았다.
- 빈 `각주` 표제도 후보에서 제거된 상태로 유지했다. 그 밖의 명명된 설명, 값·단위, 외부 링크와 분류는 수정 본문에 유지했다.
