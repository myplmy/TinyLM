# 14948 원형 보류 메모

- 입력: `expanded_train:14948`; 후보 basename `expanded_train_14948_candidate.txt`.
- 원형 보류 구간:
  - ` 일본(日本) 남조(南朝) 고와() 3년`
  - ` 일본(日本) 북조(北朝) 에이토쿠() 3년`
- 수정 본문에서는 각각 `고와 3년`, `에이토쿠 3년`으로 정리했다. 실제 명칭, 조정 구분, 연수는 유지하고 값이 없는 괄호 포장만 제거했다. 빈 괄호에 없던 한자나 별칭을 보충하지 않았다.
- 선택 본문은 후보의 빈 `탄생`/`사망` 표제 제거를 포함한 나머지 텍스트를 유지한다.
