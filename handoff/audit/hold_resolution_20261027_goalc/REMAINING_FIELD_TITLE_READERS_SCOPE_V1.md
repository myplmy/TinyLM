# 필드·제목 잔여 전량의 판독 자료 준비

전체 잔여 정제의 승인 범위에서 수행한다. 18,237고유/29,659위치의 원문 복원과 동결 정책의 후보 재생성이 실제 일치했다. 이번 단계는 36페이지 전량의 판독 입력을 만드는 작업이며 정제·채택·의미 검토 완료가 아니다. 512행은 분할 단위이며 작업량 한도가 아니다.

기존 prepare_remaining_birth_readers_v1.py를 읽고 정확 입출력·유형 안내·2000문자 패킷·상한 검사만 어댑트한다. 원문/후보는 검증한 새 native 입력 pin을 재사용해 불필요한 TXT 복제를 줄인다. source ID와 SHA 보호 경계를 파일 열기 전에 검사한다. 페이지 간 중복0과 18,237개 전체 포함을 검산한다.

코드 영향은 새 준비 어댑터와 감사 근거뿐이며 생산 정책·토크나이저·캐시 스키마는 바꾸지 않는다. 데이터 영향은 새 판독 파생물뿐이다. 기존 순서 재구성·pin·20,000,000바이트 상한 검사를 재사용한다. 정본 문서는 현재 WIP에 진행 사실만 반영하며 전체 결과/기준표/METHODS/COMPASS의 완료 연쇄는 이후 실제 전량 결과에 맞춘다. 유지 부담은 페이지 목록과 각 실제 읽기 상태 추적이며 읽기 준비를 판독 완료로 바꾸지 않는다.

GPU·학습·모델·TinyDataset·타 세션 전용자료·설치·다운로드·원형 덮기/삭제·push·PR은 제외한다. 기존 다섯 Luna가 자기 literal 배정을 마친 뒤 새 정확 범위를 순차 배정한다. controls의 실제 입력은 별도 고정 reader 준비 후에만 허용한다. 입력 동일성은 후보 중복 읽기의 대체 근거일 뿐 내용 수용 근거가 아니다.
