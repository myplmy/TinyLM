# expanded_train:344828 원형 보류

원문에는 빠진 중첩 함수 예시를 직접 가리키는 조각과, 그 예시를 pipe operator로 다시 쓴다고 제시한 호출 줄이 있다. 빠진 예시를 보충하거나 그 호출을 독립적으로 뒷받침되는 결과로 만들지 않고 이 직접 의존 범위만 원형으로 보류한다.

~~~text
Take the following nested functions into consideration:
Here, we are passing the value
bar/1, and finally the result of
foo/1.
Let’s take another look at the code snippet above rewritten using the pipe operator.
other_function() |> new_function() |> baz() |> bar() |> foo()
~~~

일반적인 pipe operator 설명과 실제 String 모듈 예시 및 경고/출력은 candidate 본문에 유지되어 있다. 누락 예시를 복구하거나 코드를 실행하지 않았다.
