# expanded_train:105927 원형 보류 메모 v2

- 리드의 원형 `광증발 효과(光蒸發 效果, )`에서 빈 영어 병기 슬롯과 `"중력적 반경"()`의 값 없는 괄호는 원형 포장만 분리한다. 실제 광증발 용어와 `중력적 반경` 문장은 유지한다.
- 원문에서 직접 분리한 조각:

```text
106 ~ 107년 후에는  지점에서의 점성이 광증발률보다 높아지며,  지점에 간극이 생겨난다.
원시 행성계 원반의 중력적 반경을 구하는 식은 다음과 같다.
 는 중력 상수이다.
 는 중심 별의 질량이며, 는 태양의 질량이다.
 는 기체의 평균 질량이다.
 는 볼츠만 상수이다.
 는 기체의 온도이다.
각주
```

- 빈 위치·기호, 식과 표제 대상이 없어 위 조각의 수치 시점·변수 대응을 확정할 수 없다. `106 ~ 107`을 지수 표기로 바꾸거나 변수 기호·식을 만들지 않는다.
- 실제 원문 어휘의 열용량율비와 일원자 분자 조건·5/3은 본문에 유지한다. 소실 기호를 추가하지 않는다.
- 원문에 실제로 있는 간극 안쪽 원반의 두 진행 관계는 명명된 대상과 술어가 닫혀 있어 본문에 그대로 남겼다.
- 원문 `AU는 최종 값의 단위로서, 천문단위이다.` 중 `최종 값의`는 소실된 식의 결과값을 가리키는 미상 지시로 원형 보류한다. 본문에는 실제 명칭 관계만 `AU는 천문단위이다.`로 남겼다.
- 별 형성의 영향에 대한 추정과 불확실성은 그대로 유지한다. 새 천문학 사실 검증이나 수식 복원은 하지 않았다.
