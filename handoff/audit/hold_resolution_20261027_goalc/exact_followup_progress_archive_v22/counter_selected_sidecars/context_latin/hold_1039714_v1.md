# expanded_train:1039714 — 원형 보류 메모

다음 PHP 예제는 주석(`//`)과 실행 구문이 한 물리 행으로 붙어 있어 원래 코드 줄과 주석 범위를 추정할 수 없다. 이 코드와 이를 직접 설명하는 실행 결과 문장만 본문에서 분리했다.

`PHP cURL Post`

`Now we are going to call the set of php cURL function to post data,`

`//Initialize cURL $ch = curl_init(); //Set location to post data using cURL curl_setopt($ch, CURLOPT_URL,"http://www.your-website.com/yourScript.php"); //Enable POST method curl_setopt($ch, CURLOPT_POST, 1); //Create a array of data curl_setopt($ch, CURLOPT_POSTFIELDS, array( 'name'=>'your name', 'email'=>'your email', 'mobile'=>'your mobile', 'dob'=>'your date of birth', 'location'=>'your location' )); //Set return True curl_setopt($ch, CURLOPT_RETURNTRANSFER, true); //Execute the cURL echo $server_output = curl_exec ($ch); //Close curl_close ($ch);`

`The above script sends a post a HTTP post request to the given URL with the array of data. Remote script will receive this data and insert into database or process this according to the requirement.`

코드 줄바꿈·주석 경계를 복원하지 않았고, 코드를 실행하거나 그 동작을 검증하지 않았다. 서론의 HTTP POST 목적/일반 설명과 이미 작성된 종결 문구는 보존했다.
