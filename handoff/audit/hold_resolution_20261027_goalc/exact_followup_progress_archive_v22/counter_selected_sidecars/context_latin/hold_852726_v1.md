# expanded_train:852726 원형 보류

후보가 분리한 실제 외부 대상을 식별하지 못하는 링크 포인터:

원문: `A similar question was asked in the following link (link to the question), but I do not think the question was resolved.`

후보는 URL 없는 `in the following link (link to the question)`만 없애고, 질문자가 유사 질문이 있었으나 해결되지 않은 것으로 생각한다고 한 문장은 남겼다. 링크 대상을 복원하지 않았다. 본문에 적힌 histogram 호출, 입력, 두 결과 배열, 질문자의 의문과 요청은 보존했다.
