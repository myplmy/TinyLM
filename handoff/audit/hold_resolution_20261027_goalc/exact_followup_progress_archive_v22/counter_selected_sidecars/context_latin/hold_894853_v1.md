# expanded_train:894853 원형 보류

후보에서 분리한 실제 구조가 닫히지 않은 두 번째 JavaScript 예제:

```text
$(document).ready(function(){
    $('.myList li').on('click touchstart', function() {
        $('.myDiv').slideDown('500');
    });
}
```

닫는 블록/호출 구조를 추정해 보충하지 않았다. 실제 닫힌 tap 예제, jQuery Mobile 설명과 브라우저 지원 조건은 후보에 남았다. 후보가 함께 정리한 빈 `출시 역사`, `각주`, `참고 자료` 표제는 내용 없는 구획으로 보류했다. 이름 있는 같이 보기 항목과 외부 자료는 유지했다.
