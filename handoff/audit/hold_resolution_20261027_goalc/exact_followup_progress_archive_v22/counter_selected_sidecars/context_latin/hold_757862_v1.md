# expanded_train:757862 원형 보류

후보에서 제거하거나 새 본문에서 좁혀 분리한 원문 조각:

- `|S.N.||Constructor & Description|`와 `This is the single constructor.`: 생성자 이름·서명이 없는 빈 생성자 설명 블록
- `This class inherits methods from the following classes:`: 뒤따를 상위 클래스 목록이 없는 직접 예고

실제 `java.util.Dictionary` 선언, 객체/키/값 설명과 이름·서명이 완결된 일곱 메서드 행은 보존했다. 생성자나 상속 메서드 목록을 추정해 채우지 않았다.
