원문과 지정 후보는 바이트 동일하다. 원문에는 아래와 같이 빠진 예시 코드를 직접 가리키는 설명과 평탄화된 코드가 남아 있다. 추출 손상 가능성이 있는 코드의 줄바꿈·들여쓰기를 추정하지 않고, 그 코드에 직접 의존하는 안내와 함께 원형으로 보류한다.

~~~text
The following python script takes a text file as input and produces an unsorted list of frequency counts of words in the text as an output text file. It’s pretty simple and short, and uses only the regular expressions module re of python, which is a standard library, so this script will run in any system with a standard python installation.
from re import compile l=compile("([\w,.'\x92]*\w)").findall(open(raw_input('Input file: '),'r').read().lower()) f=open(raw_input('Output file: '),'w') for word in set(l): print>>f, word, '\t', l.count(word) f.close()
~~~

명시된 Input file/Output file 예시와 빈도 값, 단어 경계에 대한 독립 설명은 새 본문에 보존했다. 코드 실행·출력 계수 재검증이나 복구는 하지 않았다.
