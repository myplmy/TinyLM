## 후보에서 분리된 직접 예고와 구조 소실 코드

> - Copy and paste the following piece of code in the editor.
> First RGSS demo
> my_sprite = Sprite.new() my_bitmap = Bitmap.new(544, 416) my_sprite.bitmap = my_bitmap my_sprite.bitmap.draw_text(0, 0, 320, 300, "Hello World!", 2) loop do Graphics.update end

명시된 예고의 대상 코드가 하나의 붙은 스니펫으로 구조가 닫히지 않아 그 예고와 스니펫을 함께 분리했다. 없는 구분자·개행·들여쓰기를 만들거나 실행하지 않았다. 별도로 채워진 `my_sprite.bitmap = my_bitmap.` 관계와 Bitmap/Sprite 설명은 후보에 유지되어 있다. 말미 `Leave a Reply`는 UI/댓글 유도 요소로 분리됐다.
