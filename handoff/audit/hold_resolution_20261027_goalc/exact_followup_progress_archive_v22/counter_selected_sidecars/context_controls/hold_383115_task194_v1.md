# 383115 · TASK194 원형 보류 메모

- 지정 원문·후보·전체 diff 3개 packet을 END까지 판독했다. 후보를 수용한다.
- 원형 첫 줄의 `|NAME | SYNOPSIS | DESCRIPTION | RETURN VALUE | CONFORMING TO | SEE ALSO | COLOPHON||The Linux Programming Interface|`는 manpage/사이트 상단 UI 조각이다. 실제 `ON_EXIT(3)` 표제와 함수 설명에 연결되는 본문이 아니므로 후보가 분리한 대로 학습 본문에서 제외한다.
- 함수 서명과 설명, 반환 조건, 출처/버전 기록은 후보에 그대로 남아 있다. 코드를 실행하거나 API를 현재 문서와 대조하지 않았다.
