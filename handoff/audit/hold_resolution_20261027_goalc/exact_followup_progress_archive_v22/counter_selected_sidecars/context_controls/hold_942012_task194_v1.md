# 942012 · TASK194 원형 보류 메모

- 지정 원문·후보·전체 diff 3개 packet을 END까지 판독했다. 후보를 수용한다.
- 원형의 `abs_path() function takes a single argument and returns the absolute pathname for that argument. It uses the same algoritm as`에서 마지막 `It uses the same algoritm as`는 이어질 대상이 없어 미완 관계 조각이다. 이 조각만 후보가 분리한 대로 보류하고 대상을 추정하거나 `algoritm`을 교정하지 않는다.
- `abs_path()`의 실제 인수/반환 설명과 주변 `getcwd`, `fastcwd`, `cwd`, `fast_abs_path` 설명·조건은 후보에 보존되어 있다. Perl 코드를 실행하거나 현재 API를 검증하지 않았다.
