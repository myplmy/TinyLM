# 6692 TASK191 원형 보류 메모

- 실제 판독: 지정 원문·후보·전체 차이의 packets 1–3을 순서대로 확인했다.
- 후보에서 분리한 문장 원형: `그 자신이 간추린 대표적 간행물의 목록은 그의 출판물 사이트에서 찾아볼 수 있다.`
- 문장은 특정 사이트명·주소·목록 항목 없이 외부 위치만 안내하므로 학습 본문에서 분리한다. 사이트나 저작 목록을 추정하지 않는다.
- 빈 병기 슬롯 및 내용 없는 각주 표제는 후보에서 정리됐다. 실제 간행물 제목·연도·저자 관계와 채워진 LSE 프로필 링크는 보존한다. 인물 정보는 외부 검증하지 않았다.
