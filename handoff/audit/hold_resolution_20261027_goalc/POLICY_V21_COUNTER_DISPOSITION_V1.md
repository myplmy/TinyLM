# v21 목적 탐색의 독립 반례 처리

최초 목적 탐색732쌍은 실제0/25.970초, 새 종결14쌍이었다. 자동 코드/Unicode/스타일/문자 순서 경고0은 의미 보존 승인이 아니다. 해당14쌍 모두 structure_counter 역할에 원문/후보 정확 SHA로 지정했다.

940988의 실제12행 전문에서 답변·가입 UI, 잘못된 중간 지수 동일식, 빠진 유도 단계가 발견되었다. 동일식 u^(v^z)=u^(v*z)는 u=2,v=3,z=2일 때512와64로 달라 총괄이 CPU로 대조했다. 새 수식·풀이를 생성하지 않고 완결 원문 질문과 마지막 조건부 결과/작성자 귀속만 별도 실제 저자 정제 후보로 남기도록 중재했다. 초안 KEEP는 채택하지 않는다. 정책은 관측된 비인용·비코드 답변/가입 UI를 새 미결 신호로 검사하며 최초 목적 탐색·당시 정책 소스는 보존한다. 모든 수식에 대한 사실 검증을 수행했다고 주장하지 않는다.

233893의 빈 갤러리/각주 표제 복원 제안은 원문 말미에서 실제 항목이 없음을 확인하여 거절했다. 원래 목적대로 빈 표제만 제거하고 노선·원색상·차종·날짜·분류 네 줄은 모두 보존한 정확 후보를 선택하도록 중재했다. 복원 초안과 최초 review는 보존하고 새 review_002_v2로 수정 기록을 남겼다.

정책 회귀 최초 실패315개 중 함수 앵커 검사의 구현 오류는 실제 조사가 아닌 다른 한국어 조사 뒤 문자열까지 같은 앵커로 오인한 것이었다. 실제 원문/후보의 같은 정확 조사까지 결합한 앵커로 수정하고 반례를 추가했다. 스타일 색상 사례는 원문 색상·노선 관계를 그대로 유지하도록 렌더러를 바꾸었으므로 v13의 '색상 손실 후 미결' 기대만 '손실 없이 원문 KEEP'으로 명시적으로 대체했다. 색상 손실 거부 자체와 다른 v13 검사는 그대로 유지한다. 수정 회귀316개와 재생40개는 실제 종료0이다. 추가 UI 반례 이후 새 회귀·새 목적 탐색을 실행하며 그 전 v21 전량은 NOT_RUN이다.
