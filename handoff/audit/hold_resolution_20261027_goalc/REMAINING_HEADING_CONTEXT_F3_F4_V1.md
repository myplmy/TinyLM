# 독립 문맥 반례의 일괄 반영

목표 §1·4·5·6과 현재의 전체 HOLD 정제·반복 축소 지시로 진행한다.
기존 METADATA_CATEGORY_ANCHORS_F3_F4_V1.md의 영향 범위를 유지한다.

| 안 | 내용 | 장점 | 한계·영향 | 비용 |
|---|---|---|---|---|
| A | 문자 보존만으로 252건 채택 | 빠름 | 실제 빈 노선·갤러리를 놓침 | 낮음 |
| B | 새 문맥 반례를 전체 후보의 추가 보류 게이트로 적용 | 오삭제 없이 이미 검증한 문자 proof 재사용 | 채워진 별도 표제도 추가 문맥 검토로 보류될 수 있음 | 낮음 |
| C | 511건을 모두 다시 사람에게 배정 | 넓은 개별 판독 | 기존 판독 반복·지연 | 높음 |

선택 B. 별도 단락으로 남은 운항 노선·화물 노선·갤러리·작품 연보·기후·사진은
문자 보존만으로 내용의 존재를 증명하지 못한다. 추가 게이트는 삭제하지 않고 채택을 보류한다.
한 블록 안에 제목과 실제 행이 함께 있으면 이 추가 게이트만으로는 보류하지 않으며,
기존 원문 연결·수치·순서·코드·문체 proof와 기존 본문 결손 게이트도 모두 유지한다.

| 경로 | 동작·권한 | 제외 |
|---|---|---|
| 이 audit의 새 게이트·시험·보고 | 신설, 목표 CPU 구현·검증 허가 | 원형·기존 proof 변경 없음 |
| census가 고정한 원문 | 정확 ID·SHA 확인 후 읽기, guard6 | 제한 ID·alias·hash 열지 않음 |
| 기존 rule30/31 후보·독립 리뷰 | 읽기·SHA 연결 | 후보 덮기·자동 ROOT/캐시 채택 없음 |

코드: 기존 independent literal proof를 재사용하고 추가 보류만 한다. 데이터: 새 본문 사본 0,
작은 metadata 보고만 생성. 시험: 새 노선·갤러리 및 실제 채워진 같은 블록·인용 반례를 확인한다.
정본: 채택 묶음과 후속 WIP·결과·METHODS·COMPASS에 실제 계수를 반영하며 GPU 결과는 없다.
기술부채: 휴리스틱이 완전한 절 파서라는 주장은 하지 않고 보수적 문맥 검토 사유로 남긴다.
보호 자료·타 세션·모델·토크나이저·학습 조건은 변경하지 않는다. STATIC_ONLY/CPU 자료 검증이며
학습·품질·캐시 소비 검증과 구분한다. 새 표제 하나마다 별도 리뷰·원장 파일을 만들지 않는다.
