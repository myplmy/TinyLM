# 335240 단일 미완 편집본의 리터럴 범위 선택

AUTHOR_LITERAL_EDITOR_335240_SCOPE_V1.md와 동일 ID·역할·target·금지 경계를 유지한다.
추가 기능은 이미 판독한 문단을 고유한 앞뒤 문자열로 선택하는 일반 편집 동작이다.
Luna가 Python/셸 코드를 작성하거나 임의 파일을 전처리하는 권한이 아니다.

같은 --apply에 JSON `{"expected_sha256":"현재 SHA","spans":[{"keep_before":"남길 앞 문맥",
"keep_after":"남길 뒤 문맥","replacement":""}]}`를 전달할 수 있다.
앞뒤 문자열은 각각 8–400자·파일 전체에서 한 번씩만 일치해야 하며, 두 경계 자체는 남긴다.
중간에 들어갈 텍스트는 리터럴 데이터다. 한 실패라도 있으면 파일을 쓰지 않는다.
기존 old/new edits, SHA CAS, 임시 파일의 단일 원자 교체, 전체 old/new 출력 한도와
최종 본문·전체 diff·EOF 판독 의무는 유지한다. 마지막 수정이 끝날 때 한 번 검토한다.
동일 SHA인 초기 prefill을 원문과 별개로 전문 재판독하거나 매 편집마다 다시 전문 읽지 않는다.
어떤 절을 제거할지는 저자가 판단하며 도구는 의미를 판단·추정하거나 ROOT/캐시에 채택하지 않는다.
