# 판독 자료 중복 출력 비용의 F3·F4 검토

상태: DESIGNED. 사용자 목표의 CPU 분석·관련 코드 구현·시험 허가에 따른 자료 전달 개선이다. 전체 정제 A–E와 기존 다섯 역할을 계속하며, 학습 본문을 총괄이 새로 작성하지 않는다. 아직 새 reader의 시험·역할 적용·실제 속도 개선은 NOT_RUN이다.

근거는 동결 단계 집계 V9의 최초 판독125고유/77.31분과 기존 reader의 실제 코드다. `scoped_packet_reader_v1.py`는2000자씩 자른 original/candidate/full_diff 프레임을 전달한다. `identical_input_reading_v1.py`는 두 바이트열이 같을 때만 중복 candidate 구간 생략을 증명한다. `field_scoped_packet_entry_v1.py`의 고정 metadata SHA와 역할·page 검사 및 `pinned()`을 재사용할 수 있다. 기존 FIELD_SHORT_READER_CONFIG_V1의 guard는V1이므로 새 진입점은 현재 V3의8ID/9SHA를 별도로 강제해야 한다. 현재 실제 배정 page의 V3 metadata 사전검사는 따로 통과한 상태다.

권장: B. 판단 기준이나 원문 판독 범위를 바꾸지 않고 출력 표현의 중복을 줄인다. 예를 들어 원문에서 빈 표제 한 줄만 삭제한 후보는 공통 본문을 다시 출력하는 대신 삭제 위치를 명시할 수 있다. 단순 patch가 후보 전체보다 길어지면 후보 전문을 그대로 전달한다. 바이트가 같은 경우는 원문 전체와 동일성 증명을 전달한다. 출력량 절감은 CPU fixture와 이미 검토한 실제 입력에서 계측하며, 모델의 실제 작업시간 개선으로 승격하지 않는다.
