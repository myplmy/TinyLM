# ROOT20 검토 이력 연결 보강

실제 v13 수집은 TASK143 초안의 다른 TASK 소속 4행을 정확히 거부했고, TASK143의 지정 5행과 TASK142의 정식 4행은 각각 올바른 리뷰를 선택했다. 그러나 기존 승인기에는 `invalid_task_rows`가 완전히 비어야 한다는 전제가 있어 새 묶음 전부가 출력 생성 전에 중단됐다. 이력 오류가 현재 선택의 오류와 같지 않다는 연결을 보강한다.

- 안 1: 기존 승인을 전부 중단한다. 데이터는 안전하지만 이미 제외된 이력 때문에 정상 신규 문서도 반영하지 못한다.
- 안 2: 독립 검산한 정확 v13 SHA와 해당 4행·잘못된 리뷰 SHA를 전용 근거에 연결한다. 새로운 무효 행은 계속 실패하며 원문·수치·코드·문맥 guard는 모두 유지한다. 현재 승인 범위에서 이 안을 적용한다.
- 안 3: 옛 리뷰를 삭제하거나 수집 결과의 오류 이력을 지운다. 복구·감사 경계에 맞지 않아 적용하지 않는다.

영향은 총괄 승인 연결과 해당 증거의 input pins로 제한한다. 기존 V1/V2 코드, 이전 선택·캐시, 원형과 훈련 TXT는 변경하지 않는다. 잘못된 네 행은 훈련·리뷰 근거로 채택하지 않는다. 새 V3은 전용 proof의 모든 pin을 다시 확인하고, 고정 v13에서 일치하는 정확 네 이력만 허용한다. 별도 예외가 없는 다음 snapshot은 이 V3 경로를 자동으로 통과하지 않는다.

검증은 v13 실제 거부 네 행·현재 선택 아홉 행·ROOT19 이전 미채택의 독립 대조, 새 선택의 이전 행 보존, 전체 297539행 원장 대조 순으로 수행한다. 이는 내용 전량 사실 검증이나 모델 품질 PASS가 아니다. 전체 정제는 계속 진행한다.
