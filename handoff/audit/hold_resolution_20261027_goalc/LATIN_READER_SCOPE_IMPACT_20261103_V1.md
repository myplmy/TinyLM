# Latin의 독립 검토 입력 경로 고정

TASK050에서1074099 한 패킷과107538 세 패킷을 현재 birth_root11 입력 대신 이전 remaining_birth_full 입력에서 읽은 실제 범위 밖 접근이 보고됐다. 실패한 네 번째 패킷은 별도로 내용 미반환이다. 성공한 이전 단계 읽기를 현재 최종본의 독립 비교 근거로 쓰지 않는다. 정확 TASK 입력으로 이미 허용된 판독은 계속한다.

| 안 | 장점 | 비용·한계 |
|---|---|---|
| A | 현재 네이티브 경로를 TASK에서 복사 | 추가 도구 불필요 | 이전 단계의 같은 ID 경로도 실제로 열려 입력 버전 혼동 가능 |
| B | 역할 폴더에 같은 입력 별칭을 추가 | 짧은 경로 사용 | 기존 단계와 별칭을 혼동할 수 있고 중복 파일·정합성 관리 필요 |
| C | 기존 고정 reader를 Latin1353개 배정에 재사용 | ID·패킷번호가 현재 manifest와 고정 SHA의 입력만 선택 | 새 registry와 명령MD 검증·전환 안내 필요 |

C를 적용한다. 고정 판독기·파일 재구성·다른 역할 거부를 실제 검증한 뒤 현재 TASK를 마친 경계에서 전환한다. 이미 완료한 TASK를 새 도구라는 이유로 다시 읽지 않는다. 이 판독기는 Python 코드 작성 권한이나 OS sandbox가 아니다.

프로젝트 영향: GPU/학습/모델·비교조건은 변경하지 않는다. 기존 Latin 배정1353개의 동일 원문/후보/차이 패킷만 대상으로 하며 보호 ID와 원문SHA를 먼저 차단한다. 원형·이전패킷·다른역할·타세션자료는 변경하지 않는다. 전체 패킷 재구성 일치와 실제 CLI 성공/다른역할 거부를 검사한다. 도구 실행 검증과 독립 의미 판독·캐시 채택을 구분하고 현재 WIP·감사 기록에 연결한다. 최종 정본 연쇄는 실제 전체 처리와 결과를 따른다.
