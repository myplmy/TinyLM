# 숫자 문맥 판독 후 제한된 보완 범위 V1

총괄은 79622의 원문917자/본문319자, 72091의 원문2052자/본문1005자 전량과 60001의 원문/본문 전량을 실제 판독했다. 읽기 근거는 3a681f와 eadc4c의 앞부분이며, 큰 진단 출력의 잘린 구간을 완독 근거로 사용하지 않는다. 원형과 기존 본문은 보존한다. 실제 새 학습 본문은 해당 기존 역할이 작성한다.

## 79622

원형의 경로 정의에서 폐구간·함수 사상이 소실돼 f(0)/f(1)의 정의역 전제를 닫을 수 없다. 값을 그대로 두는 안, 통상적인 [0,1] 사상을 새로 채우는 안, 그 정의와 불명확한 매개화 예시만 분리하고 실제 미분 가능 조건을 복구하는 안 중 마지막을 적용한다. 새로운 식이나 구간을 만들지 않는다.

기존 선택 본문 expanded_train_79622_task011_v1.txt에서 다음만 변경한다.

1. f(0)을 시작점, f(1)을 끝점이라고 하는 한 문장을 원형 HOLD한다. 이어지는 시작점·끝점이 같은 경로를 고리라고 하는 완전한 문장은 보존한다.
2. 실직선의 f(x)=x와 g(x)=x2가 서로 다른 경로라는 한 예시 문장은 정의역·평탄화된 지수 문제를 보충하지 않고 분리한다.
3. 남은 매개화 설명의 X는 원형 서두가 실제 명명한 위상 공간 X임을 명시한다. 새 대상은 넣지 않는다.
4. 속도·속력 설명 앞에 원형의 실제 조건 ‘만약 경로가 미분 가능하다면’을 붙여 그 조건 아래의 설명으로 남긴다. 결손 속도식은 복원하지 않는다.

## 60001

や라는 실제 표제와 ya 로마자, 7/8 인터넷 슬랭 설명의 귀속은 원형에서 확인했다. 없는 가타카나 글리프를 만들지 않는다. 기존 expanded_train_60001_historical_review_20261104_v2.txt의 끝에 독립된 ‘や1’ 한 줄만 분류/추출 잔여로 원형 분리한다. 다른 음절·모라·순위·입력·통화표·모스 부호·슬랭 값은 유지한다.

각 역할은 지정 기존 선택 TXT에서 새 이름 TXT를 만들고 정확 변경/원형 보류 MD와 같은 TASK의 명시 리뷰 수정본을 새로 저장한다. 삭제·개명·끝 바이트 자르기·원형/initial/기존 확정본 덮어쓰기를 하지 않는다. EOF에 LF가 추가되면 사실대로 기록한다. 총괄의 변경 밖 바이트·리뷰·UTF-8/EOF·새 고정본 검산 전에는 채택하지 않는다.
