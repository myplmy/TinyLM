# expanded_train:261707 원형 보류

원문에는 아래 shape 포인터가 있지만, 이어지는 표에 도형 모양/수식은 남아 있지 않다. 모양이나 누락 수식을 만들지 않고, 표제·도형 지시 문장·빈 표 포장을 원형으로 보존한다. 실제 산란 진폭 성분과 s/t/u 채널의 관계는 선택 본문에 남겼다.

```text
파인먼 도형의 모양
이 세 변수에 비례하는 산란 진폭 성분을 나타내는 파인먼 도형은 다음과 같이 특정한 모양을 지닌다. 이런 모양의 파인먼 도형에 해당하는 산란 진폭 성분을 s 채널 · t 채널 · u 채널로 부른다.
{|cellpadding="10"
|
|
|
|-
|align="center"| 채널
|align="center"| 채널
|align="center"| 채널
|}
```

선택 본문은 이 세 변수에 비례하는 산란 진폭 성분을 파인먼 도형으로 나타내며, 해당 성분을 원문에 적힌 s 채널·t 채널·u 채널로 부른다는 관계만 남긴다. 표의 누락 도형/수식, 채널별 모양이나 함수식은 복구하지 않았다.
