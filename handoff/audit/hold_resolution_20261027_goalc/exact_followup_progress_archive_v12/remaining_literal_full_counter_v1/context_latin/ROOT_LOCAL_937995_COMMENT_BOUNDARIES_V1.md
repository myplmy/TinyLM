# 937995의 주석·실행문 경계 중재

총괄은 지정 원문 도입과 `names` 예제까지 실제 읽었다(도구 a3c172).
이미 완결된 값·API·설명과 실제 손상 단위를 구분한다.

- 단독으로 닫힌 대입/호출의 토큰 경계가 유일한 곳에는 개행만 복원할 수 있다. 원문에 없는 코드·값·들여쓰기·블록은 만들지 않는다.
- `#` 뒤에 이어진 Python의 주석 끝은 닫힌 대입 토큰이 보인다는 이유만으로 추정하지 않는다. `names`, births, groupby, graph의 해당 주석/코드 혼합 단위는 그 끝을 입증하지 못하면 원형 보류한다. 명명된 변수·값·설명까지 주변에서 전부 삭제하지 않는다.
- 빈 `ascending=` 값은 현재 라이브러리 상식이나 결과의 크기 순서만으로 채우지 않는다. 이 호출과 그 빠진 값에 직접 의존하는 결과 설명만 보류한다.
- 완결된 독립 튜토리얼 설명, 실제 1880/1000/병원 비유와 버전·이름·값·조건은 보존한다. 없는 그림을 참조한다는 이유만으로 독립적인 설명·원저자 결과 보고를 통째로 삭제하지 않는다.

발행자 Bitbucket 저장소는 확인했으나 지정 notebook의 실제 본문은 웹 도구에서 접근하지 못했다. 검색된 재게시본은 Pandas 버전과 대소문자 등이 달라 이번 원문 주석 경계의 복원 근거로 채택하지 않았다. 이 실패는 원문 내용 오류의 증거가 아니다. 원문 밖 구현을 이식하지 않는다.
