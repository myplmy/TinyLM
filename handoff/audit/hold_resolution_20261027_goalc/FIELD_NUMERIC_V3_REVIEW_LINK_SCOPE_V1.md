# 숫자 진단 V3 판독 근거 연결 범위

기존 판독을 재사용하되 같은 원문 ID만으로 새 본문을 면제하지 않는다. 실제 목표의 CPU 분석·관련 코드/감사 작성 범위 안에서 새 감사 파일만 만든다.

| 안 | 내용 | 영향과 비용 |
|---|---|---|
| 원문 ID만으로 재사용 | 본문·표적 변화와 무관하게 옛 판정을 적용 | 비용은 작지만 새 숫자와 소실 전제를 누락하므로 적용하지 않는다. |
| V3 전부 다시 판독 | 기존과 동일한 87문서·441표적도 모두 재판독 | 검토 비용이 크고 이미 저장한 동일 본문 근거를 중복한다. |
| 정확한 본문과 표적 연결 | 원문 SHA·본문 SHA·숫자 위치/값이 일치한 판독만 연결하고 나머지는 명시 미연결 | 기존 근거를 재사용하면서 변경된 본문의 후속 필요량을 드러낸다. 이 방식을 적용한다. |

새 audit_field_numeric_v3_review_links_v1.py와 결과 JSON만 신설한다. 기존 V1/V3 진단·판독 기록·원형·본문·roster·캐시와 일반 guard는 변경하지 않는다. 전체 진단 기록은 메타데이터로 읽고 원문/본문의 새 payload 판독은 하지 않는다. 원문 ID/SHA 보호 계약을 먼저 확인한다.

코드는 V3 441개 신호와 옛 V1의 425개 국소 증명/문맥 판정, 추가 batch013~016의 정확 표적을 대조한다. 원문·본문·표적이 다른 판정은 자동 전이하지 않는다. 결합 합계 441과 미연결 목록을 별도로 재검산한다. 이는 판독 근거의 연결 확인이며 수학적 참/전체 의미 통과가 아니다.

데이터 스키마와 기존 cache3의 HOLD110173은 바뀌지 않는다. GPU·학습·모델·보호 자료·타 세션 파일·설치/다운로드·push/PR은 범위 밖이다. 계획/결과/기준표/METHODS/COMPASS/실험TSV는 새 실험·모델 수치·학습 풀 채택이 없으므로 이번 감사로 수정할 사항이 없다. 작업 우선순위는 다섯 역할의 신규 판독을 유지하고 총괄의 동일 근거 재확인을 줄이는 데 있다.
