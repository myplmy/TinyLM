# 검증된25 위의26 증분 초안 범위

전량25는 실제 종료와 별도 전 행 검산이 닫혔다.26의 두 새 정책 파일은 전량 미결 census와 실제 원문27쌍/371회귀에서 동결되어 있다. 이 단계에서 기존63정책이나 두 새 정책을 수정하지 않는다.

| 안 | 장점 | 한계·비용 |
| --- | --- | --- |
| 원구간 전량을 다시26으로 수행 | 모든 원문에서 정책을 다시 실행 | 이미 닫힌25의 약58.5분 작업을 재수행 |
| 대표27만 바꾸고 나머지는 확인 생략 | 짧음 | 숨은 다른 정책 영향과 행 누락을 찾지 못함 |
| 검증된25를 상속하고 모든 미결에서26의 무영향을 검산 | 새 실제 원문27과 나머지 전 행을 구분하여 검증 가능 | 상속 근거와 증분 범위를 명시해야 함 |

세 번째 안을 적용한다. `draft_proposals_v26_delta_v1`은 원문 전량26 재실행이라고 부르지 않는다. 기존 터미널·다른 미결 행은 바이트 내용에 해당하는 JSON 구조를 그대로 계승하고 행별 기존 규칙 버전도 보존한다.27개 변경 행만 실제 원문으로25진단을 다시 재현한 뒤26을 적용한다. 모든77,665미결의 고정된25결과 위에서26을 실행하여, 그27개 외에는 규칙 버전 표지만 제외하고 어떠한 판정/이유/수정/본문 영향도 없음을 확인한다. 다른 행에서 원문 접근이나 새 영향이 발생하면 실패한다.

비변경 행의 EOS/UTF-8/원문SHA 근거는 실행·독립검증된25의 계승이다. 메타데이터만 확인한 행을 새 원문 판독으로 계산하지 않는다.27개는 새 OriginalReader에서 실제 토큰 구간·EOS·UTF-8·원문SHA를 다시 확인한다. 저장은 전체297,539고유/460,695위치와462,874,291원inputIDs를 모두 포함한다. 원문·기존캐시·토크나이저·분할과값/분류순서는 바꾸지 않는다.

새 producer66코드와검증된25/전량census/27쌍manifest를SHA로고정한다. 독립 검산은 옛/새 모든고유행과위치행을직접대조하고, 변경27개의 원문을별도로재생성하여26결과와대조한다. 새파일은각20,000,000바이트미만의shard와manifest다. 수정문을캐시에자동채택하지않으며 판독자 제안·총괄선택·cache와학습허가는구분한다.

모델 구조·GPU·학습·품질·속도 실험에 영향0이며 보호TinyDataset/타세션 경로에접근하지않는다. 이번변경은CPU파생초안/자기코드/감사근거에한정되고 공유정본과Git/index는변경하지않는다. 새로운237판독 결과는 별도 회수하며 이27개 자동증명에 섞지 않는다.
