# 출생 최종본문 독립 검토의 순서와 영향

현재 사용자 승인인 전체 HOLD 정제와 목표문서 1·5·6항 안에서 수행한다. 실제 TXT 정제는 기존 다섯 Luna 중 지정 역할만 맡고, 총괄은 도구와 판단을 맡는다. 새 에이전트는 만들지 않는다.

| 안 | 내용 | 장점 | 단점 | 영향도 | 수행비용 |
|---|---|---|---|---|---|
| A | 총괄이 잔여 flag와 출생 전량을 순차 판독 | 추가 배정 준비가 적음 | 이미 중재와 검토가 총괄에 집중됨 | 현재 병목 유지 | 높음: 전문 판독이 직렬 |
| B | 다섯 Luna를 모두 독립 검토로 전환 | 독립 검토 처리량 집중 | field/other의 진행을 모두 멈춤 | 전체 잔여 정제 순서 변경 | 중간: 기존 배정 복귀 관리 |
| C | controls/Latin이 옛 literal 중재를 닫은 뒤 교차 검토, 세 역할은 field 계속 | 의미 검토와 잔여 정제를 병행 | 두 역할의 field 착수가 늦어짐 | 소유 새 폴더와 두 역할의 순서만 변경 | 중간: 기존 생성기·판독기 재사용 |

**채택: C.** 실제 ROOT11 독립 판독 15건에서 기존 본문의 결함 10건을 발견했으므로 검토를 뒤로 미루지 않는다. 1056993의 첫 문단 외 출생연도 잔존, 104207의 한자명 소실, 106989의 출생지 소실처럼 단순 표제 신호만으로 해소되지 않는 문제를 두 번째 편집자가 대조한다. 관측 표본의 오류율을 전체로 외삽하지 않는다.

대상은 기존 출생 원문 2743 중 실제 선택본문이 있는 2707건이다. 나머지 36건은 별도 원문 전문을 총괄이 두 번째로 판독해 HOLD를 확정한 `ROOT_REVIEWED_TERMINAL_HOLD37_V1.json`의 해당 ID·SHA·판독 방법으로 연결한다. 검토 준비를 2707건의 실제 판독 완료로 계산하지 않는다. 기존 ROOT11에 아직 미채택인 같은 유형 보완 7건 중 이 출생 묶음에 속한 6건은 검토가 끝난 정확 새 본문을 후보로 제공하고 그 교체 출처를 명시한다. 다른 묶음의106989 보완은 별도 선택 추적을 유지한다.

| 파일·경로 | 예정 동작 | 권한 근거 | NOT_RUN·제외 |
|---|---|---|---|
| 소유 감사 폴더의 새 생성기/판독 wrapper/검산 근거 | 신설·CPU 실행 | 목표문서1·6항 | 기존 helper/환경파일 변경 없음 |
| 소유 BASE의 birth_root11_independent_v1 및 두 역할의 같은 새 폴더 | 고정 원문/선택문 사본·패킷·TASK 신설 | 목표문서5·6항 | 원형/기존 캐시 덮기·삭제 없음 |
| 두 Luna의 정확 새 TXT/MD | 전문 비교·필요한 최소 수정 | 목표문서5항 | 코드·시험·해시·웹·Git·모델 권한 없음 |
| 현재 세션 WIP와 공개 tmp 조정노트 | 진행·재개 지점 갱신 | 현재 사용자 재개 지시와 목표문서2항 | 타세션 원장/비공개자료 제외 |

| 축 | 영향 | 근거와 처리 |
|---|---|---|
| 코드/중복 | 있음 | 기존 prepare_remaining_birth_readers_v1의 pair/frame/export와 scoped_packet_reader_v1의 역할·해시·경로 검사를 재사용. 새 의미 정제 알고리즘 없음 |
| 데이터 | 있음 | 새 고정 사본과 manifest만 생성. ID와 원문SHA를 보호 계약에 대조한 뒤에만 본문 판독/해시 |
| 검사 | 있음 | 배정 집합의 전량 동일성·기존 편집자와 다른 검토자·원문/선택문SHA·패킷 재구성과 크기·wrapper 실제 출력 및 다른 역할 거부 확인 |
| 정본 문서 | 단계적 | 지금은 WIP/감사 기록. 최종 채택·캐시·전체 재계측 후 필요한 결과/계획/기준표/METHODS/COMPASS를 실제 근거로 연쇄 갱신 |
| 부채/순서 | 있음 | 두 역할의 field 착수를 검토 종료 뒤로 이동. 현재 읽는 작업과 옛 중재는 먼저 마감하고 정확 커서로 복귀 |
| GPU/학습/모델 | 없음 | CPU 파일 전처리만. 추가300M 금지 유지 |
| 보호/동시 소유 | 없음 | 승인된 소유 경로와 제한 전 원문 메타데이터만 사용. 보호 TinyDataset·타세션 자료/프로세스는 접근하지 않음 |
| 학습 비교 조건 | 없음 | 풀/토크나이저/학습/평가 조건을 변경하지 않음. 검토 후보는 아직 캐시 채택이 아님 |
| 증거 수준 | 있음 | 준비/기계 검산/실제 의미 판독/최종 채택을 분리. 같은 입력의 중복 읽기를 독립 검토로 세지 않음 |
| 문서 연쇄 | 있음 | 미완료와 기존 cache3 수치를 유지하며 독립 전량 검토가 끝난 뒤 상태를 전환 |

완결 이름·한자명·직함·출생지·날짜·숫자·단위·조건·부정·불확실성·명명 서지·살아있음 분류를 보호한다. 같은 인물의 충돌 연도만 국소 보류하고 어느 값이 사실인지 고르지 않는다. 출생 논쟁·다른 사람·사망일·활동 연도와 혼동하지 않는다. 새 wrapper는 고정 registry의 출력만 허용하며 OS sandbox 자체로 주장하지 않는다.
