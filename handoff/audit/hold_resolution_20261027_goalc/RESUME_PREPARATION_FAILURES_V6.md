# 후속 수집·판독 실패와 복구 기록 6

이 문서는 이전 V5까지의 실패 이력을 대체하지 않고 추가한다. 아래의 판독 자기보고와 총괄이 실제 확인한 도구 결과를 구분한다.

- WIP 갱신기 update_wip_repeat_full_independent_started_v1.py는 새 설명에 한자 한 글자가 섞여 한국어 원장 작성 게이트에서 exit2로 거절됐다. V2의 세 필드 CAS 갱신은 실제 성공했다. 자동 승인 검토 거절이 아니다.
- 새 스크립트 준비 명령 한 번은 literal 역슬래시 개행 토큰 때문에 PreToolUse 보호 훅이 실행 전에 차단했다. chr(10)을 사용한 재작성은 성공했다. 해당 차단을 셸 실행 실패 또는 auto_review 거절로 바꾸지 않는다.
- snapshot7의 생년 수집은 review_049_v10_v2.md의 비표준 중첩 파일명 때문에 실제 exit1이다. 이력이 담긴 파일을 삭제·개명하거나 비판정 문서로 속이지 않고, 정확 SHA/두 ID/정상 후속 v11을 검사하는 역사 순위 별칭 한 건을 별도 등록했다. 새 수집기4의 snapshot8 세 프로세스는 실제 exit0이다. 별칭 게이트의 5회귀시험도 exit0이다.
- snapshot7 독립 반복 판독의 역사 역할 TASK017–020 20행은 열 제목 `출력 TXT`가 계약과 달라 NO_EXACT_BODY_OUTPUT_PATH로 본문 연결이 거절됐다. 원형을 남기고 정확 `출력` 열을 쓴 새 리뷰를 요청했다. snapshot8에서도 아직 20행이 미연결이었다. 프로세스 exit0을 이들 본문 채택으로 주장하지 않는다.
- Latin의 반복 TASK001–030 완료 보고에는 실제 TASK002 5건 리뷰 미저장과 261707 미결 수정이 남아 있었다. 총괄이 manifest/TASK/저장 snapshot으로 누락을 확인했고 역할이 완료 주장을 정정한 후 review_002.md와 review_009_v2.md 및 실제 본문을 새로 저장했다. 총괄의 누락 확인용 review_002.md 읽기 한 번도 당시 No such file로 exit1이었다.
- 310298의 새 복사본에서 `조카라고도`를 잘못 옮긴 오타, 110981 첫 복사본에서 첫 문단 일부를 누락한 오류는 역할이 diff로 발견했다고 보고했다. 이전 초안은 보존하고 정확 후보 또는 새 수정본을 선택하도록 정정했다. 841706의 대상·축 없는 메달 표를 복원한 초안도 선택에서 제외하고 전체 표 보류로 정정했다. 교정 여부는 선택된 실제 본문으로 다시 검증한다.
- historical 1082701 잘못된 역할 경로의 본문 반환 주장은 자기보고다. 총괄은 해당 original/candidate 두 exact 경로의 현재 lstat 부재만 확인했다. 과거 반환의 진위, 다른 파일 접근 여부는 독립 확인하지 못했다. private 로그를 조사하지 않았고 잘못된 입력 경로의 본문·해시를 열지 않았다. NEW_IO_INCIDENT_CURRENT_METADATA_V1.json이 현재 metadata 증거다.
- 같은 metadata 검사에서 legacy의 잘못된 이전 그룹 sidecar 생성 경로가 현재 688바이트 일반 파일임을 확인했다. hangul의 지정 두 `.tmp` 파일은 현재 각각 0바이트다. 내용은 열지 않았고 삭제·정리하지 않는다. 이전 Latin path_error_note_v2의 과거 바이트 보존 미확인도 그대로 남는다.
- 38865의 packet 부재 보고는 agents 접두사를 잘못 붙인 경로 호출이었다. 실제 TASK056 31행의 공유 경로를 총괄이 확인해 전달했고, 역할이 그 입력의 재판독과 새 리뷰를 보고했다. 다른 접두사 추가/재구성/파일명 충돌 자기보고도 각 역할의 새 note와 snapshot sidecar archive에 보존한다. 정확 명령 목록을 birth 전3501패킷에도 생성·해시 확인했다.
- 새 수치 진단의 8회귀시험은 exit0이다. snapshot6의 실제 본문2087개에서32개 숫자 대응 표시를 냈다. 월일을 생년 숫자에 잘못 정렬하는 보수적 표시와 승인된 사실 복구도 포함될 수 있어 자동 반려/면제하지 않는다. 102091에서는 실제 다른 두 인물의 나이10/11 중10을 지운 사례를 확인해 복구를 요청했다.
- 달력 공개 근거의 긴 PDF 전체 열기는 10896224바이트 도구 제한으로 실패했다. 나가시노 날짜 쌍은 검색 색인 도입만 확인했다. 혼노지 날짜 쌍은 다른 공개 PDF의 실제 파싱 488–493행을 확인했으며, 이를 그레고리력으로 기록하지 않는다. 앞선 171249의 screenshot Timeout도 별도 VIEW_LIMIT 기록대로 유지한다.

공식 검증 캐시 v2는 이 후속 초안·미결·연결 오류를 아직 채택하지 않는다. 전체 goal은 active이며 본문 교정, 독립 판독, 새 캐시 연결과 최종 정본 갱신을 계속한다.
