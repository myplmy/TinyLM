# 지정 문서의 검토 범위와 자율 처리 재확인

이 MD는 현재 사용자의 전체 정제 목표 안에서 총괄이 기존 다섯 역할에게 내린 범위 설명이다. 모델·역할·출력 권한을 바꾸지 않는다. 각 역할은 이 정확 MD를 읽을 수 있고, 쓰기는 기존에 허용한 자기 페이지/ID의 새 TXT·MD만 가능하다.

- 지정 ID의 원문·후보 전체가 검토 범위다. 초기 candidate의 diff가 한 줄뿐이어도 문서의 나머지 명백한 추출 결손을 자기 새 출력에서 정리할 수 있다. 후보 diff는 처리 한도가 아니다.
- 내용 없는 표제, 실제 빈 별칭·병기 괄호, 깨진 포장, 명백한 조사 연결은 실제 채워진 명칭/값을 보존하며 최소 정리한다. 같은 원칙을 건마다 재확인할 필요는 없다.
- 인물의 열린 생년 범위 `~`나 실제 불확실성 표지는 그 자체로 깨진 형식이 아니다. 사망/생존·달력·원문에 없는 사건은 판단해 채우지 않는다.
- 수식·기호가 없다는 이유로 명명된 성질·조건 정의·예시까지 함께 버리지 않는다. 대상과 조건이 글만으로 닫히는 부분은 보존하고 실제 소실된 식과 직접 의존만 HOLD한다.
- 같은 문장의 명시된 유일한 대상을 가리키는 최소 지시어 보완은 가능하되 새 함수·구간·식·수치·단위·주체·사실을 생성하지 않는다. 서로 다른 대상일 가능성이 실제로 있으면 중재를 요청한다.
- 물성명–실제 단위, 채워진 명명 목록은 관계가 유지되면 보존한다. 대응 글자/인물/문항이 사라진 gloss나 표 조각을 새 예시·명단으로 만들지 않는다.
- 동일 항목 안에서 같은 역할·연도·판본의 정확한 추출 반복만 두 번째 것을 분리한다. 역할·섹션·발화·판본이 다른 반복은 의미를 확인해 보존한다.
- 실제 문맥 충돌은 해당 주장/구간을 원형 sidecar에 보존해 질문하고 독립 ID를 계속한다. 채워진 별도 역할의 값이나 공통된 확정 정보까지 함께 없애지 않는다. 충돌 해결을 외부 지식으로 추정하지 않는다.
- 전문을 완료한 입력은 메타데이터 정정·표시 현상 때문에 전체 재판독하지 않는다. 필요한 국소 문맥과 새 본문 전체 diff/EOF를 확인한다. 실제 못 읽은 조각·잘린 출력은 완료로 세지 않는다.
- 한 exec에 한 지정 패킷/조각, BEGIN/END·EOF와 정확 페이지/ID를 지킨다. 실제 다음 TASK 목록과 총괄이 허용한 다음 페이지 입력을 따른다.
- 원문·candidate·initial·기존 확정본의 덮기/삭제/개명, EOF 바이트절단, sed 시작~끝 범위삭제는 금지다. 실패 초안은 미선택 보존하며 새 버전으로 복구한다. LF 추가/경로 오류는 사실대로 기록한다.
- 코드·시험·JSON registry·Git·GPU/모델·외부 취득·보호 경로·다른 역할/세션 자료 접근은 허용되지 않는다. 명백한 형식 자율 처리는 학습/roster/캐시 채택 권한이 아니다.

모든 사례를 중재하면 확인 대기가 반복되고, 모든 의미 판단을 자율 확정하면 오삭제 위험이 있다. 기존처럼 명백한 형식은 자율 처리하고 실제 의미·조건·주체의 미결만 총괄이 중재한다. 이 문서로 완료/일시중지나 전체 의미 통과를 선언하지 않는다.
