# 원형 보류 메모 — 1251896

- 선택문에서 다음 원래 REPL 한 줄의 프롬프트와 결과가 붙어 있었다.

>>> input( 'What is your number: ' ) '32' >>> number = input( 'What is your number: ' ) >>> number '32'

- 이 줄에 이미 있던 세 프롬프트와 두 개의 '32' 출력 사이에 행 경계만 복원했다. 사용자 입력, 추가 출력, 프롬프트 또는 실행 결과를 만들지 않았다.
- Python 2.x의 raw_input() 조건과 두 연습 지시는 선택문 그대로 보존했다.
