# 50559 즉위일 사실정정 근거 재확인

2026-11-01. 현재 root가 정확 원문을 읽어 인물이 엘리자베스1세이며 정보상자 재위 시작이1558-11-07임을 확인했다. 지정 후보는 이전 root 중재로1558-11-17을 사용한다. 기존 중재와 원형·정정 이력을 없애지 않는다.

[Historic Royal Palaces의 공식 궁전사 자료](https://www.hrp.org.uk/hampton-court-palace/history-and-stories/the-elizabethan-era-a-golden-age/) 본문 ‘When was the Elizabethan era?’를 다시 직접 열었다. 해당 본문1125행은 즉위일을1558-11-17, 사망일을1603-03-24로 명시한다.

따라서 이 정확 인물의 재위 시작일11-07→11-17 정정은 내부 정보상자만 임의 우선한 선택이 아니다. 새 사실정정으로 분류하고 이전 값·위치·근거 URL·원문/후보 연결을 보존한다. 다른 날짜·인물·전체 역사 내용의 사실검증으로 확대하지 않는다. 원문에 없는 웹 문장을 학습 본문에 추가하지 않는다.
