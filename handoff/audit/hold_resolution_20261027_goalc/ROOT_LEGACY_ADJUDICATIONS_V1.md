# 이전 HOLD 원문의 총괄 중재 기록

이 문서는 판독자에게 전달한 내용 보존·분리 기준을 남긴다. **개별 새 본문을 이미 승인하거나 실제 캐시에 넣었다는 명세가 아니다.** 지정 입력은 `data_cache/p106b_hold_resolution_v1_20261027_goalc/legacy_span_review_v2/manifest.json`의 원문 ID/위치/SHA이며, 판독·범위·새 산출물은 각 역할의 review가 소유한다. 최종 채택은 정확한 본문 SHA와 독립 대조를 별도로 연결한다.

## 공통 기준

- 이전 HOLD는 불량 확정이 아니다. 보수적인 패턴, 실제 누락, 귀속/경계 문제를 원문에서 구별한다.
- 원문 문장의 외부 사실·의학·법률·정치적 진위를 승인하는 작업이 아니다. 원래의 화자/출처, 인용과 비판, 부정·조건·수치·불확실성을 유지한다.
- 생물학·의학·종교·정치·역사적 증오표현이라는 주제 자체를 형식 오류나 제외 근거로 삼지 않는다. 실제 위험한 절차의 재전사와 독립적인 일반 설명은 구별한다.
- 긴 문서는 실제 전문 판독 전까지 미판독 범위를 명시한다. 길이·시간 부족 때문에 내용 불량/제외로 바꾸지 않는다. 원문과 후보가 같은 바이트인 읽기 별칭은 별도 전량 SHA 대조에만 근거한다.
- 빈 표/수식/필수 조건이 사라진 경우 그 기호나 값을 만들지 않는다. 그 부분을 요구하는 예·결론·지시도 함께 분리하고, 남은 본문이 자체 주어·조건을 갖는지 확인한다.
- 제목/행 머리글에 대응하는 간결한 목록 항목은 유효한 관계일 수 있다. 예를 들어 숫자4 문서의 `베릴륨(Be)의 원자번호.`는 제목4와 대응하므로 단순한 수치 결손으로 삭제하지 않는다.
- 기존 평가/시험 문항과 정답을 복구 명목으로 새 학습 후보에 추가하지 않는다. 실제 전용 평가·시험/플래시카드 블록은 보존 원형에 남기고 후보에서 제외하되, 일반 해설·독립 비문항 본문까지 같은 이유로 버리지 않는다. 보호 평가 풀을 열어 확인한 것은 아니다.

## 적용기와 작성자의 책임 구분

원문을 기준으로 정확히 한 번 존재하는 비중첩 anchor만 적용한다. 실제 값이나 기호를 흐릿하게 일치시켜 자동 수정하지 않는다. 빈 치환 fence를 오독한 적용기 v1 오류와 검토표의 열/수정 버전을 오독한 집계 v1/v2 오류는 총괄 소유이며, 원형·스냅샷과 새 버전으로 보존했다. 작성자의 실제 미존재/중복/중첩 anchor는 별도 실제 검사에서 거부하고 새 버전 보완을 요청했다. 본문 기계 생성, 텍스트 판독, 총괄 의미 승인, 캐시 채택은 서로 다른 단계다.

23003의 레닌 꼬리 혼입 주장도 같은 추가 반증으로 철회했다. 23894/23988의 판독자 주장을 총괄이 전체 diff 전에 실제 발견으로 옮겨 적고 사용자 진행 보고에도 포함한 것은 총괄 오류다. 사용자에게 정정했고 위 표도 그 정정을 명시한다. 새 내용 추가/누락 주장은 실제 정확한 source ID/경로/전후 구절과 전체 diff 검증 전까지 확인된 사실로 보고하지 않는다.
