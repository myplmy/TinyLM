# 저장된 전문 판독의 빈 절 변경 묶음 검증

사용자의 전체 정제와 반복 판독 축소 지시 및 목표의 CPU 코드·시험 권한을 적용한다.
기존 delta profile의 미채택177개에서 각주82, 인구80 등 단독 표제 삭제가 관측됐다.
표제라는 이름만으로 삭제를 승인하지 않는다. 이미 작성자가 전문을 읽고 별도 본문과
리뷰를 저장한 결과 중 문자 보존이 독립적으로 증명되는 것만 추가 판단한다.

| 안 | 내용 | 장점 | 부담·영향 | 비용 |
|---|---|---|---|---|
| A |177개 원형과 최종을 총괄이 새로 전량 완독|개별 문맥 확인|작성자 전문 근거와 동일 부분 반복|높음|
| B |실제로 빈 표제와 다음 부록 경계를 독립 검증하고 모든 나머지 문자·값을 대조|기존 판독 재사용|경계가 증명되지 않으면 계속 보류|중간|
| C |새 표제 규칙을 아직 판독하지 않은 전체 잔여에 즉시 적용|적용 범위가 큼|새 유형의 오삭제 검토가 필요|높음|

B를 사용한다. 인구·기후·갤러리·사진은 다음 비어 있지 않은 줄이 명시 부록 표제일 때만
빈 절로 인정한다. 기존 독립 각주·외부링크 등 빈 EOF 표제 집합은 재사용한다.
사망·평가 같은 다른 내용 표제와 표제 뒤 실제 본문은 이 확장으로 지우지 않는다.
코드, 인용 블록, 목록, 들여쓴 전사, 보통 문장 안의 표제 단어도 대상이 아니다.
실제 편집은 하지 않는다. 두 본문에서 증명된 빈 줄 표제만 가려 비교하고 모든 나머지
채워진 문자·숫자·단위·부정·조건·문체·순서·기존 metadata 값을 보존해야 한다.
기존 ROOT의 명시 반례, 남은 결손, 불완전 문장·내용 표제·구분자 검사는 그대로 유지한다.

| 경로 | 동작 | 권한 근거 | 제외 |
|---|---|---|---|
| 이 감사 폴더의 순수 판정기·회귀·readiness adapter와 작은 근거 | 신설 | 목표 CPU 구현·시험 및 현재 효율화 | 원형·작성본 편집 없음 |
| 기존 profile·리뷰·본문 | 읽기 | 지정 HOLD 정제 승인 | 제한 원형과 비교본은 metadata만 |
| 별도 ROOT 선택·최종 matching roster/cache | 후속 신설 | 목표 파생본 생성·검증 | 이 검사만으로 자동 반영하지 않음 |

코드 축은 기존 v3 readiness와 독립 literal/metadata/구분자 검사를 재사용하며 새 경계 판정만
추가한다. 데이터 스키마와 원형은 바꾸지 않고 body 사본은 만들지 않는다. 회귀는 채워진
절·인용·코드·미지 표제·숫자 삭제 거절을 포함한다. 정본 수치는 실제 채택·캐시 검증 후
관련 결과·METHODS·COMPASS에 묶음 반영한다. 낮은 처리량의 새 규칙을 계속 늘리지 않도록
이미 저장된 저자 결과에 한정하고 전체 대기열 전파는 별도 근거 전까지 하지 않는다.
GPU·모델·학습은 실행하지 않으며 보호 데이터·로그·동시 작업자 소유권을 유지한다.
기존 풀·토크나이저·EOS·split은 바꾸지 않는다. 이 검사는 새 전문 판독이나 모델 품질 증거가 아니다.
