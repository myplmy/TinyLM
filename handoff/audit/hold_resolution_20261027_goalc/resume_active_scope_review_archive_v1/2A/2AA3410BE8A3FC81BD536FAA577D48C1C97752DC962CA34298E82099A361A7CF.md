# ID 17218 원형 보류 v2

후보 본문은 지정 candidate 그대로 유지한다. 아래 원문 조각은 값이나 연결되는 표제가 비어 있어 후보 본문에 귀속할 수 없으므로, 구조와 실제 문구를 원형 보류한다. 외부 지식으로 누락된 표현이나 언어를 채우지 않는다.

## 사용 국가

```text
사용 국가
  (국어이자, 공용어이다.)
  (일부 사용자가 있다.)
  (일부 사용자가 있다.)
  (일부 사용자가 있다.)
  (일부 사용자가 있다.)
  (불가리아계 이민자가 일부 사용.)
  (불가리아계 이민자가 일부 사용.)
  (일부 사용자가 있다.)
```

국가명이 빠진 각 사용 범주를 별도 항목으로 보존했다. 국가를 추정하지 않는다.

## 빠진 표현과 직접 연결된 설명 및 표제

```text
불가리아어 배우기
  [회화체, 남성]
  [회화체, 여성]

중성에 해당하는 표현은 이며 일부 경우를 제외하고는 매우 드물게 쓰인다.

[격식을 차린 표현, 남성]  (격식을 차린 표현으로 복수 동사에 사용하지만 단수에도 사용하며 화자들은 이 두 문법의 형태를 인정한다. 게다가 격식을 차린 1인칭 단수의 "당신"을 뜻하는 "Вие"는 항상 복수형 "당신"들과 구분하기 위해 В를 항상 대문자로 쓴다.)

[격식을 차린 표현, 여성]
[복수형]
[회화체]
) [격식을 차린 표현, 복수형]

[회화체]
[격식을 차린 표현, 복수형]

[격식을 차린 표현]
[회화체]
```

후보 본문은 별도로 다음 문장을 보존한다. 이를 빈 `[격식을 차린 표현, 남성]` 표제의 값으로 연결하지 않는다.

```text
격식을 차린 표현의 "Вие"에서 "В"는 항상 대문자로 쓴다.
```

## 빠진 어휘를 참조하는 차용 표현 설명

```text
다음은 다른 언어에서 온 표현이다. 하지만 격식을 차린 표현에서도 자주 사용하지는 않는다.

; 에서 차용.
; 에서 차용.
; 에서 차용. 양이나 성에서 존칭을 나타낸다.
; 에서 차용
```
