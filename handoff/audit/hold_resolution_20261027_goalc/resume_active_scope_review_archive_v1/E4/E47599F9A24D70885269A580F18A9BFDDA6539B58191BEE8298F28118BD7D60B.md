# expanded_train:8925 원형 설명 보류

## 보류 범위

`TryCreate` 세 행의 원문 설명은 `Creates a new using...` 형태로 생성 대상 명사가 빠져 있다. 후보의 설명란 공란을 유지한다. 빠진 대상을 추측해 설명을 보완하거나, 다른 메서드의 설명을 옮기지 않는다.

## 원문 보존

> |TryCreate(String, UriKind, Uri)||Creates a new using the specified String instance and a UriKind.|
>
> |TryCreate(Uri, String, Uri)||Creates a new using the specified base and relative String instances.|
>
> |TryCreate(Uri, Uri, Uri)||Creates a new using the specified base and relative instances.|

## 보존 경계

세 `TryCreate` 메서드명, 오버로드, 인수·서명은 실제 식별되는 API 정보이므로 후보에 그대로 남긴다. 위 불완전 설명 원형은 이 sidecar에 보존한다. 본문에 새 설명을 생성하거나 인접 메서드 설명을 복원하지 않는다. `Object.GetHashCode()`와 `Object.ToString()`은 실제 메서드 표기이므로 후보의 설명 안에서 보존한다.
