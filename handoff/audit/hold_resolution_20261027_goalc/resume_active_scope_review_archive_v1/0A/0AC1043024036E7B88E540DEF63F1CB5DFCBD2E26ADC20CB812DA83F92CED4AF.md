## 복구하지 않은 잘못된 등가 비교

원문에서 제시한 다음 등가 설명은 본문에 되살리지 않았다. `Meta` / `MyMeta` 토큰을 고쳐 쓰거나 코드 블록을 새로 만들지 않는다.

> That code produces a class equivalent to
>
> class MyClass(object, metaclass=Meta): pass
>
> on Python 3 or
>
> class MyClass(object): __metaclass__ = MyMeta
>
> on Python 2.
