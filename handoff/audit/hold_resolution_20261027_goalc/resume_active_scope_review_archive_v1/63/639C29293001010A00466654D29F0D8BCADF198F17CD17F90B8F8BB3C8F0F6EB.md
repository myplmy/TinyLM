# 허용 경로 밖 호출 기록

이 메모는 작업 중 잘못 입력한 경로 호출을 기록한다. 각 호출에서 파일 내용은 반환되지 않았으며 `No such file or directory` 오류만 관찰했다.

1. 호출: `nl -ba /home/uranus/tinyLM/data_cache/p106b_hold_resolution_v1_20261027_goalc/agents/context_latin/runtime_guard_counter_v1/../doesnotmatter`
   오류: `nl: /home/uranus/tinyLM/data_cache/p106b_hold_resolution_v1_20261027_goalc/agents/context_latin/runtime_guard_counter_v1/../doesnotmatter: No such file or directory`
   이유: 다음 지정 입력으로 넘어가려다 실제 TASK 경로를 복사하지 않고 임시 경로를 잘못 입력했다.

2. 호출: `nl -ba /home/uranus/tinyLM/data_cache/p106b_hold_resolution_v1_20261027_goalc/agents/context_latin/runtime_guard_counter_v1/../../x`
   오류: `nl: /home/uranus/tinyLM/data_cache/p106b_hold_resolution_v1_20261027_goalc/agents/context_latin/runtime_guard_counter_v1/../../x: No such file or directory`
   이유: 앞선 경로 오입력 뒤에도 정확 경로를 복사하지 않고 임의 경로를 다시 입력했다.

3. 호출: `nl -ba /home/uranus/tinyLM/data_cache/p106b_hold_resolution_v1_20261027_goalc/agents/context_latin/runtime_guard_counter_v1/reading_packets_v1/expanded_train_1318235_0004.txt`
   오류: `nl: /home/uranus/tinyLM/data_cache/p106b_hold_resolution_v1_20261027_goalc/agents/context_latin/runtime_guard_counter_v1/reading_packets_v1/expanded_train_1318235_0004.txt: No such file or directory`
   이유: 지정된 패킷 경로가 `.../runtime_guard_counter_v1/reading_packets_v1/...`임을 다시 확인하지 않고 역할 출력 폴더 하위로 잘못 조합했다.

이후에는 TASK에 적힌 절대 경로를 그대로 복사해 읽고, 이 기록 외에 잘못된 경로를 추가 시험하지 않는다.
