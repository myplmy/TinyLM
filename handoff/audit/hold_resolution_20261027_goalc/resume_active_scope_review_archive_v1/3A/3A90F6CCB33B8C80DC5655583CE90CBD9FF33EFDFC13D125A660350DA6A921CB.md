## Appendix의 손상된 식

슬라이드 61의 `Minimum detectable effect, for sample size N` 뒤 식:

`MDE=( t 1 κ + t α/2 ) σ 2 /P(1 P)N`

슬라이드 61의 `Minimum sample size, for hypothesized effect size β` 뒤 식:

`N= ( t 1 κ + t α/2 ) 2 σ 2 / β 2 P(1 P)`

슬라이드 62의 `Minimum detectable effect, for sample size N` 뒤 식:

`MDE= ( t 1 κ + t α/2 )/(c d) σ 2 /P(1 P)N`

슬라이드 62의 `Minimum sample size, for hypothesized effect size β` 뒤 식:

`N= ( t 1 κ + t α/2 ) 2 σ 2 / (c d) 2 β 2 P(1 P)`

슬라이드 63의 `Minimum detectable effect, for J groups with n members` 뒤 식:

`MDE=( t 1 κ + t α/2 ) σ 2 /JP(1 P) (ρ+ 1 ρ/n )`

슬라이드 63의 `Minimum number of groups, for hypothesized effect size β` 뒤 식:

`J= ( t 1 κ + t α/2 ) 2 σ 2 / β 2 P(1 P) (ρ+ 1 ρ/n )`

식의 괄호·분수·루트·첨자·마이너스 관계는 원문에서 복구하지 않았다. 슬라이드 61–63의 완결 조건, 변수 설명, 계산 대상 이름은 본문에 원문 순서대로 보존했다. 슬라이드 31·33·42의 원래 응답 수치도 후보를 보완한 본문에 원문 순서대로 복구했으며, 백분율과 선택지 사이에 새 대응을 만들지 않았다.
