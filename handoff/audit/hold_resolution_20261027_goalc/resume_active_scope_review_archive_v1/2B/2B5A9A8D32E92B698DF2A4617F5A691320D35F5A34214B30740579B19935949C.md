# expanded_train:8925 미상 설명 보존

세 API 서명은 본문에 유지한다. 생성 대상이 빠진 설명 전체는 이웃 API에서 URI를 가져오지 않고 원형으로 보류한다.

`Creates a new using the specified String instance and a UriKind.`

`Creates a new using the specified base and relative String instances.`

`Creates a new using the specified base and relative instances.`

`|IsWellFormedUriString||Indicates whether the string is well-formed by attempting to construct a with the string and ensures that the string does not require further escaping.|`

이 설명에서 생성 대상을 포함한 `by attempting to construct a with the string` 조각은 원형 보존한다. 이와 별개로 완결 조건 `and ensures that the string does not require further escaping.`는 본문에 복구했다.

클래스/인스턴스 대상이 빠진 원문 문장:

`The constructors for allow a Silverlight application to create a instance for many schemes as described in the Scheme property.`

같은 문서에 `Uri(String)`, `Uri(String, UriKind)`, `Uri(Uri, String)`, `Uri(Uri, Uri)`라는 실제 생성자와 `Scheme` 속성이 명시되어 있다. 이에 따라 v2 본문은 빠진 클래스명/인스턴스 타입을 대입하지 않고 다음에 해당하는 채워진 관계만 복구했다.

`The constructors allow a Silverlight application to create instances for many schemes as described in the Scheme property.`

`Uri`를 원문의 빈 대상명에 대입하지 않았고 다른 클래스·인스턴스 타입도 새로 붙이지 않았다. 세 `TryCreate`의 생성 대상 누락은 이 판정에 포함되지 않으며 원형 HOLD를 유지한다.

두 코드 예시 뒤 원문은 빈 출력 내용을 예고한다. 출력 문자열은 만들지 않고, 실제 예시와 연결된 compacted / not compacted 동작만 본문에서 각각 명시한다. 원문 예고의 원형은 다음과 같다.

`When this code is executed, it returns the following output with the escaped sequence compacted.`

`When this code is executed, it returns the following output with the escaped sequence not compacted.`

원문 설명의 출력 예고 앞부분과 별개로, 본문에는 HTTP에서 compacted, FTP에서 not compacted라는 원문 동작 대비만 보존한다. 코드 실행이나 결과 생성은 하지 않았다.
