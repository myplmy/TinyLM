# ROOT49 기존 정제본 묶음 검증과 추가 보류

불변 secondary MD에서 추출한 732개 판정 행과 기존 primary 전문/EOF 기록을 재사용했다. 이미 선택한 ID는 제외하고 전량 source/body 문자·수치·코드·Unicode·순서·스타일·메모·본문 미완·잔여 표제·명시 ROOT 보류 검사를 유지했다. 새 문헌 검증이나 최초 전문 판독 실적을 주장하지 않는다.

전량 검사는 5.928초에 231고유449위치를 후보로 분리했다. 독립적으로 확인된 빈 표제가 최종 본문에 남은 184413은 2위치 모두 제외했다. 이어서 230개 최종 본문의 말미를 전량 검사하고, 역할과 보존 근거의 일곱 조합마다 가장 짧은 본문을 정해 원문과 최종 본문을 ROOT가 실제 EOF까지 비교했다. 이는 대표 사례 검토이며 ROOT가 모든 원문을 다시 전문 판독했다는 뜻이 아니다.

- 97376: 다마치역 동음 목록의 실제 역명과 위치를 유지한다. 빈 괄호와 비어 있는 같이 보기 표제만 제거했다.
- 488152: hasNext() 자체는 명시된 API지만 마지막 `O(n) space, O(1) has next and next:`가 뒤에 없는 구현 설명을 예고한다. API 판독의 승인을 전체 본문 완결성 승인으로 바꿀 수 없어 이번 묶음에서 제외한다. 입력 원형은 보존하고 별도 수리한다.
- 249359: 도호쿠정 연혁·인접 자치체·교통·실제 홈페이지·분류는 모두 있고 내용 없는 인구 표제만 빠졌다.
- 21464: 몽주의 실제 생몰일·정의·분류는 유지되고 빈 각주 표제와 빈 별칭 쉼표만 빠졌다.
- 231515: 하가정의 실제 역사·날짜·노선·정류장·홈페이지·분류를 유지하고 내용 없는 인구 표제만 제거했다.
- 120796: 브린의 원문에 있는 생몰 범위 기호, 학력, 날짜가 붙은 서술과 분류를 보존한다. 빈 각주·외부 링크 표제만 제외했다. 원문의 시점 의존 직책·순자산 서술을 현재 사실로 검증했다고 주장하지 않는다.
- 141157: 성협의 OB/T/R 설명·수치·조건·실제 이동성군 목록·참고 링크·분류를 보존했다. `다음과 같다` 뒤 실제 여덟 항목이 있어 미완 목록이 아니다. 빈 각주 표제만 빠졌다.

따라서 이번 채택 대상은 229고유445위치다. 근거가 있는 함수/API 구문과 명사형 목록의 source-specific 판단만 재사용하며 일반 scanner를 완화하지 않는다. primary 판독 기록, 불변 secondary MD, 실제 본문 해시와 원형 연결을 유지한다. 신규 본문 사본과 최초 전문 판독 credit은 0이다.

ROOT48의 13,415개 선택을 그대로 보존하고 이번 229개만 추가한다. 실제 독립검산 성공 후 B안 신규는 495고유945위치, 기대 HOLD99,987, 공식 cache18 HOLD100,932, 캐시 반영 대기945, 처리 후 미채택7,757, 미처리92,192, 기존 검토 HOLD38로 계산한다. 실제 새 캐시 생성·소비 검증과 전체 정제 A–E는 미완이다.
