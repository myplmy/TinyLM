# ROOT51 총괄 단독 묶음 채택

현재 사용자 지시로 다섯 보조 역할을 중단했다. 이 묶음의 추가 판독·수정·검증은 총괄이 직접 수행했다. 기존 primary 전문/EOF와 변경 밖 동일성을 재사용하며 새 첫 전문 판독 credit은 0이다.

기존 26규칙의 대량 처리와 최근 경로는 같지 않았다. 과거는 검증한 변화 유형의 전량/영향 범위 적용과 불변 결과 재사용이 중심이었다. 최근은 개별 재대조·기록 형식 정리·검증 경로 버전 생성의 비중이 높았고, 삭제 전용 순서 검사를 수작업 괄호 복구에도 적용했다. 이 절차 비용을 난도 증가만으로 설명하지 않는다.

이번에는 ROOT50에서 아직 선택하지 않은 기존 본문 3,926고유7,461위치를 단일 pass로 검사했다. 217.772854초에 94고유188위치가 준비 후보가 됐다. 3,280개는 source value/order 보존 검사의 별도 문맥 검토 대상, 288개는 본문 미완/구조 문제, 264개는 이미 기록된 구체적 보류에 해당했다. 이 구분은 서로 겹치지 않는다. 원문 전체 문자와 다른 부분 정제본을 곧바로 결함 확정으로 읽지 않는다. 그 경우에는 보존 본문과 보류 원문을 연결하는 적절한 별도 계약이 필요하다.

전체 대기 목록에는 profile locator가 없는 118고유212위치도 있다. 판본 충돌29/42위치, 전문 판독 근거 미확립44/88위치, 명시/제한 보류45/82위치로 설명되어 있으며 삭제·누락 처리하지 않는다. 따라서 당시 대기7,673위치는 실제 검사7,461과 별도212로 맞는다. 보호된 원형을 열어 이 수를 줄이지 않는다.

원문 값·수치·코드·Unicode·스타일·메타데이터 검사와 본문 미완·잔여 표제 검사를 유지했다. 명사형 분류 오탐은 기존 독립 category verifier의 동일한 값/경계/미완문 조건을 재사용해 해소했다.
