# 본문 진단 V3의 범위

기존 FIELD_BODY_DIAGNOSTICS_REUSE_IMPACT_V1.md의 보존·계보·내용·비용·운영 경계를 그대로 적용한다. 새 고정본은 2720리뷰이며 본문 없는 개별 전체 HOLD6건을 제외한2714본문이다.

| 안 | 효과와 한계 |
|---|---|
| 바이트로 고정된 기존 진단 재사용 | 새/변경 본문에 같은 수치·코드·Unicode·스타일·순서·메모·UTF-8/EOF 검사를 적용한다. 구현 의미는 바꾸지 않는다. |
| 이전2494본문 receipt만 재사용 | 새로 고정된 본문과 보완본의 현재 상태는 확인하지 못한다. |
| 별도 검출기 재작성 | 같은 기능을 중복 구현하고 비교 기준이 달라진다. |

첫 안을 적용한다. 래퍼는 대상 버전·예상 건수·출력 이름만 바꾸며 기존 V1 생산자 SHA를 강제한다. 원형·초안·기존 진단·캐시는 보존하고, 검사 통과를 전량 사실검증이나 자동 채택으로 승격하지 않는다. CPU 검사이며 모델/GPU 실행이 아니다.
