# expanded_train:779305 보류 연도

외부 사실을 이용해 어느 연도가 맞는지 선택하지 않는다. 후보에서 연도 없는 월일을 보존하며, 원문에서 충돌한 출생·사망 연도는 원형대로 따로 기록한다. 독립적인 수상 연도와 경력은 본문에 유지한다.

| 필드 | 원문 위치와 원형 문구 | 상태 |
|---|---|---|
| 출생연도 | 소개: `1897년 11월 9일` | `1907년 출생`과 충돌; 연도 보류 |
| 출생연도 | 분류: `1907년 출생` | `1897년 11월 9일`과 충돌; 연도 보류 |
| 사망연도 | 소개: `1978년 6월 7일` | `1997년 사망`과 충돌; 두 연도 보류 |
| 사망연도 | 분류: `1997년 사망` | `1978년 6월 7일`과 충돌; 두 연도 보류 |

소개에 있던 실제 월일 `11월 9일`, `6월 7일`과 양쪽의 사망 상태는 수정 본문에 남겼다. `1978년 : 로모노소프 황금 메달`은 독립 수상 기록이므로 그대로 보존했다.
