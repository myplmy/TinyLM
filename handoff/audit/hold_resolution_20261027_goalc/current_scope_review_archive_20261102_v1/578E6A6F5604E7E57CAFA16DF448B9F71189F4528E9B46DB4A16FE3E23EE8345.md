## 경로 복원 코드와 불완전 배열 선언 원형

```text
 let dist be a  array of minimum distances initialized to  (infinity)
 let next be a  array of vertex indices initialized to null

 procedure FloydWarshallWithPathReconstruction ()
    for each edge (u,v)
       dist[u][v] ← w(u,v)  // 변 (u,v)의 가중치
       next[u][v] ← v
    for k from 1 to |V| ''// 일반적인 플로이드-워셜의 수행
       for i from 1 to |V|
          for j from 1 to |V|
             if dist[i][j] > dist[i][k] + dist[k][j] then
                dist[i][j] ← dist[i][k] + dist[k][j]
                next[i][j] ← next[i][k]

 procedure Path(u, v)
    if next[u][v] = null then
        return []
    path = [u]
    while u ≠ v
        u ← next[u][v]
        path.append(u)
    return path
```

두 선언에는 배열 크기 수식이 빠져 있다. `dist` 선언에는 `initialized to (infinity)`가, `next` 선언에는 `initialized to null`이 실제로 남아 있으므로 초기값이 없다고 보지 않는다. 크기나 형식 수식을 추정하거나 다른 구간에서 가져오지 않는다. 두 선언이 빠진 상태에서 이 루틴을 완결된 경로 복원 알고리즘처럼 본문에 복구하지 않는다.
