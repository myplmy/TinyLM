# 1403490 강사 크레딧의 출판사 근거

2026-11-03 KST 총괄의 읽기 전용 웹 대조다. 이 문서는 보조 역할에 웹 접근 권한을 주지 않는다. 원형 TXT를 덮지 않고 새 본문을 작성하는 정확한 철자 경계만 설명한다.

지정 원문은 7.1 마지막 인덕터 고장 진단 강의다. 시작 크레딧은 `Tim Feiegenbaum`, 말미 크레딧은 `Tim Fiegenbaum`이며 두 곳 모두 North Seattle Community College이다. 실제 본문의 시작과 고장 진단 문맥은 출판사의 [Inductors (Part 3) - Troubleshooting](https://www.allaboutcircuits.com/video-lectures/inductors-troubleshooting/)과 대응한다. 같은 출판 페이지 자체에도 두 철자가 각각 서두/말미에 존재한다. 앞서 참조한 Part 1은 같은 강의 계열이지만 이 원문의 정확한 강의 제목으로 사용하지 않는다.

출판사의 2009-01-21 공지 [Video Lectures](https://forum.allaboutcircuits.com/ubs/video-lectures.228/)는 제작자 이름을 `Tim Fiegenbaum`으로 명시하고 같은 학교를 표시한다. 이 별도 출판사 공지와 실제 강의 말미 크레딧의 일치가 서두 철자 정정의 근거다. 모든 기술 설명을 사실 검증하거나 새 강사 약력을 추가한 것은 아니다.

총괄 판정: 강사 제작자 크레딧 하나를 `Tim Fiegenbaum`과 실제 학교명으로 보존한다. 같은 강의에 중복된 말미 크레딧 하나와 서두의 다른 철자는 원형 sidecar에 보존한다. 강의 기술 본문과 실제 독립 댓글은 유지한다. Samtec 파트너 홍보와 작품 경계 없는 Robert Keim/Jake Hertz/Jeff Child/Jake Hertz 목록은 강의 저자에 귀속시키지 않고 별도 원형 보류한다. 그 밖의 전기적 사실·단위·저항 조건을 이번 이름 정정과 함께 바꾸지 않는다.

새 TXT와 리뷰에는 이 정확 문서와 지정 원문의 전체 판독을 근거로 기록한다. 최종 캐시 채택은 총괄의 정확 본문 핀/전체 차이/독립 검토 이후 별도다.
