# 개별 원문의 최신 처리 근거 연결

이 문서는 새 검토표에 명시한 내용의 실제 연결을 정정한다. 현재 검증된 중간 캐시의 본문이나 잔여 수를 변경하지 않으며, 다음 승인 명세에 연결할 두 건의 판정이다.

| ID | root 판정 | 실제 근거와 연결 |
|---|---|---|
| expanded_train:608143 | EXCLUDE | 원문SHA `0047EAD934D123677CE2A5E298A34EE21F1CECCA50173E23D53D41D06656342C`. 여러 출처의 게임/학업 성과 주장·1인칭 의견·끊긴 인용/서지가 섞였고 NAPLAN 표 참조와 표본/모델 귀속을 분리할 근거가 없다. 과거 root 중재 후의 EXCLUDE 행은 snapshot_v2에 실제 보존돼 있다. 이후 작성자가 review_v2.md를 다른 교정 두 행으로 바꿔 옛 ESCALATE가 다시 선택됐지만 내용 재판정을 뜻하지 않는다. 원파일 전체의 옛 바이트를 복구했다고 주장하지 않고, 보존된 행·당시SHA·sourceSHA 및 이 현재 root 판정을 연결한다. 과학 주장의 외부 진위 판정이나 평가과제라는 이유의 제외가 아니다. 원형은 보존한다. |
| expanded_train:1242413 | EDIT | 최신 본문은 원작성자 v3보다 뒤에 실제 보완된 context_controls/literal_guard_recheck_v1/expanded_train_1242413_recheck_v2.txt다. root가 실제 diff와 원문을 읽고 cohere 함수·Hanning/50%/optional 인수, 실제 cxyN 호출, 완결된 Matlab 예제와 조건을 보존하게 했다. 값 없는 길이 자리와 미완 결과·깨진 예고만 분리했고 새 식/값/결과를 생성하지 않았다. 정확 원문/본문SHA와 실제 코드 조각10개는 LITERAL_GUARD_APPROVALS_V2.json이 소유한다. 코드 실행과 외부 사실 검증은 하지 않았다. |
