# 새로 식별한 비재작성 원문의 가드 확장

expanded_train:28876은 지정 판독 중 무기 제작 세부가 확인되어 새 학습 본문으로 정리하지 않는다. 실제 세부와 원형 문장을 감사 MD에 재인용하지 않는다. 원본/initial은 그대로 두고 metadata와 최소 비채택 이유만 연결한다.

| 안 | 영향 |
|---|---|
| V1만 계속 사용 | 새 식별 ID/원형 SHA를 다음 처리에서 놓칠 수 있다. |
| V1을 덮어쓰기 | 기존 입력 핀과 동결 진단/캐시 증거가 깨진다. |
| 새 V2로 누적 차단 | V1 원형을 보존하고 새 ID·원형/파생 후보 SHA를 추가한다. 이 방식을 적용한다. |

쓰기 대상은 이 MD와 GUARDED_SOURCE_METADATA_CONTRACT_V2.json 및 새 최소 판정 기록뿐이다. 현재 전체 정제 목표의 원형 보존/비채택·CPU 분석 권한 안에서 수행한다. protected 데이터나 원형 payload를 새로 열거나 해시하지 않는다. 새 사례는 이미 허용 판독 중 식별됐지만 이후 재판독·제작 설명 재작성·값/형식 복원은 하지 않는다.

V2의 trusted_metadata/parent_decision은 기존 schema를 유지하고 같은 원문에 대한 새 metadata HOLD를 추가한다. metadata entry 수는 역사 별칭을 포함하므로 고유 원문 수나 corpus 위치 수와 더하지 않는다. 새 원형 ID와 SHA 외에도 같은 내용에서 나온 후보 SHA를 차단해 별칭 경로를 보호한다.

신규 원문/본문/packet 열기·해시·디코드 전에는 V2 ID와 SHA 검사를 먼저 적용한다. 둘 다 허용돼야 읽을 수 있다. V1에 고정된 옛 진단/reader는 새 ID를 포함하지 않는 동결 부분집합에 한해서만 역사적 재현에 사용한다. V1 파일·옛 선택/캐시·일반 보존 guard를 조용히 변경하지 않는다.

회귀는 V1 ID/SHA가 V2에 전부 포함됨, 새 ID/두 SHA가 차단됨, metadata만 사용함, 구조/정본 핀/합계를 확인한다. 새로운 캐시/학습 실행이나 전체 목표 완료를 뜻하지 않는다. GPU/모델·설치·다운로드·타 세션·push/PR 변경은 없다.
