# 설립·폐지 등 명시된 연혁 메타데이터 경계

현재 전체 정제/CPU 규칙·시험 승인 안에서 source-linked delta를 만든다. 원형·기존규칙을
덮지 않으며 새 metadata_v3/policy_v29/test_policy_v29 세 scripts와 작은 감사 근거만 신설한다.
GPU/모델/학습·다운로드·TinyDataset·타세션·push/PR은 제외한다.

실제 ROOT35 잔여를21.257초에 분류해 기존 remaining_reasons가 반복 하나인19472고유,
메타데이터 경계 하나인10830고유를 찾았다. 이는 채택 수가 아니다. 이 profile의 첫 수는
candidate_reasons와의 합집합이 아니라 remaining_reasons 기준이므로 새 판정은 반드시
현재 전체 policy와 모든 보존 가드를 다시 통과해야 한다. 별도 metadata 합집합 표본에서
경계10830 중135를 간격80으로 조사했고134의 꼬리에 기존 연도/분류 어휘 밖의 값이 있었다.
이를 무시하지 않고 실제 다른 명시 연혁 경계를 좁게 증명한다.

총괄은 원형62713/87620을 전문 판독했다. 87620은 완결된 장안파 조선공산당 서술·유효
서지/같이보기가 있고, 마지막 빈 각주 뒤 `조선공산주의단체 / 1945년 설립 / 1945년 폐지`가
있다. 기존 birth/death/year 한정 규칙은 이 연혁쌍을 인식하지 못했다. 62713의 관련 항목과
서지·역사 수치는 보존 대상이다. 6393은 길이를 확인했을 뿐 전문 판독으로 세지 않는다.
325의 빠진 수상자 목록,443의 실제 출연목록/제작 분류,4430/7242의 수식 결손은 별도 반례다.

| 안 | 내용 | 장점 | 위험·영향 | 비용 |
|---|---|---|---|---|
| A | 경계10830 모두 개별 전문 작성 | 문서별 중재 | 이미 관측된 수기 병목 지속 | 높음 |
| B | 명명된 도입+서로 다른 시작/종결 연혁쌍+별도 꼬리 문단만 새 증명 | 날짜·분류를 그대로 보존하며 빈 말미 표제만 정리 | 나머지 결손은 계속 PENDING | 중간 |
| C | 분류 어휘 목록만 대폭 확장 | 짧은 구현 | 어휘만으로 실제 단락 경계를 증명할 수 없음 | 중간 |

선택 B. `설립/설치`와 `폐지/해체`가 각각 실제 연도와 명시되어야 하고 시작 연도가
종결보다 뒤인 복잡/충돌 사례는 자동 해제하지 않는다. 날짜 사실을 정정하지 않는다.
새 규칙은 마지막 literal metadata 값들을 삭제·재정렬하지 않고 인접한 실제 빈 footer만
정리한다. 참고자료나 같이보기의 채워진 값과 표제는 보존한다. 실제 content quarantine,
개별 HOLD/NEEDS_ROOT, 코드·Unicode·문체·수치·순서 또는 다른 formal hole은 해제하지 않는다.

코드 영향: 기존 metadata suffix의 block/label/quote 검증과 policy28 전체 결과를 재사용하고
APPENDIX_CATEGORY_BOUNDARY 하나만 새 증명에 따라 닫는다. 기존26~28 함수/핀은 불변이다.
데이터 영향: 규칙 후보 census는 작은 ID/SHA/증명만 저장한다. 비해당 원문/후보 사본0,
채택 전 본문 payload0. 독립 populated-character 대조와 기존 실제 문맥 리뷰의 불일치를
닫은 후에만 변경분을 채택한다. 마지막 matching roster/cache/consumer까지 진행한다.
검증 영향: 기존394회귀와 새 양성/음성·빈축·서지·인용·코드·개별HOLD 반례를 실행한다.
정본 영향: 새 규칙을 인간 전문 판독으로 세지 않으며 다음 의미 있는 stage/WIP/로컬 저장
묶음에 반영한다. 규칙 후보 또는 전송 시험을 공식 캐시 감소·전체 내용 복구로 보고하지 않는다.
