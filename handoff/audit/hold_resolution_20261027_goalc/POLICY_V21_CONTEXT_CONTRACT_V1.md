# 정상 자료 구조와 반복 리터럴의 문맥 증명 v21

첨부 목표의 CPU 정제·관련 코드/검사·새 파생자료 권한에서 새 버전만 구현한다. 실행 중 v20의46파일·원문·기존 캐시는 불변이다. 소규모 검사는 규칙 개발용이며 최종 전량/캐시/의미 검토를 대신하지 않는다.

| 안 | 내용 | 장점 | 한계 | 영향도 | 비용 |
|---|---|---|---|---|---|
| A | 모든 구조 신호를 개별 TXT로만 판독 | 개별 근거 상세 | 정상 코드/표/크레딧도 같은 확인 반복 | 저자 자료만 | 높음 |
| B | 완전한 원문 구조와 모든 반복 위치의 실제 귀속을 증명한 경우만 보존 | 값/순서/코드를 바꾸지 않고 정상 신호 분리 | 불완전 표/동일 문맥 중복은 미결 유지 | 새 helper/정책/재생/시험 | 중간 |
| C | 코드·표·앨범 같은 단어가 있으면 문서 전체 허용 | 회수량 큼 | 다른 곳의 빈 값·중복/UI까지 함께 허용 | 광범위 | 낮음 |

선택 B. inline code를 가린 뒤 동일해 보이지만 실제 완전한 원문 행은 서로 다른 DISPLAY 출력은 원문 값 자체가 다르다. 크레딧은 명시 수록곡 절의 채워진 트랙별 값으로 귀속하고, 캐스트의 반복 역할은 이름:배우 레코드가 서로 다를 때만 유지한다. 같은 트랙/같은 인물 레코드 안의 두 벌은 그 근거로 허용하지 않는다. 실제 다른 코드 표현식에 붙은 주석도 해당 모든 위치의 직접 구문을 확인한다.

완전히 닫힌 코드 예제나 헤더/행/열 값이 모두 있는 표는 자연어 문장이 없다는 이유만으로 불완전 본문이라 하지 않는다. 표의 누락 머리글/셀·다른 열 수·rowspan/colspan·깨진 닫기·밖의 잔여 템플릿은 이 증명에서 제외한다. 유효 표나 의미 있는 HTML 강조를 보존하는 것은 실제 값에 연결된 구조를 유지하는 것이며 위키/HTML 토큰 전체의 정상 선언이 아니다. 다른 UI·빈 필드·수식·날짜 충돌 경고는 그대로 적용한다.

[MediaWiki의 표 문법](https://www.mediawiki.org/wiki/Help:Tables)은 시작/끝, 헤더와 데이터 셀, 속성과 콘텐츠의 구분을 명시한다. [공식 형식 문서](https://www.mediawiki.org/wiki/Help:Formatting)는 일부 HTML 표기를 문서 형식으로 사용함을 설명한다. 이를 좁은 구조 검사의 근거로 삼고, 임의 템플릿 렌더링 의미나 표의 사실 정확성을 추정하지 않는다. 원문 값을 만들거나 복잡한 배열을 새로 결합하지 않는다.

| 축/경로 | 영향과 검증 |
|---|---|
| 새 structure_v1/policy_v21/refinement_v9/revision_v21 및 시험 | 기존 v20/보존 helper 재사용; 새 구문/지역 레코드 증명만, 과거 생산파일 불변 |
| 데이터 | SHA/원구간/토크나이저/분할 불변, 실제 코드·값·스타일 보존, 새 초안만 |
| 검사 | 이전 의미/재생 회귀, 전체 반복 위치·불완전 표·오른쪽 이름만 다른 가짜 문맥·실제 missing 값 반례, 목적 원문쌍 독립 대조 |
| 정본 | 실제 전량 및 cache/전량 재계측 후 연쇄 갱신; 구조 통과를 사실/품질로 승격하지 않음 |
| 부채 | 실제 정상 형식 예외를 버전/원문/본문/근거에 고정; 전역 guard 비활성 없음 |
| GPU/소유 | CPU만, 보호 TinyDataset/다른 세션 전용자료·프로세스·Git 변경 없음 |
| 비교/증거 | 원래 풀과462874291입력ID 합계 유지, 설계/목적/전량초안/실제캐시/학습 분리 |

새 종결은 기존 실제 독립 본문과 정확히 비교하거나 새 전문 반례로 회수한 후에만 전량 실행한다. zero-HOLD 계약과 설명되지 않은 미처리 금지를 유지하고 PENDING을 일괄 EXCLUDE하지 않는다.
