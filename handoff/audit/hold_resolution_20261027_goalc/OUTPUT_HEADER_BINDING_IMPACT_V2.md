# 페이지 회수기의 명시 출력 열 보완

[기존 영향도](OUTPUT_HEADER_BINDING_IMPACT_V1.md)의 범위 안에서, 실제 페이지 리뷰의 `출력 (TXT basename)`이라는 정확 표기를 추가한다. 원저자 리뷰55행을 현재 v5 페이지 래퍼가 전체 행 fallback으로 잘못 해석했다. 실제 본문 소실이 아니다.

| 안 | 내용 | 장점 | 단점 | 영향·비용 |
|---|---|---|---|---|
| A | 55개 유효 리뷰행 재작성 | 기존 파서 유지 | 저자 중복 작업·이력 증가 | 리뷰 변경, 중간 |
| B | 정확 별칭과 페이지 opt-in 래퍼 | 리뷰 바이트 보존·같은 엄격한 출력 바인딩 | 두 명시 별칭의 충돌 검산 필요 | 새 회수본만, 낮음 |
| C | 표제 부분문자열/행 전체에서 파일 추정 | 다양한 표제 수용 | 근거 열의 옛 출력 오선택 | 의미 오연결 위험, 높음 |

B를 적용한다. 기존 별칭 모듈을 재사용하고 정확 한 표기만 추가한다. 출력 열이 둘 이상이면 계속 거부하며, 미등록 표제나 근거 속 파일명은 추정하지 않는다.

| 경로 | 동작 | 권한 근거·제외 |
|---|---|---|
| 자기 audit의 alias_v2/page_collector_v2/test_v2 | 신설 | objective의 관련 CPU 구현·시험 허가. 기존 v1/v5/v6 및 환경 파일 불변 |
| 자기 field page002 snapshot v3 | 신설 | 새 파생 산출물 허가. 과거 snapshot/원문/저자 TXT·MD/캐시3 불변 |
| 자기 WIP | 정상 CAS 갱신 | 현재 재개 지시. 다른 원장·09 수정 없음 |

코드는 v1 alias의 명시 열 중복 거부와 frozen v1 페이지 래퍼의 페이지 수·source 수·manifest SHA·역할·ID·판정 바인딩을 그대로 재사용한다. 실제 저자55행/기존25행, 두 별칭 충돌, 기존 정상·미등록·근거 파일명 오승격 거부를 검사한다. 데이터 스키마나 본문 선택은 변하지 않는다. 정본 영향은 WIP/audit의 진행 근거뿐이며 전체 goal의 최종 정본 연쇄는 미완이다. 별도 생산 파서나 캐시 재구축을 추가하지 않는다.

프로젝트 도메인 축은 .agents/project.json에서 재확인했다. GPU·모델·학습은 실행하지 않고, 자기 파생 경로만 접근한다. 토크나이저·학습 풀·평가 비교 조건은 변하지 않는다. 이 검증은 파일 연결 증거이며 의미 보존·모델 품질·전량 완료의 증거가 아니다.
