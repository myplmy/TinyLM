# 완료본 근거를 재사용하는 335240 국소 보정

목표의 총괄 판단·G 본문 편집 분담을 유지한다. 완료된 v1과 원형은 불변이며,
총괄은 v1을 새 미완 v2로 바이트 그대로 한 번 복사한다. 의미 편집은 G가 한다.

| 안 | 검토 범위 | 비용과 근거 |
|---|---|---|
| A | 원형·완료본 전체 diff를 다시 처음부터 읽음 | 이미 닫힌 동일 부분까지 반복함 |
| B | 완료본 SHA와 기존 전문·diff EOF 근거를 재사용하고 모든 새 hunk와 새 전문 EOF를 확인 | 바뀌지 않은 부분의 근거를 유지하며 반복을 줄임 |
| C | 새 hunk만 보고 전문·이전 근거를 확인하지 않음 | 문맥과 계보가 충분하지 않음 |

B를 적용한다. 기존 G v1 최종 SHA는
`749B8E66B2A826852EEE7F8BD656A458E305CF6829D09EBB4EBD7B805C0E8748`이다.
G의 기존 source pair12/12, v1 본문7/7, 원형 대비 diff16/16 EOF 기록과
총괄의 v1 전체24,010바이트 판독을 재사용한다. 새 최초 전문 판독으로 계수하지 않는다.

허용하는 새 의미 변경은 두 곳뿐이다. 어원 괄호 안에 끼어든 Old Persian 일반 정의만
제거하고 Sistan 예시를 남긴다. Elamite 문단의 `Istakhri map 2jpg|thumb|right|`
이미지 구문만 제거하고 유효한 지도 설명은 별도 문단으로 보존한다. 그 다음 문장의
`It was written`은 같은 문맥의 `Elamite was written`으로 선행사를 명시한다.
다른 지명·어원·값·인용·서술 순서는 그대로 둔다.

고정 literal 편집기의 새 v2 scope만 편집 가능하다. 완료 review_016_v3.md가 생기면
다시 읽기 전용이다. G는 새 hunk 전량과 최종 본문 전문·EOF를 확인한 뒤 새 review와
sidecar를 남기고, 원형 대비 diff를 새로 완독했다고 주장하지 않는다. 총괄은 v1→v2
모든 변경과 기존 증거 연결을 확인한 뒤 별도 채택을 판단한다. 자동 채택은 없다.
