# 78121 교육 문제의 빈칸과 실제 결손 구분

총괄이 지정 original 67행 전체를 실제 판독했다. 아래 행 번호는 그 original의 행 번호다. 독립 문제에 정답이 없다는 사실이나 학생에게 조사·유도를 요구한다는 사실만으로 결손을 단정하지 않는다.

- 1–14행의 독립 문제와 R/ρ/l/A 정의, 20–29행의 실제 조건이 있는 도선 문제는 보존한다. 학생이 식을 유도하거나 자료를 조사하도록 한 과제 자체를 제거하지 않는다.
- 15–18행은 사라진 표를 직접 지시하는 문제·정렬·그 표의 출처 설명이므로 원형 sidecar에 분리한다. 19행의 실제 독립 금속 비교 설명은 사라진 수치를 새로 채우지 않고 보존한다.
- 30–35행은 주어진 회로 그림이 사라져 문제 조건과 답의 대상이 성립하지 않는 동일 문제 블록이므로 원형을 분리한다. 36–41행도 없는 회로와 per length의 대상·구성이 필요한 전압 비교 문제 블록이므로 원형을 분리한다. 숫자나 선로 수, 계산 결과를 추측하지 않는다.
- 42행의 손실 조건 설명과 44–46행의 실제 변수 정의는 보존 가능하다. 43행의 사라진 식 도입과 46행의 연산자가 없는 괄호 Rwire1 Rwire2만 분리한다. R의 실제 총 선로 저항·ohms 정의는 유지하며 더하기 기호를 만들지 않는다.
- 47행의 사라진 식을 대수 조작하라는 의존 지시만 분리하고, 실제 200kW·48A·최소 효율90% 조건의 최대 저항 계산 문제와 48–49행의 실제 답·주의는 보존한다. 총괄이나 역할이 답을 재계산한 것으로 기록하지 않는다.
- 50–52행은 없는 회로에 직접 의존한 문제와 답 블록이므로 분리한다. 53–55행의 일반 부하 및 strain gauge 설명은 보존한다. 56행의 없는 그림 지시는 분리한다.
- 57–59행의 두 행에 걸친 `( )`는 완결된 답이 함께 있는 의도된 빈칸 문제다. 그대로 보존한다. 60–61행의 conductance 단위 질문과 교사 안내도 독립 학습 지시다. 실제 단위명을 쓰지 않았다는 이유로 제거하거나 이름을 새로 답해 넣지 않는다.
- 62–67행의 실제 라이선스 문구·byline·파트너 표기는 원래 순서대로 보존한다. 서로 다른 파트너 표기가 있어 단순 중복으로 귀속을 지우지 않는다.

새 전체 본문·원형 sidecar·새 리뷰를 자기 역할 폴더에만 작성한다. 이 지침은 원문 전기·공학 사실의 외부 검증이나 앱 실행이 아니다. 실제 보존 내용과 제거 범위는 전체 diff와 EOF로 다시 대조한다.
