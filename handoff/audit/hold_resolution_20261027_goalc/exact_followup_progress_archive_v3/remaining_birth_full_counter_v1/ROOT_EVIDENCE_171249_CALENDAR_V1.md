# 171249 사망일 병기는 모순이 아닌 달력 대응

총괄은 지정 원문 전체를 다시 확인했다. 사타케 요시쿠니의 도입 사망일은 1725년 3월 29일이고 생애 말미는 교호 10년 2월 15일이다. 숫자 월일만 달라 보인다는 이유로 두 표현을 지우지 않는다.

JCDP가 공개한 《弘前藩庁日記（御国）》의 서기/구력 날짜 대조표는 PDF 146쪽(0부터 세면145)에 1725년3월29일과 享保10년2월15일을 같은 행에 병기한다. 이 행과 열 표제를 확인했으며 새 달력 변환 계산을 수행하지 않았다.
- https://jcdp.jp/wp-content/uploads/2020/08/2ed3543cba5c5b37bc7fe917711255ef.pdf#page=146

동일 인물의 일본어 위키 고정판106250221도 사망 필드에 같은 두 날짜를 함께 쓴다. 이는 지정 텍스트와 날짜 병기의 대응을 확인하는 보조 근거이며, 전기 전체의 사실을 독립 입증하는 자료로 확대하지 않는다.
- https://ja.wikipedia.org/w/index.php?title=佐竹義都&oldid=106250221

따라서 두 날짜·연호와 원문의61세를 전부 보존한다. 새 월일을 만들거나 본문 날짜를 삭제하지 않는다. 다른 구조 손상이 없으면 지정 candidate를 ACCEPT할 수 있다. 이전 모순 의심/NEEDS_ROOT는 정정 리뷰와 이 근거에 연결해 보존한다. 원문 출처 메타데이터는 UNKNOWN이며 이 검색으로 소급 확정하지 않는다.
