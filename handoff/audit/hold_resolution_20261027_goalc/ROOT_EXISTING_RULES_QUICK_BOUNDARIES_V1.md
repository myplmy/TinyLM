# 기존 의미 보존 기준의 공통 적용

목적은 이미 승인한 단순 유형을 담당자가 자율 마감하고, 이름·조건·수치가 있는 정보를 빈 형식과 함께 버리지 않는 것이다. 새 사실·식·역할·실행 결과를 만들거나 허용 경로를 확대하지 않는다. 기존 다섯 역할은 이 안내 파일 하나를 추가로 읽을 수 있다.

- **채워진 분류·관련 명칭**: 말미에 독립 명칭으로 있어도 실제 범주/개념/작품명이면 원형 순서로 보존한다. 빈 각주·같이 보기·분류 표제만 정리한다. 새 각주·관련항목 역할로 재분류하지 않는다. 광고/소셜 CTA/내용 없는 이동 UI와 유효 명칭을 함께 버리지 않는다.
- **명명된 목록·목차**: 해당 문서/강좌/책의 실제 주제 이름과 순서는 정보다. 값 없는 행과 일반 이동 버튼은 분리하되 실제 목차 주제·API명·유효 목록값은 보존한다. 새 계층이나 누락 제목을 추정하지 않는다.
- **목록/식 일부 결손**: 실제로 채워진 독립 항목·수량과 단위·명시된 관계·조건은 보존한다. 개수 진술 자체가 완결돼 있으면 빠진 설명이 있다는 이유만으로 개수를 지우지 않는다. 빠진 부분을 포함한 완전한 목록이라고 새로 선언하지 않는다. 정의 없는 기호나 사라진 식/그림에만 의존한 관찰은 sidecar로 보류한다. 이름만 남았다고 조건이 닫힌 것은 아니다.
- **코드와 기호**: 원문의 인용 코드 조각과 질문은 완전한 실행 프로그램으로 주장하지 않는다. 명백한 전처리/서명 어휘 경계의 개행은 최소 복원하되 값·인자·블록·정답을 만들지 않는다. 함수명 뒤 ()와 실제 연산자·괄호는 빈 병기가 아니다. 이름 없는 언어/별칭 슬롯과 고립 구두점만 좁게 정리한다.
- **서지·인용**: 실제 제목/저자/날짜/단위와 주체를 보존한다. 대상 없는 권수·빠진 발화 내용·그 내용에 직접 의존한 인과는 보류하며 앞 항목에 추정 연결하지 않는다. 실제 인물 관계나 별도의 완결 사건까지 함께 버리지 않는다.
- **저장·보고**: 현재 TASK의 정확 ID·candidate 행으로 작업본을 만든다. 직전 ID 경로를 재사용하지 않으며 잘못된 초안은 삭제/덮기하지 않고 미선택 이력으로 보존한다. 매 TASK의 실제 리뷰/새본문·sidecar 저장과 변경 본문 전문/diff/EOF는 유지한다. 일반 완료 통보는 새 3TASK마다 한 번, 질문·사고·명시 보완 완료·페이지 끝은 즉시 보고한다.

위 기준에 명백히 해당하면 매번 승인 대기를 만들지 말고 자율 마감한다. 실제 대상·조건·주체가 불분명한 중요한 경우만 정확 원문과 쟁점으로 총괄에 올리고 독립 다음 입력은 계속한다. 코드·시험·계산·모델·GPU·Git·작업규약 수정은 맡기지 않았으며, 이 안내도 그 권한을 주지 않는다.
