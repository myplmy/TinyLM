# ROOT11 최종본문의 추가 보완: 151

총괄이 원문·기존 선택문과 전체diff를 실제 읽고 이 좁은 문제를 확인했다. 실제 새 TXT/MD는 지정 Luna가 작성한다.
지정 역할=historical_review. 입력은 이 새 자기 폴더의 두 readonly original/selected_root11 사본과 초기working이다. 쓰기는 이 폴더의 아직 없는 새 TXT/MD만 허용한다.
기존 원문/선택문/캐시/다른 역할/보호자료/코드/시험/통계/해시/웹/Git/모델/GPU는 금지다.

이미 원문과 저장본문 전문을 총괄이 대조했다. 표가 빠진 뒤 내용 없이 성질 표제 앞에 남은 독립 중복 소제목 르장드르 다항식만 분리한다. 수직관계의 첫 따라서 접속어는 직접 앞의 식이 보류됐으므로 접속어만 정리하고 실제 직교성, 구간[-1,1], 스튀름리우빌 조건과 노름의 불확실성 한정은 보존한다. 수식이나 누락된 적분경로를 복구하지 않는다.

원문/기존선택 전문과 새본문 전문/전체diff를 실제 EOF까지 대조하고 review_001.md에 ID/REVISE_TEXT/실제판독범위/정확TXT basename/원형 sidecar와 사유를5열로 기록한다.
자기 폴더의 파일명은 rg --files로 볼 수 있고 PROGRESS_LOG를 append-only로 쓸 수 있다. 같은 본문을 다른 경로로 반복 읽을 필요는 없다.
현재 판독 TASK를 읽는 중이면 그TASK부터 마감한뒤 이보완을 처리하고 원래 다음 TASK로 복귀한다. 중간저장/한TASK종료로 전체goal을 멈추지 않는다.
