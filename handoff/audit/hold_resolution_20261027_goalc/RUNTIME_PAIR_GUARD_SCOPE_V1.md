# 실제 캐시 가드와 원문별 예외 검토

4,381개 정확 선택을 동결 캐시 엔진의 실제 코드·유니코드 가드로 검사했다. 4,333개 본문, 48개 명시 제외이며 코드 가드 경고9, 자동 서식 보존 경고14, 본문 검수 메모0이다. 이 수치는 캐시 채택·의미 보존 완료가 아니다. 새 후속 독립26에서 추가 수정이 나오면 해당 정확 SHA는 새로 검산한다.

| 안 | 동작 | 장점 | 한계 |
|---|---|---|---|
| A | 동결 엔진을 그대로 적용 | 기존 실행 경로 유지 | 이미 원문별 복구한 프로그램·비프로그램 구분도 다시 HOLD 가능 |
| B | 최신 초안의 가드를 전역 대체 | 일부 형식 오탐 해소 | 신규 전역 판정으로 이전 baseline·다른 자료까지 영향을 줌 |
| C | 동결 엔진 유지, 경고23개를 전량 원문 판독한 뒤 정확 원문SHA/본문SHA/근거 핀에 한정한 예외 | 기존 baseline·다른 쌍의 가드는 그대로 검증 | 각 쌍의 실제 프로그램·유니코드·범례 의미 검토 필요 |

선택 C. 아직 예외를 승인하지 않았다. 세 Luna 역할은 지정23개의 전체 원문/본문/diff와 복사된 판단 근거만 읽고 자신의 새 txt/md에만 판독을 남긴다. 다른 두 역할은 앞 후속26의 독립 판독을 마친다. 최대5역할을 넘기지 않는다. 코드는 총괄이 구현·시험한다. 의미가 바뀐 프로그램이나 값/범례가 사라진 사례는 예외로 통과시키지 않고 본문을 고치거나 원형 보류한다. 이미 채택된 baseline1,145,290개 본문에는 예외를 적용하지 않는다.

코드 실행·모델·GPU·학습·추가300M·설치·다운로드·보호TinyDataset·타세션 전용 경로·원형 덮기/삭제·push/PR은 허용하지 않는다. 실제 새 캐시·독립 소비자 검증과 남은 전량 복구는 계속 남아 있다.
