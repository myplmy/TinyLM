# 1300527: 출판 원문과 일치한 소실 수식 기호 복구

총괄은 지정 원문 전문을 읽고 NED/IPAC가 제공하는 Hauser·Dwek 논문의 동일 3.6절 HTML과 저자 PDF를 실제 대조했다. 두 매체는 같은 논문의 계보이므로 독립 사실 출처 두 개로 세지 않는다. 일반 물리 지식으로 수식을 추측한 것이 아니다.

- https://ned.ipac.caltech.edu/level5/March03/Dwek2/Dwek3_6.html
- https://ned.ipac.caltech.edu/level5/March03/Dwek2/paper.pdf

HTML의 동일한 절·저자별 연구 순서와 문장, PDF 0기준13–15쪽의3.6절에서 아래 기호를 확인했다. PDF 텍스트585/598/611/620–621/674/680–687행이 대응한다. PDF는 일부 산문이 출판 HTML과 달라 산문 전체를 교체하는 근거로 쓰지 않는다. 이 근거의 변경은 원형에서 깨진 해당 기호 자리로만 한정한다.

| 원형의 정확 문맥 | 복구 허용 표기 | 출판 근거 |
|---|---|---|
| 첫 자기상관함수 `C()` | `C(θ)` | HTML theta 이미지의 대체표기와 PDF585행 |
| rms 값의 `( I)` | `δ(ν I_ν)` | HTML delta/nu/하첨자와 PDF598행 |
| Kashlinsky1996a의 `C(0)1/2 = ( I)` | `C(0)^(1/2) = δ(ν I_ν)` | HTML의 지수·delta·nu 및 PDF611행 |
| 같은 연구의 한계·Burigana 문단의 `C(0)1/2` | 각 위치의 `C(0)^(1/2)` | PDF620/674행 및 동일 HTML 위치 |
| 그 한계를10배한 문장의 `upper limits on I` | 그 문맥에서만 `upper limits on ν I_ν` | HTML의 두 nu 기호와 PDF621행 |
| cirrus의 `P k-3` | `P ∝ k^(-3)` | HTML propto/상첨자 및 PDF680–682행 |
| 뒤 관측 거듭제곱 `k-3` 및 `arcmin-1` | `k^(-3)`와 `arcmin^(-1)` | HTML 상첨자와 PDF684–687행 |

표기용 `^`/괄호/하첨자 밑줄은 실제 상·하첨자를 평문에서 읽기 위한 것이다. 원형 각 자리는 sidecar에 보존하고 새 전체 TXT는 Luna가 작성한다. 모든 I/C 문자열을 일괄 치환하지 않는다. 기존 `C(0)`/`csc(|b|)`/`PS` 등 채워진 나머지 기호는 바꾸지 않는다. 숫자·단위·인용자·연도·가정·상한/검출/이방성 여부·모델 의존 한정을 모두 보존한다.

Table1/2의 실제 표 데이터를 새로 삽입하지 않는다. 이 절의 기존 표 번호 참조는 명명된 논문 내 교차참조이며, 대응 수치/방법이 산문에 채워진 절까지 무차별 삭제하지 않는다. 실제 없는 표 자체를 새로 만들거나 현재 연구의 타당성·전량 사실 검증으로 확대하지 않는다. 원문의 깨진 저널/저작권 머리는 원형 sidecar로 분리할 수 있고 완결된3.6절 제목은 보존한다. 복구 기호와 무관한 산문·다른 절·새 평가 자료는 추가하지 않는다.

원문 출처 메타데이터는 UNKNOWN을 유지한다. 이는 일치한 출판 문맥의 기호 복구 근거이며 캐시 계보 라벨을 새로 복원했다는 뜻이 아니다. 기존 NEEDS_ROOT/초안은 보존하고 TASK018 전체5행 새리뷰·새TXT·원형 sidecar에 정정 이력을 연결한다. 새 본문은 총괄의 정확쌍/기호/전체diff 검사를 받기 전 캐시로 채택하지 않는다.
