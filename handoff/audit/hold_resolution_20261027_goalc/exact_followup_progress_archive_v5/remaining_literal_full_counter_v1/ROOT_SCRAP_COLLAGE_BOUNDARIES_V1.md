# 혼합 스크랩 두 원문의 총괄 문맥 판정

총괄은 아래 정확 원문을 실제 전문으로 읽었다. 기존 파일을 덮거나 지우지 않는다. 이 기록은 채택 학습 본문이 아니라 검수 근거다.

## expanded_train:213255

원문 SHA-256: 77C8BC0A59517D75E348C77B184F8CDDE13ECA97AD1FB458A43AA7746DE701BE.

R 표준오차 제목 아래 문장 중간에 malware·Rosetta·One Ring·airport·luggage·SEO 표제와 서로 다른 통계/R 스크립트 조각이 끼어 있다. 문장 끝/주체/대상이 넓게 손실됐으며 어떤 다른 발행처/저자의 글이 섞였는지도 복구되지 않는다. source(file = "sample_script.txt") 호출과 원 저자의 따옴표 주석은 문법상 구분할 수 있지만, 해당 조각 하나만 뽑아 새 튜토리얼로 만들 충분한 원래 본문 경계는 확인하지 못했다.

전체 원형을 개별 판독 HOLD로 남기는 판정을 승인한다. 이는 모든 짧은 코드 조각을 무효로 보는 규칙이 아니다. 이 특정 원문의 복합 추출 손상과 본문 경계 미복구가 이유이며, 오류 신호만 보고 미판독을 HOLD로 개명한 것이 아니다. 누락된 통계식/설명이나 원래 글을 상식으로 재작성하지 않는다.

## expanded_train:229534

원문 SHA-256: 565298AC0C420C2B0A2F69720D6E72C72F2BBC5220E0176CBAC9E3B0A257D1DD.

stdio/fwrite, ImageMagick 채널, shell 함수, Node/PHP/.NET/POSIX 설명이 문장 중간에서 반복 전환된다. sgtraslochi.com으로 API 식별자가 치환된 흔적, 수/인수/연산자/헤더/errno가 사라진 구절, 직접 대상 없는 file/this/flag 설명이 있다. 몇 개 완결된 일반 문장은 존재하지만 어느 하나의 원래 본문과 그 경계를 복구해 이어 읽을 수 있는 상태는 아니다.

전체 원형을 개별 판독 HOLD로 남기는 판정을 승인한다. 보존되는 원형을 근거로 출처 복원 가능성은 열어 둔다. 일관된 main article로 단정하거나 무관한 완결 문장들을 합쳐 새로운 설명을 만들지 않는다. API 이름·fopen 선언·오류 코드를 원문 밖에서 채우지 않는다.

두 행은 historical_review의 실제 해당 TASK와 다섯 원래 행을 보존한 새 리뷰에 각각 기록한다. 출력은 학습 TXT가 아니라 정확 원형 sidecar와 HOLD 이유이며, 수집기의 기존 NEEDS_ROOT 형식을 사용해 총괄이 개별 판독 비채택으로 연결하게 한다. 자체 코드/통계/채택은 하지 않는다. 다른 배정은 계속한다.
