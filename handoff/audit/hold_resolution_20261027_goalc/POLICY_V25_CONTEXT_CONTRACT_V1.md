# v25 전열 결손과 선택 공란 구분

v24의987쌍 검산은 실제0(P861/E99/K27), 기존 회귀356/재생47도 실제0이었다. 그러나897170의 실제 언어 비교 표는 부양어 여섯 값이 전부 빠져 있다. 축이 명시됐다는 사실만으로 선택적 공란이라고 판정한 자동 종결을 반려한다. ISBN/비고와 실제 언어 형태가 없는 필수 비교축은 다르다. 전량v24도 실행하지 않는다.

대안은 공란을 가진 표를 전부 보류하기, 실제 한 내용 열 전체에 값이 없는 표만 자동 종결하지 않고 독립 복구하기, 기존 넓은 희소표 종결을 유지하기다. 두 번째를 선택한다. 실제 채워진 축/행/셀은 원형 보존하며 이름·행 대응이 없는 미지의 값을 생성하지 않는다. ISBN/10/13, 비고·참고사항·특기사항·주석·remarks·notes의 정확 선택 metadata 열은 기존 판독 범위로 남긴다. 다른 내용축 전체 공란은 값0/해당없음으로 해석하지 않고 PENDING으로 유지한다.

897170은 실제 채워진 어근-PMP 여섯 쌍만 원래 두 축으로 보존하고, 전열 결손인 부양어와 그 직접 예고는 별도 exact hold로 분리한다. 이는 개별 검토 본문이며 자동으로 모든 표를 축소하는 규칙이 아니다. 467565는 모형 조건과 기호/표현도 빠져 있어 응용표를 직접 의존 문맥과 함께 분리하고 독립 코니폴드 설명을 보존한다.

새 규칙은 보호된 코드/인용을 구분하고 명시 희소표 검증을 먼저 통과한 실제 원문 구조만 검사한다. v24의 명명 정의 자동 범위 제한과 영어/한국어 결손 재검사, 기존 코드/Unicode/스타일/순서/부분격리 경계는 유지한다. 기존61 생산파일과 모든 실패/반례는 보존하고 새63 파일로 시험·987쌍 목적·독립 대조 후 검증v21을 기준으로 전량 처리한다. 캐시·goal 완료와 학습 재개 승인은 별개다.
