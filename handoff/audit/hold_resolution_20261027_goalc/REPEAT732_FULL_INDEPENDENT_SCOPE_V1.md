# 반복732건 전량의 역할 교차 의미 검토

732건의 수정본은 원문 연결과 가드를 확인했지만 동일 판독자의 결정만으로 의미 보존이 끝났다고 하지 않는다. 비교 범위는 원문 전체와 실제 선택본문 전체이며 자동가드 통과를 의미 판정으로 쓰지 않는다.

| 방안 | 장점 | 남는 한계 |
|---|---|---|
| A: 순서삭제 표시74건만 재검토 | 비용이 가장 작다 | 표시가 없는 오삭제·주체 소실·중복 오판을 놓칠 수 있다 |
| B: 언어/유형별 표본 재검토 | 여러 위험을 일부 확인한다 | 이번732건의 미검토 문서가 남는다 |
| C: 다른 역할이732건 전량 재검토 | 자기 수정본 자기 승인과 미표시 문맥 오류를 함께 줄인다 | 추가 전문 판독 비용이 든다 |

C를 적용한다. 기존 승인된 Luna 다섯 역할만 사용하며 각 ID의 기존 편집자와 다음 검토자를 반드시 다르게 배정한다. 별도 START/TASK/원문/실제선택본문/전차이의 연속 패킷과 정확 새 출력 폴더를 생성한 뒤 위임한다. 새 에이전트나 모델·GPU 실행은 없다.

현재 출생 묶음의 이미 읽는 TASK를 마감한 뒤 이 전량 검토를 우선하고 출생 미결 TASK로 돌아간다. 목표나 WIP를 완료·일시중지로 바꾸지 않는다. 독립검토에서도 실제 수정이 필요하면 지정 역할의 새 전체TXT/원형MD로 남기고 총괄이 기존 선택과 대조한다. 기존 편집자의 판단·출처·숫자·조건을 다르게 만들지 않으며 새 추정으로 결손을 채우지 않는다.

영향 경계: 원문·기존캐시·보호7본문·TinyDataset·타세션 자료는 변경하지 않는다. 입력은 승인된732건의동결뷰이며 새 산출물은 각20MB미만이다. 실행 학습풀·토크나이저·모델 조건에는 영향이 없다. 이 단계는 데이터 의미 검토이며 모델 품질·학습 재개 증거로 승격하지 않는다. 정본연쇄는 최종전량조인·캐시검증 이후 현재근거에맞게갱신한다.
