# 명명된 지역 목록과 소실 구간의 분리

START/TASK와 중재V1/V2를 따른다. 자기 배정의 원문만 읽으며 이 지침을 다른 역할 자료·웹·코드 접근 권한으로 넓히지 않는다. 이전 전체 셀 보류가 명명된 정보를 함께 빼면 새 TXT/교정 리뷰로 복구한다. 원형과 이전 모든 버전은 보존한다.

실제 이름이 여럿 나란히 있는 셀은 문장 동사가 없어도 유효한 목록이다. 원문의 지역명·반복·순서와 섬/도시/방향을 보존한다. 구간 시작 좌표/경계가 사라진 단독 대시·'부터' 조각만 원형 보류할 수 있다. 누락 경계를 보고 지역 이름 전체를 버리거나 새 경계/국가/주체를 만들지 않는다. 반복된 같은 주 이름도 서로 다른 실제 통과 구간이면 유지한다.

거리 수치가 바로 앞 실제 지역명과 같은 항목에 붙어 있으면 그 이름/거리 결합을 보존한다. 여러 이름이 있다는 사실만으로 모든 거리를 미상으로 돌리지 않는다. 빈 행에 거리만 있고 실제 대상이 없는 경우에 한해 그 좁은 원형을 보류한다. 지명과 수치를 새로 조합하거나 인접 행에서 대상을 가져오지 않는다.

소유자·영유권·관리자·분쟁 당사자를 실제로 잃은 관계절은 여전히 원형 보류한다. 두 명명값 목록과 두 미상 당사자의 관계절은 다르다. 원문에 실제 '이름없는 섬'이라는 서술이 명명 지역과 묶여 있으면 그 표현 자체를 소실된 이름으로 단정하지 않는다. 값 없는 수식/경계 표식과 구별한다.

부분적으로 채워진 경로표의 원래 빈 행은 미상 구간의 위치를 표시할 수 있으므로 유지한다. 앞뒤 채워진 항목을 직접 인접한 것으로 만들지 않는다. 값이 전혀 없는 별도 예시표/빈 표 셸·미완결 예고는 따로 원형 보류할 수 있다. 표 전체를 동일한 빈 구조로 처리하지 않는다.

이미 전체 셀을 보류한 자기 사례도 재확인한다. 특히 context_hangul의663423/663426/663432/663680/747298/747605/747630/747631/747745/747831, context_latin의663422/663429/669225와 이후 같은 명명 목록 형태를 확인한다. 새로 제시된670749/670750/672151도 이름/직접 붙은 거리/반복·순서를 보존하고 실제 소실 경계만 분리하는 원칙이다. 이는 특정 값의 외부 사실검증이나 원문에 없는 이름을 추가하는 지시가 아니다.

출력 열에는 정확 TXT basename 하나를 쓴다. 이전 리뷰가 설명/선택을 잘못 적었다면 새 전체5행 교정 리뷰에 실제 원문과 선택 본문을 고정한다. 미선택 초안은 보존하되 파일 버전 숫자로 최종 본문을 추측하게 하지 않는다. 후보 동일·패킷 읽기·부분 검사·대기열 생성은 캐시 채택이나 전체 goal 완료가 아니다.
