# 663410 대권 연결문의 26/29 숫자 정정

2026-11-03 KST 총괄은 지정 원문1172자를 끝까지 읽었다. 도입·경로 표제는 서경29도를 명시하고, 말미 이웃 링크는28/30이다. 대권 연결문 한 곳만 서경26도와 동경151도를 묶고 있어 내부 충돌이 있다.

한국어 출판 페이지의 웹 호출은 DisabledError로 내용을 얻지 못했다. 이를 출판 페이지 확인 성공으로 세지 않는다. 대신 실제 출판된 [29th meridian west, 고정판1298234175](https://en.wikipedia.org/w/index.php?title=29th_meridian_west&oldid=1298234175)는 서경29도와 동경151도가 대권을 이룬다고 명시한다. 같은 판의 북부/남부 Peary Land, Frederick E. Hyde Fjord, Independence Fjord 순서가 지정 원문의 채워진 경로와 대응한다. 이 출판 판에는 추가 출처가 필요하다는 표시도 있으며, 전체 지리 사실 검증이나 새로운 측량 증거로 삼지 않는다.

각도 산술로도29+151=180이고26+151=177이다. 원문의 다른29도 필드와 출판 연결문을 대조한 범위에서 연결문 단일 `서경 26도`를 `서경 29도`로 정정한다. 원형26 표현과 대조 근거는 sidecar에 남긴다. 다른151 값이나 경로, 현재 국가/좌표/영유권 주체를 새로 채우는 승인이 아니다. 원문의 트린다지섬 반복 방향 등 다른 지리 주장까지 이번 숫자 정정으로 옳다고 판정하지 않는다.

대서양 행의 이름 있는 섬과 방향은 실제로 채워진 내용을 보존하고 빈 괄호만 원형 보류할 수 있다. 명명된 두 남극 권역이 나오는 실제 관계는 미상 주체절과 구별한다. 다른 표의 국가명에서 새 주체를 가져오지 않는다. 혼합 캐시의 문서 출처 UNKNOWN은 그대로이며 이 URL은 정정 대조용이다. 실제 새 TXT는 지정 보조 역할이 작성하고 총괄의 정확 핀·전체 차이 검토 후에만 선택한다.
