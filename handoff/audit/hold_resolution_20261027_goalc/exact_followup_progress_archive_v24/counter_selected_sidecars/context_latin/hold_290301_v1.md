# expanded_train:290301 원형 보류

## 실제 분리 문자열

`Thus, the expression`

`will return the indicated variable's value, and`

`will set a new value.`

## 이유

위 설명은 두 실제 awk 표현식을 직접 가리키지만 그 표현식 값이 원문에 없다. 후보는 완결된 `Every awk script has an associative array.`를 남기고 누락 식과 그것에 의존하는 결과 문구만 분리했다. 환경 변수의 정의·예시, 셸 구문, C 함수명 및 서명은 그대로 두며 새 변수를 채우지 않는다.
