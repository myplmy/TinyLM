# expanded_train:605647 원형 보류

후보가 아래 평탄화된 C# 예제와 직접적인 실행 파일/디컴파일 안내를 본문에서 분리했다. 코드를 복원하거나 실행하지 않았다. 본문에는 이름이 명시된 `IEnumerable`, `IEnumerator`, `MoveNext()` 설명과 원문에 적힌 값·비교·조건을 유지했다.

## 예제 코드 원형

```text
using System.Numerics; // also add reference to System.Numberics
private static IEnumerable Fibonacci()
BigInteger prev = 0;
BigInteger current = 1;
yield return current;
var next = prev + current;
prev = current;
current = next;
static void Main()
// print Fibonacci numbers from 10001 to 10010
var numbers = Fibonacci().Skip(10000).Take(10).ToArray();
```

## 코드/결과에 직접 연결된 원형 조각

- `How it works under the hood (I recommend to decompile resulting .exe ﬁle in IL Disaambler tool):`
- `(d 0 in ildasm).`
- `State consists of current position in method and values of local`
- `(5 2 and 5 1 in ildasm). In our method we have two positions (<>1 state): first at the opening curly brace, second at yield return.`

이 조각들은 제거된 프로그램 또는 그 디컴파일 결과의 구체 구조를 직접 가리켜 원형 보류했다. 뒤의 독립된 설명 문장과 저자의 메모리 비교는 원문 그대로 유지하며 실행 결과로 검증하지 않았다.
