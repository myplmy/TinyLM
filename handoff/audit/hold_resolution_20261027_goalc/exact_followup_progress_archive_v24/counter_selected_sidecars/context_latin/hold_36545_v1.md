# expanded_train:36545 원형 보류

## 빈 기호 병기

원형 첫 문장에는 `아연(亞鉛, )`라는 빈 괄호 포장도 있다. 실제 표기 `亞鉛`은 본문에 남기고 빈 슬롯만 분리했다.

원형 표현: `기호는 Zn(←), 원자 번호는 30이다.`

`Zn`은 실제 기호 표기로 남겼다. 괄호 안의 `←`에는 연결 대상이 없어 본문에서 분리했다. 빠진 대상을 추정하지 않는다.

## 끝맺음이 없는 생산 문장

원형 표현: `국내 경북 봉화, 강원 정선, 충북 제천·괴산 및 중국, 미국, 호주 등에서 생산되는 아연은`

문장이 술어 없이 끝나므로 이 절 전체를 본문에서 분리했다. 지명과 생산 관계를 원형 그대로 보존하며, 다음의 실제 사용 항목에 연결하지 않는다.
