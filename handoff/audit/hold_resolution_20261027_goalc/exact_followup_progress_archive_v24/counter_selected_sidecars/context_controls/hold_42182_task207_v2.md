- 사유: 두 연쇄 계산행은 `=` 오른쪽 값이 비어 있고, 마지막 `integer p = rq(x);`도 그 미완 계산 연쇄의 결론으로 직접 제시되어 있다. 전체 연쇄의 산출값이나 계산을 보완하지 않는다.

## 원형 보류 구간

```text
오른쪽 부분을 계산하여 정리하면 이렇게 될 것이다.

  integer p = rq(x) + rq(y) * (0) = 
  integer p = rq(x) + 0           = 
  integer p = rq(x);
```

## 연결·보존 근거

원문에는 명명된 `rq`/`rt` 정의와 `p` 식이 있다. 미완 계산 연쇄를 뺀 뒤에도 원문에 명시된 `rq(x)는 rq(x)와 같지 않다`는 관계, 전역값이 전달되지 않고 변경된다는 설명, 같은 식을 빼면 0이라는 상식을 깨뜨린다는 서술은 본문에 보존했다. 원문 문장 `그러나 이것은 rq에 대해서는 성립하지 않는데 rq(x)는 rq(x)와 같지 않기 때문이다.` 중 사라진 계산을 직접 가리키는 도입만 정리했다. 뒤의 `rt` 대비 문장도 원래 용어와 조건 그대로 보존했다.

미완 계산의 값을 추정하거나 식을 실행·검증하지 않았다.
