# 856316 서지의 고립 닫는 대괄호 — root 근거

2026-11-01 root가 지정 본문 검토자의 질문을 받아 읽기 전용 웹 조회로 서지 제목의 포장을 대조했다. 새 책 본문/학습 자료를 수집하거나 추가하지 않았다.

- 검토자가 확인한 로컬 문자열은 `The Sarum Missal, Done into English]`이며 제목 안에 대응하는 여는 대괄호가 없다.
- [Oxford 소장본의 Google Books 서지 레코드](https://books.google.com/books/about/The_Sarum_Missal_in_English_by_A_H_Pears.html?id=cyUBAAAAQAAJ)는2판/1884년으로 표시되며 해당 제목 끝에 고립된 닫는 대괄호를 표시하지 않는다. 메타데이터의 번역자 안내에 있는 균형 잡힌 대괄호와 구분했다.
- [Internet Archive의1884년 원본 소장 레코드](https://archive.org/details/per_the-sarum-missal-done-into-english_a-harford-pearson-_1884_ia40330203-33)도 같은 제목과Pearson, London : Church Printing을 표시한다. 소장 페이지의 서지 메타데이터를 읽었으며 원본 페이지 이미지를 직접 판독한 것은 아니다.
- Google Books의 Title Page 링크는 열었으나 이미지 글자는 도구 본문에 제공되지 않았다. 그 페이지의 Plain text 요청은403이었다. 출판 원문 전체의 정확 전사를 검증했다고 주장하지 않는다.

판단은 로컬 기호의 불균형과 위 서지 메타데이터를 함께 근거로 한 국소 포장 정리다. 본문에서 고립된 닫는 대괄호 하나만 제거하고 실제 제목 단어·번역자·판·출판사·연도와 나머지 서지를 그대로 보존하도록 지정했다. 다른 문헌의 대괄호를 일괄 삭제하는 규칙이나 새로운 출판 사실을 학습 본문에 추가하는 근거로 일반화하지 않는다.
