# 기존 저자 완독 결과의 빈 지리 절 경계 검증

F3는 A 모든 미채택 본문을 다시 원문 전문부터 읽기, B 빈 표제에 보편적 삭제 예외 추가, C 기존 저자 전문·정제본·리뷰를 재사용하고 빈 인구/기후/갤러리/사진과 명시된 다음 지리 절 사이에 내용이 전혀 없는 좁은 문자 비교를 추가하는 방법이다. C를 적용한다. 실제 보유 결과의 주요 잔여 형태는 인구→교통 70건과 인구·기후→교통 23건이다. 새 본문 생성이나 첫 판독 실적 증가는 없다.

F4는 기존 empty-section v1의 보호와 모든 실제 원형 numeric/code/Unicode/style/order/no-memo 검사를 유지한다. 새 경계는 교통/철도/도로/역사/기후/자매 도시/자매도시의 독립 표제만이며 삭제할 절 앞과 뒤에 빈 줄이 있어야 한다. 그 사이에 기입된 값·설명이 한 글자라도 있으면 해당 절을 비어 있다고 증명하지 않는다. code fence·인용·목록·들여쓰기는 제외하고 bare 사망 EOF 등의 기존 부정은 유지한다. 명시된 다음 절의 실제 내용은 전부 문자 순서대로 유지해야 한다.

프로파일의 added/replaced word 분류도 검증 대상에 포함하되, 이는 띄어쓰기 조정으로 토큰 경계가 바뀐 경우를 놓치지 않기 위함이다. 모든 populated 문자 stream이 같아야 하므로 실제 단어·조건·부정 추가/교체는 그대로 거절한다. scanner 무결함만으로 채택하지 않고 저장된 전문 판독, 일치하는 리뷰, 문자·수치·순서 증명과 ROOT 실제 층화 문맥 확인 후에만 다음 선택에 추가한다.
