# 독립 문맥 대조 두 번째 묶음의 채택 범위

기존 ROOT12의 7,980개 선택을 그대로 보존하고, 고정 counter v5의 저장된 560행에서 이전 채택을 뺀 다음 묶음만 심사한다. 다른 역할이 원문·이전 선택문·전체 차이를 판독한 최종 리뷰와 정확 본문 SHA를 연결한다. 부분 수집 시 미검토 원문은 열지 않는다.

새 코드 복제, 기존 생산기의 해시 고정 재사용, 검사 신호만으로 전량 자동 채택하는 세 방법 중 기존 생산기 재사용을 택한다. 판독과 의미 판정의 계약을 바꾸지 않고 이전 선택과 나머지 원장 행을 보존하는 범위가 가장 좁다. 코드·숫자·Unicode·문체·순서·검수메모 검사는 기존 함수를 사용한다. 경고가 남은 ID만 별도 보류한다.

1060968은 정확 원문/본문 쌍에서 단어의 줄바꿈 접합·공백 추가와 미완 절을 보류한 뒤의 종결 마침표만 총괄이 확인했다. 단일 구절의 쉼표→마침표 정규화 뒤 기존 순서 검사를 다시 통과한 별도 근거가 있을 때에만 그 정확 쌍의 순서 신호를 닫는다. 전역 허용이나 검사 생략이 아니다. 56606의 옛 재배열 본문은 채택하지 않고 원형 순서를 복구한 새 v2만 심사한다.

검토가 닫혔어도 캐시 생성·독립 consumer 검증 전에는 학습 입력 채택으로 계산하지 않는다. 이 묶음의 대조는 신규 1차 검토량에 더하지 않으며 전량 사실검증·모델 품질·학습 승인·목표 완료를 뜻하지 않는다. 보호 원형·캐시·타 세션 자료와 GPU·모델·외부 상태는 변경하지 않는다.
