# 규칙28의 소스 연결 일괄 채택 범위

접근·권한·반례·프로젝트 영향은 `V28_DECLARED_NAME_VARIANTS_F3_F4_V1.md`를 따른다.
목표 §1·5·6의 CPU 전처리와 현재 사용자의 기존 대량 처리 방법 재개 지시로 수행한다.
기존1~27과 원문·고정후보·기존캐시를 변경하지 않고 현재ROOT34의 모든 행을 그대로 보존한다.

새28은394회귀를 통과했다. 남은65911개 대기열의 원문65891개를 SHA로 검증하고
제한/개별 보류20개를 열지 않은 전량 census에서407개/545위치의 새 후보를 얻었다.
그407개 전부에 대해 별도 문자·숫자·순서·코드·Unicode·문체 보존을 확인했다.
후보본문을 census에 복사하지 않았으며 실패 후 재검증도815202B metadata shard를 읽기 전용으로 재사용했다.
대기열 밖879개는 이번 규칙으로 처리하지 않았고 별도로 상태를 연결해야 한다.

독립적으로 저장돼 있던 실제 전문 판독21개와 대조했다.13개는 같은 바이트,
7개는 끝 줄바꿈만 달랐고346999 하나는 비어 있는 선행 공백·끝 빈줄만 달랐다.
총괄이398B 원문과 두 본문 전체/diff를 직접 읽고 정확한 한자·동 번호·구분·문장 순서를 확인했다.
그 하나는 별도 SHA 한정 closure로 닫고 전역 whitespace 또는 코드 가드를 완화하지 않는다.

총괄이 원문을 전문 판독한 선언 유형의 근거는 실비오309329,코바치304771,후안 베론307632,
아웅 투1053703,버밍햄186152,퐁퐁761947 및 연산동346999다.
사보 졸탄의 값만 남은 인물행,허강의 이름 없는 강,깨진 닫는 괄호와 빈 작품명은 일반 해제하지 않는다.
이는 문맥 유형별 근거이며 나머지386개 각각을 인간이 전문 판독했다고 주장하지 않는다.

새 body는 프로그램 정책 결과로 명시한다. 실제로 같은 기존 본문은 그대로 참조하고 다른 본문만
새 hash 경로에 한 번 저장한다. 각 원문 SHA·정제 SHA·규칙 핀·보존 proof·독립 판독/closure를 연결한다.
새로운 개별 NEEDS_ROOT와 보호 자료는 제외하고 일반 가드 실패를 면제하지 않는다.
신규20MB 미만 파일/4MB·512행 metadata 조각 한도를 유지한다.

채택은 캐시 검증이 아니며 캐시15 공식H105824를 바꾸지 않는다. 최종 묶음에 맞춘 전체roster,
opaque/참조census/현재코드핀과 실제cache/consumer 검증이 후속이다. 개별 인간 판독과 규칙 처리는
계수6으로 분리한다. GPU/모델/추가300M·push/PR과 타세션 변경은 제외한다.
