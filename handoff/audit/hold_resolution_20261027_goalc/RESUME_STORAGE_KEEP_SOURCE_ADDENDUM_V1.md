# 동일 본문 중복 복사 방지 보완

수집기 `KEEP_SOURCE`는 고정 reader 헤더의 exact original 절대 경로를 출력 셀에 선언하면 원문 파일을 그대로 선택한다. 원문 자체가 최종 선택일 때 동일한 새 TXT를 만들지 않는다. 후보가 최종 선택이면 `ACCEPT_CANDIDATE`와 `accept_output_absolute`를 사용하고, 실제 수정이 있을 때만 새 TXT를 작성한다. 이 지원은 기존 author-output binding/materializer 코드에서 확인했으며 새 본문 생성 코드나 원형 변경을 추가하지 않았다.

기저장 TXT는 모두 보존한다. 판정 리뷰는 저장한 버전을 불변으로 두고 정정·추가 결과는 새 버전에 기록한다. 작업 중 진행은 PROGRESS에 적는다. 같은 내용을 정규 이름과 v1 이름으로 두 번 저장할 필요는 없다. 실제 수집에서 확인한 page012의 예외 파일명은 동일 본문5행의 새 정규형과 정확 SHA를 결합해 기존 alias 검사로 처리했고 최초 판독이나 본문 정제 증가로 세지 않는다.

이 보완은 현재 cache15가 고정한 기존 저장 계약 파일을 바꾸지 않는다. 원문·모든 기존 작성본·원로그·현재 검증 캐시를 보존하며, 향후 새 중간 캐시를 폐기할 때에는 대체 검증과 현재 참조 해제 및 정확 manifest를 먼저 확인한다.
