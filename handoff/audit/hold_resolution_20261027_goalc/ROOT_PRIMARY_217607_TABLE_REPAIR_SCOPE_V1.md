# 217607 원형과 공식 출처에 한정한 부분 복구

- ID: expanded_train:217607
- 원형 SHA-256: 497BA466DE6B5EFFFFEE724848DCC336E5D06686A5B7343B60DF4BF4104C2BED
- 원형 45877자 중 총괄은 0–24000자와 아래 공식 출처의 관련 표·라이선스를 직접 읽었다. 전체 원형 판독은 담당자의 1–23 패킷 근거이며 총괄 전량 재판독으로 주장하지 않는다.

- 서지: Vahabzadeh A, Keshav NU, Salisbury JP, Sahin NT. 원형의 논문 제목. JMIR Ment Health 2018;5(2):e25. DOI 10.2196/mental.9631. 2018-04-02.
- 저작권자: Arshya Vahabzadeh, Neha U Keshav, Joseph P Salisbury, Ned T Sahin. CC BY 4.0: https://creativecommons.org/licenses/by/4.0/ . 원형 제목·서지·공식 URL·이 저작권/라이선스를 sidecar에 함께 유지한다.

허용은 자기 page011의 이 ID 새 TXT/MD와 TASK004 새 리뷰 버전에 한정한다. 담당자는 이 안내 파일 하나를 읽어도 되며 웹 접근·수치 계산·코드 실행·다른 역할 파일 변경을 하지 않는다.

1. 숫자·범위·부호·불확실성과 한계 문단은 유지한다. 초록과 본문의 실제 반복은 의미 중복만으로 삭제하지 않는다. 빈 인용 슬롯은 공백·쉼표·하이픈뿐인 경우만 제거하며, 실제 번호·구간·수식·값 있는 괄호는 보존한다.
2. 개인별 자료 표는 원형에 머리글만 있고 행이 없어 해당 빈 표 구조를 sidecar HOLD한다. 외부 원문에 보이는 개인별 값은 새로 들여오지 않는다. SCQ/ADHD의 채워진 약어 정의는 독립 정보로 보존 가능하다.
3. 전체 인구통계 표에서 15 (3.4)의 통계 항목은 공식 출처에서 나이(년)임을 확인했다. 이 행과 실제 SCQ 점수의 18.1 (5.8) 행은 항목·평균/표준편차 역할을 명시해 보존한다. 값이 없는 성별/진단/치료 빈 행은 sidecar로 둔다. 외부에서 새 범위·인원·비율을 가져오지 않는다.
4. 뒤의 두 ABC-H 표는 각각 높은 증상군과 낮은 증상군이다. 원형의 실제 집계 2행씩과 열의 시간·변화율·N/A를 보존하고 이 군 구분을 머리글에 복구한다. 개인별 누락 행·숫자를 추가하지 않는다. 원형에 이미 있는 정의와 분모 조건은 보존한다.
5. `.and summarize participant demographics.`와 대상이 빠진 그래프/그림 지시문은 sidecar로 분리한다. 완결된 참가자 설명과 Face2Face/Emotion Charades의 명명·작동 설명은 보존한다. 빈 그림 괄호만 제거하고 이미지의 미확인 상세를 채우지 않는다.
6. 새 본문 전문·이전본 대비 전체 diff·EOF를 확인하고 출처에 따라 복구한 항목, 보류한 빈 구조, 숫자 추가 0을 sidecar/리뷰에 적는다. 임상 효과·실행·문서 전량 사실 PASS를 주장하지 않는다.
