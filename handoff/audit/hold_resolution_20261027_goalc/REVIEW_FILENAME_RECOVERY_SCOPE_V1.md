# 비표준 리뷰 파일명 이력 연결

birth snapshot7은 review_049_v10_v2.md의 비표준 중첩 버전명 때문에 실제 exit1로 중단됐다. 유효한 review_049_v11.md에는 두 ID의 정확한 후보 채택으로 정정된 행이 있다. 실패 로그·원형 파일을 보존한다.

세 대안을 대조했다. 기존 파일 개명은 원형 경로와 이력 보존에 어긋난다. 임의 접미사를 일반 허용하면 잘못된 최신 판정이 묵인될 수 있다. 선택한 방법은 이 파일의 정확 경로·SHA·두 ID·같은 폴더의 더 높은 정상 버전 리뷰를 고정한 별칭 순위 한 건을 등록하는 것이다.

등록된 과거 파일도 실제 판정 행으로 파싱·보존하며 비판정 보조문서로 속이지 않는다. 해당 별칭 밖의 비표준 이름은 계속 거부한다. 두 파일의 SHA, ID 집합, 정상 후속 버전, 같은 TASK/폴더 조건 중 하나라도 달라지면 수집을 거부한다. 이력 연결은 본문 승인이나 캐시 채택이 아니다.
