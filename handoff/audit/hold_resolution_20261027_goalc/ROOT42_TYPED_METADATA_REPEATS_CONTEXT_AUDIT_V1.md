# ROOT42 동일 비수치 분류 태그의 후속 출현만 정리

목표의 CPU 전처리·새 파생본·관련 코드 시험 권한과 기존 반복 문맥 F3/F4를 적용한다.
대안 A는 반복 줄을 일괄 삭제하는 것으로 문항 선택지·본문 반복·숫자 손실 위험이 있다.
B는 이미 확인한 단일 마지막 분류 블록의 동일 비수치 태그만 정리하며 전량 독립 문자·수치·순서 증명을 요구한다.
C는 이전에 판독한 자료 전량을 다시 읽는 것으로 추가 원문/문맥 증거 없이 호출을 반복한다.
권장 B를 적용하며 기존 원형·후보·완료 저자 TXT는 수정하지 않는다.

기존 rule32 전체 잔여 대기열 census는 52개 일치 중 신규 terminal 21개/31위치를 냈다.
그 중 완결된 문항·답안 344665/2위치는 이번 채택에서 제외한다. 실제 평가 자료인지 확인됐다는 뜻이 아니라,
문항 구조가 완결됐다는 proof만으로 학습 추가 경계를 충족했다고 볼 수 없기 때문이다.
나머지 20개/29위치는 마지막 typed 분류의 동일 비수치 태그 후속 출현만 제거한 후보이다.
최신 ROOT41에 이미 채택되었거나 저장 저자 본문과 충돌하는 경우는 그대로 보류한다.

ROOT가 이미 전문을 판독한 457072·472081의 실제 구단 분류 태그 중복 사례와,
484877의 반복 설립 연도(숫자이므로 제외), 344665의 서로 다른 문항에 같은 선택지(보존)를 대조 근거로 재사용한다.
원형·완료본 재독에 새 최초 판독 credit을 주지 않는다. 새 수동 학습 TXT 작성은 ROOT가 하지 않는다.

독립 검증기는 production metadata/repeat prove를 호출하지 않는다. 줄 경계로 마지막 단락을 정하고
복수 독립 category marker, 중복의 마지막 단락 내부 한정, 비수치 여부, 첫 출현을 남긴 유일값 전체와 순서,
별칭 구분자·빈 실제 appendix를 제외한 모든 본문 문자, 실제 숫자·code·Unicode·style·order·메모를 검사한다.
남은 문장·빈 내용 표제·수식·delimiter와 저장 리뷰 충돌도 기존 채택기가 재확인한다.
본문의 같은 태그, 숫자 태그, 고유값 이동, 이름/숫자/부정 변경, 문항·답안 반례는 거절한다.

기존 431개 policy 회귀와 별도 7개 독립 문자 반례 시험을 연결한다. 최초 test 실행의 -I import 실패는
TYPED_METADATA_REPEATS_INDEPENDENT_TESTS_V1.log에 남기고 명시 경로 로딩을 고친 실제 V2 성공과 구분한다.
최초 독립 V1 결과의 20/29와 후속 V2의 내용 표제 명시 필드 추가를 구분하며 V1은 채택 입력으로 쓰지 않는다.
채택·native shard 독립 검산·matching roster/opaque/census·actual cache guard·새 cache 소비 검증은 각각 별도다.
