# 분류 경계의 다음 대량 규칙

사용자 지시의 사례·반례→좁은 규칙→회귀→전체 해당 범위 적용을 따른다. 이전 ROOT35
프로파일의 10,830개 분류 경계 단일사유 자료 중 9,681개는 typed intro와 짧은 tail을
갖췄다. 이 수는 새 규칙 채택량이 아니며 나머지 사유의 합집합도 아니다.

| 안 | 방식 | 이점 | 비용·영향 |
|---|---|---|---|
| A | 분류명마다 사전 whitelist 추가 | 제한 범위가 명확 | 같은 문법의 분류마다 구현·검증 반복 |
| B | 실제 고유명 정의+별도 tail의 독립된 typed marker 둘 이상+전량 보존 | 같은 구조를 한 번에 처리 | 인용·빈 내용절·다른 결손은 별도 보류해야 함 |
| C | 분류 경계 사유를 일괄 제거 | 빠름 | 본문/문헌/분류의 근거가 없어 채택 불가 |

B를 구현하고 실제 매치 수를 별도로 계수한다. 원형을 읽은 양성 validation:443에서는
실제 영화명/출연진과 두 개 이상의 유형화된 영화 분류가 있으며, 나머지 literal 분류도
그대로 보존한다. 반복된 배우 이름은 삭제하지 않는다. 양성 여부는 새 전량 검산 뒤다.
반례 validation:325에는 무자료 수상자 절이 있어 단순 metadata 해제 대상이 아니다.
validation:457에는 빈 지도/자료를 가리키는 문맥 검토가 남아 있어 무조건 해제하지 않는다.
expanded_train:789의 채워진 문헌·링크/인용/연대도 전량 보존하며 무자료 내용절은 보류한다.

rule30 독립 여섯 건에서 6722의 빈 교육기관/인구 도표 문맥, 691012의 빈 전투서열/역대
사령관 절을 확인했다. 두 후보는 미채택이다. 새 도구는 이런 빈 내용절을 자동 삭제하지
않고 보류한다. 다른 유형에서 정당한 제목/목록이 걸릴 수 있으며 불량 확정으로 표현하지 않는다.

| 경로 | 동작 | 권한 근거 | 제외 |
|---|---|---|---|
| scripts/p106b_hold_resolution_metadata_v4.py, policy_v31.py 및 해당 시험 | 신설 | goal의 CPU 정제/관련 코드·시험 허가 | GPU/모델/학습 |
| 이 audit 폴더의 새 census/config/독립 검산 | 신설 | 전체 처리/원문 연결 근거 | 기존 근거 덮기 |
| 정확한 기존 배정 원형/metadata | 읽기 | 확정 HOLD 정제 범위 | guard6 자료/보호 TinyDataset/타세션 |

코드 영향은 새 metadata delta뿐이며 이전 정책과 소비자의 terminal body 계약을 계승한다.
원형·기존 후보·리뷰·캐시는 바꾸지 않는다. 모든 차 있는 문자·숫자·코드·문체·순서와
metadata 값을 별도 verifier로 대조한다. 본문 사본 없이 metadata만 전체 대기열에 적용한다.
시험은 기존 회귀 전부와 무자료 절/인용/다의어/동일 marker 중복/개별 HOLD 반례를 포함한다.
분류 사유 이외의 미해결 사유나 실제 값 결손은 지우지 않는다. 결과·기준표·METHODS·COMPASS는
실제 채택/캐시 검증 뒤 전체 수량과 묶어서 갱신한다. 이 작업은 사실검증/정제 완료 주장이 아니다.
