# 기존 전문 판독 결과의 실제 빈 표제·메타데이터 경계 재검증

현재 지시와 목표 §1·4·5·6의 CPU 정제·검증 허가로 수행한다.
AUTHORED_LITERAL_BATCH_F3_F4_V1.md와 CLOSED_LITERAL_RULE_BATCH_F3_F4_V1.md의
문자·수치·코드·순서·독립 문맥 및 보호 경계를 유지한다.

| 안 | 내용 | 장점 | 한계·영향 | 비용 |
|---|---|---|---|---|
| A | 원래 literal 기준만 재사용 | 기존 proof 그대로 | 마지막 분류 앞의 실제 빈 표제를 모두 단어 손실로 보류 | 낮음 |
| B | 원래 기준 또는 독립 typed metadata 경계에서만 빈 표제 제거를 허용 | 기존 전문 판독을 재사용하며 모든 차 있는 문자 보존 | 그 밖의 부분정제는 계속 보류 | 낮음 |
| C | 모든 표제 삭제를 허용 | 넓은 채택 범위 | 채워진 문헌·인물 목록의 표제까지 오삭제 가능 | 낮음이나 부적합 |

선택 B. metadata는 독립 line parser의 둘 이상 실제 명목 분류나 명시 출생/사망·생존 쌍+
명목 분류 또는 명시 설립/폐지 쌍으로 확인한다. 원문과 최종본의 metadata는 그대로 같아야 한다.
그 바로 앞의 EOF prefix에서만 실제 내용 없는 알려진 표제들을 떼어 비교하며,
남은 원문 문자와 순서·숫자·코드·Unicode·문체가 같아야 한다.
그 밖의 빈 본문 절·결손 변수·미완 산문·애매한 인용/소속·실제 ROOT 반례는 계속 보류한다.

경로: audit의 새 순수 검사·CPU 시험·config·readiness metadata만 신설한다.
stage17과 ROOT37 및 기존 저자 TXT/리뷰는 ID·SHA 확인 후 읽기만 한다. body 사본은 만들지 않는다.
기존 closure·선택·원형·고정후보·모델·GPU·학습풀/검증분할·타 세션 자료는 변경하지 않는다.
이 검사 PASS는 ROOT/캐시 채택이나 개별 추가 전문 판독이 아니다. 실제 문맥 층별 검토 후
검증된 묶음만 기존 authored admission/선택 독립 재구성을 재사용하여 연결한다.
문서 영향은 실제 채택량을 후속 roster·WIP·결과·METHODS·COMPASS에 묶음 반영한다.
실제 빈 메타데이터 앞 표제만 소유하는 좁은 확장이고, 일반 whitespace/숫자/코드 면제는 없다.
