# 실제 저장 본문 선택 계약 v3

v2와 과거 실패본을 보존한다. 현재 사용자가 허가한 잔여 원문 CPU 처리·새 파생본·관련 코드/검사/문서 범위에서 정확한 source/body/review SHA만 선택한다. 이 선택은 최종 캐시 채택, 전량 사실검증, 학습 승인 또는 goal 완료가 아니다.

| 안 | 내용 | 장점 | 한계 | 영향도 | 수행비용 |
|---|---|---|---|---|---|
| A | 기존 선택 v3만 고정 | 추가 충돌 없음 | 실제 복구한 문장·분류값·광고/수식/메모 수정 미반영 | 낮음 | 낮음 |
| B | 정확한 이전 결정의 명시 대체와 검토 목적별 source/body/review 연결 | 실제 오삭제·잔존 오류의 수정 회수 | 미중재 동일목적 충돌은 별도 처리 필요 | 선택/감사 새 버전만 | 중간, 실제 본문 재검산 필요 |
| C | 모든 대안이 일치한 본문만 사용 | 차이를 숨기지 않음 | 수정 전 실패본 때문에 복구본까지 사용 불가 | 회수율 감소 | 높음, 불필요한 재검토 |

선택 B. 62929는 원문의 MOS 전하 분포 문장 한 개를 복구한 정확 대체 파일을 적용한다. 6030은 기술 본문을 재복제하지 않는 정확 제외 근거를 적용한다. 다른 기존 exact root 결정은 유지한다. 기존 파일을 조용히 덮거나 서로 다른 body를 mtime/파일명 숫자로 고르지 않는다.

| 파일·경로 | 동작 | 권한 근거 | 제외 |
|---|---|---|---|
| 이 감사 폴더의 새 v7 선택계획/v4 본문선택/v2 재검산 코드·JSON | 신설 | 첨부 목표의 CPU 구현·검사·문서 허가 | 원형 수정/삭제 없음 |
| 지정 역할의 새 TXT/MD와 기존 source/candidate | 지정 범위 읽기/해시 | 첨부 목표의 총괄 검토와 실제 저장물 채택 판단 | 제한 parent는 metadata-only 또는 정확 승인된 view |
| 자기 tmp·정확 세션 WIP | 연락문 추가/CAS 갱신 | 사용자 tmp 조율 지시·작업원장 규약 | 타 세션 원장/코드/자료/프로세스 변경 없음 |

코드 영향은 collector의 기존 SHA/철회/명시 리뷰 구문 검사를 재사용하고 선택 순서만 새 목적에 연결하는 것이다. 데이터 스키마와 원문·기존 캐시는 바꾸지 않는다. 테스트는 기존 명시 리뷰 파서와 source/body pin·제한 view·합계 검사, 실제 선택 본문 재검산을 적용한다. 정본 연쇄는 실제 채택·재계측 후 별도 갱신하며 현재 검사만으로 완료 상태를 바꾸지 않는다. 기술부채는 과거 버전과 실패 이력을 유지하는 비용이며 선택 목적/핀을 명시해 숨은 최신파일 추측을 없앤다.

도메인 경계: GPU·모델·학습 실행0, 보호 TinyDataset/타 세션 전용자료 접근0, 원래 풀/토크나이저/구간을 바꾸지 않음, 정적/내용/캐시 증거를 구분, 계획·결과·기준표·METHODS·COMPASS는 실제 결과가 확정된 범위만 연쇄 갱신한다.

선택 순서는 기존 exact root와 명시 예외를 우선하며 그 밖에서는 새 v19 유형 전문 판독, 반복13의 최종 전문 재판독, v18 독립 반례4, v17 새22, 실제 선택 본문 신호276, 철회된3행의 독립 재판독, v2의 기존 목적 순서로 정한다. 높은 목적의 NEEDS_ROOT는 낮은 후보로 우회하지 않는다. 동일 목적에서 다른 실제 본문이 남으면 미결로 기록한다.

명시 예외 641587은 retracted_review_counter_v1의 실제 v3와 review_v2를 선택한다. 원문의 caption/링크값/항공 용어/자료명을 유지하고 BackTo 탐색행과 Category 포장만 정리한 원문 전문 대조 결과다. 2166과11885의 독립 재판독은 main의 유효 수정과 정확 같은 본문이다. 306600은 반복13에서 실제 연속 중복 문단 한 벌만 제거한 새 본문을 선택한다.

새 반복13의 중재 이력을 모두 보존한다. 248762는 수학 본문/수식/표/조건/연습질문을 유지하며 검색·게임·뉴스레터·DVD UI만 분리한다. 186100은 실제 면역계 설명을 보존하고 빠진 목록 소개·홍보·관련 글 미리보기를 분리한다. 834134의 두 평가 신청 CTA를 분리한다. 1037240/789184/311753/469087의 정상 분류값 삭제본은 실패 이력이며 복구한 새 본문을 쓴다. 685903의 검수 메모가 섞인 v3는 실패본이고 메모를 MD로 분리한 실제 v4를 선택한다. 뒤 자료 목록은 강의 인용이나 저자 역할을 새로 만들지 않는다. 완결 원문값과 직접 명시된 역할만 사용하며 깨진 수식/시각적 대응은 복원하지 않는다.

v20 독립3은 실제 지역 코드/4CTA를 전문 대조한 새 source/body/review이므로 위 일반 목적들보다 먼저 연결한다. 834134는 기존 신청2줄만 분리한 본문에 남았던 주문/구독2줄까지 원문에서 확인한 총4CTA를 분리한다. 새16의 legacy 역할이865115초안을 삭제·근사재생성하고24219초안을 제자리 수정했다고 보고했으므로 그 역할의 해당2건 산출물은 선택하지 않는다. AUTHOR_REASSIGNMENTS_V1의 정확 source SHA에 따라 다른 역할이 legacy_incident_counter_v1 새폴더에서 원문부터 재작성한 본문을 우선한다. 이전2배정은 저장완료로 세지 않고 명시 재배정으로 따로 보존한다. 삭제전 바이트는 회수되지 않았으며 당시부터 모든 초안이 보존됐다는 주장은 철회한다.

306600은 main의 실제 빈 별칭 정리/미상 생몰 표기 보존과 반복13의 실제 연속 문단1벌 분리를 합친 v3/review001_v2를 사용한다. 한 대안의 회수가 다른 대안의 유효 수정을 되돌리지 않도록 두 대안과 원문의 전체 diff를 대조했다. 311753은 후속 v5/review006_v3의 고립 따옴표 및 대상 없는 개업 조각 분리도 연결한다.

1215625/1251307/474106/842241의 ACCEPT 행은 새 저자 파일 대신 실제 TASK candidate의 파일명/경로를 출력에 적었다. v27이 이 이름을 저자 폴더에만 적용해 잘못된 파일 없음으로 거부했고 선택4는 실제 종료1이었다. v28은 실제 지정 입력과 동일한 파일명 및 정확 경로/SHA인 경우만 입력 참조로 연결한다. 다른 디렉터리의 동명 파일·URL·다른 버전의 저자 파일은 그 근거로 허용하지 않는다. 실제 네 입력과 위조 동명 경로의24검사를 닫았으며 과거 오류 기록은 보존한다. 원문/후보가 실제 존재한다는 확인은 해당 문서의 의미 보존 승인이 아니므로 본문 재검산은 그대로 수행한다.

선택 후 숫자·새 어휘·검수 메모·코드/Unicode/스타일·빈 필드·미완결 수식·원시 구문을 실제 source/body 쌍으로 재검산한다. 정상 수학·프로그램·인용·전사 리터럴의 정확 예외는 source/body/review 근거에만 묶는다. 전역 검사 완화, PENDING 일괄 EXCLUDE, zero-HOLD 캐시 계약 변경은 하지 않는다.
