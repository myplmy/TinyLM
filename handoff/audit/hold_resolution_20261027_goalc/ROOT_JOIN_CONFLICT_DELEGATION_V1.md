# 전체 선택 차이215건의 원문 대조 위임

ROOT_AUTHORED_SELECTIONS_V10_PREVIEW2의 미결215건 전량을 다섯 Luna 원문 역할에 배정한다. 원문SHA가 같은 옛 선택과 새 본문 차이를 읽는 작업이며, 높은 버전·최근 시각을 선택 근거로 쓰지 않는다. 보호7개 원문은 이215건에 없다. 총괄은 CPU로 실제 native 디코딩·원문SHA/EOS/UTF8/입력 위치와 지정 전문 순서뷰를 검증한다.

역할별 허용 입력은 새 root_join_conflict_counter_v1 아래의 지정 START/TASK/READING_VIEWS·해당 ID의 original/candidate/previous/다른 새 variant 및 순서 패킷과 복사한 지정 근거 MD뿐이다. 허용 출력은 각 agents/역할/root_join_conflict_counter_v1 안의 새 txt/md뿐이다. 이전 코호트 출력 폴더·다른 역할·규약·코드·시험·통계·해시·Python·Git·웹·모델·GPU·보호자료·타 세션에는 접근하지 않는다.

원문·모든 본문 전문과 전체 차이·실제 EOF를 읽는다. 독립적으로 채워진 코드·날짜·조건·부정·인용·경력·목록 값을 보존한다. 누락 식·표제·그림·단위·변수에 직접 의존하는 문장은 원형 보류하고 남은 본문의 독립성을 확인한다. 불명확한 원문 필드끼리 충돌하면 값을 생성하거나 날짜·나이를 역산하지 않는다. 출생의 연도 필드 충돌로 독립 경력·월일·사망 상태까지 지우지 않는다. 역할은 새 정제 본문을 실제 작성하고 총괄은 판정·중재·검산을 맡는다.

정확 예외 근거가 제공되는291381과50559는 기존 공식 자료에 핀한 좁은 날짜 정정을 보존한다. 이 두 근거는 문서 전체 사실검증이 아니다. 51521은 원문의 명시U+코드포인트와 원래 슬롯 관계가 증명되는 글자만 복구하며 다른 이름 소실·미완결 작은 가나 절까지 일반화하지 않는다. 본문에 실제 존재하는𛀁를 삭제하거나 없는 제목에 귀속시키지 않고 원형 위치와 보류를 연결한다.

리뷰는 ID·판정·실제 판독 범위·정확 전체 TXT 한 경로·구체 보존/보류 이유의5열 표다. 적절한 지정 candidate는 ACCEPT_CANDIDATE, 옛 본문이 맞거나 새 작성이 필요한 경우 새 TXT에 저장하고 REVISE_TEXT로 가리킨다. 판단할 수 없는 구간만 NEEDS_ROOT와 좁은 질문으로 남긴다. 검수 메모와 원형 보류는 학습 본문 밖 MD로 분리한다. 캐시 채택·전체 품질 완료는 선언하지 않는다.
