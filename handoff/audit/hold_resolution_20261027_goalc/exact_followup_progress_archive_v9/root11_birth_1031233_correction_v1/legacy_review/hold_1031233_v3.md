# 1031233 보류 및 서지 정리 경계

- 원문 리드의 `1962년 6월 14일`과 분류의 `1961년 출생`은 같은 인물의 서로 다른 출생연도 주장이므로 두 연도만 선택 없이 보류한다. 공통 월일 `6월 14일`과 생일 서술은 본문에 남겼다. 연도를 하나 고르거나 나이·사망 여부를 추정하지 않았다.
- 원문 분류 `살아있는 사람`을 v3 본문에 보존했다. 이는 지정 원문에 있던 분류를 되살린 것이며 현재 생존 여부를 외부 검증한 주장이 아니다.
- 원문 `| 쪽 = `은 값이 없는 항목이라 v2처럼 제외하고 쪽수나 대체 서지정보를 만들지 않았다.
- v2에 있던 `제목`, URL, 출판사, 저자, 날짜, 확인날짜의 값과 각 필드 관계는 바꾸지 않았다. v3에서는 사람이 읽기 쉬운 서지 필드 표기로만 표시를 정리했다. 실제 날짜 `2013-03-06`과 확인 날짜 `2022-03-18`을 합치지 않았고, 제목·URL·출판사·저자·날짜를 추가하거나 축소하지 않았다.
