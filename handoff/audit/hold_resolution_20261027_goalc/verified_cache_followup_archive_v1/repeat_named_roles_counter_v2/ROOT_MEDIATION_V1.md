# 반복 문맥 전량 판독의 공통 중재

이 문서와 START/TASK의 지정 입력만 보조 역할의 읽기 허용 목록에 더한다. 다른 역할 폴더·웹·코드·시험·해시·통계·원형 덮기/삭제 권한은 주지 않는다. 이미 읽은 명명 유형의 질문에 대한 총괄 중재이며 새로운 전체 문서 자동 삭제 규칙이 아니다. 이전 리뷰/본문은 보존하고 필요한 새 TXT/MD 및 교정 리뷰를 남긴다.

1. 한 완결 기사에 같은 bare byline만 반복되고 별도 작품·인용·서명·약력 역할이 없으면 첫 귀속 하나를 유지하고 뒤의 동일 메타데이터만 분리한다. 1082701/122910/1296689/1386311/147229/163481이 이 경계다. 같은 기사 앞에서 연속한 222007/241842도 하나만 유지한다. 222007 말미의 실제 서명은 별도 역할로 유지한다.
2. 실제 서로 다른 제목에 각각 붙은 동일 저자는 모두 유지한다. 1308609의 별도 실제 목록 크레딧, 1353239의 제목/크레딧 쌍, 204267과 187863의 말미 제목/크레딧 쌍, 261337/162643의 별도 글 크레딧은 제목을 보존한 채 유지한다. 관련글인지 같은 글인지 새 동일성은 만들지 않는다.
3. 제목/작품 경계 없이 서로 다른 이름이 여러 줄로만 모인 목록은 뒤 본문에 새로 배정하지 않는다. 1255469/120133/1285439/1339195/149007/216309/190758의 미귀속 목록은 전체 원형을 sidecar에 남긴다. 실제 제목·본문·독립 약력과 출판 문구는 보존한다. 1285439의 약력을 근거로 기사 저자를 새로 지정하지 않는다.
4. 채워진 단독 이름이 실제 설명에 인접하면 역할 미확정만으로 삭제하지 않는다. 1439102의 Anna Elena Eyre와 1409217의 Emily Hacker는 현재 위치를 보존하고 새로운 저자/인용 관계를 붙이지 않는다. 불확정 관계는 MD에 적는다.
5. 실제 본문 밖 Back to Top/Like/Share/Tweet/Continue reading 등 페이지 동작·복사 위젯과 독립 Pingback 메타데이터는 원형 sidecar에 보존한다. 실제 댓글·작품 제목·인용·기술 예제로 쓰인 문자열은 유지한다. 186415의 연속 동일 메뉴 By Historical Era는 하나를 유지하고 중복 하나만 분리한다. 1408837의 참고문헌 내 사이트 offline 한정은 실제 불확실성 정보로 보존한다.
6. 표의 채워진 수치·축·분류·순서·동률·rowspan·색 범례가 의미를 가지면 보존한다. 내용 없는 wiki 행 경계는 정리하되 빈 셀을 새 이름/값으로 메우지 않는다. 행의 실제 식별 관계가 사라졌으면 수치를 특정 국가/팀에 귀속시키지 않는다. 미상 행이라는 정보와 순서를 명시해 값만 독립적으로 보존할 수 있는지는 문서 전체로 판단하며, 불가능한 구간만 원형 보류한다.
7. 130640은 실제 대회 개요·라운드 일정·지역 분류·Palermo 철회/Auxerre 대체·공식 링크를 유지한다. 누락 경기 대상의 7월16일/경기 장소 각주는 원형 보류한다. FK 제타의 협회 참가 사실과 명명된 구장 상태 등 원문에서 독립적으로 완결한 절은 유지할 수 있지만 미상 경기·상대·날짜·인과를 만들지 않는다. 빈 각주 표제를 새로 복원하지 않는다. 132438의 지역/그룹 A–H/단계 분류와 32강 참가 조건·결승 설명은 유지한다.
8. 1336995의 실제 B 태그 안전 경고 강조는 보존하고 Add to Favorites/Visit Us 동작만 분리한다. 모든 HTML 태그를 무차별 제거하지 않는다.
9. 1403490의 이름 한정은 ROOT_EVIDENCE_1403490_CREDIT_V1.md의 정확 출판사 근거를 따른다. 다른 사실이나 기술 설명에 철자 정정 범위를 넓히지 않는다.

위 중재를 근거로 한 새 본문도 전량 차이·원문 연결·코드/Unicode/조건/수치 보존 검사를 통과해야 한다. 후보와 원문이 동일하다는 사실은 정제 적합성이나 캐시 채택을 의미하지 않는다. 이 732건을 마쳐도 다른 잔여 구간은 계속 미결이며 전체 goal을 완료/일시중지하지 않는다.
