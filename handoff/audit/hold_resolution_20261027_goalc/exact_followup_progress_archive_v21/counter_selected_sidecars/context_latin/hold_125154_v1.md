# 125154 원형 보류 및 수정 근거

candidate에서 복원한 실제 저자 문장은 원문 그대로 `I developed kernel patch for FreeBSD which makes TCP_CORK, which is in FreeBSD-4.5 and later.`이다. 외부 사실을 확인하거나 문장을 교정하지 않았다.

원문 끝에는 `I have a program which I used to test the behaviour of`라는 목적어 없는 예고가 있다. 뒤에 실제 프로그램 본문은 없으므로 이 불완전한 문구만 원형 보류한다. 뒤의 `$dotat: doc/web/writing/nopush.html,v 1.3 2007/08/22 01:59:07 fanf2 Exp $`는 실제 채워진 파일/개정 메타데이터로 candidate에 남겨 보존하며, 이를 앞 예고의 목적어로 새로 연결하지 않는다.
