# expanded_train:1409807 원형 보류 메모

- 분리한 원형 조각: `The following example creates the employees table and uses GETDATE for a default value for the`
- 이 문장은 끝에서 목적어/값 설명이 잘린 채 완결되지 않는다. 뒤에는 완결된 SQL Server 예제와 GETDATE 설명이 있으므로, 잘린 예고 문장만 candidate에서 빠진 경계를 유지한다.
- 예제의 SQL, 실제 열/기본값, 결과 설명 및 함수명은 그대로 보존한다. 누락된 설명을 추정해 채우지 않으며 SQL을 실행하지 않았다.
