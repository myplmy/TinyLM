# expanded_train:49548 원형 보류

판정 경계: 이름과 자연어 관계가 모두 있는 인장/전단 탄성 계수의 비율 설명은 그대로 보존했다. 원문에 `응력()`·`변형도()`처럼 비어 있는 표기 슬롯이 있었더라도 해당 문장에는 응력을 변형도로 나눈다고 실제 설명되어 있으므로 새 수식 없이 그 설명을 남겼다. F(하중), A0(단면적), l0(원래 길이)의 실제 연결도 유지했다. 아래의 미귀속 길이 변화량 표현과 누락식에 직접 기대는 관계 문장만 보류했다.

## 보류한 원형 조각

```text
탄성 계수 E의 단위는 파스칼이며, F는 작용하는 하중, A0은 단면적, 는 재료의 길이 변화량, l0은 재료의 원래 길이이다.
탄성 계수의 관계식 
등방성 재료에 대해, 인장 탄성 계수(E)와 층밀리기 탄성 계수(G) 사이에는 다음과 같은 관계가 성립한다.
여기서 는 재료의 푸아송 비이다.
```

길이 변화량 앞의 변수명·공식 및 E/G 관계식은 원문에 채워져 있지 않아 만들지 않았다. 관계식 표제 아래 본문에 남은 내용이 없어 표제도 본문에서 함께 정리했다. 부피 탄성 계수 K의 독립 설명, 조건이 있는 재료 설명, 같이 보기 명칭 및 실제 외부 자료명은 후보대로 보존한다.
