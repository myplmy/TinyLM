> Get all the videos in this Access VBA collection 100% FREE by signing up at http://vbahowto.com/ms-access-tutorial

원문의 VBA 코드 예시는 다음과 같이 한 줄로 평탄화되어 있다. 실행 흐름이나 개행을 추정하지 않고 코드 단위 전체를 보류한다.

> Option Compare Database Private Sub Form_Current() Dim intResult As Integer Forms!Categories.Caption = Me.CategoryName intResult = calculate(6, 6) MsgBox intResult End Sub Function calculate(num1, num2) Dim dblResult As Double dblResult = num1 + num2 calculate = dblResult End Function

candidate에 실제로 남은 Access 폼의 `!`/`.` 구분, `Forms!frmCategories`/Caption 예, `Me` 설명과 영상 시리즈 문구는 보존한다. URL을 새로 만들거나 코드를 실행하지 않는다.
