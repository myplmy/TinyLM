# expanded_train:10301 원형 보류

최종 본문은 원소명·Rb 기호·원자번호와 원자량, 안정/방사성 동위원소의 이름·비율·반감기, 실제 반응 및 설명을 보존한다. 원소명 바로 뒤의 역할을 식별할 수 없는 두 화살표 병기와 문장 사이에 고립된 중복 마침표만 본문에서 분리했다. 빈 녹는점 값 문장과 빈 각주 표제는 기존 선택본문에서 이미 빠져 있었으며 이를 복원하지 않았다.

## 보류한 원형 조각

```text
루비듐(←, ←)은
녹는점은 이다.
가지고 있다. . 루비듐과 칼륨은 불꽃 실험에서 아주 비슷한 보라색을 보여준다.
각주
```

화살표 두 개에 새 이름/대상/관계를 부여하지 않는다. 녹는점 값을 만들지 않고, 각주 아래 실제 WebElements 항목은 본문에 보존한다. 중복 마침표는 문장 의미를 추가하지 않는 고립 문장부호로 기록했다.
