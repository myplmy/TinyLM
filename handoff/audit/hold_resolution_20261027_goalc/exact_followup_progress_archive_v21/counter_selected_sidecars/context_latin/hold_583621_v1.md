# expanded_train:583621 원형 보류

원문 시작은 `Unformatted text preview: xecuting a file with my program`이며 곧바로 `x Need another program ...`로 이어진다. 이 깨진 미리보기 머리말/부분 문자열은 선택본문에서 제외되었다. 원문 끝의 흐름 문장 조각 `You`도 뒤의 `4 Programming languages` 제목과 이어지는 완결 절이 없어 후보에서 분리되었다. 두 조각은 이 메모에 보존한다.

보기 UI `View Full Document`는 후보가 제거했다. 실제 슬라이드 내용의 4/5 표제와 예시, 자료의 수업/교수/학기 귀속, `Fall '00` 표기는 선택본문에 유지했다. 코드 예제를 실행하거나 수업 자료를 검증하지 않았다.
