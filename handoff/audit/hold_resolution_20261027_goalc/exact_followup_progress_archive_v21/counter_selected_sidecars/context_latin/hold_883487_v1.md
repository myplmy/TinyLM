# 883487 원형 보류

원문에 있는 평탄화 코드 예시는 구조를 추정할 수 없어 그대로 보류한다.

> def eratos(upperBound): primes =  seq = range(2, upperBound + 1) while True: try: p = seq except IndexError: break seq = filter(p.__rmod__, seq) primes.append(p) return primes
>
> from itertools import count, ifilter def i_eratos(): seq = count(2) while True: p = seq.next() seq = ifilter(p.__rmod__, seq) yield p

원문의 `In our first example we use lists.`와 `The following example uses the same algorithm, but with Python “iterators” instead of lists.`에는 사라진 예제를 가리키는 표현이 있다. 본문에서는 그 포인터만 걷고 리스트/이터레이터 방식에 대한 실제 설명은 보존했다. 저자의 `Using this method I managed to generate more that 131.000 prime numbers, before Python crashed with a Segmentation fault message.`라는 자기 보고도 그대로 남겼으며 실행 결과로 확인하지 않았다. 코드·출력·정확도를 새로 만들지 않는다.
