# expanded_train:1258788 원형 보류

실제 책 내용인 다음 장의 명칭 `HTML Forms`와 Objects/클래스/API의 목차 명칭·원래 순서는 본문에 보존했다. 목차의 내용은 새 계층으로 재구성하지 않고 원래 평탄한 순서로 두었다. API 괄호와 비교 연산자도 유지했다. `>>`는 이동표식으로 분리했다.

## 분리한 일반 이동/사이트 UI

```text
Next chapter: HTML Forms >>
Table of Contents
Follow us on
Identi.ca or Twitter
Next chapter
```

첫 줄의 실제 장 이름은 본문에 보존하고 `>>` 이동표식만 분리했다. 말미에 별도로 남은 대상 없는 `Next chapter` 표식과 Follow us/소셜 계정은 UI/CTA로 분리했으며 실제 목차 명칭은 삭제하지 않았다.
