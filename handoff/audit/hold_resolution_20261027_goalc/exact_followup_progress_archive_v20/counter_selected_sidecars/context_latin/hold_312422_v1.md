# expanded_train:312422 원형 보류

원문 조각은 `onclick="document.getElementById('demo1').innerHTML = Date()">` 다음에 `Press me! I will display the current date and time.</button>`로 이어집니다. 실제 `onclick` handler의 호출·인수·대상 `demo1`·`Date()`와 표시문구는 새 본문에 원문대로 보존했습니다. 빠진 여는 `<button` 태그를 추정하지 않고, 그에 짝이 없는 `>` 및 닫는 `</button>` 태그껍질만 여기에 원형으로 둡니다. 실행 또는 HTML 완성 예제로 검증하지 않았습니다.
