# expanded_train:34440 원형 보류 및 복구 근거

- 원형 문구에는 `26 = 64`가 인쇄되어 있고 지수/위첨자 표식은 보이지 않는다. `26 =`라는 깨진 정식 표기만 원형 sidecar에 둔다. 이를 `2^6`으로 바꾸거나 새 식을 만들지 않는다.
- 원문이 직접 채운 `여섯 개의 점에 각각 두 가지 경우가 가능하므로 64가지 점자가 가능하다`는 자연어 조건/결과를 새 본문에서 보존했다. 64를 계산해 검증한 것이 아니라 원문에 실제 있는 결과를 candidate의 과잉 삭제에서 복구했다.
- 원형 `해당하는 점()`의 빈 괄호는 candidate가 정리했다. 2-4-5-6 위치 값/완결 설명, 8점의 7/8 배치, ASCII·Unicode 범위, 실제 같이 보기와 분류는 유지했다.
