# 175957 원형 보류

본문은 실제 작성자/게시 시각, Python 1.5.2와 2.0 예시, `%` 연산, 부동소수점 비교 질문 및 제안된 대안을 그대로 보존했다. 원문에는 링크 대상이 붙지 않은 두 이동 포인터가 있다. 후보가 분리한 첫 포인터와 새 본문에서 뺀 마지막 UI 문구를 아래에 원형대로 보존한다.

- `full story here:` — 뒤에 표적이 없음.
- `More information about the Python-list` — 본문 뒤의 일반 추가정보 이동 UI. `Python-list`라는 식별자만 원문 출처 메모에 보존하며 URL이나 링크 대상을 만들지 않는다.

코드 예시와 포럼 발화는 저자의 질문/설명 문맥이므로 불완전하다는 이유로 삭제하거나 실행 가능한 코드로 고치지 않았다.
