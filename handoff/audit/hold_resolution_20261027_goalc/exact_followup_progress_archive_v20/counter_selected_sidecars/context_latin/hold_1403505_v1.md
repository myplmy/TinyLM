# expanded_train:1403505 원형 보류 및 복구 근거

- 원문에는 `Check our two animations below:`라는 시연 포인터가 있으나 해당 두 시연의 내용은 없다. 원래 `Version 2.0` 꼬리는 짝이 되는 출력 없이 남은 라벨이므로 본문에서 분리한다. candidate의 `5-4-3-2-1 Hapy New Year! - Version 1.0`은 실제 채워진 출력 문자열 그대로 보존하며 철자도 고치지 않는다.
- `More Text-Based Animations` 표제와 `Visit this blog post to find the code for more text-based animations and start creating your own animations.`는 대상 링크가 없는 별도 탐색/CTA 문맥으로 분리한다.
- candidate가 삭제한 `This animation makes use of 10 procedures called one(), two(), three(),…, up to ten() ... stored in a module called myNumbers.`는 실제 절차 이름, 개수, 목적과 모듈명이 명시된 완결 설명이므로 새 본문에 복구했다. 실제 함수 표기의 `()`는 보존한다.
- countdown 조건과 `sleep()` 설명, 다른 실제 문구는 바꾸지 않았으며 코드 실행/출력 재현은 하지 않았다.
