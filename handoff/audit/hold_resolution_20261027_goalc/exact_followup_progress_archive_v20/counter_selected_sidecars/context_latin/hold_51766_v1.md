# expanded_train:51766 원형 보류 근거

- 원형 첫 문장의 `위도(緯度, )`에서 쉼표 뒤 병기 값은 비어 있다. 후보가 이 빈 슬롯만 제거한 처리를 유지한다.
- 후보에는 실제 내용이 없는 `각주` 표제가 남아 있어 새 본문에서 해당 빈 표제만 제거했다.
- 뒤의 `각`, `지도학`, `위선`, `측지학`, `항법`은 채워진 끝부분 라벨로 원래 순서대로 보존했다. `각`을 새 각주 내용으로 확장하거나 다른 라벨을 추정하지 않는다.
- 위도 정의/종류, 각도 범위, 2015년 기준 문장, 실제 한반도 위도·경도 값과 `같이 보기` 경도 항목은 변경하지 않았다.
