# 50964 원형 보류

후보가 삭제한 편제 구획은 실제 편제표/목록 값이 없어 직접 예고만 분리했다. 실제 역사 서술과 1944년/1945년 편제 차이를 비교하는 완결 문장은 본문에 유지했다. 원문의 채워진 설립·폐지 연도, 전쟁참전/부대 성격 분류 레이블은 본문 끝에 원문 순서대로 복원했다.

원형 편제 도입부:

> 편제
> 제1 체코슬로바키아 기갑여단은 다음과 같이 편제되었다.

비어 있던 이름 확장 슬롯은 원형 그대로 남긴다: `제1 체코슬로바키아 기갑여단()`; `프랑스 국내군(FFI, )`. 이 괄호들에 값이나 다른 이름을 생성하지 않는다.
