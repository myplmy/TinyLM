# expanded_train:852169 원형 보류 기록

원문 앞의 `|Skip Navigation Links|` 및 `|Exit Print View|`는 탐색/인쇄 UI 문자열이라 본문에서 분리했다. 원문의 `See attributes(5) for descriptions of the following attributes:`는 뒤따를 속성 표를 직접 가리키지만 그런 표가 없다. 표 내용은 생성하지 않는다. 실제로 채워진 man-page 명칭 `attributes(5)`는 본문에 원문 어휘로 `See attributes(5).`라고 남겼다.
