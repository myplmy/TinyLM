# expanded_train:1313860 원형 보류 및 복구 근거

- candidate는 질문 본문에서 `This is what it looks like:`와 작성자가 제시한 `>>>>mylist =`, `> for char in x:`, `> print mylist`를 삭제했다. 이는 reversing-string 질문의 실제 시도 예제이므로 새 본문에 원문 그대로 복구했다. 실행 가능성이나 저자의 정답을 새로 판정·수정하지 않는다.
- `More information about the Python-list`는 URL·서지 없이 이동을 권하는 말미 footer/UI 포인터라 sidecar에 보존하고 본문에서 분리했다. Python-list라는 실제 라벨은 이 메모에만 기록하며 주소를 만들지 않는다.
- 답변의 실제 `reverse()` 설명과 `reversed(x)` 예시는 candidate대로 유지한다.
