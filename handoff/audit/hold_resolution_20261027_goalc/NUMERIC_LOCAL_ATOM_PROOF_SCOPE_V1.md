# 수치 문자 정렬 표시의 국소 원형 대조

v1 검사는 문자 정렬 때문에 출생연도1941년을 분리한 뒤 원래1월을 남긴 경우에도 새1을 만들었다고 표시할 수 있다. 이전 진단과 반려는 그대로 보존한다.

| 안 | 처리 | 한계 |
|---|---|---|
| A | 모든 표시 자동 면제 | 실제 숫자 일부 삭제·부호 손실·새 값도 통과할 수 있음 |
| B | 모든 숫자 표시를 수작업으로만 재판독 | 안전하지만 이미 같은 원형에 있는 월일의 문자 정렬 오류도 계속 재검토함 |
| C | 동일 변경 블록 안의 완전한 수치 원자와 뒤 단위를 순서·중복 수까지 연결하고 나머지만 수작업 중재 | 원형 수치가 보존됐다는 좁은 증거이며 인물·사건 귀속이나 외부 사실 검증은 아님 |

선택C다. 전체 숫자/소수/부호를 하나의 원자로 다루고 연속된 값의 합치기·부분 취하기를 허용하지 않는다. 동일 변경 블록의 본문 수치 전량이 원문 수치의 순서 있는 부분수열이어야 증명한다. 다른 줄의 같은 숫자를 빌리지 않는다. 출처·대상·의미에 대한 기존 판독과 root의 개별 승인은 계속 필요하다. 정당한 사실 정정은 별도 정확 원문/본문 SHA와 1차 근거를 연결하며 이 검사로 자동 면제하지 않는다.

생산66개 코드·기존 검사·캐시·원형은 바꾸지 않는다. 총괄의 새 CPU 진단 도구와 의미 있는 회귀 시험만 추가한다. 진단/시험 통과는 모델 품질이나 학습 승인이 아니다.
