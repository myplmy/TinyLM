# 누적 보호 V4 하의 독립 대조 채택

이전 선택과 고정된 snapshot의 SHA를 먼저 확인하고 기존 선택 행을 정확히 보존한다. V4 계약과 모든 부모 별칭을 포함한 payload-open observer를 원문 접근 전에 활성화한다. 이전 V3 계약은 역사 근거로만 검산하며 현재 보호 판정을 대신하지 않는다. snapshot 오류가 있으면 새 채택을 진행하지 않는다.

서로 다른 작성 역할이 정확 원문과 후보를 전체 대조한 행에 기존 숫자·코드·Unicode·문체·순서·검수메모 검사를 적용한다. 본문과 리뷰 SHA를 고정한다. 개별 문맥 판정은 해당 원문·본문·리뷰 SHA와 실제 전체 문맥 판독 근거에만 적용하며 전역 검사를 완화하지 않는다.

숫자74의 두 신호는 기존 고정 근거의 정확 source/body 범위, 같은 숫자, 문맥 anchor와 두 제곱수·순서 조건을 검산한 경우에만 닫는다. 다른 ID나 숫자 변경에 재사용하지 않는다. 순서 보완은 기존 exact substitution 계약을 유지한다. 총괄은 학습 TXT를 작성하지 않는다.

선택은 캐시 채택이 아니다. 새 전체 원장과 독립 검산, 실제 캐시 생성과 consumer 검증이 끝나기 전에는 공식 HOLD 수치를 갱신하지 않는다. 작은 검토 묶음마다 대형 캐시를 만들지 않는 저장 계약을 함께 적용한다. 전체 정제·전량 사실검증·모델 품질·학습 허용으로 표현하지 않는다.
