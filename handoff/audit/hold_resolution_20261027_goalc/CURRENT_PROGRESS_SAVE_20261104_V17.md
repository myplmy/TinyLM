# 현재 정제 진행과 저장 범위

전체 정제는 RUN이며 완료·일시중지 상태가 아니다. 기존 다섯 Luna가 지정 원문을 읽고 실제 TXT/MD를 작성하며 총괄은 판단·검산·조정을 맡는다.

| 구분 | 실제 고정 저장 | 해당 단계 미저장 |
|---|---:|---:|
| literal 1차 | 1,793고유 / 2,597위치 | 0 |
| 필드·제목 1차 | 2,810 / 18,237고유 | 15,427 |
| 다른 유형 1차 | 입력·큐 준비 | 50,162 |
| 생년·사망일 독립 2차 | 2,707 / 2,707고유 | 0 |

1차 미저장은 65,589고유다. 생년 2차와 숫자 독립 검토 20건은 새 1차 원문 수에 더하지 않는다. 필드 첫 두 묶음은 각 512건 전량 저장했고 최신 9개 고정본의 연결 오류는 0이다. 작성 중이거나 고정 수집 이후의 리뷰는 이 수에 포함하지 않았다.

공식 cache3은 최초 HOLD 460,695위치 중 350,522처리 / 110,173잔여다. 새 리뷰는 아직 ROOT/roster·캐시 채택 전이므로 공식 HOLD 감소량에 반영하지 않았다. 새 개별 전체 HOLD 6원문 / 12위치는 이유와 원형 연결을 갖고 학습 후보에서 분리하기로 판단한 결과다. 전량 복구 불가능을 증명한 수가 아니다.

CPU 진단 V3는 2,720리뷰 / 2,714본문 범위에서 UTF-8과 검수 메모 검사를 통과했다. 원형 대비 끝 LF 추가 1,259건을 기록했고, 숫자 87문서 441원자·코드 4·Unicode 1·스타일 3·순서 349신호는 개별 문맥 판독 대상으로 남겼다. 최신 2,810개 전체의 의미·사실 통과나 학습 승인으로 읽지 않는다.

옛 숫자 V1의 412문맥요청은 406개 보존·근거 정정 2개·부분 HOLD 분리 4개로 출처에 연결했고, 별도 국소 증명 13개는 그대로 구분했다. 기존 C가 다른 작성자의 20원문을 독립 검토했고 총괄이 275표적·원형/본문 SHA·패킷 수를 대조했다. 이후 소실 전제·위키 함의 도식·숫자 결합·평탄화 수식 등 발견된 제한 보완은 실제 새 본문, 변경 밖 바이트, UTF-8/EOF와 다른 리뷰 행 불변을 검산해 고정본에 연결했다. 이는 해당 신호와 범위의 처리이며 전량 수학·과학 사실검증이 아니다.

느려진 구간의 기존 5시간 관측은 186.0→155.4건/시간으로 약 16.5% 감소였다. 문서 길이·난도·인원을 통제하지 않았다. 현재는 한 문서 19~33패킷의 긴 글, 소실 식·주체·표본 조건, 사전 삽입·코드·인용 경계를 다루고 신규 1차 판독 외 독립 검토·보완·저장에도 시간을 쓴다. 입력 잘림·경로·리뷰 오기와 총괄의 안내·출력·검산 오류도 재작업을 만들었다. 원인별 비중·하드웨어 저하·이후 계속 감속은 확인하지 않았다. 공식 HOLD가 움직이지 않는 집계 지연도 진척과 구분한다.

자체 초안 삭제와 EOF 절단 사고는 기록하고 원형·후보·initial 무결성, 미선택 실패 초안 보존, 실제 선택 수정본을 검산했다. 다른 문서 메모가 섞인 163020 보고는 실제 원형/후보 7,777자 바이트 동일을 확인해 자료 오류와 구분했다. 실패·오보고를 삭제하거나 검증 통과로 바꾸지 않았다.

이번 V17은 한국어 명시 로컬 저장용 중간 범위다. 저장이 끝나도 전량 큐 처리·계보/의미 검토·ROOT/roster·최종 별도 캐시/독립 consumer·전체 재계측·필요 정본과 최종 핸드오프를 계속한다. A–E와 추가 300M 학습 선결은 미완이다. GPU·모델·학습·설치·다운로드·보호 데이터/타 세션 전용 자료·원형/기존 캐시 삭제 덮기·push/PR은 범위에 포함하지 않는다.

수량·버전·SHA 정본은 POST_V15_SCOPE_DELTA_V1.json, 진단은 FIELD_BOUND_BODY_DIAGNOSTICS_COMPLETE_V3.json, 의미 검토와 실패 한계는 RESUME_PROGRESS_AND_SPEED_20261104_V15.md 및 개별 검산 receipt를 따른다. 현재 검증된 이전 커밋은 b9259eaba7de799086bec65df12302e5e133deb3이며, V17 실제 커밋 ID는 저장 receipt와 독립 검산 후 확정한다.
