# expanded_train:160179 — 원형 보류 메모

판정 대상은 TASK_008의 지정 원문·후보·세 연속 패킷에서 확인한 멱등성 문서다. 빈 식이나 미상 기호를 추정 복원하지 않았다.

## 원형에서 분리한 식·값 의존 구간

- 단항연산 일반 설명의 빈 식 직접 의존 꼬리: `즉 인 경우`; 절댓값 예의 빈 결과 포장 `만족한다: .`는 본문에서 포장만 제거했다.
- `단항연산 f, 즉 어떤 집합 S에서 자신으로 가는 함수의 멱등성은 S의 모든 원소 x에 대해` 다음에 식이 없고 `가 성립한다는 성질이다.`로 이어지는 정의식 전체. 단항연산 표제는 다음의 실제 멱등 함수 설명이 있어 본문에 유지했다.
- `항등 함수`와 `상수 함수` 표기 사이 및 뒤에 있던 빈 수식 슬롯. 두 실제 이름과 `모두 멱등성을 만족한다`는 명시 관계는 본문에서 연결해 보존했다.
- 멱등 함수 개수에 대해 원문이 예고한 조합식, `여기서 는 조합으로...` 설명, `kn-k은 ... 함수의 총수이다`의 모호한 식 설명. 이 부분의 조합 기호·식을 보충하지 않았다. 그와 별도로 원문에 실제 적힌 `n 원소 집합에 정의된 멱등 함수의 개수`와 n=0,1,2,...의 값 열거를 본문에서 연결해 보존했다: `1, 1, 3, 10, 41, 196, 1057, 6322, 41393, ...`.
- 이항연산 멱등원 정의의 `★를 S 위의 이항연산이라고 할 때... 멱등원은`과 `를 만족하는 S의 원소 x이다` 사이의 빈 식 직접 의존부.
- 이항연산 멱등성 설명 뒤 `즉 임의의 x ∈ S에 대해`와 빈 식을 받는 `가 성립한다는 것이다` 조각. 앞의 완결된 `S의 모든 원소가 멱등원` 설명은 보존했다.
- 함수 합성에서 멱등원이라는 설명 뒤 `즉`으로 시작해 빈 등식에 직접 의존하는 조각. 실제 집합·함수·합성의 명명된 관계는 문장으로 보존했다.
- 통계학 예: `통계학에서의 분산과 비슷한 다음과 같은 함수는 멱등성을 만족한다.`부터 평균이 7인 입력 예, 출력 `(-4, -1, 1, 1, 3)`, 평균 0 및 재적용 설명까지의 전체 블록. 정의식과 평균 기호가 빠져 있어 결과를 독립 주장처럼 남기지 않았다.

## 빈 표제와 포장

본문에 실제 내용이 이어지지 않는 `환의 멱등원`, `컴퓨터 과학`, `외부 링크` 표제는 제거하고 원형을 이 메모에 기록한다. 내용이 이어지는 `단항연산`, `함수`, `형식언어`, `다른 예`, `같이 보기` 표제와 설명·목록은 유지했다. 값 없는 별칭 포장 `멱등성(冪等性, )`, `멱등 함수()`에서 이름·뜻은 유지하고 빈 꼬리만 정리했다.
