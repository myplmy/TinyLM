# 496903 원형 보류

본문에서 분리한 원문 구간:

- `In order to deal with these servlet programming, we must import`
  `into our java program.`
- `You Might Also Like`
  `♦ About Author ♦`

첫 문장은 `import`의 대상이 빠져 있어 특정 패키지나 클래스를 새로 채우지 않고 분리했다. 마지막 두 줄은 실제 기사 설명·저자 이름이 없는 사이트 영역 표제이므로 학습 본문에 두지 않았다. 원문의 서블릿 설명, 세 인터페이스/클래스 목록, Myserlet.java 언급과 HTTP 설명은 원래 순서로 보존했다. 표기나 기술 사실은 외부 확인으로 교정하지 않았다.
