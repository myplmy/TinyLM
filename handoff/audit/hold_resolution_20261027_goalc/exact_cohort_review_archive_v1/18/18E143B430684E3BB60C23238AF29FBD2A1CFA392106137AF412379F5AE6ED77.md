# 1339952 원형 보류 v2

반복 `Edit`는 각 소제목에 붙은 페이지 편집 UI 잔재이므로 떼었다. 실제 제목은 유지했다.

누락된 이름 목록이 이어질 다음 두 문장만 본문에서 분리하고 원형을 보존했다. 뒤에 실재하는 `Object1`, `Object2`, `Object3`를 앞 목록으로 소급해 채우지 않았다.

> Suppose we have two more objects called
> Object3 and we want to load all three objects with one command.
> We then create a directory called mymod and we store three files called
> Object3.py in it.

`These files would then contain one object per file but this not required (although it adds clarity).`는 앞서 언급한 실제 directory/files 주제를 이어가는 독립 파일 구성 설명이므로 유지했다. 이어지는 `Object1`/`Object2`/`Object3` import, `__all__`, `Object2.py` 관계와 코드 표기는 원문 그대로다. 코드를 실행하거나 들여쓰기·개행을 더해 실행 가능한 예제로 재구성하지 않았다.
