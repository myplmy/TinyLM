# 1330597 원형 보류

1. 누락된 스크린샷/표시 대상을 가리키는 문구:
   - `You should see the following page:`
   - `The default Apache directory is:`
   - `If you need to have files accessible over web, you should place the files in that directory.`
   - `You should now be able to see the PHP info page that you just created:`
   - `Go back to your browser and enter the following:`
   값 없는 디렉터리 경로·페이지·주소를 만들지 않았다. 첫 Apache 확인 문장과 PHP 파일 생성·저장 안내는 남겼다.

2. MariaDB 보안 설정 단락에서 실행 명령이 빠져 그 명령의 실행 결과에 직접 의존하는 나머지 지침:
   - `To change this settings, we recommend running the following command:`
   - `This action will start a series of questions that you will need to answer in order to improve the security of your MySQL server.`
   - `Here is what you will need to do.`
   - MySQL root 암호, 새 MariaDB root 암호, 익명 사용자 제거, root 원격 접근 금지, test 데이터베이스 제거에 관한 이어지는 목록 전체
   - `Finally reload the database privileges and you are done.`
   빠진 명령을 보충하거나 어떤 다른 실행 대상으로 치환하지 않았다. 앞의 MariaDB 설치 설명과 이후 PHP 설치 절차는 보존했다.
