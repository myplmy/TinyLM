# expanded_train:26370 원형 보류 v2

이 파일은 `hold_26370_missing_formula_dependent_spans_v1.md`의 원형 인용을 더 정확히 적은 보완판이다. v1은 보존하고 본 리뷰에서는 이 v2를 근거로 연결한다. 판독은 original·candidate 전문과 packets 0001–0004, full_diff의 실제 논리 END까지 대조했다.

## 이진 해밍 부호 구성 전체

원형 direct-dependent span:

`이진 해밍 부호`
`다음 데이터가 주어졌다고 하자.`
` 2 이상의 정수 `
`그렇다면, 다음과 같은,  계수의  행렬 를 정의할 수 있다.`
`즉, 의 번째 열의 성분들은 의 이진법 표기의 성분들이다. 예를 들어, 일 때 는 다음과 같은 3×7 행렬이다.`
`이제, 를 패리티 확인 행렬로 갖는 이진 선형 부호`
`를 -이진 해밍 부호 또는 -해밍 부호라고 한다.`

미상 변수·차원·행렬·부호 이름과 예시 행렬이 모두 빠져 있어 이 구성 및 그 직접 예고를 본문에서 분리했다.

## 임의 진법 구성 전체

원형 direct-dependent span:

`임의의 진법의 해밍 부호`
`보다 일반적으로, 다음이 주어졌다고 하자.`
` 소수 거듭제곱 `
` 2 이상의 정수 `
`그렇다면, 유한체  위의 차원 벡터 공간  및 차원 사영 공간`
`을 구성할 수 있다. 다시 말해, 사영화 몫 함수`
`는 집합  위에 동치 관계를 정의하며, 그 동치류의 수는 다음과 같다.`
`이제, 각 동치류에서 임의의 대표원을 고를 수 있으며, 이 대표원들을 열벡터로 삼아  성분의  행렬`
`을 구성할 수 있다. 이 행렬을 패리티 확인 행렬로 갖는 선형 부호`
`를 진 -해밍 부호라고 한다.`

빠진 필드·차원·몫 함수·동치류 수·행렬·부호 값을 채우지 않았다.

## 확장 부호 및 성질의 불완전 절

원형: `해밍 부호에 모든 성분에 대응되는 (즉 일반적인) 패리티 성분을 하나 더 추가할 수 있으며, 이는 -선형 부호이다.`

본문에는 실제 패리티 성분 추가와 `확장 해밍 부호(擴張Hamming符號)` 명명을 보존하고, 미상 매개변수에 걸린 `이는 -선형 부호이다`만 분리했다. 원문에서 candidate가 제거한 빈 별칭 `擴張Hamming符號, `도 여기 기록한다.

원형: `해밍 부호의 거리는 3이다. 즉, 일반적으로, 소수 거듭제곱  및 양의 정수 가 주어졌을 때, 진 -해밍 부호는 -선형 부호이다. 특히, 거리가 3이므로, 해밍 부호는 각 부호어마다`

빠진 소수 거듭제곱·정수·진법·부호 매개변수에 의존하는 일반 선형부호 절만 분리했다. 채워진 거리 3과 오류 교정·검출 및 두 오류의 잘못된 복구 가능성은 본문에 남겼다.

## 가짓수와 최적성 전체

원형 범위: `가짓수` 표제부터 미상 소수 거듭제곱·동치류 크기·가능한 패리티 확인 행렬 수·유일성 및 서로 다른 3진 부호의 개수에 대한 직접 주장 전체, 이어지는 `최적성` 표제부터 미상 부호 매개변수·부등식과 끝의 `이다.`까지다. 값과 식이 없는 수량 주장만 따로 떼지 않고 해당 관계 전체를 분리했다.

## 예시의 빈 행렬·값 포인터

원형:

`생성 행렬과 표준형 패리티 확인 행렬은 다음과 같다.`
`이진 3-해밍 부호`
`가장 흔히 사용되는 해밍 부호는  이진 해밍 부호이다. 이 경우,  이진 해밍 부호의 생성 행렬과 표준형 패리티 확인 행렬은 각각 다음과 같다.`
`삼진 2-해밍 부호`
`위의 사영 직선 을 구성하는 의 동치류들은 다음과 같다.`
`이에 따라, 예를 들어 첫째 대표원들을 고르면, 삼진 2-해밍 부호의 표준형 패리티 확인 행렬은 다음과 같다.`
`그 표준형 생성 행렬은 다음과 같다.`

미상 부호·사영 직선·동치류와 빈 행렬에 직접 의존하는 위 예고 구간을 분리했다. 이진 2-해밍 부호의 삼중 반복 설명과 실제 전송·수신 조건은 본문에 유지했다. original의 빈 병기 `三重反復符號, `를 기록한다.

## 미상 특정 부호를 받는 역사 결론

원형: `해밍 부호, 특히  이진 해밍 부호는 오늘날에도 널리 사용되고 있다.`

어느 특정 이진 해밍 부호인지 빠진 대상에 직접 의존하므로 문장 전체를 분리했다. original 첫 문장의 빈 병기 `해밍符號, `도 candidate가 정리한 원형으로 기록한다.

## 비어 있던 표제와 정리한 괄호

original에만 있던 빈 `참고 문헌`, `각주`, `내용주` 표제와 candidate의 빈 `외부 링크` 표제를 기록한다. 실제로 채워진 참조주/분류 이름을 새로 만들지 않았다. candidate의 빈 괄호 정리를 유지했고, 역사 문장의 `벨 모델 V()`에서는 빈 괄호만 정리했다.
