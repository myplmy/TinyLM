# TASK009 새 본문 및 EOF 확인

- 다섯 초안은 허용된 자기 페이지 initial candidate 사본에서 `cp --no-clobber`로 만들었다.
- 249323: 제목의 빈 괄호만 본문에서 제거하고 빈 인구/기후 표제와 외부 링크·분류 꼬리를 분리했다. 본문 전체 차이와 마지막 도로/교통 문맥 및 EOF를 확인했다.
- 249346: 명명 생산 설명·인접 자치체·역사·교통을 유지하고 빈 제목 괄호, 빈 인구 표제와 외부 링크·분류 꼬리만 분리했다. 전체 차이와 본문 EOF를 확인했다.
- 249356: 실제 지리·역사·교통 문장을 유지하고 빈 제목 괄호, 인구 표제, 외부 링크·분류 꼬리만 분리했다. 전체 차이와 본문 EOF를 확인했다.
- 250085: 지정 0001–0003을 순서대로 판독해 원문 전체, 후보 연결, 최종 diff 끝을 확인했다. 새로운 본문 전체와 전체 diff/마지막 보존 문장을 확인했다. 조건이 비어 있는 정의·예시 문장만 sidecar에 원형 보존했다.
- 250831: 원문·후보·차이의 지정 패킷 전부와 최종 수정 전체를 확인했다. 잔여 빈 제목 괄호 외 작품 제목·작가 이력·조건·분류는 보존했고 최종 본문 EOF를 확인했다.
- 새 본문은 수치·사실·이름·조건을 새로 만들지 않았다. 차이는 지정 빈 별칭/표제/탐색 꼬리 또는 결손 정의문장에 한정된다.
- 후보와 비교해 249323, 249346, 249356, 250085, 250831의 새 본문 끝에는 LF가 추가되었다. 차이는 EOF 메타데이터로 기록했고 UTF-8 바이트 절단은 하지 않았다.
