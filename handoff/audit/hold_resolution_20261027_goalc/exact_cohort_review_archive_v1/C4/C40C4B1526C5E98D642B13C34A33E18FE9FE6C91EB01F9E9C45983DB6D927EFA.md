# expanded_train:55635 — RW/VW 문장의 주체를 원문 6-sensor 문맥에 연결

기존 선택의 다음 문장에서 일반 주어 `Results`를 사용했다.

> Results can be returned in one of two coordinate systems (see the next section): the real world's or the virtual world's. When requesting values relative to the virtual world, it is necessary to specify a user number, because if there are multiple users, they are each allowed to have their own virtual world coordinate system. If the application is designed for only one user, then it is reasonable to use 0 (zero) as the user number.

바로 앞 원문은 표준 FreeVR 6-sensor routines의 위치값과 그 좌표계 변환을 설명하고, Requesting the value of an input 단락도 six-sensors가 보고할 좌표계를 고른다고 명시한다. 따라서 새 본문은 관계를 그 명명된 6-sensor 값에만 연결했다. RW/VW·다중 사용자·user 0의 내용은 원문 그대로 남기며, 2009년 FreeVR 0.6a 문서의 빠진 API 이름/함수는 후대 문서에서 가져오거나 새로 만들지 않았다. 기존 원형 보류는 `hold_55635_v2.md`에 그대로 보존한다.
