# 829288 — 분리한 페이지 UI 원형

## 본문과 구분되는 문자열

- `You are visitor`
- `Back to Top` (본문 여러 지점의 반복 내비게이션 표기)
- `ELIJAH WHITEOFFICERSHISTORY 1863HISTORY 1864HISTORY 1865ROSTERPHOTOSGENERALS`

## 판단 근거

원문·candidate·전체 diff를 순서대로 대조했다. 본문은 35th Battalion의 날짜별 이동·작전·인명·부대·전투 및 사상 정보가 이어지는 하나의 역사 서술이며 candidate에서 유지된다. `You are visitor`, 반복 `Back to Top`, 말미의 연결된 메뉴 문자열은 방문자 상태/페이지 내비게이션 UI로 본문 사건에 속하지 않는다. candidate가 이 UI 줄만 제거했고, 본문의 날짜·이름·부대·사건 관계는 diff에서 삭제되지 않았다. 이 보류는 본문에 새 사건을 귀속하지 않는다.
