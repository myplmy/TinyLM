## 분리한 손상 예제

원문에서 완결된 `do.call("complex", list(imaginary = 1:3))` 뒤에 이어진 다음 구간은 R 주석과 여러 문장/호출이 구분자 없이 한 줄로 합쳐져 있어 실제 실행 단위와 결과 귀속을 확인할 수 없다. 새 줄 경계나 실행 결과를 추정하지 않고 이 직접 손상 단위를 본문에서 분리했다.

```text
## if we already have a list (e.g., a data frame) ## we need c() to add further arguments tmp <- expand.grid(letters[1:2], 1:3, c("+", "-")) do.call("paste", c(tmp, sep = "")) do.call(paste, list(as.name("A"), as.name("B")), quote = TRUE) ## examples of where objects will be found. A <- 2 f <- function(x) print(x^2) env <- new.env() assign("A", 10, envir = env) assign("f", f, envir = env) f <- function(x) print(x) f(A) # 2 do.call("f", list(A)) # 2 do.call("f", list(A), envir = env) # 4 do.call( f, list(A), envir = env) # 2 do.call("f", list(quote(A)), envir = env) # 100 do.call( f, list(quote(A)), envir = env) # 10 do.call("f", list(as.name("A")), envir = env) # 100 eval(call("f", A)) # 2 eval(call("f", quote(A))) # 2 eval(call("f", A), envir = env) # 4 eval(call("f", quote(A)), envir = env) # 100
```
