# 305234 빈 괄호와 미상 영유권 주장 주체 보류

빈 껍데기 원형 6곳:

- `세미소포치노이섬()`
- `누쿨라엘라에 환초()`
- `티콤비아섬()`
- `모알라섬()`
- `토토야섬()`
- `마투쿠섬()`

각 괄호 안에는 값이 없어 새 이름·좌표를 채우지 않고 괄호 두 기호만 분리했다. 섬·환초 명칭, 동서 방향, 경선 설명, 목록 순서는 그대로 유지한다.

원형 영유권 구절: `로스 속령, 가 영유권을 주장하고 있다.`

새 본문에는 명시된 `로스 속령`을 남기고 미상 주장 주체에 관한 절만 분리했다. 어떤 국가도 새로 지정하지 않는다.
