# expanded_train:323284 분리 원형

아래 Perl 예시는 여러 문장을 구분 없이 한 줄에 붙였고, `#` 주석이 뒤 내용을 흡수한다. 문장 경계와 주석 범위를 새로 만들지 않고 그 코드 줄 전체를 보류한다. `code2language()`와 `language2code()`가 실제 이름·인수와 함께 있는 별도 예시는 본문에 보존한다.

```text
use Locale::Language; $lang = code2language('en'); # $lang gets 'English' $code = language2code('French'); # $code gets 'fr' @codes = all_language_codes(); @names = all_language_names();
```
