# expanded_train:14076 원형 보류 경계

원문·candidate에 한 줄로 평탄화된 예제와 그 뒤의 출력:

    # File: smtplib-example-1.py import smtplib import string, sys HOST = "localhost" FROM = "firstname.lastname@example.com" TO = "email@example.com" SUBJECT = "for your information!" BODY = "next week: how to fling an otter" body = string.join(( "From: %s" % FROM, "To: %s" % TO, "Subject: %s" % SUBJECT, "", BODY), "\r\n") print body server = smtplib.SMTP(HOST) server.sendmail(FROM, [TO], body) server.quit()

    From: firstname.lastname@example.com To: email@example.com Subject: for your information! next week: how to fling an otter

문장·코드 줄 경계가 사라진 상태라 명령 경계/개행을 추정해 실행 예제로 복원하지 않았다. 출력도 이 손상 예제에 직접 붙어 있으므로 함께 분리했다. 모듈 소개와 SMTP 헤더·라우팅·수신자 인수의 독립 설명은 본문에 보존했다. 실행하거나 결과를 검증하지 않았다.
