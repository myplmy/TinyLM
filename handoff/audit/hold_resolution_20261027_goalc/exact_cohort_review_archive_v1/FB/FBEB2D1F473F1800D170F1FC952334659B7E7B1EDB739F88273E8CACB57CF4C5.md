## 사유와 경계

첫 두 줄은 `of datasets.`까지의 완결된 LightCurveEstimator 설명 뒤에 “available in”의 대상을 잃은 절과 주어를 잃은 `contains` 절이 붙은 형태다. 완결 설명은 본문에 남기고 미완 두 절만 분리했다. 표 예시·유틸리티 포인터의 목적어가 없거나, `SpectrumDatasetOnOff` 주변의 직접 설명/API 주어·함수명이 빠져 문장이 완결되지 않는 구간도 원형 보류했다.

명명된 LightCurve와 LightCurveEstimator 정의·클래스 역할, 실제 Table/LightCurve 및 LightCurveEstimator 예시 코드, `compute_chisq`, `compute_fvar`, `robust_periodogram` 이름과 실제 이어지는 정성 설명·조건·예시·목록 값은 그대로 보존했다. 빠진 API 이름·자료 대상·식은 만들지 않았다.

`source is the model component describing the source of interest` 절은 실제 명시된 설명이 완결되므로 마침표로 닫아 유지했다. 그 뒤 주어가 없는 `object produced by data reduction.` 조각만 보류했다. `Calculate the chi-square test for`는 이어질 대상이 없으므로 이 조각만 보류했으며, 뒤의 완결된 튜토리얼 제목은 보존했다. 예시 코드의 함수 이름 차이는 외부 지식으로 정정하지 않고 원문 그대로 두었다.

원형 구절은 이 sidecar에만 보존한다.
