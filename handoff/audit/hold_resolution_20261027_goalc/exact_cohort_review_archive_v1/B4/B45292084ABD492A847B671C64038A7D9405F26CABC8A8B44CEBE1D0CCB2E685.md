# 1392975 원형 보류

원문에서 값이나 예시가 실제로 채워지지 않은 다음 예고 표현만 분리했다.

1. `Bad name:` — 변수 이름의 나쁜 예를 예고하지만 예시가 없다.
2. `And if you se a call to a method like this:` — 불리언 인수 호출 코드 예고가 비어 있다. 뒤의 실제 설명은 보존했다.
3. `Examples:` — if/else, while, foreach, try catch의 코드 예시 예고가 비어 있다.
4. `and our methodcall could look like this:` — 빈 리스트를 반환하는 완결된 조건 설명 뒤의 호출 코드 예고가 비어 있다.

예시 코드를 추정하거나 생성하지 않았다. 3–6줄, 10줄, 3인수 한도 등 실제 수치와 나머지 완결된 설명을 본문에 보존했다.
