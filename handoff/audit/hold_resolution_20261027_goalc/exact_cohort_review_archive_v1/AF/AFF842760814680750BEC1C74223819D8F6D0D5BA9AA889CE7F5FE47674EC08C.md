# Hold: expanded_train:18131

판독한 원문에서 다음 두 조각은 함수 원형과 인수 설명의 코드 서식 경계가 무너져 있어 본문에서 분리했다. 헤더와 선언 사이에 줄바꿈을 추정해 복구하지 않았다.

```text
#include <pthread.h> void pthread_exit( void* value_ptr );
- A pointer to a value that you want to be made available to any thread joining the thread that you're terminating.
```

뒤의 완결된 설명은 `pthread_exit()`와 `value_ptr`를 명시하며 joinable/detached 조건, 정리 처리, 반환 상태, 마지막 프로세스 스레드의 `exit(0)`, 날짜를 보존했다. 이 분리만으로 누락된 함수나 다른 조건을 만들지 않는다.
