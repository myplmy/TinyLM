# 567926 별도 보류 원형

원문/후보는 자기 TASK_048 동일성 연결에 따른다. 아래 원형은 본문으로 선택하지 않은 조각이다. 본문에는 검수 표시를 넣지 않았다.

| 원문 범위 | 원형 | 처리 근거 |
|---|---|---|
| 3–6 일부 | `int dump`<br>`, caddr_t addr`<br>`, daddr_t blkno`<br>`, int nblk` | 함수 원형에서 괄호/첫 인수와 구분이 소실되어 실행 가능한 시그니처로 보이지 않는다. `dump` 이름과 각 변수명·타입을 추정해 재조립하지 않았다. `#include <sys/sunddi.h>`는 본문에 보존했다. |
| 7–11 일부 | `This entry point is required`<br>`. For drivers`<br>`that do not implement dump()`<br>`should be used.`<br>`Device number.` | 문장 연결 및 `Device number.`의 표적 필드명이 소실되어 있다. `nodev(9F)`를 여기 끼워 넣지 않았다. `illumos specific (illumos DDI).`와 뒤의 명시된 함수 참조는 본문에 보존했다. |
| 15–16 앞부분 | `is used to dump a portion of virtual address space directly to a`<br>`device in the case of system failure.` | 주어가 빠진 문장 조각이다. 앞 제목만으로 문장 주어를 생성하지 않았다. 같은 기능을 직접 명시한 완결 제목 설명은 본문에 남겼다. |
| 23 | `returns the status of the transfer.` | 반환 동작의 주어가 없다. 누락된 함수 이름을 보충하지 않았다. 앞의 완결된 addr/nblk/dev/blkno 설명은 보존했다. |
| 28의 끝 | `is called at interrupt priority.` | 호출 대상이 없는 미완결 절이다. 바로 앞의 명시적 SEE ALSO 참조 `ddi_in_panic(9F)`는 보존했다. |
| 29–30 | `RETURN VALUES dump()`<br>`on success, or the appropriate error number.` | 반환값/서술어가 빠져 있어 성공 값을 만들어 넣지 않았다. |

원문에 실제 적힌 `addr`, `blkno`, `nblk` 이름과 각 설명은 서로 맞닿아 명확히 대응하므로 그 순서 관계를 보존해 본문에서 항목별로 읽히도록 정리했다. 본문은 명시된 checkpoint 설명, 메모리 영역의 addr/nblk 정의와 dev/blkno 관계, timeout(9F)/delay(9F) 동작, SEE ALSO와 날짜를 유지한다.
