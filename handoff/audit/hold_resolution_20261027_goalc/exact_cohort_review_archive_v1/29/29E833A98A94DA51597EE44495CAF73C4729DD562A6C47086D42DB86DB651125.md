# 600574 별도 보류 원형

원문/후보 동일성은 자기 TASK_049 연결에 따른다. signature 조각과 페이지 UI만 별도로 보존한다.

| 원문 범위 | 원형 | 처리 근거 |
|---|---|---|
| API 페이지 header | `Syntax View Source` | `View Source`는 페이지 UI이며 완결된 API 내용이 아니다. |
| signature 조각 | `cSignedInt AS STRING`<br>`) AS LONG`<br>`public static int Bin2L(` | 언어/표기별 signature가 순서와 괄호가 깨진 채 섞여 있다. `Bin2L`의 이름, 입력 타입 및 반환값 표기를 선택·재조립하지 않았다. `Bin2L()`의 완결 설명은 본문에서 보존했다. |

본문에는 XSharp.Core 버전, 입력이 32-bit signed integer를 담은 문자열이며 little-endian 순서에서 첫 4바이트만 사용한다는 설명, long integer 변환 및 inverse `L2Bin()` 관계를 유지했다. `sales.dbf`, 바이트 4–7, 실제 코드 호출/인수와 원문 출력 `84`를 그대로 보존했다. 예제를 실행하지 않았다.
