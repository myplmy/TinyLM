# expanded_train:74078 직접 의존 결손 원형 보류

이 보류는 공식/그림/변수의 값을 복원하거나 사실 오류를 판정한 것이 아니다. 원문·후보에 빈 수식 슬롯이 있어 그 수식이나 그림을 직접 가리키는 조각만 본문에서 분리했다. 아래에는 분리한 원문 문구와 후보에 남아 있던 일부 같은 의존 문구를 기록한다.

## 그림에 직접 의존한 서술

- `붉은 선은 초기에 하중을 재하하여 압밀할 때의 유효응력-공극비 변화, 연두색 선은 하중을 제거하여 유효응력이 감소하면서 공극비가 커지는 것을 나타내는 선이다.`
- `하중을 재하했다가, 제거한 뒤 다시 재하하면 파란 선과 같은 곡선이 나타난다.`
- 평균압밀도에 관한 `이것을 그래프로 그리면 아래와 같다.`와 뒤의 색 범례 `빨강: 하단 일면 배수 / 파랑: 양면 배수 / 노랑: 하단 일면 배수`.

## 미분방정식·해·기호

- 기본 미분방정식 도입의 `가정을 만족하는 토체 내부의 임의의 한 흙 요소에 대해 연속성을 고려하면 다음과 같은 미분 방정식을 유도할 수 있다.` 및 `여기서` 아래의 기호 없는 과잉 간극수압·시간·방향·투수 계수·체적압축계수·물의 단위중량 표기. 식과 각 변수 소유가 비어 있어 식을 보충하지 않았다.
- 해 부분의 미상 초기/경계 식 원형: `일 때 (여기서 는 초기 과잉간극 수압)`, `및 에서`, `이때, 미분방정식의 해는 다음과 같다.` 뒤의 빈 식, 그리고 `과잉 간극수압, : 초기 과잉 간극수압 / : 정수 / : 배수 거리 / : 점토층 하단으로부터의 수직 거리 / : 시간 계수`의 기호 누락 줄.
- 미분방정식 도입에 붙은 압밀계수 차원 설명은 별도 완결된 명칭·값이어서 본문에 문장으로 보존했다. 같은 부분의 누락 기호 변수 목록 중 기호가 없는 `시간 계수`, `압축 계수`, `체적 변화 계수` 대응은 보류했다. 원문 `대한민국 국가 표준에는 방법 또는 방법을 사용하도록 되어 있다.`의 두 방법명도 빈 슬롯이므로 보류했다.
- 체적 변화 계수 아래의 원형 기호 목록 `: 압축 계수, : 초기 간극비, : 에서 간극비, e2: 에서 간극비`는 값의 대상/압력 조건이 빠져 있어 보류했다.

## 압밀도·시험 방법 식

- Casagrande 방법의 미완 `에서 수평선을 그려서 그래프와 만나는 점에 해당하는 가로축의 시간을 압밀이 50% 진행된 시간 이라 한다.` 및 기호가 없는 `압밀도 50%에 이르는 시간` 줄.
- Taylor 방법의 미상 가로축 변수와 직접 의존 문장 원형: `가로축을 로 하여 그래프를 그린다.` 및 `여기의 가로축 값이 이고 이 값을 제곱하면 t90을 얻을 수 있다.` 기울기 1.15배와 90% 교점은 채워진 설명이므로 본문에 남겼다. 원문 `1.15배()`의 빈 괄호만 정리했다.
- 압밀도 정의 뒤의 미상 기호와 직접 조건 줄, 빈 수식의 앞뒤 `위에서와 같은 조건의 점토층에 대해서`, 평균압밀도의 `다음과 같이 정의된다`와 빈 식, 침하량 기반 관계 뒤의 빈 식·무기호 침하량 정의 줄을 보류했다. 채워진 `t`, `e`, `σ`, `U` 설명 및 평균압밀도가 시간계수 T의 함수라는 문장은 본문에 유지했다.
- 압축지수 경험식의 완결 소개문 뒤에 있던 빈 `교란 점토 시료` 및 `불교란 점토 시료` 수식 슬롯은 값/식을 만들지 않고 원형 보류했다.
- 1차 압밀 침하량의 빈 공식 묶음 원형: `(정규 압밀)`, `(과압밀, )`, `(과압밀, )`, `과압밀, 인 경우 Cr이 작으므로 1항은 생략 가능하다.`, `(과압밀, , 1항 생략)`. 산식과 과압밀 조건이 유실된 관계절은 본문에서 분리했고, 명명 지수·초기 간극비·두께 조건은 계산 입력을 설명하는 독립 문장으로 보존했다.
- 2차 압밀에서 `... 다음과 같이 계산된다.` 뒤의 산식 슬롯은 비어 있어 수식을 만들지 않았다. 정의·유기질 흙의 상대 크기·무기질 과압밀 점토에 관한 한정과 실제 명명된 입력 조건은 본문에 보존했다.

## 빈 표제

원문 말미의 내용 없는 `주해`, `각주`, `외부 링크` 표제만 분리했다. 실제 참고문헌과 `토질역학` 분류는 남겼다.
