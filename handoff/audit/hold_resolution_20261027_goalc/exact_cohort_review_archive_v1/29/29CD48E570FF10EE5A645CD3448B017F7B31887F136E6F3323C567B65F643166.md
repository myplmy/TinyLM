# 755500 비본문 UI 원형

본문 중간에 동일한 탐색 UI 문자열이 다섯 번 반복된다. 아래 위치의 `Back to top`을 기사 본문에서 제외하고 원형을 보존했다. 각 항목은 해당 섹션의 설명/예시가 끝난 뒤 다음 섹션으로 넘어가기 전에 나온다.

1. `Back to top` — “Why So Vague?”의 이유 목록 뒤, “Some Examples of Vagueness” 앞
2. `Back to top` — “Some Examples of Vagueness”의 다섯 용어 설명 뒤, “The Value of Vagueness” 앞
3. `Back to top` — “The Value of Vagueness” 본문 뒤, “What's a Patient To Do?” 앞
4. `Back to top` — “What's a Patient To Do?”의 환자 제안 목록 뒤, “The Bottom Line” 앞
5. `Back to top` — “The Bottom Line” 본문 뒤, 저자 약력 앞

반복 위치와 페이지 이동 문구의 형태는 비본문 탐색 UI임을 보여 준다. 기사 본문, 모든 섹션 제목/내용, 마지막 Robert H. Shmerling 약력은 보존했다.
