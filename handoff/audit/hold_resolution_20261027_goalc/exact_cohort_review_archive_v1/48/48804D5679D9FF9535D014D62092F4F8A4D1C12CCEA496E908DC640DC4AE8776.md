# 50956 원형 HOLD

두 선언문 설명에는 실제 값이 빠져 있어 그 자리를 추정하거나 코드의 타입을 문장에 대입하지 않는다. 완결된 선언 코드와 주변의 일반 정의는 본문에 보존한다.

## Spirit.Qi 설명에서 제외한 구간

원문:

```text
As an example, the following code declares a
int as its synthesized
attribute, while expecting a single
as its inherited attribute (see the section about the Spirit.Qi
Rule for more information):
```

본문에는 앞선 일반 설명과 실제 완결 코드 `qi::rule<Iterator, int(double)> r;`를 유지했다. `while expecting a single ... as its inherited attribute`에서 빠진 유형은 보충하지 않았다.

## Spirit.Karma 설명에서 제외한 값 자리

원문:

```text
The example below declares a Spirit.Karma
rule consuming a
while not expecting any additional inherited attributes.
```

본문에는 이 문장을 값 없는 채로 남기지 않고 `consuming a` 절만 분리했다. 실제 코드 `karma::rule<OutputIterator, double()> r;`와 완결된 일반 설명은 유지했으며, `double`을 누락된 소비 속성 설명에 새로 귀속하지 않았다.
