# 200543 원형 보류 구간

## 입력과 판독
- 원문·후보·전체 diff는 TASK_016 지정 입력이며 원문 패킷 1–2, 전체 diff 패킷 3의 BEGIN/END 경계를 모두 확인했다.
- 원문과 후보는 동일하다. 아래 보류는 원문/후보에 실제 있던 구간을 학습 본문에서 분리한 기록이다.

## 보류 구간
1. 누락된 예제 코드를 직접 예고하는 문장: `In this Tutorial we want to describe you a code that helps you in understanding JDBC Insert Prepared Statement.` 본문에는 실제 코드가 제공되지 않으므로 예고 문장만 분리했다.
2. 준비문 설명 뒤의 손상된 메서드/값 설명 전체: `set The String( ) : Set String XXX is defined in prepared statement to substitute a value in the question mark placeholder as string,int .In the code, we substitute a question mark value as string.executeUpdate ( ) :This method provides you the numbers of affected rows in the table and execute the statement in a given code.` 여기서는 메서드 경계·인수·귀속이 끊겨 있어 이름이나 기능을 다른 호출에 연결하지 않았다.
3. 지원 요청/질문 모집 CTA: `If you are facing any programming issue, such as compilation errors or not able to find the code you are looking for.` 및 `Ask your questions, our development team will try to give answers to your questions.`

## 보존 경계
`class.forname( )`의 실제 원문 표기와 그 설명, `getConnection ()`, `prepareStatement ( )`, `executeQuery ( )`, `next ( )`의 실제 이름/채워진 설명, 예외 처리 설명, 이름·값 표는 유지했다. 손상된 문자열을 현재 API 지식으로 고치거나, 빈 예제 코드·새 결과를 생성하지 않았다.
