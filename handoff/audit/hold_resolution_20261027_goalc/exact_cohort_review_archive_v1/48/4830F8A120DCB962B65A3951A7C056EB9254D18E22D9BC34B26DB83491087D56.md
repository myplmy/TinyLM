# expanded_train:691590 원형 보류

아래에는 입력/예제 코드가 비어 있어 그 직접 예고나 결과로만 읽히는 원문 조각을 보존한다. 명령, 인수 또는 실행 결과를 추정해 본문에 보충하지 않았다.

## 비어 있는 예제 포인터

```text
For example, try writing this:
```

```text
Try typing:
or, for example, let's say we don't understand what went wrong with our print hello command above, we want specific information about the "print" command:
You'll get a long and complete description of everything the print command can do.
```

## 입력이 빠진 도움말 예제와 직접 결과

```text
Doing:
Will give us a list of all available modules.
```

이 입력에는 실행할 값이 명시되지 않았고, 바로 뒤 문장은 그 입력이 모듈 목록을 표시한다고 단정한다. 해당 출력 주장은 이 위치에서 독립적으로 확인할 수 없어 함께 보류했다. 뒤의 `q` 및 `dir()` 관련 명명 설명은 본문에 남겼다.

## 입력 예시가 빠진 출력 설명

```text
will print the result on the screen, but outside the interpreter, since there is no print command inside the function, nothing would appear on the screen. You would need to:
to have something printed.
```

첫 줄은 앞선 빈 `doing:` 예제의 직접 결과를 이어 쓰고, 마지막 조각은 별도의 빈 print 예제를 전제한다. 빠진 예제를 복원하지 않고 이 두 직접 의존 구간만 보류했다. 본문에는 인터프리터에서 명령 결과가 표시된다는 독립 설명과 `Read more about functions here.`를 남겼다.
