# 283056 출생연도 충돌 보류

원문 리드의 `1947년 6월 19일`과 분류의 `1949년 출생`은 같은 인물의 서로 다른 단정 출생연도다. 어느 쪽도 고르지 않는다. 후보는 두 연도를 본문에서 분리하고 실제 리드에 있던 `6월 19일`은 연도 없이 남긴다. 이 월일을 두 주장에 공통이라고 해석하지 않는다.

분리한 원문 조각:

> 존 랠스톤 소울(, CC, 1947년 6월 19일 ~ )
>
> 1949년 출생

실제 `CC` 표기, 오타·약칭이 아닌 채워진 인명·작품·연설·강연·상훈·인용과 생애 설명은 보존한다. 빈 `참고 문헌` 표제는 후보가 제거했으며 이를 되살리지 않는다.
