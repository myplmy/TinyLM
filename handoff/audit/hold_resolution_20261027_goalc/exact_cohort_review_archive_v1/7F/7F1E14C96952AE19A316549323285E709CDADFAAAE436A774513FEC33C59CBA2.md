# expanded_train:828403 원형 보류

원문에 `The various flags, which may be or-ed together, are:`라고 있으나 뒤에 플래그 목록이 없으므로 그 목록 도입만 분리했다. 함수 원형의 `flags` 인자와 뒤의 실제 `If non-zero, alter the operation of fparseln().` 설명은 보존했다.

반환 설명의 `otherwise,` 뒤에 실패 반환 문장이 없으므로 그 접속부를 제거했다. 성공 반환 설명은 완결된 문장으로 보존했다. `fparseln() function uses internally getline(3), so all error conditions that apply to getline(3), apply to`의 `so` 이하에는 적용 대상이 빠져 있고, 뒤의 `fparseln() may set errno ...`는 별도의 완결 문장이므로 `so` 이하만 보류했다. `fparseln()`의 실제 ENOMEM 설명과 함수의 첫 등장·날짜·플랫폼 표기는 유지했다.

보류 원형 조각:
- `The various flags, which may be or-ed together, are:`
- `otherwise,`
- `so all error conditions that apply to`에서 끝나며, 이어지는 `getline(3), apply to`까지의 적용 대상은 소실되어 있다.
