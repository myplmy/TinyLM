## 비어 있는 표와 빠진 인덱스 예시

원형:

열 값과 escape-character 대응이 없으므로 표 표제·열 이름·두 행을 모두 보류했다. 별도로 원문은 "Notice that the expression spam evaluates to the string value 'H', since H is the first character in the string 'Hello'. Remember that indexes start at 0, not 1. This is why the H’s index is 0, not 1."라고 적었다. spam을 산출하는 인덱스 식이 없어 이 예시 문장 전체는 보류하고, Hello의 첫 문자와 0부터 시작한다는 독립 설명만 본문에 남겼다.

원문에는 "The expression 'Zophie' evaluates to the string value 'p'. This 'p' string is just like any other string value, and can be stored in a variable. Type the following into the interactive shell:"도 있다. 'Zophie' 뒤에 필요한 인덱스가 없으므로 첫 문장과 이어지는 빈 입력 지시를 보류했다. 문자열 'p'를 변수에 저장할 수 있다는 일반 설명만 유지했다.

원문 line 50의 완결된 앞부분 "Notice that the expression 'Hello world!'[6:12] first evaluates to 'world!'"는 본문에 남겼다. 뒤의 "which is an indexing that further evaluates to 'r'."는 그 다음에 적용할 인덱스가 없어 원형 보류했다.

## 누락 출력에 직접 매인 나머지 조각

- 원문 line 43의 "...then Python will display an error saying that our index is “out of range”:"에서 마지막 콜론은 빠진 오류 출력을 예고한다. 5자 Hello와 인덱스 10 설명, 오류 조건은 본문에 보존했다.
- "Notice that -5 and 0 are the indexes for the same character."는 앞선 누락 예시의 문자열/문자에 의존하므로 보류했다. 뒤의 일반적인 양수·음수 인덱스 설명은 보존했다.
- 원문 line 74–75의 오류 화면 예고와 Python 2 실행/펭귄 문장은 그 화면을 직접 가리켜 보류했다. 같은 줄의 input() 차이와 Python 3 설치 URL은 독립 문장으로 보존했다.
- 원문 line 19의 expression 안내 및 line 20의 'Hello, ' + spam / 'Hello, Al' 설명은 원문 순서대로 본문에도 유지했다. 이 보류 목록에 포함하지 않는다.

이 기록은 빠진 코드나 실제 화면을 복원했다는 뜻이 아니다. 새 본문에는 검수 안내를 넣지 않았다.
