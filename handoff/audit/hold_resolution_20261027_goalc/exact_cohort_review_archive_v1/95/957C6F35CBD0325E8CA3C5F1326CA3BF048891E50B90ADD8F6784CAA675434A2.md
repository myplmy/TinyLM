# expanded_train:625 보류 원형

## 값 없는 병기 슬롯

- 행렬(行列, )
- 성분(成分, ), 원소(元素, ), 계수(係數, )
- 대각 성분(對角成分, ), 대각 원소(對角元素, )
- 정사각 행렬(正四角行列, ), 행벡터(行-, ), 열벡터(列-, )
- 행렬환(行列環, )

본문에는 이미 각 한국어 용어와 괄호 안 한자 표기가 채워져 있다. 빈 후행 병기 슬롯 및 그 구분 쉼표만 정리했고, 한자나 새로운 표기·정의를 추가하지 않았다.

## 빈 섹션 표제

- 참고 문헌
- 외부 링크

후보에서 이미 비어 있는 두 표제를 제거했다. 해당 표제가 가리킬 문헌이나 링크를 만들지 않았다. 실제 역사·어원 문장은 유지했다.

## 범위

후보와 새 본문의 차이는 위의 실제 빈 병기 슬롯 정리뿐이다. 수식이나 변수를 복원하지 않았다. 원문에 남은 수식 누락 설명은 별도 해석·복구 없이 후보대로 두었다.
