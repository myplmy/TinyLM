# 112940 보류 원형

- 탐색 UI 표식 `… Read More »`를 분리했다. 제목·정답이나 전체 글을 새로 만들지 않았다.
- 잘린 정의 조각 `Starting with any positive integer N, we define the Collatz sequence corresponding to N as the numbers formed by the following operations: N → N/2…`를 보류했다. 끝의 연산 규칙을 추정하지 않았다.
- `How many labelled Trees (please note trees, not…`는 원문에서 직접 보이는 두 번째 질문의 불완전 부분으로 분리했다. 같은 항목 앞의 완결된 spanning-tree 질문은 보존했다.
- `Consider below…`는 뒤에 오는 대상이 사라진 불완전 질문 예고로 분리했다. bool 형식에 관한 앞 문장은 그대로 남겼다.
- `In C, typedef is considered as a storage class like…`는 직접 비교 대상이 잘린 절로 분리하고 앞의 storage-class 설명은 보존했다.
- `Predict the output of following program.`은 지시 대상 프로그램이 없어 분리했다.
- ` (we will…`은 Atomic Operation 단락의 미완 괄호 조각으로 분리했다. 그 앞의 질문과 완결 설명은 보존했다.
- `and may have size different from that…`는 열거 상수 유형 설명에서 직접 목적어가 빠진 끝조각으로 분리하고, 그 앞의 C/C++ 유형 비교는 보존했다.
