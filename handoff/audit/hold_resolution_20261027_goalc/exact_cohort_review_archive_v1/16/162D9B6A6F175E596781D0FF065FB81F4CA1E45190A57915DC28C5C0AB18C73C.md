# 9623 — 원형 보류

원문에서 매개변수 설명의 이름/순서 대응이 없는 조각을 보존한다. 매개변수명을 추가하거나 PHP 서명을 외부에서 복원하지 않았다.

```text
The string to parse (e.g. returned from strftime()).
The format used in
date(e.g. the same as used in strftime()). Note that some of the format options available to strftime() may not have any effect within strptime(); the exact subset that are supported will vary based on the operating system and C library in use.
```

원문의 `respect the current locale set with setlocale() (`에서는 괄호 안 값이 소실되어 빈 여는 괄호만 분리했다. 완결된 locale 관계는 본문에 보존했다. 표의 실제 tm 필드명·범위·설명, 예제 코드/출력과 버전 조건은 원문 그대로 두었다.
