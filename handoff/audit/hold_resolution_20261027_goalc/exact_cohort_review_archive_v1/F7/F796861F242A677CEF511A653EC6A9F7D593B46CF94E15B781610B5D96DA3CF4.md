# 80183 보류 원형

## 빈 별칭/구분자

- 원문 도입에는 `클루브 아틀레티코 데 마드리드, S.A.D.(; 마드리드의 체육단, 스포츠 공개 유한 법인)`와 `알레티()`가 있다. 첫 괄호 안 실제 한국어 명칭은 보존하고 빈 선행 별칭 구분자만 정리했으며, `알레티`의 빈 괄호도 제거했다. 새 별칭은 만들지 않았다.

## 값이 빠진 필드 묶음

- `UEFA 구단 점수 순위 / 2022년 5월 29일 기준` — 실제 순위 값 없이 표제와 기준일만 남은 블록.
- `선수 / 현재 선수 명단 / 2023년 9월 1일 기준 / 그 외 계약 선수 / 2군 차출 명단 / 임대 선수 명단` — 선수 명단 표와 각 하위 값이 없는 블록. 명단이나 선수 값을 만들지 않았다.
- `기술진 / 출처: Atlético Madrid / 감독 / 회장` — 실제 기술진·감독·회장 값이 없는 필드 묶음. 이어지는 실제 `현 이사진`과 기재된 인물은 본문에 보존했다.
- `최근 시즌` — 뒤따르는 내용이 없는 표제.
- 원문에는 내용 없는 `각주` 표제도 있었으며 후보에서 제거된 원형을 여기에 보존한다.

각 표제/기준일/출처는 해당 누락 필드와 연결해 sidecar에 두었다. 대회·선수·임원에 관한 나머지 완결 본문, 수치·날짜·귀속은 선택 본문에서 유지했다.
