# expanded_train:1323673 보류 조각

후보는 원문과 바이트 동일이다. 누락된 객체 표현식이나 이름을 채우지 않고 다음 손상/비본문 조각만 분리했다.

- 비본문 탐색/화면 UI:
  - `|Skip Navigation Links|`
  - `|Exit Print View|`
- C++ 표준 인용에서 완성 객체/기반 객체 관계를 지정하는 손상 문장:

```text
If the virtual function call uses an explicit class member access and the object expression refers to the complete object of
xor one of that object's base class subobjects but not
xor one of its base class subobjects, the behavior is undefined.
```

  `x`와 `or` 사이 경계·대상 관계를 추정 복원하지 않았다. 인용의 앞선 완결 문장과 [class.cdtor] 서지 귀속은 본문에 보존했다.
- 빠진 비교 대상을 요구하는 미완 문장:
  - `Likewise, the B::~B() destructor calls B::release() rather than`
- 호출 대상이 빠져 문장 주체/상황이 불완전한 원문:
  - `At the time of the call to D constructor has not been entered, and the behavior of the under-construction object will be to invoke B::seize() rather than D::seize().`
  본문에는 그 뒤 명시된 `B::seize()`/`D::seize()` 비교만 완결 문장으로 보존했다.
- `as in this example` 두 참조는 본문에 예제가 없어서 제거했다. OOP50-CPP-EX1/EX2의 실제 조건·예외 설명은 본문에 남겼다.
- 잘린 부가 열: `||Checked by |`. `Clang`과 버전 `3.9`는 본문에 보존했고 누락된 검수자 이름은 만들지 않았다.
