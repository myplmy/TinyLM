# 31567 빈 필드 정리 근거

## 원형 조각

```text
쓰다주쿠 대학, 또는 츠다쥬쿠대학()은 일본 도쿄도 고다이라시에 있는 4년제 사립 대학이다.
1900년 여자 영학 주쿠()로서 개학
1933년 쓰다 영학 주쿠()로 개칭
1948년 학제 개혁으로 쓰다주쿠대학 설립(, 쓰다주쿠대학/쓰다주쿠대학)
저명한 동문
```

## 판정

- 후보가 lead의 빈 괄호 한 곳과 역사 연호 항목의 빈 괄호 두 곳을 제거한 것을 전체 diff에서 확인했다.
- 1948년 항목의 빈 병기 칸 앞 쉼표만 정리하고, 실제 두 표기와 순서를 보존했다. 두 표기가 반복되더라도 서로 다른 역할일 가능성을 추측해 하나를 제거하지 않았다.
- 내용이 없는 `저명한 동문` 표제만 분리했다. 실제 외부 링크의 `공식 사이트` 값과 나머지 본문·분류는 유지했다.
