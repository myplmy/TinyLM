# 739353에서 분리한 원형 보류 구간

## 원문 구간

`x = 5 # global variable def f(): print(x) # ok def g(): x += 1 # error, need to use "global x"`

## 이유

앞의 Q&A 질문, 오류 표시, 두 스코프가 다르다는 설명, 함수 안에서 `global x`를 쓰라는 답과 일반 설명은 보존했습니다. 이 뒤 조각은 `# global variable` 주석이 뒤의 함수 정의까지 같은 한 줄에서 삼키는 구조라 코드 경계를 원문만으로 복구할 수 없습니다. 주석 끝이나 함수의 줄 경계를 추정하지 않고, 이 혼합 조각만 원형대로 분리했습니다.
