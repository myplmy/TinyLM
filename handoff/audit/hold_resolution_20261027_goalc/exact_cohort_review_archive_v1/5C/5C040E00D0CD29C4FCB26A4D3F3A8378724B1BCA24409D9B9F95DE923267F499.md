# expanded_train:81312 보류 원형과 경계

원문에 없는 변수·기호·등식·함수·대상을 추정해 채우지 않았다. 아래 구간은 지정 원문에서 직접 판독한 원형이다.

## 정의 목록의 기호 의존 항목

```text
 자명환이 아니며, 임의의 에 대하여, 와  둘 다 가역원이 아니라면  또한 가역원이 아니다.
 자명환이 아니며, 임의의 원소 에 대해 가 가역원이거나, 아니면 가 가역원이다. (즉, 는 양쪽 아이디얼을 이룬다.)
```

각 문장의 미상 기호가 조건의 대상과 결론을 정하므로 두 항목을 분리했다. 나머지 명시된 극대 왼쪽·오른쪽 아이디얼 조건과 유한합 조건은 본문에 남겼다.

## 국소환 준동형의 수식 정의

```text
두 국소환 ,  사이의 국소환 준동형() 은 다음과 같은 함수이다.
 은 환 준동형이다.
 이다.
```

미상 환·함수·조건의 기호를 만들지 않았다. 바로 뒤의 명시 문장 `국소환들과 국소환 준동형들은 범주를 이룬다.`는 독립적으로 남겼다.

## 몫환 및 누락된 표수 관계

```text
(비가환일 수 있는) 국소환 에 대하여, 몫환 은 항상 나눗셈환이다. 만약 가 추가로 가환환이라면, 몫환 은 체이다.
 국소환의 몫환은 국소환이다.
구체적으로, 가환 국소환 가 주어졌을 때, 와 의 표수는 다음 4가지 가운데 하나이다. 여기서 는 임의의 소수를 뜻한다.
인 경우를 동표수 국소환(同標數-, )이라고 하며, 아니면 형의 혼합 표수 국소환()이라고 한다. 가 동표수 국소환인 것은 가 어떤 체를 부분환으로 포함하는 것과 동치이다.
```

몫의 대상·아이디얼과 표수 비교 대상·경우·값이 소실된 직접 의존 구간을 보류했다. 본문에는 완결된 일반 표수 범위와 완비화에 대한 채워진 닫힘 성질을 유지했다.

## 분류의 누락 기호 의존 구간

```text
가환 국소환 이 주어졌다고 하자. 이 경우, 의 에서의 국소화  역시 국소환이다. 이렇게 얻어진 국소환을 가환 완비 국소환이라고 한다. 가 정칙환인 것은 가 정칙환인 것과 동치이다. 의 표수는 의 표수와 같으며, 의 잉여류체는 의 잉여류체 와 같다.

가환 완비 국소환 의 계수환()은 다음 성질들을 모두 만족시키는 부분환 이다.
 는 가환 완비 국소환이다.
 의 잉여류체 의 사영 사상  아래의 상은 이다.

뇌터 가환 완비 국소환 가 주어졌을 때, 코언 구조 정리에 따르면 다음이 성립한다.
 는 적어도 하나의 계수환 를 갖는다.
 만약 가 동표수 국소환이라면, 이게 놓을 수 있다.
 만약 이 개의 원소 로 생성되는 유한 생성 아이디얼이라면, 가 되는 -아이디얼 이 존재한다.
 특히, 만약 가 뇌터 환이라면 은 유한 생성 아이디얼이며, 위 조건이 성립한다.
 특히, 만약 가 추가로 동표수 정칙 국소환이라면, 이다.
여기서
 은  계수의 개의 변수에 대한 형식적 멱급수환이다.
```

누락된 국소화 입력·점·계수환의 정의 대상·사영·잉여류체·아이디얼과 형식적 멱급수환의 기호가 적용 범위와 관계를 정하므로 이 블록을 분리했다. `계수환은 유일하지 않을 수 있다.`와 그 앞의 완결된 코언 구조 정리 소개는 본문에 남겼다.

## 기호 누락으로 직접 규정되는 군환 주장

```text
양의 표수 의 체  및 p-군  가 주어졌을 때, 군환 는 국소환이다.
```

표수·체·군환의 기호와 대응이 빠져 있어 주장 전체를 분리했다.

## 빈 서지·외부 링크 표제

원문에 값이 없는 `참고 문헌`과 `외부 링크` 표제 및 외부 링크의 빈 슬롯을 기록한다. 실제 `같이 보기`의 채워진 항목과 분류명은 본문에 유지했다.

## 본문에서 기호만 정리한 일반 예

```text
가환환 의 임의의 소 아이디얼 에서의 국소화 는 국소환이다.
(비가환환일 수 있는) 환  위의 왼쪽 가군 의 자기 사상환 이 국소환이라면, 은 분해 불가능 가군이다. 반대로, 만약 이 유한한 길이를 가지며 분해 불가능 가군이라면, 자기 사상환 은 (비가환환일 수 있는) 국소환이다.
체  위의 2×2 행렬환 은 유일한 (극대) 양쪽 아이디얼 을 가지지만, 극대 왼쪽 아이디얼 또는 극대 오른쪽 아이디얼은 유일하지 않으며, 따라서 국소환이 아니다.
```

이 구간은 원문에 실제 명시된 소 아이디얼의 국소화, 왼쪽 가군과 자기 사상환의 관계, 2×2 행렬환의 반례를 그대로 남기고 빈 기호 슬롯만 문법상 연결했다. 새 기호나 추가 조건을 만들지 않았다.
