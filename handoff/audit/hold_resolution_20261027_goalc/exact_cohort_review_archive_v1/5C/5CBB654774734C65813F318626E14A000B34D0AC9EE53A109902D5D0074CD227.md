# 149473 보류 원형 및 경계

판독 입력은 TASK_028의 Vim 원문 전문 패킷 0001–0003이다. 원문과 지정 candidate는 V2 계획에서 실제 바이트 동일로 연결되며, 최종 full_diff의 END까지 읽었다. 이 동일성은 내용 적합성 판정 자체가 아니다.

아래 조각은 원문 그대로 보류한다.

- and put it into the buffer using / 이어지는 You should see:: 앞 예시의 명령 또는 기대 결과가 완결되지 않았다.
- call setline(".", @a) or call append("$", @a) 뒤의 You should see:: 기대 출력이 빠져 있다.
- A useful function in this context:와 :echo strtrans(@a) a^@b: 명령과 출력의 경계 및 결과 귀속이 평탄화되어 있어 양쪽 모두를 생성적으로 구분하지 않는다.
- In this case:: 예시 도입만 남아 있어 보류한다.
- let @a = substitute( "a\rb", '\r', '\r', 'g' ) call setline( "$", @a ) a<0d>b: 두 호출과 출력이 한 줄로 평탄화되어 있어 실행 코드로 재구성하지 않고 전체 원형을 보류한다.

새 본문은 이 조각들만 제거하고, 줄바꿈/NULL의 Vim 설명, 실제 명령 및 함수명, 질문과 뒤의 완결 설명은 후보대로 보존한다. 누락된 예시 결과나 코드 경계는 만들지 않는다.
