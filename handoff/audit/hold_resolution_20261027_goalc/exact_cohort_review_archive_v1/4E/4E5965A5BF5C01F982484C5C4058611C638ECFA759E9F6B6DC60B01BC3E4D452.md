# expanded_train:68526 원형 보류 조각

이 기록은 지정된 원문·후보·전체 diff를 대조해, 새 본문에서 분리한 실제 원형만 보존한다. 목록의 인명·관계·날짜·수치·표 값은 외부 검증하거나 새로 귀속하지 않았다.

## 분리한 원형과 경계

- 빈 소제목: `방송 시간`, `출연 패널 결정 방법`, `각주와 인용`, `외부 링크`. 지정 본문에서 각 제목 아래 실제 항목이나 설명은 확인되지 않았다.
- 명단 소개에서 화면 서식에 직접 의존하는 부분: `지명도나 출연횟수가 다른 패널에 비해 상대적으로 낮은 패널의 이름은 회색으로 표시되었다.` 및 `이름의 굵은 글씨는 방송에서 공식적으로 부르는 통칭이며,`. 이 원형은 화면의 회색/굵은 표시를 설명한다. 그 뒤 실제 이름 표기 원칙인 `전체 이름이 알려진 경우에는 방송에서 이름을 줄여쓴다 하더라도 전체 이름으로 표기한다.`는 새 본문에 남겼다.
- 불완전한 명단 구간: `나타샤 코스티나(Natasha Kostina,키릴 문자 :Наташа Костина, 퇴테 문자:)`의 값 없는 `퇴테 문자:` 슬롯; `캐서린 디워 베일리(Catherine Dewar Baillie) →에서 출생,  에든버러에서 성장.`의 `→에서 출생` 구간; `아나이스 크리스틴 줄리엔 →친할머니가 인`; `피나 세너(Pınar Şener) →부모가 인.`; `서 마사키(서정수(徐正樹), 일본명:)`의 값 없는 `일본명:` 슬롯.
- 서지 항목의 빈 괄호 원형: `《쿵후 소년 장비》- 손요 저, 김지민 그림 ()`; `《도키나와 코코로》- 후지타 사유리 저, 신용현·김지영 공역 ()`; `《Schlaflos in Seoul: Korea für ein Jahr》(서울의 잠 못 이루는 밤)- 베라 홀라이터 저, 독일어로 출간되었음. ()`; `《서울의 잠 못 이루는 밤 : 한국에서의 일 년》- 베라 홀라이터 저, 김진아 역. 한국어로 번역되어 출간되었음. ()`. 채워진 제목·저자·역자·출간 언어 설명은 본문에 보존했다.

## 선택한 처리

새 본문은 위 빈 슬롯·화면 서식 의존 문구·불완전 관계절만 분리하고, 패널 이름과 실제 설명, 명단 순서, 날짜·수치·귀속, 책 제목/저자/번역자 및 시청률 표의 축과 14개 값을 보존한다. 표에 이미 있던 행/열 구조를 닫기 위해 마지막 시청률 행 뒤에 `|}`를 추가했다. 표 수치·열 의미는 바꾸지 않았다. 전체 원문과 추출 구조가 완전히 복구됐다고 주장하지 않는다.
