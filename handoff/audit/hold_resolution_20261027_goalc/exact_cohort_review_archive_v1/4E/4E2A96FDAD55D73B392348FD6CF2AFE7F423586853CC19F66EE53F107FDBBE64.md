# 650891 원형 보존 메모

## 빈 좌표·주석 포장

원문에 들어 있는 위치/좌표 괄호와 표기는 다음과 같다.

```text
스코틀랜드 포울라 섬 (at )의 바로 동쪽을 지남
스코틀랜드 애버딘 ()의 바로 동쪽을 지남
잉글랜드 — 베릭어폰트위드 ()와 버밍엄 주 서부 ()를 지남
코탕탱 반도의 바로 서쪽을 지남 ()
```

각 행의 실제 지명·완결 방향/통과 관계는 본문에 유지한다. 포울라 행의 `(at )`는 빈 좌표값 표시만 이곳에 보존하고 값은 채우지 않는다. 실제 빈 괄호는 빈 주석 포장으로 원형 보존한다. candidate가 베릭어폰트위드/버밍엄 행의 빈 괄호를 먼저 제거했지만 original 원형을 여기 기록했다.

## 대상을 잃은 영국 해협 관계절

원문 셀의 연속 구간은 다음과 같다.

```text
코탕탱 반도의 바로 서쪽을 지남 ()  섬의 바로 동쪽을 지남 ()
```

코탕탱 반도 서쪽 통과는 완결된 명명 지형 관계이므로 본문에 남겼다. 뒤 `섬의 바로 동쪽을 지남 ()`은 섬 이름/대상이 소실된 관계절이므로 그 관계절을 통째로 보류한다. 인접 지명으로 섬을 특정하지 않는다.

## 미상 영유권 주체가 있는 관계절

원문 남극 행 주석은 다음과 같다.

```text
퀸모드랜드, 가 영유권을 주장한다.
```

`퀸모드랜드`는 지명으로 본문 표에 보존한다. 주장 행위자가 없는 관계절은 원형대로 분리하고 국가/주체를 추정하지 않는다.

## 판독 범위

지정 original/candidate 전문과 순서 패킷 0001을 BEGIN부터 END/EOF까지 대조했다. candidate의 전체 diff에는 베릭어폰트위드와 버밍엄 주 서부의 빈 괄호 삭제만 있었다. 새 본문은 실제 지명, 방향, 거리와 사막 위치 설명을 유지하고 위의 빈 포장·미완결 관계절만 분리한다.
