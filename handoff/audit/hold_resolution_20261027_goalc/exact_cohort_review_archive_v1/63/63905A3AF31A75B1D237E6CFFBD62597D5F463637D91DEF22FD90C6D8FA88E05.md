# 169893 — 없는 WebDriver 코드·결과를 가리키는 조각

## text 결과 예제

> So if we took the HTML above and the following code
> it would return ‘I’m Richard’. As that is all the text between <p> and </p>.
> So we’d get
> I'm Richard I created this course

HTML 조각과 일반 동작 설명은 본문에 남겼다. 실제 WebDriver 호출 코드가 없는 상태에서 바로 그 코드의 출력이라고 하는 예고/결과만 분리했다.

## SendKeys 결과

> This would result in WebDriver looking for an element with the ID of ‘firstname’ and if it finds it, it’ll try and type ‘richard’ into it.

앞선 본문에 대응하는 호출 코드는 보이지 않으므로 구체 ID·문자열을 가진 결과 설명을 원형 보류했다. `SendKeys()`의 채워진 사용 설명과 키 입력 설명은 유지했다.

## attribute 결과

> This would look for an element with the id ‘firstname’, and return the value in the attribute input.

호출 예제가 없는 직접 결과 문장만 분리했다. `getText()`와 value 속성의 비교, WebDriver 속성 설명 및 명명된 `getTitle()`/`getCurrentUrl()` 내용은 유지했다.
