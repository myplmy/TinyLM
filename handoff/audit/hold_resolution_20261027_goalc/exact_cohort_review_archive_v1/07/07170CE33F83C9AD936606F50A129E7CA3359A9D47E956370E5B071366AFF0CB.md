## 손상된 예제 코드 줄

다음 원문 코드 줄은 주석 경계가 같은 평탄화 줄 안에 있어 이후의 코드 문자가 주석에 포함되는 형태로 남아 있다. 줄바꿈이나 연산 의미를 새로 복구하지 않고 예제 단위 그대로 보류한다.

- `int x = 1 ; int& rx = x ; optional<int&> ora ; optional<int&> orb(x) ; ora = orb ; // now 'ora' is bound to 'x' through 'rx' *ora = 2 ; // Changes value of 'x' through 'ora' assert(x==2);`
- `int a = 1 ; int& ra = a ; int b = 2 ; int& rb = b ; ra = rb ; // Changes the value of 'a' to 'b' assert(a==b); b = 3 ; assert(ra!=b); // 'ra' is not rebound to 'b'`

본문에는 완결된 일반 C++ 참조 대입 설명, 초기화된 optional reference 대입에 대한 완결된 원문 문장, 그리고 실제 코드 표기 `optional<int&> a = get(); int x = 1 ; int& rx = x ; optional<int&> b(rx); a = b ;` 및 그 바로 뒤 질문을 유지했다. 이 코드 조각을 실행 가능한 전체 프로그램이라 주장하지 않으며 `get()`의 정의나 누락 대상을 만들지 않았다.
