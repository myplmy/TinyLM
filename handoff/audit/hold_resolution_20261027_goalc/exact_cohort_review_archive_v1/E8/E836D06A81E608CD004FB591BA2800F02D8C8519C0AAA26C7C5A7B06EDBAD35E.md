# 321265 — 원형 보류

원문 리드와 생애는 출생 1877년, 사망 1947년을 적지만 말미 분류는 `1887년 출생`, `1920년 사망`으로 서로 다른 연도를 단정한다. 출생·사망 각각의 상충 연도를 외부 판단으로 선택하지 않고, 말미의 두 분류를 원형대로 보류한다.

본문에 명시된 `70세로 사망할 때까지`는 원문 나이 표현이므로 보존하며 출생·사망 연도로 새 계산이나 수정하지 않는다. 이름 뒤 빈 괄호와 하랄드 보어 뒤 빈 별칭 포장, 값 없는 `각주`·`외부 링크` 표제는 후보에서 정리되었고 실제 명명된 이름·날짜·경력·서지는 유지된다.
