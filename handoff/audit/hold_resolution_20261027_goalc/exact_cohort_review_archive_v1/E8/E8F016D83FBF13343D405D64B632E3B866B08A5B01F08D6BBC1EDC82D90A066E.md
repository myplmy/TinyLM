# validation:1750 원형 HOLD

## 보류 원문

```text
, using the command
The applet runs in Kawa 5 and ie6 but only prints one asterisk per integer i.e. if I enter 6 the applet shows
using the
For example:
Notice I've left out the num5...or it'll get printed however many times the for() loop specifies AS WELL.
```

## 이유

첫 세 구절은 각각 비어 있는 명령, 출력 결과, 사용 조건 포인터다. 입력 6·Kawa 5·ie6·애플리케이션에서 작동한다는 실제 주장은 본문에 남기고 보이지 않는 명령/출력/후속 값을 만들지 않았다. 답변의 `For example:` 뒤에 예시 코드가 없으므로 그 예고와 빠진 코드의 num5 생략을 직접 가리키는 설명만 분리했다. x좌표를 바꾸라는 완결 지시와 이어지는 숫자 문자열/별표 배치 설명, 실제 `drawString` 및 반복 조건·다섯 입력 논의는 보존했다.
