# 46969 빈 이름 슬롯

원문에서 실제 이름 뒤에 값 없는 괄호 슬롯이 두 곳 확인되어 괄호만 정리했다.

- `벨라루스어()` — 제목의 실제 언어명은 보존.
- `Byelorussian — 나라 이름 «Byelorussia» ()에서 나온 형태.` — `Byelorussia`라는 실제 표기는 보존하고 빈 병기만 제거.

Belarusian/Belarusan/Byelorussian/Belorussian의 실제 표기·설명, 로마자 상용 표현과 한국어 뜻, 사용 지역·언어 계통 등 나머지 본문은 유지했다. 빈 슬롯에 새 이름·언어·발음을 추가하지 않았다.
