# 257919 원형 보류 근거

## 학습 본문에서 분리한 결손 의존 조각
- `알리프가 성문폐쇄음을 나타낼 경우, 함자를 알리프 위(모음 ) 또는 밑(모음 )에 첨부하는 식으로 해결했다.`
- `함자가 붙지 않는 경우의 알리프의 발음은 다음과 같다.`와 그 아래 장모음·성문폐쇄음/장모음·탄윈·무음 목록. 발음값·문자 형태가 비어 있어 목록의 각 항목을 복원하지 않았다.
- `알리프와 같은 발음을 가지는 문자로가 있다.` 및 `음가로는 를 가진다.`처럼 빠진 대상/값에 직접 의존하는 부분. 야(ي)와의 모양 유사성은 독립된 원문 정보로 남겼다.
- `기원으로 볼때, 알리프 마끄수라는  와 같은 문자로` 비교 구절. 비교 문자를 만들지 않고, 원문에 이어 실제 명시된 오래된 철자와 /j/ 표기 설명은 유지했다.
- `한편, 음은 전혀 다르나 모양새가 똑같은 문자로`라는 비교 도입. 뒤에 원문에 이름과 글리프가 있는 페르시아 문자 설명은 비교를 주장하지 않는 독립 문장으로 유지했다.
- `결합 형태` 아래 `알리프가 ل의 뒤에 올 때(람 + 알리프, [-la-])에는 의 모양으로 합자된 형태로 쓴다.` 및 `부호 위치` 아래 단독 `أ`: 모양 대상/설명 연결이 비어 있어 원형을 분리했다. 내용이 남지 않는 해당 표제도 본문에서 제거했다.

## 보존 경계
리드의 실제 이름 `알리프 또는 알레프`, 히브리 알레프(א)·그리스 α·로마자 A 대응, 꾸란/함자 관련 완결 서술, 여섯 연결 비대상 문자 설명, 알리프 마끄수라의 실제 야(ي) 모양 관계·이름 뜻·단어 끝/표준 아랍어 조건, 나바테아 문자 관련 완결 문장, 페르시아 문자 ى 설명과 Unicode 이름·코드 관계를 유지했다. 누락된 모음값·비교문자·글리프·IPA를 외부 지식으로 보충하지 않았다.
