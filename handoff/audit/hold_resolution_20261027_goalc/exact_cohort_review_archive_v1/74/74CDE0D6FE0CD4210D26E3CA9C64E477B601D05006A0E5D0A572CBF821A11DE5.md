# expanded_train:673607 — 원형 보류와 수정 경계

- 모델 설명의 원문 끝: `Models are set up automatically, so you don't have to deal with them unless you want to take advantage of the power they can`. 본문에는 여기서 완결되는 앞 정보만 남겼습니다.
- 스레드 안전 호출의 원문: `Two JComponent methods are safe to call from any thread: repaint` 및 `These methods queue requests to be executed on the event-dispatching thread.` 단 하나의 메서드명만 제시됐고 뒤의 복수 지시가 목록 누락에 직접 기대어 있어, 본문에는 실제로 식별되는 `repaint` 안전 관계만 남겼습니다.
- 빠진 두 메서드 이름에 직접 연결된 원문: `The SwingUtilities class provides two methods to help you run code in the event-dispatching thread:` / `Requests that some code be executed in the event-dispatching thread. This method returns immediately, without waiting for the code to execute.` / `Acts like invokeLater, except that this method waits for the code to execute. As a rule, you should use invokeLater rather than this method.` 메서드명을 생성하지 않았습니다.
- 빈 WindowConstants 목록 예고: `The argument to setDefaultCloseOperation must be one of the following values, which are defined in the WindowConstants interface (which JFrame implements):` API 이름/목록은 추가하지 않았습니다.
- 미완 코너 설명: `A corner component is visible only if both sides that intersect at that corner contain visible`. 코너의 대상 값을 만들지 않았습니다.
- 빈 메서드 목록 예고: `The Scrollable interface includes the following methods:` 실제로 적힌 Lists/Tables/textComponents/trees 설명은 본문에 유지했습니다.
- 주체가 없는 boolean 설명: `boolean : Determines whether the component repaints as the user drags the split pane.` 속성명은 채우지 않았습니다.
- 지시 대상이 고정되지 않은 문장: `It uses BoxLayout as its layout manager and hence can have its components call setAlignmentX, setAlignmentY etc.` antecedent를 임의로 보충하지 않았습니다.

- 겹치는 표 행 뒤의 미완 절: `The root pane adds the menu bar and content pane to its layered pane at`. 다음 DEFAULT_LAYER 행을 이 절의 값으로 새로 귀속하지 않았습니다.
- 끝난 대상/목록이 없는 HTML 변환 도구 구절: `There are tools that generates this new tags from <APPLET>`. 도구명이나 태그를 만들지 않았습니다.
- JOptionPane의 빠진 overload 인수/행 경계 원형: `int showMessageDialog(Component, Object, String, int,` 및 두 번 반복된 `int showConfirmDialog(Component, Object, String, int,`. 앞의 온전한 서명과 완결된 설명은 본문에 남겼습니다.
- 온전한 인수 목록 뒤에 닫는 기호가 빠진 원문: `|int showOptionDialog(Component, Object, String, int, int,Icon, Object, Object||Show a customized modal dialog. The arguments specify (in order) the parent component, message, title, option type, message type, icon, options, and initial value for the dialog.|`. 여덟 인수와 설명은 원문 그대로 보존했고, 서명 끝에 닫는 괄호 하나만 구조상 분명한 범위에서 복구했습니다.
- 불완전한 옵션 목록과 인수 조각의 원형: `Specifies the set of buttons that appear at the bottom of the dialog. Choose from one of the following standard sets: DEFAULT_OPTION, YES_NO_OPTION, YES_NO_CANCEL_OPTION,` / `Choose from one of the following values: PLAIN_MESSAGE (no icon), ERROR_MESSAGE, INFORMATION_MESSAGE,` / `Further specifies the option buttons to appear at the buttom of the dialog.` / `Specifies the default value to be selected.` 본문은 실제 열거된 값만 비완결 목록으로 표현했고, 인수 나열에 적힌 `initial value`와의 직접 연결만 최소 문법으로 살렸습니다. 추가 상수나 다른 인수명은 넣지 않았습니다.
- 생성자/부모 연결이 깨진 원문: `constructors do not include this argument. Instead, you specify the parent you create the JDialog that contains the JOptionPane, and you use the JDialog setLocationRelativeTo method to set the dialog's position.` 본문에서는 명시된 부모 지정 및 setLocationRelativeTo 관계를 최소 문법으로 연결했습니다.
