# 823399 원형 보류

| 위치 | 원문 | 이유 |
|---|---|---|
| 원문 4행 | `These are:` | 바로 앞의 완결된 주장 `There are two types of complementary animation systems in React Native.`는 보존했다. 이 콜론은 뒤따를 목록 도입만 가리키지만 목록 값이 없어서 분리했다. 이후 본문에 실제로 쓰인 `Animated`/`LayoutAnimation` 설명을 누락 목록의 항목으로 다시 연결하지 않았다. |
| 원문 16행 | `To use this API in Android we need to set the following flags via UIManager:` | 뒤따르는 flags 목록이 없다. 빠진 설정 이름/값을 추정하지 않고 이 도입문만 분리했다. |

명시된 `Animated`, `Animated.Value`, `inputRange`/`outputRange`, `Animated.timing()`, `interpolate()`, `LayoutAnimation`, `UIManager`, `TouchableOpacity`, `View`, `_onPress()`와 크기 변화 15 unit 설명은 원문 순서대로 보존했다. 실제 예시 코드가 없다는 이유만으로 이들 완결 API·관계 설명을 삭제하지 않았고, 오탈자 `aninatedValue`와 원문 문법은 고치지 않았다.
