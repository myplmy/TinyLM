# expanded_train:19091 보류 구간

## 원형 보류

- 도입: `모든 꼭지점은 시공간에서 해당 지점의 단일  장 인자에 해당한다.` 중 미상 장 인자를 받는 문장.
- 규칙 도입: `도형에 해당하는 섭동 급수의 항은 소위 파인만 규칙에서 다음과 같은 식을 적어서 얻는다.`
- 두 규칙: `모든 내부 꼭지점 에 대해, 인자 을 적는다.` / `두 꼭지점 , 을 연결하는 모든 모서리에 대해 인자 을 적는다.`
- 후속 문장: `대칭 인자 로 이러한 규칙을 따르면 정확히 위의 표현식이 생성된다.`
- 빈 n-point 계산 도입: `차수에 대한 -점 상관 함수를 계산하기 위해 개의 외부 점과 개 이하의 꼭지점이 있는 모든 유효한 파인만 도형을 나열한 다음 파인만 규칙을 사용하여 각 항에 대한 식을 얻는다. 정확히 말하자면,`
- 이어진 수식 슬롯은 실제 값이 없는 공백 행으로 남아 있었습니다.
- 결손 결과: `개의 외부 점이 있는 연결된 모든 도형(에 해당하는 표현)의 합과 같다.`
- 미상 상호작용 이론을 전제로 한 문장: `위에서 논의한  상호 작용 이론에서 모든 꼭지점에는 네 개의 다리가 있어야 한다.`

## 보존 경계

외부 꼭지점·내부 꼭지점·모서리의 실제 관계와 설명 bullet은 본문에 남겼습니다. `여기서는` 뒤의 미상 예시 라벨과 모서리 뒤 빈 표기만 보류했습니다. `네 개의 모서리`는 이 도형 예시의 서술로 유지했습니다. `모든 꼭지점에 네 개의 다리` 같은 일반 규칙으로 바꾸지 않았습니다.

완결된 전파 인자 푸리에 변환 설명, 도형의 대칭 인자로 나누는 규칙, 연결 도형/진공 기포 정의, 특정 상호작용의 산란 진폭·감쇠 속도를 S-행렬과 파인만 도형으로 찾는 설명을 보존했습니다. 빠진 차수·변수·인자·결과는 채우지 않았습니다.
