# 171301 원형 보류 기록

## 보류 원형

```text
그람() 은
발뭉()
노퉁()
각주
```

## 처리 근거

검의 실제 이름과 두 문학 작품에 연결된 서술을 보존하고, 비어 있던 괄호 포장만 제거했다. `그람 은` 사이의 분리도 빈 괄호를 제거한 뒤 조사에 맞게 최소 정리해 `그람은`으로 이었다. 실제 각주 내용이 없는 `각주` 표제는 분리했다. 검명·별칭 값을 새로 만들지 않았다.

새 TXT에는 원본 후보에 없던 종단 LF가 추가되어 있다. 마지막 분류 행과 본문을 유지했으며, 말미를 바이트로 자르지 않았다.
