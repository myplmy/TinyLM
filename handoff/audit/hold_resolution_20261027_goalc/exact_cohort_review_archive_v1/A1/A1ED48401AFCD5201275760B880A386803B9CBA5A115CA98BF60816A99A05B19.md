# 18640 보류 원형

| 원형 조각 | 처리 근거 |
|---|---|
| `텔레비전(, )` | 실제 표제어와 본문 설명은 보존했다. 빈 병기 슬롯만 분리했다. |
| `디지털 텔레비전()`; `고선명 텔레비전()` | 실제 기술 명칭은 유지하고 빈 괄호만 정리했다. 새 영문명이나 약칭을 넣지 않았다. |
| `파울 고틀리베 닙코프(, 1860년 8월 22일 – 1940년 8월 24일)`; `카를 페르디난트 브라운(, 1850년 6월 6일 -1918년 4월 20일)`; `필로 판즈워스(, 1906년 8월 19일 ~ 1971년 3월 11일)`; `블라디미르 K. 즈보리킨(, 1889년 7월 30일 - 1982년 7월 29일)` | 채워진 이름과 날짜를 유지하고 이름 뒤 빈 병기 슬롯만 분리했다. 빠진 이름 표기는 만들지 않았다. |
| `"텔레바이저"()`; `NTSC()`; `SECAM()`; `PAL()` | 채워진 명칭/기술 약칭은 유지했다. 빈 병기만 정리하고 약칭의 풀네임을 새로 만들지 않았다. |
| `주해`; `각주` | 각 표제 아래에 실제 항목이나 주석 내용이 없어 빈 표제로 분리했다. 실제 항목이 있는 `외부 링크`와 그 뒤 내용은 보존했다. |

원문과 후보에 실제로 채워진 본문 문장, 날짜, 수치, 표준명, 절 표제와 외부 링크는 유지했다. 이 메모는 누락된 확장형이나 서지 내용을 복원하지 않는다.
