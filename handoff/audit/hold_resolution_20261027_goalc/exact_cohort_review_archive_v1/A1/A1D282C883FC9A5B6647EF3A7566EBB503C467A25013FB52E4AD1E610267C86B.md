# 1408866 원형 보류

다음 원문 조각은 완결 대상이 직접 누락되어 본문에서 분리했다.

- `printf( )can be used on` — `printf()` 뒤에 대상이 없다.
- `isatty( )by dynamically linking in a version that always returns true. This will require altering the environment before calling the child coprocess, so that the child process's dynamic load library path includes the revised isatty. See isatty_preload.c for how to do this in SUN Solaris.` — 문장은 함수명 뒤 `by`로 시작하는 미완 구문이다. 파일명과 그 설명은 원형대로 여기에 보존했고, 이 예제를 새로 완결하거나 `isatty`의 동작을 확장하지 않았다.

`system( )is that I/O bypasses your program unless you take steps to catch it.`는 원문 그대로 기록한다. 본문에서는 명시된 `system()` 주체와 I/O 동작 관계를 보존하면서 문법상 끊긴 연결만 `system( ) — I/O bypasses ...`로 정리했다. `fp behaves` 및 `expect can` 앞의 원문은 분명히 명명된 식별자와 설명어의 공백 누락만 복구했다. 함수 서명, 선택 설명, `popen` 예제와 주석은 실행·수정하지 않았다.
