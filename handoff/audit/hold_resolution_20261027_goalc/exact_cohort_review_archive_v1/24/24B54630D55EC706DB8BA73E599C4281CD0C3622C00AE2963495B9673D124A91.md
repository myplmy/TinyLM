“A frequency polygon and a histogram are very much alike. Both help visualize the distribution of a data series, the former using bars to represent counts and the latter using lines.”

새 본문에서는 두 번째 문장의 former/latter 귀속만 교정했다:
“Both help visualize the distribution of a data series, the former using lines to represent counts and the latter using bars.”

## 근거와 한계
총괄이 제공한 공식 ggplot2 문서 근거는 histogram을 막대, frequency polygon을 선으로 설명한다: https://ggplot2.tidyverse.org/reference/geom_histogram.html (ROOT scope에 기록된 115view0, 44행). 이 보조 근거는 총괄 제공 자료를 통해 적용했으며, 여기서 코드 실행이나 별도 웹 조회를 하지 않았다.

본문의 다른 내용은 기존 선택 v1과 동일하다. 변수/df 예고의 손상 경계, 손상된 코드·그에 직접 의존하는 플롯 설명 및 결과, 빈 목록 예고는 기존 원형 보류 그대로 유지한다. 보이는 ID/values/df 역할, rnorm 인수와 독립된 완결 ggplot/geom_freqpoly 호출·실제 매개변수는 새 코드로 재구성하지 않고 기존 보존 범위에 둔다. 외부 예제나 다른 API 주장을 새로 추가하지 않았다.
