# 532315 원형 보존 메모

## 분리한 즐겨찾기 UI

후보에서 단독 `Add To Favorites` UI 두 줄을 제거했다.

```text
Add To Favorites
Add To Favorites
```

첫 줄은 hollyhock doll 활동 지침 직전의 즐겨찾기 버튼이고, 둘째 줄은 `Creating a quilt block...` 관련 활동 설명 뒤, `How much is a liter?` 카드 앞에 놓인 동일 버튼이다. 두 줄 모두 저장/즐겨찾기 동작 UI이며 공예 활동의 이름이나 절차가 아니다. `Join Us on`, hollyhock doll의 완결 지침, quilt block 및 metric 측정 활동 소개는 각각 원문에 있는 그대로 유지했다.

## 판독 범위

지정 original/candidate 전문과 순서 패킷 0001–0002의 BEGIN부터 END/EOF까지 대조했다. 후보 전체 diff는 줄 차이가 없었다. 새 본문에서 위 즐겨찾기 버튼 두 줄만 제거했다.
