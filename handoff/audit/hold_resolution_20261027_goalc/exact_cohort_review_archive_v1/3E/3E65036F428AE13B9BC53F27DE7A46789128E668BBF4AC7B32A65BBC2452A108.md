# 191639 불완전 BULK INSERT 예제 보류

원형 예고와 코드 조각은 다음과 같다.

`Here is the T-SQL code to BULK insert data from text file to SQL Table:`

`BULK INSERT [Database]..[TableName]`

`FROM 'D:\test.txt' -- Path of text file WITH`

`( FIRSTROW = 1`

`,BATCHSIZE = 10000`

`,FIELDTERMINATOR = ','`

`,ROWTERMINATOR = '\n'`

`,LASTROW = 20`

닫힘이 없는 괄호와 `-- Path of text file WITH`가 같은 줄에 붙어 주석/코드 경계도 불완전하다. 예고와 이 코드 조각만 본문에서 분리했다. 뒤의 다섯 실제 키워드 이름·설명은 해당 설명 대상이 분명하므로 보존했다. 새로운 SQL이나 필드 설명은 만들지 않았고 코드를 실행하지 않았다.
