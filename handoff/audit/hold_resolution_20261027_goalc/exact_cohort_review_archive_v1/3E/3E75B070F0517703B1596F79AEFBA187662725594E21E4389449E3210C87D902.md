# expanded_train:396839 원형 보류 및 반복 문맥

원문과 후보는 ROOT_IDENTITY_TASK_040_V2의 동일성 계획으로 연결했고 지정 full diff는 변경 없이 끝났다. 두 proxy 소개 문장은 서로 다른 내용을 말한다. 첫 문장은 대리 객체가 접근을 제어한다는 목적이고, 다음 문장은 인터페이스와 구현 사이에서 호출을 가로챈다는 설명이므로 둘 다 본문에 보존했다. 반복 구현의 비용 설명, InvocationHandler/Proxy/newProxyInstance 이름과 서명·인수, 예외 설명, dynamic proxy/AOP 관계도 서로 다른 역할이므로 유지했다.

다음 예시 코드들은 선언·메서드 몸체·괄호가 여러 줄에 걸쳐 평탄화/누락되어 있어 실행 가능한 코드로 재구성하지 않고 원형으로 보존한다.

## 인터페이스별 기존 proxy 예시

> public interface Foo
> public void doSomething();
> public void doAnother();
> public class FooImpl implements Foo
> public void doSomething() throws MyException
> public void doAnother()
> System.out.println("Doing something else...");
> public class LoggingProxy implements Foo
> private FooImpl target = null;
> public FooProxy(FooImpl target)
> this.target = target;
> public void doSomething()
> public void doAnother()

`FooProxy` 표기와 `LoggingProxy` 이름의 관계 등 코드를 바로잡지 않았다. 완결 문장으로 실제 반복 비용을 설명한 본문은 유지했다.

## DynamicProxy 예시

> public class DynamicProxy implements InvocationHandler
> private Object target = null;
> public static Object newInstance(Object target)
> Class targetClass = target.getClass();
> Class interfaces = target.getInterfaces();
> return Proxy.newProxyInstance(targetClass.getClassLoader(), interfaces, new DynamicProxy(target));
> private DynamicProxy(Object target)
> this.target = target;
> public Object invoke(Object proxy, Method method, Object args) throws Throwable
> Object invocationResult = null;
> System.out.println("Before method " + method.getName();
> invocationResult = method.invoke(this.target, args);
> System.out.println("After method " + method.getName();
> //this is the exception thrown by the method being invoked
> //we just rethrow the wrapped exception to conform to the
> System.err.println("Invocation of " + method.getName() + " failed");

본문에는 InvocationHandler의 실제 이름/메서드 서명과 `Proxy.newProxyInstance` 설명이 남아 있다. 코드의 중괄호·인수 타입·메서드 괄호를 추가하거나 복구하지 않았다.
