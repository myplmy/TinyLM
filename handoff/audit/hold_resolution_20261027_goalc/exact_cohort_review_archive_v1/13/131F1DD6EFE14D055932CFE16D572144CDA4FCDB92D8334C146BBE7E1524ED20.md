# Hold: expanded_train:196520

원문에서 함수 서명·인수 이름 없이 연속한 두 매개변수 설명 조각을 분리했다. `stream` 같은 미기재 이름을 함수 지식으로 보충하거나 각 설명을 인수 위치에 연결하지 않는다.

```text
The file pointer.
The number of bytes to buffer.
```

원문에 실제 채워진 `buffer is 0` 조건과 unbuffered read 동작, `fread()` 및 반환 조건, 두 함수명과 버퍼링 설명은 본문에서 유지했다. `bufferis`는 문장 안에서 `buffer is`로 읽히는 결합형이므로 공백만 정리했다.
