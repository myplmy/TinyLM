# 1350973 원형 보류

비교 문장 끝의 `while POSIX documents EPERM only when the permission check failed for all target`는 대상이 잘린 불완전 절이므로 분리했다. 같은 문장 앞의 BSD 반환 동작 설명은 원문에 실제로 적힌 범위에서 유지했다.

보류 원형: `while POSIX documents EPERM only when the permission check failed for all target`

다른 errno 설명, Linux 구현 호출, 참조 함수·매뉴얼, 페이지 버전과 날짜는 유지했으며 함수 실행이나 외부 정정을 하지 않았다.
