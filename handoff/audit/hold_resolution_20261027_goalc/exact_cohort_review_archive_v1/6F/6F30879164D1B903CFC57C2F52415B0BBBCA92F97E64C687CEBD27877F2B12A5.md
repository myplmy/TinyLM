# expanded_train:532103 원형 보류

원문에서 코드가 뒤따르지 않는 예고문 `Here is the code of program:`은 본문에서 분리했으며 프로그램을 새로 만들지 않았습니다. 마지막 `Ask your questions, our development team will try to give answers to your questions.`는 본문 기술 설명이 아니라 사이트 질문 안내 UI로 분리했습니다.

`Above method checks the token created by the StringTokenizer() methods. It returns Boolean type value either true or false. If the above method returns true then the nextToken() method is called.`는 검사 메서드의 실제 이름/정의가 제시되지 않고 사라진 코드에 직접 의존하므로 원형을 보존합니다. 그 이름을 추정하지 않았습니다.

원문에는 `Above constructor of the StringTokenizer class ...`라고 되어 있어 물리적 `Above` 지시만 본문에서 제거했습니다. 본문은 같은 원문이 실제 명시한 StringTokenizer 생성자·문자열 인수·공백/탭/개행 설명만 최소 문법으로 연결했습니다. 생성자 서명이나 누락 코드는 넣지 않았습니다.
