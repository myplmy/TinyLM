## 분리한 페이지 편집 UI 잔재

원문에서 다음 네 소제목에 붙은 반복 `Edit`는 내용 제목이 아니라 페이지 편집 UI 꼬리로 판단해 제거했다. 소제목 본문은 보존한다.

- `Importing a ModuleEdit`
- `Creating a ModuleEdit`
- `From a FileEdit`
- `From a DirectoryEdit`

## 총괄 중재가 필요한 명명 목록 경계

원문은 다음과 같이 말하지만, 세 파일 이름을 채우지 않고도 어떤 구간을 독립 보존할 수 있는지 판단이 필요하다. 뒤의 실제 import 코드에는 `Object1`, `Object2`, `Object3`가 명시되어 있으나 이를 앞 문장의 누락된 이름 목록으로 역삽입하지 않았다.

> Suppose we have two more objects called
> Object3 and we want to load all three objects with one command.
> We then create a directory called mymod and we store three files called
> Object3.py in it.
> These files would then contain one object per file but this not required (although it adds clarity).

이 세 문장은 현 수정본에 그대로 남아 있으므로, 그 경계는 미결로 보고한다. 누락된 파일명·객체명을 생성하지 않았다.
