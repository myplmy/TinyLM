# 275889 원형 보류 — 빈 별칭/각주 표제 (v1)

## 판독 범위

TASK_003의 지정 packet 0001–0004를 순서대로 읽었다. 0004에서 candidate의 실제 END와 full diff 끝을 확인했다. 새 본문 전체 diff와 마지막 내용도 확인했다.

## 분리한 원형

- 도입 원형 `표준 스트림()은 ...`에서 괄호 안 값은 비어 있다. `표준 스트림`이라는 실제 명명 주체와 뒤의 완결 정의를 보존하고, 빈 괄호만 정리했다. 영어 별칭이나 다른 용어를 만들어 넣지 않았다.
- 원문 말미의 `각주` 표제에는 각주 항목이 없다. candidate가 이 빈 표제를 제거한 상태를 유지한다.

## 보존 범위와 한계

표준 입력·출력·오류의 실제 명칭, 파일 서술자/상수/변수, 동작 설명, 채워진 참고문헌·같이 보기·외부 링크·분류를 원문 순서와 범위대로 보존했다. 기존 서지의 빈 쉼표는 새 저자·판본·제목을 추정하지 않고 그대로 두었다. 표준 스트림 동작을 외부에서 검증하거나 갱신하지 않았다.
