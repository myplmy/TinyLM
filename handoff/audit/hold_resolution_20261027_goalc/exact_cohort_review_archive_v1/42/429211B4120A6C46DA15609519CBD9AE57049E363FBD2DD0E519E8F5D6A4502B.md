# 1037809 원형 보류 (정정 v2)

TimeBar의 레이블·간격·줌에 따른 표시 설명, GetFormatters라는 실제 메서드명 및 목록 반환 서술, H:mm 표기와 표시 동작 설명, IntervalSpans의 이후 실제 기본값 1과 시간 구간 예시는 보존했다.

다음은 직접 빠진 정의/형식에 의존하므로 원형으로 분리했다.
- “for function -” 뒤에 함수/대상 이름이 없는 조각. 앞의 실제 “GetFormatters returns a list”는 유지했다.
- 도입부 “in our case in HourFormatterProvider() / we have set 2 dates:”와 `formatters = new Func<`, 두 date.ToString 람다 줄. 이 조각은 빠진 제네릭 형식·닫힘에 직접 의존한다. HourFormatterProvider() 이름은 원형에 보존했고, 형식 인수/호출관계를 만들지 않았다.
- 주어가 없는 “is used when one period control corresponds to a couple of interval items. For instance if you set the IntervalSpans” 조각. 뒤의 실제 IntervalSpans 기본값/구간 설명과 연결해 누락 주어를 추정하지 않았다.
