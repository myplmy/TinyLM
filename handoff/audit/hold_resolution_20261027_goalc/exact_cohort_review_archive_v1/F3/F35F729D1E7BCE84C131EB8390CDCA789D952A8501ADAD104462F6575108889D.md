다음은 대상이 빠진 직접 의존 구절이다. 각 원형을 보존하고 본문에서는 분리했다.

- shortcut 대상을 잃은 예고: `This method is a shortcut for`
- 미완 reload 구절: `Even a page reload will first create an`
- proprietary 대상이 빠진 조건: `, and contrasted with the proprietary`
- handler 결속 대상이 빠진 구절: `unload event handler should be bound to the`
- 존재하지 않는 코드의 결과를 직접 지시하는 문장: `After this code executes, the alert will be displayed whenever the browser leaves the current page.`
- 실제 예제가 없는 표시 예고: `To display an alert when a page is unloaded:`

본문에서는 원문에 실제로 있는 `unload event`, `window element`, navigation 조건 및 `.preventDefault()` 관계를 보존했다. 문장 경계를 잇는 최소 관사/어순 외에 API 이름, handler 대상, 코드 예제는 만들지 않았다.
