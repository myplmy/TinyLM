# 423325 원형 보류 기록

원문·후보 전문과 0001–0003 패킷, 전체 diff END를 판독했습니다. `import`와 `print` 명령들이 한 줄로 합쳐져 실행 구문 경계를 잃었으므로 세 프로그램 예제는 복원하거나 실행하지 않고 원형 그대로 분리했습니다. 완결된 `sys.version`, `sys.version_info`, `platform.python_version()` 설명, 3.9.5 버전 및 major/minor/micro 값 설명과 저자 약력은 본문에 보존했습니다.

```text
import sys print(sys.version) # 3.7.2 (tags/v3.7.2:9a3ffc0492, Dec 23 2018, 23:09:28) [MSC v.1916 64 bit (AMD64)]
```

```text
import sys print(sys.version_info) # sys.version_info(major=3, minor=9, micro=5, releaselevel='final', serial=0) print(sys.version_info) # Major: 3 print(sys.version_info) # Minor: 9 print(sys.version_info) # Micro: 5
```

```text
import platform print(platform.python_version()) # 3.9.5
```

`You can access the major version with`와 뒤따른 `sys.version_info, the minor version with`, `sys.version_info, and the micro version with` 조각은 각각 어떤 속성을 읽는지 소실되어 해당 문장 조각을 보류했습니다. 빠진 필드 이름을 추정하지 않았습니다.
