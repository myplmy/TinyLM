# 223581 원형 보류 메모

- 지정 original/candidate와 packet 1의 original/candidate/full_diff를 END까지 판독했다. 입력 candidate는 original과 같았다. root 중재에 따라 부분 보류와 빈 포장 정리를 반영한 새 TXT를 작성했다.
- 리드의 실제 정의 `함수의 도함수가 0이 되는 점`과 임계점/정류점/정상점 명칭, 극대점·극소점·안장점 분류는 보존했다. `임계점(臨界點, )`의 빈 병기 칸과 뒤 쉼표만 정리했다.
- 정의 블록은 아래 원형 전체를 보류했다. 대상인 다양체/함수와 조건식·좌표계 표기가 빠져, 빈 부분을 지식으로 채우지 않았다.
  - `매끄러운 다양체  위의 1차 미분 가능 실함수 의 임계점은 다음이 성립하는 점 이다. 임의의 좌표계 에서,`
  - `이 경우, 값 를 임계값()이라고 한다.`
- 분류 블록의 원형 전체를 보류했다. 리만 다양체·함수·헤세 행렬의 기호 대응이 없고, 채워진 고윳값 부호/정부호 조건과 극대·극소 결과가 서로 일관되지 않아 일부 조건만 떼거나 부호를 교정하지 않았다.
  - `리만 다양체  위의 2차 미분 가능 실함수 의 임계점 들은 그 헤세 행렬`
  - `에 따라서 다음과 같이 분류된다.`
  - `만약 헤세 행렬이 양의 준정부호라면 (모든 고윳값이 음수가 아니라면), 는 극대점이다.`
  - `만약 헤세 행렬이 양의 정부호라면 (모든 고윳값이 양수라면), 는 엄격한 극대점()이다.`
  - `만약 헤세 행렬이 음의 정부호라면 (모든 고윳값이 양수가 아니라면), 는 극소점이다.`
  - `만약 헤세 행렬이 양의 정부호라면 (모든 고윳값이 음수라면), 는 엄격한 극소점()이다.`
  - `만약 헤세 행렬이 둘 다 아니라면, 는 안장점이다.`
- 페르마의 임계점 정리 블록 전체도 함수·점 대응과 전제가 닫히지 않아 보류했다. 원형은 `페르마의 임계점 정리()에 따르면, 연속함수 의 최대점 또는 최소점 이 존재한다면, 다음 둘 가운데 하나가 성립한다. / 는 에서 미분 불가능하다. / 는 에서 미분 가능하며, 임계점을 이룬다.`이다. 내부점/미분가능 조건이나 식을 새로 보충하지 않았다.
- 빈 `외부 링크` 표제는 제거했다. 실제 `같이 보기`의 `모스 이론`과 `다변수 미적분학`, `특이점 이론` 분류는 유지했다. 새 수학 사실을 외부 검증하거나 추가하지 않았다.
- 원형은 마지막 분류 뒤 EOF 개행이 없었고 새 TXT에는 EOF 개행이 있다. 이는 텍스트 파일 끝 형식만 정규화한 것이다.
- 새 본문은 `expanded_train_223581_revised_task008_v1.txt`이다. 입력 원형은 변경하지 않았다.
