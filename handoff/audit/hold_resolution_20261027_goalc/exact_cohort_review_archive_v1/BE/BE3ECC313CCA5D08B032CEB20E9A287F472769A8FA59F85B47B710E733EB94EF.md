# 136939 채워진 infobox 값 보존과 빈 필드 정리

- 판정: REVISE_TEXT. 본문은 `expanded_train_136939_revised_task016_v1.txt`에 연결한다.
- 지정된 16개 연속 packet에서 original/candidate/full_diff/논리 END/EOF를 읽었다. 후보의 원문 대비 full diff는 내용 없는 `각주` 표제 제거 한 건이었다. 생년·사망년은 본문과 분류에서 일치하며 바꾸지 않았다.
- 왕족 정보 template 형태를 유지했다. 이름·그림 파일·작위의 두 실제 값과 순서·재위/대관식 날짜·전임/후임·재상·휘·별호/연호/묘호/존호/시호·칸호·출생·사망·매장·왕조/가문/가족·종교 등 채워진 필드명과 값은 그대로 두었다. `작위`의 다중값 순서를 재구성하지 않았고, 날짜·이름을 새로 넣지 않았다.

## 제거한 빈 필드/표기 껍데기 원형

```text
|원래 이름 = 
|그림설명 = 
|서명     = 
|문장     = 
|문장설명 =
|즉위식2   = 
|섭정2     = 
|수상2     = 
|총리2     = 
|능호     = 
|친인척   = 
|휘       = 카이샨(, )
|칸호 = 쿨룩 카안 (
족보
기년
```

- `원래 이름` 이하 비어 있는 값 필드는 본문에 값이 없는 필드로 남기지 않고 분리했다. 빈 `휘` 병기 슬롯만 제거해 실제 `카이샨`은 유지했다.
- 열린 `칸호` 괄호는 내용이 없으므로 괄호만 정리해 `쿨룩 카안` 값을 보존했다.
- 본문 원형의 `칸호는 쿨룩 카안(, хүлэг хаан)`에서 빈 앞 슬롯과 쉼표를 정리해 실제로 있던 `хүлэг хаан`을 유지했다. `본명은 카이샨'''(, 키릴 문자:Хайсан, )`의 빈 병기 슬롯과 짝 없는 강조 표식만 제거하고 실제 `카이샨`/`Хайсан` 표기를 유지했다.
- 값이 없는 `족보`, `기년` 제목을 분리했다. 실제 링크 제목과 끝 분류는 유지했다. candidate가 이미 제거한 빈 `각주` 표제도 본문에 복원하지 않았다.

외부 역사 검증이나 칭호/이름 보충은 하지 않았다.
