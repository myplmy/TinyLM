# 50028 원형 보류: 누락된 이름 값과 표

## 입력 범위

지정된 `expanded_train:50028` 원문·후보 패킷 0001–0003을 순서대로 읽었다. 원문과 후보의 논리 END, full diff END, 마지막 패킷의 물리 EOF를 확인했다.

## 원형 보류

- 실제 권장안에 쓰인 이름 값이 비어 있는 문장: `실제 권장안에 표기된 이름은 순서대로 이다.` 이름을 추정해 추가하지 않았다.
- 빈 별칭 필드의 원형: `특정한 이름(SGML 실체, )`, `미리 정의된 실체()`.
- 표를 직접 예고하는 원문: `아래 표는 2010년 기준으로 HTML 권장안에 포함된 252개의 문자 실체 이름과 XML에서 지정된 어포스트로피(U+0027)를 더한, 모두 253개의 사용 가능한 문자 실체 참조 목록이다.` 이 입력에는 그 표 본문이 없다. 표·항목을 생성하지 않았으며, 실제 적힌 2010년 기준·252개·U+0027·253개 관계만 본문에서 표가 있다고 주장하지 않는 산문으로 남겼다.
- 내용이 없는 표제 `표 각주:`와 `참고 문헌`.
- 말미 분류 메타데이터: `컴퓨터 용어`, `W3C 표준`, `HTML`, `XML`.

후보가 원문에 있던 설명 `쌍반점(;)으로 끝맺는다`에서 실제 세미콜론 문자를 빼 둔 부분은 원문 표기를 새 본문에 복구했다. 실제 &rarr;, &lt;, &Aring;, &aring; 예와 문자 코드 표기 예, 표준·조건·수치는 원문대로 보존했으며 외부 표준을 새로 검증했다는 뜻은 아니다.
