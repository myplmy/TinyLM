# expanded_train:172538 빈 병기 슬롯

원형의 고베역 목록에는 다음과 같은 두 명명 행이 있었다.

- 고베역 (효고현)() - 효고현 고베시 주오구에 있는 서일본 여객철도의 도카이도 본선·산요 본선 (JR 고베 선)의 역.
- 고베역 (나가사키현)() - 나가사키현 운젠시에 있는 시마바라 철도의 시마바라 철도선의 역.

두 지역명이 실제로 채워져 있어 각 역명·지역 구별과 설명을 본문에 보존하고, 끝의 빈 괄호만 정리했다. 후보가 이미 빈 괄호의 고소쿠코베역과 내용 없는 같이 보기 표제를 제거한 선택도 유지했다. 남은 노래명 표기와 실제 노선·지역·역 설명을 변경하지 않았다.
