# 414080 원형 보류 구간

- `I'm going to show examples of two different classes.`와 `There are my two classes.` — 뒤에 예고된 실제 class examples가 입력에 없으므로 그림/예제 포인터를 분리한다. 다음 문단의 실제 `Methods`, `HelloWorld`, `myObject`, `method2()` 명칭과 같은 폴더·package 조건은 새 본문에 보존했다.
- `Now run the program, you should see that it displays 3.14159 under Hello World! This is because that is what that method is supposed to do. You can look back at the Methods class to verify this.` — 보이지 않는 `method2()` 구현과 실행 결과에 직접 의존하는 문장을 원형 보존했다. 원문에 적힌 3.14159를 새 본문에서 새 계산 결과로 제시하지 않았다.
- `If you have any questions, comments, or concerns about this tutorial, feel free to contact us.` — 학습 설명이 아니라 사이트 연락 CTA이므로 분리했다.
