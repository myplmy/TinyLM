# 15288 원형 보류

| 원형 조각 | 처리 근거 |
|---|---|
| `일본(日本) 덴분() 24년 / 고지() 원년` | 두 연호와 연도는 채워져 있어 보존하고, 각각의 빈 괄호만 정리했습니다. |
| `류큐(琉球) 쇼세이왕() 29년` | 왕명과 연도는 채워져 있어 보존하고 빈 괄호만 정리했습니다. |
| `각주` | 원문 말미에 표제만 있고 각주 내용이 없습니다. 후보가 제거한 빈 표제입니다. |

실제 사건·탄생·사망의 명칭·날짜·관계·순서는 유지했습니다. 채워진 연호·기년 값도 원문 그대로 두었으며 새 값을 만들지 않았습니다.
