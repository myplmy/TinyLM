# expanded_train:67116 보류 메모

- 원문 도입의 빈 병기 `니콜라 부르바키( )`는 값이 없어 분리했다. 실제 이름과 단체가 사용한 가명이라는 설명은 본문에 남겼다.
- 원형 `다음은 《수학 원론》에 속하는 책들의 목록으로, 괄호 안은 프랑스어 원제목이다.`는 뒤에 목록이 없어 그 예고 문장 전체를 보류했다. 실제 저서명 `《수학 원론》(Éléments de mathématique)`과 목적 설명, 뒤의 채워진 책명·출판 서술은 유지했다.
- 원형 `공집합을 나타내는 기호인 나 난해한 부분을 가리키는 '부르바키 급커브 기호'(, ☡)와 함께,`는 기호값이 빠져 직접 해석할 수 없으므로 해당 연결 구절을 보류했다. 빈 기호나 기호 관계를 만들지 않았다. 뒤의 실제 명명된 단사·전사·전단사 용어에 관한 문장은 독립적으로 보존했다.
- 원형 `단사(), 전사(), 전단사()`와 회원 이름 `샤를 에레스만(), 르네 드 포셀(, 숄렘 만델브로이트()`의 빈 별칭 포장만 정리했다. 각 실제 용어와 인명, 순서, 소속 서술은 그대로 남겼고 이름·별칭을 새로 귀속하지 않았다.
- 원문 `참고 문헌`은 내용이 없는 표제뿐이어서 본문에서 분리했다. 출처를 보충하지 않았으며 실제 외부 링크는 보존했다.
