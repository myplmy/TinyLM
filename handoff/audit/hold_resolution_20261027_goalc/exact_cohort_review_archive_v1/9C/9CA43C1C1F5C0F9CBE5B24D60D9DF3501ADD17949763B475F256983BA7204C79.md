# 44472 원형 보류

- 원문 `복잡도` 절의 불완전 문장: `의 리스트를 정렬하는데 걸리는 시간을 , 는 임의의 상수라 하고, 리스트가 두 개의 거의같은 부분집합으로 나뉜다고 가정하여 얻은 평균 시간 복잡도는 다음과 같다.`
- 이 문장은 대상 기호·시간 변수/상수와 뒤따를 복잡도 식이 실제로 빠져 있어 문장 전체를 분리했다. 특정 변수명, 점근식 또는 상수를 추정해 넣지 않았다.
- 앞부분의 최악/평균 비교 횟수 O(n2), O(n log n), 메모리 복잡도 설명, 알고리즘 설명·정확성 증명과 각 언어의 실제 코드/예제는 별도 완결 내용으로 그대로 보존했다. 코드를 실행하거나 기능·성능을 검증하지 않았다.
