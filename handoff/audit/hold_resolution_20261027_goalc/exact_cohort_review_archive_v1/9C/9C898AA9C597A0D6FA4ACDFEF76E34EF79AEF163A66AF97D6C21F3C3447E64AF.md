# expanded_train:10566 원형 보류

## 분리 범위

- 빈 별칭 포장: `오세트어()`에서 별칭을 추정하지 않았다.
- 실제 내용이 없는 표제: `모음`, `이론 방언`, `디고르 방언`, `발음`, `자음`, `각주`, `외부 링크`.
- 누락된 문자 목록을 직접 예고하는 문장: `다음과 같은 키릴 문자를 쓴다.` 그 뒤에 해당 목록이 없으므로 목록을 만들어 넣지 않았다.

## 보존 범위

실제 내용이 이어지는 `방언`, `문자`, `문법` 구획과 동부 이론 방언·서부 디고르 방언·표준어의 관계, 로마/조지아 문자 사용 시기, 음운·어휘 설명, 분류 항목을 보존했다. 누락된 모음·자음·발음·문자 목록은 복구하지 않았다.
