# expanded_train:178922 원형 보류 및 경계

원문 지시의 “Give it the following name;”에는 지정할 매크로 이름이 뒤따르지 않는다. 이 문장만 원형 sidecar에 보류했고, 매크로명을 추측해 쓰지 않았다. 실제로 채워진 나머지 설명과 이름 붙은 코드 토큰은 보존한다.

코드 줄은 원문에 이미 있는 토큰과 순서만 유지하면서 다음 줄 경계로 분리했다.
Sub ApplyTableStyle()
Dim tbl As Table
For Each tbl In ActiveDocument.Tables
tbl.Style = "Medium Shading 2 - Accent 1"
Next
End Sub

이는 텍스트에 표시된 코드 경계를 복구한 것이며, 코드를 실행하거나 실행 가능성·동작을 검증했다는 뜻이 아니다. 주변의 실제 스타일 수정 지시와 따옴표, 변수명, 속성명은 유지했다.
