# 3655 원형 보존 메모

## 분리한 반복 페이지 UI

본문 후보에서 답변/절 사이에 독립 행으로 놓인 다음 문자열 두 건을 제거했다.

```text
Back to Top
Back to Top
```

첫 줄은 “reasonable” 해석에 대한 설명 뒤, 두 번째 줄은 Word 문서 접근성 설명 뒤이자 PowerPoint 절 앞에 있다. 같은 페이지 이동 라벨이며 문서 접근성의 실질 설명이나 절 제목이 아니므로 본문에서 분리했다. Academic's Role 표제, 접근성 지침, Word·PowerPoint의 실제 절차와 조건은 유지했다.

## 판독 범위

지정 original/candidate 전문과 두 순서 패킷을 처음부터 끝까지 대조했다. 후보 전체 diff는 줄 차이가 없었다. 새 본문에서는 위 두 UI 라벨만 제거했다.
