# 5390 보류 원형 및 정리 근거

| 원형 | 처리 근거 |
|---|---|
| `없다고 추정된다` | 주어와 대상이 없는 고립된 추정 절이다. 무엇이 없다고 추정되는지 새로 연결하지 않고 원형을 보류했다. |
| `사건` | 원형과 후보에 내용이 없는 표제다. 본문에서 분리했다. |
| `문화` / `탄생` / `사망` | 원형에 내용이 없는 표제들이다. 후보에서 일부가 이미 제거됐으며 남은 빈 표제도 본문에 두지 않는다. |
| `일본(日本) 가쇼() 3년` | `가쇼`와 `3년`은 보존하고 빈 괄호만 제거했다. 누락된 별칭을 추측하지 않는다. |

최종 본문은 `draft_5390_task011_v1.txt`이다. 실제 연호·기년 값은 그대로 유지하고, 빈 대상·내용을 만들지 않았다.
