# expanded_train:291279 — 빈 병기와 내용 없는 표제

TASK 지정 packet 1–2를 순서대로 읽었다. packet 1에는 원문/후보 전문이 있고, packet 2의 full_diff는 두 전문에 줄 차이가 없다고 표시한다. 이 동일성 자체를 정제 적합성 근거로 사용하지 않았다.

도입 `베르카닉스()는`에는 실제 명칭 뒤의 값 없는 병기 슬롯만 있어 본문에서 괄호를 정리했다. 이후 `《베르카닉스》(Berkanix)`라는 실제 한글/영문 명칭과 게임의 장르·개발사/개발 스튜디오·엔진·특징·개발 중단/날짜·비용 서술을 원래 위치와 조건대로 보존했다. 빠진 별칭이나 현재 상태를 새로 넣지 않았다.

`각주` 표제 뒤에는 각주 내용 없이 분류 항목들만 이어진다. 빈 각주 표제만 분리하고 `언리얼 엔진 게임`, `대규모 다중 사용자 온라인 롤플레잉 게임`, `대한민국의 비디오 게임`, `윈도우 게임`, `취소된 윈도우 게임`은 실제 명명된 분류 항목으로 그대로 남겼다.

원형의 빈 슬롯/표제를 기록하며 새 각주나 게임 정보를 보충하지 않는다.
