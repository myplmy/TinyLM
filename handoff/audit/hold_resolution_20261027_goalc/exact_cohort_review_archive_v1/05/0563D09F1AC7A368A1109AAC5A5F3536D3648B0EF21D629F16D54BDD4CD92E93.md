# 416176 원형 HOLD 근거

원문 조각: `In this case, we are connecting to the MySQL database flightdb on the host`

`flightdb` 데이터베이스명은 원문에 채워져 있어 본문에 남겼다. `on the host` 뒤에 실제 문장 속 호스트명이 없어 그 미완 위치구만 보류하고, 앞 문장을 `In this case, we are connecting to the MySQL database flightdb.`로 끝맺었다. 코드 예제의 호스트 인수나 다른 위치에서 값을 가져와 문장에 채우지 않았다.

`QSqlDatabase` 생성, 실제 `addDatabase`/`setHostName`/`setDatabaseName`/`setUserName`/`setPassword`/`open` 호출, 두 명명 연결의 생성·열기, `false` 조건과 `lastError()`, `database()` 및 `removeDatabase()`의 설명은 원문 그대로 유지했다. 코드 실행이나 자격정보 검증은 하지 않았다.
