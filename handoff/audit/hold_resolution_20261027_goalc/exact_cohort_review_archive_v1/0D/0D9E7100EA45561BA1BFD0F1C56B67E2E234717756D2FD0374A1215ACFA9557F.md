# expanded_train:919357 페이지 UI 분리

완결된 관광 정보를 지시하지 않는 일반 페이지 이동·공유 UI만 본문에서 분리했습니다.

- `Know more...` (2회) 및 `Know more....` (1회): 단락 끝에 붙은 일반 추가 이동 링크 문구.
- `Read more...` (1회): 단락 끝의 일반 추가 이동 링크 문구.
- `- SHARE THIS` (2회), `- TWEET THIS` (1회), `- LOVE THIS 1` (1회): 페이지 공유·반응 컨트롤.

각 문구 앞의 채워진 인구, 관광, 경제, 의료 등 설명은 본문에 남겼습니다. 주소·출처가 명시된 연결 정보는 없어서 링크 대상을 만들지 않았습니다.
