# 원형 보류 기록 — expanded_train:81323

판정: REVISE_TEXT. 빈 괄호 병기 슬롯을 제거하고, 실제 참가팀·우승팀·기록 값이 없는 섹션과 그 값에 직접 적용되는 범례/기준일을 본문에서 분리했다.

원형 보류 범위:

```text
참가팀

역대 우승 팀

세르비아 몬테네그로 (2002-2006)

세르비아 (2006-현재)

기록

최다 득점 선수
볼드체로 표시된 선수는 현재 수페르리가에 소속된 선수이다.
이탤릭체로 표시된 선수는 현재 타 리그에 소속된 선수이다.

<2023년 2월 19일 기준>
```

각 제목 아래에 팀·우승자·기록값이 제시되지 않았다. 두 국가/기간 표기는 원래 우승자 목록의 구획이고, 굵게/기울임 범례와 기준일은 해당 선수 기록표를 전제로 하므로 그 구조와 값을 함께 원형 보류했다. 빈 값을 채우거나 기준일을 다른 내용에 귀속하지 않았다.

리드의 `세르비아 수페르리가()`는 괄호 안 값이 비어 있어 괄호만 제거했다. 역사 문단, 후원사 명칭, `외부 링크` 아래의 실제 `공식 홈페이지` 라벨 및 세 분류 항목은 그대로 보존했다.
