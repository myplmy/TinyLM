## 근거

`Picture #1`은 없는 그림을 지시한다. Java 코드에는 미완 class/main 선언, 닫히지 않은 `BufferedReader` 생성, 빠진 블록 경계와 고립 `catch`가 있어 코드를 완성하지 않고 예제 전체를 보류했다. 실제 객체 생성에 직접 붙은 도입문, `data_in`/`data_out` 생성 주장, 누락된 반복문·EXIT 처리 및 그 예제를 직접 가리키는 문장은 코드와 함께 원형으로 보존했다. 반면 원문 bullet의 `ServerSocket`·port `9999`, `s.accept()`, welcome message 관계는 각각 명명된 주체와 조건이 완결돼 본문에 남겼다. XMLSocket 및 client/server 설명도 유지했다. 페이지 이어짐 표시는 원형으로 분리했다. 코드를 실행하거나 누락 토큰을 만들지 않았다.
