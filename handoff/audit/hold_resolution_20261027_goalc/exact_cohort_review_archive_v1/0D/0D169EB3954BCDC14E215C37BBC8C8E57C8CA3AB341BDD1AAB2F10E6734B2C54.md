# expanded_train:1261754 원형 보류 기록

원문은 질문자가 작성한 프로그램을 설명하는 답변이다. 없는 코드 예시와 그에 직접 매인 안내 구절은 복원하지 않았다.

## 누락 코드 예시를 직접 예고하는 원형

- `At some point it appears you wanted to do something like`
- `though you would have to work out where that gets done that ne is the correct object and answer is in the block you want it to be in.`
- `A more common way of doing that is something like`

위 문구에는 예고된 코드가 없고 두 번째 문구도 `ne`를 포함한 손상 구문이므로, 어느 클래스/객체/변수 블록을 뜻하는지 추정해 채우지 않았다. `run()`이 자기 자신을 호출한다는 원문의 진단과 반복을 종료할 조건에 대한 독립 설명은 본문에 유지했다.

## 보존된 조건 설명의 문장 경계

원문의 `where 'done' gets set to true under some condition and terminates the loop.`는 누락된 반복 코드 예시를 받는 종속절이었다. 본문에서는 새 상태나 조건을 만들지 않고 이를 `The loop terminates when 'done' gets set to true under some condition.`으로 독립 문장화했다. 완료 조건이 지정되지 않은 상태임도 원문대로 남겼다.
