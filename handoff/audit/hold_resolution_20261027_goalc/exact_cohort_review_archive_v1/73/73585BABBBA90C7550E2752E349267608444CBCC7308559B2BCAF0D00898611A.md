# 291856 원형 보존 메모

## 분리한 반복 페이지 UI

후보 본문에서 다음 단독 문자열을 다섯 번 제거했다.

```text
Back to Top
```

각 발생은 FAQ의 답변 끝과 다음 질문 사이에 같은 형식으로 놓인 페이지 위쪽 이동 링크다. strobe tuner 설명, 비교 조건, 제품명, 정밀도 수치, 기타 튜닝 목록, 조율 체계 설명을 담지 않으므로 학습 본문에서 뺐다. 다섯 발생의 위치는 각각 needle tuner 정확도 답변 뒤, strobe tuner 유형 답변 뒤, Turbo Tuner 속도 답변 뒤, alternate tunings 목록 뒤, temperament 답변 뒤다.

## 판독 범위

원문, 후보, 전체 순서 패킷을 처음부터 끝까지 대조했다. 후보는 원문과 줄 차이가 없었다. 새 본문은 후보에서 위 다섯 UI 문자열만 제거했고 나머지 문장은 그대로 유지했다.
