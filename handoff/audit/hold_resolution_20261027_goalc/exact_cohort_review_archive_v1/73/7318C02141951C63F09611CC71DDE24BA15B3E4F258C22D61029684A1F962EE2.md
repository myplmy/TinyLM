# 1220019 보류 원형

## 수식 구성 및 CASE 결과에 직접 의존하는 문장

`This formula utilizes two functions: CASE() and MOD().`

`The CASE part of the formula is what returns the name of the day of the week; you can see above that the result that corresponds with the value 3 is “Wednesday”.`

원문에 표시된 MOD 식은 있지만 CASE 값-결과 매핑이 없다. 첫 문장은 소실된 CASE 부분을 포함한 식의 구성 주장이고, 둘째 문장은 특정한 값-결과 대응 주장이라 두 문장을 보류했다. 별도의 완결된 일반 함수 서명/설명 `CASE(expression, value1, result1, value2, result2,…, elseResult)`와 CASE 함수 설명은 본문에 유지해 실제 API 이름을 보존했다.

## 첫 번째 손상된 DATEVALUE 식

원문 그대로:

`So we’ll add x to the Created Date to show the next Saturday: DATEVALUE(CreatedDate)+(6-MOD(DATEVALUE(CreatedDate)-DATE(1900,1,7),7).`

수식의 닫힘 경계가 손상돼 있다. 수식만 분리했고, 앞 문장의 x 정의와 뒤의 명시된 조건 설명은 보존했다.

## IF 수식

원문 그대로:

`So we’ll add an IF statement to add a week when the desired day of the week has passed in that week: DATEVALUE(CreatedDate)+(6-MOD(DATEVALUE(CreatedDate)-DATE(1900,1,7),7)+IF(6-MOD(DATEVALUE(CreatedDate)-DATE(1900,1,7),7>=6,7,0).`

피연산자/닫힘 괄호 경계가 불완전하므로 수식 자체만 보류했다. IF의 조건부 역할을 설명하는 앞뒤 완결 문장은 유지했다. 수식이나 CASE 매핑을 추정하지 않았다.
