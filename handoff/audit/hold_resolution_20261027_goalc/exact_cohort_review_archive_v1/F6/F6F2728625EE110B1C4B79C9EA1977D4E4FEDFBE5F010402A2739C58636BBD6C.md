# 2491 — 원형 보류 근거

| 원문 범위 | 처리 이유 |
|---|---|
| `CPU(, central/main processor)` | 실제 명칭 `CPU`와 채워진 `central/main processor`는 보존하고 빈 별칭 슬롯 앞의 쉼표만 정리함. 다른 확장명은 추정하지 않음. |
| `인출` 절의 마지막 독립 조각 `프로그램 내부의 명령어의 위치(주소)` | 해당 명사구 뒤 서술어·값이 없어 어떤 주소 관계를 말하는지 정할 수 없으므로 조각만 보류함. 앞의 완결된 인출 단계 설명은 유지함. |
| `싱글 코어 및 다중 코어를 칭하는 명칭은 다음과 같다.` | 예고된 목록이 실제로 뒤따르지 않아 이 예고문만 보류함. 다음 문단의 CPU 속도·코어 설명은 보존함. |

본문에는 HOLD 메모를 넣지 않음. 도입부와 `설계와 구현` 절에 반복된 CPU 기본 구성 문장은 실제 서로 다른 문맥에 놓여 있어 임의 삭제하지 않음. 실제 명명 제조사 목록, 역사·명령 주기 단계와 모든 수치·설명은 원순서로 유지함.
