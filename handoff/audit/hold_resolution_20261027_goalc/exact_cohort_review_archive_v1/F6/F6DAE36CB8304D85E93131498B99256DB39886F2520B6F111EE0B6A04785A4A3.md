# expanded_train:300819 분리 원형

`$hget(name/N)`와 `$hget(name/N, item, &binvar)` 등 실제 명명된 API 설명은 본문에 보존했다. 아래 문장은 설명 대상 API 이름이 빠졌거나 호출 인수가 비어 있어 직접 보류한다.

```text
Returns the data associated with an item in the specified hash table.
You can also reference the Nth data value directly with $hget().data.
```
