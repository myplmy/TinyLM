# 9025 원형 보류 — 빈 어원/별칭 필드와 내용 없는 링크 표제

리드의 화살표 관계는 양쪽 값이 빠져 있어 괄호 구간 전체를 원형으로 보류했다. `백신 또는 예방주사`의 명명된 표제와 실제 정의는 본문에 유지했다.

```text
백신(← ,  ←  ← )
```

`바이오백신()`의 빈 괄호 껍데기만 제거하고, 실제 명명된 `바이오백신` 표기는 유지했다. 원형은 다음과 같다.

```text
바이오백신()
```

실제 링크가 없는 `외부 링크` 표제만 본문에서 분리했다. `각주 및 참고 문헌`에는 실제 출처가 있으므로 그대로 보존했다.
