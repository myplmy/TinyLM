# 51365 원형 보류 기록

## 입력 범위

지정된 0001–0004 패킷에서 원문·후보·전체 diff를 순서대로 실제 END까지 읽었다.

## 원형 보류 조각

`마이크로소프트 워드 2007 이후에서는 [빈 문자열]라는 긴 워드 사용법이 출력된다.`

`마이크로소프트 워드 2013 이후에서는 [빈 문자열]라는 워드 신기능 홍보 문구가 출력된다.`

실제 출력 문자열이 비어 있어 각 버전의 빈 안내/출력 문장 전체를 본문에서 분리했다. 누락된 문자열·명령·홍보 문구를 만들지 않았다. `=rand()`와 `=rand(N,M)`는 원문에 적힌 실제 명령 표기이므로 그대로 보존했다. 후보가 제거한 내용 없는 `각주` 표제도 되살리지 않았다.
