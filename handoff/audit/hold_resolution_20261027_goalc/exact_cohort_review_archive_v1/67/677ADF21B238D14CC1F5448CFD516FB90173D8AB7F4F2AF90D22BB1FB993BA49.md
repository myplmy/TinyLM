- `At this point, no fields or form elements are focused. A manual way to blur a`에서 `A manual way to blur a`는 목적어가 소실된 미완 조각이므로 그 부분만 분리했다. 앞의 초점 없음 문장과 뒤의 독립 API 설명 `blur() method only removes focus from its object, without giving focus to any other field in the form or in the page.`는 본문에 보존했다.
- `August 10, 2000|`의 마지막 `|`는 날짜 뒤에 홀로 남은 구분 기호여서 정리했다. 날짜, 앞의 제목 줄, 뒤의 실제 제목·발행 팁·저자 표시는 유지했다.

`blurevent`, `textobject`, `blur()method`는 각각 `Blur event`, `text object`, `blur() method`로 단어 경계를 최소 정리했다. HTML 예제의 실제 `onFocus="this.blur()"`, `SIZE="40"`, `VALUE` 문자열은 그대로 보존했다. API 동작이나 코드 결과는 새로 만들지 않았다. 이전 v1 초안에서 미완 조각은 줄 안에 남아 있었으므로 그 파일은 보존하고 v2에서 바로잡았다.
