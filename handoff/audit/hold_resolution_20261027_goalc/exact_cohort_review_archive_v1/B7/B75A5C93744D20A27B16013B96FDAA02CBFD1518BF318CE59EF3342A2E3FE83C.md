# 1432460 원형 보류

original과 candidate는 지정 동일성 계획에서 바이트 동일성이 연결되었다. 다음 조각은 미완 프로그램 포인터, 그에 직접 의존하는 실행/결과 주장, 붙어버린 코드 호출, 그리고 댓글 UI이므로 학습 본문에서 분리한다. 없는 프로그램이나 문장 연결은 채우지 않는다.

## 누락된 프로그램 및 직접 의존 주장

> Save the following text to a file called hello.py
> Run the program (ideally using a Python virtual environment) in your console.
> projects > python ./hello.py hello world

> so we have printed the string “hello world” using the print function.
> We have passed a string to the print function.

첫 번째 부분은 “following text”가 있으나 실제 프로그램이 빠져 있고, 뒤 콘솔 실행 줄 및 앞뒤 실행 주장은 그 예제/출력에 직접 의존한다. 실행을 보충하지 않는다. `hello world`를 string이라 부르는 설명과 “printing” 용어 설명, 함수에 전달하는 것을 argument라 부르는 독립 정의는 본문에 남겼다.

## 붙은 예제 코드 및 페이지 UI

> print("hello", end="...") print("Bob")

두 print 호출 사이의 구분이 없어 정상 실행 예제로 복구하지 않는다. `end` 매개변수 설명은 본문에 보존했다.
