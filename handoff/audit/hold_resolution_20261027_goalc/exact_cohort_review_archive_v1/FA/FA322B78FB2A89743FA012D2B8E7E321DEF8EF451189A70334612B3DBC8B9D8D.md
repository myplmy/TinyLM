# validation:1386 원형 HOLD

## 보류 원문

```text
The file should contain the following
numbers, one per line:
The file should contain the following numbers, one per line:
```

## 이유

두 입금/출금 파일 소개 뒤에 `following numbers`를 예고하지만 실제 숫자 목록은 없다. 없는 예시 금액을 채우지 않고 목록 포인터만 분리했다. `deposits.txt`/`withdrawals.txt`, assignment의 월중 입금·출금, 시작 잔액 500.00 및 이자 설명은 본문에 유지했다. 질문자가 올린 원형 코드 조각은 문제 맥락의 자료이므로 토큰·이름·값을 보정하거나 실행하지 않고 그대로 본문에 두었다.
