# expanded_train:275260 정리 근거

- 지정 원문·후보와 연속 패킷 0001–0004를 순서대로 읽어 논리적 END 및 최종 full_diff END를 확인했다. 새 본문은 후보 대비 모든 diff hunk와 EOF를 확인했다.
- 후보가 이미 비어 있던 `3삼매(三三昧, )`와 `공(空, )`의 병기 슬롯, 그리고 내용 없는 `참고 문헌` 표제를 제거했다. 그 실제 명칭·정의 문장은 보존했다.
- 원문에 남아 있던 다음 빈 번역/병기 슬롯은 미상 어형을 만들지 않고 제거했으며, 이미 채워진 한자어·한정어·정의는 보존했다:
  - 원형:
    ```
    공삼매(空三昧,
    , )에서의 공은 후자의 경우이다.
    ```
    본문에서는 `공삼매(空三昧)에서의 공은 후자의 경우이다.`로 최소 정리했다.
  - 원형:
    ```
    무상삼매(無相三昧,
    ,
    )는
    ```
    본문에서는 `무상삼매(無相三昧)는`로 최소 정리했다.
  - 원형:
    ```
    무원삼매(無願三昧,
    ,
    )는
    ```
    본문에서는 `무원삼매(無願三昧)는`로 최소 정리했다.
- 말미 `각주` 표제는 내용 없는 필드 표제여서 분리했다. 뒤의 실제 `불교 용어`, `삼매` 항목은 원래 순서대로 유지했다.
- 새 본문에는 EOF 개행이 한 개 들어갔다. 후보의 끝 내용과 항목은 그대로 보존했으며 끝 바이트를 잘라 맞추지 않았다. 이 줄바꿈은 diff에 표시된 그대로 기록한다.
- 불교 용어·교설이나 다른 외부 사실을 검증하거나 새 번역·병기 값을 보충하지 않았다.
