# expanded_train:193402 원형 보류 메모

원문과 candidate의 지정 full_diff에는 변경이 없었다. 실제 채워진 명칭·수치·단위·관계는 candidate에서 유지했다.

## 본문에서 분리한 원형 빈 필드

- `대한민국 : `, `러시아 : `, `콜롬비아 : `: 나라별 목록의 항목명만 있고 해당 국가의 상륙정 값이 비어 있어 전체 원형 줄을 보류했다. 국가별 장비를 추정하거나 새로 연결하지 않았다.
- `레이다:`: 미국 해군 제원 목록의 값 없는 항목 행을 보류했다.
- `외부 링크 `: 링크 내용이 없는 표제이므로 본문에서 분리했다. 채워진 `같이 보기` 목록과 `상륙정` 분류는 유지했다.
- 빈 `()`는 `다목적상륙정` 뒤 선택 병기 슬롯으로 기록하고 이름·정의는 유지했다.
- 인도 행은 원형 `인도 : , Mk. IV LCU`에서 값 없는 선행 슬롯/고아 쉼표만 분리해 실제 명시값 `Mk. IV LCU`와 국가 귀속을 유지했다.

`육군 : LCU 2000/`는 candidate의 실제 문자열 그대로 본문에 보존했다. 슬래시의 기능이나 빠진 뒤 값을 확정하지 않았고, 별도 값을 생성하지 않았다.
