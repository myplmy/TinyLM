# 654487 원형 보류

본문에서 직접 대상이 없거나 미완인 구절을 원형으로 보류한다. 실제 함수명·값·완결 코드·독립 설명은 본문에 보존한다.

- `In GDAL RFC17 file , implemented Python’s new namespace` / `ogr are both included under this namespace.` — RFC17 설명에 주어/동사 관계가 손상돼 대상이나 문장을 안전하게 복원할 수 없다.
- `>>> import gdal usr(/lib/python2.6/dist-packages/osgeo/gdal.py:99: ...` — 경고 예시는 일부만 남아 있다. 경고가 존재한다는 원문 서술은 유지한다.
- `The following statement can be used to register all data drivers at one time, but only read but not write:` — 뒤에 지시된 실제 statement가 없다.
- `Some different types of data-driven encodings have already been introduced in the table [tab:gdaL_format].` — 가리키는 표/형식 값이 본문에 없다.
- `the correct format is` — GeoTiff 실패 문장의 정답 형식 이름이 소실됐다. GeoTiff 실패 주장과 뒤의 명명된 제목은 별도로 보존한다.
- `It can be seen that in different Debian distributions, the number of GDAL support drivers is still relatively large (table [tab_gdal_drv_num]). This aspect shows that the development of GDAL is still very fast, on the other hand, it also shows that GDAL is now relatively mature.` — 근거로 지목된 표와 비교값이 없다.

없던 모듈명, 형식명, 드라이버명/값, 표 데이터나 경고 내용은 보충하지 않았다.
