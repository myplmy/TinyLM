# expanded_train:222 보류 원형과 경계

| 원형 텍스트 또는 위치 | 처리 경계와 근거 |
|---|---|
| 빈 `영어:` 표기와 빠진 수식 뒤의 `와 ,` | 내용 없는 영어 표기와 분리 구두점만 정리했다. 실제 표기 기호를 보충하지 않았다. |
| `브라와 켓이 서로 변환될 수 있는 것처럼(를 으로 만듦으로써), 에 상응하는 쌍대공간의 원소는 이다. 이때 는 연산자 의 에르미트 수반이다. 다시말해,` | 식별자·변환 대상과 수식이 빠져 그 직접 관계를 복구할 수 없다. 이 단락을 보류하고 브라/켓의 일반 정의와 실제 기호가 명시된 리스 대응 문장은 본문에 둔다. |
| `만약 가 행렬로 표현된다면, 는 의 켤레전치이다.` | 조건의 주체와 행렬·켤레전치 대상 기호가 모두 비어 있어 어느 관계인지 알 수 없으므로 문장 전체를 보류한다. |
| `인 자기수반연산자는 양자역학에서 중요한 역할을 한다.` 및 `만약 가 자기수반연산자이면, 는 항상 실수이다(복소수가 아니다). 이것은 관측가능량의 기댓값이 실수임을 의미한다.` | 첫 절의 대상과 뒤의 변수·값 관계가 소실됐다. 이 단위는 보류하되 독립적으로 완결된 `예를 들어, 관측가능량은 항상 자기수반연산자로 표현된다.`는 본문에 보존한다. |
| 성질 도입문의 `무엇을 다음과 같이, 과 는 임의의 복소수이고, 는 의 켤레 복소수를 의미하며, 와 는 임의의 선형 연산자를 나타내고` | 성질에 사용된 문자와 식이 사라져 정의되지 않은 기호 관계를 남기지 않는다. 도입의 완결 문장과 `이러한 특성은 브라와 켓 어느것을 골라도 적용된다.`는 그대로 본문에 보존한다. |
| `선형성` 아래의 `브라가 선형 범함수` 및 `일 때, 덧셈의 정의와 쌍대공간에서의 선형 범함수의 스칼라곱의 정의에 따라 다음과 같다.` | 필요한 브라·켓, 계수, 수식과 조건이 비어 있다. 제목·미완 문장·직접 수식 지시를 함께 보류하며 선형 범함수의 독립 정의 문장은 앞 절에 유지한다. |
| 연관성 절의 `예를 들어:` 뒤 빈 예시와 `등과 같다. 식의 오른쪽(어떠한 괄호도 없는)과 표현은 중의적이지만 표현되는 것이 허용된다. 왜냐하면 왼쪽의 표현과 같기 때문이다.` | 빈 예시의 식·좌우 표현에 직접 의존하므로 이 연결과 설명을 보류한다. 완결된 결합성 설명과 비선형 연산자 표현에 대한 별도 한정문은 본문에 보존한다. |
| `브라–켓 표기법은 특히 에르미트 수반(또는 데거라고 하며 으로 표시한다.)의 표현이다.`에서 `으로 표시한다`가 받는 기호 | 실제 기호가 없으므로 그 기호 설명만 분리한다. 에르미트 수반의 일반 설명과 채워진 규칙은 본문에 보존한다. |
| 에르미트 수반 규칙 예시 도입의 `아래는 몇가지 예시이다.` 및 빈 `켓:`, `내적:`, `행렬 원소:`, `외적:` 항목과 `Note 가 스칼라,Hermitian 복합 단지는 복잡한 공액,즉` | 각 예시의 기호·식·결론이 없거나 문장이 끊겼다. 예시 블록만 보류하며, 실제로 완결된 에르미트 수반 규칙과 일반 설명은 보존한다. |
| `브라와 켓의 합성` 아래 `두 힐베르트 공간 와 는 텐서곱을 통해 또다른 공간 을 형성할 수 있는데, ...`부터 `이러한 곱의 적용은 양자 얽힘과 EPR 역설을 참고하라.`까지 | 두 공간·합성 대상·곱 표기와 조건이 소실돼 특정 관계 및 후속 지시를 독립적으로 읽을 수 없다. 해당 합성 설명 블록만 원형 보류하고, 앞뒤의 다른 독립 설명을 보존한다. |
| `단위 연산자` 절의 정규직교 기저·노름·켓 표현·내적 및 항등 연산자 결론 블록 | 기저, 노름, 켓과 내적의 식별자가 비어 있고 결론도 그 식에 직접 의존한다. 빠진 기호나 항등 연산자 수식을 만들지 않고 이 절의 해당 블록을 보류한다. |
| `수학자들에 의해 사용된 표기법` 아래 `를 힐베르트 공간이라고 하고`부터 괄호 안 세로선을 제거한 식을 얻는다는 마지막 문장까지 | 힐베르트 공간·벡터·쌍대공간·위상동형·내적·대체되는 기호의 이름이 소실되어 문장 관계를 정할 수 없다. 해당 기호 중심 블록을 보류한다. 앞의 `브라-켓 표기법을 사용할 때 물리학자가 고려하는 대상은 힐베르트 공간 (완비 내적 공간)이다.`는 독립적으로 완결돼 보존한다. |
| `참고 서적` 및 `니다. 또한 자신의 표준 텍스트, 양자 역학의 원리,IV edition Clarendon Press(1958년),` | 참고 서적 표제 아래 실제 서지 항목의 시작과 앞 문장의 시작이 소실되어 서명·저자·서지 관계를 추정할 수 없다. 해당 조각과 빈 표제만 보류한다. |
| 빈 `각주` 표제 | 뒤에 각주 내용이 없어 표제만 정리한다. |

실제 꺾쇠 `⟨`, `⟩`와 수직선 `|`, 채워진 Riesz 문장의 `〈ψ|` 및 `|ψ〉`, 켓/브라의 행·열벡터 설명, 복소공간·유한차원 등 완결된 조건과 관계는 본문에서 유지한다. 빈 수식의 내용이나 기호·인수를 추정하지 않는다.
