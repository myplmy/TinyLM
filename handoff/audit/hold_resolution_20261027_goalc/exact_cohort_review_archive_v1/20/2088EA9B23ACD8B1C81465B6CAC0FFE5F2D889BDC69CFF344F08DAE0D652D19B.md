# 1279865 원형 보류 v4

## 지정 입력 원형

- 빈 `using the following files:` 예고만 분리했다.
- 같은 analog input 설명에서 `A2-A5`와 `labeled A0 through A11`은 양립하지 않는 pin 범위이므로 두 범위만 각각 원형 보류했다. 공통으로 실제 명시된 4 analog inputs, 모든 analog input의 digital I/O 사용 가능성, 10-bit/1024값은 본문에 남겼다.
- 기본 analog measurement upper range를 5 volts로 말하는 구절은, 같은 자료의 3.3V 전원 구동 관계가 별도 확인되지 않아 보류했다. 상한을 analogReference()로 바꿀 수 있다는 완결 능력은 보존했다.
- `For details, see the reference`는 값이 없는 참조 포인터라 분리했다.

## 추가 형식 정리 원형

- EEPROM 라이브러리 설명의 열린 괄호 뒤에 실제 완결 문구가 이어져 닫는 괄호/마침표만 구조적으로 보완했다.
- `.inf file is required` 뒤의 고립 `>`만 제거하고 문장 경계를 정리했다.
- `Keyboard and Mouse` 제목의 빈 나머지 포인터만 마침표로 닫았다.

3.3V 공급 설명, 다른 핀/API/값, 시리얼/USB/프로그램·업로드·리셋·치수 설명은 유지했다. 12개 analog inputs라는 계산이나 A2-A5로의 범위 정정을 하지 않았고, 5V를 3.3V로 바꾸거나 회로 결론을 만들지 않았다. 앞선 revised_v3 초안은 두 analog 문장 정제가 실제 적용되지 않아 선택하지 않는다.
