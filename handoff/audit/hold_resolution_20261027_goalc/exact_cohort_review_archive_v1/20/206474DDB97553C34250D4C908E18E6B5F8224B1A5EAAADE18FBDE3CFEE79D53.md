## stand-alone 예제와 그 출력

> To run a stand-alone QuestionGenerator:
> from haystack.nodes import QuestionGenerator text = """Python is an interpreted, high-level, general-purpose programming language. Created by Guido van Rossum and first released in 1991, Python's design philosophy emphasizes code readability with its notable use of significant whitespace.""" qg = QuestionGenerator() result = qg.generate(text)
> The output looks like this:
> [' Who created Python?', ' When was Python first released?', " What is Python's design philosophy?"]

코드 줄 경계가 사라져 실행 예제로 다루지 않았다. 그 예제가 출력했다고 직접 연결된 세 질문도 함께 분리했다.
