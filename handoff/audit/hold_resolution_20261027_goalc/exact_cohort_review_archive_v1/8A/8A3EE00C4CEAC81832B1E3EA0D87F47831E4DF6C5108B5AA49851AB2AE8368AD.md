# 233642 원형 보류 범위

| 원문 조각 | 판정 근거 | 본문 처리 |
|---|---|---|
| `Let's filter out people below 18 in this array:` | 실제 배열/예제가 이어지지 않아 무엇을 필터링하는지 확인할 수 없다. | 이 예고만 분리했다. 앞의 `.filter()` 일반 정의는 유지했다. |
| `Again, I've use the shorthand syntax here as it's very common when using higher order functions, the longer form version of this looks like this:` | `Again`, `here`, `this`가 받는 짧은 형식 및 긴 형식 예제가 모두 빠져 있다. | 이 직접 지시문을 분리했다. 문법이나 예제 코드를 새로 만들지 않았다. |
| `Change the age above to be older than the oldest person (so at least 33), what do you think you'll get back?` / `You get back an empty array.` | 빠진 배열·predicate 예제를 다시 가리키는 질문과 그 특정 실행의 답이다. threshold 33과 결과를 재구성하지 않는다. | 질문과 답을 함께 분리했다. |
| `In this example if no number is larger than the one you filter by then an empty array is the correct response.` | 빠진 예제의 수치 조건과 `the one you filter by`에 직접 기대므로 독립 일반 명제로 바꾸지 않는다. | 이 조건 문장만 분리했다. |
| `Some people get confused by this. It's an empty array (rather than an error or warning) because an array with no items in it, is still a valid response from a filter.` | 앞 절의 `this`와 `It's`는 누락된 구체 답을 가리키지만, 끝부분에는 독립적으로 완결된 빈 배열의 일반 설명이 들어 있다. | 일반 설명을 `An array with no items in it is still a valid response from a filter, not an error or warning.`로 보존했다. 잃은 예제 결과나 threshold는 추가하지 않았다. |

`.filter()`가 predicate로 배열을 거르고, 빈 배열도 유효한 결과라는 일반 설명과 맺음말은 본문에 유지했다. 원형 예시·질문·특정 결과는 이 문서에만 보관한다.
