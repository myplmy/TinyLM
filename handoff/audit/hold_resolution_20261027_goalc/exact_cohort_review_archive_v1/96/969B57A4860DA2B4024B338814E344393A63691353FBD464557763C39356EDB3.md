# 101892 원형 보류

실제 malloc 과제 설명, malloc()/free()/sbrk() 호출과 매개변수 설명, 연결 리스트·비트맵 선택, 메타데이터 구조 설명, 드라이버·채점 조건과 -m32 옵션을 새 본문에 그대로 남겼다. 코드 실행이나 내용을 외부 검증하지 않았다.

직접 의존 구간만 분리했다.
- 실제 그림이 없는 지시: “A better idea is illustrated in the figure below:”
- 뒤따를 실제 명령이 없는 지시: “To create a tar.gz file, if your code is in a folder named project3, execute the following commands:”
- 그 명령의 변수를 받는 조각: “Where USERNAME is your username.”
- 실제 복사 대상이 없는 지시: “Then copy your file to:”

명령·경로·변수 값을 생성하지 않았다.
