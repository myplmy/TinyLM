# 969894 원형 보류

## 미상 값과 표 조각

```text
By default, it is 1433
Consider the following table.
|104||Asst. Manager||2017-06-11 01:00:00|
```

## 대상 없는 날짜 쿼리 예고

```text
Following MySQL query returns the current date:
Following MySQL query returns the current date and time:
Following SQL Server query returns the current date and time:
```

## 근거

`By default`의 대상이 없고, 표 예고 뒤에는 헤더 없는 한 행만 남아 빈 셀의 열 의미를 알 수 없어 그 조각만 분리했다. 날짜 쿼리 예고 세 문장에는 해당 쿼리가 붙어 있지 않다. 바로 뒤 Oracle 예고와 `SELECT SYSDATE FROM DUAL;`는 원문에서 직접 연속해 있으므로 본문에 보존했다. 빠진 쿼리·표 축·1433의 대상은 추정하지 않았다. 나머지 완결된 정의, SQL 구문/예제, 조건, 값과 순서는 보존했다.
