# 128 원형 보류 조각

아래는 지정 원문의 실제 구간이다. 비어 있는 기호·수식이나 그 직접 의존 설명을 새 본문에서 분리했다. 빠진 값이나 관계는 채우지 않았다.

- `기호는 그리스 문자 이다.` — 그리스 문자 뒤의 실제 기호가 원문에 없다.
- `광자 한 개의 에너지는 플랑크 상수()에 빛의 진동수()를 곱한 값, 즉  이고, 운동량은 (는 광속)이다.` — 괄호 안 두 기호, 즉 뒤 식, 운동량 표현의 대상, 광속 기호가 소실됐다. 본문에는 원문이 명시한 말 설명인 `광자 한 개의 에너지는 플랑크 상수에 빛의 진동수를 곱한 값이다.`를 보존했다.
- `광자에너지` 아래 `빨간색의 광자에너지는 `, `아보가드로 상수는`, `이다. 따라서 단위물질량당 광자에너지는` — 각 구절의 수식/값이 없으므로 해당 계산 문맥을 보류했다.
- `각주` — 뒤에 각주 내용이 없는 표제다.

완결된 광자 설명과 역사 서술, 실제 외부 링크와 범주 항목은 새 본문에 유지했다. 원문에 없는 수치·기호·수식·광자에너지 값은 추가하지 않았다.
