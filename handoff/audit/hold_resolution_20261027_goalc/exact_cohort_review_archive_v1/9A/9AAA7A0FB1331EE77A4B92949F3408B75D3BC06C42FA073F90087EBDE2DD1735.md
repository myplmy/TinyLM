# expanded_train:97960 원형 보류 근거

현재 배정 원문·candidate·세 순서 패킷과 full diff를 읽었다. 아래는 학습 본문에서 분리한 원문 구간이다. 수식·변수·집합을 추정해 채우지 않는다. 이는 수학적 사실을 외부 검증한 판단이 아니라, 현재 텍스트에서 직접 확인되는 주체와 조건만 남기는 범위 정리다.

## 원형 보류 구간

### 볼록 집합의 형식 정의

원문:
```text
정의 
실수 위상 벡터 공간 의 부분 집합 가 다음 조건을 만족시키면, 볼록 집합이라고 한다.
 임의의  및 에 대하여, 
```

공간·집합과 두 점·조건식이 비어 있어 정의의 대상과 조건을 판정할 수 없다. 빈 정의 제목은 본문에서 함께 분리했다.

### 다각 연결 집합의 형식 정의와 변수 의존 연결

원문:
```text
다각 연결 집합 
실수 위상 벡터 공간 의 부분 집합 가 다음 조건을 만족시키면, 다각 연결 집합()이라고 한다.
 임의의 에 대하여, 다음 세 조건을 만족시키는 자연수  및 가 존재한다.
 
 
 각  및 임의의 에 대하여, 
위 정의에서 을 어떤 자연수로 고정하면, -다각 연결 집합()의 정의를 얻는다.
```

정의의 집합·양화 대상·세 조건·고정할 수와 다각 연결 집합의 기호가 소실됐다. 명명된 개념을 빈 조건으로 완결된 정의처럼 만들지 않도록 이 정의와 직접 연결되는 첫 문장만 보류했다. 원문 바로 뒤의 `이 경우, 볼록 집합은 1-다각 연결 집합과 동치이다.`는 실제 명명 관계가 문장 안에 남아 있어 본문에 보존했다.

### 소실된 기호에 직접 의존하는 함의 구간

원문:
```text
모든 -다각 연결 집합은 다각 연결 집합이다. (그러나 다각 연결 집합은 어떤 에 대하여 -다각 연결 집합일 필요가 없다.)
```

두 곳의 다각 연결 차수와 양화 대상이 비어 있으므로 해당 관계와 괄호 문장을 함께 보류했다. 앞의 경로 연결 문장과 뒤의 별모양·볼록 집합 관계는 완결되어 있어 보존했다.

### 티체-나카지마 정리와 두 일반화

원문:
```text
유클리드 공간 의 부분 집합 에 대하여, 만약 가 닫힌집합이며, 연결 공간이며, 국소 볼록 집합이라면, 는 볼록 집합이다 (티체-나카지마 정리, ). 보다 일반적으로, 만약 가 닫힌집합이며, 연결 집합이며, 개 이하의 국소 비볼록점을 갖는다면, 는 -다각 연결 집합이다. 보다 일반적으로, 만약 가 닫힌집합이며, 연결 집합이며, 의 국소 비볼록점의 집합이 (서로소일 필요가 없는) 개의 볼록 집합의 합집합이라면, 는 -다각 연결 집합이다.
```

각 명제의 ambient space·부분집합·개수·결론의 차수가 비어 있다. 티체-나카지마 이름만 남겨 정리 내용을 새로 요약하거나, 소실된 일반화 조건을 삭제해 보편 명제로 바꾸지 않고 해당 단락 전체를 보류했다.

### 볼록 성분에 관한 미상 집합·조건

원문:
```text
부분 집합의 극대 볼록 집합 
실수 위상 벡터 공간 의 부분 집합 가 주어졌다고 하자. 의 볼록 집합들은 포함 관계에 따라 부분 순서 집합을 이룬다. 그 극대 원소를 의 볼록 성분()이라고 한다. 의 임의의 볼록 집합은 의 볼록 성분에 포함되며, 임의의 볼록 성분은 연결 집합이므로, 의 유일한 연결 성분에 포함된다.
```

고려하는 공간·부분집합이 반복해서 비어 있고 포함 관계의 대상도 빠져 있어 정의·귀속·포함 주장을 보류했다. 같은 문단 뒤의 독립 완결 문장 `그러나 연결 성분과 달리, 볼록 성분들은 서로소일 필요가 없다.`는 접속어만 제거한 채 본문에 남겼다.

원문:
```text
만약 가 닫힌집합이라면, 모든 볼록 성분 역시 닫힌집합이다.
```

닫힌집합인 대상이 비어 있어 조건의 주체를 확정할 수 없어 보류했다.

원문:
```text
실수 위상 벡터 공간 의 부분 집합 가 가산 개의 의 서로소 볼록 닫힌집합 들의 합집합이라면, 의 볼록 성분들은 정확히 들이며, 특히 의 볼록 성분들은 의 분할을 이룬다.
```

공간·집합·가산 개수·각 포함 대상·결과 집합이 비어 있어 이 전체 조건문을 보류했다.

### 집합 예시

원문:
```text
집합

은 경로 연결 공간이지만, 의 다각 연결 집합이 아니다.
```

예시의 대상 집합과 후속 관계의 주체가 비어 있어 제목과 문장을 함께 보류했다. 다른 예시인 `실수선 의 볼록 집합은 단순히 구간이다.`는 `실수선의 볼록 집합은 단순히 구간이다.`로 빈 기호 자리를 제거해 명명된 대상과 문장 관계를 보존했다.

### 비어 있는 표제

원문에 항목이 없는 `참고 문헌` 및 `외부 링크` 표제는 내용을 새로 만들지 않고 본문에서 제거했다. 원형 표제는 이 기록에 보존한다.

## 보존 범위 메모

명명된 국소 볼록 집합 설명, 실제로 완결된 다각 연결/별모양/볼록 집합 관계, 실수 노름 공간의 연결 열린집합 서술, 볼록 성분의 서로소 비필요성, 실수선 예시, 역사 서술, 실제 같이 보기와 분류명을 새 본문에 남겼다. 원문에 없는 수식·기호·공간·집합 이름·개수·정리 조건을 추가하지 않았다.
