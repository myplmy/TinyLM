# 838628 보류 원형

본문에서 다음 원문 단위는 제외했다.

1. `A function definition could look like:`와 `fmcwPulse (priInt1, priInt2, pause1, pause2, trcf , txwst1 , txwst2 , rxwst , bfwst )`, 이어지는 두 `PRI(...)` 행. 인수·정의 범위가 완결되지 않은 함수 정의 예시다.
2. `The above REPEAT loop could then be written:`와 뒤의 `fmcwPulse (5e-3,6e-3, ” tr0rx12 “, ” txfmcwup “, ” txfmcwdown “, ” rxfmcw1 “, ” bfwide7″)` 호출. 바로 앞 정의의 인수/호출 관계에 의존한다.
3. `The following is an example aiRPL program, which uses the above fmcwPulse function definition.` 이 문장은 보류한 정의를 직접 지시한다.
4. `LOAD LUT (10e-3, ” fmlut 15 “) // load beamforming tables`, `REPEAT (8) // outer loop repeats 8 times`, `REPEAT (32) // inner loop repeats 32 times`, `fmcwPulse (5.0e-3, 6.0e-3, 1e-3, 2e-3, ” tr0rx12 “, ” txfmcwup “, ” txfmcwdown “, ” rxfmcw1 g”)`. 이 중첩 예시의 끝과 호출의 arity/인수 연결이 명확하지 않아 단위 전체를 보류했다.

추출 손상인지 저자의 미완 또는 잘못된 예시인지는 판정하지 않았다. 별도로, 본문에는 `An aiRPL program is defined within a main() call. After loading a set of beamforming tables, this program generates 8 sets of 32 pulses. Each set of pulses is identical. There is a one millisecond pause between each set of pulses.`와 `All text following a double slash ... is a comment.`를 원문대로 남겨, 명시된 수와 조건을 보존했다. 입력 인수·코드 경계는 보충하지 않았다.
