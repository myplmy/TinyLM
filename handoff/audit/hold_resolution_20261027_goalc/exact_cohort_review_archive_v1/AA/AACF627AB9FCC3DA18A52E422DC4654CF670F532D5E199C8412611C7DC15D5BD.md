# 경로 입력 오류 기록

이 기록은 호출 당시의 확인 응답과 작업 기억을 구분해 남긴다. 잘못된 경로의 원문·후보를 다시 열거나 내용·해시를 확인하지 않았다.

## 잘못된 원문 경로 호출

1. 실행 명령:
   `nl -ba /home/uranus/tinyLM/data_cache/p106b_hold_resolution_v1_20261027_goalc/agents/context_hangul/repeat_named_full_independent_v1/inputs/expanded_train_1008072_original.txt`
   관측 응답: 줄 번호가 붙은 텍스트 본문이 실제 반환됐다. 반환 내용 첫 줄은 `The category “Science” has 4 subcategories...`였고, 도구는 출력이 잘렸다고 알렸다. 따라서 “원문을 읽었다”는 말은 호출 시도만을 뜻하지 않고, 이 잘못된 경로의 원문 내용을 실제로 받았다는 뜻이다. 해당 반환을 지정 입력 판독의 근거로 사용하지 않는다.

2. 실행 명령:
   `sed -n '45,68p' /home/uranus/tinyLM/data_cache/p106b_hold_resolution_v1_20261027_goalc/agents/context_hangul/repeat_named_full_independent_v1/inputs/expanded_train_1008072_original.txt`
   관측 응답: 해당 구간의 실제 텍스트가 반환됐다. 이것도 잘못된 경로에서 내용을 받은 것이며 지정 입력 판독에서 제외한다.

## 잘못된 후보 경로 호출

1. 실행 명령:
   `sed -n '81,120p' /home/uranus/tinyLM/data_cache/p106b_hold_resolution_v1_20261027_goalc/agents/context_hangul/repeat_named_full_independent_v1/inputs/expanded_train_1008072_candidate.txt`
   관측 응답: `sed: can't read ...: No such file or directory` 오류만 반환됐고 후보 본문 텍스트는 반환되지 않았다. 이는 호출 시도였으며 이 호출로 후보를 읽었다고 할 수 없다.

## 상태

잘못된 원문 경로에서 반환된 내용은 판정에 사용하지 않는다. 잘못된 후보 호출은 실패했으며 후보 내용이 오지 않았다. 이 경로 오류 때문에 1008072 판독은 아직 마감하지 않았고, 이 기록을 쓰는 시점에 리뷰나 선택 본문 수정은 만들지 않았다. 이후 작업은 총괄이 정확 입력 경로와 재개 범위를 제공한 뒤 그 지시를 따른다.
