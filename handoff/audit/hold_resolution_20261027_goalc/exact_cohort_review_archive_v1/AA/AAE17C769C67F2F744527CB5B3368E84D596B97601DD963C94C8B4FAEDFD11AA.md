# 533 결손 수식 및 직접 의존 원형

원문과 후보는 같았다. 아래 원형에는 기호·변수·식 또는 식이 들어갈 대상이 비어 있어 그 값을 추측하지 않았다. 완결된 자연어 설명과 실제 수치·관계는 본문에 남겼다.

| 원형 보류 | 근거 |
|---|---|
| `정의` 절: `양의 정수 의 오일러 피 함수 은 정수환의 몫환 의 가역원군의 원소 개수이다. 즉, 1부터 까지의 정수 가운데 과 서로소인 것들의 개수이다.` | 정식 정의의 대상·함수 기호·범위가 소실됐다. 이 절만 원형 보류한다. 리드의 이어지는 완결 자연어 정의와 실제 6, 11, 1 예시는 보존한다. |
| `값` 절: `1부터 80까지의 정수의 오일러 피 함수 값은 다음과 같다.` | 예고된 값 표가 비어 있다. 빈 목록 예고와 표제만 보류하며 수열은 만들지 않는다. |
| `즉, 만약 두 정수 이 서로소라면, 다음이 성립한다.` | 두 정수 변수와 등식이 빠져 있어 곱셈성의 구체 조건 설명을 복원하지 않는다. 직전의 완결 문장 `오일러 피 함수는 곱셈적 함수다.`는 본문에 보존한다. |
| `오일러 피 함수 값은 소인수를 통해 다음과 같이 구할 수 있다. 이를 오일러 곱 공식()이라고 한다.` | 계산식과 공식 표기가 빠졌으며, `이를`의 표적도 결손식이다. |
| `이므로 은 다음과 같이 구할 수 있다.` | 20의 실제 소인수 2와 5는 독립적으로 보존했지만, 이에 따른 함수값·계산식은 비어 있으므로 추가하지 않는다. |
| `그리고, 소수 의 거듭제곱 의 오일러 피 함수 값은`부터 `특히 소수 의 경우` 및 두 `이다.`까지의 블록 | 소수·거듭제곱 변수와 식이 빠진 직접 의존 예시다. |
| `오일러 피 함수를 통해 항등 함수를 다음과 같이 나타낼 수 있다. 이는 레온하르트 오일러가 증명하였다.` | 표현식이 없어 `이는`의 대상과 귀속 관계가 불명확하다. |
| `또한, 다음이 성립한다.`와 `여기서 는 뫼비우스 함수이다.` | 식과 뫼비우스 함수 기호가 빠졌다. |
| `만약 양의 정수 이 서로소라면, 다음과 같은 합동식이 성립한다. 이를 오일러의 정리라고 한다.` | 변수와 합동식이 빠져 있어 정리의 식·대상을 추정하지 않는다. |
| `예를 들어, 군론에서는 순환군 의 가능한 생성원(generator)의 수는 이다. 이는 과 서로소인 임의의 수를 사용하여 를 생성할 수 있기 때문이다.` | 순환군의 매개변수·생성원 수·생성 대상 기호가 빠져 예시 관계 전체를 해석할 수 없다. |
| 정다각형 문단 전체: `또한, 정n각형이 작도 가능한 다각형인지, 즉 눈금없는 자와 컴퍼스만으로 작도할 수 있는지는 이 2의 거듭제곱수인지와 동치이다.`부터 `특히, n이 소수인 경우를 페르마 소수라고 한다.`까지 | `이`가 받는 함수 대상과 두 번째 수열의 표제가 빠져 있다. 수열·작도 가능성·다른 값의 배제·페르마 소수 설명은 같은 결손 관계에 직접 의존하므로 전부 보류하며 수열 대응을 새로 만들지 않는다. |
| 리드의 `오일러 파이 함수(-函數, )` 중 빈 별칭 슬롯; `외부 링크` 빈 표제 | 실제 `-函數` 표기는 보존하고 빈 괄호와 쉼표만 정리했다. 내용이 전혀 없는 외부 링크 표제는 분리했다. |

본문에는 실제 명시된 n/ϕ(n) 정의, ϕ(6)=2·ϕ(11)=10·ϕ(1)=1, 곱셈적 함수라는 완결 문장, `20`의 실제 소인수 2와 5, 다양한 분야에 등장한다는 문장, RSA 역할, 같이 보기 항목과 분류를 보존했다. 계산·수식·누락 기호를 새로 생성하지 않았다.
