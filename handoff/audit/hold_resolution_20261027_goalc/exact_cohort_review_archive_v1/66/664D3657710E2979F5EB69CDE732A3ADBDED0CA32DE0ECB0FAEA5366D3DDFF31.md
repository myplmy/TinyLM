# 732325의 공식 예시 개행 근거

총괄이 원문 52–58행과 R Core 문서의 Examples를 실제 대조했다.

- 원문 ID: expanded_train:732325
- primary: https://stat.ethz.ch/R-manual/R-devel/library/utils/html/aspell.html

원문 58행에 들어 있는 모든 기존 주석/대입/호출이 primary의 같은 예시에서 같은 순서로 나타난다. 첫 두 주석행, Rd의 두 문장, Sweave의 주석과 두 문장, Texinfo의 주석과 두 문장, 사전 목록의 주석과 마지막 호출이라는 총 12행 경계만 복원할 수 있다. 기존 비공백 토큰과 문자열을 바꾸지 않는다.

공식 문서에만 있는 바깥 Not run/End 표시와 새 필터/인자/버전 설명은 본문에 추가하지 않는다. 현재 R 버전의 실행 가능성이나 런타임 PASS를 주장하지 않는다. 명시된 예시와 원문이 실제로 일치하는 이번 구간에만 적용한다. 다른 자료의 평탄화된 주석과 for/if의 범위를 유추하는 일반 허가는 아니다.

원문의 실제 서지 항목과 저자·연도·권호·쪽수는 보존한다. Luna가 새 TXT와 근거 sidecar/review를 작성하고 기존 버전은 보존한다.
