- 원형: `This function is fired when the dispatcher receives a task sequence. It has the following parameters: |Task Sequence||treenode||The task sequence that was received by the dispatcher.|`
- 사유: 표/행의 제목 또는 대상 함수명이 없어 `On Receive Task Sequence` 이벤트인지 앞 문맥의 `Pass To` 함수인지 확정할 수 없습니다. `Task Sequence`와 `treenode` 값은 보존 기록했고, 이를 어느 함수에 귀속하는 새 표제는 만들지 않았습니다. 이름이 명시된 Pass To 반환값 설명과 이벤트 목록은 본문에 유지했습니다.
- 원형 빈 표제: `The Dispatcher object uses the following properties panels:` / `The Dispatcher object uses the following properties:`
- 사유: 두 표제 뒤 실제 패널명·속성명·값이 없습니다. 빈 내용의 표제만 제거했으며 패널/속성 목록을 생성하지 않았습니다.
