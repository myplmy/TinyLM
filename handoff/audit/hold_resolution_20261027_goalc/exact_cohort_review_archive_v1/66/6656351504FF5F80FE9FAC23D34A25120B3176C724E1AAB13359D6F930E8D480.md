## 근거

각 `class`, `def`, `pass`, `print`와 호출이 한 문자열로 이어져 class/method/statement 경계·들여쓰기가 사라진 코드 예제를 분리했습니다. 각 코드에 직접 이어진 IDLE/콘솔 출력, 객체 참조와 주소, 직원 이름·급여·직책 결과도 같은 단위에 두었습니다. 코드를 실행하거나 새 줄바꿈, 들여쓰기, 구분자 또는 실행 가능한 예제를 만들지 않았습니다.

`General syntax for creating instance variable:` 뒤의 일반 구문은 제시되어 있지 않아 그 프롬프트만 분리했습니다. 클래스/인스턴스, 인스턴스 변수, 생성자, `self`, `vars()`·`dir()`에 대한 실제 완결 산문과 함수명·설명 표는 본문에 보존했습니다. 이 파일은 분리된 원형 보관용이며 학습 본문이 아닙니다.
