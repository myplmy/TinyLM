# expanded_train:878870 원형 보류

`Comparison to Regions` 아래 원문은 region operator 일반 설명 다음에 잘린 `While this command`, `®ion` 토큰이 든 명령, 그리고 그 명령의 실패 여부를 잇는 단편을 둔다. `®ion`을 `region` 등으로 복원하지 않고, 그 손상 명령과 직접 연결된 비교 표현만 학습 본문에서 분리한다.

## 원형 조각

```text
While this command
unix% dmcopy "img.fits[sky=mask(mask.fits)®ion(ciao.reg)]" out.fits ERROR
does not work, this command
```

앞의 완결 문장 `Masks cannot be used with region operators "+", "-", "!", "*", "&", and "|".`와 뒤의 완결 `dmcopy` 명령은 보존한다. 다른 명령·데이터 행이나 값의 대응을 임의로 만들지 않는다.
