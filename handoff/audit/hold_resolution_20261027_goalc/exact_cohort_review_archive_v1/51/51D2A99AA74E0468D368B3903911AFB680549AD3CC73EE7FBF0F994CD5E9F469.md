# expanded_train:185696 원형 보류

## 식별 대상이 없는 선두 조각
원문 첫 두 조각을 귀속할 매개변수명이나 표 머리글이 제시되지 않아 분리했다. 뒤의 완결된 본문에는 Save/Restore 명령과 file 매개변수 설명이 별도로 있으므로 그 설명은 본문에 유지했다.

- `save a session to be restored by the package's Restore command`
- `string; string of the filename ending in .m to contain saved session data`

## 페이지 UI
본문 뒤에 붙은 다음 독립 인터페이스 문구는 본문 내용이 아닌 UI 조각으로 분리했다.

- `Download Help Document`
- `What kind of issue would you like to report? (Optional)`

MolecularGeometry 예제의 실제 원문 문자열과 Maple 명령·파일 경로·날짜·설명은 손대지 않았다. 누락된 함수 구문이나 매개변수 이름을 추정하지 않았다.
