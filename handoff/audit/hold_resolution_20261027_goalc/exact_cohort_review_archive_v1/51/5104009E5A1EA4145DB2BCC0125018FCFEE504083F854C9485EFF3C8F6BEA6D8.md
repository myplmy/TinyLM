# expanded_train:1279865 원형 보류 기록

- 첫 문장의 `using the following files:` 뒤에 파일 항목이 없다. 해당 빈 목록 예고만 보류하고 open-source hardware 및 보드 제작 문장은 유지했다.
- 원문 analog 입력 행은 `- Analog Inputs: A2-A5. The LilyPad Arduino USB has 4 analog inputs, labeled A0 through A11, all of which can also be used as digital i/o.`이다. 서로 다른 범위와 개수가 같은 대상 설명에 병기되어 있어 어느 핀 범위를 맞다고 선택하지 않고 해당 두 범위와 개수의 연결만 함께 보류했다. 원문에 독립적으로 적힌 모든 아날로그 입력의 디지털 I/O 사용 가능성, 입력당 10-bit/1024 값, 기본 전압범위, `analogReference()`는 본문에 유지했다. 외부 보드 지식으로 조정하지 않았다.
- `ATmega32u4` 문장의 열린 괄호 뒤에 실제 문구 `which can be read and written with the EEPROM library`가 완결돼 있어 닫는 괄호와 마침표만 보완했다.
- `For details, see the reference`는 뒤따르는 참조 값이 없는 직접 링크 안내라 분리했다. 실제 보드 선택 메뉴와 이름은 유지했다.
- `On Windows, a .inf file is required` 뒤의 고립 `>`를 제거하고 문장 경계를 마침표로 정리했다.

실제 핀 번호, 전압·전류·해상도·버전·API 이름과 동작 설명, 완결된 Arduino 예제/업로드·리셋·치수 정보는 보존했다. 새 코드·값·링크는 넣지 않았다.
