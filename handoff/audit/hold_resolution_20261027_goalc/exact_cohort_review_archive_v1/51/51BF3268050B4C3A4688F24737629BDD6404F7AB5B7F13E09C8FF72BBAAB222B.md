# 1366234 원형 보류 v3

이 파일과 revised_v3 본문을 선택한다. 이전 초안들에는 줄 경계로 남은 일부 결손 조각이 있었으므로 선택하지 않는다. 누락된 속성/API 대상이나 대체 권한 방식을 추측하지 않고 아래 구간만 분리했다.

- 권한 속성을 어느 component에 적용하는지 이어질 이름이 없는 `to (applied to the` 조각.
- Android 버전에 따라 권한을 자동 추가하는 결정의 미상 attribute와 그에 직접 의존하는 조건.
- `If your is 3 or lower`의 빠진 대상, `always update your`의 빠진 대상 및 비어 있는 release 안내 포인터.
- permission declaration 부분의 대상 없는 `using one or more`.
- activity/service의 미상 permission-check timing/API 이름, receiver의 미상 permission-check API 시점.
- `and who can write to it`의 이름 없는 write permission attribute.
- provider method 이름이 빠진 `Using ... requires the read permission; using ... requires the write permission.`
- 이름 없는 fine-grained permission-check method와 이름 없는 direct PackageManager method 설명.
- `android:grantUriPermissions attribute or` 뒤의 누락된 대안.

명시된 권한 속성/태그/인수/플래그, component별 실제 역할, 권한 없는 호출의 SecurityException 조건, broadcast delivery 시 예외 대신 전달이 안 된다는 실제 결과, 완결된 Context API, 예시와 독립적인 URI 권한 설명은 본문에 보존했다. 출력 선택은 본문 v3 하나이며 이 sidecar는 분리된 원형만 기록한다.
