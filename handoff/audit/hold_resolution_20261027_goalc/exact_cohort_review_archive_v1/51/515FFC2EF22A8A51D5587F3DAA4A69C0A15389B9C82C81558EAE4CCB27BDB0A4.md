# 1279865 원형 보류 v5

## 실제 내용 보류

- 원문의 빈 using the following files: 예고만 분리했다.
- 같은 analog input 설명에 함께 있는 A2-A5와 labeled A0 through A11은 서로 다른 핀 범위라 둘 다 원형 보류했다. 같은 설명에 명시된 4 analog inputs 개수는 보류하지 않고 본문에 유지했다.
- 기본 measurement range를 ground to 5 volts라고 하는 정확 절은 같은 보드 문맥의 명시 3.3V 운영 전압과 관계가 미확정이므로 별도 보류했다. analogReference()로 upper range를 바꿀 수 있다는 완결 능력은 본문에 보존했다.
- For details, see the reference는 실제 참조 값이 없는 포인터라 분리했다.

## 형식 정리 원형

원문 EEPROM 설명의 괄호는 열린 채 끝났으나, 괄호 안의 실제 설명이 완결되어 있으므로 닫는 괄호와 문장부호만 보완했다. Windows .inf 요구 문장 뒤의 고립 >만 제거하고 문장을 닫았다.

다른 핀/API/값과 모든 완결 보드·시리얼/USB·프로그램·업로드·리셋·치수 설명은 유지했다. 범위나 전압을 외부 지식으로 선택·변환하지 않았다.
