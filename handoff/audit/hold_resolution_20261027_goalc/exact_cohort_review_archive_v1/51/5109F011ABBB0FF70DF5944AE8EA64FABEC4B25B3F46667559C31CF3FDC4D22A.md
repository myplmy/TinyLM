# 283650 보류 원형과 편집 근거

## 원형에서 분리한 빈 표제

원문에 실제 내용이 붙지 않은 다음 표제는 학습 본문에서 분리했다. 표제 아래의 노선·사진 값을 추정하거나 만들지 않았다.

- `운항 노선`
- `국제선`
- `국내선`
- `화물 노선`
- `사진`

원문에 있던 빈 `통계`와 `각주` 표제도 candidate에서 이미 분리되어 있어 본문에 되살리지 않았다. 이 메모는 해당 원형의 빈 표제만 보류하며, 실제 버스 J1/J2·택시·주차 안내, 애들레이드 공항 홈페이지 표기, 공항 역사·수치·분류는 본문에서 유지했다.

## 판독 범위와 제한

지정된 원문/candidate 입력의 두 패킷과 전체 diff를 읽었다. 새 본문은 candidate에서 시작해 제목의 빈 병기 `(, )`와 위 빈 표제만 정리했다. 빈 표제 아래에 값이 없다는 점 외의 원인을 추정하지 않았으며, 공항 정보의 외부 사실 검증을 수행하지 않았다.
