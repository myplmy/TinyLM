# expanded_train:7599 원형 보류 — v2

영문 Diff mode 문서의 지정된 original, candidate 및 연속 패킷 0001–0005를 읽어 각 논리 END와 full_diff END를 확인했다. 명시된 모드명, 명령명, 실제 hook 코드, 그리고 명령별 채워진 동작 설명은 본문에 보존했다.

## 원형 보류

- 원문 조각: “To disable automatic line number correction, change the variable”. 설정 변수명이 빠져 있어 이 지시를 본문에서 분리했다. 변수명을 추정하지 않았다.
- 원문 조각: “This command has a side effect: it refines the hunk you move to, highlighting its changes with better granularity.” 앞에서 가리키는 명령명이 빠져 있어 이 설명을 분리했다. 이름을 추정해 명령에 귀속하지 않았다.
- 이어지는 “To disable this feature, type M-x diff-auto-refine-mode to toggle off the minor mode Diff Auto-Refine mode.”의 ‘this feature’는 위의 누락된 명령 설명에 직접 기대므로 그 지시어 연결을 본문에서 제거했다. 실제 명명된 `M-x diff-auto-refine-mode`로 해당 모드를 끌 수 있다는 정보와 이어지는 실제 hook은 본문에 보존했다.

실제 `diff-hunk-prev` 뒤의 고립된 닫는 괄호는 제거했다. 다른 명령명·인자·키 조합은 새로 만들지 않았다.
