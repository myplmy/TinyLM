# 74039 원형 보류

후보는 원문과 같으며, 실제 메서드 이름과 설명의 일부 연결이 누락되어 있다. 누락된 이름을 추정하지 않고, 아래 원문 조각만 학습 본문에서 보류한다.

- `The following example demonstrates how to implement a queue using the ArrayDeque class.` 다음에 예제가 없으므로, 빠진 예제를 직접 예고하는 문장.
- `It retrieves, but does not remove, the head of the queue represented by this deque. It returns null if the deque is empty.` 대상 메서드 이름이 없는 설명.
- `It retrieves and removes the head of the queue represented by this deque. If the deque is empty, it returns` 대상 메서드 이름과 반환 내용이 모두 없는 설명.
- `This method returns true if the deque contains no elements, or false otherwise.` 대상 메서드 이름이 없는 설명.

보존한 `1) add(E element)`와 바로 연결된 삽입 설명, 명명된 `offer(E element)`, `element()`/`remove()`와 `peek()`/`poll()`의 원문 관계 및 빈 큐 동작, 나머지 완결 소개와 서술은 유지했다. 위 미상 설명을 목록 순서나 일반 API 지식으로 메서드에 연결하지 않았다.
