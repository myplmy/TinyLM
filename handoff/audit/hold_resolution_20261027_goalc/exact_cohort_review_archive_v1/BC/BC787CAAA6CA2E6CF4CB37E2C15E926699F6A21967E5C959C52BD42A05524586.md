# expanded_train:14054 보류 원형

일본 연호 항목에 실제 값 없는 괄호가 있다. 연호명·연도·같은 행의 순서는 보존하고 빈 괄호만 제거했다.

```text
일본(日本) 조헤이() 8년 / 덴교() 원년
```

본문에서는 `일본(日本) 조헤이 8년 / 덴교 원년`으로 정리했다. 이름·연도·관계를 새로 보태지 않았다.

내용이 없는 범주 표제만 분리했다.

```text
사건

탄생
```

`연호`와 `기년`의 실제 행은 보존했다. `사망` 아래에는 `벽진(碧珍)의 성주(星州) 이총언`이라는 명명된 항목이 있어 해당 표제와 항목을 함께 유지했다.
