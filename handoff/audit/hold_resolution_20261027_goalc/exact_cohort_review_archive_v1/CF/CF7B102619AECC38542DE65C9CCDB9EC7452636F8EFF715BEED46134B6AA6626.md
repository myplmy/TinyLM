# expanded_train:82159 보류 원형

## 빈 병기와 고립 자료 표제

```text
FOAB(Father of All Bombs, ) 또는 정식명칭 ATBIP(, )
각주와 참고자료
```

실제 `Father of All Bombs` 확장명칭을 유지하고 뒤의 빈 쉼표 슬롯만 제거했다. 후보는 ATBIP 뒤의 값 없는 괄호를 이미 제거했다. `각주와 참고자료` 표제 뒤에는 자료가 없으므로 표제만 분리했다.

폭발력·중량·반경의 모든 실제 수치와 단위, MOAB와의 원문 비교, 개발 발표 시점, 방송·인터뷰 발언의 귀속과 조건은 본문에 그대로 보존했다. 원문의 군사적 사실을 외부 검증하거나 새 사실을 추가하지 않았다.
