# 18943 보류 원형

| 원형 조각 | 처리 근거 |
|---|---|
| `불파음(不破音, )` | 실제 용어와 한자 병기를 보존하고 값이 없는 뒤 병기 슬롯만 정리했다. |
| `한국어: 음절 말의 /ㄱ/(), /ㄷ/(), /ㅂ/()에서 이 소리가 난다.` | 세 실제 음소 표기와 한국어 예시 관계를 유지했다. 각 괄호는 값이 비어 있어 정리했으며 다른 음소값을 추가하지 않았다. |
| `광동어: 음절 말의 /k/(), /t/(), /p/()에서 이 소리가 난다.` | 세 실제 음소 표기와 광동어 예시 관계를 유지했다. 각 괄호는 값이 비어 있어 정리했으며 다른 음소값을 추가하지 않았다. |

태국어의 실제 기호·문자 목록, 세 언어의 예시 관계, 본문, `자음`·`파열음` 분류는 보존했다.
