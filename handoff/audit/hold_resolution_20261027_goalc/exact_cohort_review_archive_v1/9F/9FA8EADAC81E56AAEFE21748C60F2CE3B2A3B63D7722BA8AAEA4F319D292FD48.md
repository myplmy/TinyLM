`.include` 지시자의 이름과 그 일반 설명은 본문에 남겼다. 바로 이어질 예시가 없으므로 위 예고 문장만 분리했으며 include 예제를 만들지 않았다.

```text

```

첫 차이 bullet의 값을 복원하지 않았다. 뒤의 실제 명명된 dot notation 및 `self` 설명은 본문에 보존했다.

```text
||Notice that the type of an
```

이 문장은 뒤 대상/조건이 없어 미완 단위로 보류했다.

```text
- A basic block of code with a name and a parameter list.
- A basic block of code which belongs to a particular class and can be called on an object of that class. Methods are just subroutines with an extra implicit
- a PMC type that stores a collection of subroutines which can be invoked by name and sorted/searched by Parrot.
- Same as a MultiSub, except it is called as a method instead of a subroutine.
```

이 네 설명 조각에 붙을 용어명이 없으므로 이름을 추정해 붙이지 않고 해당 bullet만 보류했다. 같은 절의 이름이 실제 있는 `Multi Dispatch`와 `Single Dispatch` 및 각각의 정의는 유지했다.

```text
||The exact scheme for creating the unique names for
```

이 말미 문장은 실제 이어질 대상을 요구하는 미완 구간으로 분리했다. 뒤의 변수명 유일성 설명은 원문대로 보존했다.

## 보존 범위

나머지 원문/candidate의 완결된 PIR 설명, 명명된 지시자·파라미터·조건·값, 실제 예제와 설명, 순서 및 단락은 새로 재구성하지 않고 그대로 유지했다. 코드 줄 경계, 들여쓰기 또는 누락 토큰을 추정해 복구하지 않았다.
