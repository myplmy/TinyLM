## Time based SQL Injection

- 원형 문구의 끝: `...such as sleep(3) which lets the database sleep for 3 seconds:`
- 원형 문구: `If the page takes longer than usual to load it is safe to assume the database version is 5.X.`
- 이유: `sleep(3)`와 기능 설명은 보존하고, 이어질 예제 입력을 예고하는 콜론만 마침표로 정리했다. 쿼리 입력이 빠진 상태에서 직접 결과로 단정한 버전 판정은 분리했다. 완결된 Out-of-Band 예제와 영향·예방 설명은 보존했다.
