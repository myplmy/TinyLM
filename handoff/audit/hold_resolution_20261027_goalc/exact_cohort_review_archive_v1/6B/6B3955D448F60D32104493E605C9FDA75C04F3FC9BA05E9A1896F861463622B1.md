# 42037 보류 원형

| 원문 조각 | 보류 근거 |
|---|---|
| `if (Request.UserAgent.ToString().IndexOf("Googlebot") > -1)` | 조건문 본문이 없어 완결 실행 예제로 남기지 않음. 실제 식별자와 비교식은 이 원형에 보존하며, 코드 본문을 생성하지 않음. |
| `Inside the web.config (or machine.config) file:` | 예고된 XML 설정 예제가 없음. |
| `The above is a sample entry for detecting Windows 98 and Windows NT operating systems in the user-agent string from the web browser.` | 존재하지 않는 직전 설정 예제를 직접 지시하는 문장. 뒤의 독립적인 BrowserCaps 목록 설명은 본문에 유지함. |
| `Open the following file for editing:` | 파일명이 없고 대상 파일을 추측할 수 없음. |
| `The actual command line to use is: C:\WINDOWS\Microsoft.NET\Framework\` | 실제 명령이 경로 중간에서 끝남. 실행 명령이나 나머지 경로를 생성하지 않음. |
| `Sponsor Me` | 저자 소개에 붙은 사이트 후원 CTA로 기사 본문 밖에 둠. |
