# 626047 대상/값이 빠진 참조 원형 보류

## 분리한 원문 문장

> The implementation of this mechanism is described in §.
>
> You can change the pvmd (and therefore task) working directory (per-host) by using the host file option wd=.

## 근거

첫 문장은 section 번호가 없어 미상 대상 참조를 보류했습니다. 마지막 문장은 `wd=` 뒤의 실제 디렉터리 값이 없으므로 문장 전체를 분리했습니다. PVM/stdout/stderr 설명, `/dev/null`, console spawn의 실제 `->` flag, `pvm_catchout()`, C stdio buffering/`fflush(stdout)`/`setlinebuf(stdout)` 및 Fortran의 FLUSH 서술은 보존했습니다. section 번호나 `wd` 값을 채우지 않았습니다.
