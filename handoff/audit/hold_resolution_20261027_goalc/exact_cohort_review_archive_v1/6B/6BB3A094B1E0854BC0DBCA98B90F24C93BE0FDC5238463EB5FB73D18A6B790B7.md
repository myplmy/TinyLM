# 63058 원형 보류

## 보류 경계

도입의 복소수/옴 단위, 교류·직류에 대한 완결 설명, 복소평면 표현 문장, 저항과의 완결 비교 및 어드미턴스/지멘스 관계를 보존했습니다. `온저항()`의 값 없는 괄호만 정리했습니다.

기호와 크기·위상 표현이 소실된 `임피던스의 기호는 ...` 문장은 직접 식 의존 단위로 분리했습니다. `이하에서는 ... 허수단위 ... 각진동수 ...` 구간은 기호/배수 대상이 비어 있어 보류했습니다.

원문 순서를 유지해 `전기저항에 의한 것 / 저항이라고 한다.`, `유도계수에 의한 것 / 유도 반응저항(리액턴스)이라고 한다.`, `전기용량에 의한 것 / 용량 리액턴스라고 한다.`는 실제 소제목과 명명 문장 그대로 본문에 남겼습니다. 변수 도입·빈 식 예고·빈 크기/위상 값은 분리했습니다. `총 온저항` 아래는 RLC 변수·식·위상차 식이 모두 비어 있어 해당 수식 의존 소절 전체를 분리했습니다. 이름·변수·수식은 만들지 않았습니다.
