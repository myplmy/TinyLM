# 986115 원형 보류

새 본문에서 분리한 결합행:

- `$ gedit audio_thread.c audio_process((short *)outputBuffer, (short *)inputBuffer, blksize/2);`

행 안에 편집기 명령과 C 호출이 결합되어 있으나, 호출 앞에 별도 프롬프트/경계가 없어 어느 위치에서 줄을 나눌지 추정하지 않았다. 명령행과 호출 관계를 원형으로 보존한다. 호출을 실행하거나 코드를 보완하지 않았다.

그 밖의 셸 명령은 원문에 실제 반복된 `#` 또는 `$` 프롬프트 앞에서만 개행했다. 프롬프트·경로·명령·인수와 명령 순서는 그대로 두었다.
