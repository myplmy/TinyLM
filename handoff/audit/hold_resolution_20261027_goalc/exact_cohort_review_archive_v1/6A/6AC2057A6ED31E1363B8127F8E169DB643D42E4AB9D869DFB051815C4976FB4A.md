# 919177 원형 보류

아래 서명/헤더 묶음은 함수명이 빠져 완결된 API 서명으로 읽히지 않는다. 반환형·함수명·구문을 추정하지 않았다.

```text
#include <sys/types.h> #include <sys/stat.h>
const char *path,
mode_t mode );
```

실패 조건의 산문은 유지했지만, 실제 errno 표식/값 목록이 빠진 다음 목록 도입은 직접 의존 문장과 함께 분리했다.

```text
If the mkdir() function fails, the directory is not created
and errno may be set to one of the following values:
```

`this error`의 지시 대상이 소실된 문장과 목록 말미의 미완결 절도 원형 보존한다.

```text
[Tru64 UNIX] By default, this error is returned
when the final node of the specified path is a symbolic
link.
The named file resides on a read-only
```

NFS errno 항목의 값 도입과 그 항목명 없이는 주체를 알 수 없는 두 `Indicates` 설명을 원형 분리한다. 명시적 주체가 있는 뒤 문장은 본문에 유지했다.

```text
[Tru64 UNIX] For NFS file access, if the mkdir() function
fails, errno may also be set to one of the following values:
Indicates either that the system file table is full,
or that there are too many files currently open in the
system. Indicates a stale NFS file handle.
```

맨 끝의 `[ Back ]`은 문서 탐색 UI라 본문에서 분리했다.
