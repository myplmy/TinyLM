# expanded_train:748508 — 최종 원형 HOLD

원문 산호해 행의 전체 주석은 `의 산호해 제도를 통과함`이다. 행 제목 `산호해`와 표가 동경 154도선의 통과 지역을 나타내는 문맥에 따라, 실제 채워진 `산호해 제도를 통과함`은 본문에 보존하고 dangling particle `의`만 보류한다.

후보/새 본문에서 정리한 빈 괄호의 원형:
- `미나미토리섬() 바로 동쪽을 지나감`
- `루쿠노르 환초() 바로 동쪽을 지나감`
- `니산섬() 바로 서쪽을 지나감`

다음 미완 조각도 원형 보류한다.
- `사하 공화국 마가단주 — 부터`
- `가 영유권을 주장하는 오스트레일리아령 남극 지역`

지역명·반복/순서·완결 방향과 남극 권역명은 본문에 유지하며 새 대상이나 주장자를 만들지 않는다.
