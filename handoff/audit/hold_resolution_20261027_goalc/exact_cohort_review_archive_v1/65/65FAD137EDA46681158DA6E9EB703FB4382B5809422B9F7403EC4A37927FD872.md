## 근거

프로토콜 값 목록이 이어지지 않는 예고 문장만 분리했습니다. `float preference() cost`는 API 서명으로 보기에 손상된 경계라 원형을 보류했으며, 어떤 토큰이 의도됐는지 추정하지 않았습니다. 바로 뒤 실제 설명의 preference 범위 0–1, 기본값 -1, 실제 명명된 set_preference 관계는 본문에 보존했습니다. 다른 실제 API 이름과 반환 설명은 순서를 유지했습니다. 패킷 경계에서 나뉘어 있던 virtual Connection*, size_t, SendBindingRequest, Start 문장은 전체 원문 순서로 읽어 완결됨을 확인했습니다.
