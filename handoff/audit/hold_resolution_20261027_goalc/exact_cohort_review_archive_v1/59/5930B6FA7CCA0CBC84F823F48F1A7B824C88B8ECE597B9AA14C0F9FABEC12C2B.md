# 222581 없는 그림/링크를 직접 가리키는 표기 원형

지정 packet 0001–0015를 순서대로 연결해 원문·candidate·전체 diff의 마지막 논리 END/EOF까지 읽었다. Candidate와 original의 full_diff는 줄 차이 없음을 표시했다. 원문 본문에는 그림 데이터가 포함되지 않고 다음 표기만 보인다.

- CIE 1931 luminous efficiency function 뒤의 (FIG. 1)
- 수정체/각막 UV 차단 설명 뒤의 (FIG. 2)
- 생쥐 neuropsin 설명 뒤의 (FIG. 4)
- 나이에 따른 수정체 변화 설명 뒤의 (Fig. 5)
- 도입 UPDATE 문장의 An example of this is reported in considerable detail here.

각 자연어 문장의 주체·조건·관계와 논지/유보는 본문에서 유지했다. 대상 없는 here 문장만 분리했고, 네 그림 번호 표기만 분리했다. 그림을 새로 복원하거나 그림에만 있는 곡선/값을 본문에 추가하지 않았다. 보류는 명시된 원문 포인터의 대상이 이 텍스트 안에 없다는 범위이며, 저자의 자연어 주장·인용 결과를 외부 검증한 것은 아니다.
