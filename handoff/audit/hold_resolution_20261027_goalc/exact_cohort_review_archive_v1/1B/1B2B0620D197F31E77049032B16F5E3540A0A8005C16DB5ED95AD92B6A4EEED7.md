# 1311426 원형 보류

## 코드 예고·코드 없는 결과 잔여

원문에 다음 결과 줄은 있으나 이를 산출하는 코드/예제는 없다. 값을 새 예제에 귀속하지 않고 각 줄을 원형대로 분리했다.

- `3 GeeksFor 12 GeeksGeeksGeeksGeeks`
- `3 GeeksFor 3 GeeksFor 3 GeeksFor`
- `ob2 is greater than ob1`
- `ob1 is lessthan ob2 Not equal`

다음은 코드 예제를 직접 예고/가리키지만 그 코드가 없다.

- `The following code will throw a syntax error.`
- `This is the ~ operator, overloaded as binary operator.`
- `Here’s an example of how to overload the and operator for a custom class:`

`__add__`의 자동 호출과 피연산자 관계, 비교 연산자의 분류, `__and__`/`MyClass`/`value` 동작을 직접 설명하는 완결 산문은 본문에 보존했다. 없는 코드를 작성하지 않았다. 말미 `Please Login to comment...`는 본문 밖 댓글 UI라 분리했다.
