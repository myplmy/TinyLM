# 583621 별도 보류/비본문 구간

원문/후보 동일성은 자기 TASK_048 연결에 따른다. 본문에는 미완결 preview 조각과 페이지 UI만 분리했다.

| 원문 위치 | 원형 | 처리 근거 |
|---|---|---|
| 첫 preview 행 | `Unformatted text preview: xecuting a file with my program` | `Unformatted text preview`는 화면 라벨이고 `xecuting`은 앞부분이 빠진 단어 조각이다. 첫 글자나 앞 문장을 추정하지 않았다. |
| 첫 슬라이드 요약의 끝 | `You` | 바로 앞의 완결된 `You write the C++ program` 뒤에 남은 고립 토큰이다. 완결된 흐름 설명은 본문에 남겼다. |
| 문서 미리보기 뒤 | `View Full Document` | 실제 강의 내용이 아닌 사이트 이동 UI다. |

본문은 processor/assembler/compiler 흐름, 실제 C++/ASM 예시, programming language의 의미론·구문 구분, 색 예시, 강의 번호 및 업로드 출처 정보를 원문 순서로 보존한다. 슬라이드 표현의 `x` bullet 표식과 O/1 표기는 원문 그대로 유지했다.
