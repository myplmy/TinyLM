# expanded_train:1240249 원형 보류 조각

판독 범위: 원문·후보 전문(2,646자), 순서 패킷 0001–0003와 마지막 논리 END 및 전체 diff. 원문과 후보는 동일했다. 측정값의 오차/불확실성 설명, Value 예시의 실제 수치·출력, 연산 후 독립성·오차 결합 설명, 비교 결과와 consistent_with() 예시는 본문에서 유지했다.

누락된 표적만 다음과 같이 원형 보류했다.

- 원문: “The key (and currently only) object type in fuzz is the” — 문장 끝에 object type의 명칭이 없다.
- 원문: “...generally indistinguishable from the” / “float 108.5, unless you actually query” — float 108.5와 비교하는 완결된 문장은 유지하고, query의 대상이 사라진 꼬리는 분리했다.
- 원문: “Values support the” / “operators. These will just compare the values themselves, and ignore error.” — 무엇을 지원하고 비교하는지 나타내는 operator 목록·표적이 없다. operator 종류나 별도 관계를 보충하지 않았다.

원문의 “The most basic Value would be created” 뒤에는 실제 REPL 예시가 있고 “For this purpose, the” 뒤에는 실제 consistent_with() 메서드명이 이어진다. 따라서 이 두 연결은 원문 내부에 채워진 예시/명칭으로 완결해 보존하고, 새 API 명칭이나 계산값을 추가하지 않았다. 모든 REPL 코드와 수치는 실행·재계산하지 않았다.
