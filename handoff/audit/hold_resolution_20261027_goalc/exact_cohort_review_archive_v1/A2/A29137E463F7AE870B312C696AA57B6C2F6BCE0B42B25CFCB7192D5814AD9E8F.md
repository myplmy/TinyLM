# 708345 별도 보류 원형

## 원문 보류 구간

페이지 UI 문자열 `Back to Top`이 본문에 7회 반복됨:

1. Class 3 indications 설명 뒤
2. “What is Lead Extraction?” 설명 뒤
3. “How do you prepare for a lead extraction procedure?” 표제 뒤
4. “What to expect when you come to the hospital?” 절차 목록 뒤
5. “What happens after the procedure?” 절차 설명 뒤
6. “What are the techniques for lead extraction?” 설명 뒤
7. 합병증 설명 뒤

## 판독 근거

각 문자열은 페이지의 상단 이동 UI이며, 주변 절차·의학 설명의 문장이나 제목이 아니다. 같은 UI 문구만 본문에서 제거하고 일곱 원형 위치를 이 보류 문서에 기록했다. 절차, 수치, 조건, 기기명과 임상 설명은 본문에 유지했다.
