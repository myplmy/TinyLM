# HOLD 1403470

본문에서 분리한 원문 조각:

> All Implemented Interfaces:

> - the type of generic declaration that declared the underlying type variable.

> For each upper bound B:

첫 표제에는 구현 인터페이스 값이 없고 다음 bullet은 주어/대상이 빠져 어느 명명 API에 연결되는지 원문만으로 확정할 수 없어 원형 보존했습니다. `For each upper bound B:` 뒤에도 그 조건의 내용이 없습니다. `java.lang.reflect.TypeVariable`의 실제 summary method names와 보이는 `getBounds`, `getGenericDeclaration`, `getName` signature는 새 본문에 그대로 보존했습니다. 빠진 인터페이스명·메서드 설명을 생성하지 않았습니다.
