## 분리한 원문 조각

### 빈 인터페이스 대상이 있는 문장

`- As I said in the pre-requisite article
Web Programming 101, one of the big benefits of using Java is
the ability it gives you to create web-based graphical user`

이 항목은 `user` 뒤에 설명 대상이 없어 문장이 끝나지 않는다. 제목 `Web Programming 101`은 이 미완 문장에 연결되어 있으므로 새 귀속 문장으로 만들지 않고 함께 보류했다.

`Instead of forcing the user to deal
with strange command-line input such as in this
can present the user with a user-friendly interface such as that
designed by Macintosh and then taken for Windows.`

`this` 뒤의 예시 대상과 `can present`의 주체가 빠져 있다. Macintosh/Windows와 관련된 뒤 종속절도 그 소실 대상에 직접 붙어 있어 함께 보류했다. 원문이 완결한 `GUIs are one of the nicest things about modern-day programming.` 및 `GUIs make using a computer fun instead of a skill.`은 본문에 보존했다.

### 생성 도구 이름과 다운로드 경로가 빠진 예고

`API reference that is generated by a java utility called`

Java 유틸리티의 이름이 없다. 이를 추정하지 않고 미상 이름을 직접 받는 후행절만 분리했으며, 온라인 API reference를 이용한다는 완결 문장은 본문에 유지했다.

`But if not, it is`

JDK 문서 다운로드 관련 문장 끝이 미완이다. 앞의 독립 문장 `Hopefully you downloaded the documentation when you downloaded the JDK.`은 보존하고 이 조각만 원형으로 기록했다.
