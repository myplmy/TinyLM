- “Context class invokes this algorithm”은 완결 정보라 유지했다. 뒤의 “Based on the need of the execution context specific variant ... either of ConcreteStrategy2 is assigned ... actual algorithm ... which instance ... is held by”는 선택 주체/종결 대상이 빠져 직접 연결할 수 없어 해당 나머지 절을 분리했다. 앞서의 일반 전략 설명과 ConcreteStrategy1/2 원문 주석은 그대로 남겼다.
