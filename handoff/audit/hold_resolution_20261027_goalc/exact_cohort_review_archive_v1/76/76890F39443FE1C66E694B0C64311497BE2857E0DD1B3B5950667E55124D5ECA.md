# 1366234 원형 보류 v5

v5 TXT/sidecar가 최신 선택이며 이전 revised/hold 버전은 모두 보존한다. 누락된 속성/API 대상, 단절된 문장 포인터만 보류했다.

- 권한 속성이 적용되는 component 이름이 빠진 `to (applied to the` 조각.
- Android 권한 자동 추가의 대상 attribute와 직접 의존 조건, 값이 빠진 `If your is 3 or lower`, `always update your`, 그리고 뒤 항목이 없는 release pointer.
- 이름이 빠진 permission declaration tag (`using one or more`).
- 권한 검사 timing/API 이름이 빠진 activity/service/receiver 문구.
- 이름 없는 write permission attribute와 이름 없는 ContentProvider 호출 방법들.
- 이름 없는 fine-grained permission-check method 및 PackageManager method 설명.
- Broadcast 수신/송신 permission 문장에서 `supplied to` 뒤 method와 `supplied when calling` 뒤 method가 없으며, 마지막 `(see` 대상도 빠짐.
- `android:grantUriPermissions attribute or` 뒤의 누락된 대안.

실제 permission 명칭, manifest code example, `android:readPermission`, 명명된 API/arguments/flags, component별 실제 role, 권한 없는 호출의 SecurityException 조건, broadcast 전달 실패 결과, URI permission 설명과 reference 항목은 보존했다. 빠진 API명·속성·값은 보충하지 않았다.
