# 1418440 원형 보류 및 편집 경계

| 원문 조각 또는 제거된 포인터 | 이유 |
|---|---|
| `I provide code excerpts from a working demonstration app to serve as a concrete example of an actual implementation.` | 뒤 본문에 실제 코드 발췌가 없으므로 없는 예제에 대한 약속 문장만 분리했다. 일반 MVVM/RAC 설명은 본문에 남겼다. |
| `Figure 1 illustrates this viewpoint of mine.` | 그림이 없는 위치를 직접 가리키는 포인터다. 바로 앞의 View Model 설명은 완결되어 보존했다. |
| `Let’s look at some code that actually implements an MVVM architecture.` | 바로 뒤 실제 코드가 제시되지 않아 코드 예고 문장만 분리했다. |
| `Here is the outline for my View Model class in Swift.` | 예고한 클래스 outline이 이어지지 않는다. 다음의 실제 프로토콜명과 dynamic property 설명은 보존했다. |
| `below` in `In my example view controller below, I have incorporated two methods for updating the views from the View Model.` | `below`가 가리킬 코드가 없다. 두 방법의 실제 설명은 뒤에서 완결되므로 문장 본문을 유지하고 위치 포인터만 제거했다. |
| `as shown by my observer registrations and de-registrations along with the` | 실제 등록 코드가 없으므로 그 증거 포인터만 제거했다. KVO, `observeValueForKeyPath:ofObject:change:context:` 및 property-change 처리 관계는 보존했다. |
| `I’ve covered the main components of MVVM, illustrated in Figure 1 and implemented using Swift and ReactiveCocoa 4.` | 없는 Figure 1 포인터는 본문에서 제외했다. Swift와 ReactiveCocoa 4 구현이라는 채워진 정보는 별도 완결 문장으로 보존했다. |
| `I’ve combined both of these methods in my example source code for the sake of comparison.` | 해당 source code가 본문에 없고 두 방법의 설명만 있다. KVO·delegation 각각의 실제 설명과 둘 중 하나로 충분하다는 완결 문장은 보존했다. |
| `and that properties are marked as` | 필요한 property 표기가 끝까지 소실된 조건절이다. `NSObject` 상속 조건은 독립적으로 보존하고 표기값은 보충하지 않았다. |

누락 코드·Figure 1의 내용이나 property 표기를 새로 만들지 않았다. 명명된 API, 역할, 조건 및 완결 설명은 본문에 유지했다.
