# expanded_train:1182564 원형 보류

## 반복된 미완결 export 문장
원문: To access a GPIO pin such as GPIO13_6(400+6 = 406) you first need to export it with.
이 문장은 미완결로 끝나지만 같은 GPIO13_6 / 400+6 = 406 매핑을 포함한 뒤의 반복 문장에는 실제 export 명령이 이어진다. 앞의 미완결 중복만 분리하고 두 번째 실제 문장과 echo 명령을 본문에 보존했다.

## GPIO 읽기 명령 미완결
원문: You can read a GPIO pin with /sys/class/gpio/gpioXX/value using
본문에는 같은 실제 경로와 읽기 관계를 남기고 마지막 using만 제거해 문장을 닫았다. 읽기 명령이나 값을 새로 만들지 않았다.

## 출력 명령 조각
원문 문장: When the direction is set to out, you can write 1 or 0 to a GPIO pin with /sys/class/gpio/gpioXX/value using
원문 다음 줄: echo 1 /sys/class/gpio/gpioXX/value
본문은 이미 적힌 출력 조건(방향 out), 값 1/0, 경로를 남겼다. 명령 표본에는 경로 쓰기 연산자가 없으므로 문장 끝의 using과 이 줄은 함께 분리했으며 연산자를 추정해 추가하지 않았다.
