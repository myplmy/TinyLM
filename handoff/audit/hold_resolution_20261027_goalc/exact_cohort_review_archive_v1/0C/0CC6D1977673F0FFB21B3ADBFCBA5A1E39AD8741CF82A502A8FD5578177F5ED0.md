# 1332854 원형 보류

빠진 경계·값·인수가 필요한 구절과 물리적으로 평탄화된 다중 문장 코드는 원형 그대로 분리했다. 코드 실행·구문 복구·환경 경로 추정은 하지 않았다.

- `matlab.enginepackage into your Python session.` — package 이름과 뒤 동사/관계가 붙거나 빠진 조각.
- `Start a new MATLAB® process by calling start_matlabfunction returns a Python object engwhich enables you to pass data and call functions executed by MATLAB.` — 원문에서는 세 줄 `Start a new ... calling` / `start_matlabfunction returns a Python object` / `engwhich enables ...`로 경계가 손상됐다. 본문은 완결된 `start_matlab` 호출 관계만 보존했다.
- `import matlab.engine eng = matlab.engine.start_matlab()` — import와 대입 경계가 없는 예제.
- `import matlab.engine eng = matlab.engine.start_matlab() eng.desktop(nargout=0)` — import·대입·desktop 호출 경계를 복원하지 않았다.
- `To set PYTHONPATH on Windows to call MATLAB R2022a, type:` 및 `On Linux® or macOS:` — 뒤의 경로/명령이 없다.
- `To check which version of MATLAB was imported, in Python type:`와 `import matlab print(matlab.__file__)` — 명령 도입과 둘 이상의 코드 토큰만 남아 경계를 임의로 넣지 않았다.
- `Python might create a subfolder installing the MATLAB engine. Verify the folder on your system to use with the` — 폴더명·대상이 빠져 관련 예시절 전체를 보류했다. 앞의 완결된 `Python might use different folder names for installation.`은 본문에 남겼다.
- `import matlab.engine future = matlab.engine.start_matlab(background=True)` 및 이어지는 `Create the MATLAB instance so you can perform computations in MATLAB.` / `eng = future.result()` — 평탄화된 예제와 미상 `future`의 직접 사용으로 함께 보류했다.
- `eng1 = matlab.engine.start_matlab() eng2 = matlab.engine.start_matlab()` — 두 대입 사이 경계가 없다.
- `Call either the` / `exit or the` — 두 번째 선택지 이름이 빠져 있다. 뒤의 독립 완결 설명(파이썬을 종료하면 실행 중인 엔진도 자동 종료)은 본문에 보존했다.

보류한 모든 literal은 이 파일에 원형으로 남아 있다. 새 MATLAB/API 이름, 환경 경로, 실행 명령 또는 코드 구분자를 만들지 않았다.
