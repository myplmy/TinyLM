# 36198 원형 보류·정제 기록

- 빈 발음 표기 슬롯 원형: `licht [] (=light)`, `nicht [] (=night)`, `thocht [] (=thought; 고대 영어: þōcht, )`, `wynd [] (=wind)`. 빈 대괄호와 þōcht 뒤 값 없는 쉼표/닫는 괄호만 정리했다. IPA·발음값은 생성하지 않았다.
- 원문에 내용이 없는 `각주` 표제는 candidate에서 제거된 상태로 유지했다.
- 실제 단어·번역·채워진 역사 언어 표기·음운 관계·차용어 예시·논쟁 조건·설문 수치·자료명·외부 링크 및 분류는 보존했다. 빈 발음값이 있다는 이유로 예시나 정성 설명 전체를 보류하지 않았다.
