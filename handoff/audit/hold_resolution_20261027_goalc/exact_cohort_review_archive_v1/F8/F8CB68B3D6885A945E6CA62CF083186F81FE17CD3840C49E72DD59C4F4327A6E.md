# validation:3644 소실 기호 의존 구절 기록

후보는 원문과 동일했다. 머리말의 빈 `()`만 정리했다. 다음 원문은 필요한 변수·기호·수식이 비어 있어 관계나 조건을 확정할 수 없으므로 본문에서 원형 보류했다.

- `유클리드 공간의 연결 열린집합에 정의된 실숫값 함수 의 점 에서의 전미분 는 다음과 같다.`
- `여기서`
- ` 는 변수 의 증분이다.`
- ` 는 의 에 대한 편미분이다.`
- `다만 이는 다음 조건을 만족해야 한다.`
- `전미분 는 에 의존한다. 반면 는 에 의존하지 않는다.`
- `만약 의 어떤 점이나 모든 점에서 의 전미분이 존재한다면, 그 어떤 점이나 에서 가 전미분 가능() 또는 미분 가능하다고 한다.`

전미분의 독립적인 개념 설명, 편미분과의 구별, 실제로 적힌 전미분 가능 함수의 성질·판정 설명, 연속 미분 가능성 문장, 반례 방향 기호, 그리고 원래의 범주 표기는 보존했다. 누락된 표적이나 공식을 채우지 않았다.
