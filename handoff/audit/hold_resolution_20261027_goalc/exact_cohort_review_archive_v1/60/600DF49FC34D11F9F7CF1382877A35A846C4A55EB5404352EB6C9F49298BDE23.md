# 134255 원형 보류

`Put the following code inside the file:`는 뒤에 있어야 할 설정 코드를 가리키지만 실제 코드가 없다. `The code above will run each time the web site (application) starts. It feeds your WebMail Object with initial values.`도 존재하지 않는 코드에 직접 기대므로 두 문장만 본문에서 분리했다.

보류 원형:

> Put the following code inside the file:
> The code above will run each time the web site (application) starts. It feeds your WebMail Object with initial values.

SMTP 속성의 실제 명칭·설명, `smtp.example.com`, `25`, `false`, `email@example.com`, `password`, `john@example` 표기와 각각의 설명, 페이지 생성 지시, `WebMail.Send()` 전 속성을 설정하라는 완결 문장은 보존했다. 누락된 코드·값은 만들지 않았다.
