# 896876 — 원형 보류: 페이지 상단 이동 UI

후보 본문의 4, 10, 14, 18, 21, 30, 56, 63행에 각각 단독으로 반복된 `Back to top`은 페이지 상단으로 이동하는 탐색 UI로 판독했다. 이 여덟 발생을 학습 본문에서 분리했다. 원형 문구와 발생 위치는 이 sidecar에 보존한다.

본문의 제목·질병 설명·위험 요인·치료 내용·인용 및 참고자료·감사 문구는 후보에서 그대로 보존했다. 치료·부작용·재발에 관한 서술은 탐색 UI와 직접 연결되지 않는 독립 본문이므로 삭제하지 않았다. 빈 값이나 새로운 의학 사실은 추가하지 않았다.

판독 입력은 TASK_028의 지정 original/candidate와 연속 패킷 0001–0005다. 원문과 후보는 모두 논리 END/실제 EOF까지 읽었고, 후보 전체와 새 본문 전체를 비교했다.
