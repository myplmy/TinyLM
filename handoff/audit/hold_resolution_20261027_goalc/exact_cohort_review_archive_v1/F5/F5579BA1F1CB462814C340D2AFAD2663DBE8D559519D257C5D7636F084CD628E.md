# expanded_train:217029 — 원형 보류

원문에서 바로 이어질 대상이 빠진 아래 부분만 원형 보류한다.

- `use MozWebSocket instead of` — 대체 이름 뒤 대상이 없다.
- `Without further ado, here’s the`와 `front.html file, with the script embedded in it:` — 선언된 프런트엔드 파일 본문이 없다.
- `If you want to use WebSockets over SSL, the protocol is` — 프로토콜 값이 없다.
- `appended it inside the big` — 삽입 대상이 빠졌다.
- `Now, let’s look at the more interesting` — 뒤에 이어질 대상이 없다.
- `And finally, you may look at my JS code in the code listing above` — 가리키는 JavaScript 코드 목록이 제공되지 않았다.

독립된 설명·완결 Tornado/Python 예시·명시된 WebSocket API와 절차는 본문에 남겼다. `using—yes, XmlHttpRequests`의 `yes`는 원문의 삽입 강조어로 보존했고, 최소 구두점으로 앞 문장에 연결했다. 빠진 파일 내용·프로토콜·대상은 만들지 않았다.
