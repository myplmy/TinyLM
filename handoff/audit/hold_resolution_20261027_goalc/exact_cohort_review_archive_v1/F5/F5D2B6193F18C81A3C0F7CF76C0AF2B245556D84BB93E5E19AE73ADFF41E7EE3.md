# 48851 빈 별칭 슬롯과 내용 없는 표제

- 원문 `제10보병사단()`에서 실제 부대 이름 뒤 빈 괄호만 정리했다. 앞의 지역수비대/사령부 명칭과 실제 제10보병사단·차량화보병사단·기갑척탄병사단 이름은 본문에 유지했다.
- 본문에 항목이나 설명이 없는 `주요 참전 전투`, `역대 지휘관`, `부대 편제`, `기사십자장 서훈자`, `외부 링크` 표제는 빈 영역과 함께 분리했다. 원문에 나열된 실제 전투 연혁과 “전쟁 범죄” 절의 주장/인용 포인터, 더 읽어보기 항목은 유지했다.

빈 표제 아래의 전투·지휘관·편제·서훈자나 URL을 만들지 않았다. 본문의 날짜, 부대명, 재편/참전 서술 및 끝의 분류 표기는 외부 사실 확인이나 교정 없이 원문대로 보존했다.
