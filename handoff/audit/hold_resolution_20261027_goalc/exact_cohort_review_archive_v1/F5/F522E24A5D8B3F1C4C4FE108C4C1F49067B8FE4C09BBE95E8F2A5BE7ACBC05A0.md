Sub CopyBudgetRecords() Dim copyrng As Range Dim cell As Range Dim PasteRng As Range Set copyrng = Sheet1.Range("B5:B20") For Each cell In copyrng Set PasteRng = Sheet4.Range("A5") If cell = "C_O_M" Then Range(cell.End(xlToLeft), cell.End(xlToRight)).Copy PasteRng Next cell End Sub

## 근거

워크북 안내에는 실제 링크나 파일 대상이 없다. FILTER와 VLOOKUP은 특정 셀에 넣은 식을 소개하지만 그 식 자체가 제시되지 않는다. VBA 코드는 변수 선언, 할당, 반복, 조건, 복사를 구분하는 문자가 없어 실행 구조를 확정할 수 없고, 바로 뒤의 단계별 해설과 실행 지시 및 결과 문장은 그 코드에 직접 의존한다. 빠진 식이나 코드 경계를 추정하지 않았다.

본문에는 실제 FILTER/VLOOKUP 일반 문법, 각 인수의 채워진 범위·조건·열 번호·일치 조건 설명, 필터 단계와 사용법 안내를 유지했다.
