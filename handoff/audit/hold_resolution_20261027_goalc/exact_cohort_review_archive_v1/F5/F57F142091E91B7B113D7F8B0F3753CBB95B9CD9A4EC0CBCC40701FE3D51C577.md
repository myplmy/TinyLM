# 5676 원형 보류 구간

## 원문

```
황해(黃海)(, ) 또는 서해(西海)()는 태평양의 일부로 대한민국과 조선민주주의인민공화국, 중화인민공화국의 바다이다.
... 《신중국지도첩》(1737년)에 표기된 황해()가 국제 표준으로 쓰이며 ...
아무르판의 서쪽 경계

지도

각주
```

## 이유

제목의 `(, )`와 서해 이름 뒤 `()`에는 실제 병기값이 없습니다. 후보가 이미 제거한 인용 안 `황해()`도 값 없는 괄호였습니다. 이름·한자·국가·바다 관계와 당빌이 만든 책의 이름/1737년/국제 표준에 관한 문장은 보존했고 빈 괄호만 정리했습니다. `아무르판의 서쪽 경계`는 뒤에 설명이나 값이 없는 표제이며 `지도`에는 지도 항목이 없습니다. 빈 항목인 `각주` 표제만 정리하고, 채워진 참고 문헌 및 링크 항목·제목은 그대로 남겼습니다. 지도/경계/주체/자료를 새로 만들지 않았습니다.
