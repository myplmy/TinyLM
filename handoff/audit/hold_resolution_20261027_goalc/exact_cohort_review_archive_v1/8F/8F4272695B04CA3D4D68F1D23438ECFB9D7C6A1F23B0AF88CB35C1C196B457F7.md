# 52702 원형 보류 근거

원문은 후보와 같지만, 빈 식/기호에 직접 기대는 부분을 아래 원형 그대로 보류했다. 식을 새로 채우거나 구조역학 지식으로 보완하지 않았다.

## 보류한 식 예고와 직접 종속 블록

- `직사각형 보에서 철근비는 아래와 같다.` 뒤의 빈 식. 이어지는 `As : 철근량`, `b : 보 폭`, `d : 유효깊이...`는 실제 정의이므로 본문에 남겼다.
- `균형철근비는 아래 식으로 계산한다.` 뒤의 빈 식과 빈 기호 정의 ` : 콘크리트 설계기준 압축강도`, ` : 철근 항복 변형률`. 채워진 `fy : 철근 항복강도`는 본문에 보존했다.
- `이때 1과 2의 경계선으로 표시한 부분을 '중립축'이라고 한다.` 도해의 1·2 표적이 없어서 이 지시 문장만 보류했다. 뒤의 압축/인장 방향 설명은 유지했다.
- `압축부 콘크리트의 압축파괴점(인 점)`에서 미상 변형률에 직접 붙은 빈 괄호 부분은 보류했다. 압축파괴점 명칭과 뒤의 실제 설명은 남겼다.
- 빈 변형률 기호 정의 ` : 압축부 콘크리트 변형률`, ` : 인장부 철근 변형률`, ` : 인장부 콘크리트 변형률`, ` : 곡률`은 원형 보류했다. 실제 정의가 있는 `b`, `d`, `h`, `c`는 유지했다.
- `예컨대` 뒤에 식이 없는 삼각함수 예고와 `이런 원리로, 각 부분이 받는 응력 f를 다음 식들로 표현 가능하다.`라는 빈 식 직접 예고를 보류했다.
- `콘크리트 탄성계수는 아래 식으로 구한다.` 뒤의 빈 식과 `이면`, `이면`, `사이는 직선 보간.`이라는 값 없는 조건 조각을 보류했다. `fck : 콘크리트의 설계기준 압축강도`와 `Ec`, `Es (=200,000MPa)`, `As` 정의는 보존했다.
- `임을 이용하면 ... 미지수는 c뿐이므로 이차방정식의 해를 구하여 c를 계산가능하다.`, `c를 구하면 변형률 ε, 응력 f, 하중 N을 전부 계산 가능하다.`는 antecedent 식에 직접 의존해 보류했다. 검산 대상 관계는 원문에 실제 이름이 있어 `Ncc, Nct, Ns가 평형을 이루는지 확인하여 검산할 수 있다.`로 남겼다.
- 정밀식의 `최종적으로 얻게 되는 M-Φ 상관도의 예는 다음 그림을 보면 된다.`는 없는 그림을 직접 예고해 분리했다. 본문 절차는 유지했다.
- α와 β의 실제 의미 설명은 보존하고 `다음 표로 주어진다.` 표 예고는 표 값이 없어 분리했다. 이어지는 `C = T의 식에서 εcc별로 ...` 계산 안내는 실제 표/값에 직접 의존하므로 원문 그대로 보류했다.
- 약산식 부분에서 `콘크리트의 파괴계수(균열 시 휨응력)은 다음 식으로 정해져 있다.`와 빈 식, 오일러-베르누이 관계/단면계수 Z/Mcr 빈 식 연쇄, `곡률 계산에 필요한 εcc를 구하면`의 빈 식, `곡률은 ... 계산하므로`의 미완 예고를 함께 보류했다. 완결된 λ 정의, 선형 응력 구간과 훅 법칙 설명은 남겼다.
- `설계기준에서는 으로 정하고 있다.`의 빈 변형률 조건과 β의 빈 식 예고는 보류했다. 실제 기재된 `α = 0.85`와 등가직사각형 응력분포 설명은 보존했다.

## 문맥형식 정리

원문은 `위에서 나열한 기본 가정 중 '콘크리트의 인장강도는 없다'는 것이 여기에 사용된다.`라고 했지만, 앞에 해당 가정 목록은 없다. 따옴표 안에 실제 채워진 가정을 독립적으로 보존하고 목록 포인터만 제거했다. 그림 포인터가 붙은 굽힘 방향 설명도 실재 그림의 내용/번호를 만들지 않고 명명된 보의 방향 관계만 남겼다.
