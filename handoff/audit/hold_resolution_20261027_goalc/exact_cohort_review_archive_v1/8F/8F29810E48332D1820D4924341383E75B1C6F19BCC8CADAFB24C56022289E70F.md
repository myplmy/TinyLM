# 현재 판독·출력 연결 규칙 v2

이 문서는 기존 TASK 명령을 바꾸지 않고 이후 총괄 지시를 보존한다.

- 고정 reader는 한 번의 exec에서 패킷 하나만 호출하고 출력 예산을 10,000토큰 이상으로 둔다. 예전 TASK의 최대4개 병렬 허용은 이 지시로 좁혀졌다.
- 반환 헤더의 내부 piece2/2 표시는 봉인된 도구가 두 조각을 합칠 때의 메타데이터다. 실제 본문은 4,000자 이하 논리 패킷 전체다. 같은 명령을 반복해도 다음 패킷으로 넘어가지 않는다. 논리 문서가 여러 패킷이면 TASK의 각 패킷을 차례로 끝까지 읽는다.
- ACCEPT_CANDIDATE 출력은 실제 지정 공유 후보의 절대경로를 적는다: `/home/uranus/tinyLM/data_cache/p106b_hold_resolution_v1_20261027_goalc/birth_root11_independent_v1/inputs/expanded_train_<ID>_candidate.txt`. validation이면 TASK의 실제 source 접두어를 그대로 따른다.
- 위 공유 입력 경로 앞에 `agents/context_controls/`를 붙이지 않는다. 역할 폴더 아래에 공유 입력이 있는 것으로 추측하지 않는다.
- REVISE_TEXT는 자기 폴더에 실제로 새로 저장하고 전문과 차이를 확인한 TXT를 연결한다. 기존 초기 사본과 새 버전 권한은 이미 지정된 전량에 허용되어 건별 복사 허가를 다시 묻지 않는다.
- 실제 TASK 판독 전에는 공식 review_NNN 행이나 근거를 완성하지 않는다. 메모가 필요하면 draft_ 이름을 사용하고 공식 선택에서 제외한다.
- 리뷰 경로만 틀리고 판독 근거가 이미 있으면 그 사실을 밝히고 정확한 연결의 리뷰 새 버전을 저장한다. 이 이유로 본문을 재저술하거나 실제로 하지 않은 재판독을 기록하지 않는다.
- 실제 의미 보완과 경로 정정이 같은 TASK에 있으면 최종 선택을 정확한 다섯 ID의 리뷰 새 버전에 함께 연결한다. 마지막 TASK의 실제 행 수는 TASK가 소유한다.
- 기존 TXT·MD·초기 사본은 덮거나 삭제하지 않는다. 원문에 없는 인명·날짜·수식·통계값·기관을 추측해 넣지 않는다.

원문과 기존 캐시의 바이트를 수정하는 권한, 다른 역할 자료를 읽는 권한, 코드·시험·해시·웹·Git·GPU·모델 실행 권한을 추가하지 않는다.
