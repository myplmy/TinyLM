# 21130 — 분리한 원형 조각

| 원문 조각 | 근거 |
|---|---|
| `나비()` | 빈 병기 괄호만 정리하고 실제 이름 ‘나비’와 뒤의 설명은 보존했다. |
| `나비의 일생은 ·알·유충·번데기·성충 네 단계를 거친다.` | 첫 항목 앞의 고립 구분점만 정리했다. 실제 네 단계 이름과 순서는 그대로 유지했다. |
| `종류` | 실제 목록/설명이 뒤따르지 않는 빈 표제다. 원형 표제만 보존하고 형태·생식의 실제 설명은 유지했다. |
| `각주` | 후보에서 제거된 빈 각주 표제를 원형으로 보존했다. 실제 같이 보기·외부 링크와 분류값은 유지했다. |
