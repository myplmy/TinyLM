### 변수·데이터프레임 도입과 붙은 주석/실행문 원형

```text
ggplot() to draw the frequency polygon for a data set generated by
rnorm() (read more here about
rnorm()). Here are the variables and dataframe:
# ID ID <- 1:200 # sample data values <- rnorm(200, mean=65, sd=15) # dataframe df <- data.frame(ID, values)
```

본문에는 이 원형 안에서 실제 문자열로 식별되는 `ID <- 1:200`, `values <- rnorm(200, mean=65, sd=15)`, `df <- data.frame(ID, values)` 세 할당을 원래 토큰 그대로 평문 구조로 보존했다. 앞의 `ggplot()` 도입 구문과 주석/실행문 경계가 붙은 원형 행은 별도로 HOLD한다. 새 개행으로 원래 프로그램을 복원하거나 실행하지 않았다.

### 누락된 비교 예시와 그 직접 의존 설명

```text
To realize how similar a frequency polygon and a histogram are, we can put them next to each other:
ggplot(df, aes(values)) + # histogram geom_histogram(bins = 30) ggplot(df, aes(values)) + # frequency polygon geom_freqpoly(bins = 30)
The shapes of these two plots are not strictly identical but they clearly show the same pattern of distribution.
```

비교용 예시의 주석/실행문 경계가 소실됐고 가리키는 그림도 입력에 없다. 이 직접 비교 예고·붙은 예시 행과 두 그림의 모양/분포 결론은 원형 HOLD한다. `bins = 30`이라는 실제 값은 바로 앞의 보존된 `stat_bin()` 메시지에 남아 있다. 그림 결과를 새로 만들거나 비교 결론을 검증하지 않았다.

### 매개변수 예시의 손상된 원형 행

```text
Here are two examples:
ggplot(df, aes(values)) + geom_freqpoly(bins = 60) # left plot, changing bins ggplot(df, aes(values)) + geom_freqpoly(binwidth = 10) # right plot, changing binwidth
```

두 예시가 한 행에 붙어 있으므로 그 행을 실행 가능한 별도 코드 두 줄로 분할하지 않았다. 본문에는 원문에 명시된 `bins = 60`과 `binwidth = 10`, 그리고 바로 붙은 left/right 설명만 짧은 평문으로 보존했다. 전체 손상 행은 이 sidecar에 원형 보존한다.

## 본문에 보존한 실제 독립 정보

- frequency polygon과 histogram에 관한 두 문장 및 former/latter의 bars/lines 관계는 앞서 승인된 방향으로 유지했다. 총괄 제공 공식 ggplot2 참고: https://ggplot2.tidyverse.org/reference/geom_histogram.html (ROOT scope의 115view0, 44행). 이 검토에서 별도 웹 조회는 하지 않았다.
- 세 변수/데이터프레임 할당은 위에 기록한 실제 문자열 그대로 보존했다.
- 원문에 단독으로 완결된 `ggplot(df, aes(values)) + geom_freqpoly()`와 `ggplot(df, aes(values)) + geom_freqpoly(bins = 60, size = 1.5, color = "darkblue", linetype = "dotted")`를 정확 literal로 유지했다.
- 기본 호출 뒤 원문 `stat_bin()` 메시지의 `bins = 30`을 보존했고, 일반적인 binwidth/빈 개수 조정 문장 및 `geom_freqpoly()` 명칭을 유지했다. 별도 두 예시의 실제 `bins = 60`, `binwidth = 10` 값과 left/right 설명은 원문 그대로의 의미를 평문으로 유지했다.
- 새 그림 결과, 변수, 호출, 패키지 주장, 수치 계산은 생성하지 않았다. R을 실행하거나 패키지를 확인하지 않았다.
