## 명명 모듈 사용 예제

import mymodule mymodule.mymodule("Jon")
Output will be: Jon

위 코드에서 import문과 호출문 경계가 소실되어 예제 전체를 보류했다. 실제 module/mymodule 이름은 다른 본문 구절에 보존했다.

## math 예제 코드

import math print("The value of pi is:", math.pi)

import문과 print 호출의 경계가 사라져 예제 코드를 보류했다. 명시 출력 문자열과 3.141592653589793 값은 본문에 남겼다.
