# 160487 결과 목록의 빈 괄호 기록

지정 원문·candidate 전문과 단일 연속 packet 0001의 논리 END/EOF, original→candidate 전체 diff를 판독했다. 원문과 candidate는 동일하며, `결과` 아래 다섯 실제 이름이 순서대로 있다.

각 이름 뒤의 빈 괄호 포장만 분리해 이름과 순서를 보존했다. 문서가 괄호의 의미를 설명하지 않으므로 국가·순위·별칭 등으로 귀속하지 않았고, 빈 값을 채우지 않았다.

```text
원문:
 모리 리요  ()
 나탈리 길마레스 ()
 리 조나이티스 ()
 이하늬 ()
 레이첼 스미스 ()

선택:
 모리 리요
 나탈리 길마레스
 리 조나이티스
 이하늬
 레이첼 스미스
```

개최일·장소·77개국 참가·탑15 아시아권 참가자 4명 및 우승자 서술, 실제 외부 링크와 분류 목록은 유지했다.
