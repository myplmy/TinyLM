# 506802 원형 보존 메모

## 분리한 페이지 공유 UI

본문 끝에 붙은 다음 사회 공유/반응 UI 항목 네 건을 제거했다.

```text
- SHARE THIS
- TWEET THIS
- SHARE THIS
- LOVE THIS 0
```

이 행들은 기사 내용인 Nanded의 지리·농업·하천·산림·기후 설명이 끝난 뒤에 모여 있다. 반복 `SHARE THIS`, `TWEET THIS`, `LOVE THIS 0`은 공유/반응 컨트롤이므로 본문에 두지 않았다. 기사에 있는 좌표·면적·행정구역·농작물·기후 수치와 명칭은 유지했다.

## 판독 범위

지정 original/candidate 전문과 순서 패킷 0001–0002를 BEGIN부터 END/EOF까지 대조했다. 후보 전체 diff는 줄 차이가 없었다. 새 본문에서는 위 UI 행만 분리했다.
