# 260228 원형 보류 근거

## 원형에 있던 빈 슬롯·구분자
- 제목 `회장님은 메이드 사마!()`와 `'사마'()`의 빈 괄호, 각 인물명/배경명 뒤 빈 `()`, `작은 언덕()`, 스태프·주제가의 빈 병기 괄호는 빈 포장으로 정리했다. 실제 한국어 인명·작품명·관계는 그대로 두었고 다른 언어 이름이나 표기를 생성하지 않았다.
- 제작 협력의 `MOVIC()`에서 빈 괄호만 정리했다.
- 단행본의 실제로 비어 있는 ISBN 칸은 빈 슬래시 구분자와 함께 제거했다. 원형의 날짜/필드 위치는 아래와 같다.
  - `대한민국: 2008년 3월 28일 발매 / `
  - `일본: 2007년 2월 5일 발매 / `; `대한민국: 2008년 5월 19일 발매 / `
  - `일본: 2007년 8월 4일 발매 / `; `대한민국: 2008년 6월 11일 발매 / `
  - `일본: 2007년 12월 5일 발매 / `; `대한민국: 2008년 8월 19일 발매 / `
  - `일본: 2008년 5월 2일 발매 / `; `대한민국: 2008년 10월 22일 발매 / `
  - `일본: 2008년 9월 5일 발매 / `; `대한민국: 2009년 1월 19일 발매 / `
  - `일본: 2009년 4월 3일 발매 / `; `대한민국: 2009년 9월 21일 발매 / `
  - `제8권: 2009년 9월 4일 발매 / `; `제9권: 2010년 4월 5일 발매 / `
- 제1권 일본판의 실제 ISBN `9484592184319`와 모든 날짜·권수는 유지했다. 채워진 제작·성우·방영·외부 링크·분류 정보를 바꾸거나 빈 ISBN을 채우지 않았다.
