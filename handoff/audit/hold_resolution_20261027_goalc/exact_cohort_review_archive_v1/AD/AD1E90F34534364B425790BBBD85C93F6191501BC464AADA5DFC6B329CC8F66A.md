# 871902 원형 보류

선택 본문: `reviewed_871902_task064_v1.txt`.

- OWASP 페이지 이전 안내와 “Project or Chapter Page” 형식표시는 기사 설명이 아닌 사이트/페이지 메타정보로 분리했다. 기사 제목과 XPath/Blind XPath 설명은 보존했다.
- 구조를 알아내는 데 쓸 쿼리와 그 결과가 빠진 예고/결과 지시문, 입력 길이를 확인한다는 쿼리의 직접 결과, 직전 query 대상이 없는 `This query` 결과 문장만 원형 보류했다. 다른 곳의 실제 쿼리를 끌어와 이 공란에 연결하지 않았다.
- 실제 XML 문서, 명시된 XPath 함수 호출 및 결과, SQL 유사점·입력 문자열 예제와 공격 제약, “Related Threat Agents” 및 Amit Klein의 실제 귀속은 보존했다. 기존 예제의 표기나 논리를 고치지 않았고 새 쿼리를 만들지 않았다.
