# 916716 — 원형 보류

후보에서 의미가 미완성이거나 직접 참조 대상이 빠진 다음 조각만 학습 본문에서 분리했다. 원문 문구를 보존한다. 명령/별칭, 예제 식 또는 누락된 대상을 보충하지 않았다.

- 도입 조각: `CGDB instead of GDB, as it is helpful to see what is visually taking place.`는 앞 문맥 없이 비교·권고 관계가 시작된다.
- `Launch GDB by telling it what program to debug:` 및 `gdb myProgram or`는 대안 명령 뒤가 비어 있다.
- `Breakpoints can be set using the` / `break command (shorthand:`의 별칭 값이 없다.
- `By doing this you can step through your program one line at a time.`의 “this”가 가리키는 조작은 현재 조각에서 확정되지 않는다.
- step 예시의 `For example, if execution is paused on the line`부터 `s will enter` 및 `foo() and break at the first line of`까지는 예시 호출 대상/마지막 객체가 잘렸다. 완결된 step 명령과 shorthand는 본문에 유지했다.
- `You can even view the result of an expression, such as`는 표현식 예시가 없다.
- `disable 1 command (shorthand:` 및 `enable 1 command (shorthand:`의 shorthand 값이 없다. 완결된 disable/enable 동작과 명령명은 본문에 유지했다.
- `clear command shorthand is` / `continue command shorthand is` / `c. You do not want to mix up these two.`는 명령과 별칭의 경계·대응이 손실되어 원형 분리했다. 다른 곳의 complete continue shorthand는 유지했다.
