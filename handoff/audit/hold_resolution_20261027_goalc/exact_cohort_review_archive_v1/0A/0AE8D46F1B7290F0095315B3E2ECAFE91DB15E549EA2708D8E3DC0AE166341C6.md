# expanded_train:897274 원형 보류

## 보류 원형

- 페이지 조작 문자열 `Add To Favorites` 2곳
- 사이트 연결 호출 `Visit us »` 1곳

## 근거

두 `Add To Favorites`는 kayaking 글과 뒤의 사이트 추천 블록 앞에 반복된 페이지 UI이고, `Visit us »`는 추천 항목 뒤의 사이트 CTA이다. 후보는 이를 제거하면서 실제 카약 안내와 만들기 지시, 강 등급(1–6), 추천 항목의 실제 문구를 보존한다. 잘린 추천 문구는 주어진 형태로 남겨 두며 이어지는 문장을 새로 만들지 않는다.
