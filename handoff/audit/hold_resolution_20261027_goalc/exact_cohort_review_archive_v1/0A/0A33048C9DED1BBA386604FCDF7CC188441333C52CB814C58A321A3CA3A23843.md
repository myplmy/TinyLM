# 1410700 원형 보류 및 편집 경계

| 원문 조각 | 처리 이유 |
|---|---|
| `and the code is available for download here.` | URL 대상이 없는 download 포인터다. 프로그램이 양쪽 Solaris/Linux용이라는 실제 조건은 본문에 유지했다. |
| `The code specific to Intel X86_64 based systems is available here.` | 코드 링크 대상이 없다. Intel X86_64 기반 시스템이라는 실제 범위는 본문에 독립 문장으로 보존했다. |
| `Using the copydd driver on a Sun X4270 Lynx server based on the Intel Nehalem architecture, we arrived at the set of curves shown below.` | 없는 그래프를 직접 가리키는 문장은 분리했다. copydd·Sun X4270 Lynx·Intel Nehalem 측정 조건은 앞 문장의 copy-bandwidth 분석과 결합된 본문 문장에 보존했다. |
| `The above curve shows that while ddi_copyin() is a small win over uiomove() for small data sizes(<1024 bytes), uiomove() beats by a factor of 2x when it comes to copying 128k chunks.` | curve 포인터만 분리했다. `<1024 bytes`, ddi_copyin()/uiomove() 비교, 2x 및 128k chunks 관계는 그래프 밖 추정이 아니라 원문에 명시된 수치·문장이므로 문법을 최소 정리해 본문에 유지했다. |

측정값·하드웨어·아키텍처·API를 새로 검증하거나 다른 값을 생성하지 않았다. 없음으로 빠진 그래프 내용은 보충하지 않았다.
