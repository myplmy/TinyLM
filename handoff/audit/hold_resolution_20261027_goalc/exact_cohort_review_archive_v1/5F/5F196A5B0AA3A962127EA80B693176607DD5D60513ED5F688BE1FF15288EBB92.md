# expanded_train:10898 원형 보류

## 원형 조각

- `자바 가상 머신(, JVM)`의 앞쪽 빈 별칭 슬롯.
- 이름 뒤 빈 병기 슬롯: `제임스 고슬링()`, `p-코드()`, `데이터 흐름 분석()`, `자바 바이트코드 검증기()`, `라이노()`, `동적 타입 언어()`, `핫스팟 가상 머신()`, `클래스로더()`.
- 내용이 없던 표제: `JVM 사양`, `클래스 로더`, `바이트코드 명령어`, `웹 브라우저에서의 JVM`, `자바 애플릿`.
- `자바 ME의 ()에서 하나 부분 집합`의 대상 슬롯.
- 후보 문장 `일례로 자바 SE와 자바 EE, 자바 ME의는 동일한 규격을 사용하고 있으나 함께 정의된 표준 API에서 차이가 있고 사용 환경 자체의 특성에 맞게 만들어진 별도의 구현이 존재한다.`에서 빠진 `자바 ME의` 대상.
- `자바 ME CDC를 위해서도 적은 메모리와 낮은 CPU 사양에 맞춰진 ()이라고 하는 별도 구현`의 빈 괄호 슬롯.

## 선택 경계

빈 별칭은 실제 명칭을 그대로 두고 껍데기만 정리했다. Java ME의 미상 부분 집합은 이름을 추정하지 않고 직접 의존 구간을 제거했다. 비교 대상이 없는 Java SE/EE/ME 예시 문장도 전체 보류해 `자바 ME의는`을 새 객체로 바꾸지 않았다. 다만 독립된 일반 문장, Java Card의 실제 명명된 두 에디션 및 `각각 하나씩 부분 집합`이라는 원문 연결은 보존했다. CDC 문장은 알려진 구현 이름을 만들지 않고 `()이라고 하는`만 정리해 실제 조건과 별도 구현 서술을 유지했다.

빈 표제의 내용은 입력에 없으므로 본문에서 제거하고 이 파일에 원형만 보관했다. 실제 내용이 있는 JVM 언어, JavaScript 변환, 구현, 각주, 외부 링크와 분류는 보존했다.
