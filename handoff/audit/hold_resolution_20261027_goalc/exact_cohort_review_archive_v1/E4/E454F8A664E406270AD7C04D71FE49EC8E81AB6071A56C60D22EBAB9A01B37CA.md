# 216309 원형 보류 메모

## 제목 미연결 byline 묶음

본문 뒤 원문에 연속한 다음 네 행은 연결할 제목이 없어 한 저자 또는 공동저자 귀속으로 묶지 않는다.

```text
by Ovidiu Mățan
by Călin Biriș
by Ovidiu Mățan
by Ovidiu Mățan
```

## 반복된 불완전 말미 조각

```text
Incremental design means creating the design while the code is written Incremental design is an alternative to the design made on paper or in specialized tools before writing code. Incremental design
```

앞선 본문에는 incremental design의 뜻과 종이·전용 도구로 사전 설계하는 방식과의 차이가 완결된 형태로 이미 설명돼 있다. 이 말미 행은 그 설명의 미완 반복 조각이며 독립 기사나 결론으로 연결되지 않는다. 말미 조각만 새 본문에서 분리한다.

## 선택

실제 TDD·incremental design 설명 본문은 유지하고, 제목 없는 byline 묶음과 반복 말미 조각만 학습 본문 밖에 보존한다.
