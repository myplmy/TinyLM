# expanded_train:65300 원형 보류 기록

원문 표제는 `오야마역(, )의 다른 뜻은 다음과 같다.`이고, 두 구획의 도입은 각각 `오야마역()`이었다. 괄호 안에는 실제 별칭값이 없으므로 새 본문에서는 세 빈 괄호 슬롯만 제거했다. 두 `오야마역` 구획은 서로 다른 실제 역 항목들(가고시마현·도쿄도 / 도치기현)을 각각 따르므로 반복된 구획 표제를 그대로 유지했다. 지명·노선·운영자 관계를 보충하거나 합치지 않았다.

원문 말미의 단독 `같이 보기` 표제 뒤에는 항목이 없다. 후보의 해당 빈 표제 제거를 유지했다.

지정 원문·후보와 TASK016의 단일 연속 패킷을 BEGIN부터 END/EOF까지 읽었고, 후보와 새 본문의 전체 diff를 확인했다. 실제 역명과 설명은 수정하지 않았다.
