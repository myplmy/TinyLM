# 8004 원형 보류 메모

검수 범위는 지정 원문·후보와 순서 패킷이다. 후보가 빈 병기 괄호 여러 곳과 빈 `출처`·`외부 링크` 표제를 이미 제거했다. 이 메모는 원문에 남았던 빈 슬롯의 원형을 보존하며, 이름이나 별칭은 추정하지 않는다.

- 제목/생몰 표기: `팀 버너스리 경(, 1955년 6월 8일 ~ )`의 선행 빈 병기
- 가족/배우자: `메리 리 우즈()`, `콘웨이 버너스리()`, `낸시 칼슨()`, `로즈메리 리스()`의 빈 병기
- 경력/수상: `인콰이어()`, `BBC '위대한 영국인 100()'`, `밀레니엄 테크놀로지 상()`의 빈 병기
- 원문 후반의 내용 없는 `출처`와 `외부 링크` 표제는 후보에서 이미 제거되었다. 이를 복원하거나 항목을 만들어 넣지 않는다.

선택 본문은 후보를 바탕으로 남아 있던 `BBC '위대한 영국인 100()'`의 빈 괄호만 제거했다. 이름, 생몰일, 혼인 관계, 연혁, 수상과 분류는 그대로 유지했다.
