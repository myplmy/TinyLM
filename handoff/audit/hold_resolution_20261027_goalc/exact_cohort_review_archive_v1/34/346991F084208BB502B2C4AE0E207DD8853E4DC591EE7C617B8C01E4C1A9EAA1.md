# 1418922 원형 보류 — v2

말미의 게시글 탐색 UI만 원형 분리했다: `- << Previous post in topic Next post in topic >>`. 이는 post body가 아니라 이전/다음 글 이동 문구다.

입력 첫머리의 `68`은 의미를 단정하지 않도록 버리지 않고 별도 행으로 보존했다. 제목 `Re: [python-iter] Colon syntax: We barely knew thee...`, 게시 날짜와 작성자 표기, 인용된 부분 코드, 응답 문장과 Russell 인용은 유지했다. 날짜/작성자 사이와 `__iterator__()` 인용 코드 뒤의 `I can see...`는 원문에 글자 단위로 붙어 있어도 문맥 경계가 명확하므로 줄만 나누었다. 코드는 부분 발췌로 보존했으며 실행 가능한 전체 프로그램으로 보충하거나 고치지 않았다.
