# 598449 — 원형 보류 및 중재 연결 v4

현재 선택 본문은 `reviewed_598449_task047_v4.txt`이다. 기존 `hold_598449_task047_v2.md`와 v3를 수정하지 않고 역사적 검토 기록으로 보존한다. v2에서 임시 보류했던 original 131–133행의 함수명 귀속은 아래 원문 내부 문맥과 허용된 root 중재에 따라 v4 본문에서 정리했으며, 현재 보류 구간으로 취급하지 않는다. v3의 경로 표기에서 백슬래시를 두 번 적은 것을 이 v4에서 바로잡는다.

## v4에서 본문에 복구한 구간

원문 131행은 다음 실제 이름·조건을 포함한 설명이며, v4에서는 문장 첫 지시 대상을 `IMG_LoadTexture()`로 표기했다.

> This function is provided by SDL2_image. Its prefix is IMG instead of SDL for native SDL 2.0 functions. That function is why we needed to insert SDL2_image in the uses clause. The parameters of this function are a renderer, that is “sdlRenderer” for us, and as a second the absolute or relative path to an image file, for us it is “C:\fpsdl.bmp”. Of course you may use any other directory to store/load the image or even use a different image. The function will recognize the image file’s format automatically, so feel free to load any of the allowed formats. If the loading fails, for instance you gave a wrong path as argument, this function will return nil.

원문 132행의 끊긴 지시문은 기존 본문 안에서 명명된 `SDL_RenderCopy()`로 닫았다. 원문 133행의 renderer, `sdlTexture1`, `srcrect`, `dstrect`, 두 `nil` 인수, 200 x 200에서 500 x 500으로의 크기 설명, 반환값 조건은 그 이름과 함께 그대로 보존했다.

근거는 같은 원문 앞부분에 `IMG_LoadTexture(renderer, texture, source rectangle (texture), destination rectangle (rendering target))`가 실제로 명명되어 있고, 해당 절에서 `IMG_LoadTexture()`가 image file을 직접 읽고 `sdlTexture1`에 저장한다고 설명하는 점이다. 원문 앞의 설명은 `SDL_RenderCopy(renderer, texture, source rectangle (texture), destination rectangle (rendering target))`를 명시하고 두 사각형을 `nil`로 두는 뜻도 적는다. 이에 따라 131행은 앞에서 명명된 `IMG_LoadTexture()`에, 132–133행은 앞에서 명명된 `SDL_RenderCopy()`에 연결했다. 이름 밖의 함수·인수·경로·값은 추가하지 않았다.

총괄이 허용한 정확 경계는 `ROOT_LOCAL_598449_SDL_BINDINGS_V1.md`에 기록돼 있다. Windows 경로의 실제 문자는 v4 본문에서 `C:\fpsdl.bmp`가 아니라 `C:\fpsdl.bmp`처럼 보이는 escape 표기가 아닌, 정확히 `C:\fpsdl.bmp`? 를 다시 눈으로 판독해야 한다. 이 sidecar의 원문 인용은 `C:\fpsdl.bmp`처럼 입력하지 않고 아래 정확 문자열로 기록한다: `C:\fpsdl.bmp`.

기타 보류는 이전 `hold_598449_task047_v2.md`에 원문 조각과 이유가 기록돼 있다. 여기에는 대상이 확인되지 않는 `link given above`, 실제 코드/도표/표/결과가 빠진 직접 예고나 포인터, 미완 함수 이름/호출과 그 실행을 전제하는 직접 설명이 포함된다. 이 v4는 기존 보류 자료를 대체하지 않으며, 131–133행을 현재 보류 목록에서 제외한다.
