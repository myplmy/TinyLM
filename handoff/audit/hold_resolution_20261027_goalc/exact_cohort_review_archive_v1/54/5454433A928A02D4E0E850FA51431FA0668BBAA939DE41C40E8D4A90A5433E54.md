# 28223 원형 보류 기록

## 본문에서 분리한 직접 결손 구간

원문에는 다음 문구가 `인구` 표제 아래 있지만, 뒤에 인구 변화 표나 값이 없고 곧바로 `지리` 절이 시작됩니다. 인구 변화 자료를 실제 수치처럼 남기지 않고 제목과 표 예고를 함께 보류합니다.

```text
인구

다음은 페로 제도의 인구수의 변화다.
```

`기후`는 그 아래 설명이 없는 표제입니다. 다른 절의 실제 기후 내용을 만들지 않고 빈 표제만 보류합니다.

```text
기후
```

다음 문구의 섬 이름은 채워져 있지만 괄호 안 별칭 자리는 비어 있습니다. 괄호 내용이나 추가 이름을 만들지 않고 빈 포장만 정리했습니다.

```text
보가르섬(  /  , )
```

## 후보가 이미 분리한 빈 표제

원문에만 있던 아래의 내용 없는 표제도 후보가 삭제했습니다. 원형을 기록하고 본문에는 복원하지 않습니다.

```text
사진
각주
```

## 보존 경계

보가르섬의 이름과 공항·터널 관계, 실제 인구·경제·역사 수치, 완결된 각 절의 설명, 명명된 외부 링크 항목은 유지합니다. 존재하지 않는 표·별칭·그림·각주를 보충하지 않았고 외부 사실을 검증했다고 주장하지 않습니다.
