# 501523 원형 HOLD

실제 메서드명을 원문에서 확인할 수 없는 두 구간을 분리한다. Connection/DbGate를 통한 모델 생성, DbContext/ObjectContext를 통한 모델 취득, 표와 필드 이름의 매핑 설명처럼 주체와 관계가 채워진 내용은 본문에 보존했다.

첫 절의 원문:

```text
There is an opportunity to create a model directly based on Connection object using DbGate component and a special method of DataModel:
```

본문에는 Connection object와 DbGate component를 통한 모델 생성 관계를 남겼다. 메서드 이름을 직접 예고하는 `and a special method of DataModel:`은 이름이 소실돼 보류한다. 다음의 실제 매핑/동일 명명 설명은 `Creating model "on the fly"` 절에 남겼다.

끝 절의 원문:

```text
When using EntityFramework we can get a model by DbContext (or ObjectContext for older versions of EF) class using special method
This method is very similar to the previous one, with the difference that we get the model's structure directly from a "context" class instead of using meta-information from database.
```

본문에는 DbContext/ObjectContext에 의한 모델 취득과 채워진 모델 구조 설명을 독립 문장으로 보존했다. `using special method`의 빠진 이름과, 이를 앞 절의 이름 없는 특수 메서드와 비교하는 `This method is very similar to the previous one, with the difference that`만 분리했다. 메서드명은 추가하지 않았다.
