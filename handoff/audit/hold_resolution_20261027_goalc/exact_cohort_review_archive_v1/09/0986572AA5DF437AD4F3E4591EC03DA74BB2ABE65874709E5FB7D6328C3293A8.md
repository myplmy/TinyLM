# 1063015의 불완결 설명 원형

아래 두 설명 조각은 결말 대상 또는 도구 이름이 소실되어 보충 없이 본문에서 분리했다.

- `Writing valid markup helps your site work the way you expect and is more compatible with older`
- `To help developers with this, IE10 now reports HTML parsing errors via the F12`

조건절 `If you need to distinguish between more recent browsers, feature detection instead.`도 조건부 동작을 완결하지 못해 원형 보류했다. 그 앞의 `This means conditional comments can still be used, but will only target older versions of IE.`는 원문 줄을 이어 읽으면 완결된 설명이므로 본문에 보존했다.

HTML DOM/IE9 비교 표본, 실제 `<b>`, `select`/`table` 코드 및 conditional-comment 예시는 새 본문에 그대로 보존했다. HTML 예시의 구조·출력을 추정해 고치지 않았다.
