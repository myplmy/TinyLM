# 54494 원문 수치 표기 보존

아래 원문에는 지수 기호가 빠져 있어 완결된 숫자 표기가 아니다. 총괄이 같은 `random()` 명세와 동일 상태 배열 조건을 원 발행처와 대조한 근거는 `ROOT_EVIDENCE_54494_RANDOM_EXPONENTS_V1.md`에 있다. 새 본문에는 그 좁은 근거가 확인한 세 지수만 복원했다.

```text
The random() function shall use a non-linear additive feedback random-number generator employing a default state array size of 31 long integers to return successive pseudo-random numbers in the range from 0 to 231-1. The period of this random-number generator is approximately 16 x (231-1).
```

```text
With 256 bytes of state information, the period of the random-number generator shall be greater than 269.
```

기존 `31`, 곱수 `16`, `256 bytes` 조건과 모든 다른 API·값·조건·출처 서술은 그대로 남겼다. 다른 2n/231 표기, 다른 구현 조건이나 새 선언은 복원 범위에 넣지 않았다.
