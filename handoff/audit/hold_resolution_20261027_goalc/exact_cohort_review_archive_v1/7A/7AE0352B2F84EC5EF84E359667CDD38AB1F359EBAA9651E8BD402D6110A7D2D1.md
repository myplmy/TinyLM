원문 9–13행의 C 예제는 함수 선언과 변수 대입만 남고 함수 본문/경계가 없습니다. 그 코드에 직접 의존하는 13행의 “Based solely on reading the code…”부터 큰 음수까지의 설명도 함께 보류합니다. 누락된 함수 본문이나 반환 동작을 추정하지 않습니다. 16행의 int main (void)는 짝을 이루는 본문이 없는 서명 조각이므로 그 줄만 보류합니다. 주변의 컴파일 결과·반올림 설명과 나머지 독립 본문은 새 TXT에 보존했습니다.

원형 보류 조각:
- 9–12행: double f(double a) / double b, c; / b = 10*a - 10; / c = a - 0.1*b;
- 13행 전체: Based solely on reading the code, you’ll conclude that it always returns 1: c = a – 0.1*(10*a – 10) = a – (a-1) = 1. But if you execute the code, you’ll find that it may or may not return 1, depending on the input. If you know anything about binary floating-point arithmetic, that won’t surprise you; what might surprise you is how far from 1 the answer can be — as far away as a large negative number!
