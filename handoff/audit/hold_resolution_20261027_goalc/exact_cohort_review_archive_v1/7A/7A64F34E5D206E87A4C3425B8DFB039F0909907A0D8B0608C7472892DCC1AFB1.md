# expanded_train:7830 원형 보류

지정 원문·후보 전문, 9개 순서 패킷과 전체 diff를 읽었다. 후보는 제목의 빈 병기 슬롯과 빈 `각주` 표제만 제거했다. 아래는 추가로 정리한 빈 번역 병기와 미완 연결이다.

## 빈 번역 병기

```text
'Enlightenment'(, )를 번역한 한자어 계몽(啓蒙)이란
```

빈 괄호만 정리하고 실제 영어 용어, 계몽의 한자 표기 및 이어지는 설명은 본문에 보존했다. 없는 번역어를 만들지 않았다.

## 프리드리히 2세와 프랑스어 서신의 미완 연결

```text
이미 언급한 바와 같이 프리드리히 2세는 계몽 사상가인 볼테르와 친밀한 관계를 유지하였지만와의 서신 교환이 프랑스 어로 이루어진 점,
```

볼테르와의 친밀한 관계는 앞부분에 명시되어 있어 본문에 독립 문장으로 유지했다. `지만와의` 다음 서신 상대 연결은 결손되어 있으므로 이 구절만 원형 보류하며 볼테르를 서신 상대에 새로 붙이지 않았다. 바로 뒤의 예술가·문인·학자들이 프랑스어로 이야기했다는 완결 진술과 이를 입증한다는 문맥은 본문에 남겼다.

원문/후보 diff에서 후보가 이미 제거한 `계몽시대(啓蒙時代, , )`의 빈 슬롯과 빈 `각주` 표제도 사실 확인 또는 내용 복원으로 취급하지 않았다. 실제 인물·시기·사상·서지와 저자 관점은 본문에 그대로 보존했다.
