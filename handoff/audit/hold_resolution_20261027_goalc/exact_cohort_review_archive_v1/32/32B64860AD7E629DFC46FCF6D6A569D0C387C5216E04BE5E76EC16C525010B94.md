# expanded_train:797310 원형 보류

- 원형 문구: `and the global variable errno is set to indicate the`
- 위치: `The munmap() function returns the value 0 if successful; otherwise the value -1 is returned` 바로 뒤.
- 이유: errno가 무엇을 나타내는지 설명이 끊겼다. 성공 시 0, 실패 시 -1이라는 완결된 반환 정보와 실제 [EINVAL] 조건·관련 함수·4.4BSD 이력은 본문에 보존했고 errno 값을 추정하지 않았다.
