# 139290 단정 생년 분류 보류

도입부와 본문은 `1342년 혹은 1349년 3월 7일(음력 2월 1일)`이라는 대안, 각 연도에 연결된 《몽골원류》·《황사》의 귀속, 서로 출생 기록이 모순된다는 설명을 유지한다. 월일·음양력 관계와 대안의 범위를 분리하거나 한 연도를 선택하지 않는다. 단일 연도를 확정하는 분류행 `1342년 출생`만 본문에서 분리했다.

《황사》의 `1349년에 태어나, 30세에 대칸위에 올랐다`와 `1349년생 설을 취한다 해도 ... 10세 정도 차이`를 포함한 친자관계 논의는 원문의 출처 귀속·조건·추정·부정에 속하므로 그대로 보존했다. 새 나이나 연도를 계산하지 않았다.
