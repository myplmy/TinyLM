# expanded_train:314266 원형 보류·정리 기록

## 값 없는 표제/포장과 사이트 UI

- 원문은 `Time Required:`의 괄호 안에 있는 수업·활동 기간을 바로 다음 줄에서 다시 제시합니다. 두 번째 괄호 행을 중복으로 분리했습니다.
- `Each TeachEngineering lesson...`부터 ASN 구조 설명까지 같은 세 문장이 바로 반복되는 두 번째 블록을 중복으로 분리했습니다. 첫 설명은 본문에 그대로 남겼습니다.
- `Do you agree with this alignment? Thanks for your feedback!`, `Alignment agreement: Thanks for your feedback!`, `Click to view other curriculum aligned to this Performance Expectation`은 정렬 피드백/탐색 UI라 분리했습니다. 인접한 실제 NGSS 기준과 설명은 본문에 유지했습니다.
- `Worksheets and AttachmentsVisit [ ] to print or download.`는 값 없는 링크 껍데기이며, 이어지는 `More Curriculum Like This`와 네 개의 `...`로 끝나는 추천 카드도 이 수업 본문이 아닌 빈 링크/잘린 탐색 카드라 분리했습니다. 이후 실제 수업 준비·요건 문장은 유지했습니다.

## 직접 의존하는 누락 수식

- `The t-statistics corresponding to the average d̅ of these paired differences (Figure 10) is computed using the equation:` 및 `where sđ = standard deviation of the differences, and n = sample size.` — 해당 수식이 없습니다. 이 수식의 값·기호 관계를 만들지 않았습니다.
- 원문의 `The P-value (P(t ≥ t đ)) corresponding to this statistic` — 위에서 빠진 통계량에 직접 연결된 표기/지시라 이 부분은 분리했습니다. Excel® `TTEST()`로 P-value를 구한다는 독립 설명, 유의수준 0.01 ≤ α ≤ 0.1, 판정 조건과 결론은 유지했습니다.
- `The corresponding t-statistic is computed using the equation:` 및 `where x m is ...`로 시작하는 표본 평균·표준편차·표본크기 설명 — 이에 대응하는 수식이 없습니다. 수식이나 변수를 재구성하지 않았습니다. 같은 원문의 `P(t ≥ t đ)`와 `corresponding to this statistic`도 직접 의존 부분으로 분리하고, TTEST·유의수준·판정 설명은 유지했습니다.
- `where this relative change is defined as relative size change (%):` — 뒤따를 정의식의 값이 없습니다. 너비 사이의 상대 크기 변화 자료를 수집한다는 문장과 실제 그래프 설명은 유지하고 비율식을 생성하지 않았습니다.
- `as stated in their power property:` — 해당 지수 법칙 식이 없습니다. 로그가 거듭제곱을 제거한다는 원문의 정성 설명과 실제 이어지는 로그 자료 처리 문장은 유지했습니다.

원형 문구는 이 sidecar와 지정 original 입력에 보존하며, 본문에는 검수 문구를 넣지 않았습니다. 외부 사실 검증이나 수식 복원은 하지 않았습니다.
