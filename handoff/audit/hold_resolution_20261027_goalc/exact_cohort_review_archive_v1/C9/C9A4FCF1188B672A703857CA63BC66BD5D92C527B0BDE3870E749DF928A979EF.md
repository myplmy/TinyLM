# expanded_train:805394 원형 보류

## 판독 범위

지정 original/candidate와 연속 패킷 0001–0003을 끝까지 읽었다. full_diff는 줄 차이가 없다고 표시한다.

## 학습 본문에서 분리한 원형

- 비어 있는 탐색/예제/적용범위 표지: “See Also Example Applies To”. 이 문자열 뒤에 대응 값이 없어서 빈 탐색 메타데이터로 분리했다.
- 실제 Implements 구문이 비어 있는 예제 도입부: “To do this, in the Declarations section of the Class module that provides your add-in's connection object, enter:”. 이 문장 다음에 입력할 코드 줄이 없다. 빠진 Implements 문장을 만들지 않았다.
- 누락된 줄을 직접 받는 절차: “After adding this line, you can then select IDTExtensibility from the module's Object drop down box. Select each method from the Procedure drop down to get the procedure template shown above in Syntax. Notice that the necessary code is automatically added to the Class module.”
- 누락된 Implements 구문을 “the above syntax”로 직접 지시하는 설명과 이어지는 메뉴 지시: “When the above syntax is entered in the Declarations section of the Class module that handles an add-in's events, the interface's methods become available for your use through the module's Procedure and Object drop down boxes. To add the code to the module, select the method from the Procedure drop down box.”

빈 표지와 코드 예고/직접 종속 절만 분리했다. IDTExtensibility_OnDisconnection 서명·매개변수와 설정 값/설명 표, Implements에 대한 완결 일반 설명, 나머지 완결 방법 동작·조건은 본문에 보존했다. removemode 표의 vbext_DisconnectMode / vbext_ConnectMode처럼 원문에 기록된 값이나 관계를 고치거나 외부 사실로 확정하지 않았다.
