# 43894 원형 보류·정제 기록

- 리드의 `독일 제15기갑사단()`에서 값 없는 괄호만 정리했다.
- 내용이 없는 `역대 지휘관`과 `시기별 배치 현황` 표제를 분리했다.
- 실제 수훈자나 명단이 없는 `15 기갑사단` 하위 표제와 직접 예고 `다음은 제15기갑사단 소속으로 기사 십자장을 수여받은 서훈자 명단이다.`를 함께 원형 보류했다. 인접한 제33보병사단의 실제 `1940년 8월 15일 - 루돌프 진체니히` 항목은 그대로 유지했다.
- 전투·부대편제·연도·수치·실제 수훈 정보와 더 읽어보기 항목을 보존하고 누락된 지휘관·배치 현황·수훈자 이름을 만들지 않았다.
