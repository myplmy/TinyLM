# TASK_003 판독 및 EOF 기록

각 지정 ID의 native original/candidate 내용, TASK가 지정한 순서 패킷, 전체 diff를 읽었다. Identity V1이 동일 바이트 연결을 지정한 경우에도 지정된 원문/후보/diff packet을 읽었다. 모든 수정본은 자기 폴더의 initial candidate 사본에서 시작했고, `diff -u`의 모든 hunk와 실제 파일 끝부분을 확인했다. 끝 바이트를 자르거나 원문을 덮어쓰지 않았다.

| ID | 입력 판독 끝 | 출력 확인 |
|---|---|---|
| 215675 | packet 0005, 원문·후보 END 및 full diff END | 새 TXT 전체 diff와 마지막 분류 태그 확인 |
| 215942 | packet 0001, 원문·후보·full diff END | 새 TXT의 제정일·마지막 분류 태그 확인 |
| 216473 | packet 0010, 전체 10개 순서 조각 후 `source_packet_sequence_complete:true` | 새 TXT 전체 diff에서 빈 괄호/고립 괄호/표식 정리만 확인, 마지막 분류 태그 확인 |
| 216912 | packet 0005, 전체 5개 순서 조각 후 `source_packet_sequence_complete:true` | 새 TXT 전체 diff에서 빈 표제/명예의 전당 블록만 제거, 마지막 분류 태그 확인 |
| 217232 | packet 0001, original·candidate·full diff END | 새 TXT 전체 diff에서 세 빈 괄호 슬롯만 정리, 말미 확인 |

전문 판독과 수정 확인 범위이며, 외부 사실 검증이나 전체 캐시 승인 주장이 아니다.
