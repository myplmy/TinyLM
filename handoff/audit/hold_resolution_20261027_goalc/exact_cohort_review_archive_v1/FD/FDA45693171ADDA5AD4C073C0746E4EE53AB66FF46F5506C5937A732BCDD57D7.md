## 근거

다운로드 안내는 대상 링크가 없다. import/대입/복수 호출이 구분자 없이 붙은 코드는 경계를 만들지 않았다. 데이터셋을 불러오는 코드의 도입과 잘린 ray 생성 설명은 해당 예제를 직접 가리킨다. 실제로 완결된 `trident.make_simple_ray(...)` 호출은 API 이름·인수·출력 파일명·lines 값이 채워져 있어, 앞 코드의 변수 정의가 보류되더라도 원문 API 단편으로 본문에 보존했다. `('gas', l')` 항목은 두 번째 필드명이 손상돼 보류하고 다른 채워진 필드 행은 남겼다. ProjectionPlot·열밀도·SpectrumGenerator·post-processing·compound-ray의 붙은 복수 문장 코드는 구분자를 추정하지 않고 각각 원형으로 보류했다. 이와 직접 연결된 빈 alias 문장과 코드가 없는 plot/save 예고도 보류했다.

본문에는 LightRay의 정의, 선 목록·원소명, 채워진 field 행, 실제 API 설명과 결과 형식, 30 SNR, 단일 ray API 호출, compound-ray 설명·지원 코드/문서 관계를 보존했다. 코드를 실행 가능한 예제로 만들거나 인자·결과를 추가하지 않았다.
