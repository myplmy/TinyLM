# 139131 원형 보류 근거

원문과 지정 후보에는 차이가 없었다. 본문에서 왕족 정보 틀의 빈 필드만 걷어내고 채워진 이름·직위·연호·날짜·가족·종교 등의 필드 관계는 그대로 유지했다. `그림` 값은 실제로 파일명만 있는 infobox 이미지 메타데이터라 학습 본문에 파일명을 문장으로 옮기지 않고 여기 원형으로 보존한다.

```text
|그림     = YuanEmperorAlbumIrinchinbalPortrait.jpg
|그림설명 =
|서명     =
|문장     =
|문장설명 =
|즉위식   =
|재상     =
|수상     =
|총리     =
|별호     =
|능호     =
|칸호 =
|출생지   =
|매장지   =
|능묘     =
|자녀     =
|친인척   =
|종교     =
```

값이 비어 있던 `원래 이름` 필드도 본문에 추정 표기를 만들지 않고 분리했다. 실제로 채워진 이름 표기만 남기기 위해 아래 빈 병기와 짝 없는 서식 표시를 정리했다.

```text
|휘       = 린친발(, , Ринчинбал)
본명은 린친발(, Ринчинбал, , ) 혹은 이린친발, 이르체말, 몽골식 칸호는 에르데네초트 칸'''(ᠪᠠᠭᠠᠲᠤᠷ ᠴᠣᠭᠲᠤ ᠬᠠᠭᠠᠨ, Эрдэнэцогт хаан)이다.
```

기록된 `린친발`, `Ринчинбал`, `이린친발`, `이르체말`, `에르데네초트 칸` 및 실제 몽골어 표기는 보존했다. 빠진 표기·이름을 생성하거나 외부 사실을 검증하지 않았다. 원문에 있는 연도·월일·대안·사망 관련 불확실성, 인물·역할·사건·수치 및 나머지 서술은 그대로 유지했다.
