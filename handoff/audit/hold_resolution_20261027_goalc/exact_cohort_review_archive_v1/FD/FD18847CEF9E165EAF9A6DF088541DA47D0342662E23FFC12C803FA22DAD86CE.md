## 줄바꿈이 손상된 Python 예제와 그 출력

세 코드 줄은 여러 실행문이 줄바꿈 없이 합쳐져 제어 흐름·문장 경계를 복원할 수 없어 원형 그대로 분리했다. 뒤에 있는 출력도 이 코드에 직접 연결되어 있으므로 새 출력 주장을 본문에 남기지 않았다.

```text
for i in range(10): if i == 3: print(quit) quit() print(i)
for i in range(10): if i == 3: print(exit) exit() print(i)
```
