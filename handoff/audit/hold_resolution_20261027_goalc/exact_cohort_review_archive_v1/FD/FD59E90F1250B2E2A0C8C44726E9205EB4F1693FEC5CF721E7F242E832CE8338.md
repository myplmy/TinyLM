# 172286 원형 보류 기록

## 보류 원형

```text
가토 도모사부로(, 분큐 원년 음력 2월 22일 (1861년 4월 1일) ~ 다이쇼 12년 (1923년 8월 24일)
외부 링크
```

## 처리 근거

실제 음력·양력 생몰 표기와 이름을 그대로 두고 빈 선행 병기 슬롯만 정리했다. 실제 총리관저 링크는 `각주`에 연결되어 있어 보존했다. 내용이 없는 `외부 링크` 표제는 분리했으며 새 날짜·링크·인명은 만들지 않았다.

새 TXT에는 원본 후보에 없던 종단 LF가 추가되어 있다. 마지막 분류 행과 본문을 유지했으며, 말미를 바이트로 자르지 않았다.
