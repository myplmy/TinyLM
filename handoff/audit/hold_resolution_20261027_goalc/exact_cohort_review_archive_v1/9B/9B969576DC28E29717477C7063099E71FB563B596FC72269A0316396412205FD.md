# 409871 원형 HOLD 근거

후보는 원문과 동일하다. 다음 문구는 실제 빠진 답변 목록/기준을 직접 예고하거나 그 누락 목록 없이는 질문의 답이 되지 않아 본문에서 분리했다.

- Q6 JIT: `There are three types of JIT and they are:`만 보류. 바로 앞의 JIT 정의는 완결되어 본문에 남겼다.
- Q9 원문 전체: `9. What are the different types of assembly?` / `There are two types of assembly –`. 종류 목록이 없어 질문·미완 답변을 함께 보류했다.
- Q32 원문 전체: `32. What are the types of Authentication?` / `There are three types of Authentication and they are –`. 이름 목록이 없어 질문·미완 답변을 함께 보류했다.
- Q33 GAC: `It is used in the following criteria:`만 보류. 앞의 GAC 위치 설명은 유지했다.
- Q34 CLR: `CLR takes care of the following:`만 보류. CLR 정의와 코드 실행 역할 문장은 유지했다.
- Q39 원문 전체: `39. How many languages are supported by .Net?` / `Following are the languages supported by VB.Net:`. 목록이 없고 질문의 .Net과 답변의 VB.Net 표기도 다르므로 어느 언어 수나 목록을 만들지 않고 단위를 보류했다.
- Q46 Code Security: `.NET framework provides security features to secure code from unauthorized users. There are two types of security in .NET:` 중 마지막 문장 `There are two types of security in .NET:`만 보류. 실제 보안 기능 설명은 유지했다.

다른 완결 문답, 실제 코드·표, 이름·API·값·조건·부정은 변경하지 않았다. 빠진 답 목록이나 정의를 외부 지식으로 채우지 않았다.
