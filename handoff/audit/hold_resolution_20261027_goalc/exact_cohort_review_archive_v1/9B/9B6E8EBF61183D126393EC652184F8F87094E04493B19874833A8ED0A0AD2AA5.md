# 40716 원형 HOLD 근거

## 직접 없는 그림 참조

원문 조각: `The screenshot below shows heading in red and bearing in blue, just after stopping walking and turning the device 90 deg counterclockwise.`

이 문장은 실제 포함되지 않은 스크린샷의 색상·시각 상태를 지시하므로 본문에서 분리했다. 바로 뒤의 `Heading follows in real time.`은 앞서 완결된 heading 동작 설명과 독립적으로 읽혀 본문에 유지했다.

원문에서 분리한 참조 표현: `If you take another look at the screenshot above, you'll see that`; `So you can see from the script list that`; `So in the figure, you can see that`.

이들은 없는 스크린샷/목록을 가리키는 연결 표현이다. 그 뒤에 실제로 채워진 서술은 보존했다: 스크립트 이름 차이, Developer Setup·Open Routine·Record Logged In User ID 사이의 호출 관계, `Set Window( [PrintFlag] )`와 `Set Next Serial Value( WhichTable, NextSerialValue )`의 실제 인자·선택성 설명. 호출명, 인자명, 관계, 조건은 추가하거나 바꾸지 않았다.

## 페이지 UI

원문 UI 행: `Reader Comments (2)`; `Add A Comment`.

댓글 UI 표제/행동 문구만 분리했다. 사이의 `Thanking you in advance`는 실제 댓글 텍스트일 수 있어 임의로 지우거나 작성자를 붙이지 않고 본문에 그대로 남겼다.
