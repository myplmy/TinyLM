# 42037 보류 원형

| 원문 구간 | 보류 근거 |
|---|---|
| `if (Request.UserAgent.ToString().IndexOf("Googlebot") > -1)` | 조건문 본문이 없고 실행 동작을 만들지 않는다. `Request.UserAgent`와 비교식은 이 원형에 보존한다. |
| `In the above code sample, we pulled the user-agent string from the HttpRequest object.` | 해당 문장은 바로 앞의 본문이 없는 `if` 예제를 지시한다. |
| `Request.Browser.Crawler Always Returns False` / `If you try using the above code sample and testing using various user-agent strings to simulate web bots (ie. with the Firefox User-Agent Switcher plug-in), you’ll notice that Request.Browser.Crawler always returns false. This is due to missing information in one of .NET’s configuration sections, called BrowserCaps. We’ll need to populate the list of BrowserCaps (the list of available user-agents that we have information about) in order to use this feature.` | 예제와 특정 테스트 관측 및 그 원인을 직접 연결한다. 이를 조건 없는 보편 명제로 남기지 않는다. |
| `Inside the web.config (or machine.config) file:` | 뒤따를 XML 예제가 없다. |
| `The above is a sample entry for detecting Windows 98 and Windows NT operating systems in the user-agent string from the web browser.` | 없는 XML 항목을 직접 가리킨다. 다음의 BrowserCaps 목록 설명은 본문에 보존했다. |
| `Open the following file for editing:` | 파일명이 없어 대상을 만들지 않는다. |
| `The actual command line to use is: C:\WINDOWS\Microsoft.NET\Framework\` | 명령 줄이 경로 중간에서 끝난다. 나머지 경로·실행명령을 추측하지 않는다. |
| `Sponsor Me` | 저자 소개에 붙은 사이트 후원 CTA로 본문 밖에 둔다. |

본문에는 실제 `Request.UserAgent`, `Request.Browser`, `Request.Browser.Crawler` 설명과 Boolean 의미, BrowserCaps/.BROWSER의 명명된 관계 및 설정 절차를 유지했다. 단, 빈 예제나 직접 의존 문장을 일반 사실로 바꾸지 않았다.
