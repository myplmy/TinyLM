# 193762 페이지 UI 보류

본문의 소절 뒤에 반복된 `back to top` 7행은 페이지 상단 이동 링크이며, `Back to Inferno main page`는 Inferno 목차로 돌아가는 링크다. 인용된 시구와 번역문 앞뒤의 두 `Loading the player...` 문구는 오디오 재생 UI 상태로 보존한다. 이 열 문구만 본문에서 분리했다.

Minos·Francesca·유명 연인·Lancelot에 대한 실제 소절 제목, 산문 설명, 이탈리아어 인용·영어 번역, 토론 질문은 모두 유지했다. 오디오 플레이어 존재 외의 의미를 덧붙이지 않았다.
