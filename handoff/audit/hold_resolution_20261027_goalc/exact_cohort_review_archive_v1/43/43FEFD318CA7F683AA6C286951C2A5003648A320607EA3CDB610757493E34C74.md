## 사유와 경계

첫 구절은 “at a”에서 목적어가 끊겨 문장이 완결되지 않는다. 잘린 목적어를 추정하지 않도록 이 불완전 비유만 보류했다. 이어지는 Java 토큰화 절차, 명명된 `InputStream`, `BufferedReader`, `File`, `FileReader`, `StreamTokenizer`, `readLine()`, `exists()`, `nextToken()`, `TT_EOF`의 설명과 실제 출력 예시는 보존했다.

코드 제시 예고 뒤에는 코드가 없고, 별도 완결 문장으로 실제 출력 예고와 출력값이 있다. 따라서 코드 예고 문장만 보류했으며 빠진 프로그램 코드를 만들지 않았다. 실제 출력의 `TokenizingJavaSourceCode.java`와 `Number of tokens = 158`은 유지했다.

원문에 있던 두 구절을 그대로 옮겼다. 이 sidecar는 학습 본문에 포함하지 않는다.
