# 15204 원형 보류

판정: 후보에서 제거된 빈 사망 구획을 유지하고, 실제 날짜·주체·관계·연호 값을 보존한 새 본문에서 빈 병기 괄호만 분리했다.

원문에서 분리한 정확 조각:

- `일본(日本) 에이쇼() 18년 / 다이에이() 원년` — 두 연호명, 연도와 순서는 보존하고 괄호 안의 빈 병기 슬롯만 분리했다.
- `류큐(琉球) 쇼신왕() 45년` — 이름과 기년을 보존하고 빈 괄호만 분리했다.
- `사망` — 원문 끝의 내용 없는 구획. 지정 후보에서 제거한 처리를 새 본문도 유지한다.

사건·탄생·사망 항목의 날짜와 각 인물의 원래 역할, 음력/양력 한정은 그대로 보존했다. 날짜 순서를 재배열하거나 인물·날짜를 서로 연결하지 않았다.
