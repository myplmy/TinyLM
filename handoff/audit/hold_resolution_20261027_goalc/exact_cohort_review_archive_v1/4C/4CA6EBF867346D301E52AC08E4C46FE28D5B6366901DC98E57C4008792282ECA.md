# expanded_train:647404 원형 보류 조각

본문에서 빈 확장 포장, 관계가 끊긴 문장, 내용 없는 각주/분류 꼬리를 분리했다. 원형은 다음과 같다.

```text
(PEB: )
PEB 커널 모드 EPROCESS 데이터 구조체 뿐만 아니라 클라이언트/서버 런타임 하위 시스템의 주소 공간에서 관리되는 프로세스 당 데이터 구조체와 밀접하게 관련되어 있다.
각주 

자료 구조
자료형
객체 지향 프로그래밍
```

첫 문장의 이미 채워진 `프로세스 환경 블록 (PEB)`와 독립적으로 완결된 뒤의 PEB 설명, WinDbg의 `EPROCESS` 설명, `IMAGE_OPTIONAL_HEADER32` 설명은 본문에 보존했다. 빠진 관계를 추정해 채우지 않았고, 분류 꼬리의 이름을 본문 설명에 재귀속하지 않았다.
