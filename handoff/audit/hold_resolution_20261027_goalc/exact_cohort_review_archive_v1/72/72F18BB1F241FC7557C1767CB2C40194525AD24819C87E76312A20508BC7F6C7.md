# expanded_train:1418578 PEP 예제 주석 위치 후속 근거

기존 원문 판독과 PEP227 근거를 다시 확장하지 않고, 허용된 Tim Peters 코드 블록만 수정했다. PEP 근거 MD의 실제 10논리줄에 맞춰 `g()`의 `# ...` 세 줄을 함수 본문과 같은 4칸 들여쓰기로 두고, `for i in x:`의 원저자 주석을 해당 줄의 inline 위치로 옮겼다.

최종 블록은 다음과 같다.

```text
i = 6
def f(x):
    def g():
        print i
    # ...
    # skip to the next page
    # ...
    for i in x:  # ah, i *is* local to f, so this is what g sees
        pass
    g()
```

`# skip to the next page`와 나머지 주석·코드는 유지했다. bank_account의 `[0]` 네 곳, wrapper의 `attr[0]`, `return balance`, 다른 예제와 본문은 변경하지 않았다. 코드를 실행하거나 현대화하지 않았다. 기존 편집 placeholder 보류 메모는 `hold_1418578_v1.md`에 있으며 이번 후속의 원형 위치/새 위치 차이는 이 메모가 기록한다.
