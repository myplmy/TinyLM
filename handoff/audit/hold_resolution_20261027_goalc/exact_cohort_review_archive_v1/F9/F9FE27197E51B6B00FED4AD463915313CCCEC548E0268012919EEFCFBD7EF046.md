# expanded_train:754182 보류 원형과 범위

candidate에서 제거한 페이지 UI 원형:

- `Back to top` (6곳)
- `Click here for more Lesson Plans and Activities`

이 문자열은 페이지 이동·추가 자료 링크 UI이므로 본문에서 제외했다. 섹션 제목·설명·학생 활동 문장은 남겼다.

문장이 직접 의존하는 대상이 빠진 원형:

- `photographed and drawn. This technique is useful in`
- `This system allows the archaeologist to create a precise map of the site and to record the exact location of all the features and artifacts on`
- `Phil Harding--of the popular British archaeology series “The Time Team”-- demonstrates the proper way to use a trowel to remove soil from a`

첫 번째 조각에서 `photographed and drawn.`은 완결 설명이므로 본문에 남기고 `This technique is useful in`만 분리했다. 두 번째에서는 완결된 위치 설명을 유지하고 소실된 뒤 목적어를 채우지 않도록 끝의 `on`만 제거해 문장을 마쳤다. 세 번째 앞의 `These short video clips show how to prepare a test unit for excavation.`은 완결 문장이어서 본문에 보존하고 대상이 빠진 Phil Harding 문장만 분리했다.
