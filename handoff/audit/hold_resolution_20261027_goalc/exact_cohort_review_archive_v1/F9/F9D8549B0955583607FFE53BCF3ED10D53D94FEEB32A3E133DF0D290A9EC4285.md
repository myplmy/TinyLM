## 보류한 원형 구간

### MySQL 단위

- 원형 설치 안내 줄에서 본문에 남긴 `If you don’t have it installed, you can get it using pip or conda` 뒤의 영상 연결부: `I have a video showing you how to install a module here: video link — skip ahead to the 7 minute mark where I explain how to install modules`. 외부 영상 CTA를 본문 설명으로 두지 않았다.
- 연결 코드 예고가 붙은 원문: `Now lets make a connection to our server: syntax should be self explanatory – localhost simply means its installed on my computer — otherwise you would provide a network path to the server there.` 코드 syntax를 가리키는 앞 절은 분리했고, 뒤의 실제 `localhost`/network path 설명은 본문에 보존했다.
- 코드 예고: `Below I am creating a table -> passing data to the table -> and committing the data`. 이 줄의 단계 설명은 해당 없는 예제 블록에 직접 붙어 있어 분리했다. 뒤의 명명된 `commit()` 효과 설명과 `executemany()` 설명은 보존했다.
- `Now let’s query our table.`은 실제 query 예제가 없이 남은 직접 예고이므로 분리했다. 같은 줄의 `.fetchall()` 동작 설명은 명명된 메서드·반환 관계가 문장에 있어 보존했다.
