# 1028579 보류 원형

후보/원문에 남아 있던 탐색 UI 두 곳을 본문 TXT에서 분리했다.

1. Bamiyan Buddha 보존·재건 설명 뒤, `Methods to preserve regional treasures` 소제목 앞: `Back to top`
2. 마지막 참고자료 목록 뒤: `Back to top`

두 문자열은 주변 문맥에서 페이지 상단으로 이동하는 탐색 표식이다. 본문 소제목, 문단, 인물·기관 이름, 인용, 수치, 조건, 참고자료 목록은 수정하지 않았다. Petra, Bamiyan, 보존 방법에 관한 각기 다른 내용 블록은 반복 본문이 아니므로 유지했다. 이 기록은 보류한 UI 문자열과 위치만 적으며, 본문 사실 검증을 뜻하지 않는다.
