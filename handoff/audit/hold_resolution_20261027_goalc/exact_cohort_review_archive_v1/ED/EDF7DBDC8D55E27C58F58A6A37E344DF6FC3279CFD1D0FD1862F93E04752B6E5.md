# 169285 원형 보류 기록

## 보류 원형

내용 없이 `의의` 앞에 있던 표제:

```text
관련 조항
```

참고 문헌의 실제 서지 항목 끝에 붙은 빈 포장:

```text
손동권, 『체계적 형법연습』, 율곡출판사, 2005. ()
```

## 처리 근거

빈 `관련 조항` 표제만 본문에서 분리했다. 실제 법리 설명과 판례 목록, 실재 참고 문헌은 보존했으며 서지 항목의 빈 괄호만 제거했다. 원문에서 채워지지 않은 조항이나 괄호값은 추정하지 않았다.

새 TXT에는 원본 후보에 없던 종단 LF가 추가되어 있다. 마지막 `형법` 행과 모든 본문 내용은 보존했고, 바이트를 잘라 원본의 비개행 종단을 흉내 내지 않았다. `각주` 뒤에 실제 `형법` 행이 남아 있어 해당 꼬리는 본문에 유지했다.
