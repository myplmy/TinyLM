## 경계 근거

초기화가 # 주석과 한 물리 줄에 합쳐져 있어 그 뒤 코드 대입을 실행 코드로 복구하지 않았다. 그 초기화에 직접 의존하는 pct/categories/shades/vals의 실행 예제와 직접 결과도 함께 보류했다. 각 예제의 호출·입력값은 아래 원형 그대로 보존하며 새 결과를 만들지 않았다.

## 직접 의존 코드 및 문장 원형

### 초기 데이터 줄

# Some data pct <- c(10, 20, 30, 40) shades <- c("white", "lightgray", "darkgray", "black") categories <- c("a", "b", "c", "d")

### pie 실행 및 직접 출력

pie(pct, labels = categories, col = shades)

As expected, here’s your pie chart in all its circular glory.

### donut 코드와 그 직접 연결 문구

Just slap a circle in the middle using

pie(pct, labels = categories, col = shades) symbols(0, 0, circles = 1, add=TRUE, bg="white")

The first line with
pie() is the same as the previous example.

### square-pie의 미완 안내와 직접 데이터 호출

Again, there’s no function from base R, but we can use the custom function from said tutorial for a

squarePie(pct, col = shades, main="")

### area graph의 초기화 의존 예제와 미완 대상

pct_over_time <- rbind(pct1=pct, pct2=2*pct) pct_df <- data.frame(pct_over_time)

Plug the data frame into
type to 1 or 2 for different baseline offsets.

For example, enter “pct_over_time” to see what the matrix looks like.

### treemap 입력값과 직접 실행

vals <- data.frame(pct=pct, cat=categories, col=shades)

treemap(vals, index="cat", vSize="pct", vColor="col", type="color")
