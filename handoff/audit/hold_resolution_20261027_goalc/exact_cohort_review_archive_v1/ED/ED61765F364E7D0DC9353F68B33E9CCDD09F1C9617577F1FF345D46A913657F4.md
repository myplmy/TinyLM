# expanded_train:73379 빈 별칭·각주 껍데기 정리

후보 본문은 원문에 있던 빈 별칭 괄호와 내용 없는 `각주` 표제를 대부분 제거했지만, `키비타스 포이데라타'''()`가 남아 있었다. 새 본문에서는 그 빈 `()`만 제거해 `키비타스 포이데라타'''`로 두었다. 실제 이탤릭 마크업과 명칭은 유지하며, 빈 별칭을 채우거나 어휘를 새로 추가하지 않는다.

원형 조각: `키비타스 포이데라타'''()`.

후보의 나머지 정리는 모두 그대로 유지했다. 실제 인물·작품·지명·정치/역사 서술, 날짜·수량·조건, 지역·축구팀 목록과 외부 링크의 채워진 제목은 유지된다. 내용 없는 `각주` 표제에는 복원할 각주 내용이 없으며, 외부 링크 표제 아래의 실제 링크 항목들은 남아 있다.

원문·후보·순서 패킷 0001–0017과 full_diff END를 대조했다. 입력 본문의 반복처럼 보이는 구간은 원문-후보 경계 뒤 후보 전문을 잇는 위치에 해당하므로 후보 내부 중복으로 보고 삭제하지 않았다.
