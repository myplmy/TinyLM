# 124827 — 원형 보류 범위

## 보존 본문

지정 후보의 나머지 서술을 유지했다. 서비스 기간, 지역 풍속 자료, 강풍 발생, overtopping 성능함수의 명명, AFOSM의 명칭과 적용, 바람 분포에 민감하다는 독립 문장을 보존했다. 성능함수의 식이나 `z`의 역할은 만들지 않았다.

## 원형 보류

- 방법 문장 안의 원형 조각: `the performance function , z, for theovertopping event`. 미상 표기와 `z`의 역할을 정할 수 없어 `, z,`만 보류하고, 명명된 관계는 `the performance function for the overtopping event`로 남겼다. `theovertopping`의 띄어쓰기만 문장 경계에 맞게 정리했다.
- 결과 문장 전체: `Firstly the results show that the risk for three different values ( ) are very variable.` 값 대상이 비어 있어 결과 범위를 보존했다.
- 끝 문장 전체: `As can be seen, in lesser ( ), more differences is obtained in the probabilities of each distribution.` 비교 조건이 비어 있어 그 조건·결론을 함께 보류했다.

`Secondly,`는 살아남은 문장을 독립 순서 항목으로 오인시키지 않도록 제거했다. 본문에 새로운 값, 함수식, 결과 또는 과학적 설명을 추가하지 않았다.
