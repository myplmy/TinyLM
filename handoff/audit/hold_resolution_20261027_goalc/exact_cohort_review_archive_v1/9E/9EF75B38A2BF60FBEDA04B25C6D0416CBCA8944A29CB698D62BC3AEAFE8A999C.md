# expanded_train:13187 원형 보류·정제 기록

빈 괄호 표기만 정리하고 실제 잰말 놀이·언어별 예문·외부 자료 이름·분류를 보존했다.

- 영어 절에서 발음하기 어려운 문장을 부르는 용어가 빈 `()`로 소실되어 해당 명명 절만 보류했다. 같은 문장에 있던 독립된 정보인 tongue-twister의 두운·각운 설명은 남겼다.
- 중국어 절의 `성조인 사성이 서로 달라 다른 뜻이 되는 "" 같은 문장`은 예시 문자열이 비어 있어 그 예시를 직접 가리키는 주장만 보류했다. 다음에 명시된 `繞口令` 명칭 설명과 실제 중국어 예문은 유지했다.
- 빈 괄호뿐인 일본어 예문 슬롯, 문장 뒤의 빈 괄호, 값 없는 독일어 섹션 제목, 고립 마침표, 대상 링크가 없는 `자세한 내용은 이곳 참조` 포인터는 분리했다. 빈 각주 표제는 후보가 이미 제거했다.
- `Barber/Bobber)`의 짝 없는 닫는 괄호만 제거했다. 대안 이름과 뒤에 오는 실제 잰말 놀이 문구는 보존했다.

한국어·영어·중국어의 채워진 반복 예문은 항목 순서와 문장 전체를 유지했다. 삭제한 인용·예문을 새로 만들지 않았고, 같은 문구가 반복된 실제 목록 항목도 임의 deduplicate하지 않았다.
