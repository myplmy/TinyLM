# expanded_train:629027 원형 보류

다음은 원문에서 사용자 정의 함수 구현에 직접 의존하는 구체 출력값이다. 함수 호출과 인수, 주석과 주변 설명은 새 본문에 보존했다. 납작해져 구현 경계가 확인되지 않는 예제의 실행 결과를 독립적으로 확정하지 않고 원형 그대로 분리한다. 값이나 함수 코드를 보충하지 않았다.

| 호출 문맥 | 보류한 원문 출력 |
|---|---|
| `y = taxDemo(80e3) % What is the tax on $80k income?` | `y = 2.0720e+04` |
| `y = f(2)` | `y = 26` |
| `y = g(2)` | `y = 35` |
| `counter1Value = counter1()` | `counter1Value = 1` |
| `counter1Value = counter1()` | `counter1Value = 2` |
| `counter2Value = counter2()` | `counter2Value = 11` |

완결된 함수 호출, 전달 인수, 일반 설명 및 그림 호출은 본문에 남겼다. MATLAB 구현이 한 줄로 평탄화되어 함수/주석 경계가 확인되지 않는 상태이므로 출력값만 제거했다. 이 판정은 코드를 실행하거나 구현의 동작을 검증했다는 뜻이 아니다.
