# 474572 원형 보존 메모

## 분리한 반복 페이지 UI

후보에서 다음 동일 단독 페이지 링크 여섯 건을 제거했다.

```text
Back to top
Back to top
Back to top
Back to top
Back to top
Back to top
```

발생 위치는 음수 섭취 효과, 하루 섭취량, 학교 물 제공 상황, 학생이 충분히 마시지 못하는 이유, 학교의 섭취 개선 질문 뒤, 섬유질 식이 설명 뒤다. 물 섭취량·2004년 지침·조건, 식수 시설 관련 설명, 섬유질 종류·식품·주의 조건은 유지했다. 끝의 `Back to the main...`, `Back to the adults' homepage`, `Find out what I can do`는 별도 이동/행동 링크로 남겼다.

## 판독 범위

지정 original/candidate 전문과 순서 패킷 0001–0003을 BEGIN부터 END/EOF까지 대조했다. 후보 전체 diff는 줄 차이가 없었다. 새 본문에서 위 반복 링크 여섯 줄만 제거했다.
