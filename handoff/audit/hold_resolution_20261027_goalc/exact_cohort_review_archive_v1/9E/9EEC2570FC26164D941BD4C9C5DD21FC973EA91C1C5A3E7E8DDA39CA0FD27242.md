# 1237937 보류 원형

- `addObserver(Observer o), and removed through` — 등록 API는 명시되어 있으나 삭제 API 명칭이 빠져 있다. `addObserver(Observer o)`와 관찰자 추가 설명을 유지하고 `, and removed through`만 보류했다. 제거 메서드 이름은 생성하지 않았다.
- `Object arg to potentially carry some extra information (passed through` — EOF에서 인용 괄호 설명이 끝나기 전에 잘렸다. 완결된 `Object arg`가 추가 정보를 전달할 수 있다는 본문은 보존하고, 이 미완 꼬리만 보류했다.

`Observable`/`Observer` 역할, 실제 `addObserver(Observer o)`, `setChanged()`, `notifyObservers()`, `update(Observable o, Object arg)` 명칭·빈 괄호·인자, 그 동작 설명은 모두 보존했다.
