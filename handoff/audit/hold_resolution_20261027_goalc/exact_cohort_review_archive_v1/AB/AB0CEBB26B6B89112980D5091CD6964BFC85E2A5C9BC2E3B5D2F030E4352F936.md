# 678088 원형 보류

원문 8행의 다음 두 문장은 질문 코드의 `data[i]` 대입과 질문에 나온 `obj`가 어떤 대상을 가리키는지 관계가 명확하지 않은 상태에서 해당 대상을 스택 변수/특정 포인터형으로 단정한다. 이 직접 결론만 본문에서 분리한다.

> The 'obj' is a variable in stack. Its type is "a pointer to object of type X".

질문에 제시된 부분 코드와 오류 맥락, 그 뒤의 포인터 크기·메모리 주소·정수 저장에 관한 일반 설명은 별도 완결 서술로 보존한다. `i` 또는 `data`의 선언이나 새 변수 관계는 만들지 않는다.
