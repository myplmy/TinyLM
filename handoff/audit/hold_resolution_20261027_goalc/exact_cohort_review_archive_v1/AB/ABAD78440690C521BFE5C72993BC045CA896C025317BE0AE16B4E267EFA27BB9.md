## 불완결 JSON 요청 코드

본문에 보이는 실제 코드 조각은 다음과 같다.

```text
params = dict(
resp = requests.get(url=url, params=params)
data = json.loads(resp.text)
```

`dict(`의 실제 인자/닫힘이 없고, 뒤의 요청은 그 미정 `params`에 직접 의존하며 JSON 파싱은 그 요청 결과에 의존한다. 위 세 줄만 원형 보류했다. shebang, `import json, requests`, 실제 `https://dns.google.com/resolve` URL과 이 코드 앞뒤의 완결 DNS-over-JSON 정성 설명은 유지했다. 파라미터 키/값·요청 결과를 새로 채우거나 코드를 실행하지 않았다.
