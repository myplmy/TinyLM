# 1164045 원형 보류

- 원문: `expanded_train_1164045_original.txt`
- 검토 본문: `reviewed_1164045_v1.txt`
- 범위: 비정렬 접근 예제의 도입문과 C 예제 전체를 보류했다. `#if defined()`의 조건식이 비어 있고, 그 조건이 x86/x86_64 어셈블리 정렬 검사의 활성화 범위를 제어한다. 이 전처리 조건만 지우면 실행 조건이 바뀌므로 예제를 완결 코드처럼 남기지 않았다. 매크로·값·대체 조건은 보충하지 않았다.

## 원문 도입문 및 C 예제 전문

> 예시 
> AT&T 어셈블리 문법의 C 프로그래밍 언어로 작성된, 비정렬 메모리 접근의 한 예이다.

~~~c
#include <stdlib.h>

int main(int argc, char **argv) 
{
    int *iptr;
    char *cptr;
    
#if defined()
# if defined(__i386__)
    /* Enable Alignment Checking on x86 */
    __asm__("pushf\norl $0x40000,(%esp)\npopf");
# elif defined(__x86_64__) 
     /* Enable Alignment Checking on x86_64 */
    __asm__("pushf\norl $0x40000,(%rsp)\npopf");
# endif
#endif

    /* malloc() always provides memory which is aligned for all fundamental types */
    cptr = malloc(sizeof(int) + 1);
    
    /* Increment the pointer by one, making it misaligned */
    iptr = (int *) ++cptr;

    /* Dereference it as an int pointer, causing an unaligned access */
    *iptr = 42;

    /*
       Following accesses will also result in sigbus error.
       short *sptr;
       int    i;

       sptr = (short *)&i;
       // For all odd value increments, it will result in sigbus.
       sptr = (short *)(((char *)sptr) + 1);
       *sptr = 100;
    
    */

    return 0;
}
~~~

본문에는 버스 오류·`SIGBUS`의 완결된 설명 두 문단과 실제 분류명 `메모리 관리`, `컴퓨터 오류`, `컴퓨터 버스`만 유지했다. 코드를 실행하거나 정렬 검사 조건을 추정하지 않았다.
