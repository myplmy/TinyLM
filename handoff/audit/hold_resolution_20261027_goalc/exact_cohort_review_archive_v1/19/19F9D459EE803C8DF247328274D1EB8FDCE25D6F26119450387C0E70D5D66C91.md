# 1174083 보류 원형

- 빈 코드 블록을 가리키는 프롬프트/예고와 해당 스크립트만을 대상으로 하는 설명을 분리했다. 대상은 `...this equates to:`, PHP의 한 줄-한 단계 코드 매핑 설명, `Capturing the return value from curl_exec() looks like this in code:`, 저장 파일 코드 도입, HTTP→FTP 예제 도입·비교, 두 FTP 옵션을 적용한 코드 예고, 사용자명/암호 변경 실행 결과 및 누락된 최종 FTP 코드 평가, `posttest.php` 파일 코드·신규 스크립트 도입, 빠진 POST 코드의 `localhost` 치환 안내와 누락 응답 예고/평가다.
- `This is because Curl fails silently...`는 앞서 보류한 실행 결과에 매달린 문장이므로 원형을 분리했다. 다음의 실제 `curl_error()` 한 인자·오류메시지 반환 설명은 이름을 명시해 본문에 보존했다.
- 완결된 함수/옵션 설명과 값은 보존했다: `curl_init`, `curl_setopt`, `curl_exec`, `curl_close`, `CURLOPT_URL`, `CURLOPT_RETURNTRANSFER`, `CURLOPT_FILE`, `fopen`, `CURLOPT_FTPLISTONLY`, `CURLOPT_USERPWD`, `curl_error`, `CURLOPT_POST`, `CURLOPT_POSTFIELDS`, `urlencode`, 그리고 변수명/값 `Hello`, `Foo`, `Baz`, `World`, `Bar`, `Wombat`. 실제 없는 코드나 출력은 추가하지 않았다.
