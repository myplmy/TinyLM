# expanded_train:488712 원형 보류

- 도입부의 `I have provided the brief and to the point answer of each question which will help you get selected in the the technical interview round.`는 아래에 답이 없는 질문(Q23, Q31, Q32)이 있어, 모든 질문에 답했다는 범위 주장을 그대로 둘 수 없어 원형 보류했다. `Here are the frequently asked questions on Servlets.`는 유지했다.
- Q3의 `3) Initialization: Servlet initialization by calling` 및 `4) Servicing the request: In this phase the servlet service the client request by calling the`는 호출 대상이 비어 있어 각 단계 문장만 보류했다. 실제 1), 2), 5) 단계와 `destroy()`는 유지했으며 init/service 메서드명을 만들지 않았다.
- Q10의 `Following are the two main differences between`은 뒤에 실제 차이 세 항목이 있고 비교 대상 문구도 비어 있으므로, 이 잘린 개수·대상 예고만 보류했다. 질문과 실제 1)–3) 차이 설명은 유지했다.
- 답이 비어 있는 `Q 23. How to invalidate a session in servlet?`, `Q 31. How do I get the server info in Servlets?`, `Q 32. How to get the client’s IP address in Servlets?`는 질문 단위로 원형 보류했다. 답이나 API/코드를 추정하지 않았다.
- Q25에서 실제 `<session-timeout>35</session-timeout>` 예시는 35로 되어 있지만 바로 뒤 문장은 `It would set the session timeout to 25 minutes.`라고 한다. 어느 값이 맞는지 고르지 않고 `This is how it is defined in the web.xml file.`, 예시 전체 `<session-config> <session-timeout>35</session-timeout> </session-config>`, 그리고 25분 결과 문장을 함께 보류했다. 요소가 session timeout을 지정한다는 독립 설명은 유지했다.
- Q11의 원문 `HTTPSeervlet`은 같은 질문 제목과 인접 문장에 있는 실제 클래스 표기 `HTTPServlet`에 맞춰 본문에서 오타만 바로잡았다.

Q20의 실제 1) URL rewriting, 2) Hidden Form Fields, 4) Secure Socket Layer(SSL) Sessions는 원문 순서와 번호를 그대로 본문에 남겼다. 빠진 3) 항목의 내용은 생성하지 않았다. `forward()`, `sendRedirect()`, `doGet()`, `doPost()`, `init()`, `destroy()` 및 XML 코드의 실제 표기·조건은 임의로 고치거나 실행하지 않았다. v1 초안은 Q25의 정의/예고 경계를 정확히 나누지 못했으므로 보존하고 v2를 선택한다.
