# 772762 잘린 설명 조각 원형 보류

본문에서 두 문장만 보류했다. 각각 실제 API 설명의 앞선 완결 사실과 함께 붙어 있었지만, 뒤의 목적어나 이어지는 비교가 빠져 있어 빈 부분을 보충하지 않았다.

1. nis_sperror_r() 반환 버퍼 설명 뒤의 잘린 구절:
   "length specifies the number of characters to copy from the error string to"

2. nis_sperror() 버퍼 설명 뒤의 잘린 구절:
   "nis_sperror_r() is the preferred interface, since it is suitable for single-threaded and"

앞서 완결된 nis_sperror_r(), nis_perror(), nis_lerror() 설명과 nis_sperror()의 반환 버퍼 설명은 새 전체 TXT에 보존했다. 뒤의 완결된 _REENTRANT 안내도 유지했다. 누락된 인수·대상·비교는 추정하지 않았다.
