# 295086 원형 보류 기록

원문에서 남아 있던 두 빈 괄호 자리는 다음과 같다.

- 선전 문구 인용 뒤 "가면라이더, 지구의 중심 핵(Core)로." ()이다.에서 빈 병기 포장을 제거하고 실제 문구 인용을 보존했다.
- 마지막편의 제목은 〈MOVIE 대전 CORE〉 ()로에서 빈 제목 병기를 제거하고 실제 제목과 목적 관계를 유지했다.

후보가 이미 정리한 빈 괄호도 그대로 두었다. 영화 제목 CORE(), 밴드 다이키치(), 각본 편 제목, 메모리 메모리(), 도펀트·인물·메달 명칭에 붙은 빈 괄호, 가면라이더 코어(), 산타짱/배우 이름/노래 이름의 빈 괄호가 이에 해당한다. 빈 각주 표제에는 내용이 없어 분리했다. 명명된 인물·작품·배역·수치·날짜·제작 관계와 실제 서술은 유지했고, 빠진 괄호 값은 만들지 않았다.

지정 원문·후보와 전체 diff 및 END를 읽었다. 새 본문 전체 diff와 끝을 확인했다. 후보의 수정 자체를 내용 적합성 근거로 삼지 않았다.
