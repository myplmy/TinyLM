# 48362 결손 수식·출처 포인터 원형 보류 초안

후보는 동일성 증명 계획에서 원문과 byte-identical임이 이미 제시되어 있었고, 원문 프레임 1–15와 최종 diff 프레임 30을 순서대로 실제 읽었다. 전체 diff는 차이가 없다고 끝난다.

## 보류 범위

- 원문 6행의 After baseline data collection (see details in ) 중 대상이 빠진 빈 링크/참조 괄호는 본문에서 분리했다. 문장의 baseline collection 이후 제어 시작 시점과 연구 결과는 유지했다.
- 원문 34행에서 Barclay & Hargrove 모델의 평가 대상을 소개하는 완결 문장은 유지했다. 이어지는 In this model, the probability ... is given by:는 식이 없는 도입이므로 분리했다. 바로 뒤 where S ... t ... σ ... λ ... 변수 설명도 빠진 식의 직접 설명이라 함께 분리했다. 그 모델을 이용한 저자 보고의 표본 수, 0.01 효율, 조건 및 후속 확률 결과는 유지했다. 변수나 식은 만들지 않았다.
- 원문 35행의 according to estimates obtained for G. palpalis gambiensis by .는 대상 저자/출처가 빠진 귀속 꼬리라 분리했다. 같은 문장 앞의 저자 보고 효율 정의와 0.01 값은 유지했다.
- 원문 33행의 as described by ,와 (, or see also )는 비어 있는 인용 대상 포인터만 분리했다. 점착 플라스틱 대상과 전기 그리드 대상의 실제 설명, might의 불확실성 및 monitoring 용도는 유지했다.

수정안에서는 본문에 있는 독립 결과/조건/수치와 텍스트 캡션을 우선 보존했다. 그림 파일의 실물 유무에 대한 별도 선택은 총괄 중재를 기다린다. 원문 사실을 외부 검증했다고 주장하지 않으며 어떠한 코드도 실행하지 않았다.
