# 484655 페이지 탐색 UI 보류

원문은 맨 앞에 `<<Back to Sinus Care Main`을 두고, 세 번 `Back to Top`을 둔다. 후보는 다음 위치의 페이지 탐색 UI만 분리한다.

1. Image Guided Sinus Surgery 설명 뒤, `Septoplasty is surgery...` 앞.
2. Septoplasty 설명 뒤, `Endoscopic Sinus Surgery` 앞.
3. Endoscopic Sinus Surgery 설명의 원문 EOF.

이 네 개의 UI 문자열은 실제 수술 설명과 분리해 여기 보존한다. 본문 문장과 절차·조건은 후보에 남아 있다.
