# 162180 빈 병기·표제 기록

지정 원문·candidate 전문과 연속 패킷 0001–0002의 논리 END/EOF 및 original→candidate 전체 diff를 판독했다. 원문과 candidate는 내용상 동일하며 candidate가 내용 없는 `각주` 표제를 이미 제거했다.

빈 외국어 병기 포장 세 곳을 정리하고, 실제 인물·기관 이름과 설립/개명 연혁 및 날짜는 그대로 유지했다. 내용이 없는 `학교 동문` 표제만 본문에서 분리했다. 그 외 공립대학·IDEA 리그·분야별 순위 등 원문에 적힌 설명과 조건, 실제 외부 링크 두 항목은 그대로 두었고 외부 사실을 새로 검증하거나 추가하지 않았다.

```text
원문: 델프트 공과대학교(, )
선택: 델프트 공과대학교

원문: '델프트 종합공과대학'(, )
선택: '델프트 종합공과대학'

원문: '델프트 공과대학'(, )
선택: '델프트 공과대학'

원문 표제: 학교 동문
뒤에 동문 항목 없음

원문 표제: 각주
뒤에 각주 항목 없음; candidate에서 이미 제거됨
```

후속 제목 `외부 링크`에는 실제 `공식 홈페이지` 항목 두 줄이 있어 두 항목 모두 유지했다.
