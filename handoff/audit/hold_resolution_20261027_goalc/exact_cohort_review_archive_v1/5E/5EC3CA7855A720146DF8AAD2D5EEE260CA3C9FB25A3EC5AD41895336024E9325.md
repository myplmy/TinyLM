# 1392312 원형 보류 조각

입력: 지정된 `expanded_train:1392312` original/candidate. candidate는 고정 identity 계획의 바이트 동일 연결이다.

| 원문 위치 | 원형 조각 | 보류 근거 |
|---|---|---|
| R 패키지 설치 뒤 | `To use the addon, you first need to load it:` | 로드해야 한다는 도입만 있고 명령/인수 값이 없다. 바로 앞 완결 설치 결과 문장과 뒤의 RStudio 안내는 유지했다. |
| 도움말 예시 1 | `If you are in R and have loaded the rgrass7 package, you can get the help page of rgrass7 by typing:` | `typing:` 뒤 실제 명령이 없다. |
| 도움말 예시 2 | `Similarly, to get help for a specific function, e.g., for the function readRAST(), you type:` | `you type:` 뒤 실제 명령이 없다. readRAST()의 실제 이름/괄호는 주변 설명에서 보존했다. |
| 도움말 예시 3 | `You can also start the R help page in your browser:` | browser 도움말 대상/주소가 뒤따르지 않는다. |

완결한 rgrass7 설치 명령, 실행 방식 설명, 책·논문·지원 링크와 Cygwin 명령은 유지했고 명령 예시를 추정하지 않았다.
