## 분리한 원형

- `Only match files that are contents. A file is a content if it implements the` — `.Page interface`처럼 실제로 구현하는 대상이 빠진 문장 꼬리다. 앞의 완결된 “Only match files that are contents.”는 본문에 남겼다.
- `If the file in context has a file type pointing to an app in an installed package, the last example return the root file of the package filesystem. Let’s break it down:` — 앞선 미상 예제를 직접 가리키는 도입이다. 미상 예시 포인터를 제거하고 조건과 root file 결과만 본문에서 일반 문장으로 보존했다. 파일형식/경로 이름은 새로 만들지 않았다.
- `root() will return the root file of that package, for example` — 완결된 root() 관계 뒤의 예시 내용이 없다. 관계는 남기고 빈 예시 예고만 분리했다.
- `Thus,` / `parent()/.. is not equivalent to` — 비교의 두 번째 값이 없어 불완전하다. 바로 앞에서 명시된 `..` 및 `parent()` 작동 설명과 뒤에 실제로 채워진 `foo/parent()/..` 및 `foo/../parent()` 관계는 본문에 그대로 유지했다.

Selector 이름이 빠진 일반 설명들은 그 자체로 채워진 문장/동작 설명이며, 별도 selector 명칭을 추정하지 않고 원래 표현으로 보존했다. `*`, `first()`, `typeChain()`, `last()`, `root()`, `/`, `..`, `parent()` 등 실제 원문에 있는 문자열과 `.Page`, `:1`, `main:`도 그대로 두었다. 어떤 selector/API 이름도 새로 귀속하지 않았다.
