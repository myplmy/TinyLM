# 28960 빈 필드 정리 근거

## 원형 조각

```text
《꼬꼬마 텔레토비》()는 1997년 3월 31일부터 방송 중인 BBC에서 만든 어린이용 TV 시리즈다.
방송 일시
```

## 판정

- 작품명 뒤의 빈 괄호만 제거하고 실제 제목, 방송 기간, 방송사, 설명은 보존했다.
- 내용이 없는 `방송 일시` 표제만 분리했다.
- 후보가 이미 비어 있는 `참조` 표제를 제거한 점을 확인했다. 실제 참고·분류 내용은 유지했다.
- `외부 링크` 아래에는 실제 `텔레토비 사이트` 이름이 있어 보존했다. URL이나 새 링크 대상은 만들지 않았다.
