## 빠진 예시·목록 표적
- `Here is a string of six exotic Unicode characters.` — 실제 문자열은 지정 본문에 없다.
- `This string is designed to look like the word "Python", but doesn't use any ASCII characters at all.` — 지시하는 실제 문자열이 없다.
- `Here we show our exotic string as UTF-8.` — UTF-8 표본을 가리키는 직접 예고만 분리했다. 다음의 H/i 바이트 설명과 가변 길이·4바이트 일반 설명은 본문에 유지했다.
- `but we aren't using any of those here` — 구체 문자열에 직접 의존하는 한정만 분리했다.
