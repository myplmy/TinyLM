# 902361 보류 원형

다음 붙어 있는 코드 줄은 행·토큰 경계가 합쳐져 있어 원형 그대로 본문에서 분리했다. 추출 손상인지 원저자가 작성한 비정상 예시인지 결정하지 않았다.

`#!/usr/bin/env pythonimport Tkinterimport tkMessageBoxtop = Tkinter.Tk()def hello():tkMessageBox.showinfo("Say Hello", "Hello World")B1 = Tkinter.Button(top, text = "Say Hello", command = hello)B1.pack()`

뒤 산문 끝에 붙은 `top.mainloop()`도 코드 경계가 본문과 합쳐져 있어 분리했다. 그 앞의 로봇이 천천히 원을 그리며 움직였다는 회고는 pre-configured tethered-driving script를 가리키는 완결 산문이므로 본문에 그대로 유지했다. 코드를 새 줄로 나누거나 고치지 않았다.
