# 747023 원형 보류

후보는 원문과 같다. 실행문 본문은 주석과 `for` 제어 구조가 평탄화되어 실제 문장 경계·들여쓰기를 확정하기 어렵다. 해당 executable code 전문은 검수자료로만 원형 보존하며 실행하거나 복원하지 않았다. 코드의 닫힌 triple-quoted documentation block은 본문에 그대로 남겨 파일명, 목적, 사용법, 예시 출력, 설정 설명, 포트 안내, URL, 작성자·날짜를 보존했다.

- 다음 두 문장은 그 문장 바로 뒤의 빠진 코드에 직접 의존하므로 원형 보류한다: `Below is Python code to send an appropriately formatted string representing the date and time over the serial port (USB) to an Arduino board. I use this for a temperature monitor.`
- `zipTimer: an iPod/iPhone app for pacing piano practice, cooking, workouts, you name it.`은 원문에 독립된 단독행으로 있으나 이 Arduino 글/코드와의 관계를 확인할 수 없어 sidecar에 원형 보존한다. 새 귀속을 붙이지 않는다.
- executable code 원문: `import os, subprocess # Settings time_zone_offset = -5 port = "/dev/tty.usbmodemfa131" # Put stdout into pipe proc = subprocess.Popen("date +%s", shell=True, stdout=subprocess.PIPE) return_code = proc.wait() # Read from pipe for line in proc.stdout: time = int(line.rstrip()) # Output to terminal and port print os.system("date") time += 60*60*time_zone_offset print "Time:", time cmd = "echo T" + str(time) + " > " + port print "Cmd:", cmd print os.system(cmd)`

코드 안의 설정값·명령·출력 문구를 수정하거나 실행하지 않았다.
