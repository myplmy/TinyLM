# 672189 원형 보류

## 빈 괄호 포장

원문에 있는 완결된 장소/방향 및 통과 설명의 빈 괄호:

```text
산둥성 산둥반도 () 바로 동쪽을 지나감
저장성 저우산 군도 () 바로 동쪽을 지나감
마누이섬 () 바로 서쪽을 지나감
술라웨시섬  () 바로 동쪽을 지나감
```

실제 지명과 방향은 본문에 유지하고 빈 괄호 포장만 보류 근거로 보존한다. 괄호에 없던 좌표나 다른 값을 채우지 않는다.

## 미상 영유권 주장 주체

원문 남극 행:

```text
오스트레일리아령 남극 지역, 가 영유권을 주장한다.
```

지역명은 본문에 유지하고 누락된 행위자가 필요한 관계절은 여기 원형대로 보류한다.
