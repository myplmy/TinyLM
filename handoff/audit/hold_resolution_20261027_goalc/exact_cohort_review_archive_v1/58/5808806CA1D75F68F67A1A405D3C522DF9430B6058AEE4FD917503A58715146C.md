# expanded_train:1292161 보류/정리 근거

후보는 원문과 바이트 동일이다. 본문에는 없는 URL·표·그림·코드의 값을 추정하지 않았다. 아래 지정 원문 조각은 원형 그대로 보관한다.

## 빠진 대상 또는 직접 의존 조각

- RFC 주소 도입의 잘린 뒷부분:
  - `If you want to`
  - `read them yourself, and you probably should if you're going to do a lot of work with`
  - `MIME, the RFCs are available on the web at`
- 표만 가리키는 캡션/참조:
  - `Table 1: Sending with Mail::Mailer`
  - `There's a full list of types in Table 2.`
  - `Each of those typescan have list of different sub-types.`
  - `Table 3 lists the most common type/subtype combinations.`
- 형식이 소실된 MIME 헤더/본문 예:
  - `Content-type: text/plain Content-transfer-encoding: 7bit This is just a plain old piece of text`
- 없는 그림에 직접 의존하는 문장:
  - `Figure 1 shows a symbolic representation of a one-part MIME message.`
  - `Figure 2 shows a sample multipart/mixed MIME message.`
  - `Figure 3 shows what you might get if you pasted a very simple HTML document into a MIME-aware mail client.`
- 원문에서 주석/문장 경계와 줄 구성이 소실된 Perl 코드 예시:

```text
# Build the message $message = MIME::Lite->new( From => 'firstname.lastname@example.org', To => 'email@example.com', Subject => "A test", Type => "text/plain", Encoding => '7bit', Data => "Just a test message"); # Tell MIME::Lite to use Net::SMTP instead of sendmail MIME::Lite->send('smtp', 'localhost', Timeout => 20); # Send the message $message->send;
```

```text
# Build the message $message = MIME::Lite->new( From => 'firstname.lastname@example.org', To => 'email@example.com', Subject => "The Net::SMTP docs" Type => "text/plain", Encoding => '7bit', Filename => 'Net_SMTP.txt' Path => 'perldoc Net::SMTP |'); # Tell MIME::Lite to use Net::SMTP instead of sendmail MIME::Lite->send('smtp', 'localhost', Timeout => 20); # Send the message $message->send;
```

```text
# Build the message $message = MIME::Lite->new( From => 'firstname.lastname@example.org', To => 'email@example.com', Subject => "Technote PDF Autoresponder", Type => "text/plain", Encoding => '7bit', Data => "This is the technote you requested"); # Add the attachment $message->attach( Type => "application/pdf", Encoding => "base64", Path => $technote_requested, Filename => "Technote.pdf"); # Tell MIME::Lite to use Net::SMTP instead of sendmail MIME::Lite->send('smtp', 'localhost', Timeout => 20); # Send the message $message->send;
```

```text
# Build the message $message = MIME::Lite->new( From => 'firstname.lastname@example.org', To => 'email@example.com;, Subject => "A test", Type => "text/plain", Encoding => '7bit', Data => "Just a test message"); $message_text = $message->as_string;
```

- 누락 코드의 직접 도입/참조:
  - `In that last example, the message we were sending was specified explicitly with Data. If you'd like to get fancier, you can try something like this:`
  - `For example, take this chunk of code from a mythical tech support autoresponder:`
  - `, like so:` (as_string 예시의 도입부)
  - `Finally, let's take a look at a full program that sends MIME mail. The program in Listing 1 is mail_attach.pl, a variation of which I've got in production on my VMS cluster. We use it for email delivery of some daily reports, but it can be easily modified to do most anything else you like.`

## 본문에 남긴 완결 정보와 최소 문장 정리

완결 MIME 설명, 명시된 메서드/API와 옵션 이름, 단위·조건, 서술상 프로그램 동작/설명, 저자 귀속은 보존했다. 본문에서 RFC 도입부의 끝에 붙은 쉼표는 문장 마침표로 정리했고, Data/Path/attachment/as_string 문장은 빠진 예제에 대한 지시어만 없애 완결된 설명으로 다듬었다. `The full list can be found at ftp://ftp.isi.edu/in-notes-iana/assignments/media-types/media-types.`라는 실제 URL 서술은 본문에 보존했다. 누락된 Listing 1의 설명 문단은 실제 값/알고리즘을 새로 만들지 않는 완결 서술로 보존했다.
