# 666693 — 원형 보류 v1

원문 24행의 빈 정보 안내만 분리했다. 바로 앞에는 perldoc 안내가 있고, 다음에는 실제 감사·저자·라이선스 정보가 있으나 이 안내 뒤에 목표·자료명·URL이 없다. 링크 대상을 추정하지 않는다.

그 외 synopsis의 실제 Config::Hosts 호출 및 메서드 설명에 대한 표제는 원문 내부 토큰 순서만으로 추정하지 않았다. 허용된 root 증거가 발행자 POD의 정확 매핑을 확인했으므로 실제 제목을 각 설명 앞에 복원하고, synopsis 주석 뒤 호출 경계는 해당 증거가 확인한 위치에서만 줄바꿈했다. 코드 토큰·호출 인수·반환 조건·저자·감사·2011 저작권·라이선스는 보존했다. API를 실행하거나 동작을 별도로 검증하지 않았다.
