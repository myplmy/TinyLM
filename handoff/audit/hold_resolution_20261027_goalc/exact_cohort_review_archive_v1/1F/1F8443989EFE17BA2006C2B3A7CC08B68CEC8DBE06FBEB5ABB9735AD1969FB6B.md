# 411315 원형 보류 구간

이 VBA/SolidWorks 튜토리얼에서 실제 이름·명령·절차·코드가 채워진 내용은 본문에 유지하고, 없는 그림이나 값 없는 직접 의존 구간만 분리했다.

- 원형: `In our previous image we have SOLIDWORKS Objects.` — 그림을 가리키는 표현은 분리했지만, 실제 노드 이름 `SOLIDWORKS Objects`와 application 항목으로 확장되는 관계는 본문에 보존했다.
- 원형: `If the project has any VBA module, the project listing also shows a` — 필수 표시 대상이 빠진 중단 문장.
- 원형: `Saving an individual object in a project is known as` — 정의 용어가 빠진 문장.
- 원형: `As you become proficient with VBA, you spend a lot of time with working in the` — 목적어가 빠진 문장.
- 원형: `Below figure shows an example of this.` 및 `as shown in below figure` — 입력에 실제 그림이 없어서 그림 직접 참조만 분리했다.
- 원형: `VBA module can store any number of Function procedure and` — 목록 연결이 끊긴 문장 조각.
- 원형: `Insert code directly into code window.` — 목적지가 빠진 세 가지 방법 목록의 항목. 뒤의 완결된 `Entering code directly into a module` 절차는 유지했다.
- 원형: `Type the following code into` — 대상이 빠진 지시 조각. 뒤의 완결된 `Sub GuessName()` 코드는 그대로 유지했다.
- 원형: `If you followed the previous steps, you just wrote a VBA Sub procedure, also known as a` — 정의/대상이 빠진 문장 끝.
- 원형: `Another way you can get code into a VBA module is by recording your actions, using the in-built` — 빠진 명칭에 의존하는 도입 조각. 뒤의 macro recorder에 관해 명시된 실제 설명은 보존했다.
- 원형: `Instead of wasting time in re-entering the code, you can activate the module and use the normal Clipboard` — 목적어/행동이 빠진 클립보드 문장 조각. 뒤의 실제 paste, `Ctrl+C`, `Ctrl+V` 절차는 유지했다.

`F5to`는 원문에서 `F5`와 `to`가 붙은 명백한 단어 경계이므로 새 본문에서 공백만 복구했다. 샘플 문장과 코드의 이름·옵션·인수·값은 변경하지 않았다.
