# 40716 원형 HOLD 근거

## 없는 이미지 참조 표현

원문에서 분리한 참조 표현: `If you take another look at the screenshot above, you’ll see that`; `So you can see from the script list that`; `So in the figure, you can see that`.

해당 스크린샷/목록을 직접 가리키는 도입구만 본문에서 뺐다. 그 뒤에 채워진 서술은 본문에 유지했다. 여기에는 스크립트 이름 차이, Developer Setup·Open Routine·Record Logged In User ID 사이의 호출 관계, `Set Window( [PrintFlag] )`와 `Set Next Serial Value( WhichTable, NextSerialValue )`의 실제 인자·선택성 설명이 포함된다. 호출명, 인자명, 관계, 조건은 추가하거나 바꾸지 않았다.

## 페이지 UI
