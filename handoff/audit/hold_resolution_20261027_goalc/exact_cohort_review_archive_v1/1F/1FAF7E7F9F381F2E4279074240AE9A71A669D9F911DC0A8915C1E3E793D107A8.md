# expanded_train:74 원형 보류

## 판독 근거

원문과 지정 후보 전체, 두 순서 패킷, 전체 diff를 읽었다. 후보는 원문에서 비어 있던 `각주` 표제만 이미 제거했고, 아래의 기호·변수·식 결손은 남아 있다. 아래 인용은 지정 후보에 남은 해당 문구를 그대로 옮겼다. `(공란)` 표기는 원문에 없는 설명용 표시다.

## 빈 병기 슬롯

```text
수론에서 곱셈적 함수(-的函數, ) 또는 곱산술 함수(-算術函數)는
```

기존에 채워진 한자 표기는 본문에 남겼다. 비어 있는 대체 표기만 삭제했고, 누락된 한자나 별칭은 생성하지 않았다.

## 본문에서 분리한 원형

### 정의와 정의역 조건

```text
정의 
함수 가 다음 조건을 만족시키면, 곱셈적 함수라고 한다.
 임의의 에 대하여, 만약 이라면, 이다.

함수 가 다음 조건을 만족시키면, 완전 곱셈적 함수(完全-的函數, )라고 한다.
 임의의 에 대하여, 이다.

(완전) 곱셈적 함수의 정의역은 의 곱셈에 대하여 닫혀있는 부분 집합일 수도 있다.
```

두 정의에는 함수 기호·조건식·변수가 빠져 있고, 정의역 문장도 집합 대상이 없다. 조건을 외부 지식으로 채우지 않는다.

### 연산에 대한 닫힘

```text
연산에 대한 닫힘 
곱셈적 함수 에 대하여, 다음과 같은 함수들 역시 곱셈적 함수이다.
```

뒤따를 함수 목록이 없으므로 목록 예고와 제목을 함께 분리한다.

### 식과 빠진 함수 기호에 직접 의존하는 항등식

```text
곱셈적 함수 에 대하여, 만약 의 소인수 분해가

일 경우, 다음이 성립한다.

만약 추가로 가 완전 곱셈적 함수일 경우, 다음이 성립한다.

곱셈적 함수 에 대하여, 다음과 같은 항등식이 성립한다.

여기서 는 뫼비우스 함수이다.

곱셈적 함수 의 정의역 이 를 만족한다면,

이다.
```

소인수분해·함수·정의역·조건·항등식 기호가 빠져 있다. 바로 뒤 식을 추정하거나 채우지 않는다. 본문에 남긴 소수 거듭제곱 값으로 결정된다는 자연어 문장은 이 결손식 없이도 독립적으로 읽힌다.

### 디리클레 합성곱의 식 의존 부분

```text
즉, 곱셈적 함수 의 디리클레 합성곱

와 디리클레 역원

은 곱셈적 함수이다.

곱셈적 함수 에 대하여, 만약 의 소인수 분해가

일 경우, 다음이 성립한다.

만약 추가로 가 완전 곱셈적 함수일 경우, 다음이 성립한다.
```

함수 이름·합성곱 입력·역원·이어지는 식이 빠져 있어 해당 예고 및 식 의존 결론을 분리한다. 독립적으로 완결된 “곱셈적 함수는 디리클레 합성곱에 대하여 아벨 군을 이룬다”는 본문에 남겼다.

### 예시 목록의 끊긴 정의 조각

```text
  (는 음이 아닌 정수): 거듭제곱 함수
 : 1을 값으로 하는 상수 함수. 거듭제곱의 지수가 인 경우이다.
 : 항등 함수. 거듭제곱의 지수가 인 경우이다.
 : 이 1인지 여부에 따라 1 또는 0을 취한다.
  (는 소수): 르장드르 기호. 이 에 대한 제곱 잉여일 경우 1을, 제곱 비잉여일 경우 −1을, 의 배수일 경우 0을 취한다.

 : 오일러 피 함수. 보다 작고 과 서로소인 양의 정수의 개수
 : 뫼비우스 함수. 이 제곱 인수가 없는 정수일 경우, 의 소인수의 개수의 홀짝성에 따라 ∓1을 취한다. 이 제곱 인수가 없는 정수가 아닐 경우, 0을 취한다.
  (는 음이 아닌 정수): 약수 함수. 의 모든 양의 약수의 제곱의 합
 : 의 모든 양의 약수의 개수. 약수 함수에서 인 경우이다.
 : 의 모든 양의 약수의 합. 약수 함수에서 인 경우이다.
```

본문에는 실제로 적힌 함수 이름과 두 분류 표제를 남겼다. 위 조각의 함수 인수·매개변수·정의·조건은 직접 결손이므로 원형 보류한다. 빠진 값이나 약수 함수의 지수를 추정하지 않는다.

### 제곱합 함수 예시의 빠진 열거와 등식

```text
예를 들어, 1을 제곱수로 나타내는 방법은 다음과 같이 4가지가 있다.

즉,

이다.
```

원문은 4가지 방법을 예고한 뒤 실제 열거와 등식이 비어 있다. 4라는 값을 유지하되 그 예시를 완결된 목록이나 새로운 표현으로 복구하지 않는다. 바로 앞의 실제 자연어 함수 설명 및 곱셈적이지 않다는 분류는 본문에 보존했다.

### 폰 망골트 함수 블록

```text
폰 망골트 함수

는 이 어떤 소수 의 양의 정수 제곱일 경우 를, 소수의 거듭제곱이 아닐 경우 0을 값으로 취한다.

이므로, 이는 곱셈적 함수가 아니다.
```

함수 기호와 정의의 대상·변수가 빠져 있으며 마지막 분류도 그 정의를 직접 받는다. 이름만 남는 빈 소제목이 되므로 블록 전체를 원형 보류한다.
