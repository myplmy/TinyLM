# expanded_train:10494 원형 보류·정제 기록

작품 목록에 한국어 작품명과 연도는 실제로 남아 있지만 각 항목의 다른 언어 제목 값은 비어 있었다. 빈 칸을 채우지 않고 괄호 안의 빈 쉼표 슬롯만 제거했으며, 실제 한국어 제목과 연도는 유지했다. 원형은 다음과 같다.

- `실험소설론(, 1880)`
- `클로드의 고백(, 1865)`, `테레즈 라캥(, 1867)`, `마들렌 페라(, 1868)`
- `루공 가의 운명(, 1871)`, `이권쟁탈전(, 1871–72)`, `파리의 배(, 1873)`, `플라상스의 정복(, 1874)`, `무레 사제의 과오(, 1875)`, `외젠 루공 각하(, 1876)`, `목로주점(, 1877)`, `사랑의 한 페이지(, 1878)`, `나나(, 1880)`, `살림(, 1882)`, `여인들의 행복 백화점(, 1883)`, `삶의 기쁨(, 1884)`, `제르미날(, 1885)`, `작품(, 1886)`, `대지(, 1887)`, `꿈(, 1888)`, `인간야수(, 1890)`, `돈(, 1891)`, `패주(, 1892)`, `파스칼 박사(, 1893)`
- `루르드(, 1894)`, `로마(, 1896)`, `파리(, 1898)`, `풍요(, 1899)`, `노동(, 1901)`, `진리(, 1903, 작가 사후 출판)`

`각주 및 참고 문헌` 표제 뒤에는 항목이 없어서 본문에서 표제만 제거했다. 실제 전집 서지, Fasquelle 항목, Biblioweb 링크, 작품명·연도·출판 상태 및 분류는 보존했다. 다른 빈 내용의 하위 표제는 실제 표제 문자열로 남겼고, 그 아래 작품이나 본문을 만들어 넣지 않았다.
