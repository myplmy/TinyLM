## 형식이 손실된 코드 예시

두 함수는 선언, docstring, 본문이 한 행에 붙어 있고 코드 구문 경계/들여쓰기가 없어 실행 구조를 복구할 근거가 없다. 토큰을 재배열하거나 코드를 테스트하지 않고 두 예제 단위를 아래 원형으로 보류했다.

`def print_attr(obj): """ Traverses the items in the object's dictionary and prints each attribute name and its corresponding value. """ for attr in obj.__dict__: print attr, getattr(obj, attr)`

`def find_defining_class(obj, method_name): """ Uses method resolution method(MRO) to get the list of class objects(types) that will be searched for methods. Return the class to which the method 'method_name' belong to. """ for origin in type(obj).mro(): if method_name in origin.__dict__: return origin`

## 잘못 맞물린 대화 예제 및 CTA

- `Here’s an example:` / `>>> hand = Hand() >>> print find_defining_class(hand, 'shuffle) <class 'Card.Deck'>` — 샘플 호출 문자열에 `shuffle`의 닫는 따옴표/호출 괄호가 빠져 있고 prompt, 결과 경계도 평탄화돼 있다. 아무 구두점이나 보충하지 않고 예고와 예제 행을 함께 보류했다.
- `So the shuffle method for this Hang object is the one in Deck.` — 위 손상된 `hand` 예제를 가리키며 `Hang`/`Hand`의 표기가 맞지 않아 대상 문장도 보류했다.

본문에는 완결된 `print_attr()`/`getattr()` 설명을 유지하고, 보존한 2번 절 표제에는 원문 코드에 실제로 선언된 `find_defining_class(obj, method_name)` 이름/인수를 옮겨 적었다. 이 서명/이름은 코드 원형에서 가져왔으며 구현을 새로 쓰거나 실행하지 않았다.
