# expanded_train:748466 보류 원형과 경계

시작점이 빠진 원형:

- `사하 공화국 하바롭스크 지방 — 부터`
- `퀸즐랜드주 뉴사우스웨일스주 — 부터 빅토리아주 — 부터`

candidate는 각 주/지방 이름과 순서를 유지하고 `— 부터`에 대응하는 시작점을 만들지 않았다.

미상 영유권 주장 주체의 원형:

- `가 영유권을 주장하는 오스트레일리아령 남극 지역`

새 주체를 추정하지 않았다. 오스트레일리아령 남극 지역 이름은 candidate/새 본문에 남았다.

candidate와 새 본문에서 빈 괄호를 제거한 명명 방향 설명 원형:

- `월레아이 환초() 바로 동쪽을 지나감`
- `니니고 제도() 바로 서쪽을 지나감`
- `스카우튼 제도() 바로 서쪽을 지나감`
- `퀸즐랜드주 머레이섬() 바로 서쪽을 지나감`

이름, 지역, 방향과 순서를 유지하고 좌표를 채우지 않았다. 빈 `각주` 표제도 candidate가 제거했다. 빈 좌표 칸과 빈 표 행은 본문에 그대로 남아 있다.
