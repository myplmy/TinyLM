# expanded_train:1381897 원형 보류

원문에서 미완으로 끝난 설명 구간:

`but if you really need a list, you have to enclose the`

`filter()call with the`

뒤에 어떤 식이나 값이 있어야 하는지 원문에는 없다. Python 2/3의 `filter()` 반환형 차이에 대한 앞선 채워진 설명은 끝 문장부호만 닫아 두고, 직접 미완 절을 원형 보류했다. 반복/예외·`filter()`·리스트 컴프리헨션 예제와 코드 표기를 보존했으며 누락된 괄호/표현식을 생성하지 않았다.

초기 v1은 치환이 적용되지 않아 original과 본문이 동일했다. 이 v2에서 확인된 두 행의 미완 절을 분리했다.
