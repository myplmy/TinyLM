# 30104 빈 필드 정리 근거

## 원형 조각

```text
《모래시계》(—時計, )는 1995년 1월 9일부터 1995년 2월 16일까지 24부작으로 편성된 SBS 특별기획 드라마로, 광복 50주년 특별기획으로 방영되었다.
시청률
극 중에서 사용된 노래 가운데 하나인 《백학》(, Zhuravli)은 러시아의 가수인 이오시프 코브존이 1969년에 발표한 노래이다.
라술 감자토프(, 1923년 ~ 2003년)가 작사하고 작곡가인 얀 프렌켈(, 1920년 ~ 1989년)이 작곡했다.
각주
```

## 판정

- lead의 두 번째 빈 병기 칸과 연결 쉼표만 정리했다. 채워진 `—時計`는 모양이 불완전해 보여도 원문 값 그대로 보존했고, 누락 한자나 표기를 추정하지 않았다.
- 내용이 없는 `시청률` 표제만 분리했다. 실제 시청률·편성 문장과 값, 다른 본문은 보존했다.
- 노래·작가 이름의 빈 병기 칸만 정리했다. `Zhuravli`, 인용된 제목, 이름, 귀속, 연도·조건은 유지했다.
- 원문에 비어 있던 `각주` 표제는 후보가 이미 제거했음을 전체 diff에서 확인했다. 실제 외부 링크 표제 아래의 두 링크는 보존했다.
