# 703384 페이지 반응 UI 원형 보류

본문 뒤 댓글 영역에 다음 비본문 UI가 있다.

- “4 thoughts on”은 댓글 수를 표시하는 UI 접두어다. 같은 줄의 실제 게시물 제목 “Legacy of Carol P. Christ: Can We Celebrate the Dark? Can We Sleep?”은 본문에 보존했다.
- “LikeLiked by 1 person” 두 줄은 각각 댓글 뒤의 좋아요 상태 UI다. 두 원문 문자열을 이 sidecar에 보존하고 학습 본문에서는 분리했다.

기사 본문, 날짜, Carol P. Christ의 약력·직접 인용, 댓글 문장과 댓글 안의 인용 및 각 댓글의 순서는 유지했다. 기사 본문에서 다시 인용한 구절과 댓글에서 같은 구절을 되인용한 경우는 독립 맥락이므로 중복 UI로 보지 않았다.
