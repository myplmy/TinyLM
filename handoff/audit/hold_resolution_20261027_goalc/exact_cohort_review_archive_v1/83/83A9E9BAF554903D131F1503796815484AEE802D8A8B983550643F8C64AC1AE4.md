# 1326802 원형 보류

다음 원문 조각은 서술 대상이나 기호가 빠져 문장으로 완결되지 않는다. 누락된 클래스명을 추정하지 않았다.

- `toString method for class`
- `returns a string consisting of the name of the class of which the object is an instance, the at-sign character ` the unsigned hexadecimal representation of the hash code of the object.`

본문에는 원문에 완전하게 기재된 메서드 설명과 같은 문서 안의 완전한 식 `getClass().getName() + '@' + Integer.toHexString(hashCode())`만 남겨 반환 문자열의 실제 구성요소를 보존했다. 다른 클래스명이나 API를 추가하지 않았다.
