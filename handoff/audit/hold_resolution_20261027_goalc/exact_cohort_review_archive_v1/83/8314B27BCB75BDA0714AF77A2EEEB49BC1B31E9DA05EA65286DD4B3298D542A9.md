# expanded_train:115838 보류·정리 원형

이 sidecar는 누락 목록 예고, 내용 없는 표제, 빈 병기 슬롯의 원형을 보존한다.

- `1923년 10월 6일 체코슬로바키아 정부가 CSA()라는 이름으로 설립했다.`에서 `()`만 제거했다. 명명된 약칭과 설립 사실은 유지했다.
- `운항 노선` 표제와 `2020년 7월 기준으로 체코 항공은 다음과 같은 노선을 운항하고 있다.`는 예고된 노선 목록이 없다. 표제와 목록 포인터를 함께 분리했다.
- `코드쉐어 협정` 표제와 `체코 항공은 다음과 같은 항공사와 코드쉐어 협정을 체결하고 있다.`는 예고된 항공사 목록이 없다. 표제와 목록 포인터를 함께 분리했다.
- `보유 기종` 표제와 `2021년 3월 기준으로 체코 항공은 다음과 같은 기종을 보유하고 있으며 평균 기령은 13.5년이다.`는 빠진 기종 목록에 직접 연결된 원형이다. 기종 목록 주장은 보류하고, 독립적으로 명시된 평균 기령만 본문에 `2021년 3월 기준으로 체코 항공의 평균 기령은 13.5년이다.`로 보존했다.
- 내용이 없는 `현재 사용하는 기종`, `퇴역 기종`, `각주`, `사진`, `외부 링크` 표제를 분리했다.
- `공식 홈페이지`는 URL이나 실제 링크 대상이 없이 남은 일반 표기이므로 빈 외부 링크 항목으로 분리했다.
