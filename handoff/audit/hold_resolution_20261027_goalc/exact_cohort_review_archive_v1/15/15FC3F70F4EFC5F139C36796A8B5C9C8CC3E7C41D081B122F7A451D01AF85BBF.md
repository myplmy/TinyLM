# 26984 직접 결손 구간 보류 근거

## 원문 구간

```text
예 : 波珍 *(중세 한국어 : )‘바다’.

/ㅣ/에 두 가지가 있었다(, )고 하는 가설이 있다.
/ㆍ/(아래아)는 중세 한국어에서는 였다고 추정되지만 고대 한국어에서는 원순성이 강한 였다고 추측된다.

(   ) 내는 중세 한국어형이다.
他矣()
衣・矣()
처격 ― 中, 良中(-애/-에. 이두의 독음은 ‘’)
```

## 본문 경계

- `波珍` 예시 블록은 별표가 적용되는 재구형과 중세 한국어 대응이 비어 있어 전체를 분리했다. 새 음가나 별표의 뜻을 추정하지 않았다.
- `/ㅣ/`의 두 빈 값에 직접 의존하는 가설 절과, 중세·고대 `/ㆍ/` 음가가 모두 소실된 비교 문장을 분리했다. 7개 모음 체계에 대한 원문의 추정과 별도 `/ㅓ/` 설명은 보존했다.
- 형태론 표에서 비어 있는 중세형 도입부와 비어 있는 독음·괄호 슬롯만 정리했다. 실제 한자 표기, 채워진 한국어형, 명시된 분류와 조건은 유지했다. `他矣`, `衣・矣`의 미기재 풀이를 새로 채우지 않았다.
- `고대 한국어()`의 빈 괄호와 빈 `각주` 표제는 후보에서 이미 정리되어 있으며 그대로 제외했다. 서지, 같이 보기, 실제 외부 링크 표기는 보존했다.
