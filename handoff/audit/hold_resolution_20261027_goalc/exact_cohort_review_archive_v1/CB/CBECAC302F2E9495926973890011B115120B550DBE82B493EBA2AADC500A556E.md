## 본문에서 한 최소 경계 정리

- 원문 `SyntaxErrorsbefore executing any code. This is different from other errors, which are only raiased during runtime.`에서 붙은 `SyntaxErrorsbefore`만 공백을 넣어 `SyntaxErrors before`로 적었다. `raiased`는 원문 그대로다.
- 원문 `hellois not the same as` / `helo. This will usually show up as a` / `NameError, but sometimes ...`는 단어 사이 공백만 복구해 문장으로 이었다. `helo`와 이어지는 오류 설명은 원문 그대로다.
- 원문 `whileloop or recursive function might stop one iteration too short. Here, it's best to walk through the iteration/recursion to see what number the loop stops at.`의 손상된 단어 경계는 `A while loop or recursive function ...`로 문법적으로만 이었다. 범위·조건·수치는 추가하지 않았다.

코드, 명령행, traceback, 예시 값, 조건 및 의미가 온전한 설명은 본문에 남겼다. 빠진 함수명·오류 세부·연산자 설명·코드 실행 결과는 만들지 않았다.
