# 48167 빈 영역 표제·표 참조와 별칭 껍데기 보류

원문/후보 전문과 두 순서 패킷, 전체 diff의 END를 확인했다. 후보는 원문에서 첫 문단의 빈 병기 슬롯을 정리하고 내용이 없는 각주 표제를 제거했다. 나머지 표제의 대응 표는 원문과 후보에 들어 있지 않다.

## 본문에서 분리한 원형

- 빈 목록 표제: 전체 유니코드 영역 목록
- 표와 직접 연결된 문장: 유니코드의 전체 범위는 다음 표와 같이 할당되어 있다. 표에서 한국어 및 한글 관련 영역은 굵은 글씨로 표시되어 있다. 표의 행·셀을 추정하거나 새 목록을 만들지 않았다.
- 실제 표제어 뒤 값 없는 괄호: '보조 사용자 영역 A'(), '보조 사용자 영역 B'(). 보충 설명이 비어 있어 괄호 껍데기만 제거했다. 명명된 영역 A/B의 실제 표기, 코드 평면·영역 수·크기·미등록 상태의 내용은 유지했다.

표의 부재로 인해 독립된 한국어 명칭 설명까지 잃지 않도록 '영역 이름의 한국어 이름은 ... 공식이 아니다'라는 완결 문장은 본문에 남겼다. 빠진 표의 데이터는 생성하지 않았다.
