# expanded_train:144506 원형 보류·정제 메모

- 지정 original/candidate 및 packets 1–11을 순서대로 읽고 original·candidate·full_diff의 논리 END와 실제 EOF를 확인했다. 새 본문은 candidate를 기준으로 작성해 전체 diff와 EOF를 확인했다.
- 리드의 `《수호 캐릭터!()》`에서 실제 작품명은 유지하고 값이 없는 괄호만 제거했다. candidate가 이미 정리한 `롯타라 롯타라()`, `우리의 지구()`, `용기의 노래()`의 빈 괄호 정리도 유지했다. 실제 곡명·가수·작사/작곡/편곡·회차 범위는 보존했다.
- 원문/candidate의 `등장인물`, `방송국` 아래 빈 `일본`, `특집격 방송` 아래 빈 `한국`, `각주 및 참고 자료`는 그 아래 실제 항목이 없으므로 해당 빈 표제만 제거했다. `방송국` 상위 제목과 내용 있는 `한국` 방송 설명, 실제 일본 특집 프로그램, 외부 링크의 명명된 라벨은 유지했다.
- `각 화별 제목` 구획에는 회차 제목 목록 자체가 보이지 않지만, 회차번호·총집편 여부·편집/방영 조건·한국어 부제 설명과 시즌3의 실제 명명 항목은 남아 있어 이를 삭제하지 않고 원래 순서대로 보존했다. 누락된 회차 제목을 만들거나 목록이 완전하다고 주장하지 않았다.
- 줄거리와 방영 연혁·스태프·주제가·실제 발매/수록 회차·상품 목록·비교 설명 및 모든 명명값을 그대로 유지했다. 작품/인물/노래·URL을 외부에서 보충하거나 사실 검증하지 않았다.
