# expanded_train:73379 빈 별칭·각주 껍데기 보존

후보의 전체 차이는 빈 별칭 괄호와 본문이 없는 `각주` 표제만 제거한 것이다. 실제 인물·작품·지명·정치/역사 서술, 날짜·수량·조건, 지역·축구팀 목록은 원문과 후보에서 유지된다. 빈 슬롯에 별칭·인물 표기나 각주 내용을 보충하지 않았고, 외부 링크의 실제 제목은 유지했다.

원형에서 보이는 예시는 `캄파니아주()`, `퀸투스 푸블릴리우스 필로()`, `키비타스 포이데라타'''()`, `쿠리우스 덴타투스()`, `트리콜로레()`, `캄파니의주 의회()`이다. `각주` 표제 뒤에는 각주 내용이 없었다. 이 괄호/빈 표제는 필드 값을 담지 않으므로 후보에서 빈 껍데기만 정리한 현재 선택을 그대로 유지한다.

전체 원문·후보와 지정 순서 패킷을 대조했다. 반복되는 역사/미술/스포츠 문단은 원문과 후보의 각 해당 위치에서 동일하게 이어지며, 이들의 위치가 한 파일에 연속 재등장하는 것은 원문-후보 경계 뒤의 후보 본문이다. 후보 안의 중복이라고 오인해 독립 문단을 삭제하지 않았다.
