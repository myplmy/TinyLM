# 1245140 원형 보류 기록

## 범위

지정 original/candidate 전문, 0001–0009 연속 패킷과 전체 diff를 논리 END/EOF까지 대조했다. source와 candidate는 동일하다. 선택 본문은 revise_1245140_v2.txt이며, 이전 hold_1245140_v1.md와 hold_1245140_v2.md를 보존한다.

## 본문에서 분리한 원문

다음은 원문에 실제로 있던 문자열이다. 누락된 목록 값, code, 예제 출력, type name은 채우지 않았다.

- 빈 목록 표제: `- Header files:` / `- Implementation files:`. 각 뒤에 이름이나 항목이 없다.
- 원문 ODR 문장: `ODR stands for the One Definition Rule and says in the case of a function.` 선택 본문은 ODR 약어가 One Definition Rule임을 남기고, 문장의 미완 꼬리는 분리했다.
- 사이트 홍보문구: `Modernes C++ Mentoring` / `Be part of my mentoring programs:` / `Do you want to stay informed about my mentoring programs: Subscribe via E-Mail.` 이는 C++ 설명이 아니라 mentoring 프로그램 구독 안내다.
- 빈 코드 예고를 포함한 원문 문장: `Let me see what my linker says when I try to link a program breaking the one-definition rule. The following code example has one header file header.h and two implementation files. The implementations file includes the header files and breaks the one definition rule because of two definitions of func exit.` 예고된 코드가 실제 본문에 없다. 선택 본문은 예고 없이도 남는 마지막 구현 파일 주장을 보존하고, 보이지 않는 코드나 원인을 더 만들지 않았다.
- 출력이 없는 원문 예고: `The linker complains about the multiple definitions of func:`. 실제 출력이 없어서 예고만 분리했다.
- 미완 결말: `First, a few rules for the organization of source files are left. Additionally, we will get modules with C++20. Let's see which effect these significant features have on C++-`에서 `C++-` 뒤의 결말이 없다. 앞의 두 완결 문장은 본문에 유지했다.
- 값 없는 예시를 가리키는 원문 두 줄: `Prefixing e.g. a type name like this:` / `just clutters the code and do not add to the readability.` 예고한 type name이 없다. 이 두 줄만 분리하고, 뒤에 실제로 열거된 `cout, endl, string`은 본문에 보존했다.

본문에는 작성자 의견, 규칙 번호와 이름, 실제 code/값, 시간 표현, supporter 이름, seminar 이름·전화번호·웹주소 및 나머지 완결 설명이 유지된다. sidecar는 원문에서 빠진 정보를 추측하거나 외부 사실로 확인하지 않는다.
