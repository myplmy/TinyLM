# 433332 원형 HOLD 근거

다음 부분은 직접 결손 또는 비본문 내비게이션이라 본문에서 분리했다.

- 선언 꼬리: `acl_type_t type_d );`. 함수 원형의 앞부분이 없어 이를 완전한 선언으로 두지 않았다. 누락 반환형·인수는 추정하지 않았다.
- 이름이 붙지 않은 인수 설명 및 불완전 열거: `Designates the file descriptor of the file or directory to retrieve the ACL from. Designates the type of ACL to retrieve: ACL_TYPE_ACCESS, ACL_TYPE_DEFAULT, or`. 인수 라벨과 열거 끝이 없어 이 조각을 보류했다. 빠진 타입이나 이름을 보충하지 않았다.
- 잘린 표준 노트: `NOTE: This function is based on Draft 13 of the POSIX`.
- 사이트 내비게이션: `[ Back ]`.

`acl_get_fd`의 채워진 설명 표제, `Security Library (libpacl.a)`, 함수의 실제 동작·반환값·ACL_TYPE별 분기·fd/type_d 오류 조건과 문서의 다른 함수 참조는 원문 그대로 보존했다. errno 값을 만들거나 코드를 실행하지 않았다.
