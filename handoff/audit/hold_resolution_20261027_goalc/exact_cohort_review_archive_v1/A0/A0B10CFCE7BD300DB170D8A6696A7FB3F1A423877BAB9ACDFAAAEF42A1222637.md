# 117808 원형 보류 및 정리 기록

## 보류한 원형

- 그린필드 문단의 미상·손상 토큰: `기형m`
- 내용이 없는 표제: `갤러리`, `각주`
- 본문 뒤 분류 꼬리(원형 순서):

  `기아의 차종` / `아시아자동차의 차종` / `버스` / `후륜구동` / `1990년대 자동차` / `2000년대 자동차` / `2010년대 자동차` / `1994년 도입된 자동차` / `2020년대 자동차`

## 본문 처리 근거

그린필드 절의 `기형m`은 무엇을 뜻하는지 복원하지 않고 해당 조각만 본문에서 분리했다. 같은 문장의 실제 분류 설명 `스탠더드 데크급 최하위 모델이다`와 뒤 연혁·제원은 유지했다. 서두의 `기아 그랜버드()`는 빈 병기 포장만 제거했다.

경일여객 행은 원형의 `...진천터미널은 경일여객이 운영한다.), 서울고속...`에서 안쪽 참고 괄호 뒤에 바깥 괄호를 하나 닫아 목록 경계를 보존했다. `K리그2` 및 남자 V-리그 행의 끝에 남은 빈 쉼표만 제거했으며 팀명·연도는 유지했다. 빈 표제와 분류 꼬리는 본문에 남기지 않았다.
