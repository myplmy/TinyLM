본문은 명명된 Granny/Geraldine 비교의 일반 설명과 `sum()`, `any()`, `all()`, `na.rm=TRUE`의 독립 설명을 보존한다. 실제 비교 벡터 `the.best`의 정의는 원문에 없고, `sum(the.best)`, `any(the.best)`, `all(the.best)`의 출력과 그에 따른 “Granny rocks” 결과 주장은 직접 연결되어 있다. baskets 벡터의 입력값은 원형 그대로 아래에 보존하되, 두 REPL 명령이 한 줄에 붙은 블록을 본문용 코드로 재구성하지 않았다. 빠진 비교식, 값, 출력을 추정하지 않는다.

```text
> baskets.of.Granny <- c(12,4,4,6,9,3) > baskets.of.Geraldine <- c(5,3,2,2,12,9)
as follows:
> sum(the.best)  3
So, three times, Granny was better than Geraldine. Granny rocks!
To ask R whether Granny was better than Geraldine in any game, use this code:
> any(the.best)  TRUE
We told you that Granny rocks! Well, okay, this result is a bit unfair for Geraldine, so you should check whether Granny was better than Geraldine in all the games.
To find out whether Granny was always better than Geraldine, use the following code:
> all(the.best)  FALSE
Still, Granny rocks a bit.
```

본문에서 끝을 정리한 sum() 문장은 원문에 이미 있는 일반 규칙만 남겼다. 코드/결과를 가리키는 직접 지시문, `the.best` 사용과 그에 종속된 주장·출력은 위와 같이 보류했다. `all()`의 명시된 목적 설명은 독립 문장으로 남겼다.
