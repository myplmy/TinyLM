전문에 예고됐으나 실제 호출/그림이 뒤따르지 않는 조각:
> hist(), which takes a single vector as its argument, e.g.:
> After this function call, R will return the following plot:

빠진 함수 호출이나 plot을 만들지 않았다. 본문에서는 hist()가 단일 벡터를 받는다는 실제 설명과, 원문이 직접 적은 20–25, 25–30, 30–35, 35–40, 40–45 구간 및 bucket 높이 설명을 보존했다. 원문의 그림 지시구 As you can tell,은 제거하고 그 뒤에 명시된 ranges/height 진술은 유지했다. 수치를 다시 계산하거나 R을 실행하지 않았다.
