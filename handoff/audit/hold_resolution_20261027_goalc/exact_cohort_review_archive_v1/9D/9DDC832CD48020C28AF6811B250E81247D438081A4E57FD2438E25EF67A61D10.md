# 32356 결손 반응 기호·표적과 직접 의존 표

## 정리한 빈 슬롯

원형 제목: `CNO 순환(, )은`. `CNO 순환`이라는 실제 이름을 보존하고 값 없는 괄호 슬롯만 정리했다.

## 원형 보류 구절

- `4   +  2   →    +  2   +  2   +  2   +  3   +  24.7 MeV  →    +  2   +  3   +  26.7 MeV`
- `제1CNO 순환의 촉매 원소의 변화는 다음과 같다.→→→→→→:`
- `제1CNO의 제한반응(가장 느린 반응)은 의 양성자 포획 반응이다.`
- `제2CNO와 거의 같으나 마지막 반응에서 가 탄소-12와 알파선을 만들어내지 않고 대신 산소-16과 광자를 만들어낸다.`
- `그래서 촉매 원소의 변화는 다음과 같다.  →  →  →  →  →  →`
- `촉매 원소의 변화는 다음과 같다.→→→→→→:` (제3CNO, 제4CNO, 제1HCNO, 제2HCNO, 제3HCNO 각 구간)
- `제2CNO와 제2HCNO 사이의 차이점은 가 감쇠하지 않고 양성자를 포획한다는 것이다. 그 결과 네온이 형성되고 네온은 다시 로 변한다.`
- `제2HCNO의 5번째 루프에서 가 양성자 하나를 포획하여 질량이 커지고 이후 제4CNO와 같은 기작으로 헬륨을 생산한다.`

빠진 동위원소·핵반응식·표적은 채우지 않았다. MeV·반감기 숫자는 해당 반응 행의 기호가 빠진 채 표 안에 있으므로 개별 수치 주장으로 떼지 않고 표 단위로 보류했다. 다음 원형 표들은 입력 후보에 있던 그대로 순서와 표 경계를 유지해 보존한다.

## 그림 포인터와 빈 표제

도입부의 `17 × 106 K (= 17 메가켈빈) 정도의 온도가 되면 CNO 순환이 pp-연쇄반응보다 우세한 에너지원이 된다(우측 그래프 참조).`에서 실제 온도·비교·우세 관계는 본문에 남겼고, 존재하지 않는 그래프 위치 지시만 제거했다. 원문의 빈 `각주` 표제도 뒤에 각주 내용이 없어 분리했다.

본문에는 표의 핵심 종을 이루는 탄소·질소·산소 및 고온 CNO 설명과 독립적인 저온/고온 조건, 온도·에너지·반감기 범위가 문장으로 실제 채워져 있으면 그대로 유지했다. 분리한 표를 재구성하거나 빠진 동위원소를 표에 다시 붙이지 않았다. 원문에서 미상 제한반응 문장 뒤에 이어진 독립 문장 2006년 항성 에너지의 실험적 측정이 하향되어 구상성단의 나이가 10억 년 전후로 교정되었다.는 원래대로 본문에 보존했다.
