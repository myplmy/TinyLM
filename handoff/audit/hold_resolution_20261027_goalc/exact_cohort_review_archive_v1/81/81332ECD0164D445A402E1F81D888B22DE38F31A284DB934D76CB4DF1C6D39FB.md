# 161685: 식·변수 슬롯이 소실된 정의 블록

판독한 원문·후보: page009 입력의 `expanded_train_161685_original.txt`와 `expanded_train_161685_candidate.txt`, TASK_007이 지정한 packets 1–2. 원문과 후보는 동일했다.

## 본문에서 분리한 원형

```text
정의 
페르미 기체의 큰 분배 함수는 다음과 같다.
 (.
이는 다음과 같이 유도할 수 있다.

이에 따라, 상태 에 놓여 있는 입자의 점유수는 다음과 같다.

 : 상태 에 놓인 입자의 점유수
 : 상태 에서의 겹침
 : 상태 에서의 에너지
 : 화학 퍼텐셜(때때로 페르미 에너지라 불리며, 로 표시한다)
 : 볼츠만 상수
 : 절대온도

이 경우에 가 페르미 에너지 이고 이면,
가 된다.
위의 수식을 페르미 함수라 부른다.
```

큰 분배 함수에 대한 실제 식이 비어 있고, `이는`, `이에 따라`, `이 경우`, `위의 수식`이 직접 가리키는 식·변수·상태가 식별되지 않는다. 변수 목록도 기호가 빠져 각 설명과 변수의 대응을 보장할 수 없다. 따라서 그 정의 제목과 직접 종속 블록만 함께 분리했다. 수식·변수·점유수·분포식을 추정해 채우지 않았다.

## 유지한 독립 내용

첫 문장의 `페르미-디랙 통계()`에서 빈 괄호만 제거했다. 통계의 열적 평형 설명, 개념·파울리 배타 원리 설명, 1925–1926년 역사 서술, 같이 보기와 분류는 후보의 내용대로 유지했다. 이 처리는 외부 물리학 사실 검증이나 수식 복원을 뜻하지 않는다.
