# 666374 원형 보류: 소실 수식 참조와 포럼 꼬리

## 판독 범위
지정 original/candidate와 TASK_052의 두 순서 패킷을 대조했다. 아래 문구는 원문에서 그대로 옮겼다.

## 학습 본문에서 분리한 원형

```text
using the formulahttp://research.cs.queensu.ca/home/c...1/Equation.JPG
```

이 수식 링크/대상은 원문에서 완결되지 않는다. 수식이나 변수 관계를 복원하지 않았다. 본문에는 앞의 독립된 과제 설명만 남긴다.

```text
Not sure which variables you'd want to have but here:
```

뒤따르는 변수 목록이 없어 도입문만으로는 내용이 완결되지 않는다. 새 변수를 만들지 않았다. 그 다음 문장의 사용자가 쓸 수 있는 모듈명·호출 예시는 그대로 남긴다.

```text
|All times are GMT +1. The time now is 06:38 AM|
Powered by vBulletin®
Copyright ©2000 - 2013, Jelsoft Enterprises Ltd.
```

## 선택 경계
월 납입액·원금·개월 수·월 이율의 원문 정의, 원문 예시의 수치와 계산 결과, 입력·계산 함수에 관한 독립 조언과 테스트 안내는 보존했다. 위의 소실된 수식 참조와 내용 없는 변수목록 도입문, 포럼 시간·플랫폼 꼬리는 분리했다. 수식·변수·추가 계산은 생성하지 않았다.
