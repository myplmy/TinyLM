# 24703 원형 보류·정리 근거

## 표·도표·빈 구획

- 아래 원문 표제들은 이어져야 할 표/도표 본체가 없으므로 표제나 값을 학습 본문에 복원하지 않고 원형 그대로 보류했다.

```text
 경상 누층군 층서 (1929년과 1975년 이후)
 기계도폭(1975)에 제시된 경상 누층군 지층 대비표
인구 
 경산시(에 해당하는 지역)의 연도별 인구 추이
```

- 본문 행정구역 설명에 실제로 명시된 2015년 5월 31일 기준 세대/인구 수치는 별도 완결 문장이므로 그대로 보존했다. 해당 수치에 연도별 인구 그래프의 점/축 의미를 붙이지 않았다.
- 내용 없는 `교육 기관`, `경산시장`, `경산시의 국회의원` 표제는 빈 구획으로 분리했다. `정치 · 행정` 및 친선·자매·우호 도시 표제는 실제 도시명이 이어져 보존했다.
- 외부 링크의 실제 원문은 다음과 같이 URL 없이 `(공식)`만 남아 있어 그 미상 대상 링크 줄과 빈 표제를 보류했다.

```text
외부 링크 

  (공식)
```

## 보존·최소 정리

- 대구층 영어 병기 끝의 빈 alias 슬롯만 정리했다. `Taegu/Daegu formation`과 `Taikyu formation`은 순서대로 보존하고 빠진 이름을 추정하지 않았다.
- 경산시의 실제 지명·방향·면적·연도·지층·화석·사건·광산·교통·행정구역·인구·도시 목록과 조건/수치는 원문 순서대로 유지했다. 같은 내용이 역사와 교통 절에 각각 등장하는 2호선 연장 정보는 절 역할이 달라 반복 삭제하지 않았다.
- 후보가 이미 제거한 빈 `각주` 표제도 유지했다. 누락된 표 셀, 지도·그래프 값, 기관·의원 이름, URL을 보충하거나 사실 확인을 주장하지 않는다.
