# 276890 원형 보류 — 빈 병기/동영상 표제와 구매 UI (v1)

## 판독 범위

TASK_004 packet 0001–0002의 original/candidate/full_diff를 읽고 packet 0002에서 candidate END와 full diff END를 확인했다. 새 본문 전체 diff/EOF도 확인했다.

## 분리·정리

- 제목 `테오쓰나고/킨단노카루마()`의 괄호 안 별칭이 비어 있어 빈 포장만 정리했다. 싱글 제목/곡목은 그대로 유지했다.
- `뮤직비디오` 표제 뒤에는 동영상 항목이 없다. 해당 빈 표제와 공백을 분리했다.
- 실제 링크 라벨의 `- 구매 부서`는 구매 동작을 가리키는 UI 꼬리로 분리했다. 바로 앞의 일본어 싱글 제목과 공식 사이트 표기는 보존했다.
- 빈 `각주` 표제는 candidate에서 이미 제거되어 있어 그대로 뒀다.

싱글의 발매일·회사·수록곡/버전별 곡목·작사/작곡/편곡·애니메이션/드라마/영화 연결·외부 링크·분류는 원래 위치대로 유지했다. 제목/크레딧/작품 관계를 새로 만들거나 외부에서 확인하지 않았다.
