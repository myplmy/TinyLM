# expanded_train:86684 원형 보류

## 원형 보류 구간

- 조사 예시가 빈 슬롯으로만 남은 부분: `(, ,  등)`.
- 지역 발음 관련 완결 정보 뒤, 미상 음운을 받는 첫 가설절: `이 사실에서, 연탁은 말의 경계에 놓여있었던 ''의 흔적이 아닌가 하는 가설이나,`.
- 말의 종류에 따른 제약 아래의 두 예시행:

  ` +   →  ()`

  ` +  →  ((부부싸움))`

  연탁 적용 대상/표현이 비어 있어 화살표와 괄호 안 표기만으로 관계를 배정하지 않았다.
- 라이먼의 법칙 아래의 두 빈 예시행과 실제 예시어가 빠진 문장:

  ` +  → `

  ` +  → `

  `극히 드문 예로, '' 등이 있다.`
- 앞부분 탁음에 관한 별도 이설의 예시절: `, '/' 등에서 그 흔적을 찾아볼 수 있다.` 이설 자체인 `한편, 예전에는 합성어의 앞부분에 오는 탁음 또한 연탁을 막는다는 설도 있었다`는 본문에 남겼다.
- 오른쪽 갈림 제약의 두 예시행. 일본어 합성어명과 구조식/요소표시가 미상 또는 비어 있어 예시 전체를 본문에 남기지 않았다:

  `''() : [[ + ] + ] (꼬리()가 흰(), 독수리(), 연탁 현상이 일어남)`

  `''() :  [ + [ + ]] (무늬()가 있는, 흰() 나비(), 연탁 현상이 일어나지 않음)`
- 의미 병렬 조건 아래의 빈 예시 두 행: `()` / `()`.
- 성씨의 지역별 예시에서 이름·결과값이 빈 괄호/슬롯으로 남은 부분: `(의 경우, 동일본에서는 , 서일본에서는 )`.
- 행 변격동사 예시 설명 중 미상 표기·한자 글자·발음 대응값·자음 소유자가 소실된 구간:

  `한자어 등에서 유래하는 행 변격 동사의 경우, 연탁의 현상과 유사한 '' 등의 표기가 존재한다. 이는 (かんずる), (えんずる), (こうずる), (ほうずる) 등에서처럼,  또는 로 끝나는 한자 한 글자가 오는 경우가 많다.`

  `이들은 원래의 발음이 /n/ 또는 /m/(), /ng/()의 비음이어서, 이의 영향으로 뒤따라온 가 탁음화된 것이다.`

  `이 문맥에서 별도로 적힌 현대 처리 설명은 본문의 행 변격동사 절에 유지했다. 괄호 안 kana 예시, 표제의 분류, 용언 처리와 확률 표현은 새로 고치지 않았다.`
- 고유어 `うとんずる` 예시 뒤의 미상 음운을 받는 발음변화 절:

  `이것은 (うとみする)가 발음편()으로 '(うとん-)'이 되어, 이로 인해 가 탁음화된 것이다.`

## 빈 포장 정리

원문에서 이미 채워진 이름/표제와 같은 자리의 빈 괄호를 정리했다: `연탁()`, `'일본대문전'()`, `'라이먼의 법칙'()`, `모토오리 노리나가()`, `오른쪽 갈림 제약()`, `발음편()`, `연탁은 언제 일어나는가?()`.

`각주` 표제 아래 실제 각주가 없어서 그 빈 표제만 분리했다. 참고 문헌·외부 링크와 실제 링크 제목, 일반 음운/역사 설명 및 명시된 조건·값은 본문에 보존했다. 빠진 일본어 형태나 발음·예시 관계를 추정하지 않았다.
