## 학습 본문에서 분리한 원형 조각

- “The following diagram illustrates how a unique stack looks and works.” 실제 도식이 입력에 없어 도식 예고만 분리했다. 앞의 unique stack 정의와 “There are no duplicated items in this unique stack.”은 보존했다.
- “In the example above, the stack contains either integers or strings.” 및 Push 설명의 “For the example shown on the first page, calling the Push function will push the new item right above 9 for the stack with integers and right above ‘This is fun’ for the stack with strings.”는 부재한 예시 도식에 직접 기대므로 분리했다. 일반 Push 동작과 다른 완결된 예외 조건·데이터 종류는 보존했다.
- Pop 설명의 “For the example shown on the first page, calling the Pop function should return 9 for the integer stack and return ‘This is fun’ for the string stack.” 및 “In the meantime, the top item of the stack would be 27 for the integer stack and ‘Hi Mom’ for the string stack after this”를 분리했다. 전자는 부재한 예시에 의존하고, 후자는 문장이 잘려 있다. 일반적인 Pop 동작과 함수 정의는 보존했다.
- “operator: [4 points] Overload the  operator so that it returns a copy of the item located at a specified index. This operation is a read-only operation. That is, it does not affect the content in the”는 연산자 기호가 비어 있고 끝도 끊겼으므로 해당 요구사항 전체를 분리했다. 연산자 종류나 추가 동작을 추정하지 않았다.
- 마지막 Good Practice Hint의 고립된 “(No”만 분리했다. 바로 앞의 두 파일만 두라는 완결 요구는 보존했다.

보류한 숫자, 문자열, 조건과 문장 조각은 원형으로만 기록한다. 새 코드나 빠진 기호를 만들지 않았다.
