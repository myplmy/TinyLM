# 16950 원형 보류 기록

## 보류하거나 분리한 원문 조각

- `페아노 공리계(Peano公理系, )`에서 값 없는 병기 슬롯
- `자연수의 덧셈은 (보통 중위 표기법으로 표현되는) 함수 + : N × N → N으로, 다음과 같이 재귀적으로 정의된다:` 뒤의 누락된 정의식 포인터
- `덧셈이 주어졌으므로, 자연수의 곱셈 또한 아래의 반복법 조건을 만족하는 함수 ·: N × N → N로 정의할 수 있다:` 뒤의 누락된 조건식 포인터
- `페아노 공리계를 만족시키는 논리학적 구조, 곧 모형은 이다.`
- `곧, 두 모형  와  이 주어졌을 때, 다음을 만족시키는 준동형사상  가 유일하게 존재하며, 이는 전단사이기도 하다.`
- `... 0을 공집합으로 정의하는 것에서 시작하여 따름수 연산자 s를 다음과 같이 정의한다.`의 정의식 포인터
- `자연수 집합 N은 s에 대하여 닫힌 모든 집합들의 교집합으로 정의된다. 다음과 같이, 각 자연수는 그것보다 작은 모든 자연수들을 모은 집합과 동등하게 된다:`에서 식을 예고하는 연결어와 콜론. 문장으로 완결된 두 관계 설명은 선택 본문에 남겼습니다.
- 원문 무모순성 문단의 방법 부분 `원시 재귀 산술()에 더하여 양화사가 없는 초한귀납법이 순서수 까지 확장된다는 법칙을 추가한 것으로부터`
- 같은 문단의 미상 순서수 정의와 식 `순서수 는 이 되는 최소의 순서수로, 그것보다 작은 극한 순서수를 모두 모은 수열의 극한으로 볼 수 있다. (즉,  가 성립한다.)`
- 역사 문단의 빈 괄호: `《새로운 방법으로 표현된 산술의 원칙》()`
- 값이 없는 표제: `각주`

## 선택 본문 경계

선택 본문은 입력에 실제로 적힌 연산 이름과 서명, 예시, 관계, 정의, 역사 주장, 조건, 참고 자료를 유지합니다. 남은 수식·모형 이름·순서수·설명 값을 만들거나 외부 수학 지식으로 채우지 않았습니다. 겐첸의 일관성 증명에 관한 완결된 원문 주장과 원시 재귀 산술의 독립 정의를 남겼습니다. 빈 `각주` 표제만 분리했으며 참고 자료와 같이 보기 항목은 유지했습니다.
