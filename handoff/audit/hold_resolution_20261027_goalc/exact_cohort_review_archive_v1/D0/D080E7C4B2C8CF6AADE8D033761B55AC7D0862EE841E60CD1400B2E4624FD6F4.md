# expanded_train:1344321 원형 보류

- `This attribute can be used with any typical HTML form element; it is not limited to elements that have an ARIA`는 목적어/속성명이 끊겨 직접 해석할 수 없어 원문 그대로 분리했다.
- 내용 없는 `Possible effects on user agents and assistive technology`, `Related ARIA techniques` 표제와 `TBD: Add support information for common UA and AT product combinations` 편집 지시를 분리했다.
- 실제 `a space-separated list of element IDs`는 같은 문맥에 이미 명시된 `aria-describedby`의 값 설명으로 현 위치에 유지했다. HTML 예시 두 개와 `Used by ARIA roles` 및 `all elements of the base markup`도 보존했다. 다른 속성명/값 표제를 만들거나 현행 사양을 검증하지 않았다.
