# validation:3463 누락 명령 예고 기록

원문에는 `It sets five variables: X, Y, Z, S, YS, and ZS.` 뒤에 `Using the special rule shown above it's possible to type commands like`라고 적혀 있고, 다음 구절은 `to get the value of X once for each variable you are interested in.`으로 이어진다. 예고한 `commands like`와 `to get` 사이에 실제 명령이 없어, 해당 불완전 문장만 본문에서 분리했다. 구체 명령을 이웃의 `gmake -f Makefile -f helper.mak printvars`에서 가져오지 않았다. 앞뒤의 Makefile 변수 예, helper.mak 규칙, 실제 출력, GNU Make 설명과 글 끝의 독자 의견 요청은 보존했다.
