# 249250 원형 보류 기록

- 원문 제목의 “< Software Engineers Handbook”은 상위 handbook으로 돌아가는 breadcrumb/UI로 보고 분리했다. 실제 페이지 경로와 Oz 제목은 유지했다.
- 원문 4–5행의 빈 “Execution Entry Point” 섹션 및 시작 위치를 묻는 작성 지시, 6–7행의 문장/대입 예시 작성 지시와 그 일반 예시, 12–16행의 변수 선언 예시 지시와 미작성 methods/functions 구현 안내, 21행의 Hello World 작성 지시, 22–24행의 컨테이너/알고리즘 목록 작성 지시, 27–28행의 미작성 언어 전환 팁/웹 참고 자료 지시는 템플릿 작성자용 텍스트라 본문에서 분리했다.
- 원문 8행의 댓글 문법 지시만 제거했다. 이어지는 실제 // 인라인 댓글 설명, /*...*/ 블록 댓글 설명과 예시는 완결된 내용이어서 보존했다.
- 원문 17행의 scope 작성 지시만 제거하고, 불확실성을 나타내는 “There is lexical scoping?”은 그대로 남겼다.
- 원문 18–19행의 conditional 문장 작성 및 서식 지시는 제거하고, 실제 “if”/“case” 지원과 pattern matching 설명은 보존했다.
- 원문 20행의 반복문 예시 작성 지시 뒤 실제 답변 “Built in.”은 같은 문맥의 반복문 주제를 받아 “Looping statements are built in.”으로 연결했다.
- 원문 23행의 “constructs a transparent data structure. The parts in lowercase are literals.”는 주체/구성 예시 대상이 원문에서 빠져 정확한 귀속이 불가능해 원형 HOLD했다. 값이나 대상 이름을 만들지 않았다.
- 원문 25행의 자동/수동 GC 질문 뒤 답변 “Is automatic.”은 명시된 주제를 받아 “Garbage collection is automatic.”으로 연결했다.
- 원문 26행의 “Is developed and executed in an IDE, Mozart.”는 주어가 빠져 대상이 명확하지 않아 원형 HOLD했다. 다음 독립 문장 “There are tools for modularization and source code management (?).”은 불확실성 표기를 포함해 그대로 보존했다.
- 원문 29행의 “Books and ArticlesEdit”에서 “Edit”는 편집 UI 잔재라 분리하고 실제 Books and Articles 표제와 Van Roy/Haridi 서지는 보존했다. 원문 30행의 서지 작성 지시만 분리했다.
- 원형 지시/미상 귀속은 이 sidecar에 보존했다. 새 Oz API, 기능, 제목, 출처나 주어를 생성하지 않았다.
