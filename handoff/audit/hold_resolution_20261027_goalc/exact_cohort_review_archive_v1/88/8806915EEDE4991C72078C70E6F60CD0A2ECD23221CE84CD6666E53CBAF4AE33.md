# expanded_train:1408837 — 제거 UI 원형 보존

후보에서 제거된 항목은 페이지 탐색 문자열 `Back to Top` 8회다. 원문 순서상 초기 분류 목차 뒤, 참고 목록 뒤, 나비 사진 설명 뒤, Symbiosis 표제 뒤, elephantiasis 사진 뒤, “Speciation in Insects” 표제 뒤, malaria 사진 뒤, phage 사진 뒤에 각각 놓여 있었다.

이 문자열들은 본문 사실, 자원명, 설명, 분류명, 사진 설명 또는 조건을 제공하지 않는 페이지 이동 UI이므로 후보의 제거를 승인한다. 후보에는 Wolbachia 자료의 제목·설명·분류, 이미지 캡션과 나머지 내용이 보존되어 있다. 이 sidecar는 UI 원문과 위치를 기록하며 본문에 복원하지 않는다.
