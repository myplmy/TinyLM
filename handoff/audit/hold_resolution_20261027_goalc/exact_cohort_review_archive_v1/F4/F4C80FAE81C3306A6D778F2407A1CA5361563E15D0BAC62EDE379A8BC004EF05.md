# 20136 — 분리한 원형 조각

| 원문 조각 | 근거 |
|---|---|
| `프란틀 수()` | 빈 기호 병기만 정리했다. 프란틀 수의 명명, 실제 비율 설명과 ‘근사적으로 표현하는 무차원 수’ 정의는 보존했다. 새 기호를 넣지 않았다. |
| `다음과 같이 표현된다.` 및 뒤의 빈 식 자리 | 식이 없으므로 직접 예고만 분리했다. 정의와 실제 Pr 값 목록은 남겼다. |
| `여기서 는 동적 점성계수이고,` | 점성계수의 앞 기호가 비어 주어 관계를 특정할 수 없다. 원형 조각만 보존하고, 같은 문장의 완결된 `α는 열확산도이다.`는 본문에 남겼다. |
| `: 동점성계수 (SI m2/s)`; `: 열확산계수 (SI m2/s)`; `: 점도 (SI Pa s = N s/m2)`; `: 열전도율 (SI  W/m-K)`; `: 비열용량 (SI  J/kg-K)`; `: 밀도 (SI kg/m3)` | 기호와 앞 콜론은 소실 포장으로 분리했다. 실제 물성명과 SI 단위는 본문에 같은 원순서로 보존했다. 기호는 만들지 않았다. |
| `한편 / 는 용적열용량(volumetric heat capacity - J/m³·K) / 동점성계수 / 열전도율` | `한편`과 `는`의 주어·기호 관계는 소실되어 원형 보존했다. 실제 용어·단위 쌍 `용적열용량(volumetric heat capacity - J/m³·K)`은 본문에 남겼고, 뒤의 두 고립 용어는 앞에서 보존한 물성명과 중복되므로 별도 관계나 식으로 재구성하지 않았다. |
| `각주` | 내용이 뒤따르지 않는 빈 표제만 분리했다. 실제 같이 보기 항목과 분류는 보존했다. |
