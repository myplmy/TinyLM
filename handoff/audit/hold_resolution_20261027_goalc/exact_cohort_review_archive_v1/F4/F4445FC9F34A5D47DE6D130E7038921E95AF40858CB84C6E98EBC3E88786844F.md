# expanded_train:817861 — 분리한 원형

## 미완결 원인/대상 꼬리
원문:
so that no change is done and the UART registers preserve the

보류 이유: preserve의 대상이 소실된 채 문장이 끝난다. 앞의 독립 문장 “I believe the spirit behind this patch is to set the same terminal config both by ldattach and ntpd”는 그대로 보존했다. 누락된 레지스터 값이나 설정을 추측하지 않았다.

다른 명명된 GPS/NMEA/PPS/ntpd 관계, 실제 config·명령·값·버전/저자 한정, 빌드 절차 및 본문 순서는 유지했다. IP 형태의 숫자 문자열도 외부 지식으로 고치지 않았다.
