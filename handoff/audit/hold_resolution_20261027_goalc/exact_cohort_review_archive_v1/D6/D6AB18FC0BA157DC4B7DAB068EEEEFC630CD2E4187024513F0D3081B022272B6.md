# expanded_train:13213 화살표형 빈 필드와 빈 반응식 포인터 원형

지정 original/candidate, 8개 연속 packet과 원문-후보 full_diff의 END를 대조했다. 화살표만 있고 실제 이름·어원값이 없는 두 괄호 슬롯은 원문대로 보존한다.

```text
악티늄(←, ←)
Ac(←)
```

악티늄명, Ac 기호, 원자 번호 89, 실제 발견 연도 1889와 독립 설명은 새 본문에 남겼다. 화살표나 괄호 슬롯에 새 이름·기호를 대입하지 않았고, 이 처리를 다른 문맥의 실제 화학·수학 화살표에 일반화하지 않는다.

빠진 반응식의 직접 예고는 다음과 같다.

```text
베릴륨은 다음 화학반응과 같이 알파 입자를 포획하여 중성자를 방출한다:
```

뒤따르는 식은 원문에 없다. 식은 만들지 않고, 이미 문장 안에 채워진 베릴륨·알파 입자 포획·중성자 방출 관계만 본문에 짧은 평서문으로 보존하며 비어 있는 `다음 화학반응과 같이` 포인터와 콜론을 정리했다. 격자 변수 a·b·c와 단위 정의, 원소·동위원소·화합물·반감기·수치·온도·조건·기타 산문 및 실제 반응식은 그대로 유지했다.
