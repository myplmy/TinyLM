# expanded_train:13752 원형 보류 경계

아래는 수식·변수·대상이 원문에 없거나 직접 예고를 받지 못한 구간이다. 원문 표현을 보존하며 수식과 변수를 보충하지 않았다.

- 그림 대상 포인터: `이는 그림과 같이`만 분리했다. 뒤의 정삼각형 배열 설명은 그림 없이도 완결되어 본문에 보존했다.
- 정의: `음이 아닌 정수 에 대하여, 번째 삼각수 는 다음과 같이 정의된다.`
- 연산에 대한 닫힘 전체: `두 정수 에 대하여, 다음 두 조건이 서로 동치이다.`, `임의의 삼각수 에 대하여,  역시 삼각수이다.`, ` 는 어떤 홀수의 제곱이며, 이다.`, `예를 들어, 만약 이 삼각수라면, 과  및 은 역시 삼각수이다.` 빈 변수·식과 직접 연결된 예시라 섹션 도입 및 종속 문장을 함께 분리했다.
- 항등식 예고: `삼각수와 임의의 각수는 삼각수를 통해 다음과 같이 나타낼 수 있다.`, `특히, 정사각수와 육각수 및 팔각수의 경우는 다음과 같다.`, `첫째 등식에 따라, 두 연속된 삼각수의 합은 정사각수이다. 두 연속된 홀수째 또는 짝수째 삼각수의 합은 다음과 같다.`
- 식 직접 예고: `구체적으로, 다음이 성립한다.`(선형 변환 설명 뒤), `삼각수는 다음과 같은 점화식을 갖는다.`, `조합론적으로, 첫 번째 항등식의 좌변은 개의 원소에서 2개를 고르는 중복 조합의 수이며, 우변은 이를 앞의 개에서만 고르는 경우와 뒤의 개에서만 고르는 경우 및 앞과 뒤에서 하나씩 고르는 경우와 같이 세 가지로 나눠 센 결과이다. 특히, 다음이 성립한다.`, `구체적으로, 다음이 성립한다.`(제곱합 설명 뒤), `구체적으로, 다음이 성립한다.`(사면체수 설명 뒤).
- 생성 함수: `생성 함수` 및 `삼각수는 다음과 같은 생성 함수를 갖는다.`
- 수론 예고: `삼각수의 임의의 정수에 대한 나머지에 대하여 다음이 성립한다.` 뒤의 홀수·짝수 주기 설명은 자체로 읽히므로 원문의 `즉,`만 걷어내고 보존했다. 실제 2·3·4 나머지 수열도 원문 순서와 값을 유지했다.
- 정사각 삼각수: `정사각 삼각수를 찾는 문제는 다음과 같은 펠 방정식의 해를 구하는 문제와 동치이다.`, `이들은 정확히 다음과 같다.`, `이는 레온하르트 오일러가 1730년에 증명하였다.` 누락된 방정식·정확한 수열에 직접 의존하는 절을 분리했다. 같은 문장의 독립 주장 `정사각 삼각수는 무한히 많이 존재한다.`와 뒤의 실제 세 수열 및 그 설명은 본문에 보존했다.
- 빈 이름 슬롯: 원문 `삼각수(三角數, )`, `정사각 삼각수(正四角三角數, )`의 빈 괄호 별칭만 정리했다. 실제 한자 표기는 유지했다.
- 항목이 없는 `외부 링크` 표제만 분리했다. 실제 참고 문헌과 분류는 보존했다.

검수 근거를 학습 본문에 넣지 않았고, 없는 수식·이름·항목을 만들지 않았다.
