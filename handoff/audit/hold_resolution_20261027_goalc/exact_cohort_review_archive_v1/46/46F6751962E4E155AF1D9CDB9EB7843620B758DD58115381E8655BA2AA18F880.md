# expanded_train:515905 원형 보존 및 수정 근거

지정 연속 패킷 0001–0002에서 본문과 이어지는 실제 네 댓글을 끝까지 확인하고 original/candidate의 직접 diff를 대조했다. 원문 `6 thoughts on “An example of fight-or-flight”`는 뒤에 실제 댓글들이 이어지는 완결 표제이므로 본문에 그대로 유지한다. 후보가 이를 단순 제목으로 바꿔 댓글 연결/원래 수량 표기를 잃었으므로 원문 표제를 복구했다. 수량을 보이는 댓글 수에 맞춰 재계산하지 않는다. 두 `LikeLiked by 1 person`는 댓글 반응 UI라서 새 본문에서 제거하고 이 메모에 원형 보존한다. 수정 본문은 원문에서 두 반응 UI 행만 제거한 전체 텍스트다.
