# expanded_train:11965 — 소실 길이와 빈 슬롯/표제

원문·후보 전문 및 지정 패킷의 전체 diff를 대조했다. 다음 조각만 학습 본문에서 분리하고 원형을 보존한다.

- 도입부 `소프라노 오보에는 대략 의 길이로`에서 길이값이 비어 있다. 해당 길이 주장만 보류하고, 실제 기재된 금속 키·원뿔형 관·나팔 모양 벨의 구성 설명은 남겼다. 길이값/단위를 만들지 않았다.
- 빈 제목 별칭 `오보에(,  )`는 후보가 이미 제거했다. 원형 슬롯만 기록하며 다른 기재된 명칭은 그대로 유지한다.
- 역사 문장의 `"French Hoboy"( )` 빈 괄호만 제거했고, 실제 이름과 역사 서술은 남겼다.
- 항목이 없는 `유명 연주자`와 내용 없는 `각주` 표제는 본문에서 제거한다. 원형 표제는 이 sidecar에서 보존한다. 후보가 이미 제거한 각주 표제는 복원하지 않았다.
- 제작사 목록의 `A. Laubin (incl. "A. Barré") (Peekskill, New York`는 제작사명과 괄호에 실제 기재된 포함 관계를 유지하고, 닫히지 않은 부분 위치 조각 `(Peekskill, New York`만 분리했다. 국가나 빠진 위치 정보를 추정하지 않았다.

작품명과 귀속, 연도·음역·수치, 완결 제조사 목록, 참고 문헌과 실제 외부 링크 표제는 유지했다.
