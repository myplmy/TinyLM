# 1203771 원형 보류

원문에서 보류한 정확 구간:

> put in the following code to let Python know where to find it.
> from selenium import webdriver opts = webdriver.Edge() dr = webdriver.Edge('C:/Users/larsobe/Desktop/msedgedriver.exe',chrome_options=opts)
> Now to see if this works, use the following line, (you can try another website if you choose)
> You are now running a web browser via Python.

코드 구간은 import와 두 할당이 공백으로 붙어 있어 문장 경계·실행 순서를 원문만으로 복구할 수 없다. 다음 줄을 예고하지만 browser navigation 호출은 원문에 없다. 따라서 연결된 코드, 그 코드 삽입 지시, 누락 호출 예고, 실행 성공을 단정하는 결과 문장만 보류했다. 호출명, URL, 인수, 코드 줄바꿈을 새로 만들지 않는다. Selenium/Edge 설치와 driver 다운로드·보관 안내는 완결된 본문으로 남겼다.
