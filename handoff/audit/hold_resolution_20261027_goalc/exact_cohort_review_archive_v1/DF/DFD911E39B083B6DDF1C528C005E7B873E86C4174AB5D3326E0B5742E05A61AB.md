# 1390696 원형 보류

| 원문 조각 | 보류 이유 |
|---|---|
| `Iterables have the function` | 필수 메서드명이 빠진 직접 미완 문장이다. 메서드명을 보충하지 않는다. |
| `A for-loop takes\nthe_list above, and calls\nthe_list.next() over and over until it satisfies the parameters of the for-loop (in our example above, that parameter is that you’ve reached the end of the list).` | for-loop가 리스트의 `.next()`를 호출한다고 주장하지만, 뒤의 실제 REPL transcript는 `the_list.next()`에서 `AttributeError`가 난다고 보인다. 충돌하는 주장 문장과 그 직접 결과 설명만 분리한다. |
| `iter(the_list) will return an iterator of` | 반환 대상이 소실된 직접 미완 문장이다. 대상을 채우지 않는다. |
| `But we can’t; it raises a` | 예외명이 빠진 직접 결과 조각이다. 뒤에 붙일 예외명을 추정하지 않는다. |
| `This MyIterator class does, however, demonstrate how iterables and iterators differ from one another, and how they depend on one another, and in this case, how a list generates an iterator that can then be iterated over with the` | 목적어가 소실된 직접 미완 문장이다. 없는 대상이나 메서드를 채우지 않는다. |

실제 `the_list.next()` 호출과 이에 대한 AttributeError REPL transcript, 기타 완결 transcript·설명은 본문에 그대로 보존한다. 중첩된 사용자 코드 예제를 재작성하거나 `__iter__` 등 이름을 추정해 보충하지 않는다.
