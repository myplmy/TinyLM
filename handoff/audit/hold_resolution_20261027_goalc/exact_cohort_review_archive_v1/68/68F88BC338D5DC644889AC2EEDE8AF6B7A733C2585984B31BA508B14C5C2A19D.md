# 97465 원형 보류 — TASK019

리드의 `도치기 방송()`에서 괄호 안 값은 비어 있어 괄호만 제거했다. 내용이 없는 독립 `주파수` 표제는 분리했다. 연혁에는 실제 주파수·출력값과 방송국 이름이 있으므로 모두 그대로 보존했다.

원문에서 분리한 형식/빈 부분: `도치기 방송()`의 빈 괄호; 독립 `주파수` 표제.

`외부 링크` 아래 `공식 사이트`라는 실제 라벨은 URL 누락만으로 지우지 않고 원래 위치에 보존했다. 이를 현재 공식성이나 실제 URL 검증으로 해석하지 않았다. 약칭·콜사인·방송국명·연혁·수치·다른 방송국 목록·말미 분류는 원문대로 남겼다. 이 정리는 다른 표제나 채워진 출처 항목을 제거하는 근거가 아니다.
