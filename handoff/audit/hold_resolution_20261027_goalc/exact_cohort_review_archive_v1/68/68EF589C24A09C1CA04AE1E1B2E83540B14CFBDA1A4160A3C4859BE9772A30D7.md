# expanded_train:210188 보류 구간

원문에서 다음 부분을 원형 그대로 분리했다.

1. `The following function keys, defined in <curses.h>, might be returned by getwch() if keypad has been enabled. Note that not all of these may be supported on a particular terminal if the terminal does not transmit a unique code when the key is pressed or if the definition for the key is not present in the terminfo(4) database.`
   - 이 문장은 이어질 실제 function key 목록을 직접 예고하지만 목록이 없다. 지원 조건을 값 없이 남기면 빠진 목록을 참조하므로 함께 보류한다.
2. `See attributes(5) for descriptions of the following attributes:` 및 `|ATTRIBUTE TYPE||ATTRIBUTE VALUE|`
   - 속성 설명을 예고하는 문장과 열 머리글만 있고 실제 속성 행/값이 없다. 속성 값을 만들지 않고 둘 다 보류한다.

그 밖에 실제 함수 서명, 함수 설명, 반환 조건, 교차 참조, 헤더 파일 정보와 사용 조건은 본문에 보존했다.
