# expanded_train:703228 — 원형 보류

- 원형: `In this example, the fun1 function and the fun2 class are considered part of the public interface of the mymodule module, while the fun3 function is considered private and should not be used by external code.`
- 사유: 바로 앞 예시 코드는 `fun2()`를 함수로, `class fun3`를 클래스로 정의합니다. 분류 설명이 코드와 충돌하므로 둘 중 하나를 고르거나 이름/종류를 정정하지 않고 그 문장만 보류했습니다. `__all__`에 실제 적힌 `fun1`과 `fun2`가 가져와진다는 다음 문장은 그대로 유지했습니다.
- 원형: `my_private_function() #NameError: name 'private_function' is not defined`
- 사유: 위 예시에서 선언한 `_my_private_function`과 호출 이름이 다르고 결과 주석에도 이름이 다르게 적혀 있습니다. 선언이나 호출을 추정해 맞추지 않고 이 호출/예상결과 조각만 분리했습니다.
- 원형: `#NameError: name '_var2' is not defined`
- 사유: 직전 실제 코드 호출은 `print(_my_var2)`입니다. 예상 오류 주석의 식별자가 코드 이름과 다르므로 결과를 새로 고치지 않고 주석만 분리했습니다. `print(_my_var2)` 호출과 앞서 명시된 `__all__` 설명은 본문에 남겼습니다.
