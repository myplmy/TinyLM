# expanded_train:46651 원형 보존 메모

- 대상 글자와 실제 예시 글자가 비어 있는 연결형 설명·아라라트 예문을 보류했다. 다른 문장에 나타난 글자를 끌어와 빈 항목을 채우지 않았다.
- 정관사 관련 sun-letter 문장에서 실제로 비어 있는 구체적 묵음 대상은 원형 보류했다. 양쪽 발음 전사와 화살표가 채워진 해/달 예시는 그 원래 문맥에서 보존하고 빈 아랍 문자 포장만 정리했다. 아랍어 원형 철자·새 IPA·소실된 묵음 대상 글자는 생성하지 않았다.
- 실제 표/목록이 없는 모음 기호 표제, 키배열의 두 `다음과 같다` 예고, 아랍 문자 유래 언어의 추가 문자 목록 표제·예고·고립 `-->`를 원형 보류했다. 변형 문자 설명 중 빠진 추가문자 목록을 직접 예고하는 문장도 분리했다.
- 아브자드 순을 외우는 방식의 빈 식 예고는 보류했다. 실제 언어명·문자명·숫자값·문자 코드포인트와 Unicode 구획은 원문 관계대로 보존했다.
- 필리핀 모로족만 남아 언어명이 소실된 언어목록 조각은 보류하고, 앞뒤의 실제 언어명은 유지했다. 문서의 다른 내용에 관한 사실검증은 하지 않았다.

## 원형 발췌

```text
단, 다음 6개의 문자는 앞의 문자와 연결되나, 뒤의 문자와는 연결되지 않는다. 예를 들어,  (아라라트)의 문자는 모두 독립형인데, ,  문자가 뒤의 문자와 연결되지 않기 때문이다.
```

```text
해 문자는 앞에 이 붙으면 이 묵음화 하며 대신 해 문자 스스로가 2중으로 발음된다.
```

여기서 빈 묵음 대상에 직접 기대는 앞 절만 보류했고, 뒤의 실제 해 문자 발음 관계는 본문에 보존했다.

빈 아랍 문자 포장만 정리해 본문에 보존한 원형 발음 예:

```text
 예) (샴씨야(툰)) → (앗샴씨야(투))
 예) (까마리야(툰)) → (알까마리야(투))
```

```text
다음에 아랍 문자의 목록을 소개한다.
```

본문에 보존한 다음 문장:

```text
28개의 기본 문자 외에, 특수 기호가 존재하며, 아랍어 외의 언어에서만 사용되는 변형된 문자가 있다.
```

원형 보류한 직접 예고와 빈 목록 자리:

```text
다음 문자들은 기본 문자에 포함되지 않고, 기본 문자의 변형으로 취급한다.
모음 기호
아브자드 순은 중간에 모음을 삽입하여,  식으로 외울 수 있다.
아랍 문자 유래 언어 추가 문자
다음 문자는 페르시아 문자, 위구르 문자 및 우르두 문자에서 추가된 문자들이다.
-->

맥 컴퓨터 자판 배열은 다음과 같다.
```

실제 순서 값이 빠진 원형 예고 구간:

```text
지역에 따라 조금씩 차이가 존재하나, 가장 일반적인 순서는 다음과 같다.(오른쪽에서 왼쪽 방향으로 읽는다)
```
