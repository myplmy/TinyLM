## 평탄화된 예제 및 직접 의존 안내

> Here is a simple "Hello, world" example web app for Tornado:
>
> import asyncio import tornado class MainHandler(tornado.web.RequestHandler): def get(self): self.write("Hello, world") def make_app(): return tornado.web.Application([ (r"/", MainHandler), ]) async def main(): app = make_app() app.listen(8888) await asyncio.Event().wait() if __name__ == "__main__": asyncio.run(main())
>
> This example does not use any of Tornado's asynchronous features; for that see this simple chat room.

## 문장 속 결손 조각

> kqueue (BSD/macOS), or

다른 시스템 이름은 추정하지 않고 `or`만 떼어 냈다. 실제로 명시된 `kqueue (BSD/macOS)`와 플랫폼 설명은 본문에 유지했다.

> is limited (Even though Tornado is built on supports Windows, Tornado does not use the APIs that are necessary for scalable networking on Windows).

Windows 실행 가능성·비공식 지원/권장 여부·기능 제한 및 확장성 제한이라는 완결 사실을 유지하고, 중간 선행 대상이 소실된 괄호 설명은 원형 보류했다.
