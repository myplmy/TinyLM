# 49325 원형 보류

본문에서 분리한 원문 구간:

- `systems may not support these system calls with buffers smaller than this`
- `The d_reclen entry may be used as an offset from the start of a dirent structure,`
- `[EBADF] The fd argument is not a valid file descriptor open`
- `[EFAULT] Either buf or basep point outside the allocated`
- `, or the current position pointer is`

첫 구간과 두 오류 조건은 문장이 끝나지 않아 미완 부분을 완결 설명처럼 본문에 두지 않았다. `d_reclen` 관련 두 줄도 다음 구조체로 가는 offset이라는 완결 관계를 제공하지 못한다. [EINVAL]의 앞선 디렉터리 조건과 `nbytes`가 디렉터리 항목 또는 항목 블록 반환에 너무 작다는 조건은 새 본문에 보존하고, 마지막 현재 위치 포인터 조건만 원형으로 분리했다. [EIO]의 완결 오류 조건, 함수 서명·반환값·버퍼 구조 설명도 새 본문에 보존했다. 누락된 단어·조건·동작은 보충하지 않았다.
