## 근거

그림 표지는 없어진 그림을 직접 지시하므로 표지만 분리했다. XMLSocket의 실제 `mySocket = new XMLSocket()` 호출, 이름 있는 connect/send/close 메서드와 이벤트·0 byte 조건은 입력에 명시되어 있어 본문에 유지했다. Java 예고·코드 안에는 미완 class/main 선언, 닫히지 않은 `BufferedReader` 생성, 제어 블록·괄호·본문이 없는 구조와 끝의 고립된 `catch`가 있다. 들여쓰기나 중괄호, 누락 인수, 반복문을 만들어 완결 예제로 바꾸지 않고 전체 코드 단위를 원형 보류했다. 뒤 bullet 설명은 이 손상 예제의 구체 단계와 루프/종료 동작을 직접 설명하므로 코드와 함께 보류했다. 그 주변의 완결된 socket/port 설명, 실제 endpoint 관계 bullet, Java 선택 이유는 보존했다. 페이지 계속 표시는 원형에 남겼고 새 본문에서 빠진 Java 예고·설명 경계와 함께 sidecar에만 보존한다. 코드를 실행하거나 Java 동작을 검증하지 않았다.
