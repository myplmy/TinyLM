# expanded_train:464168 — 댓글 좋아요 UI 및 Pingback 보류

원문 29·34행의 “LikeLiked by 1 person”과 40행의 “LikeLiked by 3 people”은 실제 댓글 뒤에 붙은 페이지 좋아요 UI입니다. 각 댓글 본문은 유지하고 해당 UI 행만 본문에서 분리했습니다.

원문 38행의 “Pingback: Tolkien Soup for the Nerdy Soul – ST. JUDE'S TAVERN”은 댓글 본문이 아니라 외부 사이트에서 들어온 Pingback/trackback 메타데이터이므로 원형과 위치를 보존해 분리했습니다.

인용문, Tolkien 작품 제목, 실제 댓글 발화, 댓글 응답, 작성자 표현은 지우거나 합치지 않았습니다. “Go to”가 포함된 본문 내 작품 링크는 실제 연결 제목을 포함하므로 그대로 남겼습니다.
