# 283342 원형 보류 범위

| 원문 조각 | 판정 근거 | 본문 처리 |
|---|---|---|
| `These functions are,` / `Each of the above PHP string extract functions differs with the arguments to be passed to these functions, type of data returned and etc. We can see about these in detail in the remaining part of this article.` | 예고된 함수 목록 자체가 없고 뒤의 문장이 그 소실 목록을 직접 받는다. 뒤의 상세 설명만으로 목록을 새로 생성하지 않는다. | 첫 설명 문장은 유지하고, 이 목록 예고와 목록 직접 참조만 분리했다. |
| `This fourth argument of this function is also optional, like end_limit. By default, internal character encoding would have been chosen, if nothing is specified for this argument.` | argument list가 없는 상태에서 특정 네 번째 인수의 optional/default 관계를 주장한다. 인수 이름을 추정하지 않는다. | 해당 문장 전체를 분리했다. mb_* prefix와 멀티바이트 처리에 관한 다른 명명 설명은 보존했다. |
| `This function includes the following arguments.` | 실제 argument list가 이어지지 않는 빈 목록 예고다. | 예고만 분리했다. 앞의 `preg_match()` 설명과 뒤의 완결된 호출은 유지했다. |
| `PHP print statement follows the preg_match() function call, and prints the following array as an output to the browser.` / `Array (  => Array (  => 4  => 48 ) )` | 배열 key/offset 표기가 소실되어 실제 출력 구조를 알 수 없다. 남은 4와 48에 새 key를 붙이지 않는다. | 출력 안내와 손상 출력 조각을 함께 분리했다. 바로 앞의 실제 preg_match 호출은 보존했다. |
| `Since we have sent the PREG_OFFSET_CAPTURE flag, the string match is returned by its offset as shown in the above output, that is, the number 4 is found in the 48th position of the given input string.` | 이 문장은 손상 출력에 직접 기대는 문구를 포함하지만, 뒤에 pattern/input/flag와 명시 값의 독립 관계가 완결되어 있다. | 원문에서 `as shown in the above output`만 제거하고, `4`와 `48th position` 설명을 원래 조건과 함께 보존했다. 값은 검산하지 않았다. |

`substr()`의 실제 prototype, positive/negative limit 설명과 완결 echo 예제, `preg_match()` pattern/input/flag가 있는 실제 호출, 댓글 두 건과 실제 댓글 표제는 본문에 보존했다. `mb_subsrt()`와 `mb_substr()` 원문 철자는 추정 수정하지 않았다.
