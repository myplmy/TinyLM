# 28500 원형 보류 기록

## 빈 별칭 슬롯

리드의 괄호에는 첫 별칭 슬롯이 비어 있으나 뒤에 실제 언어명과 표기가 채워져 있습니다. 빈 슬롯만 정리하고 언어명·실제 표기·조건을 보존했습니다.

```text
마르티니크(, 앤틸리스 크레올: Matnik 아니면 Matinik)
```

## 후보가 이미 분리한 빈 표제

원문에는 아래의 표제만 있고 해당 절의 본문이 없습니다. 후보가 이를 분리했으므로 본문에 되살리지 않습니다.

```text
인구
각주
```

## 보존 경계

완결된 역사·지리·정치·경제 설명과 실제 값, `같이 보기` 아래의 명명된 항목, 실제 외부 링크 명칭 및 분류는 유지합니다. 인구 자료나 별칭을 새로 만들지 않았고, 채워진 외부 링크 라벨을 일반 UI라고 간주해 제거하지 않았습니다.
