# expanded_train:43823 원형 보류

- 도입 원형 `피겨스케이팅(, )은`의 두 병기 슬롯은 비어 있다. 이름과 정의는 본문에 직접 완결되어 있으므로 새 본문은 괄호 포장만 제거하고 피겨스케이팅의 범위(개인·2인조·집단)를 그대로 보존했다. 빈 명칭을 추정하지 않는다.
- `싱글 스케이터 스파이럴`의 실제 목록 뒤 `페어 스케이터 스파이럴` 표제가 있으나 다음 `경기 형식과 채점` 전까지 해당 표제 아래 실제 항목은 없다. 표제 문자열만 이 sidecar에 보존하고 누락된 페어 스파이럴 항목은 만들지 않는다.
- 원문에만 있던 비어 있는 `각주` 표제는 후보가 제거했다. 이를 원형 기록으로 남긴다.

점프·스핀·리프트·스텝·경기 형식의 실제 정의/조건/값, 그리고 장비 범주별 실제 목록은 보존했다. 표제 결손을 근거로 주변 완결 설명을 삭제하지 않는다.
