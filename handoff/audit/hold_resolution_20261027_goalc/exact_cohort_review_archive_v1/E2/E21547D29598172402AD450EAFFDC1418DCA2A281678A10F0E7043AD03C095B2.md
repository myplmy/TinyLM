# 205351 원형 보류 메모

## 분리한 원형

- 리드 뒤의 빈 병기 슬롯: `( ,  )`
- 내용 없이 다음의 실제 외부 링크 목록을 예고하던 표제: `각주와 인용`

## 판정 근거

빈 병기 슬롯에는 연결할 별칭이나 값이 없다. 이를 삭제하고 앞 문장의 실제 PHP 기반 게임 설명만 보존했다. `각주와 인용`에는 항목이 없으며 다음에 실제 `외부 링크` 절과 게임물등급위원회 항목이 있으므로 빈 표제만 분리하고 외부 링크 정보는 유지했다. 빠진 별칭이나 인용을 만들지 않았다.

초기 후보와 원문은 이 두 지점에서 동일했다. 새 본문에는 두 빈 껍데기만 정리했고, 원래 EOF 개행이 없던 파일 끝에 개행을 추가했다.
