# expanded_train:1315229 보류 조각

후보는 원문과 바이트 동일이다. 아래 두 구간만 원형 보존했으며, parameter/결과를 임의로 고치거나 표를 생성하지 않았다.

- 시작 위치(`«Start»`)의 정의가 앞뒤에서 zero-based라고 명시된 가운데, 다음 문장은 `«Count»`에 0/1 위치값을 귀속해 서로 다른 역할을 섞는다. 어느 표현을 고르지 않는다.

```text
In specifying «Count», "0" represents the first member in the set, "1" the second, and so forth.
```

- 결과 표가 지정 본문에 없는 Table 1 참조와 캡션:

```text
our returned dataset would resemble that shown in Table 1.
Table 1: Results Dataset, with Subset() Defining Columns
```

  표에 대응하는 결과값을 채우지 않았다. 앞 문장의 실제 column/row 축 설정은 본문에 독립된 설명으로 보존했다. 표를 다시 가리키던 `as shown`도 제거했다.
