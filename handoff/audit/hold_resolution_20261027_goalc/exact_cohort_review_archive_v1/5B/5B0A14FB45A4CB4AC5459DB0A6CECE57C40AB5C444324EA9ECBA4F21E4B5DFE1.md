# 40239 원형 보류 구간

이 입력은 Python 초보자용 튜토리얼이다. 보류하는 것은 없는 화면·목록·예제에 직접 기대는 조각뿐이며, 원문 그대로 기록한다.

- `You should see something like this` — 실행 뒤 보여 줄 화면이 입력에 없다.
- `Here's a list of what those are.` — 예고된 기본 명령 목록이 없다.
- 원형: `One easy command is "print". So you can follow the example in the screen capture by typing: Print ("Hello world") and see what happens` — 화면 캡처를 가리키는 표현은 분리했다. 새 본문은 명령명과 실제 입력할 문자열을 남기고 화면 예고만 제외했다.
- `As you can see, it outputs a line of Hello world in the IDE.` — 없는 캡처를 직접 관찰하라는 문장이라 분리했다.
- `as you can see …` — Fractions 라이브러리 적재를 설명하는 문장 속 화면 포인터만 분리했다.
- `It's not much easier than that,` — 없는 캡처를 받는 비교 표현이라 분리하고, 실제 명령 `just type "import fractions."`는 본문에 유지했다.
- `If you want to browse around, here are the libraries of functions you can load in right now just like we did with "import fractions."` — 이 문장이 예고하는 라이브러리 목록은 입력에 없다.
- `Let's do our fraction addition now. Without over-explaining it, you can see how it goes below:` 및 이어지는 `Congrats again, you've written your second program.` — 설명·축하가 직접 가리키는 실제 분수 덧셈 예제가 없다.

화면이나 코드를 새로 만들거나 실행 결과를 추가하지 않았다. 날짜 섹션의 원문 설명, 변수에 관한 독립 문장, 다음 학습 경로와 실제 입력에 적힌 모든 텍스트는 본문에 남겼다.
