# expanded_train:854282 원형 보류

파일명/값이 빠져 직접 대상을 특정할 수 없는 조각만 보류했다. 복사 후 `install`이 대상 파일 목록을 쓴다는 동작은 보존하되 빠진 이름을 보충하지 않고 일반적인 `a file`까지만 남겼다. 이름이 비어 있는 두 번째 파일을 조건으로 삼아 그 파일 내용을 병합한다는 절은 의존 구간 전체를 보류했다. `install_default()` 단락의 `The argument is the value of MakeMaker's`도 어떤 MakeMaker 값인지 소실되어 그 한 조각만 보류했다.

보류 원형:
- `If there is another file named by\nthe contents of this file will be merged into the written file.`
- `The argument is the value of MakeMaker's`
