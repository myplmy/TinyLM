# expanded_train:32852 원형 보류

- 사이트 UI 조각: `[permalink] [id link]`는 내용 본문과 분리했다.
- 손상된 목록 조각: `Every and subset`, `Every and vector`, `Every and space`는 문장/표제 대상이 소실된 형태 그대로 보류했다.
- 누락된 지시 대상에 직접 의존하는 문장: `Every such subset has a smallest element, so to specify our choice function we can simply say that it maps each set to the least element of that set.` 앞의 집합 유형 표제가 `Every and subset`으로 손상돼 있어 이 문장도 보류했다.
- 결손 정의/대상: `Every separable metric space is isometric to a subset of C (), the separable Banach space of continuous functions → R, with the supremum norm.` 및 `Every vector v in determines a linear map from R to taking 1 to v, which can be thought of as a Lie algebra homomorphism.`는 빈 정의역·공역/함수 인자가 직접 필요해 원형 보류했다.
- 미완 관계식: `, where a norm and an inner product are said to be associated if for all x ∈ X.`는 연관 조건의 식이 빠진 직접 의존절로 원형 보류했다. 앞의 Hilbert space 완결 문장은 본문에 남겼다.
- 미상 J의 근거절: 원문 `Every finite-dimensional Hausdorff topological vector space is reflexive, because J is bijective by linear algebra, and because there is a unique Hausdorff vector space topology on a finite dimensional vector space.`에서 `because J is bijective by linear algebra`의 대상 정의가 없어 그 직접 근거절은 보류했다. 본문은 실제 명명된 결론과 유일 위상 주장을 사실 선택 없이 보존했다.
- 정리 범위: 완결된 다른 수학 문장, 조건, 용어와 Freenet 문장을 보존했다. 연속 사상의 괄호는 원문에 이미 있는 문장과 `i. e.` 설명을 유지하고 짝 없는 닫는 괄호 하나만 맞췄다. 누락 수식/변수/대상은 추정하지 않았다.
