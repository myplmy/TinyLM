# 34258 원형 보류 근거

- 제목 원형 `《선녀전설 세레스》()`의 빈 별칭 괄호는 후보가 제거했다.
- 원문에서 후보가 제거한 빈 괄호: `세레스()`, `츠카사 슈로()`, `미카기()`, `알렉산더 O 하우엘()`, `우라카와 유키()`, `츠카사 케이()`, `히로베 마야()`, `쿠루마 쇼타()`, `신구지 타츠조()`, `신구지 마이()`, `마사토()`, `아마쿠 미츠루()`, `쿠시마 사라()`, `미카게 미쿠()`.
- 후보에 남아 있던 실제 별칭 뒤 빈 괄호만 새 본문에서 제거했다: `미카게 아야(유나 벨몬드)()`, `토야(레온)()`, `아오기리 유우히(아론)()`, `아오기리 스즈미(마리아)()`, `쿠루마 치도리(제니)()`, `미카게 아키(유타 벨몬드)()`, `미카게 카가미(쥬스트)()`, `사하라 미오리(세라)()`. 각 실제 한국어 별칭은 그대로 보존했다.
- `오다 큐（()`는 값 없는 잘린 괄호 모양이므로 빈 괄호/포장만 제거하고 `오다 큐`라는 인명은 남겼다.
- 서로 다른 인물·작품·성우·화수·사건 설명과 외부 링크/분류는 원문대로 보존했다. 목록의 실제 반복 맥락을 중복으로 판정해 합치거나 삭제하지 않았으며, 빈 별칭을 추정하지 않았다.
