# 1399996 원형 보류 및 편집 경계

| 원문 조각 | 보류 이유 |
|---|---|
| `A unidirectional association is indicated like this:` | 바로 뒤의 그림/표현이 없다. 앞의 bi-directional 조건은 완결되어 본문에 남겼다. |
| `There is only one right way to draw this:` | 뒤의 도형이 없는 채 그림에 대한 단정만 남은 포인터다. 동물 분류의 실제 예와 계층 설명은 보존했다. |
| `To show this with an example: Suppose you want to create two classes for vehicles which are horse-drawn.` | 구체 예를 예고하지만 실제 두 클래스나 설명이 이어지지 않는다. 앞뒤의 독립적인 상속 설명은 남겼다. |
| `And example of multiple inheritance is shown below. Also notice how the functions are displayed in this model.` | 이 지점의 다중 상속 도형/함수 배치 예시가 없다. 뒤에 실명으로 채워진 Griffin, Lion, Eagle, `eatMeat()`, `roar()`, `squawk()`, `fly()` 설명은 유지했다. |
| `Without virtual inheritance` / `With virtual inheritance` | 문맥상 빠진 도형의 독립 캡션이다. 다음 본문에 실제로 적힌 With virtual inheritance의 Griffin/Animal 관계는 보존했다. |
| `First of all, you draw the class itself:` | 빈 클래스 도형을 직접 예고한다. 이어지는 CFloatPoint, x/y, float, Empty()와 0.00000 정보는 보존했다. |
| `As you can see, x and y are both private (lock-sign) and have the type "float".` | `As you can see`라는 빠진 그림 포인터만 제거했다. x/y의 private 조건과 float 값은 본문에 남겼다. |
| `Now, we want to make the function Empty() visible in the model:` | 기능 도형의 결과가 제공되지 않는 시각 단계 예고다. Empty() 이름과 reset 관계는 앞 문장에서 보존했다. |
| `which looks like this:` | note 그림이 없는 직접 포인터다. 추가 class information을 note에 넣을 수 있다는 완결 설명은 본문에 남겼다. |

새 클래스·메서드·도형 내용은 만들지 않았다. 명명 관계·분류·조건·값 및 남은 독립 본문은 원문대로 보존했다.
