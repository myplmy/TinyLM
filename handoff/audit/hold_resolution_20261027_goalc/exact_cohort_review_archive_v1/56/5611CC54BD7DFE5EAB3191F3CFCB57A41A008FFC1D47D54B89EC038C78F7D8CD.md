## 닫힘/반환부가 빠진 C#·VB.NET 함수 예제

> private static string ReverseString(string input)
> string output = string.Empty;
> char chars = input.ToCharArray();
> for (int i = chars.Length - 1; i >= 0; i--)
> output += chars[i];
> Private Shared Function ReverseString(ByVal input As String) As String
> Dim output As String = String.Empty
> Dim chars As Char() = input.ToCharArray()
> For i As Integer = chars.Length - 1 To 0 Step -1
> output &= chars(i)

두 언어의 코드 단위 모두 반복/함수 종료 부분이 없어 완결 실행 예제로 둘 수 없다. 누락한 괄호·`Next`·반환 구문을 추측해 추가하지 않았다. 본문에는 채워진 함수명, 매개변수 설명, `ToCharArray` 이름, 역순 순회·문자 추가·반환에 대한 완결된 자연어 설명을 유지했다.

## 닫힘이 빠진 ASP.NET 이벤트 처리기 조각

> protected void Reverse(object sender, EventArgs e)
> lblReverseString.Text = ReverseString(txtName.Text);
> Protected Sub Reverse(ByVal sender As Object, ByVal e As EventArgs)
> lblReverseString.Text = ReverseString(txtName.Text)

각 이벤트 처리기에는 본문이 있어도 언어별 블록 닫힘이 보이지 않아 코드 예제로는 분리했다. 채워진 TextBox/Button/Label 마크업·`OnClick="Reverse"` 연결과 본문 설명은 완결되어 본문에 보존했다.
