# 603415 별도 보류 원형

원문/후보 동일성은 자기 TASK_049 연결에 따른다. 아래는 소실된 code/example 및 끊긴 link를 직접 가리키는 원형이다.

| 원문 위치 | 원형 | 처리 근거 |
|---|---|---|
| `Executing Other Files` 설명 뒤 | `// Do some stuff...`<br>`The above script will "do some stuff" and then execute the file another.rex (if the base directory property is unmodified this will be called from the same directory as the original script.` | 실제 `REX::ExecFile()` 호출이 없는 placeholder를 특정 스크립트의 실행으로 해설하는 조각이다. 앞 문장의 완결된 API/상대 경로 설명은 본문에 유지했고, `another.rex` 실행이나 그 예시 결과를 만들지 않았다. |
| variable-stack 설명 뒤 | `The above code will set my_variable to be "hello" and then echo it back in the output.` | 가리키는 code block이 없다. `my_variable`/`hello`와 결과의 관계를 새 코드로 복원하지 않았다. |
| 마지막 부분 | `To see more detail on this and also the environment variables please see the`<br>`A good example showing use of variables is the counter example (available from the examples page` | 문장과 링크 참조의 끝 대상/URL이 소실됐다. |

본문에는 PHP/REX file 조건, global scope, `$REX`, `REX::ExecFile()`의 명명된 상대 경로 관계, REX 변수 stack/environment 설명과 `REX::Set()`/`REX::Get()` 이름을 보존했다. 호출이나 변수값을 만들어 채우지 않았다.
