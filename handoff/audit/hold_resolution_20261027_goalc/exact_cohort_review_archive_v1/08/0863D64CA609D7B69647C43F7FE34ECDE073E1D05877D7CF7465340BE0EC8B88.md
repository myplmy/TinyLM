# HOLD 1413085

본문에서 정리한 원문 조각:

> If the font shall be embedded the file the font outline must be present as well.

이 문장에는 조건부 결론 사이에 `the file`이라는 고립 조각이 있어 이를 sidecar에 원형 보존하고 새 본문에서는 제거했습니다. 조건 “If the font shall be embedded”와 “the font outline must be present as well”는 그대로 연결해 보존했습니다. 함수명, 인수 설명, encoding 조건, `.pfb` 확장자와 반환 설명은 바꾸지 않았고 외부 API 검증은 하지 않았습니다.
