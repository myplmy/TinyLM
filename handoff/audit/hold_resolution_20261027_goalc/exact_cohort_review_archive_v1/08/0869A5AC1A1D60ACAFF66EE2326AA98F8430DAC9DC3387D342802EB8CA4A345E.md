# expanded_train:33935 식·축·값이 없는 구간의 원형

후보는 원문과 동일했다. 이 보류는 빈 수식의 값을 만들지 않고, 그 식을 직접 지시하거나 그 변수·값 없이는 의미를 정할 수 없는 문장만 분리한다. 완결된 서술 관계와 원문이 명명한 예시 이름은 새 본문에 보존했다.

## 빈 이름 슬롯

`홀함수()`와 `짝함수()`의 괄호 안 값은 비어 있다. 새 본문에서 괄호만 정리했으며 별칭이나 기호를 추가하지 않았다.

## 수식·정의 의존 원형

- `실수 함수 의 정의역 가 를 만족시키는 구간이라고 하자.`
- `만약 임의의 에 대하여 라면, 를 홀함수라고 한다.`
- `만약 임의의 에 대하여 라면, 를 짝함수라고 한다.`
- `이는 항상 이기 때문이다.`
- `예를 들어, 은 이므로 홀함수도 짝함수도 아니다.`
- `홀함수는 다음과 같은 꼴의 함수와 동치이다.`
- `짝함수는 다음과 같은 꼴의 함수와 동치이다.`
- `이는 다음과 같다.`
- `짝함수 의 집합은 -대수를 이루며, 홀함수 의 집합은 -벡터 공간을 이룬다. 함수 의 공간은 이들의 직합이다.`
- `어떤 함수가 짝함수의 필요 충분 조건은, 그래프가 축에 대하여 대칭인 것이다.` — 어떤 축인지 입력에 없다.
- `홀함수 의 적분은 다음과 같다.`
- `짝함수 의 적분은 다음과 같다.`
- `즉, 다음과 같은 꼴이다.` — 앞 문장의 각 푸리에 급수 식 예고에 붙은 빈 식 포인터.
- `즉, 다음과 같은 꼴이다.` — 두 번째 푸리에 급수 식 예고의 빈 포인터.

## 값 없는 예시·링크 영역

`홀함수의 몇 가지 예는 다음과 같다.` 아래 및 `짝함수의 몇 가지 예는 다음과 같다.` 아래에는 실제 함수식이 없다. 원문에 실제로 적힌 항등 함수·홀수차 멱함수·사인·쌍곡선 사인·오차 함수와 상수 함수·짝수차 멱함수·절댓값·코사인·쌍곡선 코사인·가우스 곡선이라는 이름 및 예시 목록 관계는 새 본문에 유지했다. 식을 새로 만들지 않았다.

원문의 `외부 링크` 표제와 그 아래 빈 링크 슬롯은 새 본문에서 분리했다. 링크 주소를 추가하지 않았다.
