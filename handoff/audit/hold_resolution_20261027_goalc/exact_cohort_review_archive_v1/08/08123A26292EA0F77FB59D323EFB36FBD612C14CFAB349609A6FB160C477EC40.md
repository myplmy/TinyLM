# 207894 — 결손 문장·출력 포인터 원형

## 문자열 첫 항목의 빠진 인덱스

> The first character in string s would be s and the nth character would be at s[n-1].

`The first character in string s would be s`에는 인덱스 관계가 들어 있지 않다. 이를 채우지 않았고, 원문에 실제 있는 뒤 절 `The nth character would be at s[n-1].`은 본문에 보존했다.

## 값이 없는 출력 예고

> Outputs (assuming the errors were suppressed):

직전 코드/오류 뒤에 출력값이 이어지지 않아 이 예고만 보류했다. 실제 traceback, 문자열 코드·출력값, 수식·조건, 색인 구조와 연습문제는 원문대로 유지했다.
