# expanded_train:147924 원형 보류

- 첫 문단의 “This however creating a game using can be a challenge for beginners.”는 핵심 연결어/목적어가 손상된 문장입니다. 다음 “This is partly because...”와 “On the other hand...” 두 문장도 이 누락된 도전 과제에 직접 의존하므로 함께 원형 보류했습니다. 나머지 Flash의 용도/시각 효과 설명은 보존했습니다.
- 27행의 “found here”는 링크 대상으로 삼을 자료가 보이지 않습니다. 문장에 직접 명시된 “This tutorial is a continuation of the first Flash artillery game tutorial”와 이어지는 상호작용 설명은 본문에 남기고, 링크 표식 두 단어만 분리했습니다.

나머지 완결된 개별 게임 튜토리얼 설명과 주제·게임명·수치·조건은 유지했습니다. 누락 제목/링크 대상을 추정해 채우지 않았습니다.
