# 814 원형 보류 메모

선택 본문은 스칼라곱의 실제 용어와 완결 설명, 2×2 수치 예시, 내적 성질의 서술, 스칼라 사영의 역할, 코사인 법칙의 일반 관계, 삼중곱의 명명된 설명, 물리학 응용 및 함수/행렬 내적의 채워진 설명을 유지한다. 식·변수·공간 차원 표기·각도 범위는 새로 만들지 않았다.

- 빈 별칭 슬롯: `스칼라곱(scalar곱, )`, `점곱()`; 실제 표기 `scalar곱`과 `점곱`만 남기고 빈 괄호를 정리했다.
- 정의에서 차원·공간·두 벡터·내적 기호를 비워 둔 두 정의의 동치 주장은 보류했다. 가운뎃점의 실제 표기/생략 규칙은 독립 문장으로 보존했다.
- 대수적 예시의 빈 좌표 및 식, 열벡터 전치형 식, 전치 대상 설명과 앞선 예시를 직접 가리키는 식 표기는 원형 보류했다. 같은 위치 성분을 곱해 합한다는 완결 설명과 임의의 정규 직교 좌표계에서의 실제 산문은 보존했다.
- 기하 설명의 원문 `여기서` 및 빈 노름/벡터/각도 기호, 비영벡터 조건 뒤의 빠진 각도 범위는 보류했다. 노름의 길이 의미, 비영벡터 각도 조건, 코사인의 실제 언어 정의와 길이 2·코사인 1/2인 수치 예시는 유지했다.
- 빈 각 조건/식이 있는 세 번째 반대 방향 예시와 각도 공식 예고는 보류했다. 같은 방향일 때 길이 곱, 서로 수직일 때 0이라는 원문 속 완결 자연어 관계는 유지했다.
- 교환·좌우 분배·스칼라 곱 보존의 실제 성질 이름은 유지하고 빈 수식 슬롯은 보류했다. 자기 자신/영벡터에 관한 완결 서술은 유지했다. 값·벡터 이름이 빠진 세 필요충분조건과 결합법칙/소거법칙의 직접 수식 예시는 원형 보류했다. 두 법칙의 문장상 명시된 1차원 예외 및 성립하지 않는다는 주장 자체는 유지했다.
- 스칼라 사영/코사인 법칙의 빈 식 및 그림을 직접 가리키는 부분, 삼중곱의 실제 정의식은 보류했다. 이름이 채워진 역할·조건의 완결 산문은 유지했다.
- 복소수 곱공간의 빈 차원/벡터와 정의식, 켤레전치 대상·복소켤레 대상, 양의 정부호성 및 대칭성 수식, 변수 조건, 각도식, 누락 식에 직접 의존하는 켤레 생략 논증은 보류했다. 복소수 곱공간에서 유사 함수를 정의한다는 완결 도입은 남겼다.
- 실수/복소 내적의 실제 성질 서술은 보존하고, 빈 공간·벡터 표기와 함수 예시의 식 도입은 정리했다. 실숫값/복소숫값 함수 내적의 적분/성질 관계와 실수 행렬 프로베니우스 내적의 성분합·대각합/행렬곱 관계는 완결 서술로 남겼다. 빈 복소 행렬 식 및 대상 없는 켤레전치 설명은 원형 보류했다.
- 링크 항목 없이 남은 `외부 링크` 표제는 정리했다.
