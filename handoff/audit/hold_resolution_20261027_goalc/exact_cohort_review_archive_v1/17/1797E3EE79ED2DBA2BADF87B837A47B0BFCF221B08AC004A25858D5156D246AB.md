# expanded_train:233144 보류 구간

원문 조각을 원형 그대로 보류했다:

- `If not logical, must be the same length as the` — 길이 비교 대상이 없음.
- `of the` — 축의 위치 설명 끝에서 대상이 빠짐. 바로 앞의 실제 bottom/top 값 설명은 본문에 남김.
- `(or` — `A Grid viewport object`는 실제 명명된 설명이므로 본문에 보존하되 뒤의 대안 값은 만들지 않음.
- `at slot of an xaxis grob is not`부터 `and ticks are drawn based on the current viewport scale.`까지 — 조건/값이 끊긴 슬롯 상태와 그에 의존하는 children 목록 및 NULL 결과 설명이다. 누락된 슬롯 값·조건을 추정하지 않고 원문 전체를 sidecar에 남김.
- `, but only`와 이어지는 `draws the xaxis (and then only if` — 빠진 함수 주체와 조건을 새로 채우지 않음.

서명 두 개와 실제 명시된 x-axis/gpar/viewport 정의는 본문에 남겼다. 설명문은 순서대로 보존하되 어떤 매개변수 이름에도 새로 연결하지 않았다.
