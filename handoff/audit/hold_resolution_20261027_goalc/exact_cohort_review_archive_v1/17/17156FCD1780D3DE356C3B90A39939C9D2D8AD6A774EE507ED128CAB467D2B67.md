# 894423 — 빈 괄호 포장과 미완 문장 꼬리 보류

선택 본문: `reviewed_894423_task066_v2.txt`

| 원문 위치 | 원형 보류 | 이유 |
|---|---|---|
| 문자열 조건 항목 | `- Is not the empty string (` | 조건의 의미는 채워져 있어 본문에 `- Is not the empty string`으로 보존했다. 닫히지 않은 여는 괄호와 그 뒤의 실제 빈 문자열 표기 슬롯만 원형으로 남겼으며 표기값은 만들지 않았다. |
| 마지막 문장 꼬리 | `when the string is` | 검사 순서와 short-circuit에 관한 완결된 앞 문장은 본문에 남겼다. 문장 끝의 미완 조건만 분리했다. |

.NET 4.0, 실제 `String.IsNullOrWhiteSpace`/`String.IsNullOrEmpty` 비교식, `String.Empty`, null·빈 문자열·공백 조건은 원문 그대로 보존했다. 코드 실행이나 API 교정은 하지 않았다.
