# 1174083 보류 원형

- 빈 코드 블록을 가리키는 프롬프트/예고와 해당 스크립트만을 대상으로 하는 설명을 분리했다. 원문에는 `...this equates to:`, 한 줄-한 단계 대응 설명, `Capturing the return value from curl_exec() looks like this in code:`, 저장 파일 코드 도입, HTTP→FTP 예제 도입·비교, 두 FTP 옵션 적용 코드 예고, 임의 사용자명/암호의 실행 결과 및 최종 FTP 코드 평가, `posttest.php` 파일 코드·신규 스크립트 도입, 누락된 POST 코드의 `localhost` 치환 안내, 미제공 응답 예고와 출력 후 평가가 있다.
- 한 줄-한 단계 대응 문장은 누락된 스크립트의 관계를 설명하므로 분리했지만, 그 안에 명시된 완결 코드 `$curl = curl_init();`는 본문에 그대로 보존했다.
- 실행 실패 상황에만 의존하는 `This is because Curl fails silently...`는 분리했다. 별도 문장으로 원문에 명시된 `curl_error()`의 인자와 반환 설명은 보존했다.
- 완결된 함수/옵션 설명과 값은 보존했다: `curl_init`, `curl_setopt`, `curl_exec`, `curl_close`, `CURLOPT_URL`, `CURLOPT_RETURNTRANSFER`, `CURLOPT_FILE`, `fopen`, `CURLOPT_FTPLISTONLY`, `CURLOPT_USERPWD`, `curl_error`, `CURLOPT_POST`, `CURLOPT_POSTFIELDS`, `urlencode`, 그리고 값 `Hello`, `Foo`, `Baz`, `World`, `Bar`, `Wombat`. 빠진 PHP/Curl 코드는 복원하지 않았다.
