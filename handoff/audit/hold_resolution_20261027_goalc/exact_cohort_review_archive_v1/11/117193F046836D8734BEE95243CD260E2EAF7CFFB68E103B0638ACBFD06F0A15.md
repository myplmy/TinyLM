# TASK_010 산출물 경계 수정 기록

expanded_train_231730_revised_task010_v1.txt는 첫 sed 명령에서 표 머리의 세로선에 역슬래시를 붙여 GNU basic regular expression의 alternation으로 해석되게 작성한 결과이며, 지정 candidate를 비우는 결과가 되었다. 해당 파일은 보존하며 선택 산출물로 사용하지 않는다. 같은 지정 candidate에서 두 빈 표 행만 제거하는 새 전문 expanded_train_231730_revised_task010_v2.txt를 작성했다. 후속 리뷰는 review_010_v2.md를 선택하도록 한다. 원문 후보 입력은 다시 지정된 정확 경로에서 판독한 내용 그대로이고 기존 파일을 수정하거나 삭제하지 않았다.
