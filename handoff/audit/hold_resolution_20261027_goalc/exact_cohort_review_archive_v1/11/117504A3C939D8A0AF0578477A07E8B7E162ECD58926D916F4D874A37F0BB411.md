# 1197997 보류 원형

- 원문의 `atime`, `mtime`, `ctime` 설명 뒤 각각 붙은 빈 괄호 `()`는 값이나 의미가 채워져 있지 않다. 해당 빈 슬롯은 원형 그대로 여기에 보존하며 내용을 추정하지 않는다. 본문에서는 값 없는 괄호 껍데기만 제거했다.
- 원문 서두의 두 `stat()` 함수 표기는 지정 후보에서 `stat`으로 바뀌어 있었다. 이들은 일반 명사가 아니라 실제 시스템 호출 이름이므로 선택 본문에 `stat()` 표기를 복구했다. 함수 선언, `stat()`/`lstat()`/`fstat()` 서명과 실제 C 예제는 그대로 유지했다.
