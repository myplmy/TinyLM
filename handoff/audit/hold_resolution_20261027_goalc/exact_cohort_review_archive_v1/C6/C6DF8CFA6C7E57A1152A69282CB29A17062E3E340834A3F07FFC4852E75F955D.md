# 216309 보류 메모

- 원형 보존: 본문 뒤에 있던 다음 네 줄.

```text
by Ovidiu Mățan
by Călin Biriș
by Ovidiu Mățan
by Ovidiu Mățan
```

본문은 Test Driven Development와 incremental design 설명으로 이어지고, 이 네 행 앞에 별도 제목이나 각 행을 특정 글에 연결하는 표시가 없다. 이름들을 하나의 공동 저자 목록 또는 해당 글의 저자로 새로 귀속하지 않는다. 후보에서 빠진 원형 byline 묶음을 이 sidecar에 보존한다.

- 별도 검토 요청: 본문 말미의 `Incremental design means creating the design while the code is written ...` 반복 요약 조각은 앞선 설명과 일부 겹치지만, 별도 추천/요약 항목인지 추출 중복인지 경계가 미확정이다. 원문을 이 sidecar에 추가 보류 처리했다고 주장하지 않는다.
