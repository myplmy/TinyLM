# 134727 빈 병기 괄호 정리

검토 범위: `TASK_014.md`에 지정된 원문·후보의 전체 본문, 2개 연속 패킷, 전체 diff와 논리 END/실제 EOF.

후보 본문에는 다음 이름 뒤에 값이 없는 `()` 포장이 남아 있었다.

- `안세이 대옥()` / `이이 나오스케()` / `무오의 대옥()`
- `마나베 아키카쓰()` / `히토츠바시 파()`
- `도쿠가와 요시카쓰()` / `마쓰다이라 요시나가()` / `도쿠가와 나리아키()` / `히토쓰바시 요시노부()` / `도쿠가와 요시아쓰()`

새 본문에서는 빈 괄호만 제거했다. 인명·사건명·날짜·행위·수량·관계는 그대로 두었고, 괄호 안 별칭은 만들지 않았다. 원문 문장 구조를 바꾸거나 외부 사실을 확인하지 않았다.
