# 401638 보류 원형

| 원문 구간 | 보류 근거 |
|---|---|
| `If you do not want this behavior you can call the following functions.` | 언급한 함수 목록이 실제로 없다. |
| `This will instantly teleport the camera to the new location. With these basic controls you can program the camera to do specifically what your game requires. If you need even more control, see Advanced Camera Control below.` | 바로 앞의 누락 함수들을 받는 결과·효과 설명과 그 직접 지시다. 호출·기능을 추정하지 않는다. |
| `An example of how this can be used is below:` | 이 예고가 받는 코드는 불완전하므로 이 직접 지시를 함께 분리한다. |
| `cameraMap = EventMap.new() cameraMap:setEvent("keyPress-rightMouse",function() Camera.beginRotate(100) end) cameraMap:setEvent("keyRelease-rightMouse",function() Camera.endRotate end) EventHandler.push(cameraMap)` | 원형에는 `Camera.endRotate` 호출 괄호가 없고, 이를 추가해 호출로 바꾸지 않는다. |
| `This example will wait for the right mouse, then have the Camera track the mouse and orbit as long as the right mouse is held down. Combine this with the previous functions and you have the camera controls that are used in the builder.` | 위의 불완전한 `cameraMap` 예제의 동작과 결과를 직접 주장한다. |
| `If you have a SceneObject foo, you can use the above commands to have the camera always keep foo in the center of its vision. If you just use these commands the cameras eye will not move, but only turn towards the object. If you would like the camera to stay within a certain distance of the object you can call the following.` | 받는 “above commands”와 다음 거리 설정 함수가 이 구간에 없다. |
| `Now the camera will move to always stay 10 meters away from the object. If you want to constrain the heading or the pitch at which the camera stays you can call the following.` | 소실된 함수의 대상·인수·호출 관계에 직접 의존한다. |
| `This will tell the camera to always maintain a global heading of 90 degrees and a pitch of 30 degrees. Passing nil to any of the above 3 functions will remove their constraint.` | 소실된 세 함수와 연결된 결과·조건이다. 수치와 관계를 새 코드로 재구성하지 않는다. |
| `In order to make 3rd mode a lot simpler there is a single function that will set up everything for you.` | 예고된 함수가 없다. |
| `The above function will automatically put the camera in 3rd Mode and tell it to follow the object foo at a distance of 10, with no constraint to heading and to maintain a 30 degree pitch.` | 누락 함수가 직접 지시 대상이다. |

본문에는 실제 `eye`/`focus` 정의, Camera의 명시된 조건, `beginRotate`/`endRotate` 일반 동작 설명, 완결된 `fpskeymap` 호출 및 `setSpeed` 설명을 남겼다. `Camera.endRotate`에 괄호를 보충하거나 빠진 3rd-mode 함수를 만들지 않았다.
