# expanded_train:3932 원형 보류 기록

원문과 후보에는 Point/Hashtable 설명, 두 해시 출력 사례, Object의 ReferenceEquals() 역할 설명이 남아 있습니다. 다만 이 자료에는 이를 지시하는 코드 블록이 없습니다. 코드에서 `line 2 & 4`를 가리키던 위치 정보와, 특정 코드를 가리키는 “below/like this” 예고만 분리했습니다. 소실 코드의 내용이나 Point 정의를 새로 만들지 않았습니다.

원형에서 보류한 구절:

- `So let assume that we have class like this:` — 뒤따라야 할 Point 클래스 예제가 없습니다.
- `In the code bellow we have two identical keys (line 2 & 4). We should expect ArgumentException.` — 실제 코드와 줄 번호 대상이 없습니다. 남은 본문에는 “There are two identical keys, so we should expect ArgumentException.”로 명시된 중복 키 주장과 기대 결과만 보존했습니다.
- `Try to execute code bellow:` — 예고한 코드가 없습니다. 바로 뒤의 실제 출력값과 그 해시 비교 설명은 보존했습니다.
- `First we override Equals() method:` — 뒤따라야 할 메서드 코드가 없습니다.
- `Next we override GetHashCode() method:` — 뒤따라야 할 메서드 코드가 없습니다.
- `The whole Point would look like this:` — 완성 Point 코드가 없습니다.

`You can see that I use ReferenceEquals() method that is static method of Object class. It checks if the specified objects are the same.`는 누락 코드에 대한 “I use” 지시를 떼고, 실제로 적힌 API명·Object 소속·정적 메서드 역할·설명을 독립 문장으로 유지했습니다. 두 출력 블록과 그 뒤의 결과 주장은 남겼습니다. 외부 사실검증이나 코드 실행은 하지 않았습니다.
