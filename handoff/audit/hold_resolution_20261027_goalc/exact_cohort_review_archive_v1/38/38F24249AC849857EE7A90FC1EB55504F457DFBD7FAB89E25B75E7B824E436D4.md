# 1434925 원형 기록

두 호출 사례 원문:

`In contrast, having the caller invoke send twice to send the same data:`
`Results in 2 TCP segments, both having 1000 bytes of payload, and both having the PSH bit set.`

호출 예제 코드는 실제 입력에 없어서 생성하지 않았다. 위 두 문장을 한 문장으로 연결해 저자가 이미 명시한 send 2회, segment 수, 각 payload 1000 bytes 및 PSH 조건을 보존했다. 또한 line 4의 원문은 `...see also "Can HTTP Request Smuggling be blocked by Web Application Firewalls?".` 형태로 괄호가 닫히지 않았다. 의미를 바꾸지 않도록 문장부호만 `...").` 순서로 닫았다. RFC 번호·날짜·TCP 수치·조건·기술 주장은 외부 검증/갱신 없이 유지했다.
