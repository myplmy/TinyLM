# expanded_train:624686 — 보류한 광고·누락 주어·그림 표식 원형

본문에서 다음 광고 문구를 분리했다.

> Optimize with a SATA RAID Storage Solution
> Range of capacities as low as $1250 per TB. Ideal if you currently rely on servers/disks/JBODs

Java object cloning 설명과 관계없는 SATA RAID 가격/구매 안내다.

다음 도입 조각은 지정 입력 그대로 기록한다.

> Cloneableinterface and override its
> clone()method in order to make a deep copy of itself as well as its contained objects.

주어·공백이 손상된 채 시작하고 clone()의 대상/클래스도 이 문장에는 없다. 이어지는 독립 설명은 보존했으며 클래스명·메서드 관계를 새로 만들어 채우지 않았다.

그림에만 직접 의존하는 원형:

> To illustrate, Figure 1 shows
> obj1, that contains two objects,
> Figure 1. The original state of obj1
>
> If a shallow copy is performed on
> obj1, then it is copied but its contained objects are not, as shown in Figure 2.
> Figure 2. After a shallow copy of obj1
>
> A deep copy occurs when an object is copied along with the objects to which it refers. Figure 3 shows
> obj1 after a deep copy has been performed on it. Not only has
> obj1 been copied, but the objects contained within it have been copied as well.
> Figure 3. After a deep copy of obj1

본문에는 그림 pointer/caption만 분리하고, 원문이 실제로 적은 `obj1`의 두 contained objects, shallow copy에서 contained objects는 복사되지 않는 관계, deep copy에서 포함된 objects도 복사된다는 관계를 문장으로 보존했다. 이후의 독립적인 clone() 설명·Vector 예시는 유지했다.
