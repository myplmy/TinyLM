# expanded_train:139240 원형 보류 메모

- 지정 원문·candidate와 순서 패킷 1–4를 판독했다. 패킷 4에서 candidate 논리 END, full_diff END와 실제 EOF를 확인했다. full_diff에는 본문 줄 차이가 없었다.
- 첫 문장의 `퍼사드( ) 패턴(외관 패턴)`에서 빈 괄호 슬롯만 제거해 `퍼사드 패턴(외관 패턴)`으로 두었다. 실제 한국어 명칭, `외관 패턴`, 영어 `Facade (외관)`와 그 뜻풀이, 패턴의 설명은 유지했다.
- Java 및 C# 예제, 클래스/메서드명, 실제 본문 설명과 조건을 변경하거나 실행 가능 코드로 재구성하지 않았다. `그림에 나오지 않은 그 밖의 응용 프로그램 코드`는 누락 그림의 내용을 채우는 포인터가 아니라 원문에 완결된 상호작용 설명의 범위 표현이므로 보존했다.
- Portland Pattern Repository, Net Objectives Repository, Jt J2EE Pattern Oriented Framework라는 실제 표기 외부 링크 라벨과 `소프트웨어 디자인 패턴` 분류를 유지했다. 링크 주소는 생성하거나 확인하지 않았다.
