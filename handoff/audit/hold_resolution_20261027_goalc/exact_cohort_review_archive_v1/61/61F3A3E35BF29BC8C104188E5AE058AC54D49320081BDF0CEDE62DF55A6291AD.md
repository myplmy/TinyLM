# 670000 원형 보존 메모

## 빈 괄호 포장

원문 말라카 해협 주석은 다음과 같다.

```text
랑카위섬 () 바로 동쪽을 지나감 피낭섬 () 바로 서쪽을 지나감
```

랑카위섬·피낭섬과 각각의 실제 방향 설명은 본문에 유지하고 빈 `()` 포장만 분리한다. 좌표를 추정하지 않는다.

## 미상 영유권 주장 주체

원문 남극 행 주석은 다음과 같다.

```text
오스트레일리아령 남극 지역, 가 영유권을 주장한다.
```

실제 지명 `오스트레일리아령 남극 지역`을 본문에 보존하고, 빠진 주장 주체가 필요한 관계절은 여기 원형대로 보류한다.

## 판독 범위

지정 original/candidate 전문과 순서 패킷 0001을 BEGIN부터 END/EOF까지 대조했다. candidate 전체 diff는 줄 차이가 없었다. 반복 카라해·타이만·인도양 표제, 여러 지역의 실제 이름·반복 순서와 표 구조는 보존하고 빈 괄호/미상 관계절만 분리했다.
