# expanded_train:463199 원형 보류

후보가 원문과 동일하므로 새 본문에서는 그림 대상이나 다음 항목이 없는 시각·탐색 포인터만 분리했다.

- `So we can see in the above screenshot that the file size is 1.10MB.` 그림 자체를 보지 않고도 문장 안에 제시된 크기 1.10MB는 본문에 `The file size is 1.10MB.`로 남겼다. 삭제한 부분은 없는 screenshot을 가리키는 표현뿐이다.
- `Click the image in the worksheet and then activate the ‘Format’ ribbon as follows.` 지시된 조작은 `Click the image in the worksheet and then activate the ‘Format’ ribbon.`으로 보존하고, `as follows` 포인터만 정리했다.
- `On doing this, a new pop-up window will appear as below:` 팝업이 열린다는 문장은 보존하고, `as below`만 정리했다. 이어지는 96 ppi와 compression options의 실제 명칭·선택 조건은 전부 유지했다.
- `Click on the ‘Home’ tab and then expand the ‘Clear’ dropdown in the ‘Editing’ section as below.` 실제 Home/Clear/Editing 조작을 보존하고, `as below`만 정리했다.
- `You can also go through our other suggested articles –`는 뒤에 제목·본문·링크가 없는 이동 CTA여서 분리했다. 앞의 Reduce Excel File Size 가이드 설명과 실제 파일 형식·수치는 유지했다.

이미지나 링크의 내용을 추정해 추가하지 않았다. 나머지 다섯 예제의 구체 절차, 값, 조건, 키 입력 및 volatile 함수 이름은 그대로 두었다.
