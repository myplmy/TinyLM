# 1439165 원형 보류 — 빈 figure 포인터

- 원형: `Let’s consider the following figure:` — 본문에 그림이 없어서 시각자료 예고만 분리했다.
- 원형: `As we can see here,` — 같은 그림을 직접 가리키는 지시어만 분리하고, 뒤의 시간창 설명은 `We keep sliding the time-window ...`로 이어 독립 보존했다.

실제 창 길이 5초/슬라이드 2초, 예시의 15초/6초, 나라 코드, 함수/API 이름, 실제 Spark 명령과 코드 표기는 그대로 유지했다. 예제는 실행하지 않았고 빠진 인자/기호를 외부 지식으로 보정하지 않았다.
