## 손상된 Python 코드 예제

예제의 여러 문장/출력 호출이 줄바꿈 없이 합쳐져 있고 `#` 주석이 뒤의 명령을 흡수한다. 코드 구조를 추정 복구하지 않고 네 원형 블록을 그대로 보존한다. 본문에는 `zip()`/`np.array()`/`reshape()`의 완결 산문 설명, 함수명, 매개변수와 명명된 결과값을 유지했다.

### sample list

```text
oneD_list = ["Nduka", "Larry", "Chichi", "Leslie", "Donna", "Taiwo"] print(type(oneD_list)) # <class 'list'>
```

### zip() example

```text
twoD_list = [list(x) for x in zip(oneD_list[0::2], oneD_list[1::2])] print(twoD_list) # [['Nduka', 'Larry'], ['Chichi', 'Leslie'], ['Donna', 'Taiwo']] print(type(twoD_list)) # <class 'list'>
```

### NumPy installation/import

```text
# install numpy pip install numpy # import numpy import numpy as np
```

### NumPy reshape example

```text
twoD_list = np.array(oneD_list).reshape(-1, 2).tolist() print(twoD_list) # [['Nduka', 'Larry'], ['Chichi', 'Leslie'], ['Donna', 'Taiwo']] print(type(twoD_list)) # <class 'list'>
```
