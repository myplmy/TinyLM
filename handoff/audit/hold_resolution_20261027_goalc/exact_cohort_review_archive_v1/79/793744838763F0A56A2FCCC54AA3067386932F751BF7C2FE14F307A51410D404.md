# 19079 보류 원형

| 원형 조각 | 처리 근거 |
|---|---|
| `물리학에서 장력(tension, )` | 실제 영어 용어 `tension`은 유지하고 값이 없는 병기 슬롯만 정리했다. |
| `위치 에 따른 장력의 크기는 이다.` | 문장에 장력의 크기 식과 그 주어가 빠져 있어 해당 식을 단정하는 문장 전체를 보류했다. 앞의 장력이 줄 위치에 따라 같다는 완결 설명은 본문에 남겼다. |
| `이 알짜힘은 복원력이며, 스튀름-리우빌 이론에 따르면 실의 움직임은 횡파이며, 다음의 방정식으로 해를 구할 수 있다.` | 원형의 복원력·스튀름-리우빌·횡파 설명은 본문에 완결 문장으로 보존했다. 식이 없는데 직접 그 식의 해를 예고하는 연결만 보류했다. |
| `는 단위길이당 힘, 는 실의 가로성분 변위 에 따른 고유 공명값이다. 여러 풀이들은 현악기의 여러 화음들을 나타낸다.` | 두 정의의 주어/기호와 앞에서 예고된 식이 소실되어 단위·고유값·해를 새 이름이나 공식에 연결하지 않았다. |
| `변형력 텐서의 성분  은 단위면적당 인장력이다(또는 단위면적당 압축력인데, 막대가 늘어나는 경우가 아닌 압축되는 경우에는 이 성분을 이용해서 음수를 나타낸다).` | 원형에서 성분 기호가 비어 있다. 본문은 성분을 특정 기호로 배정하지 않고 단위면적당 인장력/압축력이라는 실제 정의와 압축 시 음수 조건을 일반 서술로 보존했다. |
| `이 상황에서 물체에는 알짜힘이 가해지며, 다음과 같다.` | 아래방향 속도 증가와 양의 가속도라는 조건, 물체에 알짜힘이 작용한다는 서술은 본문에 남기고, 빠진 계산 결과를 직접 가리키는 `다음과 같다` 부분만 보류했다. |
| `물체 A에는 위로 잡아당기는 장력  와, 아래로 잡아당기는 무게 ()의 두 힘이 작용한다. 따라서 A에 작용하는 알짜힘은  이므로 이다.` | 두 물체의 질량, 연결, 비신축·무마찰·비굴곡 조건과 A에 작용하는 위쪽 장력/아래쪽 무게 관계는 본문에 보존했다. 빠진 장력·무게 기호와 결과식에 의존하는 서술은 원형대로 보류했으며 식을 만들지 않았다. |

평형 예시의 등속 낙하, 장력과 중력 크기가 같다는 완결 문장, 알짜힘/가속도 일반 설명, 실제 3차원 연속체·현대 물리학 설명, 훅 법칙과 `표면장력` 참조는 보존했다. 식이나 기호를 추정하지 않았다.
