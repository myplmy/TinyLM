# expanded_train:28703 원형 보류 및 경계

빠진 변수·관계식·함수 표기를 채우지 않았다. 아래는 그 표기나 조건에 직접 의존하는 원문 조각이다. 본문에는 실제 완결된 자연어 정의·설명·예시·연혁을 남겼다.

## 정의, 표기, 예시의 빠진 기호

- `함수 는 다음과 같은 튜플 이다. / 는 집합이며, 이를 의 정의역이라고 한다. / 는 집합이며, 이를 의 공역이라고 한다. / 는 곱집합 의 부분 집합이며, 이를 의 그래프라고 한다. / 이 튜플이 다음 조건을 만족시켜야지만 함수라고 한다. / 임의의 에 대하여, 인 가 유일하게 존재한다. 이러한 를 라고 쓴다.`
- `는 가 정의역 , 공역 를 갖는 함수라는 뜻이다. 표기 / 는 와 같은 뜻이다.`
- `함수 는 정의역이 , 공역이 이며, 1, 2, 3을 각각 , , 로 대응시키는 이항 관계를 나타낸다.`
- `가 실수의 집합이라고 하자. 그렇다면 / 는 각 실수를 제곱시키는 함수이다.` 함수 이름은 빠져 있으나 완결된 자연어 제곱 설명은 본문에 남겼다.
- `가 하나의 원소만을 갖는 집합이라고 하자. 그렇다면 임의의 집합 에 대하여, 를 정의역, 를 공역으로 하는 유일한 함수 / 가 존재한다.`
- `이 공집합이라고 하자. 그렇다면 임의의 집합 에 대하여, 을 정의역, 를 공역으로 하는 유일한 함수 / 가 존재한다. 일 경우 이는 공역이 공집합인 유일한 함수이다.` 본문은 지정 집합 기호 없이 명시된 정의역·공역 관계만 자연어로 보존했다.

## 빠진 정의 조건과 표시 수식

- 원문의 단사·전사·전단사 정의에 있던 변수 조건과 등식은 빠져 있다. 실제 문장에 적힌 서로 다른 정의역 원소의 대응, 치역과 공역의 관계, 역함수 동치 설명은 본문에 자연어로 보존했다.
- `실변수 실숫값 함수 (는 의 열린집합)`의 빈 표기 부분은 보류했다. 그 외 위상 공간·매끄러운 다양체에 대한 설명은 유지했다.
- 증가·감소·홀·짝·주기 함수의 원문 조건식 및 빈 예시 수식은 보류했다. 그래프에 대한 실제 완결 설명과 삼각 함수의 주기성 주장은 본문에 보존했다.
- `두 매끄러운 다양체 사이의 함수 에 대하여, 다음 두 조건을 만족시키는 유한 개의 서로소 집합 이 존재한다면, 를 조각마다 〜 함수라고 한다.` 및 두 빈 조건식, `예를 들어, 의 분할의 한 가지 예는 다음과 같다.`는 필요한 대상/조건/예시가 빠져 있어 보류했다. 실수 구간의 분할에 관한 완결 설명, 절댓값·부호 함수의 실제 예는 보존했다.
- 다가 함수의 빈 기호 조건과 `다가 함수 는 일반적으로 에서 로 가는 함수가 아니지만 멱집합으로 가는 함수 / 와 동치이다.`의 누락된 집합·함수 관계는 보류했다. 실제 자연어로 적힌 다가 대응 설명과 거듭제곱·제곱근 예는 보존했다.
- `부분 정의 함수 는 다음과 같이 약화된 조건을 사용하여 정의한다. / 임의의 및 에 대하여, 만약 라면 이다.`와 `부분 정의 함수 는 일반적으로 에서 로 가는 함수가 아니다. 그러나 이는 다음과 같은 꼴의 함수와 동치이다.`의 빈 조건·대응 수식은 보류했다. 유일하게 대응하거나 대응하지 않는다는 문장과 역수 예시의 실제 설명은 보존했다.
- 상·원상 정의의 빈 함수/집합/집합값 수식과 사인 함수의 빈 치역·원상 예시는 보류했다. 실제 문장 `정의역의 상을 치역이라고 한다.`는 보존했다.
- 역함수 정리의 빈 함수 조건과 역함수 표시는 보류했다. 전단사와 역함수의 동치 및 역함수의 방향 설명, 지수 함수/로그 함수의 실제 명명 관계는 자연어로 보존했다.
- 합성 예시의 빈 두 함수/대응/결과 수식은 보류했다. 첫 함수의 공역과 둘째 함수의 정의역이 같은 경우 합성을 생각할 수 있다는 실제 조건은 본문에 남겼다.
- 함수족 호환의 빈 조건과 그로부터 함수를 합친다는 직접 결론은 보류했다. 점별 함수와 공역 곱집합에 관한 실제 일반 설명은 보존했다.
- `구체적으로 이들은 각각 다음과 같다.`는 이어지는 점별합·점별곱 수식이 비어 있는 예고라 보류했다. 점별 연산에 관한 앞 문장과 실제로 서술된 덧셈·곱셈 관계는 보존했다.

## 연혁·어원에서 빠진 고유어

- `17세기 고트프리트 빌헬름 라이프니츠는 수학 저서에서 라틴어 단어 를 주로 ‘기능’이란 뜻으로 썼다. 이후 요한 베르누이 등이 를 기술적인 해석학 용어로 쓰기 시작했다. 이것이 다른 유럽 언어로 전파되었다.` 핵심 라틴어 단어가 빠져 직접 귀속된 주장 전체를 보류했다.
- `‘함수(函數)’라는 용어를 쓰기 시작한 사람은 이선란과 이다. 그들은 번역서 《대수학(代數學)》(1859)과 《대미적습급(代微積拾級)》(1859)에서 영어 의 번역어로 ‘함수(函數)’라는 단어를 썼다.` 미상 인명·영어 단어에 기대는 주장만 보류했다. 바로 뒤 De Morgan의 실제 책·function 용례·函 설명은 보존했다.
- `‘함수’가 영어 단어 의 발음을 음역한 단어라는 설이 있지만 두 발음이 크게 달라 근거가 희박하다.` 음역 비교 대상 단어가 빠져 있어 보류했다. 나열된 번역어 상수·변수·계수·지수·급수가 음역이 아니라는 독립 문장은 본문에 보존했다.
- 원문에 빈 참고 문헌 표제만 남은 부분은 candidate에서 제거된 범위를 유지했다. 외부 링크 표제 아래 실제 링크 항목이 없어서 그 빈 표제도 새 본문에서 제거했다.

표기·빈 표제의 정리는 원문에 없는 수식·값·사실을 채우지 않는다. 외부 수학·역사 사실을 검증하거나 보정하지 않았다.
