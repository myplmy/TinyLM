# expanded_train:1217595 — 본문 밖의 페이지 내비게이션

`Back to top`은 각 섹션 뒤와 문서 끝에 배치된 페이지 내비게이션이다. 해당 UI 문구 3개를 원형 보존하고 본문에서 분리했다. 섹션 제목, 식이섬유 권고, 예시, 음식 목록 및 `Last reviewed: 2012`는 유지했다.

분리한 원문 문구(모두 원문과 같은 대소문자):

1. `Back to top` — 변비 징후 목록 뒤.
2. `Back to top` — 변비 원인 목록 뒤.
3. `Back to top` — `Last reviewed: 2012` 뒤, 문서 끝.
