# expanded_train:78310 원형 보류

빈 제목 병기 `1966년 FIFA 월드컵()`과 실제 정보가 없는 섹션 뼈대(개최국 선정/희망 국가, 개최 도시 및 경기장, 지역 예선, 선수 명단, 조별 리그의 A–D, 결선 토너먼트의 각 라운드, 우승국, 각주)는 원형만 기록하고 본문에서 분리했다. 실제로 채워진 시드 추첨 날짜, 오심 서술, 득점자·수치, 자책골, 순위 판정 방법, 기록, 외부 링크, 분류는 보존했다.

다음 불완전 문장은 실제 주체가 빠져 있다: `FIFA 총회는 1960년 8월 22일 이탈리아 로마에서 열린 회의에서 를 1966년 FIFA 월드컵 개최국으로 선정했다.` 이어 `은 7점차로 탈락하였으며 은 유치를 포기하였다.`도 두 주체가 빠져 있다. 빠진 국가명을 앞 문맥에서 보충하지 않고 이 두 원형 문장을 함께 보류했다. 개최국·탈락국·유치 포기국을 추정하거나 외부 사실로 검증하지 않았다.

빈 섹션 원형: `개최국 선정 / 개최를 희망했던 국가`, `개최 도시 및 경기장`, `지역 예선`, `선수 명단`, `조별 리그 / A조 / B조 / C조 / D조`, `결선 토너먼트 / 8강전 / 4강전 / 3·4위전 / 결승전`, `우승국`, `각주`. 표나 결과의 빈 값을 채우지 않았다.
