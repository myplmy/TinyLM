# expanded_train:1273105 원형 보류 기록

- 인용 질문의 원형은 `> Anyway, how can i declare a global variable and assign a value to it in a`이다. `in a`는 이어지는 대상이 없는 잘린 전치사 조각이므로 본문에서는 그 조각만 분리하고 질문의 실제 주제·변수·의도를 유지했다. 문장을 다른 질문으로 바꾸거나 답을 덧붙이지 않았다.
- `More information about the Tutor`는 가리킬 자료/링크 값 없이 단독으로 남은 탐색 안내라 분리했다. 메일 헤더, 저자 역할 문구, 두 실제 튜토리얼 제목은 본문에 보존했다.
- `(And more about functions and modules in the "Modules & Functions"`는 실제 제목이 완결돼 있지만 여는 괄호가 닫히지 않은 원문이다. 내용은 그대로 두고 제목 뒤에 닫는 괄호와 문장 마침표만 보완했다.

본문의 코드 조각·변수·수치와 설명은 원문대로 보존했으며 실행/검증하거나 빠진 함수 정의를 채우지 않았다.
