# TASK_010 판독 범위와 종료점

입력은 page010의 TASK_010에 정확히 지정된 original/candidate 및 packet을 고정 reader로 순서대로 읽었습니다. 아래 범위는 해당 입력의 실제 논리 END와 packet EOF 확인을 기록합니다.

| ID | packet 범위 | 종료 확인 |
|---|---|---|
| expanded_train:196617 | 0001 | original/candidate 각 END, full_diff END, 실제 packet EOF를 확인했습니다. |
| expanded_train:196652 | 0001 | original/candidate 각 END, full_diff END, 실제 packet EOF를 확인했습니다. |
| expanded_train:197195 | 0001 | original/candidate 각 END, full_diff END, 실제 packet EOF를 확인했습니다. |
| expanded_train:197510 | 0001–0028 순서대로 | 0028에 `source_packet_sequence_complete=true`였고 original/candidate 및 full_diff의 논리 END, 실제 packet EOF를 확인했습니다. 후보는 full_diff상 줄 차이가 없었습니다. |
| expanded_train:197656 | 0001 | original/candidate 각 END, full_diff END, 실제 packet EOF를 확인했습니다. |

다섯 새 출력은 지정 candidate 대비 전체 diff와 말미를 확인했습니다. 197510에서는 확인된 편집 배너 한 줄만 분리하고 나머지 문장을 유지했습니다. 나머지 네 건도 지정된 빈 괄호/미상 귀속 경계만 수정했습니다.
