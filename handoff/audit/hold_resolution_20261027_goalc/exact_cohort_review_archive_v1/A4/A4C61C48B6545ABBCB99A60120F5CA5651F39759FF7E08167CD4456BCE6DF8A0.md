# 9761 원형 보류

후보의 본문을 유지하며, 아래 원형만 본문에서 좁게 정리했다.

- 책 목록의 다섯 서지 항목에는 연도 뒤에 비어 있는 두 번째 필드가 있다. 어떤 출판 정보를 뜻하는지 채우지 않고 빈 구분자만 정리했다.
- 어록 문단 끝의 `《촘스키 누가 무엇으로 세상을 지배하는가》에 실린 글은 다음과 같다.`는 뒤에 그 문구가 없어 미완의 직접 예고로 분리했다. 해당 책 제목은 저서 목록에 실제 이름으로 이미 남아 있다.

```text
《지식인의 책무》(2005, )
《세계를 해석하는 것에 대하여 / 세계를 변화시키는 것에 대하여》 (2003, )
《해적과 제왕》(2004, )
《여론조작》(2006, )
《영어의 음성체계》(1993, )
《촘스키 누가 무엇으로 세상을 지배하는가》에 실린 글은 다음과 같다.
```

빈 필드에 출판사·번역정보·추가 연도를 만들지 않았다. 인물의 출생일, 경력, 주장·인용, 실제 서명·연도·저서명 및 완결 목록은 유지했다.
