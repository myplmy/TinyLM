# 5318 원형 보류 구간

## 원문 목록 골격

```
국가

북아프리카

중앙아프리카

남아프리카
 
 
 
  (프랑스령)

동아프리카
 
  ()

서아프리카
 
 
 
 
 
 
 
 
 
 
 
 
 
 
  (영국령)
```

## 이유

이 목록에는 실제 국가명이나 항목 귀속이 없고 지역 표제, 빈 행, 빈 괄호, 대상이 빠진 식민지 표지만 남아 있습니다. 값 없는 목록 골격 전체를 원형으로 보존해 분리했습니다. 앞의 채워진 아프리카 지리·역사·경제·문화·교통 설명과, 이 목록 앞의 완결된 국가 분류 기준 문단, 뒤의 실제 같이 보기·외부 링크 항목은 본문에 유지했습니다. 지역명을 새 국가나 귀속 주체로 만들지 않았고 다른 독립 문맥의 지역명도 삭제하지 않았습니다.
