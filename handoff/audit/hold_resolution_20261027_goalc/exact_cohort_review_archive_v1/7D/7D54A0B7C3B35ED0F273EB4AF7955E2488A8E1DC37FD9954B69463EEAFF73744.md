# 1403013: 분리한 페이지 탐색 UI

- 원형 문자열: 독립 행 `back to top`이 반복됨. 두 보존 위키 발췌 사이에는 `Back to the Objects Page`와 `Back to the Objects Page.`가 각각 별도 행으로 나타남.
- 처리: 위의 독립 탐색 UI 행만 새 전체 TXT에서 제거함.
- 보존 경계: `More on ...` 연결, 질문 제목과 답변, 수치·조건, 관련 내용이 채워진 제목 및 링크는 유지함. `Healthy Soils: Sources | Top | Why Soil Organic Matter Is So Important`의 `Top`도 연결된 탐색 항목을 포함한 채로 보존함.
- 근거: 제거한 문구들은 해당 페이지 안에서 위쪽 또는 사이트 원 페이지로 이동하는 독립 내비게이션 표시다. 주변 문단·질문/답변의 정보와는 분리 가능하다.
