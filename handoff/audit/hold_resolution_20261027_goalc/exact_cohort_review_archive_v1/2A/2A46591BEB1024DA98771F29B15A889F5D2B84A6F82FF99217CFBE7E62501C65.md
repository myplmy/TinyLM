# expanded_train:217553 — 원형 보류

원문의 결손으로 주체·문제 형식·관계를 확정할 수 없는 아래 단위만 보류했다.

- Search Problem의 `- Requirements: Given and solution then in polynomial time we can check that is a solution to`와 뒤의 `To show problem is a search problem...` 알고리즘 문장: 검증 대상·관계 기호·입력 크기 기호가 소실됐다.
- SAT의 `- Output: Satisfying assignment if one exists; NO if satisfying SAT assignment`와 `SAT NP: Given and an assignment , for each clause in time ...` 검증 문장: 출력 조건·변수·식·시간 값이 없다.
- k-Coloring의 `- Input: and integer`와 `Note, k-Coloring NP: Given and ...` 검증 문장: 입력 대상·변수·검증식·시간 정보가 빠졌다. 바로 앞의 k색과 인접 정점 색상 제약, 보이는 출력 문구는 보존했다.
- Knapsack의 `- Input: objects: integer weights ; values ; integer as weight limit` 및 `- Output: Solution of objects with weight no more than and the max value of the objects`: 해당 문제 인스턴스와 목적 값의 기호가 비어 있다. 최대값 검증에 관한 완결 자연어 설명은 남겼다. 뒤의 `but that algorithm takes time . The input size is of size poly(). Hence we don’t know that Knapsack is in NP, in fact, if it is in NP then P=NP.`는 빠진 실행시간·크기 식에 직접 기대므로 보류했다.
- Knapsack-Search의 입력/출력 행과 `Note, Knapsack-Search NP...` 문장: goal과 중량·값 조건의 변수·한계가 소실됐다. 최적화/검색 버전이라는 본문 명시와 자연어 환원 설명을 보존했으며, 원문의 `binary search over .`에서 missing 범위 값은 쓰지 않았다. `Hence, we’ve shown that: Knapsack Knapsack-Search.`는 관계 연산자가 빠져 보류했다.
- MST의 `- Input: with for every`와 `Note, MST NP: Given and ...` 검증 문장: 그래프·가중치·검증 대상·시간 값이 비어 있다. 명명된 MST와 실제 출력 문구는 보존했다.
- 요약 목록 원문 `- NP contains: MST, Knapsack, SAT, K-Coloring, TSP`에서 문제 형식이 특정되지 않은 `Knapsack` 항목만 보류했다. 이어진 `According to the definition ... P NP` 문장 및 `- P NP: ...`와 `If P NP, then ...` 단위는 소실된 P/NP 관계 표기에 기대므로 보류했다.
- `To show SAT is NP-Complete, we need to prove:`와 뒤의 `- SAT NP (shown above)` 및 `For every problem A NP ... (A SAT)` 조건은 빠진 관계 연산자·대상이 필요해 보류했다. 완결된 NP-complete 문제 이름·목록은 남겼다.
- `Here we formally the notion of a reduction...`는 서술어가 빠져 있고 `(or ) means A reduces to B:`는 표시 대상이 없어 보류했다. A/B의 실제 예시, B를 푸는 알고리즘으로 A를 푼다는 자연어 설명, `f(I)`와 `h(S)`의 단계·검증 조건은 보존했다.
- `Suppose we know SAT is NP-Complete somehow, which gives us ... A SAT.` 뒤의 연쇄 및 Colorings 문단의 `A Colorings`, `SAT Colorings`, `A SAT Colorings`, `A Colorings` 표현, 마지막 `- Colorings NP`와 `B Colorings`는 모두 연결 연산자가 없다. 독립된 `SAT is NP-Complete` 가정 및 `Colorings is NP-Complete` 소개 문장만 남겼다.

빠진 변수·goal·연산자를 채우거나 P=NP의 방향을 고르지 않았다. Knapsack의 decision/optimization/search 변형을 새로 단정하지 않고, 원문에 명시된 최적화/검색 설명과 `f(I)`/`h(S)` 절차 및 실제 명명 목록은 보존했다.
