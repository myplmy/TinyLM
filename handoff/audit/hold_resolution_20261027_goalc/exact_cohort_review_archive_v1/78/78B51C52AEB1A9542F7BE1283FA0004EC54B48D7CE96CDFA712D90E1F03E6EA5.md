# 874017 원형 보류

선택 본문: `reviewed_874017_task064_v2.txt`.

- 실제 `if (x != 0) launch_nuclear_missiles();` 코드는 본문에 보존했다. 그 뒤의 `... and then, possibly in another function`은 이어질 내용/관계가 본문에 없으므로 보류했다.
- `some people would view ... as superior to one that only calls x is non-zero`에는 비교 대상/조건이 완결돼 있지 않다. 원문 밖에서 비교 대상을 보충하거나 `superior`를 비교 없는 확정 평가로 남기지 않고 비교 문장 전체를 원형 보류했다.
- `but such behavior would only be appropriate ...`의 `such behavior` 주체는 바로 앞의 미완 비교 문장에만 있으므로 이 직접 의존 한정문도 함께 보류했다. `If one knows ... division-by-zero ...`와 `With aggressively-optimizing compilers ...`는 각각 주체·조건·관계가 완결된 문장이므로 본문에 유지했다. 새 컴파일러 행동이나 결론을 만들지 않았다.

## 원문 발췌

```text
... and then, possibly in another function
some people would view a compiler that replaces the "if" with an unconditional call to
launch_nuclear_missiles() as superior to one that only calls
x is non-zero, but such behavior would only be appropriate when processing tasks that will never involve untrustworthy input.
```
