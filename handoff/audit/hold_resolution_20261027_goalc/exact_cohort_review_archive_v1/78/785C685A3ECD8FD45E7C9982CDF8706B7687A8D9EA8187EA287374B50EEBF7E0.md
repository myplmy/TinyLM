# 145870 원형 보류

원문에서 뒤따를 code/header 값이 없거나 code comment만 남은 지시를 원형 보존했다.

- `// Just adding the Active Object to scheduler` — 해당 Add() 코드가 없다.
- `Add following header.` — header 값/지시행이 없다.
- `Link against: euser.lib, so add the following line to the .mmp file.` — `euser.lib` 이름은 명시되어 있으나 .mmp linker line은 없다.
- `// Delete active scheduler` — 대응하는 삭제 코드가 없다.

본문의 `Add()` method 설명과 실제 scheduler allocation/install code, `CActiveSchedulerWait` 권고 및 Start/Stop pseudo-code의 모든 수치·상태·설명은 유지했다. 코드를 재구성하거나 실행하지 않았다.
