# expanded_train:26723 원형 보류 v3

이 파일은 앞선 sidecar들의 입력 차이 설명을 보존하면서 총괄 중재에 따른 최종 경계를 적는다. v1/v2는 수정·삭제하지 않는다.

- 실제 판독 범위: original, candidate, packets 0001–0006의 원문·후보·full_diff를 논리 END/EOF까지 확인했다. candidate 대비 새 본문 전체와 전체 diff도 확인했다.
- 첫 문장의 원형 빈 괄호: `루비()`는 마쓰모토 유키히로가 개발한 동적 객체 지향 스크립트 프로그래밍 언어이다. 채워진 이름 뒤의 값 없는 괄호만 정리했고 새 별칭/이름은 만들지 않았다.
- original에만 있던 빈 `각주` 표제는 candidate에서 제거됐다. 원형 표제는 `각주`다.
- original/candidate의 원형 행: `Cardinal: : Parrot에서 Ruby를 동작시키기 위한 구현물이 개발되고 있다.` 총괄은 `Cardinal`과 `Parrot에서 Ruby를 동작시키기 위한 구현물` 관계가 실제 문장에 채워져 있고 이중 콜론은 중복 문장부호라고 판단했다. 새 본문에서는 콜론 하나만 정리해 `Cardinal: Parrot에서 Ruby를 동작시키기 위한 구현물이 개발되고 있다.`로 보존했다. 개발현황을 새로 검증하거나 언어명/값을 추가하지 않았다.
- 다른 구현체 이름·설명, 예제 코드·값·결과, 날짜, 링크, 분류와 실제 `같이 보기` 항목은 그대로 유지했다.
