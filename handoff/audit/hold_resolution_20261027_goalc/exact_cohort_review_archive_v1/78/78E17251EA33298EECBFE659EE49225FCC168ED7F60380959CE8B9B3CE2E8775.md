# expanded_train:285400 — 페이지 이동 UI 원형 보존

후보에서 제거된 네 개의 `back to top`은 본문에 포함되지 않은 페이지 위로 이동 UI다. 원문 순서상 사고 분류/원인 확인의 첫 설명 뒤, 개인·조직 요인을 다룬 분석 절 뒤, 오류 분류 예시 뒤, 안전문화 평가 설명의 말미에 각각 있었다.

후보는 작업장 사고 분석, 오류 유형, PHECA/SHERPA의 명칭·분류, 개인/조직 관점, 행동기반 안전·문화기반 접근 및 시행 절차의 본문을 그대로 보존한다. 수치·조건과 설명을 삭제하지 않았다. UI 원문과 위치만 이 sidecar에 기록한다.
