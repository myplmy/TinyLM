## 원형 보류

아래 식별자·기호·대응은 원문에서 소실되어 본문에 생성하지 않는다. 명시된 자연어 관계나 명명 예시가 독립적으로 완결된 부분은 본문에 남긴다.

### 원소 표기

> 가 의 원소임을 와 같이 표기하며, 가 의 원소가 아님을 와 같이 표기한다.

두 포함/비포함 기호와 집합 식별자가 없으므로 이 표기 설명만 보류한다. 같은 문장의 대문자 집합/소문자 원소 일반 설명과 공집합을 뜻하는 명시된 `φ` 설명은 보존한다.

### 벤 다이어그램의 일반 개수식

> 즉, 개의 원으로 이루어진 벤 다이어그램은 총 개의 영역으로 나뉘어야 한다.

두 개수식의 수가 없어 일반 조건으로 복구하지 않는다. 이어지는 3개 집합·총 8개 영역 설명과 실제 열거는 원문대로 보존한다.

### 합집합·교집합·곱집합

> 일련의 집합들이 주어졌다고 하자. 여기서 는 집합이며, 각 는 를 식별하는 데 쓰이는 첨수이다.

> 집합들의 합집합은 이들 가운데 적어도 하나에 속하는 원소의 집합이다. 합집합을 나타내는 기호는 이다.

> 특히, 두 집합 와 의 합집합을 나타내는 기호는 이다.

> 또 한 가지 예를 들어, 두 집합 / 의 합집합은 / 이다.

> 집합들의 교집합은 이들 모두에 속하는 원소의 집합이다. 교집합을 나타내는 기호는 이다.

> 특히, 두 집합 와 의 교집합을 나타내는 기호는 이다.

> 또한, 두 집합 / 의 교집합은 / 이다.

각 빈 식/식별자/첨수 및 이에 직접 의존하는 줄만 보류한다. 자연어로 완결된 일반 합집합·교집합 설명과 오각형/정다각형의 명시된 합집합·교집합 관계는 본문에 보존한다.

> 집합들의 곱집합은 각 -좌표를 에서 취하는 튜플의 집합이다. 곱집합을 나타내는 기호는 이다.

> 특히, 두 집합 와 의 곱집합을 나타내는 기호는 이다.

> 예를 들어, 두 집합 / 의 곱집합은 / 이다. 또한, 실수의 집합 과 자기 자신의 곱집합은 2차원 유클리드 공간 / 이다. 이 집합과 의 곱집합은 3차원 유클리드 공간 / 이다.

좌표·집합·곱 기호 및 결과 공간이 빠져 있어 이 직접 의존 단위를 보류한다.

### 차집합·여집합·대칭차 및 항등식

> 집합 와 집합 의 차집합은 에 속하지만 에는 속하지 않는 원소의 집합이다. 차집합을 나타내는 기호는 나 이다.

> 예를 들어, 두 집합 / 의 차집합은 / 이다.

> 만약 가 의 모든 원소를 포함한다면, (즉, 가 의 부분 집합이라면,) 와 의 차집합을 의 여집합이라고 한다. 여집합을 나타내는 기호는 나 이다.

> 집합 와 집합 의 대칭차는 에 속하거나 에 속하지만, 동시에 둘 다에 속하지는 않는 원소의 집합이다. 대칭차를 나타내는 기호는 이다.

> 예를 들어, 두 집합 / 의 대칭차는 / 이다.

> 집합의 연산에 대한 여러 가지 항등식이 성립한다. (드모르간 법칙) / (드모르간 법칙)

대상 식별자·기호가 비어 있어 정의/연산/직접 예시를 새로 만들지 않는다.

### 부분집합 및 크기 비교

> 만약 집합 에 속하는 모든 원소가 집합 의 원소이기도 하다면, 를 의 부분 집합이라고 한다. 이를 나타내는 기호는 이다.

> 만약 , 라면, 이다. 만약 , 라면, 인데, 이는 3이 의 원소이지만 의 원소가 아니기 때문이다.

> 만약 가 의 부분 집합이면서, 가 의 부분 집합이라면, 와 의 원소는 완전히 같아진다. 이때 와 가 서로 같다고 하며, 이를 나타내는 기호는 이다. 만약 가 의 부분 집합이면서, 와 가 서로 같지는 않다면, 를 의 진부분 집합이라고 한다. 이를 나타내는 기호는 이다.

> 예를 들어, 가 모든 삼각형의 집합, 가 모든 다각형의 집합이라면, 는 의 부분 집합이다. ... 모든 사각형의 집합 ... 모든 정다각형의 집합 ... 는 의 부분 집합이 아니다.

위 첫 정의와 기호만 있는 후속 관계는 식별자가 빠져 보류한다. 명시된 모든 삼각형/모든 다각형, 모든 사각형/모든 정다각형, `부분 집합이다`/`부분 집합이 아니다` 관계는 새 식별자 대신 명명된 집합으로 최소 연결해 본문에 보존한다. 별도로 뒤따르던 두 수식 예시의 `가로 2, 세로 3` 설명 및 부정 관계는 본문에 완결된 설명이 실제 있어 보존한다.

> 집합의 모든 부분 집합을 모은 집합을 생각할 수 있다. 이를 의 멱집합이라고 한다. 멱집합을 나타내는 기호는 나 이다. 예를 들어, 의 멱집합은 / 이다.

멱집합의 일반 자연어 정의는 대상 관계가 완결되어 있어 본문에 보존한다. 특정 집합·기호·멱집합 예시는 보류한다.

> 두 집합 가 모두 유한 개의 원소만을 가진다고 하자. 만약 의 원소 개수가 의 원소 개수보다 많다면, 가 보다 크다고 한다. 반대로 만약 의 원소 개수가 의 원소 개수보다 적다면, 가 보다 작다고 한다. 만약 의 원소 개수가 의 원소 개수와 같다면, 가 와 크기가 같다고 한다.

> 예를 들어, 가 1부터 20까지의 자연수의 집합, 가 21부터 30까지의 자연수의 집합이라면, 의 원소 개수는 20, 의 원소 개수는 10이다. 20이 10보다 크므로, 의 크기는 의 크기보다 크다.

유한 집합 크기 비교의 대상과 조건은 실제 자연어로 완결되어 있어 한 집합/다른 집합 관계로만 읽히게 최소 정리하고, 구체 예시의 명시적 숫자·순서·비교 관계를 보존한다. 식별자 자체는 생성하지 않는다.

> 두 집합 가운데 적어도 하나가 무한 개의 원소를 갖는다고 하여도, 이 두 집합의 크기를 비교할 수 있다. 만약 의 서로 다른 원소와 의 서로 다른 원소가 남김 없이 짝지어질 수 있다면, 다시 말해 와 사이에 전단사 함수가 존재한다면, 와 의 크기가 같다고 한다. ...

첫 문장의 일반 진술과 독립된 `진부분집합은 원래의 집합과 크기가 같을 수 있다`는 원문 결론은 보존한다. 빈 집합 식별자/대응/방향이 필요한 전단사 조건과 비교식 및 뒤의 특정 예시는 보류한다.

> 집합의 크기는 기수로 양화될 수 있다. 집합 의 크기를 나타내는 기호는 또는 이다. 집합 의 크기가 의 크기보다 큼을 나타내는 기호는 또는 이다.

기수 일반 설명만 보존하고, 비어 있는 기호 대응은 보류한다.

### 기호 집합과 집합족의 특정 예

> 은 모든 자연수의 집합이다. 문맥에 따라 0부터 시작할 수도 있고, 1부터 시작할 수도 있다. / 는 모든 정수의 집합이다. / 는 모든 유리수의 집합이다. / 는 모든 실수의 집합이다. / 는 모든 복소수의 집합이다. / 는 모든 사원수의 집합이다. / 는 모든 팔원수의 집합이다. / 는 모든 십육원수의 집합이다.

각 집합 기호가 소실되어 기호-대상 대응은 보류한다. 실제 표기가 있는 `T는 2의 배수이며 홀수인 수의 집합이다(=φ)`는 유지한다.

> 집합 역시 또 다른 집합의 원소가 될 수 있으므로, 일정한 조건을 만족시키는 집합들을 모은 집합을 생각할 수 있다. 한 가지 예는 어떤 집합의 멱집합이다. 예를 들어, 와 이 집합이므로, / 는 집합족이다.

집합족의 일반 설명은 유지하고, 예시의 집합 이름 및 식이 빠진 직접 예시만 보류한다.
