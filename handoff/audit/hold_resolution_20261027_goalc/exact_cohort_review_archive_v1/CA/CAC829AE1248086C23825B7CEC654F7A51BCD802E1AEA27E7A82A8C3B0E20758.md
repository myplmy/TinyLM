- VelocityTracker 인스턴스 생성 안내에서 실제 정적 메서드 이름이 빠져 있는 문장만 보류했다. 보이지 않는 API 이름은 추정하지 않았다.
- VelocityTracker가 사용자 입력에 대해 무엇을 알아내는지 서술하는 문장도 목적어가 빠져 있으므로 원형 보류했다.
- 실제 `addMovement(MotionEvent ev)`, `onTouch()`, `onTouchEvent()` 이름과 인수/처리기 관계는 보존했다. 두 MotionEvent 이상이라는 실제 조건과 실제 메서드명, X/Y 방향 속도 반환 관계를 한 문장으로 이어 읽히게 했으며 새 호출·값은 만들지 않았다.
