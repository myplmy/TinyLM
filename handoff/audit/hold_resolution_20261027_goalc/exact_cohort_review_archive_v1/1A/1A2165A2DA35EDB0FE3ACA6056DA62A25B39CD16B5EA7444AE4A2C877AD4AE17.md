# 37860 원형 보류·정제 기록

- 도입 원형 `아러타이 지구(), )`는 candidate가 빈 괄호 일부만 정리해 남긴 `아러타이 지구, )` 꼬리까지 제거하여 실제 명칭에 조사를 붙였다. 이름 외의 값을 추정하지 않았다.
- 행정구역의 빈 별칭 괄호·쉼표를 정리하고 실제 시/현 이름·괄호 안의 채워진 대체명·순서를 유지했다. candidate의 푸윈 현 빈 괄호 제거도 유지했다.
- 표 내용이 없는 원형 `민족` / `2000년 알타이 지구의 민족 조사에 의한 민족의 수와 비율은 다음과 같다.`는 직접 예고와 함께 원형 보류했다. 별도로 도입에 완결된 `2000년의 조사에 의하면 주민의 대부분이 카자흐족(51%)이다.`는 별도 정보로 보존했다.
- 지리·면적·인구·행정 개수·경제 수치·실제 링크와 분류는 그대로 두고 외부 사실 검증은 하지 않았다.
