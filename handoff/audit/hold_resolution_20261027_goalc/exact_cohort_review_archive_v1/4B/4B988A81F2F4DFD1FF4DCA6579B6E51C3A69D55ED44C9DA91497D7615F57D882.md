# 251390 원형 보류 및 정리 근거

지정 packet 0001–0003에서 원문·후보와 diff의 끝까지 확인했다. 제목의 빈 별칭 포장을 정리하고, 빠진 임시 이름에 직접 의존하는 구절과 빈/탐색 메타데이터를 분리했다.

```text
메티스(, )
메티스는 1979년 스티븐 시넛이 보이저 1호가 촬영한 사진 속에서 찾아냈으며, 임시 이름 을 부여받았다.
같이 보기 
 목성의 내부 위성
 아드라스테아
 아말테아
 테베
 목성의 고리
각주 
내용주
참조주
```

본문에서는 `메티스(, )`의 빈 별칭 껍데기만 정리했다. 1979년 발견 사실은 원문에 있는 대로 유지하고, 임시 이름 값이 빠진 종속 구절만 제거했다. 원문은 1983년 공식 명명과 유래를 별도 문장으로 명시하므로 해당 문장은 보존했다. `같이 보기` 항목은 탐색 목록으로 원형을 보존하고 본문에서 분리했다. 후보가 이미 제거한 빈 각주 표제들도 이 노트에 원형으로 남겼다. 명명된 NASA 태양계 탐사 프로필 항목과 채워진 분류명은 유지했다.
