# 1416443 원형 보류

원문에서 실제 command/URL을 예고했으나 값이 비어 있는 구간만 분리했다.

- `When you are there simply type the following command.` — terminal startup command가 없다. 앞의 `open up a terminal and cd into your ‘server’ directory` 절차는 본문에 보존했다.
- `Your server is now fully operational! To see your first page fire up a browser and type the following into the location bar.` — startup command와 browser URL이 모두 없다. URL이나 실행 명령을 추정하지 않았다.

뒤의 실제 `Hello World!` 출력 기대, 권한 점검·종료 안내와 server/CGI Python 코드 및 8000 port 값은 유지했다. 코드를 실행하지 않았다.
