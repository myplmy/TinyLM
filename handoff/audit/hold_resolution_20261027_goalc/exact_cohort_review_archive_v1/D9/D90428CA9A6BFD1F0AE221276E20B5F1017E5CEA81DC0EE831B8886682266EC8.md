# 941832 원형 연결 기록

## 원문 결합

- `가중 랑데부 해시를 구현하는 파이썬 코드 : #!/usr/bin/env python`
- `return champion WRH의 출력 예 : [GCC 4.2.1 Compatible Apple LLVM 6.0 (clang-600.0.39)] on darwin`

## 처리 근거

첫 경계는 본문에서 파이썬 코드라고 명시한 표제와 실제 shebang의 경계이고, 둘째 경계는 함수의 완결 `return champion`과 바로 이어지는 명시적 출력 예 표제의 경계다. 새 토큰·값·API·코드 구조를 만들지 않고 줄 경계만 분리해 두 항목을 읽히게 했다. 원래 결합 문자열을 보존하며 코드를 실행하거나 출력값을 검증하지 않았다.
