# 311141 TASK003 원형 보류 메모

- 입력: 지정 original/candidate packet 1의 전문과 `=== END expanded_train:311141 full_diff ===`를 확인했다. 서로 다른 입력이다. 선택 본문은 candidate에서 시작해 직접 수정했다.
- 아래는 필요한 기호·함수 대상 또는 수식이 빠져 있어 해당 의존 단위로 원형 보류한 구간이다.
  - 도입: `수학에서 람베르트 W 함수()는 복소함수 의 역관계의 일부인 함수들의 집합이며, 다음과 같은 공식을 가진다.`
  - 이어지는 미상 주체절: `가 전사 함수가 아니기 때문에, 관계 W는 z=0일 때를 제외하고 여러 값을 가질 수 있다.`
  - 역사 중 미상 대상절: `1783년 레온하르트 오일러는 이 방정식의 특수한 경우인 에 대한 논문을 발표하였다.`
  - 도함수: `음함수의 미분을 사용하여, 임의의 W의 가지가 상미분방정식` 뒤에 식이 비어 있고, `를 만족시킴을 안다.`가 이어진다. 이 식에 직접 연결되는 설명도 함께 보류했다.
  - `따라서, W에 대한 다음 공식을 얻는다.` 뒤의 공식 예고/값 없는 식 슬롯.
  - `한편, z = 0에서 W의 미분계수는` 뒤에 값이 없고 `이다.`로 닫히는 문장.
- `(W는 z = −1/e에서 미분가능하지 않다.)`는 주체와 점이 적힌 완결 진술이라 원래 표현으로 보존했다. `람베르트 W 함수는 초등 함수로 나타낼 수 없다...`라는 완결된 사용 설명, 1758년 역사문과 1925년 언급문, 치환적분 문장, 외부 링크와 분류도 보존했다.
- 내용이 없는 `다른 공식들`, `그래프` 표제는 선택 본문에서 분리했다. 빈 `참고 문헌` 표제는 candidate에서 이미 분리되어 있었다. 실제 링크 두 개가 있는 `외부 링크`는 보존했다.
- 수식/대상/연결을 추정해 복원하거나 외부 사실을 검증하지 않았다. 선택 TXT 끝에는 입력 candidate에 없던 최종 LF가 추가되었다.
