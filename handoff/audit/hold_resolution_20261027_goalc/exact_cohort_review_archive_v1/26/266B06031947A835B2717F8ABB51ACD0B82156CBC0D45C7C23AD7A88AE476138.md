# expanded_train:479593 원형 보류

- `A manual way to blur a`는 원문에서 다음 독립 문장 `blur()method only removes focus from its object, without giving focus to any other field in the form or in the page.` 앞에 붙은 미완 조각이다. 이 조각만 분리했다. `blur()` 메서드가 자체 대상에서 초점을 없앤다는 실제 설명은 API 이름을 유지하고 `blur() method`로 띄어 본문에 보존했다.
- `August 10, 2000|`의 마지막 `|`는 날짜 뒤에 홀로 남은 구분 기호여서 정리했다. 날짜, 앞의 제목 줄, 뒤의 실제 제목·발행 팁·저자 표시는 유지했다.

`blurevent`, `textobject`, `blur()method`는 각각 `Blur event`, `text object`, `blur() method`로 단어 경계를 최소 정리했다. HTML 예제의 실제 `onFocus="this.blur()"`, `SIZE="40"`, `VALUE` 문자열은 그대로 보존했다. API 동작이나 코드 결과는 새로 만들지 않았다.
