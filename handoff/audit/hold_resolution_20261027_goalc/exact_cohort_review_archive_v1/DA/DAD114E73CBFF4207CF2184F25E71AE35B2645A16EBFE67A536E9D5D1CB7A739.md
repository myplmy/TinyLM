## 값과 목록이 빠진 직접 의존 구간
- `Deterministic` 설명 뒤의 `The default value is`는 값이 비어 있어 그 포인터만 분리했다.
- `DEFINERis the creator of the procedure. The default value is`에서 기본값 포인터만 값 없이 남아 있어 그 포인터만 분리했다. 실제 creator 설명은 본문에 남겼다.
- `Comment : For documentation purposes; the default value is`에서 기본값 포인터만 값 없이 남아 있어 그 포인터만 분리했다. 문서화 목적 설명은 본문에 남겼다.
- `There are technically three standard loops:` / `LOOP loops, and` / `REPEAT loops.`는 열거 항목과 수량이 완결되지 않아 이 불완전한 문장 묶음만 분리했다. 이어지는 GOTO 설명 및 실제 예시는 원문대로 본문에 남겼다.

빈 기본값을 채우거나 빠진 반복문을 추정하지 않았다. 저장 프로시저의 완결된 정의·호출·매개변수·변수·흐름 제어·커서 설명과 코드 조각은 그대로 유지했다. 코드를 실행하거나 기술 내용을 외부 검증하지 않았다.
