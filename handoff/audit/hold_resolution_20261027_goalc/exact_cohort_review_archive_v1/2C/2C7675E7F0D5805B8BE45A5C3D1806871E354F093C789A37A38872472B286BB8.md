# expanded_train:445466 원형 보류 기록

memcmp() 설명은 남아 있는 본문에 OS X의 이론적 -255~+255 범위, Linux 반환값의 정수형 범위 설명, signed char 범위, 취약성 전제와 SSE 최적화 조건이 구체적으로 적혀 있어 모두 그대로 보존했습니다. 실제 인용 내용이 전혀 없는 man page 예고만 분리했습니다.

- `According to my Linux man page:`
- `And according to my OS X man page:`

인용할 man page 문장을 생성하거나 OS/라이브러리 주장을 외부 지식으로 교정하지 않았습니다. 각 수치·범위·조건과 후속 보안 권고는 원문이 실제 말한 내용으로 남겨 두었습니다.
