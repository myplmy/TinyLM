# 1319447 보류 원형

## 빠진 초기 Person 코드와 그 직접 지시

```text
Very easy. Now, in a normal world you would have something like this, in order to create a new instance of a class person.
This code is classic and very verbose.
```

원문에서 이 구절이 가리키는 초기 코드가 없으므로 그 코드에 대한 문장만 분리했다. 실제 `PersonFactory.CreatePerson(...)`와 `PersonFactory.CreateAddress(...)` 호출은 본문에 보존했다.

## 소실된 인터페이스/UML/구현 블록의 직접 예고

```text
And this is the final result:
Look at the UML:
// we can skip this line now ...
Let’s see the code:
Let’s the concrete implementation of this factory:
Person Fluent Factory
And now Visual Studio will follow our rules …
```

이 표제와 주석은 빠진 코드나 UML을 직접 가리키고 있어 원형으로 보존했다. 명시된 `IInitFactory`, `IPersonFactory`, `ICreateFactory`, 실제 `IPersonFactory` 메서드 서명, 예시 호출 및 Fluent Interface 산문은 본문에 유지했다. 빠진 구현은 만들지 않았다.

## 누락된 참조 대상

```text
If you don't know what I am talking about have a look here.
```

링크 대상이 원문에 없어 지시문만 분리했다. 같은 문장의 실제 Lambda Expressions 언급은 본문에 보존했다.
