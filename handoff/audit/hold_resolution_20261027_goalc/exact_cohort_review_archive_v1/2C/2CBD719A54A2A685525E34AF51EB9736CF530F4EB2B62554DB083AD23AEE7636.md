# expanded_train:421 — 누락 조건식·값과 직접 종속 구간 원형

원문·후보의 전체 diff 및 세 순서 패킷을 확인했다. 수식·점·집합·함수값을 외부 수학 지식으로 채우지 않았다.

## 원형 HOLD

### 거리 함수와 집합의 미상 조건

- 원문 정의: `집합 위의 거리 함수(距離函數, )는 다음 조건을 만족시키는 함수` 뒤의 빈 식, 이어지는 `이다.`
- 원문 공리 조각:
  - `(구분 불가능한 점의 동일성) 임의의 에 대하여,`
  - `(대칭성) 임의의 에 대하여,`
  - `(삼각 부등식, ) 임의의 에 대하여,`
  - `(삼각 부등식)` 뒤 빈 대체 식.
  - 원문 `여기서 로 잡으면 가 되어, 대칭 공리를 얻는다.`
  - 첫째 조건을 `로 약화시키면`으로 시작하는 유사 거리 함수 연결절.
- 실제 기호·변수·조건식이 비어 있어 완전한 거리 함수 공리 정의 및 유사 거리 직접 설명 블록을 보류했다. 채워진 이름·용어가 없는 공식을 만들지 않았다.
- 원문 특수 집합 절: 점·중심·반지름 값이 모두 비어 있는 열린 공/닫힌 공 정의와, 빈 조건식을 직접 예고하는 유계 집합 정의(`인 점 가 존재한다.`)는 해당 정의 블록만 보류했다.
- 원문 거리 위상 절의 빈 열린집합 조건: `즉, 거리 위상에서의 열린집합은 다음 조건을 만족시키는 부분 집합 이다. 모든 에 대하여, 인 가 존재한다.`의 식·기호를 보충하지 않았다.
- 원문 `거리 위상은 거리 함수 를 연속 함수로 만드는 가장 엉성한 위상이자, 함수 집합 의 시작 위상이다.`는 함수/대상이 비어 직접 의존하므로 문장 전체를 분리했다. 별도로 완결된 열린 공 기저 정의와 모든 거리 공간이 위상 공간을 이룬다는 문장은 본문에 보존했다.

### 예시의 빠진 거리식

- 실수 예시 원문: `실수 에서, 거리가 절댓값을 이용하여, 로 정의되었을 때, 는 완비 거리 공간이다.`
  - 구체 공식·점 표기를 넣지 않았다. 원문이 직접 명시한 절댓값을 이용한 거리와 완비성의 정성 관계만 본문에 유지했다.
- 유클리드 예시 원문: `유클리드 공간에서, 에서, 거리를 로 정의하면, 는 거리 공간이다.`의 좌표·공식·대상 기호는 보충하지 않았다. 원문에 명시된 유클리드 거리·n차원 유클리드 공간 명명, 자연과학에서 쓰는 거리의 설명, 완비성은 실제 이름 관계로 본문에 보존했다.
- 미상 거리 예시 원문: `에서 을 거리로 정의하면, 는 거리공간이다.`는 집합·거리값·대상이 비어 있어 그 예시 문장만 분리했다. 이어지는 같은 집합에 여러 거리가 가능하고 두 거리 함수가 같은 위상을 정의한다는 일반 관계는 특정 예시에 묶지 않고 본문에 보존했다.
- 원문 노름 예시 두 건: `노름 공간 에 대하여, 거리 함수를` 다음 각각 빈 식과 `로 정의한다면, 는 거리 공간이다.`; 이어진 `이 거리 함수를 우체국 거리()라고 한다.`
  - 공식·공간·함수값 및 별칭값이 비어 있으므로 예시와 그에 직접 붙은 이름을 전부 보류했다.
- 원문 연결 리만 다양체 예시: `임의의 연결 리만 다양체 에 대하여, 거리 함수를` 뒤 빈 식과 `로 정의한다면, 는 거리 공간이다.`라는 전체 직접 의존 블록을 보류했다.
- 원문 초거리/이산 거리 예시: `임의의 집합 및 양의 실수 에 대하여,` 뒤 빈 식과 `는 초거리 함수를 이룬다. 이를 이산 거리 함수라고 한다.`의 대상이 없는 직접 의존 블록을 보류했다.

## 본문 보존 근거

실제로 적힌 두 점 사이 거리와 위상의 관계, 거리 함수가 있는 집합이라는 거리 공간 설명, 열린 공 기저의 거리 위상, 완비 거리 공간의 코시 수열 정의, 지름·유계 공간·부분 집합의 관계, Hausdorff/파라콤팩트/T6/제1 가산이라는 성질, 분해 가능/제2 가산/Lindelöf 조건의 동치, 유리수·절댓값·유클리드·연결 그래프의 이름과 완결된 관계는 수식 값을 새로 쓰지 않고 본문에 유지했다.

## 빈 표제 정리

- 후보가 제거한 빈 `참고 문헌` 표제는 유지하지 않았다.
- 실제 링크값이 없는 `외부 링크` 표제만 분리했다. `계량기하학` 분류와 값이 있는 같이 보기 항목은 보존했다.
