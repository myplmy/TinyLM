# 1330050 보류 원형

보류 조각은 학습 본문 밖에 둔다. 본문에서는 실제 명시된 `file_open`, `file_mem`, `file_string`, `file_close` 및 완결 호출·인수·리턴 조건을 보존했다. 별도 표제가 없던 API 이름은 추정하지 않았다.

| 원문 원형 | 이유 |
|---|---|
| `Use this to rewind the current file to the beginning, to re-read the file etc.` | 앞에 API 표제가 없다. rewind 동작을 다른 이름 있는 함수에 연결하지 않았다. |
| `This reads (or writes if in a @serialize write) the variable from(to) the current file.` | 읽기·쓰기 동작의 API 표제가 소실돼 있다. |
| `Returns the number of items remaining in the file, if it is in read mode. Returns < 0 if in write mode. If the file is in text mode (file_text(handle) returns TRUE), then the return value is simply 0 if EOF, 1 if not EOF.` | 함수 이름 없이 반환 조건과 `file_text` 조건이 시작되어 어느 API의 반환인지 확인할 수 없다. 본문에서 `file_avail` 등으로 귀속하지 않았다. |
| `istext ? use_diff_avail syntax;` | 조건식/식별자가 손상되어 실행 예로 남길 수 없다. |
| `If the file was a text file (and ended in .txt), this will return 1. If you need to use different file_avail() logic for text files (you often will), you can query it this way.` | 바로 앞의 손상된 `istext` 식을 지시하므로 직접 의존 설명으로 함께 보류했다. |
| `Closes a file opened with file_open().` | 원문은 이 문장 바로 앞에서 실제 함수 `file_close()`를 사용한다. working 본문에서는 그 유일한 국소 이름만 연결해 `file_close() closes a file opened with file_open().`로 문법을 정리했다. |
