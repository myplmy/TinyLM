# 37112 원형 보류·정제 기록

- 미상 대상으로 향하는 이름 병기 원형: `아이오딘(←)`, `요오드(←)`, `옥도(沃度←)`, `옥소(沃素←)`, `La(←)`. 화살표가 연결하는 누락 값을 추정하지 않고 각 괄호 병기만 원형 보류했다. 실제 명칭·한자·La·원자 번호와 나머지 문장은 보존했다. 다른 반응식·기호의 화살표는 이 판단에 포함하지 않았다.
- 원문 `그리스어 를 따라`에서 값 없는 슬롯은 보충하지 않고 `그리스어를 따라`로만 문법을 잇고, 미상 그리스어 낱말은 원형에 기록했다.
- candidate에서 이미 제거한 빈 `아이오딘산염()` 괄호와 빈 `각주` 표제를 유지했다. 내용 없는 `화학 및 화합물`, `응용` 표제도 분리했으며 아래 생물학 설명을 보존했다.
- 원소의 성질·역사·수치·조건·출처·분류를 외부 지식으로 수정하거나 추가하지 않았다.
