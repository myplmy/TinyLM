# 946732 — 원형 보류

후보에서 실제 없는 다이어그램/이미지 또는 비어 있는 말미 절에 직접 의존하는 조각만 분리했다. 주변에서 완결된 Objective-C 설명·메서드명·조건·문장은 본문에 유지했다.

- 빠진 다이어그램 직접 포인터: `The Objective-C runtime offers places to initialize your classes during its startup, as the following diagram shows:` 본문에는 주절만 남겼다.
- NSApplication 다이어그램/이미지 의존 블록: `Here is the typical startup for NSApplication (as invoked through NSApplicationMain() in the previous diagram):` / `This image shows the application (normally NSApplication but this is configurable in the Info.plist file) being initialized and run. Despite the fact you can change the principal class of your application, it is advised that you don't — so this isn't the first place to consider putting startup code.`
- NIB 로딩 다이어그램 포인터와 그 설명: `An Interface Builder NIB file is loaded as follows:` / `Application windows, document windows, the menubar and the NSApplication delegate are all typically loaded from a NIB file in this fashion.` 이후 완결된 init/IBOutlet/awakeFromNib 설명은 보존했다.
- 문서 로딩 다이어그램을 직접 가리키는 `A document is loaded as follows:`만 분리했다. 다음 문장의 실제 init methods와 windowControllerDidLoadNib 설명은 보존했다.
- 누락된 목록을 직접 예고하는 `These locations are:`와 이어진 `as well as the usual init methods for your own subclasses.`를 분리했다. 기존에 이름이 나온 메서드들에 관한 결론 문장은 보존했다.
- 내용 없는 말미 표제 `Break into Debugger`를 분리했다.
