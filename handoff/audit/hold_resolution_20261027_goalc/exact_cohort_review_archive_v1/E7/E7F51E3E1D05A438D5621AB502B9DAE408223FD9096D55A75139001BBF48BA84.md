# 1008072 원형 보류

학습 본문에서 분리한 페이지 탐색·보기 제어 UI. 원문 표기를 그대로 보존한다.

```text
Back to top
Hide question numbers Show categories Show notes Show audio
Version (?): Lightly Edited, Ra Contact, Relistened, Original, Swedish, Czech
Back to top
```

두 `Back to top`은 문답 본문이 끝난 뒤와 보기 옵션 뒤에 각각 놓인 페이지 이동 UI다. 숨김/표시 제어와 판본·언어 선택 행도 읽기 본문이 아니라 표시 UI/선택값이므로 본문에 섞지 않았다. 문답과 저작권·연락 정보는 그대로 둔다.
