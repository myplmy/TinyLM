# expanded_train:946424 원형 분리 및 구조 정리

- 원문 `The settings for the terminal connection are the same whether it’s a`는 비교 대상이 없고, `Open the correct COM port:` 및 `Change connection properties under` / `Connection > Serial...:`는 뒤따르는 설정 값·완료 단계가 없어 각 미완 절/단계로 분리했다.
- 원문 `It also tends to use` / `print() instead of`는 비교항이 없으므로 분리했다.
- 원문 `It’s important to note` / `print("hello") are exactly the same: they both output to`에는 비교 주체와 출력 대상이 명시되지 않는다. `uart module exposes many useful functions such as`도 목록이 없어 각 미완 설명을 분리했다.
- 두 문장 끝의 `:`는 다음에 목록/절차가 없어서 마침표로 정리했다. 원문은 `To access this interface, the mbed serial drivers must be installed:` 및 `Once installed, plugging in the microbit will cause a COM port to appear on the the host computer:`였다. 마지막 `Establishing a serial connection is useful when developing applications on the computer to interact with the microbit:`도 마침표로 끝내 본문 안의 완결 주장으로 보존했다. Tera Term 소개도 같은 이유로 끝의 콜론을 마침표로 정리했다.
- 숫자 `COM port 5`, `115200 baud rate`, 명명된 Tera Term/Realterm, USB·PXT/Python·UART 설명은 본문에 그대로 유지했다. 빠진 비교값, 포트 설정, 코드 및 이미지 내용은 만들거나 확인하지 않았다.
