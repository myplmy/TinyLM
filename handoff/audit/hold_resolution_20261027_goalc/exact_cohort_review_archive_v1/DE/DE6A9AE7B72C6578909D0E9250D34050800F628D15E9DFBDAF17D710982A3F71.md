# 573989 원형 보존 메모

## 분리한 즐겨찾기 UI

후보에서 단독 `Add To Favorites` 두 줄을 제거했다.

```text
Add To Favorites
Add To Favorites
```

첫 줄은 Huichol yarn-card 활동 앞에 놓인 저장 UI이고, 두 번째 줄은 잘린 bookmark 활동 소개 뒤에 놓인 저장 UI다. 두 줄 모두 활동 내용이나 제작 단계가 아니다. `Join Us on`, 실제 yarn-card 재료·문화 설명·제작 단계, 다른 활동 소개와 footer는 그대로 유지했다. bookmark 소개의 원문 말미가 `using a`에서 끊긴 사실도 임의로 완성하거나 수정하지 않았다.

## 판독 범위

지정 original/candidate 전문과 순서 패킷 0001을 BEGIN부터 END/EOF까지 대조했다. 전체 diff는 줄 차이가 없었다. 새 본문에서는 위 두 즐겨찾기 UI 줄만 분리했다.
