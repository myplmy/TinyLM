# 285825 출생연도 충돌 및 빈 범위 끝점 보류

원문 리드의 `1979년 12월 14일`과 분류의 `1978년 출생`은 같은 인물의 서로 다른 단정 출생연도다. 어느 연도도 선택하지 않는다. 최종 본문에는 리드의 실제 12월 14일을 연도 없이 남긴다.

원문 후보의 `12월 14일 - )`는 종료 날짜 없는 범위 포장이다. 실제 사망일은 없고 `살아있는 사람` 분류가 있으므로 하이픈과 빈 끝점 괄호 포장만 정리했다. 다른 사람과의 연령 차이, 경력 날짜, 실제 결혼일은 이 출생연도 판단에 사용하지 않는다.

분리한 원문 조각:

> 나카노 미나코(中野 美奈子, なかの みなこ, 1979년 12월 14일 - )
>
> 1978년 출생
>
> 12월 14일 - )
