# 894853 보류 원형

본문에서 다음 원문만 분리했다.

1. `$(document).ready(function(){\n    $('.myList li').on('click touchstart', function() {\n        $('.myDiv').slideDown('500');\n    });\n}` — `사용예`의 두 번째 코드 예시는 `ready` 호출을 닫는 `);`가 보이지 않아 블록 경계/완결성이 불명확하다. 원저자 미완 예시인지 추출 누락인지 결정하지 않고 이 코드 단위만 보류했으며 닫는 토큰을 만들지 않았다. 앞의 `$('div').on('tap', ...)` 예시는 완결되어 본문에 유지했다.
2. 빈 제목 `출시 역사` — 뒤에 역사 내용이 없다.

candidate는 비어 있는 `각주` 및 `참고 자료` 표제도 제거했으며, 외부 링크와 분류는 보존했다. 본문에는 완결된 라이브러리 설명, 호환성 관계, 브라우저 지원 범주와 실제 외부 링크·분류를 그대로 유지했다.
