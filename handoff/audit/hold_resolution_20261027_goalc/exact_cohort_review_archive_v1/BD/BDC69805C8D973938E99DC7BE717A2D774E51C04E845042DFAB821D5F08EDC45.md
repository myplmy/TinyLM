## 사유와 경계

바로 뒤에 실제로 나열된 함수 이름은 `mcrypt_module_open()`, `mcrypt_create_iv()`, `mcrypt_enc_get_iv_size()`, `mcrypt_enc_get_key_size()`, `mcrypt_generic_init()`, `mcrypt_generic()`, `mcrypt_generic_deinit()`, `mcrypt_module_close()`로 여덟 개다. 원문의 `seven` 수량과 나열값이 일치하지 않으므로 어느 한쪽을 정답으로 선택하지 않고 수량만 보류했다. 수정 본문은 해당 문장을 “To encrypt data requires the following functions:”로 연결하고, 명시된 함수 이름·프로토타입·실제 코드·각 기능 설명은 원문 그대로 유지한다. 외부 API 검증이나 코드를 실행하지 않았다.

원형 수량 주장은 보존을 위해 이 sidecar에만 기록하며 학습 본문에는 넣지 않는다.
