# 202854 원형 보류 구간과 보존 경계

## 지정 입력 판독
지정된 original/candidate 연속 패킷 0001–0016의 전체 프레임을 순서대로 읽었다. original, candidate, full_diff의 각 논리 END를 확인했다. 새 본문은 candidate에서 시작해 아래에 적은 구간만 분리했다.

## 원형 보류 구간
1. 두 인물 어원 설명에서 실제 일본어 표기/표제값이 비어 있는 종속 절:
   - `이름인 '드라마투르기'는 문학·드라마 예술의 '극작법(Dramaturgy)'에서 유래되었으며, 일본어 표기인 ''의 ''는 검을 뜻하는 일본어이다.`
   - `이름인 '에피소드'는 'Episode'에서 유래되었으며, 일본어 표기인 ''의 ''는 검을 뜻하는 영어 단어 'Sword'의 일본어식 표기이다.`
   앞의 실제 이름 유래 문장은 유지하고, 빈 문자에 직접 의존하는 뒤 절은 원형 그대로 이곳에 기록했다. 빠진 일본어/한자 표기를 추정하지 않았다.
2. 주제가 블록의 빈 제목 슬롯:
   - `여는 곡 〈〉(돌아가는 길)`
   - `여는 곡 〈〉(연애 circulation)`
   - `닫는 곡 〈〉 (당신이 모르는 이야기)`
   빈 꺾쇠 제목 표시만 본문에서 제거하고 실제 괄호 안 표기, 작사·작곡·편곡·노래·레이블 관계는 보존했다. 빈 원제의 값을 추정하거나 괄호 안 표기를 다른 언어의 정식 제목이라고 검증하지 않았다.
3. 실제 목록 내용이 전혀 없는 표제 블록:
   - `OP·ED 목록` / `오프닝 애니메이션` / `엔딩 애니메이션` / `방영 목록`
   - `WEB 라디오` 설명 뒤의 빈 `방영 목록`
   - 원문 말미의 빈 `각주` 표제 (candidate가 이미 제거함)
   각 표제/예고가 가리키는 목록이나 각주 본문은 입력에 없다. 이 공란 목록을 복원하지 않았다.
4. CD 곡명 뒤의 빈 괄호 병기: `<추억의 앨범>()`, `<고마워요, 작별이네요>()`, `1. 입학 시험()과 2. 합격 발표(), 44. 봄방학()와 45. 골든 위크(), 53. 계단()과 54. 괴담()은 각각 하나의 트랙에 모여 있다.` 실제 제목·번호·각 제목의 순서와 각각 하나의 트랙이라는 원문 관계는 유지하고, 값 없는 괄호만 제거했다.

## 보존 경계
작품 소개·줄거리·두 사건 연혁표의 실제 일시/사건/작품명·등장인물의 이름/성우/관계와 조건·출판 및 방송 정보·채워진 스태프/주제가 크레딧·실제 DVD 목록·외부 링크와 말미 분류를 보존했다. 빈 인명 별칭 괄호는 candidate의 정리를 유지했다. 원문 수치·작품명·불확실성이나 인용을 외부에서 검증/보충하지 않았고, 표의 깨진 HTML을 새 구조로 재작성하지 않았다.
