# 1174083 보류 원형

- 빈 코드 블록을 가리키는 문장/문구만 분리했다: `...this equates to:`, `Capturing the return value from curl_exec() looks like this in code:`, `...the script looks like this:`, `Our next basic script ... gets a listing of the root directory there:`, `With both of these changes implemented, the new script looks like this:`, `...here is our final FTP script:`, `First, create the file posttest.php ... Type into the file this code:`, `...Now, create this new script:`.
- 빠진 코드에 직접 의존하는 요약/평가만 보류했다: `That script will output the same as the previous script...`, `If you are thinking that looks just like the second script...`, `Again, just a minor change ... nothing surprising in there at all.`, 임의 사용자명/암호를 바꿔 실행해 보는 지시, 누락된 최종 FTP 코드의 로그인 결과 설명, `posttest.php`의 코드 설명, 원격 서버에서 `localhost`를 바꾸라는 누락 스크립트 지시, 미제공 POST 출력 예고 및 `As you can see...` 결론.
- 실제 API 설명/상수·인자·반환 조건은 보존했다. 여기에는 `curl_init`, `curl_setopt`, `curl_exec`, `curl_close`, `CURLOPT_RETURNTRANSFER`, `CURLOPT_FILE`, `fopen`, `CURLOPT_FTPLISTONLY`, `CURLOPT_USERPWD`, `curl_error`, `CURLOPT_POST`, `CURLOPT_POSTFIELDS`, `urlencode`와 세 POST 변수명/값의 원문 설명이 포함된다. 빠진 PHP/Curl 코드를 복원하거나 새 연결을 만들지 않았다.
