## 사유와 경계

위 구절들은 각각 기능이 “available in” 뒤에서 끊기거나, 표 예시·유틸리티 포인터의 목적어가 없거나, `SpectrumDatasetOnOff` 주변의 직접 설명/API 주어·함수명이 빠져 문장이 완결되지 않는다. 명명된 LightCurve와 LightCurveEstimator 정의·클래스 역할, 실제 Table/LightCurve 및 LightCurveEstimator 예시 코드, `compute_chisq`, `compute_fvar`, `robust_periodogram` 이름과 실제 이어지는 정성 설명·조건·예시·목록 값은 그대로 보존한다. 빠진 API 이름·자료 대상·식은 만들지 않았다.

원문 `source is the model component describing the source of interest and object produced by data reduction.`에서는 첫 정의 절이 완결되어 있으므로 그 절을 마침표로 닫아 유지하고, 주어가 빠진 `and object produced by data reduction.`만 보류했다.

`Calculate the chi-square test for`는 이어질 대상이 없으므로 이 조각만 보류했다. 다른 실제 튜토리얼 제목인 `Calculate the fractional excess variance.`, `Plot a light curve and its periodogram.`, `Make random times assuming a Poisson process.`, `Compute a light curve’s period.`는 보존했다. 예시 코드의 두 함수 이름 차이를 외부 지식으로 정정하지 않고 원문 그대로 두었다.

각 원형 구절은 이 sidecar에만 보존한다.
