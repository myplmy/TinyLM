# expanded_train:12376 보류 원형

본문은 명시된 알래스카주 이름과 음차 자료, 면적·역사·지리의 실제 내용과 순서를 유지한다. 빈 병기 칸을 제거하고 채워진 음차 괄호만 닫았다. 아래 원형은 누락 어원어를 새로 만들지 않기 위해 본문에서 제외했다.

## 값이 빠진 어원 구절

```text
알래스카의 어원은 알류트족의 ", 섬이 아닌 땅"이다.
```

## 정리한 빈 병기 포장

```text
알래스카주(, , , 음차: 阿拉斯加(아랍사가)는
```

세 빈 병기 칸과 불균형한 괄호를 정리했다. 기존에 채워진 `阿拉斯加`와 `아랍사가`는 본문에 보존했다.

## 내용이 없는 표제

```text
각주
```

`각주` 표제는 지정 후보에서 이미 제거된 빈 표제이며, 원형 기록을 위해 여기에 남긴다.
