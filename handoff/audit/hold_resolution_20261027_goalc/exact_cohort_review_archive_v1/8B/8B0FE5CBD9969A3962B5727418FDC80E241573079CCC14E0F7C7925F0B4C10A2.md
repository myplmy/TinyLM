# 76046 원형 보류

- 분리한 원문 표제: `수록곡`, `발매 일정`.
- 두 표제 아래에는 실제 수록곡 목록이나 발매 일정 내용이 없었다. 따라서 빈 항목을 본문에 남기지 않고 표제만 원형으로 기록했다. 후보가 제거한 내용 없는 `각주` 표제도 되살리지 않았다.
- 제목 뒤 빈 괄호 `〈이제 찾지 않아〉()`와 `〈이렇게 사랑하는데도〉()`는 원문에 채워진 제목의 빈 별칭 포장으로 확인되어 정리했다. 제목 자체와 작사·작곡·편곡, 발매일·음반코드, 차트 성적·재발매 정보, 실제 링크/분류는 보존했다.
- 이 분리는 빈 섹션과 빈 병기 처리에 한정되며 음반 정보의 외부 검증을 뜻하지 않는다.
