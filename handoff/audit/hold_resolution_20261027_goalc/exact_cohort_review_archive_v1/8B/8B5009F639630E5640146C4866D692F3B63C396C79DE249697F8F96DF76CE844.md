# 1415486 원형 보류 — v2 본문 연결

원문과 후보는 바이트 동일했다. 수정본은 아래에 적은 실제 빈 명령·그림/코드 대상에 직접 기대는 구절만 본문에서 분리했다. 코드나 값을 보충하지 않았다. GPIO 배선·17/11 핀 관계·WebIOPi 실제 명령/설정·`webiopi()` 및 변수/메서드 설명·CSS/HTML 실제 필드와 수치·조건·경로·보안 설명은 수정본문에 남겼다.

## 원형 보류 구절

- 그림 포인터 원형: `In the pictures above,` / `[CENTER]Circuit diagram [/CENTER]` / `SEE THE HANDY CHART.`
- 설정 유틸리티 빈 명령 예고 원형: `At the command prompt, enter this to open the configuration utility:`. 뒤 메뉴 설명은 원문에 실제로 적힌 `configuration utility`라는 대상만 재사용해 독립적으로 이었다. 그 안의 빈 창 캡처 예고 `You'll see this in your window: [CENTER][/CENTER]`와 `as shown`은 분리했다. 숫자 8, `Advanced Options`, 16 설정과 나머지 탭/재부팅 순서는 보존했다.
- 소실 명령 직접 참조 원형: `Enter the above commands, one at a time to get everything we need to let Python talk to the GPIO. Without this, our project will do nothing except give us errors when we try to run it. Nobody likes errors.`
- 빠진 명령 뒤의 위치·실행 예고 원형: `You won't find it in your package manager, but installing it is still pretty easy. Make sure you're in your home folder:` / `Enter the directory you just created:` / `Run the setup script (as root):`. 실제 `tar -xvzf WebIOPi-0.7.0.tar.gz`와 `sudo webiopi -d -c /etc/webiopi/config`는 보존했다.
- 폴더 생성 명령 예고 원형: `From the command prompt, do this to make sure you're in your home folder:` / `Create a Project folder:` / `Create a Webio project folder:` / `Move to the Webio project folder:` / `Inside our Webio project, make an html folder:` / `Inside the html folder, make a folder for images, scripts and stylesheets:`. 뒤 문단의 경로 조정 조건과 사용자/기계 이름 설명은 보존했다. 빈 트리 그림 예고 `If you followed along, you should have this: [CENTER][/CENTER]`만 분리했다.
- 소실 자바스크립트 파일을 직접 지시한 원형: `When you have this file created and saved on your computer, copy it to Projects/Webio/html/scripts with Filezilla.`. 앞의 실제 함수/변수 설명은 유지했다.
- 없는 CSS 링크/코드·예시를 직접 가리킨 원형: `This link is your lifesaver when you have to write CSS. I'm not going to try and explain each and every line here, but we will take a look at each block to discuss what it does.` / `Besides drawing some nice buttons on a tiny web page like we're doing, you can do this with it. I tip my hat to Derek Kessler, and thank the gods both old and new that I wasn't asked to build that.` / `OK, let's look at this code a bit.`. 실제 블록 설명과 CSS 속성/수치/브라우저 이름은 보존했다.
- CSS 파일 자체가 없는 상태에서 그 파일을 복사하라는 지시의 원형: `Copy this file exactly as it is written to your editor, and save it as bacon.css so it works with our html. When done, copy it to the Projects/Webio/html/styles folder on your Pi.`. 수정본문은 실제 파일명 `bacon.css`와 실제 경로를 보존하는 독립 문장으로 연결했으며 파일 내용을 만들지 않았다.
- 빈 HTML 코드/그림을 직접 전제한 원형: `Once you have this file all written up in your editor,` 및 `It should look like this:`. 실제 세 meta/link 행, `index.html` 파일명, `Projects/Webio/html` 위치와 최상위 폴더 조건은 수정본문에 남겼다.
- 연결 예시 주소가 없는 예고 원형: `Enter the IP address of your Pi (the same one you use for SSH) followed by the port to talk to:`. 앞에서 실제로 제시된 WebIOPi 테스트 URL과 이후 IP/포트 설명은 유지했으며 이 위치에 주소를 복사해 넣지 않았다.
- 빈 연결 그림 포장 원형: ` [CENTER][/CENTER]` (실제 `Connecting` 표제는 보존).

위 보류 구절은 입력에 보이는 원형만 기록했다. 없는 명령, 그림, 전체 JavaScript/CSS/HTML, 예시 URL은 생성하지 않았다.
