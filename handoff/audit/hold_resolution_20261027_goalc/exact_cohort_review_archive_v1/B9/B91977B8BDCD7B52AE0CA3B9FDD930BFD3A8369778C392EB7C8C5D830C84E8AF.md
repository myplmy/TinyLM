# 21829 원형 보류 기록

## 판독 범위
지정 원문·candidate 전문과 세 순서 패킷의 original/candidate/full_diff를 논리 종료 및 실제 EOF까지 대조했다. 초기사본과 새 본문 초안의 전체 diff도 확인했다. 본문에 있는 책의 제목·저자·출판사·날짜·수량·주장·출처는 새로 만들거나 검증하지 않았다.

## 제목/대상이 비어 있는 유사 도서 조각
`비슷한 책` 아래의 다음 항목은 인명이 채워졌으나 작품 제목은 비어 있고, 뒤 설명과 날짜·발행량은 그 제목 없는 항목에 붙어 있다. 원문 순서대로 이 묶음만 본문에서 분리했다.

```text
조지 아키야마·코붕유 - 《》(, )
중화인민공화국에 도착하고, 주로 비판하는 입장에서 쓴 만화이다. 2005년 8월 6일 발행했다. 2005년 9월 22일 현재 18만부 발행
```

작품명을 추정하거나 두 사람에게 다른 책의 저자 역할을 붙이지 않았다. `비슷한 책`의 별도 채워진 코바야시 요시노리의 제목·출판사 항목은 본문에 유지했다.

## 빈 절 제목
다음 제목 아래에는 내용이 없고 곧 다른 절 `주장`으로 넘어가므로, 빈 제목만 본문에서 분리했다.

```text
등장인물
```

## 문서 끝 분류 꼬리
실제 외부 링크 목록 다음에 설명 없이 붙은 문서 분류 줄을 본문에서 분리했다.

```text
일본의 만화
일본의 반한 감정
2005년 책
```

이 줄들은 페이지 분류 꼬리로 보존했다. 실제 `같이 보기` 항목과 `외부 링크`의 명명 자료는 본문에 유지했다.

## 원문에 있던 빈 괄호 정리
candidate가 비어 있는 병기 포장만 제거한 부분은 실제 이름과 출판사 값을 유지했다. 해당 원형은 다음과 같다.

```text
《만화 혐한류》(, )
니시오 간지(), 니시무라 고유(), 오쓰키 타카히로(), 시모조 마사오()
(겐도샤, )
```

야마노 샤린, 신유샤의 일본어·영문 표기, 네 기고자의 이름, 겐도샤는 본문에 보존했다. 이 빈 괄호 정리는 표기 정리일 뿐 새 이름·귀속 추가가 아니다.
