## 본문에 남긴 독립 내용

```text
On a basic level, nondimensionalization gets all units out of the problem.
Getting units out of the problem is important because most natural functions don't have any meaning when fed a unit.
Do not misunderstand: you can solve any problem you like keeping units in place.
A motivation for nondimensionalization can be seen by noting that ratios of variables to dimensions ("dimension" includes both a size and a unit) have a tendency to show up again and again.
The solution of one nondimensional problem is far more useful then the solution of a specific dimensional problem. This is especially true if the problem only yields a numeric solution: solving the nondimensional problem greatly reduces the number of charts and graphs that need to be made since you've reduced the number of parameters that could affect the solution.
```

## 판정 범위

첫 문단의 BC·간단한 수·변수 슬롯이 비어 있고 뒤의 전개 전체가 그 수식에 직접 기대므로 해당 예시 연쇄를 보류했다. 완결된 단위 제거 설명, 단위를 가진 함수를 다루는 이유, 단위를 유지해도 문제를 풀 수 있다는 문장, 변수와 차원의 비율에 대한 일반 설명, 무차원 문제의 일반적인 유용성은 보존했다. 누락된 BC, 변수, 계산, 미분식, 값은 생성하지 않았다.

원문에서 `nondimensionalization does two things` 및 `- Gets all units out of the problem.`을 연결해 본문 문장 하나로 정리했다. 원문의 `We'll talk about getting units out of the problem for now: important because most natural functions don't have any meaning when fed a unit.`은 원문 근거로 문법만 연결해 보존했다. 빈 식을 가리키는 인용과 기술 설명은 sidecar에서 원형대로 유지한다.
