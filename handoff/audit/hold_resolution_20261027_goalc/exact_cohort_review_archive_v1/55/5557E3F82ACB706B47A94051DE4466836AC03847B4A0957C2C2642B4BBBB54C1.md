# expanded_train:569146 원형 보류

`array_rand()`의 실제 입력 배열과 호출은 유지했으나 결과 예시에는 키 자리의 값이 없어 해당 결과 조각과 뒤따르는 구분선만 분리했습니다.

> Array (  => Arizona  => Ohio ) ===========================================================

`array_chunk()`의 설명은 완결되어 있어 본문에 남겼습니다. 뒤의 `$cards` 배열은 쉼표에서 끝나 닫히지 않고, 다음 `array_chunk` 호출과 결과 예시도 이 불완전 입력에 직접 의존합니다. 그 코드·출력 전부를 아래 원형 그대로 보류했습니다. 결과의 빠진 키/값이나 카드 입력을 보충하지 않았습니다. 해당 코드 바로 앞 `An example follows:`도 이어질 수 없는 예고라 함께 보류했습니다.

$cards = array("jh","js","jd","jc","qh","qs","qd","qc",
// shuffle the cards
// Use array_chunk() to divide the cards into four equal "hands"
$hands = array_chunk($cards, 4);
This returns the following (your results will vary because of the shuffle):
Array (  => Array (  => jc  => ks  => js  => qd )
 => Array (  => kh  => qh  => jd  => kd )
 => Array (  => jh  => kc  => ac  => as )
 => Array (  => ad  => ah  => qc  => qs ) )============================================================
