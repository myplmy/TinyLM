# 747618 별도 보류 원형

## 주 경계 조각·대상 없는 거리의 원문 행

```
| 매니토바주 온타리오주 — 부터
| 위스콘신주 아이오와주 — 부터 일리노이주 — 부터 아이오와주 — 부터 일리노이주 — 부터 미주리주 — 부터 아칸소주 — 부터 미시시피주 — 부터 아칸소주 — 부터 약 2km 미시시피주 — 부터 루이지애나주 — 부터 미시시피주 — 부터 약 4km 루이지애나주 — 부터 미시시피주 — 부터 루이지애나주 — 부터
| 캄페체주 타바스코주 — 부터, 대부분 동쪽으로 2km 떨어진 과테말라 국경선과 거의 평행에 가깝게 이어짐.
```

세 행의 실제 주 이름과 반복·순서는 본문에 목록으로 보존했다. 시작점이 빠진 `— 부터` 조각과 해당 주 행 안에서 측정 대상을 특정할 수 없는 `약 2km`, `약 4km`만 보류했다. 캄페체주·타바스코주 행의 과테말라 국경선과 거의 평행하게 이어지는 실제 설명 및 그 대상이 적힌 2km 관계는 본문에 유지했다.

## 미상 청구 주체 원문

```
| style="background:#b0e0e6;" | 가 영유권을 주장하는 페테르 1세섬()의 바로 서쪽을 지나감
```

본문에는 페테르 1세섬의 이름과 바로 서쪽이라는 통과 관계를 남겼다. 미상 주체의 영유권 주장 절만 보류했다. 별도 남극 행의 실제 `영유권 주장이 없는 권역` 설명은 보존했다.

## 편집 근거

갈라파고스 제도 핀타섬·산티아고섬의 실제 이름과 각각 바로 서쪽이라는 방향은 보존하고 빈 괄호만 제거했다. 반복 해역, 표의 행 구조, 남극 서쪽/동쪽 방향 설명을 유지했다.
