# expanded_train:714145 — 빠진 man 예제 명령 안내

원문에서 분리·정리한 구간:

> Finally, as a bonus, users of Unix-like operating systems (FreeBSD, Linux, Mac OS X) can use the man command to look up functions by name. For example:
> This command displays the manual entry for the sqrt() function, including its options, common uses, and related or similar functions.

`sqrt()` 항목을 여는 `For example:` 뒤에 해당 man 명령 자체가 없어, 빠진 명령을 참조하는 도입만 분리했다. 설명에 실제로 적힌 내용은 `The manual entry for the sqrt() function includes its options, common uses, and related or similar functions.`로 문장 주체만 명시해 본문에 보존했다. 뒤의 완결된 `man 3 log` 명령 예제와 C 함수 설명·코드·값은 유지했고, 누락 명령을 추정하거나 실행하지 않았다.
