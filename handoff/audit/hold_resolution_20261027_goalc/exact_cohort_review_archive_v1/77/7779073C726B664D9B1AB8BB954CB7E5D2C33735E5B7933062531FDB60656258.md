# 38287 원형 보류

원문에서 비어 있던 별칭 슬롯은 다음과 같다.

- `보그다노비치(, ‘보그단의 아들’이라는 뜻)`
- `이폴리트 보그다노비치(, 1743(율리시스 력에서는 1744 3/1)~1803)`
- `막심 보그다노비치(, 1891~1917)`
- `보그단 보그다노비치 (건축가)(, 1922~)`
- `피터 보그다노비치(, 1939~)`
- `라데 보그다노비치(, 1970~)`
- `보그다노비치()`

빈 이름·별칭 값은 보충하지 않았다. 실제 뜻 설명, 인명, 1743/율리시스 력의 1744년 3월 1일 표기, 생몰 표기, 직업 및 도시 설명은 본문에 보존했다.

원문의 마지막 빈 `같이 보기` 표제는 뒤에 항목이 없어 본문에서 분리했다. 실제 관련 대상은 생성하지 않았다.
