## 판독 범위

지정 original/candidate 전문과 0001–0009 순서 패킷을 각 END까지, 전체 diff를 끝까지 대조했다. source와 candidate의 본문은 동일하다. 선택 본문은 revise_1245140_v2.txt이며 이전 초안 revise_1245140_v1.txt는 선택하지 않는다.

## 원형 보존 및 본문에서 분리한 구간

- 빈 목록 표제 `Header files:`와 `Implementation files:`는 값이 뒤따르지 않는다. 빈 표제 자체를 본문 목록으로 두지 않고 원형 상태를 여기 보존한다.
- `ODR stands for the One Definition Rule. It is...` 다음의 ODR 설명은 이어지는 대상과 문장이 완성되지 않는다. 확장된 약어와 실제로 완결된 설명은 본문에 남기고, 뒤의 미완 꼬리를 여기 보존한다.
- `Modernes C++ Mentoring` 및 `Be a part of ... / Subscribe ...` 홍보 문구는 기술 설명이 아닌 서비스 구독 안내라 본문에서 분리했다. 원문 표기와 순서는 그대로 기록한다.
- `Let me see what my linker says... The following code example has one header file header.h and two implementation files.`는 이어지는 코드 예제가 없다. 선택 본문은 빈 예제 예고를 제거하되, 원문에서 독립적으로 채워진 구현 파일 관계를 문맥이 넓어지지 않게 유지했다. 누락된 코드나 파일명은 보충하지 않는다.
- `The linker complains about the multiple definitions of func:`는 실제 linker 출력이 뒤따르지 않는 예고라 분리했다. 출력 내용은 만들지 않았다.
- 끝부분의 `Let's see which effect these significant features have on C++-`는 문장이 미완성이어서 보류했다.
- `Prefixing e.g. a type name like this:` 뒤에 그 예고에 해당하는 타입 이름은 없다. 실제 뒤따르는 cout/endl/string 항목은 본문에 남기고, 값 없는 예고와 그에 직접 연결된 잔여 설명만 분리했다.

## 경계

본문에는 채워진 코드, 숫자, 시간 단위, 저자·발표자 이름, 행사·세미나 및 독립 설명을 보존했다. 이 기록은 빠진 코드나 예제, 이름을 추정하거나 채우지 않는다.
