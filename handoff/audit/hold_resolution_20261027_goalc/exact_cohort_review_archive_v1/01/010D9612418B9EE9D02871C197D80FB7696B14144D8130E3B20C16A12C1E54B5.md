# 1332947 원형 보류

- `__init_ is the class constructor.` — `__init_`라는 손상 식별자를 임의로 고치지 않았다. 원문 뒤쪽의 실제 `__init__` 언급은 보존했다.
- `class Example: def __init__(self): print("Example object is created") def PrintHello(self): self.name="1" print("hello world")` — 여러 함수 정의·문장·출력의 경계가 평탄화되어 복원하지 않았다. 실제 `__init__`, `PrintHello`, `self.name`, 문자열 값은 이 원형에 보존한다.
- `If you observe the above class definition you can see that __init__ method as well as the PrintHello() method are passed a parameter called self.` — 위 코드 경계를 복원하지 않고 완결된 메서드명·self 관계만 본문 문장으로 남겼다.
- `We can access the attribute name from the calling method as:` 및 `ob=Example() ob.PrintHello() print(ob.name) #this will print the value "1"` — 이어지는 예제의 문장/문장 경계를 추정하지 않았다. 실제 attribute 설명은 본문에 남겼다.
- `Leave a Reply` — 사이트 댓글 UI이므로 본문 밖에 분리했다.

`class Example: pass`는 완결된 한 줄 정의이며 그대로 보존했다. 코드 실행이나 문법 복구는 하지 않았다.
