# 501523 원형 HOLD

두 API 소개에는 실제 특수 메서드 이름이 없습니다. 빠진 이름을 만들지 않고, 본문에는 독립적으로 이해되는 Connection/DbGate를 통한 모델 구성 관계와 DbContext/ObjectContext 문맥을 유지했습니다. 해당 메서드 이름을 예고하는 꼬리만 분리했습니다.

원문 첫 절:

```text
There is an opportunity to create a model directly based on Connection object using DbGate component and a special method of DataModel:
```

본문은 명시된 Connection과 DbGate 관계를 보존하고, `and a special method of DataModel:`만 제외했습니다. 이어지는 표 구조/필드 이름 설명은 “on the fly” 제목 아래에서 독립적으로 읽히므로 유지했습니다.

원문 끝 절:

```text
When using EntityFramework we can get a model by DbContext (or ObjectContext for older versions of EF) class using special method
```

본문은 DbContext/ObjectContext를 통한 모델 취득 설명을 보존하고 `using special method`만 제외했습니다. 빠진 메서드 이름이나 호출은 추가하지 않았습니다.
