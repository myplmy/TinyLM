# 17449 보류 조각

판정 보조: 본문 수정은 선택적 별칭 칸과 실제 내용이 없는 세 하위 표제만 정리한다. 원문에 이미 있는 뵤르켄 축척, 인명, 주장, 수치, 설명 및 `Particle data group` 표기는 유지한다. 빠진 별칭은 추정하지 않는다.

## 원형

- `뵤르켄 축척()`의 빈 괄호: 뒤의 문장에서 이미 `뵤르켄 축척(Bjorken scaling)`으로 이름이 채워져 있어, 누락된 병기는 만들지 않고 빈 괄호만 본문에서 제거했다.
- 빈 표제: `참고 문헌`, `리뷰 논문`, `교과서`. 세 표제 아래에는 본문 내용이 없다.

## 처리 근거

첫 줄의 비어 있는 구분 슬롯과 세 저자 이름 뒤의 빈 괄호는 후보에서 정리됐으며, 출처 파일의 다른 문장과 실제 인명은 보존했다. 외부 링크 아래의 실제 `Particle data group` 문자열은 유지했다.
