# expanded_train:230034 정제 근거

지정 원문·후보와 packets 1–8의 original/candidate/full_diff를 순서대로 읽어 마지막 packet의 논리 END와 EOF를 확인했다. 후보는 원문에서 빈 각주 표제만 제거한 본문이었다. 이 빈 표제 제거는 유지했다.

## 정리한 빈 괄호 포장

원문에 값이 없는 병기 포장만 제거했고, 실제 이름·문자·로마자 대응·뜻·수목명·조건은 유지했다. 원형의 대표 포장은 다음과 같다.

- 오감(, )
- 베흐리스닌(), "페더()", "아크머()", 브리하로감()
- "아크미(, 가족들)"에서 값 없는 선행 슬롯과 구분 쉼표만 정리해 실제 가족들 병기를 남겼다.
- 아크머 베허(), 아크머 후허(), 아크머 미너(), 아크머 알머(), 포르페더()
- 각 문자 행의 베허(, ), 리스(, ), 페른(, ), 닌(, ), 우흐(, ), 다르(, ), 티너(, ), 콜(, ), 케르트(, ), 민(, ), 고르트(, ), 게탈(, ), 스트라프(, ), 알름(, ), 온(, ), 우르(, ), 에다드(, ), 이다드(, ), 에바드(, ), 오르(, ), 일란드(, ), 이핀(, ), 에만콜(, ), 페허(, ).

이 슬롯에 들어갈 원어 글자·어원·번역·독음은 만들지 않았다. 실제 로마자 값(B/L/F/S/N 등), 한글 이름, 뜻, 불확실성 표현, 문자 목록의 순서, 역사·문헌·연도·참고 자료·명명된 외부 링크 및 분류를 원문대로 유지했다. 본문 사실을 외부 검증하지 않았다.

빈 병기괄호를 제거한 뒤 두 닌 항목은 이름 뒤 조사만 닌는에서 닌은으로 맞췄다. 이름과 연결되는 원문 서술은 바꾸지 않았다.
