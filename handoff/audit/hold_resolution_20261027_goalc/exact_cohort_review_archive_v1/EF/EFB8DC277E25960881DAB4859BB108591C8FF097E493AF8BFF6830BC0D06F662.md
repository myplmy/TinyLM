# expanded_train:809662 — 분리한 원형

## Java 배열 생성 예시와 직접 의존 설명
원형:
In Java arrays are created as follows, int arr=new int; so if you have a generic type of T, you would expect to create a generic array this way: T=new T; but simply you can’t. Java does not allow generic array creation and this is actually because generics are implemented in Java using Erasure. Generics are implemented purely in compiler level and actually only one class file is generated for each class. So to create the array we need an ugly cast as follows, T=(T) new Object; and when you try to compile, the compiler will issue a warning that you are doing an unsafe cast!
But raising a compiler warning on a design issue may confuse someone who faced it for the first time.

보류 이유:
- 예시의 배열 표기에는 []와 크기가 채워져 있지 않고, 앞·뒤 코드형 표현도 이 상태만으로 생성 구문/타입/값을 확정할 수 없다.
- 실제 예시가 원저자의 의도적 축약/오류인지 추출 손상인지 원문만으로 결정하지 않았다. 배열 구문·크기·타입·cast를 새로 보충하지 않는다.
- 예시와 그 표기/컴파일 경고에 직접 의존하는 구간만 분리했다. Java가 generic array creation을 허용하지 않는다는 독립 설명, erasure 설명, 그 뒤 독립된 구현 절충·언어 평가 및 나머지 글은 본문에 유지했다.
