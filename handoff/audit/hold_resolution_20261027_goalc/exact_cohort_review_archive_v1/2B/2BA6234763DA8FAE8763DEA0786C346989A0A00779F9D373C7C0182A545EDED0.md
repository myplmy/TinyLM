# 1116543 보류 원형

- 미제공 그림 참조 `as shown below in the picture with the red arrow`만 분리했다. 바로 앞의 관리자 권한 실행 안내는 완결되어 보존했다.
- 예제 명령이 소실된 `For example, if your file name is “First_program.txt” then you might as well use the command below with`와 그 명령을 직접 받는 `This helps in avoiding mistakes in specifying file names or paths and even directories.`를 보류했다. 명령을 새로 만들지 않았다.
- 대상 URL/링크가 없는 `There is a very thorough article on Python i/o errors on ask python, you can check it out here!`와 `We have an in-depth article about python exception handling. Click here to read!`는 링크 탐색 문구로 분리했다.
