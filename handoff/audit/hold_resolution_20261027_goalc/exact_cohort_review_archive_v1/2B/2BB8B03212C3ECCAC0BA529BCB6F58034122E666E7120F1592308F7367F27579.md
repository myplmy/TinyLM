# expanded_train:371978 원형 보류

후보는 원문과 동일하다는 identity 계획에 연결되며 전체 diff는 변경 없이 끝났다. 이 문서는 고의로 반대 조언을 하는 풍자 글이다. 저작권·저자·인용·날짜, 제목, 완결한 풍자 서술과 코드 예시는 그 문맥 그대로 본문에 유지했다. 문장 끝/대상이 실제로 소실된 조각과 antecedent가 없는 설정 문장만 원형 보류했다. 코드 예시는 실행하거나 보정하지 않았다.

## 결손 끝부분·선행 대상이 없는 문장

> private and protected to prove that your classes are well

실제 `private`/`protected` 키워드 사용 풍자는 남기고, 빠진 상태/서술어에 직접 의존하는 이유절을 제거했다.

> to a reasonable number, invoke some of your code bypassing the wrappers at each of

원문에서 명시한 wrapper 우회 지시는 `at each of` 앞까지 온전해 해당 일반 지시를 본문에 남겼다. 끝의 미상 대상을 sidecar에 보존한다.

> clone any common logic and sit back and wait for it the copies to gradually get out

실제 `clone any common logic` 조언은 보존하고 이어지는 미완 문구만 분리했다.

앞 문단의 1976년 메서드/변수 보존에 관한 완결 조언을 남기고, 위의 문장 조각은 목적어가 빠져 전체를 분리했다.

앞 문장의 두 번째 전역 플래그 확인은 보존하고, 뒤의 독립 명령은 직접 대상 설명이 빠진 상태로 원형 보류했다.

> Make sure they squirrel results and internal state information away in global

바로 앞의 C 함수에 대한 완결 문장과 이후 독립 `In C` 문장은 보존했다. 이 문장은 뒤의 명사가 소실되어 분리했다.

`idempotent` 및 괄호 설명은 그대로 보존하고, “I hope...”의 누락된 목적어만 분리했다.

> : These usually have the form keyword=value. The values are loaded into Java variables at load time.

`These`와 `The values`의 선행 대상이 이 위치에서 확인되지 않는다. 원문에 실제로 있는 뒤의 키워드/Java 변수 이름 차이, 설정 파일과 유지보수 비용 설명은 독립 사실로 유지했으며, 누락된 표제/대상을 생성하지 않았다.
