# expanded_train:7700 원형 보류

지정 원문과 후보 전문, 3개 순서 패킷, 전체 diff를 읽었다. 후보 diff는 `cītā` 뒤의 빈 병기와 내용 없는 `각주`·`참고 문헌` 표제를 제거했다. 새 본문은 그 후보에서 이어서 빈 제목/표제와 짝 없는 서식 조각만 정리했다.

## 빈 제목 병기와 고립 서식

```text
'치타(,
)는 고양이과에 속하는 포유류이다.

치타(cītā, )에서 비롯되었다.

아시아치타 (Acinonyx jubatus venaticus'')
```

빈 제목 병기를 걷고 실제 이름 `치타`, 로마자 `cītā`, 종명 `Acinonyx jubatus venaticus`를 유지했다. 제목 앞의 짝 없는 작은따옴표와 종명 뒤의 고립된 위키 이탤릭 마크는 서식 잔재로 분리했다. 누락 별칭이나 라틴어 이름은 만들지 않았다.

## 실제 내용이 없는 표제

```text
계통 분류
사진첩
각주
참고 문헌
외부 링크
```

`각주`와 `참고 문헌`은 후보가 이미 제거했다. 계통 분류·사진첩·외부 링크 표제에도 실제 계통/사진/링크 내용이 없으므로 빈 표제만 분리했다. 채워진 하위 아종명, 기사 본문, 말미 분류 태그는 보존했다.
