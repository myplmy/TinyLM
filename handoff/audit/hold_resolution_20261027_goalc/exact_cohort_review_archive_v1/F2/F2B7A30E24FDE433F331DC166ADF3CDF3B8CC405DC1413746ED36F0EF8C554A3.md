# 250085 원형 보류 및 정리 근거

지정 입력의 원문 전문, 원문/후보가 이어지는 패킷 0001–0002, 최종 full diff 패킷 0003을 순서대로 읽었다. 패킷 0001/0002의 구간 끝은 연속 분할이고 packet 0003에서 후보와 diff의 논리 끝을 확인했다. 원문과 후보는 identity 증거에서 바이트 동일로 연결되며, 이를 별도 내용 판독으로 세지 않았다.

본문에는 정수 문자열 위치를 한정하는 빈 괄호가 들어 있다. 이 미상 한정은 반회문 정의의 범위를 직접 좌우하고, 이어지는 예시도 그 정의에 의존한다. 조건·수식·예시를 추정하지 않도록 그 문장 전체를 학습 본문에서 분리한다.

```text
String t is a half-palindrome, if for all the odd positions i () the following condition is held: ti = t|t| - i + 1, where |t| is the length of string t if positions are indexed from 1. For example, strings "abaa", "a", "bb", "abbbaa" are half-palindromes and strings "ab", "bba" and "aaabaa" are not.
```

문제 설명, 입력/출력 조건, 사전식 순서 설명과 다른 원문 문장은 그대로 유지했다. 잃은 위치 범위나 수식 표기를 복원하지 않았으며 이 정리는 문제의 알고리즘이나 결과를 검증한 것이 아니다.
