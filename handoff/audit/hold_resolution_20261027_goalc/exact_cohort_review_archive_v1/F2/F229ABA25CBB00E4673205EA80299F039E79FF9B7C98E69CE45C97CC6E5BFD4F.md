## 실제 없는 코드 예고와 그림 포인터

- `Here’s how an animation with requestAnimationFrame would be written.` — 뒤에 해당 코드 예제가 없다.
- `as illustrated here` — wormhole 설명의 그림 포인터이며 그림이 없다.
- 말미의 queue 문장 원형은 `...when only one should happen on a regular interval:`로 끝나고 이어지는 예시가 없다. 앞 문장의 관찰·조건은 완결되어 있으므로 본문에는 문장 내용만 보존하고 빈 예고용 콜론을 마침표로 정리했다.

interval/requestAnimationFrame의 타이밍, 비활성 탭, 긴 time delta, queue의 영향에 대한 나머지 설명과 실제 API 이름은 유지했다.
