# 118872 보류 원형

- `Let's say the tag prefix`는 잘린 예고로 분리했다. 앞의 완결 JSP taglib 선언 예시는 보존했다.
- `There are several`은 다음 비교 목록을 여는 문장이 중단된 잔여어라 분리했다. 이어지는 실제 차이점 문장들은 보존했다.
- `What is JSP page?`와 `A JSP page is ... and JSP elements, which construct`는 정의 대상/서술이 중간에서 끊겨 블록으로 분리했다.
- implicit-object 정의는 완결되어 남겼고, 뒤의 `They are:` 목록 도입만 분리했다. 실제 object 이름을 만들지 않았다.
- `How many JSP scripting elements and what are they?`의 실제 count `There are three scripting language elements.`는 보존했다. 원문에 없는 열거 목록은 추가하지 않았다.
- `How can a servlet refresh automatically if some new data has entered the` 질문과 그 직접 답변 `You can use a client-side Refresh or Server Push.`는 질문의 조건/대상이 끊겨 함께 분리했다.
- `Page Numbers : 1`은 페이지 메타데이터로 sidecar에 분리했다.
