# 1320622 보류 원형

아래 조각은 원문에 실제 그림/스크린샷이 없는 직접 지시이므로 학습 본문에서 분리했다. 새 캡처 내용이나 API 출력은 추가하지 않았다. 원문 문맥에서 선택한 세 번째 항목, 친구·팔로워 정보 등 문장에 이미 기재된 사실은 본문에 보존했다. `In this above given example we` 중 지시대상만 분리하고 나머지 완결 설명은 `We have selected...`로 이어 보존했다.

- `Look at the below given screenshot.`
- `In this above given example`
- `You can look at the below screenshots for its summary.`
