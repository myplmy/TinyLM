# TASK016 본문 차이 및 EOF 기록

지정 원문·후보·순서 패킷을 판독한 뒤 새 편집본의 전체 diff와 실제 말미를 확인했다. 각 원형 보류 구간과 사유는 해당 ID의 hold_*.md에 연결했다.

- `expanded_train_260310_historical_review_20261105_v1.txt`: 후보와 전체 diff에서 빈 별칭 세 곳만 정리했다. 본문 끝은 원래 개행 상태를 유지했다.
- `expanded_train_260643_historical_review_20261105_v2.txt`: 편집 초안 전체 본문을 연속 구간으로 읽고 초기 candidate와 전체 diff를 끝까지 대조했다. 빈 인용 포인터, 빈 행정 표제, 참고문헌 탐색 UI를 분리하고 Open Access 접합부의 공백을 정리했다. 마지막 원문 인용까지 확인했으며 출력에는 종단 LF가 추가됐다. 기존 `_v1.txt`는 수정하지 않았고 선택하지 않았다.
- `expanded_train_260745_historical_review_20261105_v1.txt`: 전체 diff에서 제목이 비어 있는 두 영화 행만 제거했다. 남은 같이 보기 항목과 마지막 줄을 확인했으며 종단 LF가 추가됐다.
- `expanded_train_260771_historical_review_20261105_v1.txt`: 전체 diff에서 빈 별칭과 항목 없는 각주 표제만 제거했다. 말미의 도시권·간토 지방 항목을 확인했으며 종단 LF가 추가됐다.
- `expanded_train_261722_historical_review_20261105_v1.txt`: 원문·후보·diff packets 1–3을 읽고, 편집 초안과 초기 candidate의 전체 diff를 확인했다. 본문 말미의 역사 문장과 아이디얼·가군론 분류를 확인했으며 종단 LF가 추가됐다. 소실 수식·조건·기호는 만들지 않았다.

모든 수정 본문을 새 경로에 저장했다. 원형·초기 사본·기존 초안은 삭제하거나 덮어쓰지 않았다. LF 차이를 바이트 절단으로 맞추지 않았다.
