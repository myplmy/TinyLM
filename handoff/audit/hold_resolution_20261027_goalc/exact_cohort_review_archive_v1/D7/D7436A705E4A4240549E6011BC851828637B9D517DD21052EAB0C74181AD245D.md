# 284605 빈 슬롯·표제 처리 근거

## 정리한 원형 포장

원형 경기 종목 목록의 빈 괄호는 다음과 같다.

- `수상 ()`
- `육상 (45) ()`
- `농구 ()`, `볼링 ()`, `복싱 ()`, `축구 ()`, `체조 ()`, `핸드볼 ()`, `유도 ()`, `소프트 테니스 ()`, `태권도 ()`, `배구 ()`, `역도 ()`, `레슬링 ()`, `우슈 ()`

빈 괄호만 제거했다. `수상`이라는 실제 표기와 육상의 실제 `(45)`, 채워진 수영장 관계, 나머지 종목명과 원래 순서를 보존했다. 값 없는 괄호의 역할을 추정하거나 경기 결과를 만들지 않았다.

원형의 `메달 집계` 표제에는 표나 수치가 없어서 본문에서 분리했다. 원문/후보의 해당 빈 표제는 이 메모에 보류했고, 메달 수·국가별 순위는 추정하지 않았다.
