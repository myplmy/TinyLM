# 591946 별도 보류 원형

원문/후보 동일성은 자기 TASK_049 연결에 따른다. 아래는 실제 누락된 그림/선언/코드, 그 직접 결과 및 링크 footer를 가리키는 구간이다.

| 원문 위치 | 원형 | 처리 근거 |
|---|---|---|
| `The code explained` 뒤 | `Let us take a sample image to implement the code on.`<br>`Following are some basic declarations:` | 샘플 이미지와 그 다음 선언 블록이 보이지 않는다. 정의된 init()/near_node/node_dist/stepping/check_validity_1/check_validity_2/draw_path/rrt 설명은 본문에 보존했다. |
| random point 예시 | `Generation of a random point:` | 이어지는 생성 코드가 없다. 바로 뒤의 실제 `index = near_node(*rnode);` 줄은 명명된 rnode를 사용하는 완결 조각이므로 본문에 유지했다. |
| stepping 예시 | `Calling the stepping function to obtain the step node:` | 호출 코드가 보이지 않는다. |
| validity 결과 | `Checking the validity of the step node. If valid, then both flag1 and flag2 would equal 1.` | flag1/flag2의 정의나 결과를 만드는 실제 호출이 없어 이 값을 어느 플래그에 연결할지 추정하지 않았다. |
| 누락된 시각화/코드 캡션 | `Joining the stepnode to the tree by a yellow line:`<br>`Marking the stepnodes green:` | 캡션 뒤의 해당 코드 또는 그림이 없다. 별도 명시된 end_node 조건과 draw_path()/iter++ 조각은 본문에 남겼다. |
| 마지막 줄 끝 | `Here is the output image after the implementation of the code:` | 실제 출력 이미지가 보이지 않는다. 앞의 명시된 draw_path() 및 iter++ 조각은 본문에 유지했다. |
| article footer | `For the complete code, click here. Find another implementation of the RRT Path Planning algorithm here.` | 별도 코드/구현 페이지로 이동시키는 링크 CTA다. 본문에서 이 링크 대상을 추정하지 않았다. |

완결 RRT 정의와 step size/장애물 조건, 실제 함수 이름·인수·반환값, end_node 조건 및 `draw_path();`/`iter++;` 문구는 원문 순서로 보존했다. 코드를 실행하거나 동작/결과를 새로 만들지 않았다.
