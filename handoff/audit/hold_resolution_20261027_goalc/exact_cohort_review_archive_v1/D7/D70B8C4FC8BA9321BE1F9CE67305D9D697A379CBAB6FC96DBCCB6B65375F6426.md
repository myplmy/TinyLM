누락 예제를 직접 가리키거나 불완전한 구간:
- `as shown in this example:` (CONCAT의 예제 출력은 없음)
- `This is a little more like it.` (앞선 CONCAT 예제/출력이 없음)
- `If length is` (SUBSTRING 설명 문장이 여기서 끝남)
- `as you can see in the following examples` (SUBSTRING_INDEX 예제는 없음)
- `The best way to explain how this function works is simply to provide a few examples.` (TRIM 예고 후 실제 예제는 없음)
- `The following are some examples using LPAD();` (실제 LPAD 예제는 없음)
- `Here’s an example:` (REPLACE의 예제는 없음)

실제 함수명·서명·조건·숫자·대소문자/문자셋 설명과 SQL-92 비교는 그대로 유지했다. `If substring is not specified, a space character is assumed`와 `BOTH` 기본값을 본문에 남겼고, 없음이 확인된 예제 출력이나 입력값은 만들지 않았다. 마지막 `blog comments powered by Disqus`는 페이지 댓글 시스템 footer로 분리했다.

v1/v2의 두 번째 TRIM 관련 치환이 `If substring is not specified` 조건까지 제거한 것을 발견했다. v3에서 그 실제 조건 문장을 복구했다. 이전 drafts는 보존한다.
