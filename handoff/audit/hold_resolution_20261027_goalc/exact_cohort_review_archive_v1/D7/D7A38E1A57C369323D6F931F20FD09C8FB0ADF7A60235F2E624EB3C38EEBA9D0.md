# 40299 원형 보류·정제 기록

- 메모리 문장의 원형 "NUMA()"는 값 없는 괄호만 정리했다. CPU·GPU와 XDR/GDDR3의 명시된 연결·접근 설명은 유지했다.
- 가격 문장 중 원형 "320GB 모델 또한 달러의 가격 인하가 있을 것이라고 말했다."는 실제 달러 금액/가격 감소치가 없는 단위 의존 구간으로 분리했다. 앞서 명시된 $805.85·$840.35 제조 비용과 $499·$599 출시 가격, 299달러·29,980엔 및 다른 실제 비용·날짜·모델 정보는 보존했다.
- 원형 "다음은 지금까지 집계된 지역별 판매량이다."는 뒤에 판매량 값이 없어 직접 예고만 분리했다.
- 값 없는 원형 비교 블록 "모델 비교 / 지역 번호 / 구 모델 / 슬림 모델 / 수퍼 슬림 모델"을 함께 보류했다. 실제 비교값·지역 코드를 생성하지 않았다.
- 나머지 CPU/GPU·메모리·소리·Blu-ray·컨트롤러·네트워크·입출력·호환성·게임·기능·디자인·기술적 문제·링크에 적힌 이름, 값, 조건, 한정, 날짜 및 귀속은 보존했다. 외부 사실 검증은 하지 않았다.
