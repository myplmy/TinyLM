# 795112 원형 보류 조각

C99/C11/C18 표제에는 내용이 없습니다. C95 호환성 예제에는 `#elif defined()`라는 빈 전처리 조건이 있어 코드를 고치거나 대체 매크로를 추측하지 않고 예제 전체를 분리했습니다. 이어진 두 중괄호는 짝 없는 위키 마크업 조각입니다. 실제 표준·연도·설명·라이브러리 이름·컴파일러별 지원 범위와 외부 링크는 본문에 유지했습니다.

~~~text
C99
C11
C18
~~~

C95 호환성을 위한 전처리기 테스트 
#if defined(__STDC_VERSION__) && __STDC_VERSION__ >= 199409L

/* C95 compatible source code. */
#elif defined()
/* C89 compatible source code. */
#endif
