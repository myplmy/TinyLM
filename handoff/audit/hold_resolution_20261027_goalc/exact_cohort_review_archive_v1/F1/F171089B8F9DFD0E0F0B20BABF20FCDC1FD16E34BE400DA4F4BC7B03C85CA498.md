- `Now let us see how we use this function:`과 `The following snippet of code gives us the age...`는 해당 코드가 실제 본문에 없고 직접 그 코드 사용/결과를 예고하므로 그 예고만 분리했다. 날짜 `08/12/1975`와 `approximately 30 years`라는 실제 예시 값은 본문에 유지했다.
- `|All times are GMT +5.5. The time now is 21:57.|`는 기사 뒤의 페이지 시각/시간대 footer로 본문에서 분리했다.
- `dateDiff()`, `explode()`, `gregoriantojd()`의 실제 인수 설명과 서명, 샘플 변수/문자열, 반복된 변수명과 서술은 원문대로 보존했고 값이나 실제 나이를 계산/수정하지 않았다.
