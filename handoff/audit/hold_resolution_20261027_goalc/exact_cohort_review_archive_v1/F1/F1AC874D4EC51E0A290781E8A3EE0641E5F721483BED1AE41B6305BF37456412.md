# 1155407 보류 원형

- 반복 도입 중 잘린 `In this example we are going to convert String into`를 분리했다.
- 시간 패턴 표의 빈 기호 행 `||hour in day (1~24)||(Number)||24|`를 보류했다. 기호를 추정하지 않았고 채워진 다른 패턴 행은 유지했다.
- `We are creating an object of Date to store the parsed formatted`는 목적어가 끊겨 해당 끝절만 분리했다.
- `The method used:`와 다음 `This method is used to parse date/time string into date...`는 실제 메서드명이 없어 직접 설명 대상을 식별할 수 없으므로 함께 보류했다. 앞서 실제로 적힌 `DateFormat.parse(String s)`를 임의 연결하지 않았다.
- `The code of the program is given below:</p>`는 뒤에 프로그램 코드가 없어 분리했다. 뒤의 실제 `javac`/`java` 명령과 출력 문자열은 완결된 실행 기록으로 남겼다.
