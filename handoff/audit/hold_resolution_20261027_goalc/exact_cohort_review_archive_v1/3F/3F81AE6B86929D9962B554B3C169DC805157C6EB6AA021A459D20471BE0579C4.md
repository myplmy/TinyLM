# 21656 원형 보류 기록

## 판독 범위
지정 원문·candidate 전체와 세 순서 패킷의 original/candidate/full_diff를 각 논리 종료와 실제 EOF까지 대조했다. candidate 초기사본과 새 본문 초안의 전체 diff도 확인했다.

## 정리한 빈 이름 병기 포장
원문에 실제로 채워진 섬·도시·곶·만·산·폭포 이름과 높이·위치·방향·좌표는 새 본문에 보존했다. 빈 대체 이름 칸만 보충하지 않고 정리했다. 원형 예시는 다음과 같다.

```text
이투루프섬(, 아이누어: Этуворопшир, , )
쿠릴스크()
라키베추 곶(, )
카사트카 만(, )
스토캅 산(1,634m, , )
보그단 흐멜니츠키산(1,587m,  )
카무이산(1,323m, , )
'일리야 무로메츠'()
코리츠키곶(, )
```

아이누어 이름, 쿠릴스크, 라키베추 곶, 카사트카 만, 폭포 이름 및 코리츠키곶의 위치 관계는 새 본문에 남겼다. 세 산의 이름과 각 실제 높이(1,634m, 1,587m, 1,323m)도 유지했다. 빈 칸을 러시아어·일본어 표기나 다른 이름으로 채우지 않았다.

## 분리한 페이지 분류 꼬리
본문의 `같이 보기` 항목 뒤에 이어지는 아래 일곱 줄은 문장/설명 없이 문서 끝에 붙은 분류 꼬리로 보아 본문에서 분리했다. 원래 순서와 문자열을 보존한다.

```text
쿠릴 열도의 섬
남쿠릴 열도
영토 분쟁 섬
소련-일본 관계
일본의 영토 분쟁
러시아의 영토 분쟁
아시아의 영토 분쟁
```

실제 명명된 `같이 보기` 항목과 기사 본문은 그대로 유지했다. 이 분리는 페이지 분류 표식의 처리이며 해당 분류 내용의 사실 검증이나 영토 관계의 판정을 뜻하지 않는다.
