# expanded_train:40442 불완전 예제와 말미 eBook 표기

본문의 일반 설명은 `List`를 만든 뒤 섞는 관계와 조건을 완결된 문장으로 설명하므로 유지했다. Map 예고 뒤의 코드에는 끝나지 않은 `stream()` 행이 있고 Set 예제에는 변환한 리스트를 섞는 호출이 없다. 따라서 각 직접 예고와 그에 이어진 해당 코드 조각만 원형 보류했다. 코드를 실행하거나 빠진 호출을 채우지 않았다.

말미의 `res – REST with Spring (eBook) (everywhere)`는 Java 컬렉션 설명과 관계를 명시하지 않은 단독 eBook 표기여서 본문에서 분리했다. 제목/링크의 다른 정보를 추정하지 않았다.

Map<Integer, String> studentsById = new HashMap<>();

Set<String> students = new HashSet<>(
