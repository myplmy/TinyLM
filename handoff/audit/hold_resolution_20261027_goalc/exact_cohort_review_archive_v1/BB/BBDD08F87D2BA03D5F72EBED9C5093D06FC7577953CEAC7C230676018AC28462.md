# 943066 — 원형 보류

아래 두 조각은 원문 문구로 보존한다. 미상 완료어·원인·주장을 만들지 않았다.

- 불완전한 네 번째 목록 항목: `- Reduce the return value variability using`
- 말미의 TOCTOU 문장: `There is a window of TOCTOU vulnerability between obtaining a filename from tmpnam_s and subsequently creating that file with tmpfile_s eliminates that particular vulnerability.` 문장 안에서 `tmpfile_s`와 `eliminates`의 관계가 문법적으로 끊겨 있어, 어느 쪽도 임의로 연결하거나 고치지 않고 문장 전체를 보류했다.

본문 목록에서는 불완전한 마지막 항목을 분리하면서 원문의 `the first four patterns`를 `patterns`로만 좁혀 남아 있는 완결 항목과 맞췄다. 앞의 세 항목과 본문에서 이미 완결하게 설명한 실제 함수·시그니처·조건·예제는 유지했다.
