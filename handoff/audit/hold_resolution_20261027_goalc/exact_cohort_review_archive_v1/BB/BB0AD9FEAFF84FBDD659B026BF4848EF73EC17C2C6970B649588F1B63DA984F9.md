# 110877 빈 별칭과 미제공 기종 목록 보류

본문에서 값이 비어 있는 괄호 포장과 내용이 없는 표제는 정리했다. 실제로 제시되지 않은 보유 기종 목록과 그 목록을 직접 예고하는 문장은 함께 본문에서 분리했다. 항공사 이름·인명·사건 연도·운항/인수 서술은 원문 표현대로 두었다.

| 원형 위치 | 원형 | 처리 |
|---|---|---|
| 1행 | `이지젯()` | 실제 명칭 `이지젯`은 유지하고 빈 괄호만 제거했다. |
| 4행 | `스테리오스 하지 이오아누()` | 실제 인명은 유지하고 빈 괄호만 제거했다. 이름의 다른 표기를 만들지 않았다. |
| 6행 | `이지젯 스위스()` | 실제 사명은 유지하고 빈 괄호만 제거했다. |
| 12–13행 | `보유 기종` / `2020년 7월 기준으로 이지젯는 다음과 같은 기종을 보유하고 있다.` | 그 뒤에 기종 목록이 없으므로 표제와 목록을 직접 지시하는 문장을 함께 원형 보류했다. 기종·수량·연도를 보충하거나 일반 보유 주장으로 바꾸지 않았다. |
| 15행 | `각주` | 뒤에 각주가 없어 빈 표제만 정리했다. |
| 17행 | `사진` | 사진/설명이 제시되지 않아 빈 표제만 정리했다. |

`외부 링크` 아래의 실제 표시 문구 `공식 홈페이지`는 남겨 두었다. URL은 원문에 표시되어 있지 않으므로 새 대상 주소를 만들지 않았다. 말미의 실제 분류 목록과 나머지 본문은 유지했다. 이 기록은 원문 항공사 연혁이나 수치를 외부 검증한 결과가 아니다.
