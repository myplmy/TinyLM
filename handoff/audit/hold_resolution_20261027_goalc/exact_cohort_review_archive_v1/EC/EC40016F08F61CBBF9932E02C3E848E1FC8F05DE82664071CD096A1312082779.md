## 코드와 직접 연결된 설명

> Use the 5th parameter of the mail() function for this:
>
> mail('firstname.lastname@example.com', 'Subject', "Message Body", $headers, '-email@example.com')
>
> So the Return-Path of this message would be “firstname.lastname@example.com” (the email address immediately following the -f switch).

코드 인수 문자열의 `-email@example.com`와 해설의 `-f switch`는 같은 표기에 대해 서로 일치하지 않는다. 어느 쪽이 맞는지 정하거나 코드를 고치지 않고, 해당 코드와 직접 연결된 결과/인수 해설을 원형 보류했다. 본문에는 5번째 매개변수를 사용하라는 명시 안내, 일반 Return-Path/From 관계와 `$headers` 설명을 보존했다.
