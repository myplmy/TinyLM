실제 syntax 예시가 뒤따르지 않아 도입만 보류했다. `pop()` 메서드명과 index 설명 표는 유지했다.

## 줄 구조가 평탄화된 코드

```text
users = ["john", "lisa", "maria", "ava"] removeElement = users.pop(1) print(removeElement) # output = lisa
users = ["john", "lisa", "maria", "randy", "ali"] removeElement = users.pop(6) print(removeElement)
numList = [9, 13, 31, 20, 33, 44] print('Original list: ', numList) remove_item = numList.pop(-1) print('New list after negative index = -1: ', numList) print('The item removed: ', remove_item)
```

여러 문장이 구분자 없이 한 줄에 결합되어 코드 구조를 추정 복구하지 않았다. 원문이 직접 제시한 IndexError traceback, 음수 index 출력·값, 실제 pop 동작 설명은 보존했다.
