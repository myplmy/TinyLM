# 58787의 실제 target language 주체

총괄이 지정 원문을 전문 읽었다. Java에서 C++로 옮기는 수업이라는 주체와 `The target language is C++ without`가 실제로 있다. 뒤의 `does, however, include gcc's statement expressions`는 이 target language의 유일한 국소 연속 설명이다. 원문에 이미 있는 `The target language`라는 주어만 이 설명에 연결할 수 있으며, 새로운 C/C++ 기능을 지식으로 추가하지 않는다.

누락된 세 질문/발표 세 이슈/두 교재 목록/세 언어 목록, 중간이 사라진 type 관련 꼬리, 이름 없는 package/toString 소속 및 마지막 super 참고 꼬리는 추정해서 채우지 않는다. 실제 Bjarne Stroustrup 참고서명·Java/C++ 제한·두 버전/학생 수/15분·평가50/25/25·환경과 수업 설명은 보존한다. 2012 수업의 서술을 현재 설치 권장으로 바꾸지 않는다. 자연스러운 문장만 만들려고 유효한 제한·부정·지원 기능을 통째로 버리지 않는다.

자기 해당 TASK의 다섯 행을 유지한 새 리뷰와 실제 새 본문/원형 sidecar로 연결한다. 새 주체를 창작하는 전역 허용이 아니라 이 원문에서 이미 명명된 target language를 이 인접 문장에 한정해 잇는 판정이다.
