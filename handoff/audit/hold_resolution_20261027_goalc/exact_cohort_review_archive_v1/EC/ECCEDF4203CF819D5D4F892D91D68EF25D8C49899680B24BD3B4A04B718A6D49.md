# expanded_train:395907 원형 보류 기록

본문의 네 브라우저 객체(Location, History, Screen, Navigator)와 실제 역할·값, document.getElementById() / paragraphElement 관계, window.location을 통한 Google 이동, 실제 history 메서드 코드, screen 크기 설명, Chrome 경고 사례는 보존했습니다. 일부 예제 HTML/코드 또는 화면 링크는 지정 원문·후보에 없으므로 그 예제·링크를 직접 가리키는 예고/지시만 분리했습니다. 빈 설명을 채우거나 JavaScript 코드를 새로 만들지 않았습니다.

보류한 원형 구절:

- Location 행 끝의 `The`와 History 행 끝의 `The` — 다음 내용을 잇지 못하는 미완 단어 꼬리입니다. 해당 두 행의 실제 객체명과 설명은 남겼습니다.
- `Let’s take a look at a basic HTML page and then modify its contents when you push a button.` — 뒤따라야 할 HTML 페이지/코드가 없습니다.
- `Go ahead and try copy/pasting the code above into your own HTML file and open it in a browser. You’ll see something interesting happen when you click on the “spice it up” button.` — 참조되는 코드가 없고, 누락된 예제의 UI 동작을 직접 예고합니다. 인용된 버튼 문구도 이 원형에 보존합니다.
- `Go ahead and copy/paste this code into your own HTML file.` — 해당 코드가 없습니다.
- `I don’t think I’ll need to give you a full example like I did above.` — 없는 이전 예제를 직접 가리킵니다. History 객체에 대한 실제 설명과 바로 뒤에 남은 back/forward 코드 예시는 보존했습니다.
- `Go ahead an click here to see how big your screen is.` — 대상 링크/화면이 없습니다.
- `Here’s some code that will break down the browser’s details:` 및 `Try that code out for yourself and see what details may surprise you about the type of browser that YOU are using!` — 예고된 browser-detail 코드가 없습니다. Navigator의 명시된 용도·Chrome/webkit 조건·사용자 브라우저 경고 설명은 남겼습니다.

해당 원형 문장과 삭제 이유를 sidecar에 보존했으며 외부 사이트나 브라우저 코드 실행은 하지 않았습니다.
