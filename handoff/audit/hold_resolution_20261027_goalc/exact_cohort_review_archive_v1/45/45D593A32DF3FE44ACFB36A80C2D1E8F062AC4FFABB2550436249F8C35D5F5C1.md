# 1063015의 불완결 설명 원형

후보에 남은 다음 세 설명은 끝의 목적어·도구명이 빠져 문장 그대로는 완결되지 않는다. 보충 표현은 만들지 않고 직접 불완결된 범위만 본문에서 분리했다.

- `Writing valid markup helps your site work the way you expect and is more compatible with older`
- `To help developers with this, IE10 now reports HTML parsing errors via the F12`
- `This means conditional comments can still be used, but will only target older versions of IE. If you need to distinguish between more recent browsers, feature detection instead.`

IE10 파싱의 완결 설명, HTML DOM/IE9 비교 표본, 실제 `<b>`, `select`/`table` 코드 및 conditional-comment 예시는 새 본문에 그대로 보존했다. HTML 예시의 구조·출력을 추정해 고치지 않았다.
