# 8694 원형 보류 — 빈 국가 별칭 슬롯과 내용 없는 표제

리드의 실제 국가명, 괄호 안 `RSA/SA(iso code)` 표기, 전체 설명과 생애·정치·사회 정보는 보존했다. 리드의 비어 있는 괄호 필드만 원형으로 남긴다.

```text
남아프리카 공화국(, RSA/SA(iso code), )
```

주 목록 뒤에 항목이 없는 `표` 표제와 본문 끝의 빈 `각주`, `내용주`, `참조주` 표제도 원형 보류한다. 이들은 내용이 없어 본문에서 분리했으며, 표나 각주 값을 생성하지 않았다.

```text
표

각주
내용주
참조주
```
