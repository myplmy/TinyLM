# TASK_102 출력 경로 정정 기록

첫 작성 시 입력 원본을 후보 파일의 공통 입력 디렉터리로 지정하면서 역할 출력 경로에 상대 경로 ../inputs를 붙였다. 두 sed 명령은 입력 후보 파일을 열지 못했다고 응답했고 본문 내용을 변환하지 못했다. noclobber 상태에서 만들어진 expanded_train_96026_revised_v1.txt 및 expanded_train_990380_revised_v1.txt는 빈 출력으로 남아 있으며 삭제하거나 덮어쓰지 않았다.

TASK_102에 명시된 정확한 후보 경로를 사용해 새 v2 본문을 작성했다. review_102_v2.md가 선택 본문과 연결된다. v1 파일은 잘못된 입력 경로로 생성된 빈 초안이므로 판정 출력으로 사용하지 않는다.
