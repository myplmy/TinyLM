> #base class constructor is available to sub class class Father: def __init__(self): self.property = 800000.00 def display_property(self): print('Father\'s property=', self.property) class Son(Father): pass #we do not want to write anything in the sub class #create sub class instance and display father's property s = Son() s.display_property()

근거: Father/Son, property, 800000.00 및 생성자 상속 설명은 본문에 유지했다. 코드의 줄/주석 경계를 재구성하거나 실행을 주장하지 않았다.
