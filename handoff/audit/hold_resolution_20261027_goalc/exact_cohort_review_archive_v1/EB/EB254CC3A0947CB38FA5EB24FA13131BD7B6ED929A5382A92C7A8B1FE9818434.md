# 17255 원형 보류 조각

원문에 실제 기재된 음운 현상, 기호, 모음, 조건, 문장들은 보존했다. 비어 있는 변환값·IPA 값과 그 빈 예에만 직접 의존하는 구간은 본문에서 분리했다. 빠진 음성값이나 예시는 추정하지 않았다.

## 명칭·비교 조각

- 도입부 원형: `스페인어(, ) 또는 카스티야어()` — 채워진 이름 외의 값이 없는 괄호/구분 슬롯은 본문에서 제거했다.
- 비교 구절 원형: `라 쓰는 것과 마찬가지로,` — 비교의 기준이 비어 있어 본문에서 분리했다. 뒤의 실제 주장인 카스테야노라는 낱말이 정치적·이념적 연관이 없는 포괄 표현이라는 내용은 보존했다.
- `에스파냐 한림원()` — 이름은 문장 안에 채워져 있어 빈 괄호만 제거했다.

- `연음화(가 가 됨), 구개음화(이 가 되고, 이 가 됨), 속라틴어 단모음 e와 o의 이중모음화(어간 변화, 가 가 되며, 가 가 됨)` — 현상명과 `e`, `o`, `어간 변화`는 본문에 남겼고, 비어 있는 변환쌍은 보류했다.
