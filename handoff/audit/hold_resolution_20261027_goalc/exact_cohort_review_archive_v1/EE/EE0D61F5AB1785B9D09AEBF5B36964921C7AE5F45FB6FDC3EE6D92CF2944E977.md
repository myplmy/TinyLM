# 144962 원형 보류: 내용 없는 보호 도메인 절 표제

## 입력 범위

- ID: `expanded_train:144962`
- TASK: `TASK_018.md`
- 지정 원문·후보와 패킷 0001–0004를 순서대로 읽었고, packet 0004에서 source packet sequence complete 및 실제 문서 END를 확인했다.

## 원형 구간

`- Assigning the first thread to the protection domain`

이 표제는 `- Creating a protection domain`과 그에 속한 완결된 PD session 설명 다음에 있고, 곧바로 `- Starting the execution`으로 이어진다. 표제와 다음 표제 사이에는 해당 절의 본문이 없다. 따라서 이 빈 표제만 학습 본문에서 분리하고, 원문 표제는 이 sidecar에 보존한다.

## 범위

`Pd_session_capability pd_cap = session("PD"); Pd_session_client pdsc(pd_cap);`와 뒤의 실제 설명 `Now that we defined the relationship...` 및 `csc.start(thread_cap, ip, sp);`는 보존한다. 없는 코드나 보호 도메인 연결 절차를 생성하지 않는다.
