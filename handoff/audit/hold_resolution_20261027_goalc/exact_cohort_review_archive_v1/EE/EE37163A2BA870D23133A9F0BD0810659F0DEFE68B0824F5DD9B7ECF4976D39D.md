# 1399996 원형 보류 및 편집 경계

| 원문 조각 | 처리 이유 |
|---|---|
| `and the code is available for download here.` | 다운로드 URL 대상이 없는 링크 안내다. 본문에는 실제 작성 플랫폼 두 곳을 보존했다. |
| `The code specific to Intel X86_64 based systems is available here.` | URL 없는 포인터이므로 분리했다. Intel X86_64 전용 코드라는 실제 구분은 본문에서 독립 문장으로 보존했다. |
| `See this kitten shown in Figure 5.3 and look carefully at how it is drawn.` | 본문에 그림이 없고 문장 전체가 보이지 않는 그림만을 직접 가리킨다. 다음 문장의 문자 기반 좌표 설명은 유지했다. |
| `As shown in Figure 5.4 the graphics got more advanced.` | 빠진 그림 포인터를 제거하고, 앞에 이미 적힌 상자 문자·색상 확장과 연결되는 진행 서술은 본문에서 보존했다. |
| `See Figure 5.5.` | 앞에 y축 방향·0 위치·화면 이동을 글로 완결해 설명한 뒤 붙은 그림 포인터다. |
| `like the one shown in Figure 5.6` 및 `One such color picker is at:` | 색상 선택기 예시 그림과 URL 대상이 없다. 온라인 color picker를 찾으라는 실제 지시는 본문에 유지했다. |
| `By calling the command below, the program will close any open windows and exit as desired.` | 바로 아래에 예고한 닫기 명령이 없다. 뒤의 다른 코드에서 명령을 옮겨 채우지 않았다. |
| `and produces the image shown in Figure 5.7.` | 이미지 결과 포인터만 분리했다. sine/cosine, 좌표 계산 코드와 offset 설명은 보존했다. |
| `shown in Figure 5.8` | 이미지 포인터를 제거하고 반복문 및 X 도형에 대한 실제 설명·코드는 보존했다. |
| `The result of this code is shown in Figure 5.10.` | 없는 그림만 가리키는 결과 문장이다. 앞의 네 arc 코드와 색·각도·경계 설명은 보존했다. |
| `This code draws what can be seen in Figure 5.11.` | 그림 포인터만 분리했다. 삼각형 이름·세 좌표·중첩 목록 설명과 실제 polygon 호출은 보존했다. |
| `Check in the example code for` / `section on-line for the timer.py example:` | 온라인 섹션 대상이 빠진 포인터다. 본문에는 실재 파일명 `timer.py`를 독립적으로 유지했다. |
| `This program, along with other programs, may be downloaded from:` | 다운로드 위치가 비어 있는 말미 포인터다. 뒤에 실제 전문 코드가 있으므로 그 전문은 보존했다. |
| `You are not logged in. Log in here and track your progress.` | 본문과 무관한 사이트 로그인/진행 UI다. |

그림·다운로드 대상·닫기 명령을 새로 만들지 않았다. 실제 API 호출, 함수 인수, 코드 토큰, 수치, 좌표, 색상, 저자/번역 크레딧은 본문에 유지했다.
