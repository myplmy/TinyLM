# 203114 빈 별칭 포장 정리 근거

동일한 이름을 구별하는 일곱 항목의 실제 표지와 설명은 유지하고, 각 항목 끝의 빈 `()`만 정리했다: `사이토 유키 (1966년)`, `사이토 유키 (1974년)`, `사이토 유키 (아나운서)`, `사이토 유키 (음악가)`, `사이토 유키 (1986년)`, `사이토 유키 (1987년)`, `사이토 유키 (1988년)`. 각 생년·직업·소속·활동 서술은 candidate의 값과 위치를 그대로 보존했다. 첫 소개 뒤의 빈 별칭 포장은 candidate가 이미 제거한 상태를 유지했다. 인물을 합치거나 새 식별 정보를 만들지 않았다.
