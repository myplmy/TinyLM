# expanded_train:986277 구조 표기 원형

본문에서 분리한 원문 조각:

```text
|set + structure||functions|
This consists of:
Addition is commutative but multiplication may, or may not, be commutative. See table below. For example matricies and quaternions don't have commutative multiplication.
|* distributive over +||Multiplication commutative||Multiplication associative|
```

첫 줄은 실제 사례 값이 없는 표 머리이고 마지막 줄은 속성 이름만 있어 비교값/축을 확인할 수 없는 조각이다. 이 둘의 표 형태를 본문에 남기지 않았다. 가운데 `This consists of:`에는 목록의 주체가 없지만, 원문에서 목록 바로 뒤의 `Groups are discussed on these pages.`가 같은 문맥의 실제 명칭을 제공한다. 그 명칭을 `Groups:` 구조 표제로만 연결하고 아래의 세 원래 항목은 순서대로 보존했다. 새 정의·공리·동일성은 만들지 않았다.

`|Level||Examples for vectors|` 뒤에는 실제 `Algebraic theory` 행과 `A+B=B+A` 예가 있어 그 채워진 표 내용은 본문에 유지했다. `See table below`는 위에서 분리한 빈 속성 표를 직접 가리키므로 해당 포인터만 제거했으며 나머지 문장과 예시는 보존했다.
