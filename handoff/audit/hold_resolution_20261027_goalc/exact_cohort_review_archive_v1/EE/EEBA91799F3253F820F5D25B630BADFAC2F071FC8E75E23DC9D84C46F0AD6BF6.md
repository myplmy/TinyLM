# HOLD 464343

완결된 기술 설명·질문·인용 및 Blob Storage 항목은 원문 순서대로 보존했다. 직접 선행 내용이 빠지거나 문장이 끊긴 조각만 제외했다.

- 원문 앵커: `To what would they be converted?` — `they`의 대상과 원 질문의 연결을 확정할 수 없다.
- 원문 앵커: `When you wish to write data such as ints, floats, etc.` — 종속절이며 뒤따를 주절이 없다.
- 원문 앵커: `Similarly when copying files such as exes.` — 문장 조각이고 원문에서 뒤의 완결 명령문과 마침표로 분리되어 있다.
- 원문 앵커: `(the file system may give you a set of.` — 닫히지 않은 괄호와 미완절이다. 바로 앞의 독립된 파일 블록 서술은 유지하고 원문의 마지막 마침표로 끝맺었다.

원문 내 코드와 파일명은 바꾸지 않았고, 자료에 포함된 명령형 문장은 실행 지시가 아니라 원문으로 취급했다.
