# expanded_train:957172 원형 분리 및 참조 정리

- 원문 `For demonstration purposes, let’s assume the attacker managers to upload the following file on a web server.`에서 `the following file`만 `a file`로 바꾸었다. 예고된 파일 본문은 지정 원문에 없으므로 없는 코드를 채우지 않고, 업로드 가정 자체는 보존했다.
- 원문 `The above script gets the command from the GET variable named cmd.`에서 `The above script`만 `The script`로 바꾸었다. 뒤이어 실제로 명시된 GET 변수 `cmd`, `shell_exec()` 호출, 브라우저 결과 관계를 저자 설명 그대로 보존했다. 실행·검증은 하지 않았다.
- 다음 미완 URL 지시를 원형대로 기록하고 분리했다:
  - `The above code can be exploited using the following URL`
  - `- “…konsole.php?cmd=ls%20-l”assigns the value ls –l to the variable cmd.`
  - `The attack URL would look something like this`
  URL 앞부분이나 누락된 공격 URL/코드를 보충하지 않았다.
- `Executing the above code on a web server gives results similar to the following.`는 예고된 결과가 원문에 없어 분리했다. 별도로 실제 명시된 `shell_exec('ls -l') ;`와 그 명령에 대한 원문의 파일/권한 설명, `rm -rf /` 예시와 그 설명, 요약 bullet은 그대로 보존했다. 어떤 명령도 실행하지 않았다.
