# expanded_train:877057 원형 보류

금융 파생상품으로서의 swap 설명과 프로그래밍 언어의 swap 설명은 서로 다른 원래 문단이므로 각 문단의 내용과 순서를 보존한다. 서로 의도적으로 비교한 것이라고 새 연결을 만들지 않는다.

입력 x/y를 설정하는 예제가 없는데 `After swap()` 결과로 x가 0, y가 1이며 값이 교환됐다고 단정한 문장은 그 미상 예제의 직접 결과이므로 학습 본문에서 분리한다. 원형은 다음과 같다.

> After swap() is performed, x will contain the value 0 and y will contain 1; their values have been exchanged.

뒤의 일반적인 swap 동작·응용과 임시 변수 방식의 정의 및 메모리 설명은 독립된 내용이므로 새 예제값을 추정하지 않고 보존한다.
