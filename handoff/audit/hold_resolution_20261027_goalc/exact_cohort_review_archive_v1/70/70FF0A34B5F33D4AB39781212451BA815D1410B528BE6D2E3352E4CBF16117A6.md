# expanded_train:1248322 원형 보류 조각

판독 범위: 원문·후보 전문(20/19행), 순서 패킷 0001–0007의 전부, candidate END와 full_diff END. 후보는 원문의 맨 앞 Table of Contents 표제 한 줄만 삭제했다. 새 본문은 ESP32·하드웨어 난수·실제 코드 식별자와 수치를 보존하며, 비어 있는 직접 지시/대상만 분리했다.

## 원형 보류

- 원문 앞부분의 "|Table of Contents|"는 목차 UI 표식이고 뒤에 목차 항목이 없다. 후보에서 제거된 이 표식과 이유를 기록한다.
- 원문: "The ESP32’s true random number generator can write a 32-bit value to the" — 목적 레지스터/대상이 빠진 미완 문장이다. RNG_DATA_REG와 주소 0x3FF75144는 앞선 완결 문장에서 보존했고, 이 뒤에 다른 값을 추정해 붙이지 않았다.
- 원문: "The associated file can be found here on GitHub (Line number 138)." — here가 실제 링크/파일 경로 없이 남아 있으므로 출처를 만들어 채우지 않았다.
- 원문: "The software and hardware of random number generation can be tested with a small sketch for the ESP32 :"와 바로 뒤의 "// Official ESP32 function" 및 "// Official Arduino function" — 실제 sketch/code가 뒤따르지 않아 도입부와 코드 주석 두 줄을 모두 원형 보류했다.

본문의 random(), esp_random(), RNG_DATA_REG 및 명시 주소/단위·값은 그대로 유지했다. 명시된 내용을 외부 검증하거나 코드를 실행하지 않았다.
