# expanded_train:69178 원형 보류 조각

원문·후보의 지정 전문과 전체 diff를 대조했다. 표·규정 문구가 실제로 비어 있는 직접 예고만 분리하고, 실제 서자 방향 설명과 채워진 용어·날짜·명칭·조건은 보존한다.

## 내용이 빠진 예고

- 북한의 표기 설명 뒤 원문: `《로동신문》을 비롯한 주요 일간지들은 가로쓰기이며, 조선말규범집에서는 이와 관련하여 다음과 같이 규정하고 있다.` 이어지는 규정 문구는 입력에 없다. 새 본문에는 이미 적힌 일반 주장과 출처 귀속만 남기고 `다음과 같이`라는 빈 규정 예고를 제거했다. 규정 내용은 만들지 않았다.
- 구두점 설명 뒤 원문: `타이완 등 중국어 번체 사용 지역에서는 구두점이 가운데에 놓이는 경우가 일반적인데, 중국 대륙이나 일본과 다른 점이다. 다음 표에 그 예가 있다.` 해당 문장은 남겨진 자료에 표가 없어 표 예고 문장만 분리했다. 실제 비교 문장은 유지했고, 표 값/예를 새로 만들지 않았다.

## 빈 포장/빈 표제 원형

- `우경식 서법(牛耕式 書法, )`
- `로버트 모리슨()` 및 `《중국어 사전()》`
- `‘미기 요코가키()’`
- `R2L 또는 RTL()` 중 `RTL` 뒤의 빈 괄호
- 원문에 있던 `BiDi()`의 빈 괄호(지정 후보에서 이미 제거됨)
- 내용이 없는 `각주`, `참고 자료` 제목

각 항목의 실제 명칭/한자 및 약어는 본문에서 보존했다. 외부 링크의 세 채워진 Unicode 문서명과 나머지 실제 설명도 유지했다. 빈 괄호 포장을 코드/API 호출로 해석하거나 어떤 약어의 확장형을 추정하지 않았다.
