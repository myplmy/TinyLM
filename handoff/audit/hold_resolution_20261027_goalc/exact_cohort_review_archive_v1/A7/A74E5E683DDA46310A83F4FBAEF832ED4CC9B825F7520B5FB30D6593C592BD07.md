# expanded_train:637681 원형 표기와 식별자 연결 근거

지정 TASK_051 원문에는 다음 설명이 식별자 없이 들어 있다.

```text
Virtual address of memory object
Length of memory object in bytes
Memory pages are locked to be read from. (Disk write or a network send.)
Memory pages are locked to be written to. (Disk read or a network receive.)
Pointer to a kernel memory cookie.
```

같은 원문 서명에 `addr`, `len`, `flags`, `cookiep`가 실제 명시되어 있다. 총괄 지정 `ROOT_EVIDENCE_637681_DDI_LABELS_V1.md`의 제한된 대조에 따라 본문에서 이 다섯 설명에 각각 `addr`, `len`, `DDI_UMEMLOCK_READ`, `DDI_UMEMLOCK_WRITE`, `cookiep`를 붙였다. 이는 새 필드나 API 설명을 추가한 것이 아니다.

원문은 성공 외 errno 설명 다섯 개도 이름 없이 순서대로 제시한다. 같은 지정 근거가 직접 연결한 이름만 본문에 붙였다: `EFAULT`, `EACCES`, `ENOMEM`, `EAGAIN`, `EINVAL`. 다섯 설명의 원문 문구는 유지했다. 외부 문서의 추가 설명, 버전 변경, 실행 결과는 넣지 않았다.

원문의 첫 줄은 두 실제 include와 선언을 한 줄로 붙여 적었다. 본문에서는 기존 토큰 사이에 줄바꿈만 두었다. 선언의 토큰·인수·형태는 바꾸지 않았다.
