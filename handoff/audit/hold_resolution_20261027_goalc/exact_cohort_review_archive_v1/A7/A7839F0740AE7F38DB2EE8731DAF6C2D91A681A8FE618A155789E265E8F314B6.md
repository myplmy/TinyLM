# 417850 보류 원형

| 원문 구간 | 보류 근거 |
|---|---|
| `and you can import modules from that package using the` | 문장이 받는 대상이 빠진 채 끝난다. 앞의 완결한 `Python treats it as a package` 관계는 본문에 남겼다. |
| `# Define a function that is used by the package` / `print(“Hello from my_function()!”)` | 실제 함수 정의가 없다. `print` 호출을 함수 정의로 바꾸지 않는다. |
| 원래 줄 순서: `In this example, the` → `__init__.py file imports two submodules of the package (` → `module2), defines a global constant (` → `MY_CONSTANT), and defines a function (` → `my_function()) that can be used by the package.` | 예시 해설의 첫 관계에는 submodule 이름이 빠져 있고, `my_function()`에 관한 설명에는 정의 코드가 없다. 빠진 이름/정의와 그에 직접 의존하는 해설을 보충하지 않는다. 다음 독립 문장 `When the mypackage package is imported, ...`는 본문에 보존했다. |
| `- sunny asked 1 month ago` / `- You must login to post comments` | 게시물 댓글/로그인 UI 메타데이터로 본문 밖에 둔다. |

본문에는 `__init__.py`의 패키지 표식·실행·초기화 설명, 예제의 실제 import 두 줄과 `MY_CONSTANT = 42`, 그리고 import 시 모듈/객체를 공개한다는 독립 설명을 유지했다. 함수 정의나 submodule 이름을 새로 만들지 않았다.
