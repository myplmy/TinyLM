# 168085 초안 오류 경위

`reviewed_168085_task027_v1.txt`는 sed `c\` replacement를 한 줄로 이어 쓰면서 뒤의 세미콜론 구분을 replacement 문자열로 취급하게 되어, `;42c...`부터 `;54d`까지의 편집 지시가 본문에 문자 그대로 삽입됐다. 이 파일은 오류 초안으로 보존하고 최종 출력에 사용하지 않는다.

같은 전문을 원문에서 다시 생성할 때 각 `sed -e` 편집을 독립 인자로 분리했고, `reviewed_168085_task027_v2.txt`의 전체 전문과 original→v2 diff를 끝까지 대조했다. 이전 파일은 덮거나 삭제하지 않았다.
