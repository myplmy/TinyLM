# 80874 보류 원형

- `특이행렬의 경우 0을 고윳값으로 가질 수 있으므로 이를 포함해 로도 쓴다.` — `로` 앞에 필요한 기호/표기가 빠져 있어 문장 전체를 보류했다. 누락된 표기를 추정하지 않았다.
- 원문 `계량 부호수(計量符號數, )`의 빈 alias 껍데기는 후보에서 이미 제거됐다.
- `양의 정부호(陽-定符號, )`, `음의 정부호(陰-定符號, )` — 실제 한자 표기와 개념명은 보존하고 빈 alias 슬롯만 선택 본문에서 정리했다.

계량 부호수의 실제 정의, (3,1)/부호 예시, 양·음 고윳값 조건, 리만/로렌츠 계량 관계와 스펙트럼 설명은 독립된 완결 내용으로 유지했다.
