# 688560: 뤼티의 날짜와 선거 연도 좁은 정정

총괄은 지정 원문 전체를 실제 읽었다. 리드 생일1889년12월31일·사망1956년12월30일, 출생1867/사망1951 분류, 본문1956년10월 사망이 충돌한다. 후임선출·재선출 두 문장의1937도 각각1940/1943 문맥과 맞지 않는다.

국가전기 출판 주체 SKS의 실제 러시아어 출판 PDF에서 저자 마르티 투르톨라의 뤼티 전기 부록을 읽었다. PDF 0기준533쪽, 추출18863–18865행은 리스토 헤이키 뤼티의 출생1889년2월3일/후이티넨, 사망1956년10월25일/헬싱키를 명시한다. 검색 반환의 핀란드어 전기도 같은 날짜지만, 해당 웹 문서 직접 열기는 메뉴만 반환했으므로 웹 전문 열람으로 세지 않는다. PDF는 실제 본문 근거이며 웹 검색과 독립 출처 두 개로 세지 않는다.
- https://kansallisbiografia.fi/pdf/kb_ru.pdf
- https://kansallisbiografia.fi/kansallisbiografia/henkilo/630

대통령실 역대 대통령 목록111–115행도 뤼티1889–1956/임기1940–1944를 명시한다. 같은 목록102행의 만네르헤임1867–1951과 캐시의 틀린 분류 두 연도가 같지만, 이것만으로 오염의 원인을 확정하지 않는다.
- https://www.presidentti.fi/en/presidency/former-presidents-of-the-republic-of-finland/

대통령실 선거 통계 PDF 0쪽85–104행은1940년과1943년에1937년 선거인단을 재사용한 선거를 구분한다. 1940년 뤼티288표가 명시돼 있다. 1937년은 선거인단을 선출한 해이며 이 두 뤼티 선거가 열린 해가 아니다. 같은 파일을 텍스트 열람하고 screenshot 도구도 호출했지만, screenshot 응답에서 별도 영상의 시각 판독 증거를 확보했다고 주장하지 않는다. 이번 연도·선거인단 구분은 실제 텍스트 행을 근거로 한다.
- https://www.presidentti.fi/halonen/public/vaalitilastot_eng0b3f.pdf

허용 정정은 이 ID의 아래 필드뿐이다. 실제 새 TXT는 Luna가 작성한다.

1. 리드 생일은1889년2월3일, 사망일은1956년10월25일로 정정하고 잘못된 두 원형을 sidecar에 남긴다.
2. 출생분류1867→1889, 사망분류1951→1956. 본문의1956년10월 사망과 명예박사 수여1956년5월·그5개월뒤라는 기존 표현은 유지한다. 새 day25를 본문 모든 날짜에 확장 삽입하거나 나이를 계산하지 않는다.
3. 칼리오 후임선거 문장의1937→1940, 뤼티 재선 문장의1937→1943. 실제288/300표 원형은 유지한다.
4. 선거인단을 의회의원이라고 한 직접 방법 주장과 `의회에서`라는 잘못된 장소·주체 한정은 원형HOLD한다. 나머지 완결 간접선거/후임/재선 관계를 보존하고 새 상세 제도·법률 설명은 삽입하지 않는다.
