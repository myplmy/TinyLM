# 1214804 보류 원형

- 시작의 `yresolution the texture has a`와 `zresolution as well (turning the pixels into voxels).`는 앞부분의 대상/문장 구조가 소실된 연속 조각이므로 그대로 보류했다. 다음의 3D 이미지 채널·bounding box 설명은 독립 문장으로 보존했다.
- `Users can query these tags from VEX using the`는 호출 대상이 빠진 문장 도입부라 보류했다. 실제로 명시된 `IMG3D_Manager::getCorner()`, `getSize()`, `getRes()`, `getNChannels()`, `getChannelName()`, `getChannelSize()`, `getChannelNumber()` API 이름과 설명은 보존했다.
- `Once the 3D texture has been created, you can call either:` 뒤에 열거 대상이 없으므로 이 도입문만 보류했다. `createTexture()` 및 실제로 완결된 `loadUntiledChannel()`/`fillUntiledTexture()` 호출 설명과 명명된 예제 파일 경로는 그대로 유지했다.

누락된 태그 조회 API나 `call either`의 항목을 추측해 추가하지 않았다.
