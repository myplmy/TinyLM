# 235462 원형 보류 기록

- 원문 7행의 “The following example shows the scatter plot created using the” 예고는 바로 뒤에 실제 예제 코드가 없다. 예고만 분리했다. 그 줄에 이어 명시된 cars dataset의 speed/dist 값 설명, 두 열과 축 관계는 본문에 보존했다.
- 원문 24–26행의 “Cars93 dataset from the MASS package and use the plot() function to draw scatter plots on its variables.”는 주어/동사 관계가 끊긴 조각이라 전체 원형을 분리했다. Cars93, MASS package, plot() 함수명은 원형 그대로 기록했으며 누락된 지시나 제목을 생성하지 않았다.
- 원문 36–37행에서 “as shown below”와 “The resulting plot is shown below”는 해당 코드와 그림이 없어 직접 포인터만 정리했다. Goldman Sachs와 Citi 변수를 고르는 이유 및 x/y 값을 별도로 공급한다는 설명은 유지했다.
- 원문 41–43행의 실제 main, xlab, ylab 인수명은 보존하고 붙어 있던 공백만 정리했다.
- 원문 44–46행의 “after calling the”는 뒤에 있는 실제 plot(...)와 grid() 호출을 가리키므로 plot() 함수명을 같은 원문에 보이는 API 표현으로 연결했다. 새 호출은 만들지 않았다.
- 원문 58행의 “3. Add the regression line using”은 사용할 함수/명령이 빠진 직접 의존 지시라 분리했다. 원문에 실제 있는 lm(), plot() 명령, 회귀선 설명과 변수 관계는 보존했다.
- 원문 59행의 “The graph will now look as follows:”는 없는 그래프 예고라 분리했다. 뒤의 완결된 plot() 형태 설명은 유지했다.
- 실제 데이터값·출력·함수명·API·변수명·축 역할·관련 읽을거리 목록은 그대로 보존했으며 R 코드를 실행하거나 새 코드를 쓰지 않았다.
