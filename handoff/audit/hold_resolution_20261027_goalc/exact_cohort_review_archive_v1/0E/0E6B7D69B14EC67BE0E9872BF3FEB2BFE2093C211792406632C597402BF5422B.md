# expanded_train:1024340 — 분리된 결손 예제와 그림 의존 표현

## 결손 텍스트 결합 예제

원문에서 분리한 예제 도입 및 직접 의존 문장:

- `Below is an example.`
- `In this example, specific pieces of the text were found in three different cells. To join these segments together, the formula also adds required spaces and punctuation housed within quotation marks resulting in a formula of =B6 & " " & C6 & ", " D6. The result is the concatenation into a correctly formatted date for this locale.`
- `Taking this example further, the result cell is defined as a name, then text concatenation is performed using this defined name.`

D6 앞 연산자는 원문과 공식 OOo3 문서 모두에 없어 수식을 보충하지 않았다. 일반 텍스트 결합 설명과 뒤의 독립된 이름·범위 설명은 유지했다.

## 사라진 그림을 직접 가리키는 문구와 캡션

분리한 원문은 다음과 같다:

- `The figure below shows these identifiers for Cell A1.`
- `The Cell Reference Operator.`
- range 정의의 끝 구절 `as shown below.`
- `Reference Operator for a range.`
- A1:D12 설명의 시작 구절 `In the upper left corner of the figure above, the range A1:D12 is shown,`
- `This same range could also be created by entering in the Name Box directly as shown below.`
- `Direct entry of Reference Operator into Name Box.`

A1, A1:D12, 그 범위에 포함되는 셀의 관계, 마우스로 범위를 선택하는 설명, 이름 상자와 Enter 동작, 겹치는 범위의 `SUM(A1:B6!B5:C12)` 식은 본문에 남겼다. A1:D12 설명은 그림 위치를 가리키는 도입부만 제거해 이미 적힌 range/cell 관계를 보존했다. 이름·값·조건을 새로 만들지 않았다.

원문의 `23 = 2*2*2`는 지정 OOo3 근거에 따라 한 곳에서만 `2^3 = 2*2*2`로 정리했다.
