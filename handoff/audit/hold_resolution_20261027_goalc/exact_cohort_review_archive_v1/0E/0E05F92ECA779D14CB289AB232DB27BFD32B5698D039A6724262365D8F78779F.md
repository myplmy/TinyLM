# expanded_train:12122 원형 보류

후보 본문에서 실제 대상이 빠진 예시 포인터와 빈 코드값은 복구하지 않는다. 아래 원형 구간은 예시 대상 또는 값이 없어 독립적으로 확인할 수 없으므로 보류한다.

- `첫가끝 코드를 사용하여 《훈민정음》 언해본의 첫 구절을 쓰면 다음과 같다(은글꼴이나 함초롬체, 본고딕 또는 본명조 등을 적용하면 볼 수 있다).`
- `한양 PUA 코드를 사용하여 《훈민정음》 언해본의 첫 구절을 쓰면 다음과 같다.`
- `한양 PUA에 있는 ퟅ(한양 PUA: )는 한양 PUA에서 추가된 문자로서 훈민정음 언해본에서 사용된 ㅅ과ㅈ을 합친 형태이다.`의 빈 코드 대응 조각 `(한양 PUA: )`. 실제 glyph와 설명은 본문에 남긴다.

U+302E와 U+302F의 실제 코드포인트·명칭은 보존하고, 그 뒤의 빈 괄호 포장만 정리한다. `한양 PUA 지원 무료 글꼴` 아래 원문의 선행 고립 콜론은 내용 없는 서식 잔재로 분리하되 뒤의 실제 글꼴 설명은 본문에 유지한다. 빈 각주 표제도 빈 구획으로 분리한다. 새 glyph, 코드포인트, 예시 문자열은 만들지 않는다.
