# 375453 원형 보류 구간

입력 원문에서 분리한 실제 구간:

- `You can resume function by calling`
- `So for example if you paste code that is shown below. You script on ready ... print("test").`

첫 구간은 resume 대상 함수가 빠져 있어 호출 대상을 보존할 수 없다. 둘째 구간은 아래 코드가 실제 입력에 없고, 뒤의 on-ready 동작 설명이 그 코드 예시를 직접 가리킨다. 없는 코드나 호출을 만들어 넣지 않고 해당 예고와 의존 설명만 원형 보류한다.

새 본문에는 완결된 `You can add object and signal to yield(). That way ...` 문장을 유지한다. 이는 두 가능한 방법 중 하나를 설명하는 원문이므로 문두의 `or`만 제거해도 나머지 선택지를 의무로 바꾸지 않는다. yield의 일반 설명, 실제 signature 및 Godot 4.0 한정 정보도 보존한다.
