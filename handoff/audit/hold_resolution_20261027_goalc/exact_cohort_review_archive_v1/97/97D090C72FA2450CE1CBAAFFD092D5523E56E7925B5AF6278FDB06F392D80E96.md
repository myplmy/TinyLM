# 580258 별도 보류 원형

원문/후보 동일성은 자기 TASK_048 연결에 따른다. 아래 code-introduction/if-else 지시는 본문에 실행 코드가 없어 직접 참조 범위를 분리했다. 빠진 코드를 보충하지 않았다.

| 원문 위치 | 원형 | 보류 근거 |
|---|---|---|
| 첫 설명 문장 끝 | `Here are the two view controllers:` | 이어져야 할 두 controller 코드가 없다. 앞 문장에서 실제 FirstViewController/SecondViewController, outlets, actions, property와 label 관계는 보존했다. |
| 첫 버튼 절 끝 | `Now we can instantiate the second view by its identifier like this:` | `like this`가 가리키는 코드가 없다. 앞 문장의 실제 Storyboard ID 이름·설정 위치를 본문에 보존했다. |
| 둘째 버튼 절 뒤 | `Now, inside the sendData() method right after the if statement append an else statement where we handle the action for our second button:` | 언급된 if 조건 및 해당 코드가 없어 분기 로직을 추정하지 않았다. ButtonTwoSegue의 명명 및 연결 설명은 본문에 유지했다. |

세 번째 버튼에 대해 원문에 명시된 ButtonThreeSegue 연결과 `prepareForSegue()`가 데이터를 전달한다는 목적·버튼 조건은 본문에서 보존했다. 마지막 문장의 receivedData 값 1/2/3과 버튼 눌림 조건도 저자의 기대 동작으로 원문대로 남겼으며 개별 버튼과 숫자 사이의 새 대응은 만들지 않았다.
