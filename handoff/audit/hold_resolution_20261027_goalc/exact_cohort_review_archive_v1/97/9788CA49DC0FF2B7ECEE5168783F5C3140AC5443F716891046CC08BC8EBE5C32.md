# expanded_train:906 보류 원형

선택 본문은 `expanded_train_906_historical_review_20261103_v1.txt`이다. 함수 서명과 완결 설명은 후보 그대로 보존했다. 아래 코드 예제에는 `int main ()` 뒤 본문 경계를 정하는 중괄호가 없고 마지막도 닫히지 않아, 구조를 추측해 복원하지 않고 블록 전체를 본문에서 분리했다.

```c
/* memchr example */
int main ()
char * pch;
char str = "Example string";
pch = (char*) memchr (str, 'p', strlen(str));
printf ("'p' found at position %d.\n", pch-str+1);
printf ("'p' not found.\n");
```

뒤의 관련 함수 항목은 링크/대상 이름이 문장 중간에서 끝나 있어 세 항목 모두 원형 보존했다.

- `Compare two blocks of memory (function`
- `Locate first occurrence of character in string (function`
- `Locate last occurrence of character in string (function`

지정된 원문·후보 사이의 full_diff에는 줄 차이가 없었지만, 동일성만으로 손상된 예제와 잘린 항목을 학습 본문으로 수용하지 않았다.
