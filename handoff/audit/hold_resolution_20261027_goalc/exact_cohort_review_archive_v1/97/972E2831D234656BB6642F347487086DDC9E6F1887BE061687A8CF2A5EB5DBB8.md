# 215 보류 원형

공준의 실제 기호를 추정하지 않았다. 주체·관계가 말로 완결된 상태·밀도 연산자·관측가능량 설명과 해밀토니언 소개는 본문에 남겼다. 기대값과 시간 변화는 표시식이 비어 있고 해당 식의 직접 지시/결론이므로 아래 원형을 분리했다.

## 빠진 기대값 식

```text
계 와 관측가능량 가 주어지면, 그 기댓값은 이다. 대신 밀도 연산자 로는 이다.
```

## 빠진 시간 변화식 및 직접 의존 설명

```text
상태 벡터의 시간 변화는 다음과 같다.

여기서 는 플랑크 상수다. 이를 슈뢰딩거 방정식이라고 부른다. 대신 밀도 연산자 를 쓰면, 그 시간 변화는 다음과 같다.
```

본문에서 정리한 빈 기호 포장은 다음과 같다. 괄호 안에 대응값이 없어 삭제했으며, 실제 이름과 서술은 보존했다.

```text
양자역학의 수학적 공식화()
계의 상태 벡터()
자기수반()
```

후보가 비어 있는 `각주`와 `참고 문헌` 표제는 본문에서 제거했다. 제공된 원문에는 각주/참고문헌 항목이 없었다.
