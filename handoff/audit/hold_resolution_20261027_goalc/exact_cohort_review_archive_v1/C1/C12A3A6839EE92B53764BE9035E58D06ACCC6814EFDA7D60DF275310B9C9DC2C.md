| 원문 범위 | 보류 원형 | 근거 |
|---|---|---|
| shuffle() 예시 출력 | `Before: Array (  => apples  => oranges  => grapes  => bananas  => strawberries ) After: Array (  => strawberries  => oranges  => apples  => bananas  => grapes )` | 배열 인덱스 숫자가 소실된 `=>` 껍데기는 복원하지 않았다. 원문에 남은 Before/After 값과 순서는 본문에 목록으로 보존했다. |
| array_rand() 코드 도입 | `The second parameter in the function tells it how many keys to return, as in the following example:` | 두 번째 인수의 완결 설명은 본문에 두고, 존재하지 않는 예제를 직접 예고하는 꼬리만 분리했다. |
| array_rand() 코드와 직접 출력 | `<?php $fruit = array('red'=>'apples', 'orange'=>'oranges', 'purple'=>'grapes', 'yellow'=>'bananas'); echo '<p>Array Before: '; print_r($fruit); echo '</p>'; $random = array_rand($fruit, 2); echo '<p>Two Random Keys: '; print_r($random); echo '<br />'; $valueOne = $random; $valueTwo = $random; echo '<p>First Random Value: ' . $fruit[$valueOne] . '<br />'; echo 'Second Random Value: ' . $fruit[$valueTwo] . '</p>'; ?>`<br><br>`This code gives us the following possible output:`<br><br>`Array Before: Array ( [red] => apples [orange] => oranges [purple] => grapes [yellow] => bananas ) Two Random Keys: Array (  => red  => purple ) First Random Value: apples Second Random Value: grapes` | `$valueOne`/`$valueTwo`에는 `$random` 배열 자체를 대입하지만 출력은 각 단일 키에 대응하는 값을 말한다. 이 연결을 새 코드나 배열 인덱스로 정하지 않고 코드·직접 결과를 함께 원형 보류했다. 출력의 빈 인덱스도 채우지 않았다. |

이 원형에는 누락 인덱스, 배열 첨자, API 동작을 새로 채우지 않았다.
