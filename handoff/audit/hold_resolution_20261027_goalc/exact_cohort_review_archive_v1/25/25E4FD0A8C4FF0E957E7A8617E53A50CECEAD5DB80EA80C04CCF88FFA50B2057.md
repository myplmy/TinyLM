# expanded_train:179203 원형 보류 및 경계

출력 본문에는 후보 첫 줄의 검색 UI 개수 문장 “4 edition ... found in the catalog.”를 포함하지 않고, 이어지는 첫 catalog record의 실제 제목/표기·이름·출판사 표기·Physical Object/Number of Pages 352 필드를 원래 순서로 보존했다. 각 라벨/값의 원래 관계를 넘어 저자·편집자·출판사 역할이나 판본 수를 새로 단정하지 않았다.

후보의 다음 문장 “The key Middle English reference work ...”부터 EOF까지는 소실된 서지값과 복수 책·검색/홍보 텍스트 및 서로 다른 서지/본문 조각이 혼합되어 한 문서의 경계를 정할 수 없다. 해당 tail 전체를 원형 HOLD로 남기고 서로 다른 조각을 한 책이나 한 출처로 재구성하지 않았다. 원형과 전체 tail은 지정 입력 파일에 그대로 남아 있으며 이 sidecar는 보류 경계의 시작 문구와 이유를 기록한다.
