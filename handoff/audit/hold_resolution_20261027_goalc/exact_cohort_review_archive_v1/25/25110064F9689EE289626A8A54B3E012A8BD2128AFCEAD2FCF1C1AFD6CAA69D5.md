# expanded_train:120410 출생 연도 보류

같은 인물에 대해 원문이 서로 다른 출생연도를 단정하므로 어느 연도도 선택하지 않는다. 원형 주장들은 다음과 같다.

- 본문 머리말: `필리프 5세(1292년 ~ 1322년 1월 3일)는 장신왕(프랑스어:le Long)으로도 알려진 1316년부터 1322년까지의 프랑스와 나바라의 왕(펠리페 2세)이다.`
- 본문 생애 서술: `필리프는 1291년 리옹에서 프랑스 군주 필리프 4세와 나바라의 여왕 후아나 1세의 차남으로 태어났다.`
- 분류: `1292년 출생`

새 본문에서는 두 출생연도 표기를 모두 분리했다. 리옹 출생, 부모, 사망일 `1322년 1월 3일`, 재위 기간, 본문 전체의 사건·가족 관계·연혁과 13·14세기 분류는 유지했다. 연도를 선택하거나 다른 날짜를 계산하지 않았다.
