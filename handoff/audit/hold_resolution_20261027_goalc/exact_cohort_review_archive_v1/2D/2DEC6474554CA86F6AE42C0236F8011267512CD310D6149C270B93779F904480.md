# expanded_train:45462 원형 보류

수식/기호가 비어 있는 정의와 그 값에 직접 의존하는 예제·결론을 원형 보존했다. 새로운 변수·함수·집합·식·출력을 채우지 않는다.

- 첫 정의 블록: `수학에서, 함수 는 집합 의 모든 원소를 각각 집합 의 한 원소에 대응시키는 수학적 구조다. 이 경우, 를 의 공역이라고 한다. 반면, 는 의 정의역이다.` 함수·집합 기호와 관계 대상이 소실되어 블록 전체를 본문에서 분리했다.
- 범위 정의 중 손상 슬롯: `모든 에 대하여, 인 가 존재할 필요는 없다.` 및 `정의역의 상, 즉 인 가 존재하는 들의 집합을 의 치역이라고 한다.` 빈 기호·항을 보충하지 않았다. 같은 단락의 완결된 `공역의 모든 원소가 정의역의 상에 포함될 필요는 없다.`와 `치역은 항상 공역의 부분집합이지만, 치역이 공역과 같을 필요는 없다.`는 본문에서 보존했다.
- 예제 1의 함수 정의/식/결과 슬롯: `함수 가 다음과 같이 정의되었다고 하자.` / (빈 식 위치) / `이 경우, 의 공역은 이지만, 의 치역은 이다.`
- 예제 2의 함수 정의/식과 비교: `함수 가 다음과 같이 정의되었다고 하자.` / (빈 식 위치) / `와 는 같은 그래프를 가지지만, 현대적 관점에서는 두 함수는 같지 않다. 그 이유는 두 함수의 공역이 다르기 때문이다.`
- 추가 정의 예고 및 빈 정의역 조건: `함수를 하나 더 정의해 보면 왜 그런지 알 수 있다.` / `정의역은 반드시 로 정의되어야 한다.` / (빈 식 위치)
- 합성 예제: `이제 함수를 합성해 보자.` / (빈 식 위치) / `이 둘 중에서 어떤 합성 함수가 올바른 것인가?` / `밝혀진 대로, 첫 번째 것은 올바른 합성 함수가 아니다. 의 치역을 알지 못한다고 가정하면(확실히 알지 못하는 상황이라면 이렇게 가정해야 한다), 단지 치역이 의 일부가 된다는 것밖에 알지 못한다. 그러면 제곱근이 음수에 대하여 정의되지 않았기 때문에 문제가 생기게 된다. 이제 모순점이 생길 수 있다는 것을 알았다.`
- 미상 합성식에 바로 연결된 평가 문장 `이것은 분명치 못하며, 이런 것은 피해야 한다.`도 식을 특정하는 문맥이 없으므로 함께 보류했다. 바로 뒤의 명시된 공역/정의역 관계와 치역 한정은 독립적으로 읽히므로 본문에 유지했다.
- 전사성 예시의 비어 있는 함수명: `는 전사 함수인데, 는 그렇지 않다.` 이 비교는 대상 함수를 알 수 없어 보류했다. 바로 앞·뒤의 완결된 공역과 전사성/단사성 일반 설명은 유지했다.

공역의 실제 두 명칭, 공역/치역에 관한 완결 문장, 현대적 관점의 그래프 관계, 완결 합성 조건, 전사성/단사성에 대한 완결 설명, 실제 같이 보기 항목은 새 본문에 보존했다. 외부 수학 검증이나 결손 수식 복구를 주장하지 않는다.
