# expanded_train:37212 빈 이름 병기와 마크업

첫 문장의 `라돈(←, )`과 기호 표기의 `Rn(←)`에는 실제 병기 값이 없다. 이름·기호·원자번호와 기사에 적힌 설명·날짜·수치·조건은 본문에 보존하고 해당 빈 슬롯만 분리했다.

역사 부분의 `akton이<ref></ref>,`는 값 없는 참고 마크업이고, `actinon''이`는 대응하는 앞표식이 없는 끝 인용부호 두 글자다. 실제 화학 원소 이름 `akton`, `actinon` 및 연도별 명명 기록은 그대로 유지해 빈 태그와 고립 표식만 정리했다. 과학·의학 서술은 원문 그대로 보존했으며 외부 사실 검증을 하지 않았다. 후보가 제거한 빈 각주 표제는 유지했다. `라돈 - WebElements.com`은 실제 링크 설명으로 보존했다.

## 원형 슬롯·표식
