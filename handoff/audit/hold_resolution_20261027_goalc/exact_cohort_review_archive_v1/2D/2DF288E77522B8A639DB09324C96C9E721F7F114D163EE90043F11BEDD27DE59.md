# 1168516 보류 원형

- `Home > Teaching > Tutorials > R Tutorial Index`는 breadcrumb 탐색 UI로 분리했다. `R Basics`와 실제 주제 라벨은 본문에 남겼다.
- `For instance, if R was looking at the Desktop ... the following command will make R look in that folder:`와 `To move back or up one folder (...), use`는 명령이 빠진 직접 예고로 보류했다. 실제 명시된 `setwd("~/Desktop")`는 보존했다.
- `When done working with R, either close the window or type`와 이어지는 `R will then prompt whether the workspace ...`는 명령이 빠진 조건/결과 구간이라 함께 보류했다.
- 벡터 출력 설명의 `Look back at the output above. There is a . That means that the first element shown on that line is the first element of x.`는 실제 출력값·위치 표식이 비어 있어 원형 보류했다. 뒤의 완결된 bracket 위치 설명과 코드 예시는 남겼다.
- 열을 `attached`해야 한다는 명령 도입문과 `Now the columns can be accessed by their names.` 문장은 실제 명령이 없어 분리했다. 데이터프레임의 완결 정의, `height` 조회와 그 실제 7개 값, `detach()` 설명은 보존했다. `attach()` 등 명령을 추정해 추가하지 않았다.
- `Data is typically imported as a data frameThis is usually...`의 문장 경계만 최소한으로 분리해 읽을 수 있게 했다. 그 외 R 함수·코드·출력은 변경하지 않았다.
