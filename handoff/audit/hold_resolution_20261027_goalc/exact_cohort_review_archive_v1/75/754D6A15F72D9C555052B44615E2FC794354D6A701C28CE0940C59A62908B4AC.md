# 874017 원형 보류

선택 본문: `reviewed_874017_task064_v1.txt`.

비교 대상으로 지정한 `one that only calls ...`에서 실제 호출 대상이 빠진 조각만 분리했다. 그 조각에 맞춰 비교를 완성하지 않았다. 앞의 실제 `if (x != 0) launch_nuclear_missiles();` 예제와 원문에 있는 컴파일러가 조건을 무시하고 무조건 호출할 수 있다는 설명은 유지했다. 이어지는 악의적 입력이 없는 작업에만 그러한 동작이 적절하다는 원래 조건도 보존했다. 저자 예시의 정확성이나 컴파일러 의미를 외부 지식으로 수정하지 않았다.

## 원문 발췌

```text
launch_nuclear_missiles() as superior to one that only calls
x is non-zero, but such behavior would only be appropriate when processing tasks that will never involve untrustworthy input.
```
