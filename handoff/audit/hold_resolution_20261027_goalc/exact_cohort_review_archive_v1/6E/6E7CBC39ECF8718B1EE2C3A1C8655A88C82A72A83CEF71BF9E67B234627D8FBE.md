# expanded_train:1412289 보류 원형

## 분리한 원문

> In PowerShell, you would do something like this:
> if ($myObject.GetType() -eq [MyType])
> #print the current name to screen

> Calling this code on the command line might look like:
> PS> $myObject = changeName $myNewObject

## 근거

if 조건의 예시는 필요한 본문/print 호출이 소실돼 완결 코드로 남기지 않았습니다. 호출 소개는 이 손상 예시를 직접 가리켜 함께 분리했습니다. 중간 changeName 호출은 앞의 실제 $myObject와 달리 갑자기 $myNewObject를 사용하므로 이 직접 불명확한 연결만 보류했습니다. 원문에 실제 채워진 $myObject.Name = "NewName" 대입, New-Object MyType 명령, 마지막 New-Object ... | changeName 파이프는 본문에 보존했으며 함수 코드나 변수 통일을 만들지 않았습니다.
