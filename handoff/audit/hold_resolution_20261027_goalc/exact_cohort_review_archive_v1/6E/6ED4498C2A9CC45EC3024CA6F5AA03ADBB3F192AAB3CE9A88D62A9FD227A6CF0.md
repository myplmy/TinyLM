# expanded_train:11066 원형 보류

## 원형 조각

- `베트남 사회주의 공화국 주석()`, `베트남 국가주석()`, `국가이사회 주석()`의 빈 병기 슬롯.
- 내용이 없는 `역대 주석`, `베트남 민주공화국`, `베트남 사회주의 공화국`, `외부 링크` 표제.
- 후보가 제거한 빈 `각주` 표제.

## 선택 경계

세 직함은 이름을 보존하고 빈 괄호만 정리했다. 역대 주석 구역은 제목만 있고 명단/내용이 없어서 표제 세 개를 학습 본문에서 분리했다. 실제 `같이 보기` 항목과 분류는 유지했다. 빈 외부 링크·각주 슬롯은 복원하지 않았다. 임기·선출·직무대행에 관한 나머지 문장은 변경하지 않았고, 새 인명·기간·목록을 만들지 않았다.
