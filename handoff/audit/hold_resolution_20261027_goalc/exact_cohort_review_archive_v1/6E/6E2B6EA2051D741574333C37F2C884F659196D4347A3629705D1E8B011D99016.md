# expanded_train:645122 — 보류한 누락/손상 assert 조각

본문에서 다음 코드 예고를 분리했다.

> and at the very end below command is used which validate all softassert if any of them is failed then it failed overall softassert.

뒤에 이 문장이 가리키는 명령 예시는 없다. 앞의 SoftAssert 설명과 조건은 유지했으며 `assertAll` 등 실제 없는 API 호출을 만들지 않았다.

또 다음 손상된 호출은 실행 가능한 코드처럼 본문에 남기지 않고 원형을 보류했다.

> Assert.fail(“There are “+ CustomAssert.size()+ happened during test execution.)

따옴표/연결 인수가 끊겨 있어 이를 수정하거나 출력 문자열을 추측하지 않았다. `CustomAssert`의 선언·사용법과 실패 수를 세는 설명은 보존했다.
