# 464188 원형 및 교정 경계

완결된 DAC constructor/method 서명, 채워진 코드 예제, 수치·단위·조건, DAC 동작 설명은 본문에 보존했다. 원문에서 API parameter/value와 이어지는 서술어 사이 띄어쓰기가 명백히 빠진 곳만 분리해 원형 기록했다. 마지막 `bits` 설명의 `or by using the`는 받는 API/method가 지정되지 않아 그 미완 연결만 본문에서 분리했다. 그 API 이름이나 동작은 추정하지 않는다.

## 지정 원문 발췌

- `portcan be a pin object, or an integer (1 or 2). DAC(1) is on pin X5 and DAC(2) is on pin X6.` → 본문에서 `port can`으로 단어 경계만 복구.
- `bitsis an integer specifying the resolution, and can be 8 or 12. The maximum value for the write and write_timed methods will be 2**``bits``-1.` → 본문에서 `bits is`로 단어 경계만 복구.
- `Noneto select the default (buffering enabled for` → 본문에서 `None to`로 단어 경계만 복구.
- `Falseto disable buffering completely, or` → 본문에서 `False to`로 단어 경계만 복구.
- `Trueto enable output buffering.` → 본문에서 `True to`로 단어 경계만 복구.
- `bitsis set when creating the DAC object or by using the` → 본문에 `bits is set when creating the DAC object.`까지만 유지하고, 받는 method/호출이 빠진 꼬리는 분리.
- `freqcan be an integer specifying the frequency to write the DAC samples at, using Timer(6). Or it can be an already-initialised Timer object which is used to trigger the DAC sample. Valid timers are 2, 4, 5, 6, 7 and 8.` → 본문에서 `freq can`으로 단어 경계만 복구.
