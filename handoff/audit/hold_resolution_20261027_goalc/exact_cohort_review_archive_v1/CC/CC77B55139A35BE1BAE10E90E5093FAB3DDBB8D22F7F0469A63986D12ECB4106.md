# 1415486 원형 보류 — v3 본문 연결

원문과 candidate는 바이트 동일했다. 수정본은 실제 빈 명령·그림·코드 대상에 직접 기대는 부분만 분리했다. 없는 명령, 그림, 전체 JavaScript/CSS/HTML, 주소 예시를 생성하지 않았다. 명시된 GPIO 배선·17/11 핀 관계·실제 WebIOPi 명령/설정·`webiopi()`/변수/메서드 설명·CSS/HTML 실제 항목과 수치·조건·경로·보안 설명은 보존했다.

## 원형 보류 구절

- 그림/빈 차트 포인터: `In the pictures above,` / `[CENTER]Circuit diagram [/CENTER]` / `SEE THE HANDY CHART.`
- 실제 명령이 빠진 설정 유틸리티 실행 예고: `At the command prompt, enter this to open the configuration utility:`. 후속 메뉴 설명은 원문에 직접 적힌 `configuration utility`라는 말만 사용해 `In the configuration utility, ...`로 최소 연결했다. 빈 캡처 예고 `You'll see this in your window: [CENTER][/CENTER]`와 그림을 받는 `as shown`은 분리했고 8번/Advanced Options, 16 설정, 탭 조작과 재부팅 설명은 남겼다.
- 소실 명령을 직접 가리키는 문장 전체: `Enter the above commands, one at a time to get everything we need to let Python talk to the GPIO. Without this, our project will do nothing except give us errors when we try to run it. Nobody likes errors.`
- 불완전한 위치/실행 예고: `Make sure you're in your home folder:` / `Enter the directory you just created:` / `Run the setup script (as root):`. 그 앞의 완결된 문장 `You won't find it in your package manager, but installing it is still pretty easy.`는 보존했다. 실제 `tar -xvzf WebIOPi-0.7.0.tar.gz`와 `sudo webiopi -d -c /etc/webiopi/config`도 보존했다.
- 폴더 생성 명령 예고: `From the command prompt, do this to make sure you're in your home folder:` / `Create a Project folder:` / `Create a Webio project folder:` / `Move to the Webio project folder:` / `Inside our Webio project, make an html folder:` / `Inside the html folder, make a folder for images, scripts and stylesheets:`. 뒤의 경로 조정 조건, 프로젝트 배치 설명, 실제 폴더 이름과 사용자/기계 이름 차이는 유지했다. 빈 폴더그림 예고 `If you followed along, you should have this: [CENTER][/CENTER]`만 보류했다.
- 본문에 나타나지 않는 JavaScript 파일을 직접 지시하는 문장: `When you have this file created and saved on your computer, copy it to Projects/Webio/html/scripts with Filezilla.` 실제 함수/변수/작동 설명은 유지했다.
- 빈 CSS 링크·코드·예시를 직접 가리키는 원형: `This link is your lifesaver when you have to write CSS. I'm not going to try and explain each and every line here, but we will take a look at each block to discuss what it does.` / `Besides drawing some nice buttons on a tiny web page like we're doing, you can do this with it. I tip my hat to Derek Kessler, and thank the gods both old and new that I wasn't asked to build that.` / `OK, let's look at this code a bit.` 실제로 적힌 블록 설명, 속성 동작, 수치와 브라우저명은 남겼다.
- 빠진 CSS 파일을 직접 가리키는 복사 지시 원형: `Copy this file exactly as it is written to your editor, and save it as bacon.css so it works with our html. When done, copy it to the Projects/Webio/html/styles folder on your Pi.` 수정본문은 원문에 명시된 `bacon.css` 파일명과 경로를 독립 문장으로 유지했으며 파일 내용을 새로 쓰지 않았다.
- 빠진 HTML 예제를 직접 전제한 원형: `Once you have this file all written up in your editor,` / `It should look like this:`. 실제 meta/link 행과 `index.html`, `Projects/Webio/html` 경로 및 최상위 폴더 조건은 보존했다.
- 실제 예시 IP/포트가 없는 직접 예고: `Enter the IP address of your Pi (the same one you use for SSH) followed by the port to talk to:`. 이 문서 앞쪽의 실제 테스트 URL과 이후 IP/포트 설명은 유지했다.
- 빈 연결 그림 껍데기: ` [CENTER][/CENTER]` (실제 `Connecting` 표제와 연결 설명은 유지).

보류 구절은 입력에 보이는 원형 그대로 기록했다. 빈 영역에 값이나 실행 가능한 표본을 보충하지 않았다.
