# 661966 원형 보존 메모

## 분리한 좋아요 UI

댓글 본문 사이에 있던 단독 UI 줄은 다음과 같다.

```text
LikeLiked by 1 person
```

이는 댓글 작성자의 발화가 아니라 좋아요 버튼/수 집계 표시로 읽힌다. 이 UI 줄만 본문에서 분리했다. `4 thoughts on ...` 표제와 독자의 실제 댓글, 답글, 문장 및 이모지는 각기 본문 내용으로 보존했다.

## 판독 범위

지정 original/candidate 전문과 순서 패킷 0001–0002를 BEGIN부터 END/EOF까지 대조했다. 후보 전체 diff는 줄 차이가 없었다. 새 본문에서 위 좋아요 UI 줄만 제거했다.
