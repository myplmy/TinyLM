# 271349 원형 보류 및 형식 정리 근거

판정은 지정된 original/candidate와 0001–0006 연속 packet의 전문 및 full_diff 끝까지 읽은 범위에 한정한다. 후보와 original의 직접 diff는 packet 0005–0006에서 끝까지 확인했다. 본문 언어와 남은 문장/태그 목록/코드 예시는 원문에 있는 그대로 유지하며 HTML 사실을 외부 검증하지 않았다.

## 본문에서 분리한 결손·빈 구획

- 비어 있는 설명 대상을 가리키는 원문 `HTML의 문서의 일부는` 및 `다음과 동등한 것으로 추론한다:`를 함께 보류했다. 그 사이에 비교 대상이 없다.
- 빈 태그 슬롯을 포함한 원문 `그림 () 요소와 같은`만 제거했다. 실제 요소명이나 그림 태그는 채우지 않았다. 같은 문단의 일반 설명은 남겼다.
- 빠진 태그명을 요구하는 원문 `빈 요소의 다른 예는  요소이며 이를 위한 문법은 다음과 같다:`를 보류했다. 뒤의 실제 `<link rel="stylesheet" href="fancy.css" type="text/css">` 예와 이어지는 문장을 보존했다.
- 주어가 비어 있는 원문 `마크업 은 Xbegin<!--Y과 그 뒤에 텍스트 Xend-->를 만들어낸다.`를 보류했다. 다른 주석 문법 설명과 주석 위치 설명은 보존했다.
- 원문의 실제 `각주` / `내용주` 표제 아래에 항목이 없으므로 후보가 제거한 빈 표제 구획을 학습본문에 되살리지 않았다.
- 외부 링크의 원문 행 `  (Oct 28, 2014): elements and attributes`는 링크 제목 슬롯이 비어 있어 행 전체를 보류했다. 실제 제목/날짜가 있는 `HTML 4.01 (Dec 24, 1999): elements and attributes`는 유지했다.

## 제한된 마크업 껍데기 정리

- 원문/후보의 목록 항목 `<h1> to <h6></code>`에서 내용에 속하지 않는 고립 닫는 `</code>`만 제거하고 실제 범위 `<h1> to <h6>`는 유지했다.
- 후보가 `시작 태그 ()`와 `종료 태그 ... ()`의 빈 괄호를 이미 정리한 것은 유지했다. 새 태그명이나 예제를 보충하지 않았다.
- `<link ...>` 코드가 실제로 남아 있고 다음의 `이 요소는`이 그 바로 앞 코드를 받는 위치에 있으므로 빈 태그 슬롯만 정리했다. 새 태그 이름을 덧붙이지 않았다.

## 보존 범위

실제 시작/종료 태그 예시, 속성 예시, HTML 태그 목록, SGML/XML·CSS·DTD·XHTML 설명, DOM 및 JavaScript 관련 항목과 `HTML`/`웹 1.0` 분류를 유지했다. 문장 품질이나 기술적 참·거짓은 이 정리에서 판정하지 않았다.
