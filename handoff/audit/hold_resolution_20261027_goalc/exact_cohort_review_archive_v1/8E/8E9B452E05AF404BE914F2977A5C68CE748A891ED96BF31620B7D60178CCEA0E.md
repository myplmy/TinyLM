# 937291 — 원형 보류: 페이지 상단 이동 UI

후보 본문에서 단독으로 반복된 소문자 `back to top` 다섯 발생(후보 원문 3, 6, 13, 29, 35행)은 페이지 상단으로 이동하는 탐색 UI로 판독했다. 해당 원형 문구와 발생 위치를 이 sidecar에 보존하고 학습 본문에서는 분리했다.

진단, 증상, 임신부·태아 위험, 치료, 용량과 조건, 갑상샘 폭풍 대처, 참고 각주 번호, 이해상충 문구와 저자 약력은 보존했다. 탐색 UI를 제거해도 인접한 의학 설명은 완결되어 있어 변경하지 않았다. 새로운 의학 사실은 추가하지 않았다.

판독 입력은 TASK_029의 지정 original/candidate와 연속 패킷 0001–0005다. 모든 패킷을 순서대로 논리 END/실제 EOF까지 읽고 original, candidate, 전체 diff를 대조했다.
