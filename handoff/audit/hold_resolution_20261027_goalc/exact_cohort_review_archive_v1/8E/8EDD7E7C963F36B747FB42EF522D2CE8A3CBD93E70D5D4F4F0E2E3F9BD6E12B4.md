# 31771 대상 국가명이 없는 사용 국가 목록 보류 근거

## 원형 블록

```text
사용 국가 
  (국가의 공용어.)
  (제2언어 등으로 사용.)
  (제2언어 등으로 사용.)
  (제2언어 등으로 사용하며, 나히체반 공화국 지역에서 다수 사용.)
  (제2언어 등으로 사용.)
  (튀르키예계 이주민이 약간 사용.)
  (튀르키예계 이주민이 약간 사용.)
  (제2언어 등으로 사용.)
  (제2언어 등으로 사용.)
  (독일에 거주하는 튀르키예계 이주민이 사용.)
  (한국 내 튀르키예계 이주민이 약간 사용.)
```

## 판정

- 각 행에 국가명이 없고 설명만 남아 있어 행별 주체·귀속을 확정할 수 없다. 목록 전체를 보류했으며 인접 문장·후속 분류에서 국가명을 보충하지 않았다.
- 독립적으로 완결된 언어 설명과 튀르키예어-한국어 비교 문단, 실제 예문, 참고문헌, 외부 사전 링크 및 분류는 본문에 보존했다.
- 빈 `각주` 표제는 후보가 이미 분리했음을 전체 diff에서 확인했다. `not()`, `no()`, `ikke()`는 원문에서 명명된 예시 토큰이므로 그대로 유지했다.
