# 1424429 원형 보류

원문이 예고하지만 입력에 실제 예시 코드/속성값이 없는 구간을 원형 보존했다.

- `So for example:` 및 `Now if I want to change the first h1 we can pass the text that we would like into the .text method:` — `.text()`의 동작 설명 뒤에 예고된 예제는 없다.
- `.attr()` 예시 구간: `For example` / `Will return the current source of the selected image. But if you use the second attribute:` / `Will change whatever the image src was to this new image hosted on my website. This changes the picture.` — getter/setter 예제 코드와 실제 속성값은 없다. URL·새 이미지·속성값을 만들어 넣지 않았다.

본문에서 `.attr() allows...`로 정리한 것은 바로 다음 문장의 동일한 `.attr()` 명칭을 주어로 연결한 것이다. 기존에 적힌 `.textContent`, `.text()`, `.innerHTML`, getter/setter, alt text 및 이미지 설명은 유지했다. 링크 대상의 현재 내용은 검증하지 않았다.
