# 947692 — 원형 보류

원문에 실제로 있던 미완성 시그니처 조각, 문장·조건 표의 잘린 항목, 손상 코드 예제를 그대로 보존한다. 함수 인수·오류 조건의 나머지·코드 비교 연산자를 채우지 않았다.

## 서명 조각

```text
const char *path,
const struct acl_entry *acl
const struct acl_entry *acl
```

이 조각은 함수 이름 및 항목 간 구분이 없어 서명으로 재구성하지 않았다.
