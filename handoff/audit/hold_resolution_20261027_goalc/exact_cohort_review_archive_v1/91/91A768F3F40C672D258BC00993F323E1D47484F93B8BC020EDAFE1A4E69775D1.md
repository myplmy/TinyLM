# expanded_train:807935 최소 문자 경계 기록

지정 original/candidate 전문, 패킷 0001–0002와 full_diff END까지 읽었다. candidate는 원문과 줄 차이가 없다.

원문 문구 `dirparameter`를 새 본문에서 `dir parameter`로 최소 띄어쓰기 정리했다. 같은 설명 안에서 반복 사용된 실제 매개변수 표현 `dir parameter`와 바로 붙어 있어 단어 경계만 복원한 것이며, 함수·경로·권한·fallback 조건은 바꾸지 않았다. 원형 표기는 이 MD에 보존한다. PHP 동작이나 외부 버전을 따로 검증하지 않았다.
