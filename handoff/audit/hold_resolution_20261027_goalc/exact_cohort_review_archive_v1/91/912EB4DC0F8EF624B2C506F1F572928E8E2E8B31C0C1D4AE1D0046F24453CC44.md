# expanded_train:1286176 원형 보류 기록

- `Look at this code:` 및 `When you run this code, you end up with two instances of`는 뒤따를 초기 코드가 없는 직접 포인터다. 원문 `MyClass that look the same:`의 정보와 `myCollection`/`myItem`/`push_back()` 관계는 본문에서 한 문장으로 보존했으며 초기 코드는 작성하지 않았다.
- 첫 부가 항목의 원형은 `Copy constructors are the most obvious scenario for move semantics, but any function can use`이다. 완결된 복사 생성자 진술은 본문에 남기고, 목적어가 없는 `but any function can use` 꼬리만 분리했다.

`MyClass(MyClass&& other)` 시그니처와 실제 핸들 필드 대입, `if (m_fileHandle != -1)`, `memcpy()`, `GimmeInstance()`, `std::move()` 등 원문에 명시된 C++ 기호/값/이름은 보존했다. 코드 조각을 실행하거나 클래스 본문·함수·인자·결과를 채우지 않았다. `std::move()to`는 이름 뒤에 빠진 공백만 복구했다.
