# 139164 원형 보류 근거

원문과 지정 후보에는 차이가 없었다. 왕족 정보 틀의 값 없는 필드행은 제거하고, 채워진 이름·직위·재위·날짜·가족·종교 등의 실제 관계를 보존했다. `그림`에는 설명 문장 없이 이미지 파일명만 있으므로 비본문 이미지 메타데이터로 이 sidecar에 보존한다.

```text
|이름     = 코실라 쿠툭투 카안 |원래 이름 =
|그림     = Khutughtu Khan Kusala.jpg
|그림설명 =
|서명     =
|문장     =
|문장설명 =
|즉위식   =
|섭정     =
|재상     =
|수상     =
|총리     =
|별호     =
|능호     =
|출생지   =
|매장지   =
|능묘     =
|친인척   =
```

실제 채워진 이름 표기를 남기고, 빈 병기 슬롯과 그에만 붙은 쉼표·괄호 및 짝 없는 굵게 표시를 정리했다. 원형은 아래와 같다.

```text
|휘       = 코실라(, )
|칸호 = 쿠툭투 카안(, )
칸호는 쿠툭투 카안(, 忽都篤 可汗, 古圖土 可汗)이다.  코실라(, , , Хослен) 또는 쿠살라'''(Ku sha la)로,
```

한자·키릴문자·몽골어 등 실제 채워진 표기는 그대로 보존했고, 누락된 표기를 추정해 넣지 않았다. 도입 연도·음력/서기 날짜·장소의 대안, 사망 원인/주장 귀속과 불확실성, 사건·가족·직위·수치는 후보 그대로 두었다. 원문에 있는 역사 서술을 외부 검증해 고치지 않았다.

작품 목록의 완결된 실제 방송·기간·배우 값은 유지하며 닫는 괄호 하나만 구조상 보충했다. 원형:

```text
 《기황후》 (MBC, 월화드라마 2013년~2014년, 배우: 이창환
```

날짜와 주체가 실제로 명시된 사건 문장 앞의 짝 없는 여는 대괄호만 분리했다. 실제 원형 구간 전체는 다음과 같다.

```text
그러나 제위 쟁탈전을 지켜본 투그테무르의 형 쿠살라는 차가타이 한국의 지도자 엘지크데이와 두아 테무르의 지원을 받아 1328년 말  몽골과 차가타이 칸국의 장군들을 모아서 월등한 대군으로 출발, 타르바가타이 지역(현, 항가이 산맥)을 거쳐 몽골로 들어갔다. [ 1329년 1월 26일 쿠살라와 그가 이끄는 군대는 카라코룸 북쪽의 체첵 호수와 테르힝 차강 호수 근처에 도달했다. 쿠살라는 원나라 내부에 지지 세력을 만들지 못했다.
```

이 구간에서 새 링크·인용·사건은 만들지 않았다.
