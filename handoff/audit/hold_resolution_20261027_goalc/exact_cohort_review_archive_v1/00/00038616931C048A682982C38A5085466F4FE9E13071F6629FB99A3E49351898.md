# 877793 원형 보류

선택 본문: `reviewed_877793_task064_v1.txt`.

세 예제 코드 줄은 Python 문장/블록 경계가 평탄화되어 실행 단위와 결과 주석의 연결을 원문만으로 확정할 수 없어 각각 원형 보류했다. 코드의 경계나 들여쓰기를 복원·실행하지 않고 숫자 출력 주석을 본문 결과로 남기지 않았다. 해당 두 예제 소개와 lambda 예제에 직접 붙은 불완전한 설명도 함께 보류했다. `map()`의 실제 이름, 일반 기능·인수 관계, iterable 정의, 이름 없는 lambda의 독립 정의, 마지막 비교 설명은 보존했다.

## 원문 발췌

```text
Let’s write a simple map function that will calculate the length of Each name in the length of each word in the tuple:
def findLengthOfNames(a): return len(a) x = map(findLengthOfNames, ('wisdom', 'James', 'Deven','Favour')) print(list(x)) #[6,5,5,6]
Lets write another function that will calculate the square of multiple numbers:
def calculateSquare(n): return n*n numbers = (1, 2, 3, 4) result = map(calculateSquare, numbers) print(result) #[1, 4, 9, 16]
Since the
map() the method expects a function to be passed in, lambda functions are commonly used while working with
numbers = (1, 2, 3, 4) result = map(lambda x: x*x, numbers) print(result) #[1, 4, 9, 16]
```
