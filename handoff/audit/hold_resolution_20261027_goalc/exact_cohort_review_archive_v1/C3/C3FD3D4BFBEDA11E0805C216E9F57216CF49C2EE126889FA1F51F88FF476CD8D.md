# 670928 — Bash here-document 예제 원형 보류 v1

원문/candidate는 동일하다. Vim/ex의 채워진 명령, 인수, 결과 설명과 일반 here-document 설명(원문 35행)은 본문에 유지한다. 원문 36행의 예제 예고와 37행의 한 줄 Bash here-document는 한 손상 단위로 분리했다. `#` 주석이 어디서 끝나는지, `COMMENT`가 예제의 종결자인지 설명문 일부인지, 실행 경계가 어디인지 추정하지 않았다.

> Example bash code:
>
> #!/bin/bash echo "this will be echoed" : <<- COMMENT echo "this will not be echoed" echo "neither will this" ls -d .[a-z]* # You can even insert tabs and comments. Or just write whatever COMMENT

이 예제와 직접 묶인 구체 실행/주석/종결 표시는 본문에 남기지 않았다. 원문 35행의 `<<- COMMENT` 일반 설명은 이 특정 손상 코드 경계를 복원하지 않아도 이해되므로 보존했다. 원문에 있는 Maedox 이름과 시간 표기도 본문에 그대로 유지한다. 쉘 실행, 코드 복구 또는 결과 검증은 하지 않았다.
