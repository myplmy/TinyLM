# expanded_train:946424 원형 분리 및 구조 정리

- 원문 `This indicates the microbit is attached to COM port 5.`는 앞의 설치/COM 표시 다음에 놓인 관측 캡션으로 보이며 이를 뒷받침하는 화면은 지정 입력에 없다. 그 정확한 포트 번호 관측을 새 증거처럼 남기지 않도록 원형 분리했다. COM 포트가 나타난다는 명시 문장 자체는 유지했다.
- `The settings for the terminal connection are the same whether it’s a`에는 비교 대상이 없고, `Open the correct COM port:` 및 `Change connection properties under` / `Connection > Serial...:`에는 뒤따르는 설정 값·완료 단계가 없어 각각의 미완 절/단계를 분리했다.
- `It also tends to use` / `print() instead of`에는 비교항이 없다. `It’s important to note` / `print("hello") are exactly the same: they both output to`에는 비교 주체와 출력 대상이 없다. `uart module exposes many useful functions such as`에는 목록이 없다. 이 미완 조각만 원형대로 분리했다.
- `To access this interface, the mbed serial drivers must be installed:` 및 `Once installed, plugging in the microbit will cause a COM port to appear on the the host computer:`의 콜론은 뒤에 목록/절차가 없어 마침표로 정리했다. `Tera Term is an open source application that’s straight forward to use:`의 콜론도 뒤따르는 누락 절차가 없어 마침표로 바꾸었다. 마지막 `Establishing a serial connection is useful when developing applications on the computer to interact with the microbit:`는 완결된 주장으로 유지하며 끝 문장부호만 정리했다.
- `COM port 5` 관측을 제외한 115200 baud, Tera Term/Realterm, USB·PXT/Python·UART 및 실제 동작 설명은 원문대로 유지했다. 빠진 비교값/설정/출력값/코드나 그림 내용은 생성·확인하지 않았다.
