독립 A* 소개, 1968년의 실제 인명·연도와 조건부 최적성 설명, 완결 3×3/1–8/빈칸/총 이동 최소화 문제는 본문에 남겼다. 실제 기호를 추정하지 않고 손상된 함수 예고와 직접 종속 예제를 아래 원형대로 분리했다.

## 미상 평가식·정의 기호

```text
이를 위한 평가 함수 은 다음과 같다.

  : 출발 꼭짓점으로부터 꼭짓점 까지의 경로 가중치
  : 꼭짓점 으로부터 목표 꼭짓점까지의 추정 경로 가중치
```

평가 함수 이름과 두 정의행의 기호/꼭짓점 인수가 소실되어 대응을 만들지 않았다. 바로 앞의 완결 문장 `이를 위해서는 각각의 꼭짓점에 대한 평가 함수를 정의해야 한다.`는 보존했다.

```text
// 이 소스 코드의 그래프는 인접 리스트 방식으로 그래프를 표현하였다.
using ii = pair<int, int>;

priority_queue<ii, vector<ii>, greater<ii> > pq;
/// N_VER은 그래프의 정점의 개수를 의미한다.
int dist[N_VER], cost[N_VER][N_VER]; /// dist[i]는 i번째 정점까지 가는 최단 거리를 의미한다.
vector<ii> edges[N_VER]; /// edges[i]는 i와 연결된 정점과 가중치를 묶어 저장하는 벡터이다.

int minDist(int src, int dst) {
    pq.emplace(0, src);
    bool success = false;
    while (!pq.empty()) {
        int v = pq.top(); pq.pop();
        if (v == dst) {
            success = true;
            break;
        }
        for (ii& adj : edges[v]) {
            if (dist[adj.first] < g(v) + adj.second + h(adj.first)) {
                dist[adj.first] = g(v) + adj.second + h(adj.first); // 이완 (relaxation)
                pq.emplace(dist[adj], adj); // 다음 정점 후보에 탐색하고 있는 정점을 넣는다.
            }
        }
    }
    if (!success) return -1;
    else return dist[dst];
}
```

예제 예고와 pseudocode/C++는 빠진 평가식 기호 및 g/h 역할 정의를 직접 참조하므로 한 단위씩 원형 보류했다. `g`, `h`, `cost`, 호출 인수/반환값, 비교 방향 및 큐 요소 타입을 새로 정의하거나 코드 실행/정정하지 않았다. 마지막 `그래프 알고리즘`, `검색 알고리즘`, `라우팅 알고리즘`, `조합 최적화` 분류는 보존했다.
