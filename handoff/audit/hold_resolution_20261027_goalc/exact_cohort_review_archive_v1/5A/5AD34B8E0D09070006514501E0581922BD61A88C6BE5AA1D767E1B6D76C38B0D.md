## 분리한 원문 조각

- 설치 안내 뒤의 미완 지시: “Next, type in,”
- 주어가 사라진 문장: “allows the Jupyter Lab to show matplotlib plots in the browser window.”
- CSV 읽기 코드가 빠진 예고: “In the next cell, type the following code to get the CSV data into a pandas dataframe:”
- 값 치환 문장을 예고하지만 실제 문(statement)이 없는 설명: “The standard replace function for dataframes and series only replaces strings with strings. However, if .astype(float) is added, the following statement replaces every ‘?’ with ‘999999’. Then, it makes the result into a float. Later calculations require floats.”
- 빠진 출력 코드를 직접 지시하는 문장: “To ensure that the replacement worked, print the first 35 values of the dataframe with the statement,”
- 빠진 출력에 직접 기대는 결과 문장: “The output should show one 999999.0.”
- X 슬라이싱 코드를 예고하지만 그 코드가 없는 두 문장: “Now, go to a new cell in Jupyter Lab. Important numeric features are in columns 1-5. Column 6 is excluded in following statement, which defines X as columns 1 through 5 of the dataframe.” / “The command selects all of the rows of columns 1 through 5.”
- 위의 빠진 코드 조각을 가리키는 문장: “Again you want all of the rows, so you have the colon first.”
