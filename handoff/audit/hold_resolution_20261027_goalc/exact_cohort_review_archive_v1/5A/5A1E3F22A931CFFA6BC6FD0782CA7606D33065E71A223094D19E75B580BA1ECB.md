# 138235 RAS 병기 슬롯과 빈 각주 표제

검토 범위: 지정된 원문·후보 전체와 2개 연속 패킷, 전체 diff와 논리 END/실제 EOF.

후보의 `여러 RAS(, ) 기능`에는 값 없는 병기 슬롯만 남아 있었다. 본문에서는 `(, )` 포장을 제거해 실제로 명명된 `RAS 기능`을 보존했다. RAS의 확장명이나 빠진 값을 추정하지 않았다. 내용이 없는 `각주` 표제는 분리하고 실제 `같이 보기` 항목과 말미 분류는 유지했다. 제목·점대점·차동 신호·순환 중복 검사에서 후보가 이미 제거한 빈 괄호도 복원하거나 값을 보충하지 않았다. 수치·속도·오류 조건과 설명은 변경하지 않았다.
