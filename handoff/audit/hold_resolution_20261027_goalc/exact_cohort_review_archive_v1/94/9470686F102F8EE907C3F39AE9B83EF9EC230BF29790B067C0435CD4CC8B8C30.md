# 1316258 보류 원형

## 비어 있는 WSE 부분 목록 예고

```text
There are three parts of the WSE including:
Three of these areas will be discussed at some length in the article.
```

여기에 직접 대응하는 세 항목 목록이 없다. 독립적으로 명시된 UDDI/WSIL의 중요도 설명은 본문에 보존했다.

## 그림 위치에 직접 의존하는 Java Servlet 문장과 캡션

```text
The newly formed Java Servlet typically looks like what might be found in Figure 4.
Figure 4 Java Servlet
```

그림 위치와 캡션만 분리했다. JSP가 Java Servlet로 컴파일되는 과정과 디버깅 설명은 본문에 그대로 남겼다.

## 그림 직접 포인터와 불완전한 폴더 목록 도입

```text
Looking at the figure below we can see this is contained in the wsexplorer folder.
Looking at Figure 1 we can see the JSP code it is all contained under the wsexplorer directory.
Here are the ten folders and a breif description of the types of function contained within.
```

원문에 있는 `wsexplorer.jsp`와 `wsexplorer` 경로 관계는 새 경로를 만들지 않고 본문에 남겼다. Figure 1 포인터와 폴더 목록 예고는 분리했으며 실제로 기재된 Action/CSS/Favorites/Images/Scripts/UDDI/WSDL/WSIL 명칭과 설명은 보존했다. 누락된 폴더명을 추정하지 않았다.

## 없는 imports 목록 예고

```text
So This incorporates two sets of code that the WSE using all the time here are the imports to look out for.
```

실제 imports 목록이 없는 이 직접 예고만 분리했다. 바로 앞에 실제로 기재된 WSDL4J API와 eclipse XSD Model API 설명은 본문에 유지했다.
