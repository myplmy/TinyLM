## 경계

- abs 예제 한 줄은 `if/else`, 주석, return 경계와 test 링크가 합쳐져 있어 코드/실행 흐름을 추정하지 않고 원형 보류한다. 함수 설명·입력 x와 절대값 조건을 보존했다.
- `It should look like`와 `when we reach this line`은 그 자리에 올 코드줄을 직접 지시하지만 해당 줄이 소실돼 포인터/조건절만 보류했다. `return «value»`, return 값, 첫 실행 return의 설명은 남겼다.
- square 예제 코드 자체가 빠져 있는 소개문과 `Here are the steps...`부터 단계별 빈 식/직접 출력 조각은 원형 보류했다. 설명에 채워진 square 이름, x, return x*x, 10/100, 2/4/16, 호출 순서는 sidecar에 원형 그대로 남겼고 새 계산이나 출력은 만들지 않았다. 일반 frame 설명은 숫자/호출값이 있는 손상 코드 결과가 아니라 독립 설명으로 본문에 유지했다.
- Common Mistakes의 `forget the`, `You may also intentionally omit a`, `resulting in an` 조각과 Try it Yourself에서 대상 없이 남은 `There's no need to use`/2-line solution pointer는 원형 보류했다. None/return 설명, 인수 개수/정의되지 않은 함수 오류는 완결되어 본문에 남겼다.
- f() 예제의 flattened `def`/body/call 구간과 바로 이어진 `fis defined`/미완 print 결과는 분리했다. 정의와 실행의 일반 차이는 보존했다.
- 사각형 둘레 문제의 채워진 과제/정의는 남겼고 빠진 formula pointer와 우측 그림 지시만 분리했다.
- nested-function 예제 도입문은 빠진 프로그램을 직접 예고해 보류했다. 문자열×정수 개념 문장은 보존했다. vertical-gray-line 안내는 누락된 interactive UI를 가리키므로 분리했다. `Step 8 of 30`, `outer`/`inner` 프레임과 호출 순서는 그 소실된 예제/시각화의 직접 실행 결과이므로 본문에 두지 않고 아래 원형 발췌와 함께 보류했다.
