# 생년 complete-reader의 내부 조각 헤더 혼동

L이 TASK251의962627·96436에서 piece2/2·characters2000–4000을 보고 첫 조각이 누락됐다고 보고했다. 총괄 root probe와 고정 코드 확인 결과, read_context_latin_birth_root11_packet_v1.py는 내부 모든 조각을 합쳐 실제 전체 패킷4000자를 출력하며 packet SHA도 전체와 맞는다. 헤더만 마지막 내부 조각의 piece/characters 값을 복사한다. 예컨대962627 packet1은 실제 original BEGIN에서 시작하고 후보 중간에서 끝난다. 다음 packet2로 이어지며 원문서 전체가 packet1에 들어 있는 계약이 아니다.

| 대응 | 이점 | 비용·한계 |
|---|---|---|
| 기존 불변 도구를 유지하고 전체 패킷/내부 조각 의미를 명시 | 기존 전달 시각·설정 핀·완료 자료를 보존하고 현재 두 미완 원문만 재개 | 혼동되는 원래 헤더는 과거 계약의 한계로 남음 |
| 새 reader/config/journal 버전을 만들어 헤더 정정 | 새 출력 메타데이터를 곧바로 명확히 할 수 있음 | 남은 짧은 생년 단계에 다중 설정의 전달 검증을 추가해야 함 |
| 원본 packet을 직접 cat하도록 권한 확대 | 호출이 간단함 | 고정 역할·ID·SHA·전달 선결 경계를 우회할 수 있음 |

첫 안으로 남은 생년 단계를 계속한다. field의 조각 호출은 별도 계약으로 이미 명시돼 있다. 기존 완료 자료 재독·과거 전달 기록 소급·원형 변경0이며 root probe는 review_inputs로 세지 않는다. 헤더 혼동을 이해·실제 판독 증거로 삼지 않는다. actual packet 전체 SHA/문자 수·BEGIN/END와 최종 source_packet_sequence_complete를 확인한다.

별도1895 건은 packet3의끝`-각`과packet4의첫`주`를 합치면 실제`-각주` 삭제다. 원형2810자/SHA6434BC0EBA3DBF5C77198BC5B29519A7EF0A4D4217A2CA75AFAC730627DDF502, 후보2807자/SHA78B134B95E23EBD04FE99BB450E5B17A01A64CDAC7364B3F6D0813AA5DD0AEE0이며 C초기사본은 후보와 동일하다. 후보에 주가 남았다는 요약은 정정했고 명명된 홈페이지를 보존한 후보 수용으로 연결한다.

영향축: CPU 고정 도구 검산만 수행하고 GPU·모델·학습0, 원형·캐시·도구의 과거 버전 변경0, 보호ID와 원형SHA의 사전 보호 유지, 타세션 접근0이다. 전체 의미통과·추가300M승인0이다.
