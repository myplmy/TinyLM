# expanded_train:105924 — 빈 발화 포인터와 서지 슬롯

TASK219 original·candidate·full_diff packet 1–4를 END까지 판독했다. 발화 내용이 뒤따르지 않는 원문 도입만 원형으로 기록한다. 연설을 복원하거나 내용을 만들지 않는다.

```text
나폴레옹은 병사들에게 다음과 같이 말하였다,
```

후보는 이 직접 포인터를 분리하면서 전투의 날짜·부대·경과 등 나머지 채워진 서술을 유지했다. 참조문헌의 빈 페이지 슬롯 `[] .` 및 짝없는 마침표도 후보에서 정리했으며 페이지 번호·서지값은 보충하지 않았다.
