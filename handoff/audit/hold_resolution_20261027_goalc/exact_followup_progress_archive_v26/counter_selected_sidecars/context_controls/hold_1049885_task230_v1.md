# expanded_train:1049885 보류·분리 기록

- 작업: TASK230, 원문·선택본문·전체 diff의 5개 packet을 확인했다.
- 누락된 최초 SQL 문장을 직접 가리키는 다음 원형 문구는 학습 본문에서 제외하고 여기 보존한다: `There is a SQL statement for this process.`, `Let’s see how vulnerable this code is.`, `The result of this SQL command is to retrieve a row of the specified name from users_table.`, `In the above command line if user enters a valid name then a record will pull up for that name.` 원문에는 이들이 지칭하는 최초 SQL 문장이 없다.
- 뒤에 실제 채워진 payload·SQL 예시와 그 인접 설명은 원저자의 예시로 유지했으며 실행하거나 사실 검증하지 않았다.
- 말미의 `Keep in touch for more discussion.`은 독자 유도 문구이므로 분리했다.
