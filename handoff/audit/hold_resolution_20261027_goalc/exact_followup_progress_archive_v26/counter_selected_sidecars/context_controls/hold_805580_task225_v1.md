## 보류한 원문 단위

```text
In the following example, the string is compressed word by word, and then decompressed by a single call to the decompress function:
# File: bz2-example-2.py import bz2 text = "the meaning of life" data = "" comp = bz2.BZ2Compressor() for word in text.split(): data += comp.compress(word + " ") data += comp.flush() print repr(bz2.decompress(data))
$ python bz2-example-2.py 'the meaning of life '
```

## 경계와 이유

`for word in text.split():` 뒤의 `data += comp.flush()`와 `print repr(...)`가 반복문 안인지 밖인지 평탄화된 원문만으로는 정할 수 없다. 해당 예제와 직접 출력, 그 예제를 특정하는 도입문을 한 단위로 보류했다. 들여쓰기나 반복 범위를 추정하지 않았다.

예제 1은 `# File:` 주석, import, 각 대입·호출문 경계가 명시된 순서로만 개행을 복구했다. 예제 3도 파일 표지, import, 대입문 경계만 개행으로 나눴고, `for line in file: print repr(line)`은 원문 그대로 한 줄에 보존했다. 예제 1·3의 코드 표기, Python 2 `print` 형식, 출력 문자열·바이트 이스케이프·숫자·파일명은 바꾸지 않았다. 코드는 실행하지 않았다.
