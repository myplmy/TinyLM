# expanded_train:224458 — 빠진 예제에 직접 의존하는 코드 지시

TASK218 original·candidate·full_diff packet 1–4를 END까지 판독했다. 다음의 구분자 없는 `crlf.py` 예제와 그 직접 도입은 명령 경계·실행 조건을 추정해야 하므로 원형 보류한다.

```text
Here, for instance is the key code from crlf.py (Windows to Unix conversion)
data = open(filename, "rb").read() newdata = data.replace("\r\n", "\n") if newdata != data: f = open(filename, "wb") f.write(newdata) f.close()
```

뒤의 “Windows-style newlines to Linux-style newlines”를 바꿀 때 실행한다고 지시한 flattened 코드도 함께 보류한다.

```text
So now when I want to convert a file from Windows-style newlines to Linux-style newlines, I do this:
filename = "NameOfFileToBeConverted" fileContents = open(filename,"r").read() f = open(filename,"w", newline="\n") f.write(fileContents) f.close()
```

`It is documented here.`라는 위치 포인터만 분리했다. 바로 뒤에 실제로 인용된 `newline` 설명, 입력/출력 조건과 값, 그리고 다른 완결된 일반 설명은 본문에 보존한다. 코드 경계·구문을 고치거나 실행하지 않았다.
