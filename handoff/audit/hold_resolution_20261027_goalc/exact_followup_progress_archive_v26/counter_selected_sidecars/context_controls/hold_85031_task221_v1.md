# 85031 원형 보류 근거

원문 말미의 다음 절은 주어가 `들은`으로 시작해 특정되지 않는다. 주어를 추측하거나 앞의 문장에 결합하지 않고 원형에만 보존한다.

```text
들은 강하게 상호연결되어 있어서 섭동 이론으로 전개하여 풀 수 없는 계(strongly correlated system)를 끈 이론의 AdS/CFT 대응성을 사용하여 계산할 수 있으리라 기대하고 있다.
```

정확 후보는 이 절과 빈 `각주` 표제를 제거하고 실제 분류 `초전도`, `신기술`을 보존한다. 새로 구성한 초안은 선택하지 않으며 해당 초안에 최종 줄바꿈 외 후보와의 다른 차이는 없다.
