# 852262 — TASK240 원형 보류 범위

원문에는 DOM event bubbling/capturing의 일반 설명과 네 단계에 실제로 붙은 BODY/table/TR/TD의 onclick 표기가 있다. 이는 본문에 유지했다. 별도의 실제 데모 UI/핸들러 구현은 제공되지 않으므로, 그 데모를 클릭하라는 지시와 배경색·alert·Reset 동작을 특정하는 문장만 원형 보류했다. 실행/시연을 하지 않았고 원저자의 관찰을 새로 검증하지 않았다.

## 보류한 데모 전용 지시·설명

- Demo: click any cell in the table and watch the click event bubbling!
- In this demo, onclick event handlers change the background color of their respective elements.
- Each event handler displays an alert message box telling you the level at which the click event is currently handled.
- The execution is paused until you dismiss the alert box.
- If you try to reset the demo by clicking the Reset button, the button's event handler function resetTable() works as expected (the background colors are reverted to white for the table and the entire page body). However, due to event bubbling, a higher-level event handler function is triggered too - which colorizes the entire page once again! To avoid unintended consequences like this, you can cancel event bubbling.

The title, general event propagation/bubbling/capturing description, actual handler markup, and named four-level event sequence remain in the body.
