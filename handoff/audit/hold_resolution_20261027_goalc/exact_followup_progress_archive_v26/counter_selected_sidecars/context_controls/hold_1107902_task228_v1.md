## 코드 경계

```text
Sub TestWhileWend() Range("A1").Select While ActiveCell > 5 ActiveCell.Font.Color = vbRed ActiveCell.Offset(1, 0).Select Wend End Sub
Sub NestedWhileWend() Dim r As Integer Dim c As Integer r = 1 c = 2 Cells(r, 1).Select While ActiveCell > 20 ActiveCell.Font.Color = vbRed While Cells(r, c) > 30 Cells(r, c).Font.Color = vbGreen c = c + 1 Wend c = 2 r = r + 1 Cells(r, 1).Select Wend End Sub
```

본문에는 두 코드 블록의 기존 토큰을 유지하고 `Sub`, 문장 경계가 명확한 호출/대입, `While`/`Wend`, `End Sub` 사이에 줄바꿈만 복구했다. 두 번째 블록의 들여쓰기는 중첩된 `While`/`Wend` 짝을 표시한다. 실행하거나 구문·동작을 검증한 것은 아니다.

## 직접 빠진 표/결과 지시

원문은 첫 블록에 대해 `If we were to run this loop starting in cell A1 on the data below, the loop would run until it gets to cell A5...`라고 이어지고, 두 번째에는 `Running this loop above on the data below will result in the following:`라고 예고한다. 필요한 worksheet 표와 결과가 원문에 없으므로, 선택본문이 이 직접 의존 설명/예고를 뺀 범위를 유지한다. 표·실행 결과를 만들지 않는다.
