# expanded_train:50956 보류 기록

- 작업: TASK230, 원문·선택본문·전체 diff의 4개 packet을 확인했다.
- 아래 원문은 예제 속 속성 이름/유형이 빠져 역할을 확정할 수 없어 후보에서 제거된 상태로 보존한다. 누락된 명칭을 서명에서 유추해 채우지 않는다.

```text
As an example, the following code declares a
int as its synthesized
attribute, while expecting a single
as its inherited attribute (see the section about the Spirit.Qi
Rule for more information):
```

- 뒤 예고의 원형은 `The example below declares a Spirit.Karma rule consuming a / while not expecting any additional inherited attributes.`이다. `consuming a` 뒤의 실제 대상을 알 수 없으므로 후보가 그 불완결 부분만 제외한 설명과 실제 서명은 그대로 둔다.
- `qi::rule<Iterator, int(double)> r;` 및 `karma::rule<OutputIterator, double()> r;`는 원문에 실제로 채워져 있어 보존했다. 코드를 실행하거나 정합성을 검증하지 않았다.
