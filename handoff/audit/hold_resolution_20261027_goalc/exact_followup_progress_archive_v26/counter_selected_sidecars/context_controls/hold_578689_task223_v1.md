# 578689 원형 보류 근거

원문 XSLT 템플릿은 전체 코드 구간이 한 줄로 평탄화되어 있고 `<xsl:text>`와 `</xsl:color>`가 서로 맞지 않는다. 코드 구조를 추정해 고치지 않고 원형을 그대로 보류한다.

```text
<xsl:template match="Content"> <div> <xsl:attribute name="style"> <xsl:text>color: </xsl:color> <xsl:choose> <xsl:when test="count(.|key('content', @ContentText)) = 1"> <xsl:text>red</xsl:text> </xsl:when> <xsl:otherwise>black</xsl:otherwise> </xsl:choose> </xsl:attribute> <xsl:value-of select="@ContentText" /> </div> </xsl:template>
```

앞 문장의 실제 key()/generate-id()/count() 표현과 red/black 조건을 설명하는 산문은 유지했다. 후보가 함께 삭제한 실제 author signature와 source links는 새 본문에 원문 그대로 복구했다. 분리한 판매/구독 홍보 문구는 아래에 보존한다.
