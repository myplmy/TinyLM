# 1332589 원형 보류 근거

후보에서 제외된 평탄화 예제는 구문 경계와 실행·출력의 대응이 확인되지 않으므로 원형 그대로 여기에 둔다. 아래는 고정 reader 원문 조각이며, 실행 가능한 코드로 복원한 것이 아니다.

```text
Pythonn strip() syntax
# to remove extra initial and ending spaces string.strip() # to remove extra initial and ending characters. string.strip(character)
string = " TechGeekBuzz " # without strip() method print(string) # with strip() method print(string.strip())
string = " Tech Geek Buzz " # without strip() method print(string) # with strip() method print(string.strip())
Tech Geek Buzz Tech Geek Buzz
string = "heading Tech Geek Buzz heading" # it will remove the heading from the end and beginning print(string.strip("heading"))
Tech Geek Buzz
```

```text

```
