# expanded_train:874017 — TASK229 원형 메모

후보는 `Given something like:`와 완결된 `if (x != 0) launch_nuclear_missiles();` 예시를 유지하고, 그 뒤의 다음 연결 단위를 분리했다.

```text
... and then, possibly in another function
some people would view a compiler that replaces the "if" with an unconditional call to
launch_nuclear_missiles() as superior to one that only calls
x is non-zero, but such behavior would only be appropriate when processing tasks that will never involve untrustworthy input.
```

`only calls` 뒤의 대상/조건 연결이 원문에서 완결되지 않았고, `x is non-zero`의 역할을 새 접속어나 호출로 복원하지 않았다. `such behavior`가 가리키는 대상을 더 구체화하지 않는다. 후보의 뒤 독립 조건문과 주변 설명은 유지하며, 예시를 실행하거나 컴파일하지 않았다.
