# expanded_train:23628 보류 기록

- 작업: TASK231, 원문·선택본문·전체 diff의 4개 packet을 확인했다.
- 원문에 없는 그림/차트 위치를 직접 가리키는 문구는 해당 포인터만 본문에서 분리하고 원형을 보존한다.

```text
위 사진에서 보이는 붉은 라인은 뉴올리언스의 제방의 위치를 나타내며,
바닷물이(1915, 1947 좌측 그림)
(1965, 2005 우측 그림)?!
오른쪽 차트에서 보는 바와 같이,
```

- 후보는 `위 사진`/`오른쪽 차트` 포인터와 그림 방향 꼬리를 정리했다. `바닷물이(1915, 1947 좌측 그림)`에서는 날짜를 남기고 `좌측 그림` 위치 포인터만 제거했다. 마지막 `(1965, 2005)?!`의 숫자는 바로 앞 완결 서술에 이미 1965년 벳시와 2005년 카트리나가 명시돼 있으므로, 그림 지시를 포함한 잔여 조각만 추가 분리했다. 새 날짜 관계를 만들지 않는다.
- 실제 행정구역·수치·운하·연도·저자 귀속이 채워진 설명은 보존했다. 빈 `각주` 표제는 후보에서 제거됐다.
