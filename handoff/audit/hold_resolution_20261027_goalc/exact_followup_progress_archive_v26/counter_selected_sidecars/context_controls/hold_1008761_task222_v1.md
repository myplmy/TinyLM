# 1008761 원형 보류 근거

다음 Python 조각은 문장 경계와 반복문 블록 구조가 평탄화돼 있다. 이를 실행 가능한 코드로 다시 만들지 않고 해당 조각과 직접 실행 지시를 원형으로 보류한다.

```text
import serial ser = serial.Serial('/dev/ttyAMA0', 115200) while True: print ser.readline()
Save it and run it.
```

본문에는 Arduberry/Arduino IDE 설정, minicom 명령과 설정 절차, pyserial 설치, 라이브러리 설치 경로와 절차 등 코드 조각과 독립적으로 완결된 내용을 유지한다. 마지막 포럼 CTA는 본문에서 분리했다. 명령/코드 실행은 하지 않았다.
