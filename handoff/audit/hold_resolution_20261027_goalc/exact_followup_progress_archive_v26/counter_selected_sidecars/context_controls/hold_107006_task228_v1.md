# expanded_train:107006 — TASK228 원형 메모

원문은 제목에 `4•12 사건( - 事件, )`를, 본문에는 `정화(이른바 )`, `4•12 반혁명정변()`, `4•12 참안()`을 남겼다. `- 事件`의 의미나 누락된 앞부분은 확정할 수 없으므로 원문 표기를 그대로 보존하고 새 글자·번역을 채우지 않는다. 새 본문은 첫 병기에서 빈 쉼표 슬롯만 정리해 `4•12 사건(- 事件)`로 남기고, 빈 alias 포장만 정리했다. `이른바` 뒤의 내용 없는 표현은 원형 그대로 이 sidecar에 두며 새 명칭을 보충하지 않는다.
