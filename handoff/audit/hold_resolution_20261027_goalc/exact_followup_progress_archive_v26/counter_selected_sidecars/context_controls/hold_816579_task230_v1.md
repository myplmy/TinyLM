# expanded_train:816579 보류·분리 기록

- 작업: TASK230, 원문·선택본문·전체 diff의 4개 packet을 확인했다.
- 후보에서 이미 빠진 원형 문구 `A general description is here.`는 실제 설명 대상이 연결되어 있지 않은 위치 지시이므로 복구하지 않는다.
- 새 본문에서 `This blog is updated daily..` 한 줄을 분리했다. 이는 R의 긴 벡터 설명이 아니라 페이지 갱신 안내다.
- 긴 벡터 지원 형식, 제한, 함수명, 수치, 조건은 후보의 원문 순서대로 보존했다. 기능이나 버전 사실을 외부 검증하지 않았다.
- 원문 문구: `This blog is updated daily..` / `A general description is here.`
