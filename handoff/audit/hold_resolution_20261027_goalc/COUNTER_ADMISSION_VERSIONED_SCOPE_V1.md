# 고정 대조 묶음의 반복 채택 계약

각 배치는 명시 설정의 이전 선택 SHA, 새 고정 snapshot SHA, 원문/후보 manifest와 metadata guard V3에 연결한다. 이전 선택 행은 보존하고, 서로 다른 작성 역할의 원문·이전 본문·전체 차이 대조를 완료한 새 행만 검토한다. 수집 오류나 미확정 출력이 있으면 해당 ID를 별도 해결하며 검토표의 약어·파일명 정정은 새 1차 판독으로 가산하지 않는다.

숫자·코드·Unicode·문체·순서·검수메모 검사는 기존 함수를 재사용한다. 개별 신호는 정확 SHA 쌍과 독립 문맥 근거가 있을 때만 닫고 전역 검사를 완화하지 않는다. 별도 총괄 독립 문맥 복구가 제공된 경우에만 그 입력·리뷰·본문 SHA와 근거를 추가하며 이를 두 Luna 대조로 표현하지 않는다.

매번 코드를 복제하거나 검사 신호만으로 자동 채택하는 방법 대신, 해시 고정 생산기와 작은 설정을 재사용한다. 선택은 실제 검토된 본문 SHA에만 적용한다. 원래 대상·조건·수량·귀속을 새로 생성하지 않는다. 새 선택 파일은 생성 전에 20,000,000바이트 미만인지 확인하며 공백 없는 동등 JSON으로도 넘으면 별도 분할 계약을 검증하기 전 중단한다.

전체 원장의 모든 canonical 행을 별도 검산해 승인된 변경과 나머지 불변을 확인한다. ROOT/원장 채택, 실제 캐시 생성, 독립 consumer 검증은 각기 다른 단계다. 새 캐시 검증 전에는 공식 검증 캐시 수치를 바꾸지 않는다. 같은 고유 문서의 대조는 신규 1차 검토량에 더하지 않는다.

이 계약은 GPU·모델·학습·설치·다운로드·원형/기존 캐시 덮기·삭제·타 세션 자료·push/PR을 허용하지 않는다. 전량 사실검증·모델 품질·목표 완료나 학습 재개 승인으로 표현하지 않는다.
