# 필드·제목 외 나머지 유형의 전량 원문 준비

전체 잔여 정제의 승인 범위다. 전체 미처리70,192고유는 현재 literal1,792+필드·제목18,237+그 외50,162+보호metadata1로 설명된다. 이 단계는 그 외50,162고유/77,879위치 전량의 복원과 기존 동결 후보 재생성만 수행한다. 내용 판독·정제·캐시 채택이 아니다.

| 안 | 영향·비용 | 판단 |
|---|---|---|
| 대표 유형만 추가 준비 | 빠르나 남은 전체를 설명하지 못함 | 미적용 |
| 새 원문 복원기/정책 구현 | 중복 코드·EOS·출처 회귀 부담 | 미적용 |

새 audit 어댑터/실행기와 새 remaining_other_types_full_sources_v1/native_proofs_v1만 쓰며, 기존 census/field/캐시·생산 정책 코드는 읽기 전용으로 재사용한다. source ID와 SHA로 보호7부모/동일SHA를 실제 본문 열기 전에 차단한다. literal과 field의 기존 소유를 재배정하지 않는다. 모든 원문/후보는 각20,000,000바이트 미만이며 경계·SHA·EOS·UTF8·정책 재생성을 대조한다. actual prose authoring은 Luna가 담당한다.

코드 영향은 새 파생 준비기뿐이고 토크나이저/캐시/훈련 기본값은 불변이다. 데이터 영향은 새 로컬 원문/기존 후보 증거다. 기존 pin/순서/크기/재생성 검사를 재사용하며 비교 분모를 바꾸지 않는다. 정본은 현재 WIP에 RUN/실제 종료만 기록하고 전체 정제 완료로 올리지 않는다. 후속 실제 판독/의미 검토와 새 캐시·문서 연쇄는 계속 필요하다.

CPU 한 프로세스와 제한 스레드로 실행한다. 이전18,237개 준비는510.4초였지만 긴 문서 구성에 따라 새 시간은 달라진다. 이 근거를 시간 보장으로 쓰지 않는다. 디스크 여유는 준비 시점462GiB였다. 설치/다운로드/외부서비스·GPU·모델·학습·추가300M·TinyDataset·타세션 전용자료·원형 덮기/삭제·push/PR은 제외한다.
