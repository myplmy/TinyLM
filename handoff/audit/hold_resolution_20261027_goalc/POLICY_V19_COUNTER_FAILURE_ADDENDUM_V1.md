# v18 독립 반례 회수와 v19 보호 확장

현재 goal 및 POLICY_V18_CONTEXT_CONTRACT_V1의 권한·영향·보호 범위 안에서 새 버전만 추가한다. 이전37생산소스와 v18의 실제 시험/탐색/반례 소스는 보존한다.

- v18 정책248회귀와 fresh33회귀는 실제0이다. 목적 탐색57789는 실제0/19.622초로714원문(P619/E81/K14)을 처리했고 terminal 코드/Unicode/스타일/문자순서 flag는0이었다.
- 독립 반례 준비10432도 실제0이며 새 종결4건은 기존 저자 역할과 다른 controls1/latin3에 배정됐다. 세부 원문·후보·생산43파일 이전의40파일 SHA는 counter manifest에 있다.
- 682279와8183은 실제 전문 대조 ACCEPT였다.
- 158959의 참고자료 삭제 의견은 총괄이 말미 실제 값을 확인한 뒤 철회했다. 원문에 있는 ‘참고 자료–낭만주의 음악’을 URL 부재만으로 빈 절로 확정하지 않으며 원래 candidate를 보존한다. 바뀐 저자 의견과 구버전 TXT는 함께 보존한다.
- 411438은 첫 명칭 정리가 올바르더라도, 성분/텐서 다음의 식이 단독 마침표만 남고 ‘여기서’ 아래 변수명도 빠진 내용을 기존 탐지기가 놓쳤다. 독립 저자는 완결 사차원 벡터 정의와 같이보기를 회수하고 직접 의존부만 sidecar로 분리했다.

v18은 전량 실행하지 않는다. v19는 실제 관측한 ‘형식 정의 예고→단독 마침표’와 ‘여기서→변수 없이 주격조사/물리량 설명’ 두 유형을 보호 검사에 추가한다. 이 검사는 수식 생성이나 자동 본문 삭제를 하지 않으며, 과거 종결에도 fresh로 적용한다. 코드/표기 예제는 실제 보호 구간을 유지하고 새 반례로 시험한다.

다음 전량 기준은 실제 검증된 v17이다. v18의 테스트·목적 탐색·독립 의견은 전량 v18 실행이나 캐시 채택으로 표시하지 않는다. 미처리 PENDING을 일괄 제외하거나 최종 zeroHOLD 계약을 완화하지 않는다.
