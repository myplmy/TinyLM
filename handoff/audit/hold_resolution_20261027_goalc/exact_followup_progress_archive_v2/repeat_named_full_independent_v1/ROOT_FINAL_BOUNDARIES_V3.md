# 의미 보존 경계의 추가 중재

현재 다섯 역할의 지정 원문 판독에만 적용한다. 기존 ROOT_MEDIATION_V3와 ROOT_MEANING_PRESERVATION_V2의 보존 경계를 구체화하며 권한을 확대하지 않는다.

명명된 같은 표 cell의 `A — 약 Nkm`는 원래 이름·값·단위를 함께 유지한다. 별도 빈 대상 행의 거리값은 원형 sidecar에 두며 행 위치는 유지한다. `A — 부터 B — 부터`의 B를 A의 출발값으로 해석하지 않는다. 누락된 시작점 포장만 분리하고 A/B 이름·반복·순서를 보존한다. 실제 지역–섬 구분자나 명명된 두 항목 사이의 대시는 남긴다.

남극 영역명은 국가 주장자 이름과 다르다. 빠진 국가를 영역명에서 추측하거나 영역 자체가 영유권을 주장한다고 쓰지 않는다. 원래 cell의 실제 영역명·섬·본토·방향은 원순서로 보존하고 미상 주체를 필요로 하는 관계절 원형만 별도 보류한다. 새로운 영유권 라벨을 만들어 주체가 확인된 것처럼 보이게 하지 않는다.

표는 실제 대상과 열 축을 보존한다. 좌표가 비었다고 다른 유효한 열의 정보와 구조를 평문으로 지우지 않는다. 반대로 국가/대상과 메달 열 의미가 모두 사라진 표는 숫자만으로 복원할 수 없어 전체 원형을 보류한다. 금·은·동·총계나 국가를 숫자 순서에서 추측하지 않는다.

실제 다른 표제 아래의 byline, 말미의 제목+byline, 실제 댓글 표제와 본문 목차는 보존한다. 명백한 UI와 같은 기능의 bare 중복만 원형과 함께 분리한다. 표제·본문·파트너·저자 약력의 서로 다른 기능을 한 중복으로 합치지 않는다.

의도된 빈칸 문제와 실제 소실 수식은 구분한다. 학생에게 유도·조사·풀이를 요구한다는 사실 자체는 결손이 아니다. 실제 값·단위·조건·정의가 완결된 행은 보존한다. 없는 도표·식에 직접 의존하는 주장과 실제 빠진 기호만 원형 보류하며 새 변수·수식·반응식을 만들지 않는다.

완료 보고와 실제 저장은 다르다. 원래 배정 TASK의 모든 ID에 새 리뷰 행이 있는지 확인한다. 미저장·NEEDS_ROOT는 완료로 세지 않는다. sidecar만 추가하고 본문이 exact candidate와 같으면 ACCEPT_CANDIDATE로 그 경로를 선택한다. 리뷰는 review_NNN_vN.md처럼 단일 버전 접미사를 쓰며 이전 파일을 덮지 않는다.
