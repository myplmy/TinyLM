# 747745 원문 인용의 직접 핀 확인

보조 역할의 보고에서 노스웨스트 준주의 존재 여부가 두 차례 바뀌어 총괄이 지정 manifest의 정확 입력 파일 두 개를 직접 확인했다. 다른 경로를 추측하거나 다른 원문에서 이름을 가져오지 않았다. 전체 파일SHA 대조와 해당 셀의 직접 판독을 수행한 것이며 이 문서가 총괄의 전체1561자 의미 판독을 뜻하지는 않는다.

original/candidate 둘 다1561자이며 manifest 핀과 실제 SHA는 `FAEC5097234211BAA02E82A5EC34B0414681A3692388206FCC2217FAFE93BB17`로 일치한다. 두 정확 파일의47행은 다음과 같다. 공백에는 U+00A0이 포함된다.

`| 누나부트 준주 노스웨스트 준주 —  서스캐처원주 — 부터`

노스웨스트 준주가 없다는 중간 보고는 이 입력에 맞지 않는다. 그 보고와 앞뒤 초안은 삭제하지 않고 비선택/정정 이력으로 남긴다. 보존할 원형은 위 실제 문자열이다.

중재V3대로 이 셀의 실제 세 지역 이름과 순서를 본문에 복구하고, 대상이 없는 구간 대시/'부터' 조각만 원형 sidecar에 보류한다. 다른 섬/주 이름을 추가하지 않는다. 지정 원문/후보·전체 diff·마지막 EOF를 다시 확인한 뒤 새 전체 TXT/전체5행 교정 리뷰로 정확 선택을 선언한다. 모든 이전 TXT/MD는 보존하며 버전 숫자만으로 최종 후보를 추측하지 않는다.
