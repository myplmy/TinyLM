# 총괄 중재 V3: 알려진 다른 필드의 상충과 판독 경계

V2의 의미 보존·명시 이설 보존 규칙은 유지한다. 출생 묶음이라는 이름 때문에 이미 발견한 사망일/생존 분류/인명 소실을 방치하지 않는다. 아래 경계와 같은 사례는 새 질문 없이 적용할 수 있으며, 다른 문맥이면 정확 구절과 함께 NEEDS_ROOT로 남긴다.

- 같은 인물의 무조건적 사망 날짜가 서로 다르면 둘 중 선택하지 않는다. 원문에서 공통인 연·월은 유지할 수 있고, 서로 다른 일자 주장만 원형 sidecar로 분리한다. 월일까지 다르면 날짜 주장 전체를 분리한다. 같은 월일에서 연도만 다르면 상충 연도만 분리한다. 다른 사건/인물/인용의 같은 숫자는 삭제하지 않는다. 명시 달력 차이·자료별 이설은 V2대로 보존하며 새 달력 환산은 하지 않는다.
- 실제 사망일·사망 서술이 있는 인물에게 고립된 `살아있는 사람` 분류가 남은 경우, 그 분류를 sidecar로 분리하고 명시 사망 사실·경력을 보존한다. 현재의 외부 생존 상태를 확인했다는 뜻은 아니다. 당시 발언·인용의 생존 묘사는 이 규칙으로 지우지 않는다.
- 생년 두 주장과 사망년 두 주장이 함께 상충하면 양쪽 필드를 각각 위 경계로 처리한다. 독립 원문 나이·경력·사건은 역산하지 않고 보존한다.
- 인물 이름 자체가 소실되고 남은 소개/빈 클럽 경력/일반 분류로 대상을 알 수 없는 경우에는 연도만 제거한 익명 프로필을 채택하지 않는다. NEEDS_ROOT와 대상 소실 사유를 기록한다. 새 이름이나 팀 귀속을 만들지 않는다.
- `20세기 사람`과 `21세기 사람`은 생애가 두 세기에 걸칠 수 있으므로 그 두 분류만으로 상충이라고 보류하지 않는다.
- 실제 이름·날짜 값이 모두 있고 닫는 괄호 한 자만 빠진 경우, 그 괄호를 추가하는 구조 복구는 가능하다. 새 사실을 채우지 않고 새 TXT/사유에 한 자 변경을 기록한다.
- 삭제한 필드의 자리에 `보류`, `충돌`, `총괄 확인`, 검수 지시 같은 메모를 학습 본문에 넣지 않는다. 원형·이유·변경 위치는 별도 MD에 둔다. 남은 본문이 독립적으로 이해되지 않으면 자동 채택하지 않는다.
- 패킷은 6,000자 연속 조각이므로 중간 파일 EOF의 문장 중간 절단이나 논리 END 부재는 정상이다. TASK에 명시된 모든 조각을 순서대로 읽고 마지막 논리 END까지 확인한다. 실제 도구의 출력 잘림 경고와 구분한다. 지정 목록이 manifest와 다르면 추측 경로를 열지 말고 총괄에 정확 TASK를 알린다.

수정은 자기 지정 폴더의 새 전체 TXT/원형 sidecar/정정 review만 생성한다. 이전 버전은 보존하고 출력 칸에는 정확 TXT 하나만 적는다. 이 지침은 사실 전량 검증이나 캐시 채택 승인이 아니다.
