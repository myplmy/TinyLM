# 잔여 정제 작업 순서와 소요 시간

기존 판정과 정제문을 같은 원문 ID·SHA로 먼저 연결한다. 같은 원문의 여러 원위치는 한 건으로 배정한다. 이전 판독으로 값 보존과 최종 본문이 확정된 묶음은 기존 검사로 회수하고, 원문에 필요한 값이 없다고 확인된 건은 근거와 함께 HOLD로 보존한다. 원문 결손을 알 수 없는 문서는 그 사유를 확정할 때까지 미처리로 집계한다.

직접 편집이 필요한 건에만 다섯 Luna 6 max를 배정한다. 배정표에 파일 한 쌍과 이전 판독, 기존 차이 계측의 문자 범위를 넣는다. 담당자는 필요한 부분의 앞뒤 문맥을 확인하고 실제 수정문을 저장한다. 총괄은 확정된 검토문을 한 번 회수하고 기존 검사를 묶음으로 실행한다. 같은 원문과 수정문 쌍의 기계 검사를 반복하지 않는다. 최종 캐시 생성과 소비 검증은 채택분을 모아 수행한다.

| 작업 방식 | 범위와 시간 |
|---|---|
| 전량 직접 판독 | 미처리 고유 원문 60,319개를 건당 1분, 다섯 역할 병렬로 처리하면 연속 8일 9시간이 걸린다. |
| 기존 규칙 재사용 | 과거 66,411개 조회가 38.43초였고 후보가 478개였다. 이미 검증된 유형을 빠르게 찾을 수 있으며 나머지는 원문 근거가 필요하다. |
| 기존 결과 회수와 실제 편집 결합 | 권장한다. 구체 누락과 원문 위치를 먼저 제공한다. J 역할의 셋째 배정 첫 10개는 6분 50초에 수정 및 기록을 마쳤다. 미처리 전체를 대표하는 표본은 확보 전이다. |

이 기록 시점의 처리 대상은 미처리 60,319개와 B안 미채택 3,695개 원문이다. 직접 작업이 필요한 비율이 10%, 20%, 30%이면 다섯 역할·건당 1분 기준 약 21시간 20분, 42시간 41분, 64시간이다. 이후 캐시 생성과 소비 검증은 직전 실측이 56분 42초다. 원장 및 마지막 문서 정리 시간은 별도다. 하루 안에 끝내려면 다른 비용을 빼기 전에도 직접 판단이 필요한 원문이 6,900개보다 적어야 한다. 그 비율은 아직 측정되지 않았다.

현재 B안 배정부터 원문 문자 범위를 붙인 방식을 적용했다. 150개를 배정했고 J·L부터 실제 편집을 시작했다. 미처리 자료의 완료 시각을 정하려면 B안 우선순위를 유지한 뒤 미처리 유형별 150개에서 기존 근거 회수, 직접 수정, 근거 있는 HOLD, 검증 실패의 수량과 시간을 기록한다. 건당 1분이면 다섯 역할의 직접 판독 몫은 30분이며 준비·회수는 별도다. 표본 내 작업도 최종 집계에 포함한다.

미처리 원문 60,319개의 로스터 사유를 8.98초에 전량 대조했다. 단일 사유 집계는 본문 반복 18,778개, 부록과 분류 경계 10,503개, 빈 필드나 제목 9,254개, 깨진 표와 위키 구문 4,936개다. 네 유형의 합은 43,471개로 미처리 고유 원문의 72.1%다. 유형별 실측 표본의 배정과 전체 추산에는 이 건수 분포를 사용한다. 분류 사유를 정제 완료나 자동 처리 가능 건수로 계산하지 않는다. 이 실행에서 원문과 수정문 파일을 열거나 복사한 건은 없다.
