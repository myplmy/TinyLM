# 실제 저장 본문 선택 계약 v7

선택8의3084개 정확 원문/저장본문 판단과18개 명시 중재는 당시 입력·review·본문 핀을 먼저 검증한 뒤 이어받는다. 이후 배정한 v23 목적9·전수 구조33·추가 실제본문2의 새 저장행은 새로운 증거다. 이전18개 중재를 이 새 검토 집합에 자동 전파하지 않는다.

대안은 선택8을 유지해 새 검토를 누락하기, 검증된 이전 선택과 모든 새 배정을 정확히 합쳐 충돌만 다시 중재하기, 모든 과거 제안을 새롭게 순위로 다시 고르기다. 두 번째를 선택한다. 새 배정이 없고 이전 핀이 그대로인 원문은 이미 검토한 정확 본문을 보존한다. 새 검토가 같은 본문을 지지하면 추가 근거를 연결한다. 새 본문·제외·미결이 다르면 이전 선택과 정확 새 검토 집합을 함께 표시하고 총괄 중재 전에는 미결이다.

새 원문도 실제 저장 본문/제외 사유와 정확 source/review/TASK가 있어야 한다. 배정행이 없거나 기계 반려·NEEDS_ROOT이면 과거 또는 다른 낮은 후보로 우회하지 않는다. source SHA가 다르면 결합하지 않는다. 새 검토의 미저장행은 계획에 남긴다.

이 선택은 source linked 저장본문의 의도이며 캐시 채택·전량 사실검증·모델 품질·학습 승인이 아니다. 제한된 parent는 승인된 안전뷰 이외 읽지 않는다. 모든 실제 본문·숫자·링크·코드·Unicode·스타일·문맥/메모 검사를 다음 단계에서 다시 수행한다. 기존 실패와 다른 대안은 보존하고 PENDING 일괄 제외나 zeroH 계약 완화는 하지 않는다.
