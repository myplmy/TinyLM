# 85646 전량 대조: v1은 아직 채택하지 않는다

총괄은 지정 원형 52,391자와 선택 초안 v1 32,157자 및 sidecar를 실제로 읽었다. 원형 ID와 원형 SHA의 보호 계약을 먼저 확인했고 원문·초안 SHA를 검산했다. 원문은 덮거나 삭제하지 않았다. 이 판정은 기술 내용의 외부 사실 검증이나 코드 실행 결과가 아니다.

원문 판독은 `408eaf`의 0–8,000, `9b0ada`의 8,000–24,000, `cc43ed`의 24,000–42,000, `f6dec4`의 42,000–52,391자 출력으로 이어진다. 초안은 `8d6d17`의 0–8,000과 `408eaf`의 8,000–32,157자/EOF, sidecar 전문은 `8d6d17`에서 확인했다. 83431의 별도 잘린 출력과 이 문서의 전량 출력은 구분한다.

다음 범위는 v2 작성 후 다시 대조한다.

1. 결손 수식을 새 해설이나 임의 동의어 요약으로 바꾸지 않는다. 원문의 완결 문장은 유지하고 필요한 삭제와 문장 경계만 정리한다. 새 `DTFT describes a window’s frequency-domain behavior` 문장은 원문을 그대로 보존한 문장이 아니다.
2. Hann 창의 주파수 영역 구현 3단계는 길이/DFT 차수와 smoother의 실제 계수가 빠졌다. 그 값을 지운 채 완결 알고리즘처럼 남기지 않고 단계와 직접 도입을 한 묶음으로 보류한다. 독립적인 family/5-point 관계는 별도 판단한다.
3. MLT의 사라진 수식 뒤 `has smallest moment of inertia over all windows` 결론을 앞의 transform 문구에 새로 결합하지 않는다. 정의 대상과 최적성의 직접 단위를 보류한다. 완결된 코딩·분석/합성 조건은 유지한다.
4. Power-of-cosine의 빠진 식과 nonnegative-integer 조건을 제거한 뒤 BH 일반화 문장으로 바꾸지 않는다. 직접 일반화는 보류하며 실제 명명된 항목은 보존한다.
5. DPSS의 이름 없는 두 기호 정의에 M/alpha를 새로 배정하지 않는다. 코드에 두 이름이 있다는 사실만으로 소실된 두 역할을 확정하지 않는다. 기존에 허용한 명명된 목적/Toeplitz 고유벡터의 질적 관계와 실제 호출·출력은 유지한다.
6. `chebwin` 설명의 실제 `ripple dB below that of the main-lobe peak`에는 단위와 기준이 있다. v1의 `set by the ripple parameter`는 이를 잃었으므로 채워진 원형을 복원한다. 빠진 길이와 예제 결과값은 생성하지 않는다.
7. 끝 L-One 단락 등에서 사라진 행렬을 직접 여는 콜론/포인터도 함께 정리한다. 온전한 자연어 개념은 원형대로 유지하고 빠진 식의 직접 의존부를 분리한다.

작성자에게 현재 TASK005의 남은 입력을 마친 뒤 새 v2 TXT/sidecar와 review019 새 버전을 쓰도록 전달했다. 이전 v1·원형·리뷰를 보존한다. 장 전체를 길다는 이유로 HOLD하지 않으며 새 수식·코드 실행·외부 값 보충을 수행하지 않는다. field006 snapshot v5의 물리적 본문 연결은 root 채택이 아니므로 이 음성 판정과 모순되지 않는다.

이 문서는 해당 초안의 보완 필요점을 기록한다. 공식 cache3의 HOLD 110,173위치와 새 리뷰 채택 수량은 바꾸지 않는다. 목표 A–E와 전체 정제는 진행 중이다.
