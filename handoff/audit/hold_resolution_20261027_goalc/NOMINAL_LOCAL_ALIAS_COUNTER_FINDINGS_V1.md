# 빈 별칭 전량 판독 중의 기계 증명 정정

V1은19,123개에 적용되어223개 후보를 찾았고 실제 원문223개를 다시 디코딩해 후보 재생성 일치와216개의 다른 기계 검사 통과를 확인했다. 이 수치는 캐시 채택이나 의미 보존 확정이 아니다.

독립 판독에서1077081의 ‘옥소아이소발레르산으로’가 주어인 아이소프로필말산의 지리 역할처럼 잘못 잡혔다. 실제 역할은 생합성 중간생성물이며 산이라는 문자열만으로 지리적 주어 역할을 증명할 수 없다. V1·전량 결과·원문·기존12시험은 보존하고 V2에서 첫 절의 실제 서술 역할과 별도 지리 문맥을 요구한다. 화학 사례와 종속절의 다른 도시·추가 빈 슬롯을 반례로 검증한다. V2가 거부한 문서도 개별 원문 판독으로 독립 본문이 확정되면 별도 근거로 채택할 수 있으며 V1 기계 증명을 그 채택 근거로 사용하지 않는다.

223개 전량 판독은 계속한다. 첫 괄호 외의 빈 필드, 조사 접합, 고아 쉼표, 누락된 사양·시구·표 예고는 각 원문 경계로 따로 처리한다. 특히1017885의 빈 출력값과 채워진 엔진 사양,167920의 동일 원문에 명시된 ‘6은’과 빠진 슬러그 목록,188351의 빠진 시구와 채워진 시인 목록을 구분한다.989715의 손상 가속 범위는 속도와 묶어 보류하고 다른 완결 사양은 유지한다. 완결 정보를 지우거나 새 값을 추측하지 않는다.

V1 후보나 V2 보완 증명만으로 채택하지 않으며 개별 전문 판독·총괄 본문 검산·원문/본문/리뷰 핀을 요구한다. 전체 잔여 목표는 계속 active이고 새 캐시·전량 재계측·정본 연쇄는 아직 미완이다.
