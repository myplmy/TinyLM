# ROOT52 빈 절과 분류 원값 복구 묶음

총괄 단독으로 기존 원문 판독과 정제본을 재사용했다. ROOT51 이후 연결된 대기3816고유7241위치를 한 번 검사해27고유54위치의 정제본을 검증했다. 자동 실행39.281978초는 전체 작업 경과시간이나 수작업 속도가 아니다. 원문 첫 전문 판독을 추가했다고 계산하지 않는다.

채워진 자녀·평가·사진의 본문은 보존하고, 실제 다음 부록 표제 또는 원문 EOF로 자식 항목이 없음이 확인되는 표제만 제거했다. 누락된 분류는 순서와 중복 횟수를 포함해 원문 값 그대로 복구했다. 게임 분류는 발매연도·매체·명시 플랫폼의 결합이 있어야 부록과의 경계를 인정한다. 수치·코드·Unicode·스타일과 그 밖의 원문 값 보존 검사는 그대로 유지했다.

ROOT는 303708의 `가면라이더 덴오(로`, 309061의 `붉은 해적단 (에`와 `Zagin, , Z=`, 451763의 단독 `의(疑,` 문맥, 410435의 염색체 설명 안 과잉 닫는 괄호를 실제 대조했다. 글자·이름·범위·기호·사실은 보충하지 않았다. 309061의 Z=는 원문에서 이미 통화명 자긴의 병기 기호로 제시되어 있으므로 등식의 미완성으로 해석한 과거 ROOT 보류를 철회한다. Z= 자체와 현상금은 그대로 보존한다. 이것은 해당 가공 설정의 외부 사실 검증을 뜻하지 않는다.

기계 검사를 통과한 뒤 발견한 빈 각주 표제303708/309061/378495도 이번 정제본에서 제거했다. 303708의 말미 단독 ㄷ은 빈 각주 뒤의 한글 정렬 키로, 등장 인물의 내용이나 항목 값이 아니다. 나머지 둘의 실제 분류와 함께 보기 목록은 모두 보존했다. 부록에 실제 링크 이름이나 참고자료가 있는 경우는 유지했다. 이 세 건은 원문 SHA와 정확한 범위를 묶어 검증하며 일반 전역 예외로 확대하지 않는다.

기존17개 수정본과 이번27개는 고유 ID가 겹치지 않는다. 이번 신규27고유54위치의 독립검산 성공 후 B 누적674고유1303위치, 기대H99629/64264고유, 처리후미채택7399, 미처리92192, 기존검토H38이다. 공식cache18은 H100932이며1303위치는 아직 캐시에 반영되지 않았다. 원본·기존 캐시·실패 이력은 보존한다. 전체 A–E와 최종 캐시·소비 검증은 계속 진행 중이다.
