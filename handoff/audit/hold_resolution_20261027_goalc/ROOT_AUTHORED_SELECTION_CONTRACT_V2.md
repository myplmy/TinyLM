# 저장된 개별 본문의 root 선택 계약 v2

이 v2는 v1을 보존하고 root_mediation_context_v1의 실제 네 본문을 해당 원문에만 최우선으로 더한다. 229468은 제공된 식·조건과 독립 역사/정성 설명을 유지한 v5,277085는 전체 크레딧을 유지하며 원문의 여는 링크/첫 구분자로 확인되는 두 작품명만 포장을 정리한 v3,801462는 빈 수식/변수/그 직접 의존만 분리한 v3,909808은 채워진 상태 라벨/값을 유지하고 고립 구문만 정리한 v2를 각 명시 최종 검토와 함께 선택한다. v1의 나머지57개 exact 선택과 명시 예외는 유지한다. 새 선택 역시 사후 본문 검산과 실제 캐시 검증 전에는 채택이 아니다.

이 선택은 캐시 채택이나 goal 종결이 아니다. 첨부 목표의 총괄 판단 권한 안에서 실제 저장된 원문·본문·검토 SHA를 선택하고, 이후 별도 본문 검산 및 최종 캐시 검증을 요구한다. 기존 원형/대안/실패/제외 이력을 보존한다.

| 안 | 방법 | 이점 | 한계 | 영향/비용 |
|---|---|---|---|---|
| A | 파일명 숫자나 mtime가 가장 큰 본문 | 간단 | 날짜형버전/실제수정목적·값복구와 맞지 않음 | 낮은 구현비, 의미 손실 위험 |
| B | 이미 고정한57개 root 결정과 명시 중재를 우선하고, 각 검토 묶음의 실제 수정 목적/원문-본문 SHA로 후속을 연결 | 오삭제 수정과 실제 저장물을 추적 가능 | 서로 다른 의미의 미중재 대안은 남겨야 함 | 새감사파일만, 검산 중간 |
| C | 모든 대안이 바이트 동일한 경우만 수용 | 결정 충돌 최소화 | 이미 원문으로 복구한 본문도 사용 불가 | 의미보존 작업의 회수율 낮음 |

선택:B. 같은 묶음의 최신 행은 이미 명시 리뷰 우선순위로 고정한 snapshot18을 사용한다. 묶음 간 선택은 아래 목적 순서로 정하며, 같은 우선순위에 서로 다른 본문이 남으면 미중재로 보존한다. 더 높은 목적 순위의 NEEDS_ROOT는 낮은 본문으로 우회하지 않는다.

1. 기존57개 exact root 선택과 이 파일의 개별 명시 예외.
2. 실제 문자/코드/Unicode/스타일/수치 반례36의 정정 본문.
3. 제한 생태/효모 view2의 승인된 범위만 저장한 본문. 전체 parent와 미판독 꼬리는 비채택.
4. v17 독립 목적 반례2와1, 새후보 문맥62의 실제 중재 본문. 각각 현 규칙의 오삭제·실제 결손을 대조한 결과다.
5. 자동 부분삭제194의 원문 전문 복구, 제외59의 재판독, 저장본문435의 형식 반례 수정.
6. 실제TXT로 회수한24개 레시피 정정과 각 규칙 버전의 독립 본문 반례. 과거 적용 실패21개를 성공으로 덮지 않는다.
7. 새문맥70/39 및 일반 문맥270의 실제 본문, 원래2110개 저자 저장물.

명시 예외:

- 290980은 v17 반례1의 context_controls 실제 정제문을 선택한다. 반례2가 유지한 수록 곡 목록/차트 성과/주간/연말 차트는 원문에 실제 행이 없다. 가온 차트1위 등 채워진 본문/분류는 보존한다. 최종 규칙 후보와 이 저자 본문은 순서가 같은 비공백 행으로도 별도 검산했다.
- 936140은 policy_v14_literal_counter_v1의 실제 v3 본문을 선택한다. 손상된 별칭의 조사 중복을 해결하면서 채워진 정보상자 라벨/숫자를 복구한 독립 전문 대조 결과다. 이전 materialized_text_repairs_v2도 역사로 보존한다.
- 1164895는 v17 반례1의 root_addendum_v4가 선택한 원래 자동 후보를 사용한다. Realidade 글자는 그대로이고 HTML 포장만 제거했다. 특정 제목이 명시되지 않았다는 이유로2016년 첫 라이브 앨범 발매 문장을 지우지 않는다.
- 393081의 빈 연도별 타격표 표제 복원본과166766의 실제 생몰일을 지운 이전 후보는 선택하지 않는다. 각각 root addendum/문자 반례36의 최종 정정을 사용한다.
- 생년/생일/사망일의 실제 충돌이 중재된232009/34237/723455/1250459는 어느 일자를 고르지 않고 충돌 부분만 분리한 실제 최종 TXT를 쓴다. 원문 없는 나이/날짜를 계산하거나 만들지 않는다.
- 28466은 root가 한정한 다섯 중립 용어 주석만 저장한 새 부분 본문을 사용한다. 혼합 연설/현대 해설의 나머지는 비채택하며, 전체 새 판독을 주장하지 않는다.
- 14760/756966/1216576 등 원문 재판독이 제한된 parent는 기존 명시 검토의 제외 근거를 유지한다. 본문을 다시 열거나 미판독을 PASS로 바꾸지 않는다.

선택 후에는 실제 선택 본문만 다시 검사한다. 숫자 추가, 편집 메모, 원문 없는 명칭, 손상된 코드/Unicode, 실제 빈 필드/수식/관계, 오삭제 신호가 남으면 개별 검토로 되돌린다. 이미 제거된 빈 표의 색 범례, UI 서명/검색 문구와 실제 코드의 차이는 source/body 정확 쌍의 root 근거로만 설명한다. 전역 예외나 검사를 끄는 방식은 사용하지 않는다.
