# 1676 원형 보류 기록

## 빈 별칭 포장

원문에는 이름이 실제로 적혀 있지만 그 뒤 병기 슬롯은 비어 있습니다. 별칭을 추정하지 않고 해당 빈 포장만 정리했습니다.

```text
과테말라시티(, )
누에바 과테말라 데 라 아순시온()
```

## 내용 없는 표제

원문에 아래 표제가 있으나 뒤에 해당 내용이 없습니다. `기후`는 후보에서 이미 제거되어 있으며 `각주`는 이번 본문 수정에서 함께 분리했습니다.

```text
기후
각주 
```

## 보존 경계

과테말라시티가 과테말라의 수도이자 과테말라주의 주도라는 관계, 명명된 완전한 이름과 별칭 `갸떼(Guate)`, 기존 분류 항목은 유지합니다. 새 별칭, 기후 설명, 각주나 다른 사실은 만들지 않았습니다.
