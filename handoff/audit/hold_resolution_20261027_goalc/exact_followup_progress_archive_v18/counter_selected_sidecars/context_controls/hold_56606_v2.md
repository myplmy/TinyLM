# 56606 원형 보류 근거 v2

- 입력: `expanded_train:56606`, TASK_001의 original/candidate/full_diff packet 1–4를 실제로 순서대로 다시 읽었다. TASK metadata는 원형과 후보가 byte-identical임을 표시하며 packet 4에는 후보 동일성 및 차이 없음 프레임이 있다. 원형 행 순서와 표의 원래 역할을 기준으로 기존 v1의 보존 경계를 교정한다.
- 본문 산문과 표 행 순서는 유지했다. 독립적으로 완결된 `control-Q`, `control-P`, `control-A`, `control-F`, `BACKSPACE`, `DEL` 행은 원래 위치 순서로 남겼다.
- `> and <`의 `Hold down > and < while pressing these`는 뒤의 `V` 속도, `L` 음량, `E` 표현 행을 지시하는 조건 헤더로 보고 네 행을 원래 순서대로 한 묶음으로 보존했다.
- 다음 무접두·무그룹 행은 어떤 제어 접두/그룹과 연결되는지 확정할 수 없어서 표에서 분리했다. 가능한 제어 접두나 그룹을 새로 추정하지 않는다.

```text
|R||generated 2-measure pattern|
|T||generated 1-measure pattern|
|A-Z||Offset value (M is 0 offset)|
|N||None (1 click)|
|P||Random choice from patterns|
|W||Write file of assignments|
|R||Read file of assignments|
|A||Copy current channel's assignments to All channels|
|Y||(followed by 0-9) Copy current channel's assignments to 1 chan|
|A||Random from All patches|
|R||Random from selected patches|
|S||Random from selected patches|
|H||Random from "hard" patches|
|B||Random from "bass" patches|
|C||Random from "perCussive" patches|
|V||Random from "vocal" patches|
|D||Random from "drum" patches|
|P||Random from "pad" patches|
|D||Random from "drum" patches|
|0-9||Fixed transition sequences|
|W||Reset (i.e. remove) warp|
|H||Comb in half|
|A||Warp applys to all channels|
|C||Warp applys to current channel|
|A-Z||Assign grabbed note/chord/phrase to letter A-Z|
```

- 두 `D` 행은 둘 다 원형에 있는 반복을 그대로 기록했다. 중복 원인을 추정해 한 행을 지우거나 나머지 무접두 행을 선택적으로 보존하지 않았다.
- 이전 `hold_56606_v1.md`와 `expanded_train_56606_counter_working_v1.txt`는 보존한다. 이번 v2는 이 행들의 경계와 순서 판단만 교정하며, 원형 입력을 수정하지 않는다.
