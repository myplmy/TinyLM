# expanded_train:37271 보류 원형 및 수정 근거

## 분리한 원형 슬롯

- `유로퓸(←, ←)`의 괄호 안은 화살표 두 개와 쉼표만 있고 어원명이나 값이 없다.
- `Eu(←)`의 괄호 안에도 화살표만 있고 설명 값이 없다.

## 처리

위 두 빈 값 슬롯의 포장과 표시만 학습 본문에서 분리했다. `유로퓸`, 원소 기호 `Eu`, 원자 번호 63, 이름이 유럽 대륙을 따라 붙었다는 문장, 브라운관 유리에 쓰인다는 문장 및 뒤의 실제 링크/분류 항목은 수정본에 보존했다. 화살표 표기가 뜻하는 빠진 이름이나 값을 추정하지 않았다. 이는 이 원문에 있는 빈 괄호 슬롯에 한정하며, 다른 화살표나 수식 기호를 삭제하는 일반 규칙이 아니다.

수정본: `expanded_train_37271_counter_working_v1.txt`. 이 메모는 검수 기록이며 학습 본문에 포함하지 않는다.
