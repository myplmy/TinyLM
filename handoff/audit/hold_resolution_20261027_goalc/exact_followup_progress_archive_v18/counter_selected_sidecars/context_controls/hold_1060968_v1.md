# 1060968 원형 보류·독립검토 근거

지정 원형·선택본문은 TASK에 기재된 SHA와 byte-identical로 판독되었고, 전체 차이 없음 프레임과 원형 전체(4 packet, 마지막 END 포함)를 확인했다. 동일 본문이라는 사실만으로 결손 정제가 완료된 것으로 보지 않았다.

## 본문에서 분리한 원형 단위

### 항목 설명 대상이 없는 bullet

```text
- The command-line parameters passed to your
- Win32 ANSI functions like
```

두 bullet은 각각 `your` 뒤 목적 대상과 `like` 뒤 API 예가 빠져 있다. 빈 대상을 채우거나 Win32 함수명을 추측하지 않았다. 별도로 완결된 `C library functions like fopen_s()` 및 그 뒤 `fopen()` 관련 독립 진술은 본문에 보존했다.

원형의 `C library functions lik\ne fopen_s()`는 줄 경계에 나뉜 동일 단어를 붙여 `like fopen_s()`로 정리하고, `fopen()is`의 단어 경계에 공백만 넣었다. 글자/API/관계를 새로 만들지 않았다.

### 미완 시험 포인터

```text
so I’ll test the replacement function
```

문장의 주장 대상 함수/시험 내용이 제시되지 않은 예고 조각이라 분리했다. `Windows thinks fopen() is insecure`라는 이미 명명된 독립 문장은 보존했다.

### 축 라벨·argv 목적어가 없는 표와 도입부

```text
Summary of some combinations of settings
Here’s a summary of what encoding you need to use for the parameters of some representative functions, under different combinations of settings. The “argv” column is for the command-line parameters passed to your
The first three columns are the settings, and the remainder are the consequences of those settings.
For convenience, this table assumes the default ANSI code page is cp1252 (Windows-1252), and the default OEM code page is cp437. It still applies if that’s not the case; you just have to make the appropriate edits.
|437||—||.UTF8||cp1252||UTF-8||cp1252||UTF-8, but only cp437-compatible characters work|
|437||UTF-8||.UTF8||UTF-8||UTF-8||UTF-8||UTF-8, but only cp437-compatible characters work|
```

`argv` 설명은 `your`에서 끊기고 표의 열 제목/축 대응이 없어 행 값의 의미를 복원할 수 없다. 표, 그 표에 직접 종속된 도입·축 설명·기본 코드페이지 가정만 함께 보류했다. 앞 문단에 독립적으로 적힌 UTF-8, 65001, 1252, 437 및 console 관련 설명은 표값을 새로 귀속하지 않고 본문에 유지했다.

## 보존 범위

UTF-8 manifest XML, manifest 편집에 대한 저자의 지식 한정, Visual Studio 설명, `GetACP()`, `SetConsoleOutputCP(65001)`, `printf()`, `fopen_s()`, `fopen()` 및 console/OEM code page 조건, 저자의 이전 setlocale 설명을 정정하는 문맥과 불확실성은 그대로 두었다. 현재 Windows 동작을 외부 검증하거나 코드를 실행하지 않았다.
