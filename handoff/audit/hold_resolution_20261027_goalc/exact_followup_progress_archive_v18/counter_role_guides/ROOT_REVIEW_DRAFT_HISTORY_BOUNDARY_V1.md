# 정식 리뷰와 작성 중 메모의 경계

review_NNN.md 및 review_NNN_vN.md는 해당 TASK의 실제 판독을 끝낸 정식 판정만 담는다. 미완 리뷰를 먼저 쓰지 않는다. 진행 메모나 작성 초안은 DRAFT_ 또는 incident_ 접두사의 자기 MD에 둔다.

TASK013의 review_013.md는 마지막 두 입력 판독 전 사유가 들어간 이력으로 보존하지만 정식 판독 증거에서 철회했다. 실제 전량 판독 뒤 review_013_v2.md가 최종 다섯 행이다. review_013_draft_incident_v1.md는 별도 판정이 아닌 경위 메모로 정확 경로/SHA를 등록했다. 기존 파일을 삭제·개명·덮지 않는다.

이후 경위 메모에는 review_ 접두사를 쓰지 않는다. 같은 ID의 두 판정을 한 리뷰 표에 중복 작성하지 않으며, 후속 수정은 해당 TASK의 새 정식 버전으로 명확히 연결한다. 이미 선택한 TXT/MD는 고정하고 새 버전을 사용한다. 이 경계는 source/모델/코드/Git 권한을 확대하지 않는다.
