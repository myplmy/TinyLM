현재 사용자 지시는 처음 19일 17시까지였으며, 후속 지시로 **20일 17시 KST까지 CPU+GPU**로 연장됐다. 정확한 원문은 현재 WIP 1~3번에 남긴다. 시간만 늘리고 동결된 v1의 학습 조건·코드·자료를 바꾸지 않는다.

코드 영향: 현행 관계 v1 동결은 그대로다. 별도 smoke는 canonical action을 모두 유지하되 타 환경용 인계 검사만 Codex 전용으로, 고정 로그 소비 경로만 새 합성 출력 경로로 연결한다. 기존 SH를 그대로 실행한 증거라고 쓰지 않는다. 모델 학습 인자는 변경하지 않는다.

데이터 영향: TINYLM_DIR를 ignored local 아래 새 폴더에 지정하여 합성 데이터/모델/로그를 독립 저장한다. 기존 HF/cache/runs 원형은 보존하며 다운로드는 offline으로 막는다. 결과 파일은 각 20MB 미만을 확인한다.

시험 영향: 독립 어댑터 회귀, 전수 codex-safe, 실제 스모크의 종료/실패팔/exit0오류/계측, 이후 cost8·학습·실답을 구별한다. 정적 통과는 모델 효능 증거가 아니다.

정본 영향: 결과101의 뒤 절→기존 P106B 계획 본문/목록→기준표·방법론→COMPASS→현재 WIP/최종 인계를 연결한다. 공용 검사기·환경·루트09 및 타 WIP는 수정하지 않는다.

비교 영향: v1의 같은 양성/교차 입력, 부모·seed·배치·업데이트·LR에서 대조 계수0/.1만 가른다. 단일 학습 seed·64 TEST 사실표의 조건부 관측이며 기존 자연 QA 개발 cohort/6개 사용자 질문의 개선을 일반 지능으로 부풀리지 않는다.

계측 해석: v1 report의 grad_max는 clip 전 전체 gradient L2 norm의 최대다. 다른 driver의 원소별 abs-max와 같은 수치가 아니므로 max_preclip_global_l2_norm으로 설명한다. 별도 CODE 미포함 의존과 인터프리터/torch/CUDA는 추가 운영 지문으로 보존한다.

## 조건부 후속: 같은 질문의 문맥 값교환 평가

현재 A가 끝난 뒤의 원인분리를 위해 CPU 계약만 먼저 준비한다. 대안은 추가 원문부모+고유QA 학습(새 학습/초기화 비용),추가 복사/표현 head(구조·캐시 변경 비용),동일 체크포인트의 문맥개입(새 학습0)이다. 현재는 마지막 경로가 가장 작은 변경으로 문맥 의존성을 직접 묻기에 우선한다. 실제 GPU는 A 원답·원형 검산 뒤만 연다.
