- 날짜: 2026-10-17
- 현재 요청: 기존 숫자/명칭 선택 유틸리티 확인 및 셸 하나로 사용 가능하게 보완, 사용자7응답 판독과 기존 실제판독 범위 확인.
- 실행 경계: GPT 모델/체크포인트 로딩·GPU·학습·smoke·다운로드·Git 변경0. 선택 후 실제 모델을 여는 것은 사용자 실행이다.
- 선택: 기존 catalog/interactive 보완. 별도 새 대화도구는 중복 유지보수, 인라인만 유지하면 사용자 실행 부담이 남는다.

데이터 스키마는 새 진단 helper의 지역 route뿐이며 체크포인트/토크나이저/캐시를 변환하지 않는다. 목록은 파일명/JSON/mtime만 보고, 모델 가중치는 사용자가 선택한 뒤에만 읽는다. --list/--help와 합성시험은 실물 가중치를 열지 않아야 한다. 서로 다른 val과 최신 저장시각을 품질 순위로 쓰지 않는다. 새 도구가 오답을 고친다고 주장하지 않는다.

테스트는 catalog 기존계약, 새 night 이름, 최근정렬, 정확선택/모호성, 토크나이저 SHA/어휘/ChatML 경계, 독립/이력·문맥예산, 실제 원문/답 분리, 종료코드·비대화형 입력거부를 덮는다. 동적 실제 모델 검증은 NOT_RUN으로 분리한다. 순수 관측이므로 인과 비교/학습토큰/ruler 계산은 해당 없다.

탐색 실수: 첫 루트 rg --files의 파일명 필터가 보호 데이터 아래 원장 경로명1건을 의도치 않게 출력했다. 해당 파일 내용/하위 추가열거/해시/변경은 수행하지 않았고 이후 검색은 scripts/tinylm/docs/handoff의 명시 경로로 한정했다. 이 노출이 보호 원천 접근 허가를 뜻하지 않는다.

연쇄 판정: 결과101/계획/P106B 양목록·방법론03·기존 사용자 안내는 갱신했다. 모델태그/학습량/계열 판정자·전체 축 결론이 바뀐 것은 아니므로 기준표/METHODS/COMPASS/리뷰와 Codex06은 이번 별도변동값을 복제하지 않는다. 루트09와 환경/공용검사기·이전인계/완료원장도 수정하지 않는다. 새 UI 옵션3개는 flag_whitelist 소유 메타데이터만 추가했다. 현재 사용자는 새 인계/커밋을 요청하지 않았으므로 기존 인계를 재작성하거나 staging/commit하지 않는다.

첫 전수는63PASS/5ERROR/6NOT_RUN이었다. dict를cfg로이름붙여get을TMTConfig로오인·필수UI옵션등록3누락·run_이름이큐항목으로오인·테스트직접진입ROOT누락을수리했다. 공용검사기면제나대화형큐등록이아니라새코드/메타/도구이름을정확히고쳤다. 합성시험초기2오류는patch대상generate가동명package함수로해석된fixture결함이며importlib로실제module을지정해회복했다. 최초감사/원형/오답을보존한다.

새 SH는 로컬 실행권한755이며 미스테이징이다. 추후 사용자가 Git 커밋을 요청하면 core.filemode=false 환경에서 실행비트를 index에 명시 확인해야 한다. 현재 추가 권한을 추정하지 않는다.
