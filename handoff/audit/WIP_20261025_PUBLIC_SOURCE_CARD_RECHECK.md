## 공식 카드에서 확인한 성격과 적용 차이

**Dolly-v2와 Dolly-15k-inst의 행 계보 동치는 미확인이다.** 공식 databricks-dolly-15k 카드는 영어 지시 자료15,000건 이상, 직원이 작성한 지시·응답, QA뿐 아니라 분류·창작·요약·추출 등 여러 과제를 설명한다. 일부 과제에는 Wikipedia 참고문맥이 있고 데이터 라이선스는 CC-BY-SA-3.0이다. 따라서 Dolly라는 이름을 QA 전용으로 읽거나 로컬14,808행을 허용목록의 다른 문자열로 일괄 치환할 근거는 없다. 원문맥을 요구하는 과제의 context를 빼고 직접 QA로 바꾸는 것도 별도 변환이다. [Databricks 공식 데이터 카드](https://huggingface.co/datasets/databricks/databricks-dolly-15k/blob/main/README.md)

공식 dolly-v2-12b 모델 카드 주소는 이번 웹 도구에서401로 열리지 않았다. 비공식 미러로 대신하지 않았다. 모델명·모델 라이선스에서 이 로컬 family의 행 ID·변환·권리 동치를 추정하지 않는다. 데이터 카드에서 확인한 권리와 열지 못한 모델 카드의 권리를 섞지 않는다.

**SODA는 합성 사회적 대화 원천이며 현재 SODA-inst와 같은 역할 구조라는 증거는 없다.** 공식 카드는 InstructGPT와 Atomic10x의 사회적 상식을 이용한 영어 대화 증류를 설명하며 dialogue·speakers·narrative·원 index·split 필드를 제공한다. 원자료는 TRAIN1,191,582·VALID146,346·TEST148,968이고 CC-BY-4.0이다. 원자료에 여러 화자가 있어도 현재 단일 user/assistant 안의 대본을 그대로 실제 assistant 다회전으로 세면 안 된다. 한국어 재고 행수가 원 TRAIN 수와 같다는 사실도 원 ID·분할 동치 증명은 아니다. [Ai2 공식 SODA 카드](https://huggingface.co/datasets/allenai/soda/blob/main/README.md)

**HotpotQA는 여러 근거를 결합하는 QA이므로 근거 보존이 핵심이다.** 공식 카드는 Wikipedia 기반 다중 문서 추론과 문장 단위 supporting_facts, question·answer·context·id 필드를 설명한다. 공개 카드의 TRAIN은90,447행, VALID는7,405행이며 fullwiki 구성에는 별도 TEST7,405행도 있다. 라이선스는 CC-BY-SA-4.0이다. 로컬 각 언어355,476행은 이 숫자만으로 원 TRAIN과 동치라고 할 수 없다. 번역·템플릿·구성별 같은 원 질문을 독립 지식으로 중복 가산하지 않아야 하며, 현재 inputs/targets가 직접 답변 과제를 보존하는지 확인되지 않았다. [공식 HotpotQA 카드](https://huggingface.co/datasets/hotpotqa/hotpot_qa/blob/main/README.md)

**Aya 집합 카드는 세 원자료와 로컬 변환 사이의 설명이지만 행별 연결 영수증은 아니다.** 공식 카드는 원자료에 지시 템플릿을 적용한 자료와 자동 번역 자료가 섞이며 dataset_name·sub_dataset_name·task_type·template_id·language·split을 제공한다고 설명한다. 집합 라이선스 표기는 Apache-2.0이다. 그러나 이 표기만으로 위 원자료 카드의 서로 다른 조건이 소멸했거나 로컬 변형의 재배포·변환·분할까지 확인됐다고 결론내리지 않는다. 카드 표기의 차이를 기록하며 법적 위반이나 사용 허용을 새로 확정하지 않는다. [Cohere 공식 집합 카드](https://huggingface.co/datasets/CohereLabs/aya_collection_language_split)

정확 revision의 README 주소는 웹 도구에서 직접 열리지 않았다. 위 집합 설명은 현재 공개 카드에서 확인한 것이며 해당 revision README의 바이트 동일성 증거로 쓰지 않는다. 열람한 집합 카드에는 Dolly-v2와 Dolly-15k-inst 사이의 별명 대응표가 없었다. 그 부재는 두 이름이 다른 자료라는 증명도 아니므로 판정은 동치 미확인으로 남긴다.

## 기존 재활용의 최소 선결

1. 이름은 원형대로 보존한다. Dolly-v2를 Dolly-15k-inst로 바꾸려면 정확 원 ID·파일/revision·변환 기록의 연결이 먼저다. 카드에 비슷한 이름이 있다는 이유로 허용목록을 확대하지 않는다.
2. 원 family·원 ID·원 split과 Aya의 dataset_name·template_id·언어·파생 관계를 연결한다. 공개 컨테이너의 train 표기와 원자료 TRAIN 또는 실제 모델 노출 이력은 서로 다르다. 번역·템플릿 변형은 같은 원개념 계보를 보존한다.
3. 원문·근거·과제 요구와 출력의 관계를 유지한다. Dolly의 혼합 과제를 모두 직접 QA로, SODA의 등장인물 대본을 모두 사용자/assistant 턴으로, HotpotQA의 짧은 답을 근거 없는 독립 사실로 자동 재분류하지 않는다.
4. 학생1024에서 필요한 전체 문맥과 대화가 무절단으로 들어가는 양, 실제 assistant target, 고유 원천량은 아직 미측정이다. 기존 역할·원천 가족 상한·분할 계약을 카드 조회만으로 바꾸지 않는다. 평가계열과 그 번역·템플릿 변형의 제외도 별도다.
