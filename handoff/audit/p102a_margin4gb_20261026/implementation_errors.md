# 현재 진단의 도구·구현 오류

첫 단계의 CPU metadata 오류와 원형 보존은 결과093 22절과 first_failure_readback.json이 소유한다. 입력을 JSON과 비교할 때 tuple/list 왕복을 고려하지 못했고 합성14회귀가 실제 metadata 계약을 누락했다. 기존 canonical 로더 계약과 같은 방식으로 수정하고 새 단계로 회수한다.

SH 실행권한 누락은 자체 오류다. BAT전용 --name 경로의 SH 거부를 SH명 규약 전체의 실패로 오인하지 않으며 셸/계획/인자 검사를 유지한다. 다른 세션의 미등록5flag는 수정하지 않고 공용 전체PASS를 주장하지 않는다.

원장 갱신 도구 초안에 사용하지 않는 외국어 문장이 포함됐다. 최종 원장 값은 한국어였지만 전송 전 작성문 검사를 그 호출에 적용하지 못해 노출을 막지 못했다. 미사용 문장을 없애고 이후 작성 문자열은 도구 전 문자 검사를 적용한다. 실제 원문에 있는 외국어 인용은 작성문과 별도로 취급한다.

동일권한증거를 JSON에 저장하려고 원장 읽기와 다른 파일 쓰기를 같은 명령에 넣어 보호훅에서 거부됐다. 원장 변경은0이며 읽기와 다른 파일 쓰기를 분리했다. 현재 사용자 원문 근거를 전달한 뒤 동일 제한 재검토가 승인됐고 root57377 종료0을 회수했다.

후속 작성문 문자검사는 미사용 외국어가 섞인 초안을 실행 전 차단했다. 그 초안으로 파일 변경0이다. 미사용 대입문을 제거하고 한국어 완성문만 새로 작성한 명령으로 실제 원장 override와95번 완료를 회수했다. 초안 차단을 모든 도구 출력의 언어 준수 보장으로 확대하지 않는다.

결과 조건서명은 comparator_tag 한 행을 빠뜨려 첫 검사1이었다. 해당 행만 추가했고 수치/조건/원형은 바꾸지 않았다.
