# C3 프론티어 81계획·승인 진행 제안서 20건의 수동 가치 재평가

> 2026-09-25. 항목별 정본은 [동일 source SHA의 C3 JSON](FRONTIER_SEMANTIC_B7A0440D34FF_EE1A567F10F6.json)이다. 이 문서는 사용자가 판단을 훑는 뷰이며 새 점수 정본이 아니다. 모델·GPU·보호 데이터를 실행·열람하지 않았다.

## 1. 전수 범위와 판정 언어

물리 계획/색인 123/123 중 미종결 81개(계획 25·진행 56)를 모두 한 번씩 검수했다. 승인 진행 제안서도 루트 파일 20개 전부를 검수했다. 계획 가치 등급은 HIGH 16·MEDIUM 49·LOW 16이다. 처분은 BUILD_NEXT 13·USER_DECISION 19·FAILED_GATE 11·LOW_PRIORITY 17·EVIDENCE_NEEDED 10·DOC_CORRECTION 11이다. 이 등급은 남은 연구의 예상 가치와 현재 증거·비용을 비교한 **수동 우선순위**이며 결과 PASS/FAIL이나 승인된 실행 명령이 아니다.

기존 C2의 AUTO_NO_LAUNCHER/HOLD 81건은 실물 런처가 없다는 재고 사실이었다. C3는 이를 과학적 후순위로 복사하지 않고 각 계획에 이유·증거 경로·다음 행동을 썼다. 계측기 first_unfinished_stage는 38/81을 미식별로 남기고 P014E·P105의 옛 문장을 첫 선결로 잡기도 하므로 계획서·결과와 수동 대조했다. 현재 연구 실행 SH는 0개다.

### 2.1 세 접근 비교

| 안 | 내용 | 장점 | 단점·영향도 | 수행비용 |
|---|---|---|---|---|
| A — 능력 원인분리 먼저 | P105→P100→P069와 P090B 공개 SFT 판정 | 현재 직답 0/98의 지식·형식·종료 원인을 직접 분리 | 공개 원천·사람 권리 결정이 필요하고 학습 효과는 아직 미측정 | CPU 진단 중간, SFT 본런은 후속 산정 |

## 3. 승인 진행 제안서 20건 — 무시인가, 실제 선결인가

| 처분 | 건수 | 해당 제안서의 짧은 이름 | 뜻 |
|---|---:|---|---|
| IMPLEMENT_NEXT | 7 | 프론티어 C3, Scout, 40MiB 지능, 계산량 X1~X3, 학습시간 T0~S3, 위키 서식, 회전 삼진 | 다음 구현 후보가 실제로 있다. 최근 빈 큐에서 방향 제안이 부족했던 축 |
| USER_DECISION | 3 | held-out 품질, 레이어 상태 실제 panel, 검증형 교사 | 보호 데이터·모델 계보·권리·비용 결정 선결 |

따라서 20건을 모두 버리거나 모두 즉시 실험할 수 있는 것이 아니다. **확인 누락도 있었다**: 특히 IMPLEMENT_NEXT 7건은 런처 부재만으로 과학적 가치가 낮아진 것이 아닌데, 최근 권장표는 P105·P014E 두 축만 한 문장으로 언급했다. 반대로 권리·실패 게이트·E2E 대기 제안서를 임의 실행하지 않은 것은 정당하다. 승인 진행 접미사는 남은 계약이 있다는 뜻이며 done 이관 근거는 아니다.

## 4. 한계와 다음 검증

C3의 수동 등급은 각 계획의 예상 기여·증거·현재 선결을 읽은 **우선순위 제안**이다. 값의 크기와 성공 확률을 새 모델로 측정하지 않았다. 실제 실험 후보를 큐에 넣으려면 계획별 preflight, 원본/풀·토크나이저·계보 고정, 실물 SH, 현재 코드 사용자 smoke가 선행한다. C3 checker는 ID·제안서 경로 누락, stale source, 복제 사유와 무순위 BUILD_NEXT를 막지만 사람 판단의 과학적 진실까지 증명하지 못한다.
