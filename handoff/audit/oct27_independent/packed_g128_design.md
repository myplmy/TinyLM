# g128 원함수 보존 패킹의 독립 준비

사용자96/97과 미완65 범위다. 정 담당은 지정 텍스트만 읽었고 코드/시험/모델/GPU/파일변경은0이다. 총괄이 판단·구현·검증한다. 현재 P078 실제 도구29790의51소스/고정자료는 끝날 때까지 수정하지 않는다.

## 재고와 선택

기존 `lut.py`의 pack_trits/unpack_trits는5트릿/바이트를 이미 제공한다. 새 codec을 중복 구현하지 않는다. `TLinear.to_lut`는 g128 스케일을 행 하나로 합치므로 단순한 무손실 저장 변환으로 쓸 수 없다. 기본 FP32/cache 실행과 배포 파일/상주·작업버퍼는 별개다.

| 안 | 재사용과 추가 범위 | 장점 | 한계·노력 |
|---|---|---|---|
| A | 기존 per-row LUT와 writer/loader | 가장 작고 직접 LUT 경로 재사용 | 스케일 병합의 손실과 과거속도음성, 현재대상 품질 별도 |
| B 권장 | g128별5트릿/원FP32스케일·행타일 복원·전용payload/loader | 기존 삼진 수치를 보존하며 전체FP32행렬 사본을 없애는 기술검증 가능 | 새 저장/재로드·alias/캐시 검증, tile GEMM 수치/속도 위험 |
| C | 같은 g128 파일을 그룹별 직접LUT 호출 | FP32 가중치 복원을 피할 가능성 | 누산순서/호출/gather 비용과 별도프로파일 필요 |

우선 B를 선택한다. 128트릿을130개로패딩해26B+원FP32 scale4B=30B, 실제1.875bpw다. 이론1.71이나per-row값을 복사하지 않는다. 코드/scale 재구성의 수치 동률과 GEMM 분할 오차를 구분한다. 기존패커의 float→int 변환 전 정수성, 예약코드, finite scale·pad·복원일치를 엄격히 검사한다. 작은alpha를clamp해서0으로 바꾸지 않는다.

## 권한·영향도

| 경로 | 행위 | 근거·제외 |
|---|---|---|
| 새 scripts의 배포모듈/독립시험/driver | 신설 | 사용자96 미완65 구현. 기존제품/진행P078소스 수정0 |
| 자기 감사/새P014E 후속/결과099·연쇄 문서 | 좁은 신설·기록 | 기존실험규약. 회전/재학습/기존판정 덮기0 |
| runs/deploy의 새 payload/원형·소형evidence | 새파일만 | 새배포파일은Git제외, 원CP/기존파일 삭제·덮기0 |
| 동결Native595 Q와 고정 tokenizer | 명시읽기 | 해당완료모델의CP/core/계보검증. 보호TinyDataset/타정제자료 읽기0 |

- 기능: 기존 product 모델/생성기와 codec을 재사용하되 별도추론전용 module/loader로 연결한다. 학습/default/kernel 교체는0이다.
- 데이터: 새 학습·교사호출·벤치답 TRAIN편입0. 초기에는 같은 FP32 embedding을 유지해 body패킹을 분리한다.
- 검증: CPU codec/파일왕복·alias/원스케일·전체모델 prefill/decode와KV·새프로세스 상주/latency. GPU는 P078 종료·여유/시간 입장 후에만 직렬로 수행한다.
- 증거: 파일/고유storage/전체모델/작업타일/KV/RSS와시작peak를 분리한다. masters/optimizer/전체_wq가 payload나실행에 남으면 성공으로 쓰지 않는다.
- 도메인: 17시/추가300M금지/타정제소유·직렬GPU·20MB미만 로그/소형근거를 유지한다. 큰배포payload는runs 전용이며 staging0이다.

메타 기기 모델 골격으로 원latent 할당 없이 재로드할 수 있는지 먼저 확인한다. `_tlinear_cache`의옛객체 참조와 plain Tensor 속성은 일반state_dict/.to만으로 처리됐다고 주장하지 않는다. 필요버퍼/alias를 명시 저장하고 전용로더로 복구한다.

FP32embedding을그대로두면 현32K 모델도40MiB목표를 못맞출 수 있다. 이 경우 실패를 숨기지 않는다. 기존int8 embedding의행조회/출력청크는후속별도변수이며, 단순bf16 저장이전체FP32임시표를없앤다는주장이나과거ternary embedding 음성의자동반전은금지한다. 큰교사어휘/직접KL·공식벤치품질·최종40MiB는검증 전까지미완이다.
