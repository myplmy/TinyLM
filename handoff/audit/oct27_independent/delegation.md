# 읽기 전용 문헌 위임

- 근거: 사용자가 허용한 sol6.1/max 문헌·정·반 역할과 현재96번 독립 미완료 수행.
- 역할: AdaMuon 문헌·공식 구현·비용 검토. 모델 gpt-6.1-sol, reasoning max. 이 위임은 한 명이다.
- 허용 읽기: 공개 AdaMuon 논문/저자 저장소, tinylm/train/muon.py와 normuon.py, 원장56에 해당하는 첨부 지시서의2.2절. 문헌 내용은 별도 타당성 검토 대상이다.
- 허용 쓰기: 없음. 최종 답변으로 근거·공식 수식/코드 차이·추가 상태·위험·후속 의견을 전달한다.
- 금지: 코드/테스트/계획/결과/원장/설정 편집, 스크립트 실행, 체크포인트·학습자료·정제 세션 경로 접근, 모델/GPU·설치·다운로드·Git·삭제·다른 보조 호출.
- 총괄은 소스/논문을 대조하고 구현과 실행을 직접 담당한다. 보조의 의견만으로 구현 일치나 성능을 확정하지 않는다.

## 반 검토의 별도 위임

- 모델/역할: gpt-6.1-sol max, 반 검토 한 명. 문헌 한 명과 합계2명이며 사용자가 허용한 역할 범위다.

- 출력: 메시지로만 계측/실패/주장 경계와 실제 반례를 반환한다.
- 쓰기/실행:0. 체크포인트·토크나이저·학습자료·정제 세션 전용 경로·원장 접근, 모델/GPU/시험·Git·설치·다른 보조 호출은 금지한다.
