# P107 적응형 masking의 문헌 읽기 사전 위임

- 대상: 기존 `literature_oct27_adamuon`, 요청모델 gpt-6.1-sol/max. 문헌·아이디어 역할만이며 총괄 편집/실행 권한을 상속하지 않는다.
- 목적: 원장59의 uniform/적응형 masking 대조를 위한 GPT-BERT 공식 손실통계·span·선택 규약과 언어/희귀/숫자 편향 및 갱신비용을 분석한다. 구현된 P107 uniform15%를 공식 적응형으로 재명명하지 않는다.
- 허용 읽기: 공개 일차 논문/저자 코드 텍스트, `tinylm/train/hybrid_mntp.py`, `scripts/diag_p107_hybrid_mntp.py`, `docs/research/20261027_MNTP_가시성과_지도위치_구현계약.md`. 사용자 지시59의 원문은 총괄 메시지에서 전달한다.
- 허용 행위: 웹 검색·페이지 읽기와 지정 파일의 rg/sed/cat. 결과는 메시지로만 논문/고정URL·확인범위·후보3안/근거·통계state와비용·필수반례를 반환한다.
- 금지: 파일생성/편집·코드구현·시험/Python/모델/GPU·실제학습자료/토크나이저/체크포인트·정제담당전용자료/원장 접근·설치/다운로드·Git·삭제·다른보조호출.
- 현재GPU전체스모크의소스는총괄이동결한다. 보조는어떤코드도고치지않으며방법의TinyLM품질효과나본학습채택을확정하지않는다.
