## 아직 닫히지 않은 입장 조건

1. 총괄이 TRAIN 재사용·형식 비교 한정·원문서 동일성 미확인을 명시한 policy와 SHA를 만든다.
2. 알려진 명시 HOLD는 같은 원문 SHA 또는 같은 source SHA의 EOS/span으로 연결해 양팔 공통 제외한다. 숫자ID가 다른 풀의 ID와 같다는 이유로 연결하지 않는다. 미해결·충돌은 중단한다.
3. 정확 VAL path/SHA를 지정하고 완전 EOS 문서·가장자리·기존32-token 대조를 재사용해 정제 후에도 공통 제외를 검산한다. 문서 URL 부재를 내용 해시로 대신해 전역 누설0이라고 쓰지 않는다.
4. 양팔 실제 ID 각각600,047,616 이상. 600M이라는 반올림만으로 2배 기준을 충족했다고 하지 않는다.
5. 출력은20,000,000B 미만 ledger 샤드와 별도 큰 bin으로 분리하고 bin/모델은 staging하지 않는다. 기존 cache와 체크포인트는 삭제하지 않는다.
6. 실제 본학습 driver·명령·source pins·초기화·마감·자원·비용 게이트를 별도 확정한다. 학습 전 짧은 수치/비용 시험은 기술 확인이며 성과 평가는 전체300M이 끝난 뒤만 한다.
