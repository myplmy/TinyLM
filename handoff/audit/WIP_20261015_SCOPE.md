## 영향 축

코드는 기존 assistant-only components/optimizer/native CE와 명시적 새 루프를 재사용한다.
스키마는 독립 namespace이며 기존 cache/reader와 호환성 변경이 없다. CPU 회귀는
root/이름 split·정답·자료량·마스크·update 전체 분모·native weight0의 gradient 불변을 검사한다.
평가에는 같은 body/토크나이저/입력·FP32 math·greedy·NTP1을 사용한다.
새 native 보조 forward는 SFT micro8×accum16의 별도 8행 batch이며 실제 입력/지도량/비용을 따로 공개한다.
통계 sigma는 이 계열에 없으며 단일 seed 결과는 관측이다. 결과·계획·기준표·방법론·COMPASS가 연쇄 대상이다.

## 사전등록

- 새 한영 코드 문맥 4096행 + 산수/논리/형식/조건갱신1024행 + 기존 공개 근거 QA512행.
- 공개 QA는 교사 PSEUDO이며 현실정답/권리 인증 아님; 새 교사 생성 없이 근거 원형 유지.
- 과거처럼 자료요청 고정문장을 절반 추가하지 않는다. 입력은 자연 본문/여러 질문 표현.
- code dev/test는 별도 이름과 root·각 split의 동결 manifest. 공개 val은 이미 사용한 개발표본으로만 보고.
- 같은 부모/seed/행 순서/micro8accum16/seq1024/ckptON/compiledefault/LR Adam5e-5 Muon2e-4/4pass.
- 독립변수: 별도 native train CE의 가중치 0/.25/1. 모든 팔에서 같은 native 입력과 CE 계산.
- native는 기존 **train.bin**의 서로 겹치지 않는 선택 chunk만 복사; val.bin은 평가 전용.
- 목적: 가중치0 대비 code test 정확·4view 일관성을 잃지 않으면서 native CE 악화를 줄이는 Pareto 후보 탐색.
  고정 인과/범용 지능·정식 TRAIN_READY/배포 채택은 주장하지 않는다.
- full test는 최종 팔을 모두 완료한 후 처음 공개. dev는 경과 관측이며 최종 epoch를 사후 교체하지 않는다.
