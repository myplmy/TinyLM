# 제안 — ★★**반복 노출 축을 연다** (풀 300M 고정 · 1/2/4 epoch)

> **작성 2026-09-03**(사용자 지적에서 나왔다) · ⚙**11.2h** · ★**배포 상주 증가 0**
> 🚫**[토큰 예산 축](20260903_토큰예산축을-연다.md)과 다른 축**이다 — §2 가 그 구분이다.

## 1. 배경

### 1.1 ★이 축은 문서에 있었는데 제안서로 안 올라왔다

[`20260902_40MB안에서-지능을-어디까지-올릴-수-있나.md`](../docs/20260902_40MB안에서-지능을-어디까지-올릴-수-있나.md):

- **§5.4** *"반복 노출은 우리가 한 번도 안 쟀다"* — 풀 600M 에서 300M 을 뽑으므로
  ★**평균 0.5 epoch** 다. **1 epoch 을 넘겨 본 적이 없다.**
- **§6.1** 문헌(arXiv:2305.16264, Muennighoff 외)은 **4 epoch 까지 거의 무손실**이라 한다.
- **§7 권고 5행** — 반복 노출(2·4 epoch), ⚙런당 3.2~6.4h.

🚫★**그런데 [토큰 예산 축 제안서] §9 는 이것을 "대안 C" 로 적고 기각했다** —
사유는 *"결과 006 의 '풀 ≥ 2배' 를 정면 위반한다"* 였다.

### 1.2 ★★그 기각 사유가 논리적으로 틀렸다

**결과 006 은 반복 노출 축에 *대한* 발견**이다(풀 300M→600M 만으로 dense **−0.12**).
그러니 *"결과 006 을 위반한다"* 는 **그 축 자체를 재려는 실험의 기각 사유가 못 된다.**
그건 *"이 실험이 재려는 것이 바로 그 효과"* 라는 뜻이다.

⚠️**결과 006 이 말하는 것은 "반복 노출은 나쁘다" 가 아니라 "반복 노출이 섞이면
다른 축을 못 잰다"** 이다. **반복 노출 자체를 독립변수로 두면 규칙 위반이 아니다.**

## 2. 목적 — ★**유니크 토큰 축과 무엇이 다른가**

| | 유니크 토큰 축(안 A) | ★**반복 노출 축(이 제안)** |
|---|---|---|
| 무엇을 늘리나 | **처음 보는 토큰** | ★**같은 토큰을 보는 횟수** |
| 풀 | 1.2B 고정, 학습 300M→600M | ★**300M 고정**, 학습 300M→600M→1.2B |
| epoch | 0.25 → 0.5 | ★**1 → 2 → 4** |
| 묻는 것 | *"데이터가 모자란가"* | ★*"모델이 **덜 굶으면** 좋아지나"* |
| 시험지(val) | 같다(풀 고정) | ★**같다**(풀 고정) |

★★**사용자 형태가 안 A 의 알려진 구멍을 메운다**: 1.2B 풀의 val 은 **한국어 0.0%** 라
안 A 는 한국어를 못 잰다. **풀 300M 은 한국어가 살아 있다**(`ko-en_300000000`).

## 4. 비용

| 팔 | 학습토큰 | epoch | ⚙ |
|---|---:|---:|---:|
| `e1` | 300M | **1.0** | 1.7h |
| `e2` | 600M | **2.0** | 3.4h |
| `e4` | 1,200M | **4.0** | 6.8h |
| | | **합계** | ★**11.9h** |

★**줄이는 안**: `e1` 은 **기존 300M 런과 조건이 다르다**(풀 600M→300M) 므로 **새로 돌려야 한다.**
🚫**기존 런을 대조군으로 쓰면 풀이 달라 무효**다(함정 2).
⚠️**e4 를 빼면 7.1h** 로 줄지만 **포화점을 못 본다** — 그것이 이 실험의 요점이다.

## 5. 원칙·근거

- ★**배포 상주 증가 0.** 토큰을 더 먹여도 모델은 그대로다.
- ★**풀이 고정이라 시험지가 고정**된다 — 우리가 풀 비교에서 늘 겪던 무효화가 없다.
- ⚠️**문헌은 고정 compute 가정**이다(arXiv:2305.16264). 우리는 **모델 크기가 먼저 고정**된
  반대 조건이라 🚫**"4 epoch 은 안전하다" 를 우리 수치로 옮겨 적지 않는다.**

## 6. 방법

| 단계 | 무엇 | ★**다음으로 가는 조건** |
|---|---|---|
| **0** | `ko-en_300000000` 풀의 val 언어 구성 확인(`diag_val_lang.py`) | ★**한국어가 0% 가 아닐 것** |
| **1** | `e1` · `e2` 두 팔 | Δ가 dense 자(0.0021)를 넘는가 |
| **2** | `e4` | ⏸**단계1 이 이득을 보일 때만** — 안 보이면 **여기서 닫는다** |

★**모델**: 32 MiB 승자 `d12_cla2_r20` 하나. 🚫**두 모델을 동시에 움직이지 않는다.**
⚠️**`--sched wsd` 의 anneal 이 steps 비율이라 steps 를 2배 하면 감쇠 시점도 2배**다 —
✅**의도한 것**이지만 *"토큰만 바꿨다"* 가 아니라 **"토큰과 그에 비례한 스케줄"** 이라고 적는다.

## 7. 거절하면 못 하는 것

- ★**우리가 파라미터당 3.7 토큰**이라는 사실의 의미를 모른 채 남긴다.
  외부 모델은 **8,026~121,739** 다(**2,169~32,902배**).
- 🚫**"작아서 못한다" 와 "덜 먹어서 못한다" 를 못 가른다.** 앞이면 아키텍처를,
  뒤면 **상주 0 으로** 고칠 수 있다 — **완전히 다른 로드맵**이다.
