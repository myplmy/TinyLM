# `proposal/` — 제안서 폴더

> **신설 2026-09-03**(사용자 지시 9). **AI 가 사용자에게 무언가를 제안할 때, 상세한 설명이
> 필요하면 여기에 마크다운 파일로 쓴다.** 대화로만 제안하면 **다음 세션이 못 읽는다.**

---

## 1. 언제 제안서를 쓰나

**대화 한두 줄로 끝나지 않는 제안**은 전부 여기 쓴다. 판단이 애매하면 **쓴다.**

| 종류 | 예 |
|---|---|
| ★**실험계획 제안** | *"토큰 예산 축을 열자"* — 승인 후에 `test_plan/` 에 계획서를 쓴다 |
| ★**아키텍처 형태 추가·수정** | 새 프리셋, 새 레버, 기존 축의 재정의 |
| ★**새 스킬 작성·기존 스킬 수정** | `.claude/skills/` 변경 |
| ★**작업 방식·논의 방식 개선** | 규약 신설, 도구 자동화, 보고 형식 변경 |
| 그 밖에 | **비용이 들거나 되돌리기 번거로운 것 전부** |

🚫**제안서는 실행이 아니다.** 제안서를 쓰는 것까지가 AI 의 몫이고,
**승인 전에는 구현·학습·데이터셋 변경을 시작하지 않는다.**

---

## 2. 파일 이름

```
proposal/{YYYYMMDD}_{한-줄-요약}.md
```

예: `done/20260903_토큰예산축을-연다-conditional.md`

승인·기각이 끝나면 **접미사를 붙여 상태를 남긴다**(🚫삭제하지 않는다 — R01):

| 접미사 | 뜻 |
|---|---|
| (없음) | ⏳**판단 대기** |
| `-approved` | ✅승인됨. 본문에 **무엇이 그 결과로 생겼는지**(계획서 번호 등)를 적는다 |
| `-rejected` | 🚫거절됨. 본문에 **거절 사유**를 적는다 — 다음에 같은 제안을 또 하지 않기 위해서다 |
| `-superseded` | ⏸다른 제안이 대신했다. **어느 것인지** 적는다 |

## 3. 양식 — **아홉 절 전부 쓴다**

정본 서식은 [`_TEMPLATE.md`](_TEMPLATE.md) 다. 새 제안서는 **그것을 복사해서 시작한다.**

| # | 절 | 무엇을 쓰나 |
|---|---|---|
| **1** | **배경** | 이 제안을 하게 된 계기. ★**측정값·결과문서 번호로** 쓴다 |
| **2** | **목적** | 이걸로 **무엇을 알아내거나 얻으려 하나** — 한 문장 |
| **3** | **성과물** | 승인하면 **무엇이 생기나**. 파일·수치·판정 중 무엇인지 구체적으로 |
| **4** | **비용** | ⚙GPU-h · engineer-h · 디스크 · **사용자가 직접 해야 하는 일** |
| **5** | **원리·근거** | 왜 이게 통할 것 같은가. ★**우리 실측**과 **외부 근거**(arXiv id/HF id)를 구분해서 |
| **6** | **방법** | 어떤 순서로. ★**각 단계가 다음 단계의 게이트**가 되게 |
| **7** | **거절하면 못 하는 것** | ★**정직하게.** *"아무것도"* 가 답이면 그렇게 쓴다 |
| **8** | **위험** | 실행했을 때 **뭐가 잘못될 수 있나**. 계측·교락·자원 |
| **9** | **대안** | 각 대안의 장단점 + ★**권장안과 그 근거** |

## 4. ★쓰는 쪽에 대한 규칙

| # | 규칙 |
|---|---|
| ★**1** | **아홉 절을 비우지 않는다.** 해당 없으면 *"없다"* 라고 **쓴다** — 빈 절은 *"안 적은 것인지 없는 것인지"* 를 못 가른다(핸드오프 §3 과 같은 이유) |
| ★**2** | **비용은 숫자로.** *"오래 걸린다"* 는 비용이 아니다. ⚙ 표시로 추정임을 밝힌다(용어설명 §n) |
| ★**3** | ★**"미룬다" 고 쓸 때는 무엇이 선결이고 그것이 얼마인지를 숫자로**(의사결정함정 D1) |
| ★**4** | **권장안을 반드시 하나 고른다.** 대안만 늘어놓는 것은 제안이 아니다 |
| ★**5** | 🚫**승인 전에 구현하지 않는다.** 배치도 만들지 않는다 — *"지금 돌아갈 때만 만든다"*(R22) |
| ★**6** | 인용은 **실제로 조회한 것만**(R31). 초록만 읽었으면 그렇게 적는다 |
| **7** | 제안이 **실험**이면 승인 후 `test_plan/` 으로 가고, **규약**이면 `ai_dev_tool/` 로 간다. 제안서는 **그 앞단**이다 |
