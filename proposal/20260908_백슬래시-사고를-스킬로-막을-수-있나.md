# 제안 — **백슬래시 사고(누적 15회)를 스킬로 막을 수 있나**

> **작성** 2026-09-08(2차) · **사용자 지시 3**(*"bash heredoc 백슬래시 사고 방지를 위해 별도 write
> 툴 규칙을 어기지 않도록 하기 위한 스킬 작성 가능한지 제안서 작성바람"*) · **상태** ⏳판단 대기
>
> ★**답 먼저: 🚫스킬로는 못 막는다.** 그리고 그 근거가 이 제안서에서 가장 중요한 부분이다 —
> ★**"Write 툴을 써라" 는 규칙은 이미 세 곳에 있고, 그 상태에서 15번 났다.**
> ✅**막을 수 있는 것은 훅(hook)** 이고, ★**이미 난 사고를 찾는 그물 하나는 이번에 만들어 켰다**(§4).

---

## 1. 배경 — **사고의 정확한 형태와 이력**

### 1.1 두 가지 실패가 한 이름으로 불리고 있다

| 류 | 무슨 일 | 결과 | 위험 |
|---|---|---|---|
| ★**A. 조용한 오염** | 파이썬 패치 문자열·heredoc 안의 `\b`·`\t`·`\v` 가 **실제 바이트**(0x08·0x09·0x0B)가 되어 파일에 박힌다 | **문법적으로 멀쩡한 쓰레기** | 🚫★**치명적** — 아무도 안 본다 |
| **B. 시끄러운 실패** | heredoc 본문의 따옴표·백틱을 셸이 먼저 파싱해 `unexpected EOF` | 명령이 **죽는다.** 파일은 안 바뀐다 | ⚠️낮다 — 즉시 안다 |

⚠️★**둘을 섞어 세면 안 된다.** *"누적 15회"* 는 두 류의 합이고,
**돈이 든 것은 A 뿐**이다. **이번 세션에도 B 가 한 번 났고 파일은 무사했다.**

### 1.2 A 류의 실제 피해

| 언제 | 무엇 | 대가 |
|---|---|---|
| 2026-08-30 | `run_P067_stage2a_gemma_probe-done.bat` 에 **0x08·0x09** — `scripts` + BS + `atch` | ★**wandb push 가 한 번도 안 돌았다** |
| 2026-09-06 | `mem_runtime.py` 에 `\n` 이 실제 개행 → `SyntaxError` | (B 류로 전환돼 즉사) |
| 2026-09-07 | 신규 배치 둘에 `\b`·`\t` | `lint_bat` 1b 가 잡았다 |

## 2. 🚫★**왜 스킬로는 못 막나 — 이것이 결정적 근거다**

**규칙은 이미 있다. 세 곳에.**

| 어디 | 문구 |
|---|---|
| `CLAUDE.md` | *"★긴 파일·백슬래시는 `Write` 툴로 쓴다"* |
| `ai_dev_tool/06` §도구사고 표 1·2 | *"★본문에 백슬래시를 쓸 일이 있으면 `Write` 툴로 직접 쓴다"* |
| ★**세션 시작 프롬프트**(매 세션 첫 화면) | *"★★긴 파일이나 백슬래시가 든 내용은 Write/Edit 툴로 쓴다 — bash heredoc 에 넣으면 `\b`·`\t` 가 된다"* |

> ★★**즉 사고는 "규칙을 몰라서" 난 것이 아니다.** 규칙이 **컨텍스트 맨 위에 있는 상태에서** 났다.
> **스킬은 텍스트를 한 군데 더 늘리는 것**이고, 🚫**네 번째 사본이 세 번째보다 잘 들을 이유가 없다.**

★**구조적 이유**: 스킬은 **호출될 때** 로드된다. 그런데 이 사고는
*"작은 패치 하나를 빨리 하자"* 는 **흐름 중간**에 난다 — **그 순간 나는 스킬을 부르지 않는다.**
🚫**스킬은 "내가 스킬을 불러야 한다는 것을 아는 경우"에만 작동한다.**

## 3. ✅**막을 수 있는 것 — 훅(hook)**

Claude Code 는 **`PreToolUse` 훅**을 지원한다(`.claude/settings.json`).
훅은 **도구 호출 직전에 실행되고, 비영 종료로 그 호출을 거절**할 수 있다.
★**이것은 내 선택 밖이다** — 그래서 규칙과 다르다.

### 3.1 제안하는 판정식 — ★**A 류만 좁게 겨눈다**

> **Bash 명령이 (①저장소 파일에 쓰고) AND (②본문에 백슬래시가 있으면) → 거절.**

| 조각 | 판정 |
|---|---|
| ① 쓰기 | `>` · `>>` · `tee` 가 저장소 경로를 향하거나, 본문에 `open(..., "w")` · `write_text` · `write_bytes` |
| ② 백슬래시 | 명령 문자열에 `\` 가 하나라도 |
| ★**면제** | 대상이 **스크래치패드**뿐이면 통과 · `git` · `grep`/`rg` · 읽기 전용(`sed -n`·`cat`·`head`) |

🚫**읽기·검색·분석은 전혀 안 막힌다.** 막히는 것은 **"백슬래시가 든 쓰기"** 하나다.

### 3.2 거절 메시지 (그대로 인쇄)

```
[hook] 🚫 백슬래시가 든 내용을 Bash 로 파일에 쓰려 한다 — 누적 15회 사고.
       ★Write/Edit 툴을 쓴다. 스크립트가 필요하면 스크래치패드에 Write 로 만들고 python 으로 돌린다.
       (면제가 필요하면 대상 경로를 스크래치패드로 바꾼다)
```

### 3.3 비용과 되돌리기

| | 값 |
|---|---|
| 구현 | ⚙**0.3h** — `.claude/hooks/no_backslash_write.py`(30줄) + `.claude/settings.json` |
| 되돌리기 | ✅**`settings.json` 에서 한 줄 삭제** |
| 사용자가 할 일 | ★**훅을 켜는 것 자체**(세션 설정) — 🚫**AI 가 자기 실행환경 설정을 바꾸지 않는다** |
| 위험 | ⚠️**오탐이 나면 내가 일을 못 한다.** → §5 |

## 4. ✅**이번에 이미 한 것 — 게이트 35(사후 그물)**

훅이 *"쓰기 전"* 이라면 이것은 *"쓴 뒤"* 다. **승인이 필요 없어 먼저 만들었다.**

**`scripts/check_control_chars.py`** — 저장소 텍스트 파일 **816개**를 스캔해
`0x00`~`0x08`·`0x0B`·`0x0C`·`0x0E`~`0x1F` 를 찾는다.

| | |
|---|---|
| 왜 필요했나 | `lint_bat` 규칙 1b 가 같은 것을 보는데 🚫**`.bat` 만** 본다. `.py`·`.md`·`.tsv` 는 **아무도 안 봤다** |
| 면제 | ⚠️**탭(0x09)은 안 본다** — `.tsv` 구분자·`.py` 들여쓰기로 합법. `.bat` 은 `lint_bat` 소관(한 개념 한 검사) |
| ✅검출 확인 | 스크래치패드 사본에 **실사고 바이트**(`scripts`+0x08+`atch`+0x09)를 심어 **exit 1**, 고친 뒤 **exit 0** |
| 현재 | **저장소 816파일에 제어문자 0건** |
| 정적 게이트 | 34종 → ★**35종** |

🚫★**그러나 이것은 훅을 대체하지 않는다.** 게이트는 **내가 돌려야** 보이고,
**돌리기 전에 그 파일로 무언가를 했으면 이미 늦다**(wandb push 가 그랬다).

## 5. 위험 — **훅의 오탐이 유일한 진짜 위험이다**

| 위험 | 크기 | 완화 |
|---|---|---|
| 🚫**정당한 명령이 막힌다** | ⚠️**중간.** 예: Windows 경로가 든 분석 스크립트를 bash 로 돌릴 때 | ★면제 셋(스크래치패드 · 읽기전용 · git). **막히면 Write 툴로 우회하면 되고, 그게 원래 규칙이다** |
| **훅이 조용히 죽는다** | 낮음 | 훅 스크립트가 예외를 삼키면 **통과**시키게 만든다 — 🚫**감시 도구가 작업을 막으면 안 된다** |
| ★**훅을 켜 놓고 잊는다** | 낮음 | 게이트 35 가 **결과**를 보므로 훅이 죽어도 사후에 잡힌다. **두 층이다** |

## 8. 거절하면 못 하는 것

**게이트 35 는 이미 켜져 있으므로 A 류를 "찾는" 능력은 유지된다.**
못 하는 것은 **"쓰기 전에 막는" 것 하나**이고, ⚙그 빈도는 이력으로 **세션당 약 1회**다.
⚠️**그중 파일을 실제로 오염시킨 것은 15회 중 3회**이므로,
🚫**거절해도 재앙은 아니다** — **게이트 35 가 그 3회를 잡는다.**
