> 툴 규칙을 어기지 않도록 하기 위한 스킬 작성 가능한지 제안서 작성바람"*) · **상태** ⏳판단 대기
>
> ★**답 먼저: 🚫스킬로는 못 막는다.** 그리고 그 근거가 이 제안서에서 가장 중요한 부분이다 —

## 2. 🚫★**왜 스킬로는 못 막나 — 이것이 결정적 근거다**

**규칙은 이미 있다. 세 곳에.**

| 어디 | 문구 |
|---|---|
| `CLAUDE.md` | *"★긴 파일·백슬래시는 `Write` 툴로 쓴다"* |
| `ai_dev_tool/06` §도구사고 표 1·2 | *"★본문에 백슬래시를 쓸 일이 있으면 `Write` 툴로 직접 쓴다"* |
| ★**세션 시작 프롬프트**(매 세션 첫 화면) | *"★★긴 파일이나 백슬래시가 든 내용은 Write/Edit 툴로 쓴다 — bash heredoc 에 넣으면 `\b`·`\t` 가 된다"* |

> ★★**즉 사고는 "규칙을 몰라서" 난 것이 아니다.** 규칙이 **컨텍스트 맨 위에 있는 상태에서** 났다.
> **스킬은 텍스트를 한 군데 더 늘리는 것**이고, 🚫**네 번째 사본이 세 번째보다 잘 들을 이유가 없다.**

★**구조적 이유**: 스킬은 **호출될 때** 로드된다. 그런데 이 사고는
*"작은 패치 하나를 빨리 하자"* 는 **흐름 중간**에 난다 — **그 순간 나는 스킬을 부르지 않는다.**
🚫**스킬은 "내가 스킬을 불러야 한다는 것을 아는 경우"에만 작동한다.**

## 3. ✅**막을 수 있는 것 — 훅(hook)**

Claude Code 는 **`PreToolUse` 훅**을 지원한다(`.claude/settings.json`).
훅은 **도구 호출 직전에 실행되고, 비영 종료로 그 호출을 거절**할 수 있다.
★**이것은 내 선택 밖이다** — 그래서 규칙과 다르다.

### 3.1 제안하는 판정식 — ★**A 류만 좁게 겨눈다**

> **Bash 명령이 (①저장소 파일에 쓰고) AND (②본문에 백슬래시가 있으면) → 거절.**

| 조각 | 판정 |
|---|---|
| ① 쓰기 | `>` · `>>` · `tee` 가 저장소 경로를 향하거나, 본문에 `open(..., "w")` · `write_text` · `write_bytes` |
| ② 백슬래시 | 명령 문자열에 `\` 가 하나라도 |
| ★**면제** | 대상이 **스크래치패드**뿐이면 통과 · `git` · `grep`/`rg` · 읽기 전용(`sed -n`·`cat`·`head`) |

🚫**읽기·검색·분석은 전혀 안 막힌다.** 막히는 것은 **"백슬래시가 든 쓰기"** 하나다.

### 3.2 거절 메시지 (그대로 인쇄)

```
[hook] 🚫 백슬래시가 든 내용을 Bash 로 파일에 쓰려 한다 — 누적 15회 사고.
       ★Write/Edit 툴을 쓴다. 스크립트가 필요하면 스크래치패드에 Write 로 만들고 python 으로 돌린다.
       (면제가 필요하면 대상 경로를 스크래치패드로 바꾼다)
```

### 3.3 비용과 되돌리기

| | 값 |
|---|---|
| 구현 | ⚙**0.3h** — `.claude/hooks/no_backslash_write.py`(30줄) + `.claude/settings.json` |
| 되돌리기 | ✅**`settings.json` 에서 한 줄 삭제** |
| 사용자가 할 일 | ★**훅을 켜는 것 자체**(세션 설정) — 🚫**AI 가 자기 실행환경 설정을 바꾸지 않는다** |
| 위험 | ⚠️**오탐이 나면 내가 일을 못 한다.** → §5 |

## 4. ✅**이번에 이미 한 것 — 게이트 35(사후 그물)**

훅이 *"쓰기 전"* 이라면 이것은 *"쓴 뒤"* 다. **승인이 필요 없어 먼저 만들었다.**

## 9. ✅**승인 및 구현** (2026-09-08(3차), 사용자 지시 2E)

> *"승인하되, 백슬래시 훅이 정당한 명령을 막지 않도록 **정당한 명령에 대한 화이트리스트 작성할 것**."*

✅**구현 완료. 그리고 실물에서 차단을 확인했다.**

| 파일 | 무엇 |
|---|---|
| `.claude/hooks/guard_backslash.py` | PreToolUse 훅. 종료코드 **2** = 차단 |
| ★`.claude/hooks/backslash_whitelist.tsv` | **화이트리스트 정본**(사용자 요구) |
| `.claude/settings.json` | 훅 등록(`matcher: Bash\|PowerShell`) |

### 9.1 판정식 — ★**두 조건이 동시에 참일 때만**

1. **쓰기 의도**: heredoc(`<<`) · 파일 리다이렉트(`>`/`>>`) · `tee` · `sed -i` ·
   `Set-Content`/`Out-File`/`Add-Content`
2. **재해석되는 이스케이프**: `\n \t \b \r \f \v \0 \x \u`

🚫**하나만이면 통과**시킨다. 읽기 전용 정규식(`grep '\d+'`)도, 백슬래시 없는 heredoc 도 안 막는다.

### 9.2 ★화이트리스트 — **네 종류**

| 종류 | 예 | 왜 |
|---|---|---|
| `readonly` | `grep` `rg` `sed -n` `cat` `head` `git` `awk` … | 읽기 전용. **정규식 리터럴이 정상**이다 |
| `tool` | `python scripts…` `python run100m.py` | 우리 도구 실행 — **`scripts\x.py` 의 역슬래시가 정상**이다 |
| `path` | 스크래치패드 · `/tmp/` | **저장소가 아니다**(자백 A17 이 여기로 쓰라고 정했다) |
| `escape` | `ALLOW_BACKSLASH_WRITE` | 명시적 예외. 훅이 **크게 인쇄하고** 통과시킨다 |

⚠️★**`readonly` 는 우회로가 아니라 문서다.** 코드에서는 **쓰기 의도 판정이 먼저** 거르므로
그 목록을 굳이 다시 보지 않는다 — 🚫**우회로로 쓰면 `echo "a\nb" > handoff/x.md` 가 통과한다**
(실제로 초판이 그렇게 새어 **미탐 1건**이 났다).

### 9.3 ★★검출 확인 — **미탐 0 / 오탐 0**

실물 표본으로 쟀다(스크래치패드 시험, 저장소에 파일 안 만들었다 — 자백 A17):

| 묶음 | 표본 | 결과 |
|---|---:|---|
| **막아야 하는 것**(전부 **실제 사고 형태**) | 4 | ★**미탐 0** |
| **통과해야 하는 것**(전부 **이 세션에서 실제로 돌린 명령**) | 11 | ★**오탐 0** |

★**초판에서 실제로 둘이 걸렸고 둘 다 고쳤다** — 게이트를 실물에 대고 확인하는 규약이 값을 했다:

| # | 결함 | 고침 |
|---|---|---|
| **미탐 1** | `echo "a\nb" > handoff/x.md` — 리다이렉트 정규식의 lookbehind 가 `(?<![0-9\s])` 라 **공백 뒤 `>` 를 놓쳤다** | 숫자만 배제 |
| **오탐 1** | 스크래치패드 쓰기 — 화이트리스트 경로가 `\` 인데 명령은 `/` 였다 | 양쪽 **슬래시 정규화** |
| ★**추가 오탐 회피** | 문자군에 `\\` 를 넣었더니 **마크다운 표의 `\|` 를 담은 `"\\|"`** 가 걸렸다 | `\\` 를 **뺐다** — 빼도 `\\n` 은 두 번째 백슬래시가 `n` 과 짝을 이뤄 여전히 잡힌다 |

### 9.4 ★★★배선 확인 — **이번에는 처음 돌 때 안 죽었다**

3세션 연속 *"신설 이래 0회 실행"* 을 끊기 위해 **훅을 붙인 직후 실물로 시험**했다:

    sed -i 's/x/\t/' _hook_wiring_probe_does_not_exist.txt
    → PreToolUse:Bash hook error: 🚫★★ 백슬래시 훅 — 이 명령을 막았다

✅**차단됐다.** 🚫**그리고 첫 시도에서 메시지가 통째로 깨져 있었다**(Windows cp949) —
★**환경변수에 기대지 않고 훅이 스스로 `sys.stderr.reconfigure(encoding="utf-8")`** 하도록 고친 뒤
**두 번째 시도에서 한글이 제대로** 나왔다.

> ★★**교훈**: *"훅이 돈다"* 와 *"훅의 말이 읽힌다"* 는 **다른 것**이다.
> 차단 메시지를 못 읽으면 **왜 막혔는지 모르는 채 우회**하게 되고, 그러면 훅이 없는 것보다 나쁘다.

### 9.5 ⚠️한계 — **넷**

1. 🚫★**셸만 본다.** `Write`/`Edit` 툴은 애초에 안전하므로 대상이 아니다.
2. ⚠️**정당한 셸 쓰기를 막을 수 있다.** 그때는 **Write/Edit 로 바꾸는 것이 정답**이고,
   정말 아니면 `ALLOW_BACKSLASH_WRITE` 를 쓴다(훅이 **경고를 인쇄**한다).
3. 🚫★**보안이 아니다.** 훅도 `settings.json` 도 내가 볼 수 있는 파일이다 —
   ★**"실수로 넘지 않게" 하는 장치**이지 강제가 아니다.
4. ⚠️**`\\\\`(이스케이프된 백슬래시)는 안 잡는다.** 문자군에서 `\\` 를 뺀 대가이고,
   **오탐을 없애려고 치른 값**이다.

### 9.6 ★사고 이력 갱신 — **16회째가 이 세션에 났다**

이 훅을 만든 그 세션에, **훅을 만들기 전에** 났다:

    python - <<'PY' … s += 'print(f"\\n …")' … io.open('scripts/diag_lrm_values.py','w').write(s)
