# TinyLM 연구 색인과 위키

저장소 루트에서 `python3 -m scripts.research_catalog`를 사용한다. 사용자용 예시와 어휘 관리 방법은 [연구 위키](../../../docs/research_wiki/README.md)에 있다.

- 정확한 실행 태그는 그대로 `search`에 넣고, 필요한 경우 `--kind result`나 `--project P109`를 쓴다. 계획과 결과의 목록은 `wiki P109`, 원문 인용 관계는 `related 저장소상대경로#앵커`로 조회한다.
- 찾은 절은 `show 저장소상대경로#앵커` 또는 `show 저장소상대경로:줄번호`로 읽는다. `--lines`로 읽을 범위를 좁히고, JSON 출력의 `next_line`에서 이어 읽는다. 원문이 바뀌면 `show`가 현재 파일에서 앵커를 다시 찾는다.
- 같은 조건의 수치가 필요하면 `--claim`·`--dataset`·`--tokenizer`로 좁힌 뒤 반환된 절에서 비교군의 풀, 초기화, 토큰과 채점 경로를 확인한다. 실행 상태와 채택 판정은 열린 원장과 결과 정본에서 확인한다.
- 링크에 갱신 필요가 표시되면 최신 원문 위치를 확인한다. 쓰기가 범위에 있으면 `refresh`로 색인을 갱신할 수 있다. 읽기 전용 작업에서는 기존 색인과 `rg`를 사용한다. 보호 자산은 기존 규약을 따른다.
- 요청된 변경은 해당 사실을 소유한 계획·결과·원장에 먼저 반영한다. 위키에는 판단 근거와 원문 링크를 남긴다. 위키나 정본을 갱신했으면 `refresh` 뒤 변경한 항목을 실제로 조회한다.
