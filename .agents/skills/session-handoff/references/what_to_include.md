# TinyLM 핸드오프 포함 기준

정본은 `ai_dev_tool/Codex/02_핸드오프_규약.md`다. 핵심 질문은
"이 항목이 없으면 다음 세션이 상태·권한·증거를 잘못 판단하는가?"이다.

## 반드시 포함

- 사용자 지시 원문과 AI가 이해한 목적
- 필요했던 작업과 실제 수행 사이의 차이
- 완료·진행·보류·미실행 상태 및 근거 경로
- 새로 확인한 수치의 이름, 조건, 단일 소스
- 뒤집힌 판정과 대체 정본
- 열린 질문과 재개 첫 행동
- 사용자에게 부탁하는 실행·삭제·기타 항목; 없으면 없다고 명시
- `-done` 배치 삭제 가능 여부와 3조건 근거
- 권장 실험의 id·시간·누적·선결·한 줄 근거
- 한국어 커밋 제목/본문, 시작 프롬프트, compact 프롬프트, 치트시트

## 링크로만 두기

- 영구 규범: `AGENTS.md`와 Codex 00~08
- 연구 수치: 결과문서, `docs/EXPERIMENT_BASELINES.md`, `handoff/COMPASS.md`
- 구현검증 항목: 루트 `ai_dev_tool/09_구현검증_필요목록.md`
- 이전 세션: 최신 유효 핸드오프의 이전 링크

## 쓰지 않기

- 일반적인 프레임워크 상식이나 프로젝트 전체 소개 복제
- 활동만 나열한 성과 보고
- 근거 없는 완료·통과 선언
- 사용자가 요청하지 않은 PR·branch 계획
- WIP 또는 루트 09의 전문 사본
- 실행하지 않은 GPU·스모크·E2E를 완료로 승격한 문구
