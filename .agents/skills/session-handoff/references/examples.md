# TinyLM 핸드오프 최소 예시

아래는 문장 밀도 예시일 뿐 파일 골격이 아니다. 실제 골격은 `scripts/new_handoff.py`로 만든다.

## §0 예시

| # | 사용자가 지시한 것 | 목적 | 필요했던 작업 | 실제로 한 것 | 결과 |
|---:|---|---|---|---|---|
| 1 | P3·P4·P6 착수 | Codex 환경 분리 | 설정·스킬·진입 규범 이식 | 대상 파일만 수정 | P7·P8 NOT_RUN |

## 상태 예시

- `STATIC_ONLY`: JSON/TOML 구문만 확인했고 새 세션 로딩은 확인하지 않음
- `E2E_NOT_RUN`: 깨끗한 Codex 세션에서 스킬 발견·라우팅을 아직 관찰하지 않음
- `NOT_RUN`: GPU, 학습, 모델 로딩, 프로젝트 스모크를 실행하지 않음

## 사용자 부탁 예시

- 이번에는 실행을 부탁할 항목이 없다.
- 삭제 가능한 `-done` 배치 없음. 삭제는 수행하지 않았다.

## 좋은 재개 지시

1. `AGENTS.md`와 `ai_dev_tool/Codex/README.md`를 읽는다.
2. 본 핸드오프의 열린 질문과 사용자 부탁 절을 확인한다.
3. 완료되지 않은 WIP가 있으면 그 항목만 이어간다.
4. 보호 경로와 `NOT_RUN` 상태를 유지한다.

경로 없는 "관련 문서 확인", 근거 없는 "완료", 영구 규범 전문 복사는 쓰지 않는다.
