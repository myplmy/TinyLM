# TinyLM 핸드오프 템플릿 표지

이 파일은 복사해서 쓰는 별도 템플릿이 아니다. 핸드오프 골격의 단일 생성 정본은
저장소 `scripts/new_handoff.py`, 형식 정본은 `ai_dev_tool/Codex/02_핸드오프_규약.md`다.

```powershell
python scripts/new_handoff.py --title "<이 세션이 남긴 것 한 줄>"
```

생성된 골격에서 다음 계약을 지킨다.

- 사용자 지시·목적·필요 작업·실제 작업·결과를 분리
- 사용자 부탁 절과 `-done` 삭제 판정을 비워 두지 않음
- 권장 실험 표 8열 유지
- 한국어 커밋 제목/본문 분리
- 열린 질문, 시작 프롬프트, compact 프롬프트, 치트시트 포함
- 계획·정적·실행·E2E의 `NOT_RUN` 상태 보존

범용 세션 양식이나 다른 에이전트 환경 템플릿을 fallback으로 사용하지 않는다.
