# P070 — **재귀 통과에서 MLP 그룹을 섞으면 품질이 오르는가**

- **상태**: ⏸**설계·구현 선결.** 배치 없음
- **신설**: 2026-08-22 (사용자 제안)
- **선행**: [P062 §12](P062_재귀추론과-재귀학습-추론-정합.md)(무KD 재귀 −0.0203) · [P062 §단계2](P062_재귀추론과-재귀학습-추론-정합.md)(`where` 축)
- **근거 결과**: [047 §12](../test_result/047_20260814_P062-단계0-스케줄을-맞추니-0.2427이-돌아왔다.md) · [041 §17](../test_result/041_20260813_P049-깊이가-산것은-MLP고-어텐션은-꺼졌다.md)

## 1. ★★왜 이것이 말이 되는가 — **우리 실측 셋이 가리킨다**

| 관측 | 출처 | 함의 |
|---|---|---|
| ★**재귀가 메모리 0 증가로 −0.0203** | 047 §12 | **같은 가중치를 더 쓰면 좋아진다** |
| ★★**복제층 어텐션 출력이 cos 0.9882** | 041 §17 | ★**두 번째 통과가 "거의 같은 일" 을 한다** — **낭비다** |
| ★**타잉이면 유니크 MLP 가 6개뿐** | `m100R1c` | **순서를 바꿀 자유도가 있다** |

> ★★★**논리**: 재귀가 이득을 주는데 **두 번째 통과가 첫 통과와 거의 같은 것을 계산**한다면,
> **두 번째 통과에서 다른 MLP 를 만나게 하면 더 벌 수 있다**는 것이 이 계획의 가설이다.
>
> ⚠️★**그런데 반대 논리도 있다** — **잔차 스트림은 층 순서에 맞춰 학습된다.**
> 순서를 섞으면 **각 MLP 가 "자기가 보던 분포" 를 못 본다.** **어느 쪽이 이기는지가 질문**이다.

## 2. ★★셔플이 무엇을 뜻하는가 — **정의를 먼저 못 박는다**

`m100R1c` 중간 16층은 `mid_mlps[j // 8]` 로 **MLP 2개**를 나눠 쓴다(g8).
`m100R1d`(g16)는 **MLP 1개**를 16층이 쓴다.

★★**그래서 "MLP 를 섞는다" 는 g 에 따라 뜻이 다르다.**

| 프리셋 | 유니크 중간 MLP | 셔플 가능? |
|---|---:|---|
| `m100R1c`(g8, 16층) | **2** | ⚠️**2개뿐이라 순열이 2가지**(항등·교환) |
| `m100R1p`(g8, 16층, p1c1) | 2 | 동 |
| ★**`m100R1d`(g16, 32층)** | ★**1** | 🚫**섞을 것이 없다** |
| ⏸ `mlp_group 4` (16층) | **4** | ✅**순열 24가지** — ★**셔플이 의미를 갖는 최소 조건** |

> 🚫★★**현 표준 프리셋에서는 셔플이 거의 성립하지 않는다.**
> **g8 은 MLP 가 2개**라 *"두 번째 통과에서 순서를 뒤집는다"* 밖에 없고,
> **g16 은 1개**라 **아예 불가능**하다.
> → ★**셔플을 재려면 `mlp_group` 을 내려야 하고, 그러면 메모리가 는다** — **교락이다.**

### 2.1 ★그래서 무엇을 섞는가 — **층 순서다, MLP 가 아니다**

★**정확한 정의**: 재귀의 **두 번째 통과에서 중간 층 방문 순서를 바꾼다.**
가중치가 아니라 **스케줄**을 섞는다. `visit_schedule()` 이 내는 리스트의 순서다.

```
uniform  : [p..p+m) + [p..p+m)                 # 현재
reverse  : [p..p+m) + reversed([p..p+m))       # ★두 번째를 역순
stride   : [p..p+m) + [짝수층…, 홀수층…]        # ★그룹 경계를 흐트린다
random   : [p..p+m) + shuffle(고정 시드)        # ★대조군(무작위)
```

★★**`reverse` 가 가장 자연스럽다** — **정보가 위→아래로 한 번, 아래→위로 한 번** 지난다.
**구현이 가장 싸고**(⚙10줄) **결정적**이다.

## 3. ★기준 모델 선정 이유

**기준 = `mC_r20_nokd`**(`uniform`, 무KD, @R2 **3.6573**).
★**이미 −0.0203 을 번 점**이고, **셔플이 그 위에 더 얹는지**가 질문이다.
🚫**`mC_initonly` 를 기준으로 쓰면 "재귀 이득 + 셔플 이득" 이 섞인다.**

## 4. ★대조군 조건 차이

| 태그 | 두 번째 통과 순서 | 기준과의 차이 |
|---|---|---|
| `mC_r20_nokd`(존재) | 정순 | — |
| ★**`mC_r20rev_nokd`** | ★**역순** | **1개** |
| ⏸ `mC_r20str_nokd` | stride 2 | 1개 |
| ⏸ `mC_r20rnd_nokd` | 고정시드 무작위 | ★**대조군** — *"순서가 중요한가, 아니면 아무 순서나 좋은가"* |

⚠️★★**`random` 대조군이 핵심이다.** `reverse` 가 이겨도 **무작위도 같이 이기면
"순서를 바꾸는 것 자체" 가 이득**이고, **무작위는 지고 역순만 이기면 "역순" 이 이득**이다.
🚫**대조군 없이 `reverse` 만 재면 결과 041 §17 에서 겪은 것과 같은 오독**을 한다.

## 5. ★예측 — 결과 전에 못 박는다

| # | 예측 | 근거 | 실패하면 |
|---|---|---|---|
| ★**U1** | `reverse` 가 `uniform` 과 **±0.010 안** | 잔차 스트림이 순서에 맞춰 학습됐다 | ★**−0.010 을 넘어 이기면 셔플 축이 열린다** |
| **U2** | `random` 이 `reverse` 보다 **나쁘다** | 무작위는 학습·추론 짝을 맞춰도 구조가 없다 | 같으면 ★**"순서는 아무래도 좋다"** |
| ★**U3** | 메모리·packed·상주 **완전히 동일** | 스케줄만 바꾼다 | 다르면 회계 오류 |
| **U4** | 벽시계 동일 | 층 통과 수가 같다 | |

★**U1 을 "±0.010 안" 으로 예측하는 이유**: 041 §17 이 **복제층 어텐션 출력이 cos 0.9882** 라고
했으니 **두 번째 통과의 입력이 첫 통과와 비슷**하다. **비슷한 입력에 어느 MLP 를 주든 비슷**할 것이다.
🚫**그러면 이 축은 닫힌다** — 그리고 **그것도 결과다.**

## 6. 🚫이 계획이 결정하지 못하는 것

- ★**`mlp_group` 을 내렸을 때의 셔플** — **메모리와 교락**된다(§2). 별도 실험이다.
- **최적 순열** — 4개 후보만 본다. **순열 공간을 탐색하지 않는다.**
- ⚠️**추론 전용 셔플** — 학습·추론 짝을 맞춰야 한다(함정 39). **한쪽만 바꾸지 않는다.**

## 7. ⚠️선결 — **구현. 배치를 만들지 않았다**

| # | 필요한 것 | ⚙규모 |
|---|---|---:|
| 1 | `--repeat-order {forward,reverse,stride,random}` — 학습·추론 **양쪽** | **약 30줄** |
| 2 | ★**스모크 팔 `sm_rorder`** — 그 경로가 실제로 도는지(함정 37) | 약 10줄 |
| 3 | `paired_eval` 에 `--repeat-order` 배관 | 약 10줄 |

⚙**합 약 50줄.** ★**선결은 구현 하나뿐이고 실험 선결은 없다.**
⚠️★**착수는 사용자 허가가 있을 때만**(D16 규칙 B). **이 문서는 "가능한가" 를 검토한 것**이다.

## 8. ★검토 결론 — **가능하다. 단 값어치는 낮아 보인다**

| 질문 | 답 |
|---|---|
| 구현 가능한가 | ✅**가능. ⚙50줄** |
| 현 프리셋에서 의미가 있나 | ⚠️★**제한적** — g8 은 MLP 2개, g16 은 1개다(§2) |
| ★**무엇을 섞는 것이 옳은가** | ★**MLP 가 아니라 층 방문 순서**(§2.1) |
| 이길 것 같은가 | 🚫★**아니다**(U1) — 041 §17 의 cos 0.9882 가 근거 |
| ★**그래도 할 값어치** | ⚠️**있다. 단 우선순위는 낮다** — **U2(무작위 대조군)가 "순서가 축인가" 를 한 번에 닫는다** |

> ★**권고: P062 단계2(`inplace`)를 먼저 본다.** 그것이 **"순서가 실재하는 축인가" 를
> 더 싸게**(구현 완료, 학습 1런) 답한다. **T1 이 ±0.010 안이면 이 계획은 착수하지 않는다.**
