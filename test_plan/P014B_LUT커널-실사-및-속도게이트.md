## 1. 왜 — 우리가 반복해 온 실수를 여기서 안 하려고

이번 세션에만 **같은 실수를 두 번** 했다(결과 016 §13·§14): **설계를 덜 마치고 구현부터 했고,
대조군이 아니었으면 둘 다 이득으로 기록될 뻔했다.**

P014 는 그보다 훨씬 비싸다 — 외부 C++ 의존, 포맷 변환, 플랫폼 빌드. 그래서 **먼저 잰다.**

### 1.1 아직 모르는 것 세 가지 (이게 게이트다)

| # | 미지 | 왜 치명적인가 |
|---|---|---|
| **U1** | **우리 모델 크기(dim 768)에서 LUT 가 이득인가** | 논문들은 **3B급(dim 2560+)** 에서 잰다. LUT 는 **표 구축 비용을 재사용으로 상각**하는데, 작은 행렬은 재사용 기회가 적다. **이득이 0 이거나 음수일 수 있다** |
| **U2** | **`micro_group=128` 그룹 스케일을 커널이 받는가** | BitNet b1.58 원형은 **텐서 단위 absmean** 스케일이다. 커널이 그룹 스케일을 모르면 α 를 **밖에서** 곱해야 하고, 그게 또 하나의 fp32 순회가 된다 |
| **U3** | **활성값 int8 을 요구하는가** | 요구하면 **정확도 영향**이 생긴다. 지금 우리 int8 경로는 로짓 게이트 `0.000e+00` 인 **무손실**인데 그 성질을 잃는다 |

**셋 중 하나라도 부정이면 P014 의 비용-이득이 뒤집힌다.**

## 3. ★예측 — 정직하게

| # | 예측 | 근거 | 틀리면 |
|---|---|---|---|
| P1 | **`mC` int8 16.1 → 25~40 tok/s (1.5~2.5×)** | 결과 014 §11 분해: 언팩이 층당 약 2ms × 20층 = 40ms 를 62.3ms 중에서 차지. 고정비 4.2ms 는 안 줄어든다 | **6.17× 가 나오면 우리 계측을 의심한다** — 그건 3B·전정밀 기준 숫자다 |
| P2 | **U2 는 부정일 가능성이 높다** | BitNet 원형이 텐서 스케일이다 | 그룹 스케일을 받으면 통합이 훨씬 쉬워진다 |
| P3 | **U1 이 가장 위험하다** | 표 구축은 활성값당 고정비, 재사용은 행렬 폭에 비례. dim 768 은 3B 의 1/3.3 | 이득이 크면 P014 즉시 진행 |

> **★P1 을 계획서와 배치 양쪽에 적어 둔다.** 그래야 결과가 나왔을 때
> "예상대로" 로 뭉개지지 않는다. **그리고 "몇 배" 를 인용할 때는 항상 기준선을 함께 적는다.**

#### 0.B AI 가 U1~U4 를 받으면 하는 일

1. **U2 판정** — I2_S 의 "Scale" 이 **텐서 단위인가 그룹 단위인가**.
   우리는 `micro_group=128` 이다. 다르면 **α 를 밖에서 곱해야 하고 이득이 깎인다**
2. **U3 판정** — TL/I2_S 가 **활성값 int8 을 요구**하는가. 요구하면 우리 무손실 성질을 잃는다
3. **가중치 포맷** — GGUF 변형인가 자체인가 → 단계1 변환기의 난이도가 정해진다
4. **라이선스** — 우리 저장소에 넣을 수 있는가(넣을 필요가 없을 수도 있다 — 안 A 는 외부 실행)
5. **커널 호출 인터페이스** — C API 로 노출되는가, llama.cpp 내부 전용인가
   → **안 B(PyTorch custom op)의 가능 여부**가 여기서 갈린다
6. 결과를 **`docs/methods/08_paper_review_202608.md` §5 에 근거 링크와 함께** 갱신하고
   **§5.2 의 "확인 필요" 표를 확정 표로** 바꾼다

### 단계 1 — **포맷 변환기** ⏸ 단계0 통과 후 · GPU 0 · 구현 소~중

우리 체크포인트 → 그쪽 포맷. **읽기 전용 내보내기이고 `tinylm/` 을 건드리지 않는다.**

- `scripts/export_ternary.py`(신설 예정): `TLinear._i8`(int8 코드) + `_alpha`(g128) 를 내보낸다
- **U2 가 부정이면** 여기서 **α 를 텐서 단위로 재계산**해야 하고, 그건 **가중치를 바꾸는 것**이다
  → **로짓 동등성이 깨진다** → 그 경우 **품질 재검증이 별도로 필요**하다(비용 증가)
- **게이트 G1**: 변환 후 **같은 프롬프트에서 로짓/출력이 우리 PyTorch 경로와 일치**하는가.
  ⚠️ U2 가 부정이면 완전 일치는 불가능하므로 **허용 오차를 미리 정한다**
