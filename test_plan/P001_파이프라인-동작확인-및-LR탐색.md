# 실험계획 P001 — 파이프라인 동작확인 + 자동 LR 탐색

## 목적
- 코드/데이터/학습 파이프라인이 오류 없이 도는지 확인(품질 판정 아님).
- 본 실행에 쓸 LR을 발산 없이 안전하게 확정.

## 아키텍처
- `tiny` 프리셋(d=256, 1+4+1, g2, cla2) — 파이프라인 확인용.
- `m100` 프리셋 — LR 탐색용(본 실행과 동일 구조).

## 실행

```cmd
:: (1) 파이프라인 동작확인 — 합성·컴파일, 수 분
python run100m.py all --tiny --data synthetic --tokens 2M --steps 40 ^
    --micro-bs 4 --seq 128 --accum 2 --eval-every 20 --compile

:: (2) 자동 LR 탐색 (range test 기본 + grid 고급)
python run100m.py lrfind --arch tied --data ko-en --tokens 50M --method both
```

## 판정/산출
- NaN·`[skip]` 없이 완주하면 파이프라인 정상.
- lrfind: `|g|`가 10을 넘지 않고 loss 단조감소하는 가장 큰 LR 채택.
  (실측: range test 발산 ~1.7e-3 → 권장 5.6e-4, 실런 검증으로 **1e-3** 채택.)

## 비고
- 합성 데이터는 순수 암기 과제라 품질 판정 불가(파이프라인 전용).
- `--compile-mode reduce-overhead`는 임베딩 타잉과 충돌 → `default` 사용.
