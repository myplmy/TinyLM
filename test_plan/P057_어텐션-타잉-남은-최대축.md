## 1. 왜 — **삼진의 48.4% 를 한 번도 안 묶었다**

| `mC_wsd` 삼진 54.85M | |
|---|---:|
| MLP | 28.31M (51.6%) |
| ★**어텐션** | ★**26.54M (48.4%)** |

**MLP 축은 소진됐다** — P045 가 g16 에서 종결(−4.7M, +0.0161), P048 이 prelude/coda 로 −12.1M.
**둘 다 MLP 쪽이다.** 어텐션은 `mlp_group` 을 아무리 키워도 **안 줄어든다** — 층마다 독립이기 때문이다.

### 1.1 문헌 근거

**MobileLLM**([`2402.14905`](https://arxiv.org/abs/2402.14905), ✅조회):
*"immediate **block-wise weight-sharing**, **no increase in model size** and only marginal
latency overhead"* → **125M/350M 에서 +0.7%/+0.8%**. ★**우리 규모와 같다.**

**ALBERT**([`1909.11942`](https://arxiv.org/abs/1909.11942), ✅조회): cross-layer parameter
sharing. ★우리는 그 논문의 **두 기법 중 factorized embedding 만** 쓰고 있다.

**외부 검토문서 E §9** 도 *"Full-block sharing 전에 **Attention-only sharing ablation 을
반드시 권장**"* 이라 적었다 — **우리 REVIEW2 와 독립적으로 같은 지점을 지목**했다.

# §N. ★선결 해소 (2026-08-13) — **그룹평균 어텐션 이식 구현 완료**

## N.1 무엇이 막고 있었나

`init_from_dense` 가 층마다 `ls.attn_mod ← lt.attn_mod` 로 복사하는데,
`attn_group > 1` 이면 **여러 학생 층이 같은 어텐션 객체**를 본다.
→ **마지막 교사 층 값만 남고 앞의 복사가 조용히 덮인다.** 예외도 경고도 없었다.

그래서 2026-08-13 에 **`NotImplementedError` 가드**를 세워 두었었다.

## N.2 ★구현 (파일 diff 확인함)

`tinylm/train/init_utils.py` — 가드를 **그룹평균 이식으로 대체**했다.

```python
for j, at_s in enumerate(student.mid_attns):
    s_mids   = list(range(j * ag, (j + 1) * ag))
    members  = [teacher.layers[lmap[sc.n_prelude + k]].attn_mod for k in s_mids]
    for nm in ["q_proj", "o_proj"] + (["k_proj","v_proj"] if at_s.owns_kv else []):
        getattr(at_s, nm).weight.data.copy_(
            sum(getattr(mm, nm).weight.data for mm in members) / len(members))
```

| 설계 결정 | 이유 |
|---|---|
| ★**`mid_mlps` 와 같은 규약**(그룹 평균) | 코드가 대칭이라 **규약이 하나로 유지**된다. 함정 28(같은 단어가 다른 규약)의 예방 |
| **잔여 파라미터도 평균**(q/k norm 등) | 빠뜨리면 **조용히 난수로 남는다.** 교사에 없으면 **크게 알린다** |
| `shared_done` 집합으로 **재복사 차단** | 뒤의 층별 루프가 평균을 덮지 않게 |
| ★**`attn_group=1` 은 비트 동일** | `shared_done` 이 빈 집합 → 종전 경로가 그대로 돈다 |

## N.3 ⚠️ **평균이 옳다는 보장은 없다**

MLP 에서는 실측으로 부모초기화 이득이 살아남았다(결과 030 §2: step0 **7.7742** vs 난수 10.4051).
**어텐션은 아직 안 쟀다.** 어텐션은 MLP 와 달리 **위치별 패턴이 층마다 크게 다를** 수 있어
평균이 훨씬 나쁠 가능성이 있다.

★**단계0 게이트가 그것을 잰다.** 통과선 = **step0 CE 대역 5.0 ~ 9.3972**(함정 34).

> 그리고 어텐션은 **P057 이 지우려는 바로 그 항목**이다.
> **두 축은 경쟁이 아니라 상보다.**

## ⚙계산 — **결합하면 기준선보다 작아질 수 있다**

`상주(fp32) = 유니크삼진 × 8B + 약 33.2 MiB` (결과 016 실측식)

## ⚠️이 단계가 답하지 않는 것

  단계1 에서 **`cla_group=1` 대조가 필요**하다(원래 P057 이 적어 둔 유보 그대로)
- **속도** — 어텐션을 공유해도 **forward 는 전 층을 지난다**(타잉의 성질). 연산은 안 준다
