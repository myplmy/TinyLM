# 실험계획 P007 — 토큰 스윕 (100/300/600M) 격차·품질 곡선

## 목적
학습 토큰 예산에 따른 (a) **dense vs tied 격차** 변화, (b) **절대 품질(val loss·bpb)** 곡선을 그려
**수확 체감 지점**과 "300M이 충분한가"를 규명한다. 향후 스케일 실험의 토큰 예산 결정 근거.

## 아키텍처
- `m100` (v5) 고정. 각 토큰 예산마다 **자체 dense 기준선 + tied** (+ 선택 KD).
- **주의**: 예산이 다르면 baseline도 달라 직접 비교 불가 → 예산별로 dense를 따로 학습해야 공정.
  300M은 **기존 결과 재사용**(m100_ko-en_300M_dense/t_base).

## 실행
```cmd
:: 100M (신규 dense+tied). 600M도 동일 패턴(재토큰화 1회).
python run100m.py all --data ko-en --tokens 100M --steps 763  --micro-bs 8 --seq 1024 --accum 16 --lr 1e-3 --eval-every 100 --compile
python run100m.py train --arch tied --data ko-en --tokens 100M --steps 763 --micro-bs 8 --seq 1024 --accum 16 --lr 1e-3 --eval-every 100 --compile --ema 0.999 --init-from --kd --tag t_kdinit
python run100m.py all --data ko-en --tokens 600M --steps 4578 --micro-bs 8 --seq 1024 --accum 16 --lr 1e-3 --eval-every 100 --compile
python run100m.py train --arch tied --data ko-en --tokens 600M --steps 4578 --micro-bs 8 --seq 1024 --accum 16 --lr 1e-3 --eval-every 100 --compile --ema 0.999 --init-from --kd --tag t_kdinit

:: 300M 은 기존 재사용 → compare 만
python run100m.py compare --tag m100_ko-en_100M_dense --vs m100_ko-en_100M_t_base
python run100m.py compare --tag m100_ko-en_100M_dense --vs m100_ko-en_100M_t_kdinit
python run100m.py compare --tag m100_ko-en_300M_dense --vs m100_ko-en_300M_t_base
python run100m.py compare --tag m100_ko-en_300M_dense --vs m100_ko-en_300M_t_kdinit
python run100m.py compare --tag m100_ko-en_600M_dense --vs m100_ko-en_600M_t_base
python run100m.py compare --tag m100_ko-en_600M_dense --vs m100_ko-en_600M_t_kdinit
```
(steps ≈ tokens / 131072. 100M→763, 300M→2289, 600M→4578.)

## 측정·판정
- 각 예산에서 **dense val, tied val, 격차, bpb, |g|max** 기록 → 토큰수 대비 플롯.
- 확인점: ① 격차가 토큰↑에서 줄어드는가(undertraining 가설), ② 절대 val의 기울기(수확 체감),
  ③ KD가 각 예산에서 격차를 닫는가(선택: tied에 --init-from --kd 추가 라인).
- **정본 300M 비교선은 불변**(기존 모델 유효). 100/600M은 별도 라인(스케일별 이름으로 공존).

## 비고
- 시간: 100M ≈ 0.5h, 600M ≈ 3h/모델. 600M은 캐시 재토큰화 1회.
- LR 고정(1e-3) — 예산이 커지면 warmup/스케줄 상수는 steps 비례라 자동 조정됨.
