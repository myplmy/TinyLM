## 3. ★★측정 설계 — **여섯 지도**

### 3.1 U1 — 층↔층 **출력 유사도 행렬**

각 층 `i` 의 **출력 델타** `d_i = x_{i+1} − x_i` (잔차에 실제로 더해진 것)를 모으고
`cos(d_i, d_j)` 를 **n×n** 으로 낸다.

★★**왜 `x` 가 아니라 `d`(델타)인가**: 잔차 스트림 `x` 는 층을 지나며 **거의 안 변한다**
(그것이 잔차의 성질이다) → `cos(x_i, x_j)` 는 **전부 0.99 가 나와 아무 정보가 없다.**
★**층이 한 일은 델타**다. **P049 의 cos 0.9882 도 델타 기준**이었다.

### 3.2 U2 — **층별 기여도**(ablation)

층 `i` 의 게이트를 **0 으로** 하고 full-val 손실 변화 `Δ_i` 를 잰다.

| | |
|---|---|
| ★**정의** | *"영향력이 큰 층"* = **빼면 손실이 많이 오르는 층** |
| ⚠️**한계** | **한 층씩만** 뺀다. 층은 상호작용하므로 **Δ 의 합 ≠ 전부 뺀 값** |
| ✅**그래도** | ★**순위**는 신뢰할 수 있고, 그것이 우리가 필요한 것이다 |

### 3.3 U3 — 잔차 노름 `‖x_i‖` 와 **상대 기여** `‖d_i‖ / ‖x_i‖`

### 3.4 ★U4 — **입력 유사도 vs 출력 유사도**를 함께

| 쌍 | 뜻 |
|---|---|
| `cos(in_i, in_j)` **높고** `cos(d_i, d_j)` **높음** | ★**같은 입력에 같은 일** → **묶어도 된다** |
| `cos(in_i, in_j)` **높고** `cos(d_i, d_j)` **낮음** | ★★**같은 입력에 다른 일** → **묶으면 안 된다** |
| `cos(in_i, in_j)` **낮고** `cos(d_i, d_j)` **높음** | ⚠️**다른 입력에 비슷한 결과** — 함수가 둔감하다 |

★★★**P049 의 오독이 여기서 풀린다**(§5.1).

### 3.5 U5 — 어텐션 확률 행렬의 **JS divergence**(층 쌍)

### 3.6 ★U6 — **재귀 통과별** 기여도

`mC_r20_nokd` 를 R=2 로 돌리면 층 방문이 36회다. **각 방문의 `‖d‖` 와 ablation Δ** 를 낸다.
★**질문**: *"2회차 통과의 기여가 1회차의 몇 %인가."*

## 4. ★★판정 기준 — **사전 고정**

| # | 게이트 | 기준 | 왜 이 값인가 |
|---|---|---|---|

## 5. ★★예측 — **결과 전에 못 박는다**

| # | 예측 | 근거 | 틀리면 |
|---|---|---|---|
| ★★**V1** | ★**U4 에서 "같은 입력·다른 일" 패턴이 나온다** — 재귀 복제층이 `cos(in) > 0.98` 이면서 `cos(d) < 0.9` | ★**P049 가 +0.0281 로 실패한 것이 그 증거**다. cos 0.9882 는 **출력 방향**만이고 **크기·잔여 성분**이 다르다 | ★**둘 다 0.99 면 "대체 가능한데 왜 나빠졌나" 가 새 미스터리**가 된다 |
| ★**V2** | **앞쪽 중간층이 뒤쪽보다 기여가 크다**(U2) | 잔차 노름이 커질수록 상대 기여가 준다(U3) | **뒤가 크면 coda 를 늘리는 것이 답**일 수 있다 |
| ★**V3** | ★**타잉 그룹 경계가 최적이 아니다**(M3 실패) | 그룹은 `j // g` 로 **기계적으로** 나눴다 — 유사도를 본 적이 없다 | ★**M3 통과면 균등 분할이 우연히 옳았던 것** |
| **V4** | `dense` 의 층간 cos 도 **0.3~0.6 으로 꽤 높다** | 잔차망은 원래 층이 비슷한 일을 한다 | 낮으면 **타잉이 유사도를 만든 것** |
| ⚠️**V5** | **U6 에서 2회차 기여가 1회차의 40~60%** | 재귀가 −0.0202 를 벌었으니 0 은 아니다 | 0 에 가까우면 재귀 이득이 **다른 데서** 온다 |
