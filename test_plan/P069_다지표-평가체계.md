## 1. ★★결과 050 이 정한 설계 제약 두 개

### 1.1 🚫**외부 지표로 서열을 매기지 않는다**

| 지표 | 필요 N(0.01 을 재려면) | 가용 |
|---|---:|---:|
| KorQuAD 정답 CE | **244,040** | 5,774 |
| YNAT 정확도 | — | **시드 노이즈 3~5%p 가 모델 차 9%p 를 잡아먹는다** |

> ★★**병목은 문항이 아니라 학습 시드다.** 시드를 늘리는 비용은 **런당 1.8h** 다.
> → ★**전략: "서열" 대신 "방향이 다른가" 만 본다.** 그건 시드 2개로도 볼 수 있다.

### 1.2 ★**우리 val 이 압도적으로 좋은 자다**

1464 크롭 · paired · **SE 0.0005**. **외부 벤치마크는 근처도 못 간다.**
→ ★**외부 지표의 역할은 val 을 대체하는 것이 아니라 *보완*하는 것**이다:
**val 이 안 보는 축(상식·물리·대명사·장거리 문맥)에서 무너지는지 확인**.

## 4. ★단계 설계

### 단계0-a — **데이터·규약 확인**(학습 0, 네트워크)

| 팔 | 무엇 | 왜 |
|---|---|---|
| **0a-1** | ★**`lm-evaluation-harness` 의 정규화 규약 조회** | ★**우리가 §1.1 에서 두 번 틀린 것**이 거기 정리돼 있을 가능성 |
| **0a-2** | 후보 7종의 **arXiv 원문 확인** | ⚠️**`11_benchmarks.md` §6 은 전부 미조회**다 |
| **0a-3** | 데이터 확보 경로·라이선스 | HF datasets / 직접 다운로드 |

⚠️★**`11_benchmarks.md` §6 의 arXiv id 는 통용값이고 조회하지 않았다.**
**0a-2 전에는 계획서·결과문서에서 근거로 인용하지 않는다.**

### 단계0-b — ★**LAMBADA 먼저**(학습 0, 수 분)

★**1순위인 이유**: **순수 LM 과제**다. 마지막 단어를 맞히는 것이고
**SFT 도 지시 이해도 필요 없다.** ★**정확도와 PPL 이 둘 다 나온다.**

| 지표 | 성공 기준값(사전 고정) |
|---|---|
| 정확도 | ⚙**우연 ≈ 1/V.** 사실상 0 → **어떤 값이든 우연 초과** |
| ★**마지막 단어 CE** | ★**연속값이라 분해능이 좋다** — 정확도보다 이쪽을 본다 |

⚠️★**한국어 코퍼스 300M 토큰으로 학습한 모델에 영어 LAMBADA 는 가혹하다.**
**낮게 나오는 것이 정상**이고 ★**"얼마나 낮은가" 가 우리 영어 능력의 첫 숫자**다.

### 단계1 — **우도 채점 3종**(학습 0)

`HellaSwag` · `PIQA` · `ARC-Easy`. ★**PMI 정규화 + 퇴화 감지 필수**(11 §4).

### 단계2 — ⏸**MMLU 참고 측정**

★**우연(25%) 근처가 예상된다.** **그것을 확인하는 것 자체가 결과**다 —
*"우리 모델은 세계 지식이 없다"* 를 **숫자로** 적을 수 있게 된다.

### 단계3 — ⏸**CE 방식 GSM8K**

**생성 채점 대신 정답 문자열 CE.** ⚠️**"수학을 푼다" 가 아니라 "정답 문자열이 얼마나
예측 가능한가" 다.** 이름을 섞지 않는다.

## 5. ★예측 — 결과 전에 못 박는다

| # | 예측 | 실패하면 |
|---|---|---|
| **B1** | **MMLU 는 네 모델 전부 우연(25%) ±3%p** | 넘으면 ★**300M 토큰에 세계 지식이 들어갔다** — 놀라운 일 |
| **B2** | **WinoGrande·BoolQ 도 우연 근처** | BoolQ 는 ★**퇴화(항상 yes)** 가 더 유력하다 |
| ★**B3** | **HellaSwag·PIQA 는 우연을 5~15%p 넘는다** | 못 넘으면 **영어 상식이 아예 없다** |
| ★**B4** | ★**시드쌍 차이가 모델 간 차이와 같은 자릿수** | 결과 050 YNAT 의 재현. **그러면 서열은 영영 못 말한다** |
| ★**B5** | **`p6d`(dense)가 여러 지표에서 tied 를 이긴다** | 결과 050 YNAT 에서 그랬다. ★**사실이면 "타잉이 무엇을 깎는가" 가 새 축이 된다** |

★**B5 가 이 계획의 진짜 질문**이다. **full-val 은 tied 가 이기고 YNAT 은 dense 가 이겼다.**
**어느 쪽이 배포에서 중요한가**는 우리가 아직 모른다.
