# P034B — **패킹 회계 시뮬레이터**: 커널을 짜기 전에 값어치를 먼저 잰다

> **신설 2026-08-13**(사용자 승인, P034 단계3.5 를 별도 번호로).
> 발단: 사용자 지적 — *"5비트 패킹 미수행시 Sherry 3:4 희소 등의 실제 가치를 판단할 수 없다."*

---

## 1. ✅ 지적이 맞다

★**상주 메모리는 bpw 를 보지 않는다**(결과 016 §7.2): 상주 = 유니크삼진 × 4B × 2벌 + 나머지.
**3:4 희소는 저장만 줄인다.** 그리고 **우리는 저장 포맷으로 배포한 적이 없다** —
`to_int8()`(P034 단계3)은 파라미터당 **8비트**로 이론값 1.25bpw 의 **6.4배**다.

| 회계 | `mA_g4s34_k4`(3:4) | `mC_g8_k4` | 출처 |
|---|---:|---:|---|
| 현행 A(우리 packed 규약) | **11.6 MB** | 14.9 MB | 결과 016 §7.4 |
| (C) 컨테이너 포함 | **14.6 MB** | — | 〃 |
| fp32 상주 | 523.5 MB | **451.5 MB** | 결과 016 §1 |

> **→ 5비트 패킹이 없으면 3:4 의 이득이 실물로 나타나는 지점이 아예 없다.**

## 2. ⚠️ 그런데 "그러므로 커널을 짜자" 는 다른 명제다

단계4 는 **커널을 요구**한다(`code*alpha` 를 fp32 로 되돌리면 이론값의 7.6배에서 멈춘다).
그리고 `custom_ternary_kernel.md` §4 가 *"현재 상주 최대항은 임베딩·어텐션"* 이라 우선순위를 낮췄다.

★**그래서 커널 없이 값어치를 먼저 잰다.** 그게 이 계획이다.

## 3. 무엇을 하는가 — **GPU 0, 커널 0**

| # | 측정 | 방법 |
|---|---|---|
| **A** | ★**실제 패킹 파일 크기** | 체크포인트의 삼진 코드를 **비트 단위로 패킹**해 디스크에 쓴다. 5비트(3:4 = `C(4,3)·2³ = 32 = 2⁵`) / log₂3 비트 두 규약 |
| **B** | ★**언팩 비용** | numpy/torch **만으로** 언팩 함수를 구현해 **토큰당 ms** 를 잰다 |
| **C** | 회계 대조 | A 를 `mem_breakdown()` 의 packed 값과 대조 — **계산이 실물과 맞는가** |
| **D** | **손익 표** | "단계4 가 얼마를 벌고(A) 얼마를 내는가(B)" |

## 4. ★예측

| # | 예측 | 근거 |
|---|---|---|
| **P1** | 실제 파일이 `mem_breakdown()` packed 보다 **크다** | 컨테이너·정렬 오버헤드. 결과 016 §7.4 가 **0.274 bpw** 로 역산했다 |
| **P2** | ★**순수 파이썬 언팩이 fp32 복원보다 느리다** | 비트 시프트가 벡터화가 안 된다 |
| **P3** | ⚠️**그래서 D 표는 "커널이 있어야만 이득" 으로 나올 것이다** | P2 의 따름 |
| **P4** | 3:4(1.25) vs 일반(1.679)의 실제 파일 크기 비가 **25% 보다 작다** | 결과 016 §7.4: 동일 회계 절감이 **15~18%** |

> ★**P3 을 미리 적는 이유**: 이 실험의 결론이 *"커널을 짜자"* 가 아니라
> **"커널이 있어야만 얼마를 번다"** 라는 조건부 숫자가 되도록 하기 위해서다.

## 5. 판정

| 결과 | 조치 |
|---|---|
| A 가 int8 대비 **−50% 이상** | 커널 착수 검토(그때 P014 안 C 를 다시 연다) |
| −30~50% | 보류. **임베딩·어텐션 축이 먼저** |
| −30% 미만 | ★**5비트 패킹 축 종결.** 3:4 의 값어치도 **저장 축에서 종결** |

## 6. 한계

- **디스크 크기 ≠ 상주**(함정 1). 이 계획은 **저장 축만** 본다.
- 언팩 비용은 **파이썬 구현의 상한**이다. 커널이면 훨씬 빠르다 — **하한이 아니라 상한**임을 명시.
- ⚠️ **3:4 의 품질 대가(+0.035~0.056)는 이 계획이 안 본다.** 그건 결과 016 에 있다.
