## 0. ★왜 — **코드가 스스로 "안 쟀다" 고 적고 있다**

`init_utils.py` 의 P057 그룹평균 어텐션 이식 주석(2026-08-13):

> *"⚠️**평균이 옳다는 보장은 없다.** MLP 에서는 실측으로 부모초기화 이득이 살아남았지만

★**지금 우리가 쓰는 규약**:

| 대상 | 규약 | 근거 |
|---|---|---|
| **중간 MLP**(`mlp_group` g) | 교사 g개 층의 **파라미터 산술평균**(RRT average-init) | ⚠️**관례** — 대안과 비교한 적 없다 |
| **공유 어텐션**(`attn_group`) | **같은 규약**(그룹 평균) | ⚠️**대칭성을 위해** 그렇게 했다고 주석이 적고 있다 |

🚫★**"어느 교사에서 가져오는가" 도 안 쟀다.** 우리는 늘 **같은 dense 정본**에서 초기화했다.

## 2. ★집약 방식 — **무엇이 후보인가**(조사)

`g` 개 교사 층 `W₁ … W_g` 로부터 **공유 가중치 하나**를 만든다.

| # | 방식 | 식 | 근거·직관 | 구현 |
|---|---|---|---|---|
| **A1** | ★**산술평균**(현행) | `mean(Wᵢ)` | RRT average-init. **가장 흔하다** | ✅있다 |
| **A2** | **중간층 선택** | `W_{⌊g/2⌋}` | 평균은 **상쇄**를 일으킨다 — 층마다 부호가 다르면 0 에 가까워진다 | ⚙0.2h |
| **A3** | **첫 층 선택** | `W₁` | 그룹의 **입구**가 대표 | ⚙0.2h |
| ★**A4** | **노름 보정 평균** | `mean(Wᵢ) × (mean‖Wᵢ‖ / ‖mean(Wᵢ)‖)` | ★**A1 의 상쇄를 정확히 되돌린다.** 방향은 평균, 크기는 원래 | ⚙0.3h |
| ★**A5** | **최대노름 층** | `argmaxᵢ ‖Wᵢ‖_F` | *"가장 많이 일하는 층"* | ⚙0.2h |
| **A6** | **SVD 1차 근사** | `Wᵢ` 를 쌓아 rank-1 | ⚠️**shape 이 커진다** | ⚙1h |

★★**A4 가 가장 흥미롭다.** 평균의 문제는 **방향이 다른 층을 더하면 크기가 줄어든다**는 것이고,
그것은 **부모초기화가 주는 신호를 약화**시킨다. **A4 는 그 한 가지만 고친다.**

⚙**측정 가능한 사전 신호**: 그룹 내 층들의 **코사인 유사도**.
- 유사도가 **높으면** 평균이 안전하다(상쇄가 없다) → A1 ≈ A4
- **낮으면** 평균이 크기를 잃는다 → ★**A4·A2 가 유리할 것**

🚫**우리는 이 유사도를 한 번도 안 쟀다.** ★**단계0 이 그것부터 잰다(학습 0).**

## 3. 단계0 — **그룹 내 유사도 실사** (⚙10분, 학습 0, GPU 0)

`scripts/diag_group_agg.py`(신설) 가 dense 정본에서:

| 지표 | 왜 |
|---|---|
| 그룹별 **평균 쌍 코사인 유사도**(MLP·어텐션 따로) | ★**평균이 상쇄를 일으키는가** |
| `‖mean(Wᵢ)‖ / mean‖Wᵢ‖` = ★**축소비** | **1.0 이면 상쇄 없음, 0 에 가까우면 심각** |
| 층 인덱스에 따른 추세 | 깊은 층일수록 달라지는가 |

★**판정**: 축소비가 **> 0.9** 면 A1 과 A4 가 거의 같다 → **Q1 이 시시해진다.**
**< 0.7** 이면 ★**A4 를 바로 만들 값어치가 있다.**

⚠️★**이 단계가 "실험을 할 것인가" 를 정한다** — 값싼 진단이 비싼 학습의 게이트다(`ai_dev_tool/06` §3.7).

## 6. 단계3 — **어느 dense 에서 초기화하나** (Q3)

🚫**우리는 늘 같은 dense 정본을 썼다.** 후보:

★★**가설 D**: **교사가 깊을수록 평균의 상쇄가 커지므로, 깊은 교사에서는 A4 가 더 중요하다.**

⚠️**얕은 dense 는 이미 있다**(`d6/d8/d10/d12_dense`, 결과 059 §10) → **재학습 없이 교사로 쓸 수 있다.**

## 7. ⏸단계4 — **압축 교사에서 초기화** (Q4)

`mC_initonly_nc`(이미 타잉된 모델)를 부모로 삼는다.
★**흥미로운 점**: 압축 교사는 **이미 그룹당 하나**라 **집약이 필요 없다** — 그대로 복사다.
⚙**예상**: 상쇄가 0이므로 A1~A5 구분이 사라진다.
⏸**선결**: 단계2 결과. 🚫**압축 교사가 dense 교사보다 나쁘면**(품질이 낮으므로) **교락**이다 —
*"집약이 없어서 좋다"* 와 *"교사가 나빠서 나쁘다"* 를 못 가른다. → ★**설계를 더 해야 한다.**

→ ★**그래서 단계0 이 게이트다.** 축소비가 1.0 에 가까우면 **단계2 를 열지 않는다.**

## 9. ⚠️한계

- 🚫**단계2 부터는 구현 선결**이다. **배치를 만들지 않는다**(R22).
- ⚠️**시드 하나로는 자 근처를 못 가른다.** P4 가 맞으면 **시드 3개가 필요**하고 그건 **32h** 다.
