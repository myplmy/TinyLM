# 실험 계획 목록

한 계획 문서는 아래 세 상태 중 정확히 한 표에 한 행만 둔다. 단계 하나의 완료를 계획 전체
종결로 승격하지 않으며, 애매하거나 후속 단계가 남으면 진행 중으로 분류한다. 세부 수치와
실행 명령은 각 계획서·결과문서·docs/EXPERIMENT_BASELINES.md가 소유한다.
