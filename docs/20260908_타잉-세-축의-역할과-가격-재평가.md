## 0. 요약 — **열 문장**

1. ★★**"타잉" 이라는 한 단어가 세 개의 서로 다른 레버를 가리킨다**(함정 28).
   MLP 타잉은 **가중치**를, 어텐션 타잉도 **가중치**를, CLA 는 **KV 캐시**를 지운다 — **화폐가 다르다.**
2. ★★★**대가는 "무엇을 묶느냐" 가 아니라 "유니크 파라미터를 몇 개 지우느냐" 로 정해진다.**
   첫 타잉 걸음의 가격은 MLP **0.001873** · 어텐션 **0.001946 nats / 유니크삼진 100만** — **4% 안에서 같다.**
3. 🚫★★**그래서 CLAUDE.md 의 *"어텐션 타잉이 MLP 타잉의 1/4.1 로 가장 싸다"* 는 정정한다.**
   그 비교는 **어텐션의 첫 걸음(ag1→ag4)과 MLP 의 마지막 걸음(g8→g16)**을 댄 것이고,
   추가로 **`cla_group` 이 두 팔에서 달랐다.** 같은 걸음·같은 `cla_group` 이면 둘은 같다.
4. ★**MLP 타잉 축에는 강한 수확체감이 있다** — g1→g4 **0.001873** 에서 g8→g16 **0.007648**
   nats/100만 = **4.1배**. *"타잉이 비싸다" 는 관찰의 대부분은 g≥8 구간에서 나왔다.*
5. ★배포 상주(MiB) 단위로 통일하면: **MLP g4 0.0098~0.0128 · 어텐션 ag4 0.0102 ·
   CLA cla2 0.00587 nats/MiB** vs **깊이 0.00614 · 재귀 R2 0.01094**(살 때는 클수록 좋다).
   → ★**CLA 만 깊이보다 싸다.** 가중치 타잉 둘은 **1.6~2.0배 비싸다.**
6. ★★★**격자가 대각선이다.** 161 full-train 런의 (깊이 × g) 표에서 **27칸 중 17칸이 비었고**,
   채워진 칸은 **유니크 MLP 개수를 2 로 고정한** 선 위에 있다.
   → 🚫***"MLP 타잉은 무가치하다" 가 아니라 "유니크 MLP 2개로 고정한 채 깊이를 바꾸면 dense 에 진다"*** 가
   실제로 잰 것이다.
7. ★★**전부 묶어도 dense 재귀와 같아지지 않는다.** 층마다 **4,610개**(RMSNorm 2 · 스케일/시프트 4 ·
   게이트 2)가 남는다. → ★**완전 타잉 = "완화된 재귀"(relaxed recursion)** 이고
   재귀는 그 완화 파라미터까지 공유한다. **둘은 같은 축의 두 끝점**이다.
8. ★★**그 사실이 FiLM·LRM 이 아무것도 못 산 이유를 설명한다** — 완화 채널이 **이미 4,610개** 있었다.
   FiLM(+0.0003, t 0.77)과 LRM(dense −0.0005, 산술적으로 무효)은 **이미 있는 것을 또 붙인 것**이다.
9. 🚫★**타잉 손실 복원 선행연구의 정공법(LoRA 완화, arXiv:2410.20672)은 우리 표준조건에서 0런이다.**
   유일한 측정이 **2026-07 300M 풀 시대**의 `t_lora32`(−0.0338)이고, 그 시대의 자는 폐기됐다.
   ★**이것이 타잉 축의 가장 큰 빈칸**이다.
10. ★그래서 **세 축의 판정이 서로 다르다**: **CLA = 유지(승자의 부품)** ·
    **어텐션 타잉 = 재심 필요**(교락 해소 + Muon) · **MLP 타잉 = 재심 필요**(LoRA 완화 + 폭 + Muon).
    🚫**셋 중 어느 것도 "종결" 이 아니다.**

## 1. 세 축은 무엇을 하는가 — **코드가 정본**

### 1.1 MLP 타잉 `--mlp-group g`

```python
# tinylm/model/transformer.py:37
self.mid_mlps = nn.ModuleList([MLP(cfg) for _ in range(cfg.n_mlp_groups)])
...
mlp = self.mid_mlps[_mlp_gi(cfg, j) if cfg.tie_mlp else j]     # j = 중간층 인덱스
```

**연속한 g 개 중간층이 MLP 객체 하나를 참조**한다. `n_mlp_groups = n_middle // g`.
★**MobileLLM 의 *immediate block-wise weight sharing* 과 같은 배치**다(흩는 방식이 아니다,
[08 §6](methods/08_paper_review.md)) — 그리고 그 배치가 **층당 비용이 g 순서로 단조**(g8 0.913 <
g4 1.022 < dense 1.163 ms, 결과 014 §11)인 이유다. 캐시 지역성.

⚠️**prelude·coda 는 대상이 아니다.** 언제나 층마다 독립이다.

### 1.2 어텐션 타잉 `--attn-group ag`

```python
# transformer.py:52
self.mid_attns = nn.ModuleList([build_attention(cfg, True) for _ in range(cfg.n_middle // ag)])
...
shared_attn = self.mid_attns[j // ag]
```

**형태가 MLP 타잉과 완전히 대칭**이다. 공유 어텐션은 **K/V 소유 형태로 만들고**,
실제 소유 여부는 호출 시 `kv` 인자가 정한다.

⚠️★**설계 시점에 이미 교락이 적혀 있었다**(코드 주석 48~52행):
*"`cla_group=2` 는 이미 K/V 를 공유 중이라 공유 어텐션이 소유층/재사용층 양쪽에 선다.
대가를 귀속하려면 `cla_group=1` 대조가 필요하다."* — **그 대조가 §3.3 이다.**

### 1.3 CLA 타잉 `--cla-group c`

```python
# transformer.py:66-73
if cfg.cla_edges or cfg.cla_group == 1:
    _own = i - (i % cfg.cla_group)
elif _p <= i < _p + _m:
    _own = _p + (_j - (_j % cfg.cla_group))     # ★middle 안에서만 묶는다
else:
    _own = i                                     # 머리·꼬리는 자기 K/V
owns = (_own == i)
```

🚫**가중치를 하나도 안 지운다.** `build_attention(cfg, owns_kv)` 가 **K/V projection 을 만들지
말지**를 정하므로 파라미터는 조금 줄지만(d12 에서 74.32M → 72.55M = **2.4%**),
★**본질은 KV 캐시 엔트리 수**다: `엔트리 = 방문 / cla_group`.

★**그래서 CLA 의 절감은 컨텍스트 길이에 비례한다** — 이것이 §3.4 의 핵심이다.

## 2. 스펙에 무엇이 바뀌나 / 성능에 무엇이 바뀌나

사용자가 나눈 두 축(**스펙** = 모델이 가지는 것 / **성능** = 돌릴 때 재는 것)으로 정리한다.

| **유니크 삼진 파라미터** | ★**크게 준다** (d16 g4: 96.73M → 54.26M, **−43.9%**) | ★**크게 준다** (L20 g8: 54.85M → 39.52M, **−28.0%**) | 거의 안 준다 (d12: 74.32M → 72.55M, −2.4%) |

### 2.2 성능 (돌릴 때 재는 것)

| | MLP 타잉 | 어텐션 타잉 | CLA |
|---|---|---|---|

| **추론 속도** | ★**약간 빨라진다** — 층당 0.913(g8) vs 1.163(dense) ms = **−21.5%**(캐시 지역성, 결과 014 §11) | ⚙미측정 | ★**엔트리가 줄어 2차항이 준다**(t4 +8.3%, 결과 014 §14) |

★★**가장 자주 오해되는 것**: *"타잉은 컴퓨트를 줄인다"* 는 **틀렸다.**
`report()` 의 FLOPs 식에 `mlp_group` 도 `cla_group` 도 **없다.**
줄어드는 것은 **저장·상주·옵티마이저 상태**이고, 속도 이득은 **연산량이 아니라 캐시 지역성**에서 온다.

### 3.0 인구조사 (161 full-train 런, steps ≥ 1000)

⚠️★**주의**: `cla_group`·`attn_group`·`n_layers` 필드는 **2026-08-23 이후 런에만** 있다.
그 앞 런은 **프리셋 기본값으로 채워서** 세었다(`m100R1c` → g8·ag1·cla2·L20).
🚫**json 값만으로 세면 옛 런이 전부 `cla_group=1` 로 잘못 분류된다** — 실제로 첫 집계가 그랬다.

2. **사용자가 물은 네 칸 중 셋이 비어 있다** — *깊은 층 × 작은 g*(L36 × g4·g8 = **0런**,

3. **`dim` 은 열이 없다** — `tiny` 를 뺀 전 프리셋이 **768** 이라 *"더 좁고 깊은 × 타잉"* 은
   **격자에 존재하지 않는다.**

🚫**틀린 것은 수치가 아니라 문장**이다 — *"어텐션 타잉이 MLP 타잉보다 싸다"* 가 아니라
***"첫 걸음이 마지막 걸음보다 싸다"*** 였다. **그것은 어느 축에서나 참이다.**

## 4. ★★"전부 채택하면 dense 재귀와 같은 구조가 되는가"

### 4.1 답 — **아니다. 층당 4,610개가 남는다**

`mlp_group = attn_group = n_middle` 이고 `cla_group = 1` 이면 모든 중간층이
**같은 MLP·같은 어텐션**을 참조한다. 그래도 `Layer.__init__`(`modules.py:176`)이 만드는
**층 소유 파라미터**는 남는다:

| 파라미터 | 개수 (dim=768) |
|---|---:|
| `ln1`, `ln2` (RMSNorm 각 dim) | 1,536 |
| `a_scale`, `a_shift`, `m_scale`, `m_shift` (각 dim) | 3,072 |
| `gates` (2) | 2 |
| **합계** | ★**4,610 / 층** |

★**즉 완전 타잉은 "행렬은 같고 층마다 아핀 조건화가 다른 구조"** 다.

### 4.2 ★★★그래서 **완전 타잉 = 완화된 재귀**다

| | 공유하는 것 | 층마다 다른 것 |
|---|---|---|
| **완전 타잉** (g=ag=n_middle) | 삼진 행렬 전부 | ★**4,610개 아핀** |
| **재귀** (`train_repeat`) | 삼진 행렬 **+ 4,610개 아핀 전부** | 🚫**없다** |

★★**둘은 다른 기법이 아니라 같은 축의 두 끝점**이다.
재귀는 **가장 강한 타잉**이고, 완전 타잉은 **relaxation 이 붙은 재귀**다.

★그리고 KV 축에서 한 번 더 갈린다:
- **재귀**: 바퀴마다 K/V 를 **새로** 만든다 → 엔트리 = 방문 수 / cla_group
- **완전 CLA**(`cla_group = n_middle`): 첫 층의 K/V 를 **동결**해 재사용
→ 🚫**`--repeat-kv-reuse` 가 정확히 이 둘을 잇는 플래그였고 기각됐다**(결과 062, 대가가 재귀
이득의 5.4~5.7배). ★**즉 "재귀의 KV 를 CLA 처럼 만들면 재귀 이득이 사라진다"** 가 실측이다.

### 4.3 ★그 사실이 FiLM·LRM 결과를 설명한다

FiLM 은 `film_scale`·`film_shift`(각 `ffn_dim`)를, LRM 은 `lrm`(3개)을 **층마다** 붙인다.
그런데 층은 **이미** `m_scale`·`m_shift`(각 `dim`)를 갖고 있다.

| 기법 | 추가하는 층별 파라미터 | 이미 있던 것 | 실측 |
|---|---:|---:|---|
| LRM | 3 | 4,610 | **−0.0005**(dense, 결과 072) — ★**산술적으로 무효**(1차 동차) |
| FiLM | 2 × ffn_dim = 4,096 | 4,610 | **+0.0003**(t 0.77, 무KD, 결과 063) |
| LoRA r=32 | 3 × r × (dim+ffn) ≈ 269K | 4,610 | −0.0338 ⚠️**300M 풀 시대** |

★★**가설(신규, 검정 가능)**: *완화 채널이 4,610개에서 이미 포화한다.*
- **예측 1**: 층별 아핀(`a_*`·`m_*`·`ln*`)을 **공유**한 타잉 몸통에서는 FiLM·LRM 이
  **갑자기 효과를 낸다.** 지금은 아무것도 안 산다.
- **예측 2**: 반대로 **재귀**(4,610개까지 공유)에 FiLM 을 붙이면 효과가 있어야 한다.
  🚫**한 번도 안 쟀다** — FiLM 은 `mlp_film=is_mid_tied` 로 **타잉 몸통에만** 붙는다.
- ★**둘 다 학습 2런(⚙2.4h)이면 갈린다.**
