## 상태 범례

- ✅ **적용**: 코드에 반영되어 기본/상시 동작
- 🧪 **실험옵션**: 코드에 있으나 플래그/프리셋로 켜는 것
- 💡 **제안**: 아직 미구현, 검토·제안 단계
- 🔜 **로드맵**: 확장(1.7B/배포) 단계에서 예정
- 🚫 **폐기**: 측정·검토 후 제외

## 버전 개요

- **v4** — 단일파일 아키텍처. 측정 기반 설계 확정(prelude/coda, 어텐션 독립, MLP 타잉,
  CLA2, factorized embedding, g128 삼진). 300M 실전에서 NaN 발산.
- **v5** — 학습 발산 해결(QK-norm, NaN 가드, compile 안전 어닐, LR 재조정).
- **v6** — `tinylm/` 패키지 모듈화 + 효율/실험 기능(EMA·WSD·베스트ckpt·조기종료·
  스케일별 체크포인트 이름·자동 LR 탐색·KD·부모초기화·ternary-LoRA·FiLM·깊은 프리셋·
  reduce-overhead·TF32·HF 리다이렉트·크기별 데이터 캐시).

## 현재까지의 핵심 측정치

> **수치 정본은 `runs/logs/*.json` 이다.** 종합 판정·기법별 채택 수준은
> [`review/202607301200_1차리뷰_실험종합및최적모델3안.md`](review/202607301200_1차리뷰_실험종합및최적모델3안.md) 참조.

### A. 300M 풀 계열 (m100, ko-en, 300M 학습토큰, lr 1e-3) — **풀 핸디캡 있음**

| 구성 | val | 메모리 | 감축 | 격차 |
|---|---|---|---|---|
| `dense` | **3.8241** (best 3.7797) | 30.9MB | 1.00× | — |
| `t_g8` plain tied g8 | 3.9520 | 14.9MB | 2.07× | +0.128 |
| `t_base` plain tied g4 | 3.9558 | 17.1MB | 1.81× | +0.132 |
| `t_kd_g8` (부모초기화+KD) | 3.8292 | 14.9MB | 2.07× | +0.005 |
| **`t_kd_g8_k4`** (KD 정적 k4) | **3.7875** (best 3.7528) | 14.9MB | 2.07× | **-0.037** |
| **`t_kd_g4_s34`** (3:4 희소) | 3.8605 | **11.7MB** | **2.64×** | +0.036 |
| **`t_kd_g8_s34`** (3:4 희소) | 3.8847 | **10.3MB** | **3.00×** | +0.061 |

### B. 600M 풀 계열 (결과 006, 공정 비교) — **핸디캡 없음**

| 학습토큰 | dense | plain tied g8 | tied+KD(full) | 격차(tied) | 격차(KD) |
|---|---|---|---|---|---|
| 100M | 4.3650 | 4.5136 | **4.2550** | +0.149 | **-0.110** |
| 300M | **3.7045** | 3.8727 | 3.7661 | +0.168 | +0.062 |
| 600M | **3.5197** | 3.6853 | 3.6180 | +0.166 | +0.098 |

**★A 와 B 를 직접 비교하지 말 것** — 풀이 다르면 본 데이터가 다르다. 같은 300M 학습토큰에서
풀 300M→600M 만으로 dense 가 **-0.12** 이므로, A 의 모든 격차는 **약화된 dense** 기준이다.

### C. 확정된 결론 3줄

- 타잉 격차는 **토큰으로 닫히지 않는다**(용량 상한). KD 이득은 **예산↑에서 감소**한다.
- 3:4 희소는 **손실 0.035~0.056 에 메모리 1.45×**, 학습시간 영향 0. **타잉과 경합**(동시 최대 금지).
- `--no-ckpt` ⚠️**-17.3% 는 철회**(아래 D-4). micro_bs↑ **이득 0**(연산바운드).

## D. ★2026-08-14 갱신 — **이 문서가 낡은 지점 다섯**

> 위 A~C 는 **2026-07-30 시점**이다. 그 뒤 결과 028~039 가 **네 개를 정정하고 하나를 뒤집었다.**
> 원문을 지우지 않고 아래에 정정을 붙인다 — **무엇이 언제 바뀌었는지가 정보**이기 때문이다.

### D-1. ★★**KD 는 300M 에서 해롭고, 빼는 것이 최대 VRAM 레버다** (결과 038 · §9)

| | reserved | full-val |
|---|---:|---:|
| `mC_wsd`(KD 있음) | 12.47 GiB | 3.6984 |
| **`mC_initonly`(KD 없음)** | ★**5.07 GiB** | ★**3.6776** |
| 차 | ★★**−7.41 GiB (−59%)** | **−0.0208**(KD 없는 쪽이 좋다) |

**두 시드에서 재현**(1337 +0.0208 / 2024 +0.0219, 차 0.0011). **부모초기화 몫 +0.1386 vs
KD 몫 −0.0032 = 43배.** 위 B 표의 *"300M 에서 +0.062"* 와 **같은 부호**다 — 우리는 알고 있었고
그러면서도 거의 모든 실험을 KD 로 돌렸다. ⚠️**표준조건 변경은 REVIEW2 가 정한다**(전환 비용).

### D-2. ★★**σ 는 상수가 아니라 조건 의존이다** (결과 009 §P012B · 038 §9 · 039)

| 조건 | 시드 노이즈 |
|---|---:|
| dense · 부모/교사 없음 | **0.0109** |
| tied · 부모초기화만 | **0.0017** |
| tied · KD + 부모초기화 | **0.0006** |

**부모초기화가 6.4배, KD 가 추가 2.8배 줄인다.**
→ **분해능 0.024 는 실무 의사결정 규칙으로 유지**하되, *"동급"* 이라 쓸 때
**"통계적으로는 유의"** 를 함께 적는다.

### D-3. **`grad_max` 에는 ±30% 시드 성분이 있다** (결과 038 §9)

같은 조건에서 시드만 바꿔 0.6437 → 0.8194. **조건 비교에 쓸 때 그만큼은 노이즈**로 본다.
그리고 **인쇄 `|g|` 가 아니라 json `grad_max`** 를 읽는다(결과 030 에서 판정이 뒤집혔다).

### D-4. ⚠️**속도 수치 대부분이 "세션 간 비교 불가" 다** (결과 037 §11.4)

**명령 문자열이 동일한데 다른 날 런의 ms/step 이 7.5% 다르다**(같은 배치 안은 1.37%).
→ C 의 `--no-ckpt` **−17.3%** 와 결과 034 의 −20.5% 는 **철회**. 정직한 범위는 **−6% ~ −20%, 미확정**.
**★속도는 같은 배치 안에서만 비교한다.** T-1(2026-08-14)이 json 에 `ms_step_median` 과
`ms_step_spread`(p90/p10−1)를 넣어 **스필 판정을 런타임이 직접** 하게 했다.

### D-5. **커널 자체 제작은 보류** (결과 028 §11)

`torch._weight_int8pack_mm` 이 **이미 존재**하고 우리 shape 을 전부 받는다. per-row α 의 품질
대가는 **분해능 미만**. → 전문은 **[`custom_ternary_kernel.md`](custom_ternary_kernel.md) §2026-08-14**.

### D-6. 학습 VRAM 최대 항목 = **모델이 아니라 KD 손실** (결과 034 §9)

교사 파라미터는 945MB 뿐인데 **어휘 전체 위 손실이 +5.48 GiB**. 레버표는
**[`methods/09_training_memory.md`](methods/09_training_memory.md)**.
★**스필은 조용하다** — 종료코드 0·손실 정상인데 +26% 느렸다. 판별 `scripts/check_spill.py`.
