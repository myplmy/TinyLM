## 3. 판정 근거 — 조치별

### 3.1 ★**A08(옵티마이저) — 이 패키지에서 가장 좋은 것**

`trainer.py` 교체본은 **추가 45 · 삭제 4** 이고 삭제 넷이 전부 같은 호출의 갱신이다.
넣는 것 셋:

| 무엇 | 왜 우리에게 필요한가 |
|---|---|
| ★★`matrix_weight_decay` | 🚫**우리 Muon 팔의 행렬 wd 가 0 이고 AdamW 팔은 0.1 이다** — 삼진 72.5M(89%)이 그 차이를 받는다. **우리가 스스로 적어 둔 미해결 항목**(P005b b-3)을 정확히 구현했다 |
| ★★★**`opt_muon` 체크포인트 저장·복원** | 🚫**우리 코드는 Muon 상태를 저장하지 않았다.** resume 하면 모멘텀이 조용히 0 으로 초기화된다. ★**실물 결함이고 우리가 못 찾았다** |
| `optimizer_audit` | 실제 업데이트 크기를 기록. b-1·b-2 판정의 계기가 된다 |

★**그래서 A08 은 ②(수정 필요)이지 ③(기각)이 아니다.** 수정은 **병합 3줄**뿐이다(§4.1).

### 3.3 🚫**A09(`diag_lrm_values`·`check_lr_factor_sync`) — 오늘 쓴 도구를 지운다**

교체본에서 `s_wd`(순수 weight decay 바닥) 계산이 **16회 → 0회**, *"WD 보정"* 8회 → **0회**,
*"기울기 몫"* 2회 → **0회**, `vector` 2회 → **0회**.

★★**오늘(2026-09-10) P086 단계3 판정이 정확히 그 출력 위에 서 있다** —
*"max|r−1| **0.256241**"*. 교체하면 **그 수를 다시 못 만든다.**
⚠️★**2026-09-10(2차) 정정** — 이 절이 인용한 *"WD 보정 0.2645 · 13.1배"* 는 **우리 도구의 결함**이었다. 그 런은 `--mlp-lrm-wd 0` 인데 도구가 0.01 을 박아 두고 나눴다. ★**A09 의 지적이 옳았고 고쳤다** — 그러나 **고친 방법은 교체가 아니라 최소 패치**다(`s_wd` 블록은 그대로 두고 wd 출처만 런 json 으로).
게다가 교체본은 **`--mlp-lrm-mode vector` 를 모른다**(2026-09-08 신설).

## 4. ★②(대체 전 수정 필요) — **무엇을 어떻게 고치나**

### 4.1 `tinylm/train/trainer.py` + `tinylm/cli.py` (A08)

🚫**교체본을 그대로 덮으면 오늘 넣은 `--muon-scale` 이 사라진다.** 겹치는 자리는 **셋뿐**이다.

| # | 자리 | 현재(오늘) | 교체본 | ★병합 결과 |
|---|---|---|---|---|
| 1 | `train()` 시그니처 | `optimizer="adamw", muon_lr_mult=1.0, muon_scale="jordan",` | `optimizer="adamw", muon_lr_mult=1.0,` + `matrix_weight_decay=None, optimizer_audit=None, optimizer_audit_every=100,` | ★**둘 다 남긴다** — `muon_scale="jordan", matrix_weight_decay=None, optimizer_audit=None, optimizer_audit_every=100,` |
| 2 | `Muon(...)` 생성 | `Muon(_mats, lr=lr * muon_lr_mult, scale_mode=muon_scale)` | `Muon(_mats, lr=..., weight_decay=0.0 if matrix_weight_decay is None else matrix_weight_decay)` | ★**인자 둘 다** — `Muon(_mats, lr=lr * muon_lr_mult, scale_mode=muon_scale, weight_decay=(0.0 if matrix_weight_decay is None else matrix_weight_decay))` |
| 3 | json 필드 | `"muon_scale": ...` | `"matrix_weight_decay": ...` 등 | ★**둘 다 쓴다** |

**`cli.py` 는 +7/−0 이라 충돌이 없다** — 교체본의 7줄(플래그 셋)을 **현재 파일에 이어 붙이면 된다.**
⚠️**그리고 새 플래그 셋을 `scripts/flag_whitelist.tsv` 에 등재**해야 `check_flag_whitelist` 가 통과한다.

★**검증**: 병합 뒤 `python scripts/check_call_kwargs.py`(cli→trainer 키워드) ·
`check_attrs` · `check_imports` · **스모크 팔 `sm_muon`·`sm_muonrms`**.
