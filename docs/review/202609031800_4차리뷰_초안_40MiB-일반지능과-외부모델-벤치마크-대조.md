## 0. 결론 — 다섯 줄

1. ★★**현재 우리 모델은 세 상식 과제에서 우연을 넘지만, 외부 소형모델에 5~12%p 뒤진다.**
   HellaSwag **29.8** vs 37.5~42.1 · PIQA **56.0** vs 65.3~68.4 · ARC-Easy **39.0** vs 43.9.
2. ★★★**그 격차의 가장 큰 설명 변수는 아키텍처가 아니라 학습 토큰이다** —
   우리 **300M** vs 외부 **800G~28T** = **2,667배 ~ 93,333배**.
3. 🚫★★**"40 MiB 라서 어쩔 수 없다" 는 변명이 안 된다** — **Falcon-H1-Tiny-90M 의 공식
   TQ1_0 GGUF 가 31.1 MB** 다. **우리 예산 안에 이미 경쟁자가 있다.**
4. ★**우리가 지금 못 재는 것이 재는 것보다 많다.** 문장작성·지시이행·양식준수·수학·코딩은
   **평가 경로 자체가 없고**, 한국어는 **held-out 이 결함 9건으로 신뢰 불가**(결과 068 §12).
5. ★**권고**: **①계측을 먼저 세우고**(⚙거의 0) **②토큰 축을 열고**(⚙5.1h)
   **③SFT 경로를 연결**한다. 🚫**아키텍처 추가 탐색은 그다음**이다.

## 2. 🚫★★"지능" 을 우리는 거의 못 재고 있다

사용자가 물은 능력 일곱 축에 대해 **지금 있는 평가 경로**를 그대로 적는다.

| 능력 축 | 평가 경로 | 상태 |
|---|---|---|
| 일반 상식 | hellaswag · piqa · arc_easy | ✅**있다.** ⚠️단 n=400 은 **서열을 못 매긴다**(필요 N 5,275~5,816) |
| 논리·수학 | gsm8k | 🚫**SFT 없어 0 이 정상.** 측정 의미 없음 |
| 코딩 | humaneval · bfcl_v3 | 🚫**생성 과제 + 실행 안 함.** 사실상 없다 |
| 지시수행 | ifeval | 🚫**SFT 미연결.** 0 |
| 양식 준수 | — | 🚫★**평가 경로가 아예 없다** |
| 문장작성 | — | 🚫★**평가 경로가 아예 없다**(`probe_prompts.py` 는 정성 프로브다) |
| ★**한국어** | held-out v2.3/v2.4 | 🚫★★**결함 9건으로 신뢰 불가**(결과 068 §12.3) |

★★**즉 일곱 축 중 신뢰할 수 있는 것이 하나(상식)뿐이고, 그 하나도 분해능이 모자란다.**

> 🚫★**그러므로 이 리뷰는 *"우리 지능이 얼마인가"* 에 답하지 못한다.**
> 답할 수 있는 것은 *"어디까지 재고 있고 무엇을 먼저 세워야 하는가"* 다.

### 2.1 ★full-val 은 지능의 대리값으로 이미 한 번 실패했다

결과 067 §12.5 실측: `d16_cla2_r20` 이 `d12_cla2_r20` 을 full-val 에서
**−0.0412(자의 20배, 승률 사실상 100%)** 로 이기는데 **HellaSwag 는 27.5 vs 29.8 로 진다.**

★**정답 CE 는 세 과제 전부 방향이 맞았다**(−0.1099 / −0.0386 / −0.0869).
어긋난 것은 **argmax 정확도**뿐이다.

→ ★★**압축률(full-val)과 과제 정확도는 같은 축이 아니다.**
🚫**1~3차 리뷰의 승자 선정은 전부 full-val 로 했다** — 그 판정을 **지능 판정으로 옮겨 적지 않는다.**

## 4. ⏸아키텍처 — **3차 리뷰 이후 무엇이 바뀌었나**

| 항목 | 3차 리뷰 | ★**지금** |
|---|---|---|
| 몸통 | 20층 **타잉** 위 4안 | 🚫**그 몸통이 졌다** — dense 12/16 + cla2 + R2 |
| 32 MiB | 안 A~D | ★**`d12_cla2_r20` 3.6054 @ 30.7**(시드 재현 ✅) |
| 40 MiB | — | ★**`d16_cla2_r20` 3.5642 @ 38.5**(시드 재현 ✅) |
| 신규 | — | `d12_cla2_r30` 3.5926 @ **33.7** — 두 예산 사이라 **미채택** |

★**아키텍처 조사문서(2026-09-03)가 새로 연 것 셋**(우리 실측으로 검증함, §7):

1. ★★**MLP 타잉 비교에 LR 교락이 있다** — `param_groups()` 가 **타잉된 middle MLP 에만**
   `lr/√g` 를 준다. 어텐션 공유에는 보정이 **없다**.
   → 🚫**"MLP 타잉 대가 +0.0637~+0.1049" 는 표현력 손실과 옵티마이저 효과의 합**이다.
2. ★**`cla_group` 이 전 층에 전역 적용**된다(`owner[i] = i - (i % cla_group)`).
   → *"바깥 CLA1 + 중간 CLA2"* 형상을 **현재 표현할 수 없다.**
3. ★**`n_kv_heads` 가 CLI 인자가 아니다** → GQA 폭 축이 **닫혀 있다**.

⚠️★**셋 다 "고치면 지능이 는다" 가 아니라 "축이 막혀 있다" 는 뜻**이다. 우선순위는 §5 에서 정한다.
