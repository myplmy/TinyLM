## P109 프리트레이닝

**통합 v3는 원문 예측과 실제 추출에서 이득을 얻었다.** 같은 질문의 실사용 답은 늘었고 감정·참거짓 등의 공식 평균과 긴 반복 종료는 따로 확인해야 한다. 감정 분류는 전체 정답을 유지해도 한 라벨에 몰리면서 macro-F1이 하락했다. 학습 교과와 손실을 함께 바꾼 비교이므로 단일 기법은 좁힌 대조에서 판정한다. [실사용 문항별 변화](../../test_result/109_20261119004016_P109-기존G4-방문-세정책-실제갱신.md#p109c-integrated-v3-final200-result-20261124) · [원문과 공식 지표](../../test_result/109_20261119004016_P109-기존G4-방문-세정책-실제갱신.md#p109c-integrated-v3-common-eval-result-20261124)

**실사용 비교에서 답 내용과 종료를 나눈다.** 같은 원답에서 다음 질문을 이어 쓰기, 길이 상한, 답 없이 종료를 구분한다. 기존 루브릭과 별도로 측정한 경계 진단은 판본의 언어별 점수 해석에 쓴다. [FINAL200 원답 800개의 종료 진단](../../test_result/109_20261119004016_P109-기존G4-방문-세정책-실제갱신.md#p109c-final200-output-boundary-result-20261124)

**영어 추출에서 복사와 입력 조작을 구분한다.** 같은 문항에 대한 원답과 정상 종료를 확인하고, 실제 교과의 답 시작 직전 사용자 발화에서 명시적 지시를 센다. 덧셈처럼 노출이 있었던 과제는 형식과 피연산자, 독립 조작 정답을 함께 본다. [같은 문항의 판본별 대조](../../test_result/109_20261119004016_P109-기존G4-방문-세정책-실제갱신.md#p109c-frozen-model-comparison-result-20261124) · [영어 조작의 교과 노출](../../test_result/109_20261119004016_P109-기존G4-방문-세정책-실제갱신.md#p109c-english-operation-coverage-result-20261124)

**기존 교과에서 자리별 계산을 다시 감독할 수 있다.** 검산된 합과 받아올림을 기존 답의 실제 위치에 연결한다. 계수가 더 많은 갱신에 분산되면 감독 위치 수, 같은 행의 본체 기울기, 독립 정답을 따로 확인한다. [라벨 입장과 역전파](../../test_result/109_20261119004016_P109-기존G4-방문-세정책-실제갱신.md#p109c-verified-decimal-label-exposure-20261124)

**교과 계수 보정은 학습률이 높은 구간에서 끝냈다.** v3에서 초반 60혼합 갱신의 계수 0.10을 유지하고 WSD 감쇠 전에 희소 감독의 계수를 제한했다. 실제 혼합 배치의 계수를 검산했고, 학습 보조 헤드 두 개를 제거한 본체가 공식 평가 경로의 엄격 로드를 통과했다. [일정 검산](../../test_result/109_20261119004016_P109-기존G4-방문-세정책-실제갱신.md#p109c-wsd-course-caps-result-20261124) · [실제 배치·내보내기 검산](../../test_result/109_20261119004016_P109-기존G4-방문-세정책-실제갱신.md#p109c-native-curriculum-cpu-readback-result-20261124)

**이전 개선 방법의 재현 여부를 볼 때** v2는 원문과 교과를 섞은 무부모 완주 기준이다. v3는 기존 v2 교과와 한영 대응 교과를 같이 학습했다. 기법별 효과는 교과 투입 시점·손실 비중, 원문 창, 답 형식을 고정하거나 따로 바꾼 대조에서 판단한다. [v3 완주와 판정](../../test_plan/P109_16층-공유-재귀-프리셋-통합.md#p109c-integrated-v3-disposition-20261124) · [기존 v2 완주](../../test_result/109_20261119004016_P109-기존G4-방문-세정책-실제갱신.md#p109c-v2-full-scratch-mixed-result) · [프리셋별 적용 근거](방법론_적용_판정.md)

**초기 기술 검증을 읽을 때** 원문 검증 손실, 체크포인트 복원, 한영 자유 생성의 정답을 각각 확인한다. 서로 다른 실험에서 관찰된 속도나 복원의 효과를 하나의 품질 개선폭으로 더할 수 없다. [교과 CE 대조](../../test_result/109_20261119004016_P109-기존G4-방문-세정책-실제갱신.md#p109c-early-course-share-result-20261124) · [한영 감독과 파일 재개](../../test_result/109_20261119004016_P109-기존G4-방문-세정책-실제갱신.md#p109c-bilingual-native-resume-result-20261124)

**원문 창을 전량 교체한 모델은 평가까지 마쳤다.** 전량 교체 입력에는 v2가 보지 않았던 위치가 232,474,309개 있었다. 기존 v2보다 공통 원문 NLL은 높아졌고 실사용 합계는 줄었다. 기존 위치를 우선 보존한 CPU 편성의 새 위치는 53,383,722개이며, 이 편성의 학습 품질은 미확인이다. 두 교체 편성은 원문 목표 300,023,808개를 중복 없이 배치한다. [원문 위치와 문서 비교](../../test_result/109_20261119004016_P109-기존G4-방문-세정책-실제갱신.md#p109c-raw-window-document-exposure-result-20261124) · [전량 교체의 실사용 평가](../../test_result/109_20261119004016_P109-기존G4-방문-세정책-실제갱신.md#p109c-raw-recovery-official-result-20261124) · [당시 종결 원장](../../handoff/WIP_20261124_작업원장-done.md)

## P077 문맥 확장

**연결 학습은 첫 행 선택과 둘째 값 선택을 따로 본다.** 정답 행을 입력하면 연결 감독이 번호 선택을 회복했다. 모델이 첫 행도 고른 경우 번호 정답이 감소했다. [CPU 학습과 조건별 정답](../../test_result/065_20260831_P077-bf16-KV-는-정확히-절반이고-cla2-재귀가-32MiB-예산에-들어왔다.md#p077-cpu-linked-supervision-result-20261124)

단일 이름이 명시된 표에서는 문자열 조회로 행 256/256과 최종 번호 156/256을 맞혔다. 두 이름인 경우 규칙은 보류하고, 이름·질문 구간을 감독한 조건은 번호 52/256을 맞혔다. [첫 행 선택과 번호 정답](../../test_result/065_20260831_P077-bf16-KV-는-정확히-절반이고-cla2-재귀가-32MiB-예산에-들어왔다.md#p077-first-row-span-result-20261124)

INT8 파일을 한 번 읽어 공유하는 질의를 16→24행으로 넓혔다. 같은 장문 두 요청의 파일 API 읽기가 24.61% 줄었으며 생성은 그대로였다. [후속 자원 실측](../../test_result/065_20260831_P077-bf16-KV-는-정확히-절반이고-cla2-재귀가-32MiB-예산에-들어왔다.md#p077-file-int8-staged24-result-20261124)

**원래 질문을 유지한 항목 안내를 별도로 확인한다.** 두 표와 질문 사이에 지정 내용을 덧붙여도 세 조건 모두 0/16이었다. 문구 안내만으로 나타난 출력 변동과 실제 두 근거 연결을 구분한다. [같은 질문에서 항목 안내 비교](../../test_result/065_20260831_P077-bf16-KV-는-정확히-절반이고-cla2-재귀가-32MiB-예산에-들어왔다.md#p077-linked-tables-assignment-note-result-20261124)

**여러 근거 연결은 두 표의 값을 따로 바꿔 검증한다.** 4,083토큰 원문과 짧은 두 표에서 지정 항목 변경이 답에 반영되지 않았다. 첫 표에서 읽은 항목을 명시해 둘째 표를 물으면 14/16을 맞혔다. [연결과 단일 추출 대조](../../test_result/065_20260831_P077-bf16-KV-는-정확히-절반이고-cla2-재귀가-32MiB-예산에-들어왔다.md#p077-linked-tables-result-20261124)

**이미 양자화한 코드를 활용한다.** FP16 복원값 대신 원래 INT8 코드와 스케일을 파일에 기록하면 같은 정보를 더 적게 읽는다. 두 4,086토큰 요청에서 경계 로짓과 긴 응답을 보존했고 읽기는 47.66% 줄었다. [정밀도를 유지한 파일 저장 비교](../../test_result/065_20260831_P077-bf16-KV-는-정확히-절반이고-cla2-재귀가-32MiB-예산에-들어왔다.md#p077-file-int8-packed-result-20261124)

**길이와 근거 위치의 영향을 확인한다.** 짧은 조건에서 조회한 같은 표에 동일한 긴 본문을 붙여 근거가 처음 또는 끝일 때를 짝짓는다. 파일 KV의 낮은 프로세스 RSS와 장문에서 근거를 답에 반영하는 품질을 함께 기록한다. [한영 긴 직접 조회](../../test_result/065_20260831_P077-bf16-KV-는-정확히-절반이고-cla2-재귀가-32MiB-예산에-들어왔다.md#p077-long-guided-placement-result-20261124)

**읽기 비용과 답변 품질을 함께 확인한다.** 파일 KV로 상주 메모리를 줄일 수 있고, 여러 쿼리에 파일 조회를 공유하면 프로그램의 누적 읽기량도 줄일 수 있다. 같은 출력과 어휘 로짓을 보존했다는 관측은 경로의 수치 일관성을 지지한다. 장문 정답을 회복하려면 위치·질문 변경과 여러 근거를 포함한 품질 대조가 필요하다. [문맥 연구와 판정](../../test_plan/P077_KV캐시-정밀도와-컨텍스트-길이.md#p077-bounded-context-exact-block-20261124) · [실제 읽기와 경계 로짓 검증](../../test_result/065_20260831_P077-bf16-KV-는-정확히-절반이고-cla2-재귀가-32MiB-예산에-들어왔다.md#p077-file-staged-prefill-result-20261124)

**표 제목을 아는 질문과 뜻으로 표를 가리키는 질문을 구분한다.** 새 부서 표현과 범주의 보관 문항에서 문자 유사도는 질문과 표 순서가 함께 바뀌는 경우를 해결하지 못했다. 다음 장문 평가에서는 질문의 의미 단서, 표 선택, 최종 답의 정답 여부를 함께 기록한다. [표 선택 대조](../../test_result/065_20260831_P077-bf16-KV-는-정확히-절반이고-cla2-재귀가-32MiB-예산에-들어왔다.md#p077-table-lexical-control-result-20261124)

다른 연구 주제를 추가할 때는 결정 이유와 다음 판단을 중심으로 정리하고, 해당 문서의 실제 절을 연결한다.
