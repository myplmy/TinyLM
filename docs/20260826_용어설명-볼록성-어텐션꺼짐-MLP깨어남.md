# (a) ★**"볼록하다" · "볼록성"**

## a.1 무슨 뜻으로 쓰고 있나

**레버를 한 칸 더 밀 때 드는 값이 앞칸보다 비싸지는 것**이다. 수학의 볼록함수에서 가져온 말이지만
우리가 쓰는 뜻은 좁다 — ★**"한계비용이 증가한다"** 다.

```
  품질 손실(누적)
    ^                                       ★볼록: 갈수록 가팔라진다
    |                              ,-'
    |                        ,--'
    |                 ,---'
    |          ,----'
    |  ,-----'
    +-------------------------------> 레버를 민 정도 (g8 -> g16 -> g32)

    같은 "한 칸" 인데 뒤로 갈수록 세로로 더 많이 올라간다 = 볼록
```

## a.2 어디서 나온 말인가 — 실측 두 건

| 근거 | 무엇 |
|---|---|
| **결과 032 §8.3** | ★**같은 `g16` 이 더 작은 기반(`p1c1`) 위에서 1.57배 비쌌다** |
| **결과 041 §14.3** | 더할 때 0.00118 vs 뺄 때 0.00342~0.00443 nats/유니크삼진100만 |

## a.3 🚫★**2026-08-26 — 이 말을 좁혀야 한다** (결과 029 §11)

| 축 | 한 칸 더 밀었을 때 | 볼록한가 |
|---|---|---|
| 임베딩 랭크 E=192 → 128 | **2.18배** | ✅ |
| 어텐션 ag4 → ag8 → ag16 | **4.6 → 6.0배** | ✅ |
| ★**MLP g16 → g32** | ★**0.91배**(0.00312 vs 0.00342) | 🚫★**아니다 — 오히려 싸졌다** |

★★**네 축 중 하나가 반례다.** → 🚫**"볼록성" 을 근거로 안 잰 점을 예측하지 않는다.**
그건 **관찰된 패턴**이지 법칙이 아니다.

## a.4 실무에서 쓰는 법

| ✅ | 🚫 |
|---|---|
| *"세 점이 볼록했다"* (관찰 보고) | *"볼록하니 다음 점은 더 비쌀 것이다"* (예측) |
| *"평균가격으로 예측 금지"*(032 §8.3) | *"평균가격 × 2 = 두 칸 비용"* |

# (b) ★**"어텐션이 꺼진다" · "안 깨어났다"**

## b.1 무슨 값을 말하는가 — **게이트**

`modules.py` 의 `Layer` 는 층마다 **게이트 두 개**를 갖는다:

```python
g0 = 1.0 / math.sqrt(cfg.n_layers)
self.gates = nn.Parameter(torch.tensor([g0, g0]))   # [어텐션 게이트, MLP 게이트]
```

층의 출력은 대략 `x = x + gate_attn · attn(ln1(x))` 그리고 `x = x + gate_mlp · mlp(ln2(x))` 다.
★**게이트가 그 층의 어텐션·MLP 가 잔차에 얼마나 섞이는지를 정한다.**

★**초기값이 `1/√n_layers`** 이므로 학습 시작 시점에는 전부 같다.
→ ★**학습 후 게이트가 초기값보다 커졌으면 "깨어났다", 작아졌으면 "꺼졌다"** 고 부른다.

## b.2 어디서 나온 말인가 — 결과 041 §15

`mC_d36`(20층 → 36층 깊이 확장)에서 **복제된 층**의 게이트가 학습 뒤 어떻게 변했나:

| | 게이트 변화 | 우리가 쓴 말 |
|---|---:|---|
| ★**어텐션** | ★**×0.279** (초기값의 28%) | 🚫**"꺼졌다"** |
| ★**MLP** | ★**×1.434** (초기값의 143%) | ✅**"깨어났다"** |

★**같은 층 안에서 두 게이트가 반대로 움직였다.**

## b.3 ★그래서 무엇을 뜻했나

> **"이식이 어텐션 깊이를 못 살렸다"** (041 §15)

깊이 확장은 교사(20층)의 층을 복제해 36층을 만든다. 학습이 그것을 **어떻게 쓰기로 했는지**를
게이트가 말한다: ★**복제층의 MLP 는 쓰기로 했고(1.43배), 어텐션은 안 쓰기로 했다(0.28배).**

🚫**"어텐션이 쓸모없다" 가 아니다.** *"이 이식 방식으로 만든 복제 어텐션이 쓸모없었다"* 다.

## b.4 ⚠️혼동하기 쉬운 두 가지

| 말 | 실제 대상 |
|---|---|
| ★**"게이트가 꺼졌다"** | **학습이 정한 값**(게이트 파라미터). 관찰 |
| ★**"게이트를 0 으로 한다"**(U2, 결과 057) | **우리가 강제로** 0 을 넣어 손실 변화를 본다. 개입 |

★**둘은 다르다.** b.2 는 *"학습이 스스로 껐다"*, U2 는 *"우리가 꺼 보았다"* 다.
⚠️**그리고 결과 057 §11.2 가 U2 의 함정을 밝혔다** — `cla_group=2` 에서 게이트를 0 으로 하면
**K/V 사슬까지 끊겨** 그 층의 중요도가 아니라 사슬 효과를 재게 된다.

# (c) ★**"MLP 가 깨어난다"**

## c.1 (b)와 같은 지표의 반대편

`gates[1]`(MLP 게이트)이 **초기값보다 커진 것**이다. 결과 041 §15 에서 **×1.434**.

## c.2 ★왜 이것이 결론이 됐나

**같은 복제층**에서 어텐션은 0.279, MLP 는 1.434 로 갈렸다는 사실이 다음을 말한다:

| # | 읽은 것 |
|---|---|
| 1 | 🚫*"복제층 전체가 죽었다"* 가 **아니다** — MLP 는 오히려 더 쓰인다 |
| 2 | ★**이식의 문제는 어텐션 쪽에 있다** — 그래서 P057(어텐션 타잉)로 이어졌다 |
| 3 | ★**깊이는 값어치가 있다** — 다만 어텐션을 늘리는 형태로는 아니다 |

## c.3 ★이 말이 지금 어디에 서 있나

★**결과 044 가 그 판단을 확증했다**: `mC_d36_ag4`(36층 + 어텐션 4층 공유)가
**상주 −15.9%** 이면서 품질 **+0.0072** 였다 — ★**어텐션을 줄이고 깊이를 얻는 것이 맞았다.**
