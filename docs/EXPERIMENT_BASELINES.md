# 실험 조건 기준표 (EXPERIMENT_BASELINES)

**이 파일은 `exp-preflight` 스킬의 참조 정본이다.** 새 실험을 설계할 때 여기와 대조해
① 조건 중복 ② 계산 오류 ③ 태그 충돌 ④ 무효 비교 를 사전에 걸러낸다.

> **★이 파일이 보증하지 못하는 것**: 여기 적힌 것은 **과거 실측치와 설계 규칙**일 뿐이다.
> 대조를 통과했다는 것은 "알려진 실수를 반복하지 않았다"는 뜻이며, **새 실험이 성공한다거나
> 가설이 참이라는 보장은 전혀 아니다.** 실제로 그런지는 돌려봐야만 안다.
> 자세한 한계는 `.claude/skills/exp-preflight/SKILL.md` §한계 참조.

**갱신 규칙**: 새 런이 끝나면 §2 레지스트리에 한 줄 추가. 새 사실이 규칙을 바꾸면 §3~§7 개정 +
개정 근거(결과 번호)를 함께 적는다. 수치 정본은 항상 `runs/logs/*.json`.
최종 갱신 2026-07-30(결과 013 시점 · REVIEW1 완료).

### 예산 → steps 환산표 (계산 오류 1순위 원인)

`학습토큰 = steps × micro_bs × accum × seq`. `--micro-bs 8 --accum 16 --seq 1024` = 131,072/step.

| 목표 학습토큰 | steps | 실제 | 권장 풀 |
|---|---|---|---|
| 100M | **763** | 100.0M | 600M |
| 255M (300M의 -15%) | **1946** | 255.0M | 600M |
| 300M | **2289** | 300.0M | **600M** |
| 600M | **4578** | 600.0M | **1200M** ← 결과 006 의 600M 행은 풀 600M(=1×)이라 결핍 상태 |

> **함정**: `--accum` 기본값은 **8** 이다. 빠뜨리면 같은 steps 로 **절반(150M)만** 학습된다.
> 결과 005 초판이 이 실수로 오염됐다. mb/accum 을 바꾸면 이 표를 다시 계산할 것.

## 4. 판정기준과 그 한계

`≤ +0.07` 성립 / `+0.07~+0.15` prelude·coda↑ 또는 g↓ / `> +0.15` 는 `grad_max` 먼저 확인.

- ✅ **σ 실측 완료(결과 012)**: `p6d`(3.704531) vs `p6d_s2`(3.692656, 시드만 2024) →
  **|Δ| = 0.0119, σ̂ ≈ 0.0105~0.012**. `2σ ≈ 0.024 < 0.07` 이므로 **임계값 유지**(갱신 불필요).
- **실무 분해능 = 0.024**. 그보다 작은 차이는 **구분 불가** — 서열을 매기지 않는다.
- 표본 2개 추정이라 자릿수 판정("0.01 급")으로만 쓴다. 추가 런의 실익은 낮다.
- 기존 결론 재평가: 006 타잉격차 16σ · 006 풀효과 11σ · 008 s34 격차 3.5~5.8σ · 005 k4 3.5σ
  → **노이즈로 무너지는 결론은 없다**. 002 의 +0.005 만 0.5σ 이나, 그건 "격차 소멸" 주장과 부합.
- 안정성 판정은 **json `grad_max`**(인쇄 `|g|` 는 10스텝 샘플이라 과소). `grad_peak_warmup` 은 별도.
- 결과 007 의 "동일 런 0.11 발산"은 `grad_max` 10.8~35.4 의 **불안정 구간** 값이라 σ 와 무관.

### ★★4.1 **step0 값의 유효 범위** — 이진 게이트이지 크기 예측기가 아니다 (2026-08-14 신설)

> **판정**: **step0 CE 는 "이식/초기화가 작동했는가" 의 GO/NO-GO 에만 쓴다.**
> **학습 후 격차의 크기·순위·축의 개폐를 step0 으로 결정하지 않는다.**

#### 근거 — 같은 축에서 step0 과 학습 후를 **둘 다 잰 사례 2건**

| 축 | step0 Δ | 학습 후 Δ(paired) | **배수** | 방향 |
|---|---:|---:|---:|---|
| **P049 깊이 36층**(결과 041 §13·§14) | **−0.5148** | **−0.0250** | ★**1/20.6** | ✅ 유지 |
| **P049B 반복 R=2**(결과 043 §4·§13) | **+0.1025** | **+0.2275** | ★**2.22배** | ✅ 유지 |

- **방향은 2/2 유지.** 부호 예측기로는 (표본 2개 한도에서) 쓸 만하다.
- **크기는 1/20.6 ~ 2.22배 = 46배 범위.** 한쪽은 **줄고** 한쪽은 **늘었다** →
  **보정 계수도 만들 수 없다.**

#### 왜 그런가 — **"학습이 초기 핸디캡을 회수한다" 가 축마다 참/거짓이다**

| 초기 핸디캡의 성질 | 학습이 하는 일 | 결과 |
|---|---|---|
| **함수 근사 오차**(교사에 없던 층을 새로 만든다) | 학습이 **메운다**. 동시에 기준선도 같이 좋아진다 | 초기 이점이 **줄어든다**(P049) |
| **학습 분포 자체의 변화**(같은 가중치를 두 번 통과) | 메울 대상이 아니다 — **매 스텝 지불** | 초기 손해가 **누적된다**(P049B) |

step0 은 **초기점**을 재고, 판정 대상은 **그 초기점에서 출발한 2289스텝 궤적의 종점**이다.
**그 구간의 동역학은 step0 에 들어 있지 않다.**

#### 쓰는 법 / 쓰지 않는 법

| ✅ 유효 | 🚫 무효 |
|---|---|
| *"난수 대조군(≈`ln V`)보다 확실히 낮은가"* = **이식이 됐는가** | *"학습 후 대가가 얼마일 것이다"* |
| *"통과 대역 5.0~9.3972 안인가"* = **구조가 성립하는가** | *"A 가 B 보다 낫다"* = **후보 서열** |
| *"죽지 않는가 / 알리는가"*(G0-a·G0-b) | *"상한의 1/3 이니 여유가 있다"* = **축을 연다** |
| step0 ce ≈ `ln V` → **초기화 실패 탐지**(결과 030) | *"거의 무관하다 / 우선순위를 낮춘다"* = **축을 닫는다** |

⚠️**"대역 안에 둘 다 있다" 는 유효하다**(이진 판정). **"둘 중 어느 쪽이 대역 안에서 더 낮다" 는 무효다.**

#### ⚠️짧은 런(250스텝)은 **다른 문제다** — 그리고 잘 쓰이고 있다

| 재는 양 | 필요한 길이 | 근거 |
|---|---|---|
| **VRAM(reserved/alloc)** | **250스텝이면 충분** | 결과 046: `ms_step_spread` **0.4% / 0.2%** = 정상상태 도달 |
| **속도(`ms_step_median`)** | **250스텝이면 충분** | 위와 같음. 단 **같은 세션**이어야 한다(드리프트 7.5%) |
| **품질** | **2289스텝 + `paired_eval`** | 250스텝 val 은 판정에 쓰지 않는다 |

> ★**짧은 런의 문제는 "짧다" 가 아니라 "짧은 런으로 무엇을 재느냐" 다.**
> F-1(결과 046)은 250스텝으로 VRAM·속도만 재고 *"Do NOT read val"* 을 배치에 적어 두고 **지켰다.**
> **step0 의 잘못은 길이가 아니라 관측 시점과 주장하는 양의 불일치다.**
