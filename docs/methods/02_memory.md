### 3:4 희소 삼진 (Sherry 1.25bpw) — 후보 (P016)
근거: Sherry(arXiv:2601.07892). 4-블록마다 정확히 1개를 0으로 강제(3개만 ±1) → `C(4,3)·2^3=32=2^5`,
5비트 무낭비 포화 = **1.25 bpw**(현 1.95 대비 ×1.56 추가절감), AVX2 vpshufb LUT 정합.
타잉과 곱셈 누적(g8 2.09× → ~3.2× 상한). 안정화 **Arenas = 우리 삼진 어닐의 특수형**(이미 보유).
리스크: 25% 강제-0의 용량손실이 공격적 타잉·KD와 복합될 수 있어 **m100 실측 필요**.
상태: **구현완료(`--sparse34`, 2026-07-25)** — `_TernarySTE` 3:4 경로 + report/compare 1.25bpw 분기.
실행 `run100m_P016.bat`. Sparse-BitNet(arXiv:2603.05168)이 "삼진 LLM은 준정형 희소에 자연 친화"로 근거 보강.
