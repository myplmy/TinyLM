# 2. 메모리 감축

배포 메모리(가중치·KV 캐시) 축소. 이 프로젝트의 1차 목표.

| 기법 | 상태 | 버전 | 작동원리(개선 기여) | 트레이드오프 | 특기 |
|---|---|---|---|---|---|
| **g128 삼진 양자화** | ✅ | v4~ | 가중치를 {-α,0,+α} 3진 + g128 그룹 스케일 → 약 1.95bpw | 품질 소폭(어닐로 완화) | llama.cpp Q2_0_g128 / T-MAC 호환. TWN 임계+L2 alpha |
| **MLP 타잉 (g=4)** | ✅ | v4~ | 중간 MLP를 4층 1그룹 공유 → 파라미터 132.5M→72.9M | 손실 격차 | 감축 **1.82×**. 메모리 축의 최대 기여 |
| **CLA2** | ✅ | v4~ | KV를 2층 공유 → KV 캐시 15→7.5 KB/token | 표현력 소폭 | 긴 컨텍스트에도 직접 기여(4번) |
| **Factorized embedding** | ✅ | v4~ | V×E+E×d 저랭크 → 임베딩 메모리 바닥 제거 | 로짓 랭크 E 제한 | (a)64k+(b)E=512 조합 시 9.2× |
| **g 스윕 (g=6, 8)** | 🧪 | v6 | 공유 강도↑ → 감축↑ | 손실↑ | g=8 → **2.08×**(63.5M). 한계 탐색용 |
| **Ternary-LoRA (저비트)** | 🧪 | v6 | 격차 복원을 저비트 LoRA로 → 품질 복원하며 메모리 거의 유지 | r·bits 의존 | r=32 ternary → 1.71× (fp16은 1.46×) |
| **어텐션 g=2** | 💡 | — | 어텐션까지 부분 공유 | 층 차별화↓(비싼 영역) | 메모리가 더 필요할 때만 |
| **vocab 64k 축소 / 1-bit 임베딩** | 🔜 | — | 임베딩·lm_head 추가 축소 | 한국어 토큰 증가/토크나이저 재학습 | 1.7B 확장 시 |
| **4bit KV** | 🔜 | — | KV 캐시 추가 압축 | 정확도(2bit V→cos 0.94) | TurboQuant: RoPE-first 필요 |
