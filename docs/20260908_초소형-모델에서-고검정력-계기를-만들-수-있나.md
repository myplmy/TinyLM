## 0. 세 줄

1. ★**문제는 "문항이 적다" 가 아니라 "문항당 정보가 적다" 이다.** 우리 held-out 300문항 중
   **66~80%가 어느 비교에도 정보를 0 준다**(두 모델이 같은 답을 낸다).
2. ★★**그래서 N 을 늘리는 것 말고 네 갈래가 더 있다** — 분산을 줄이기 · 효과를 키우기 ·
   문항당 정보를 늘리기 · 반복 측정. **넷 다 우리 데이터로 시작할 수 있다.**
3. ✅**둘은 이미 값을 냈다** — `gold_margin`(ρ +0.943) · 시드 pooling(z 를 살렸다).
   ★**가장 큰 미개봉 레버는 "무변별 문항 제거"** 이고 ⚙0.2h 로 셀 수 있다.

## 1. 문제를 정확히 적는다

두 모델의 정확도 차 `Δ` 를 유의하게 보려면

    N ∝ σ² / Δ²

우리 수(결과 074 §23 · 056):

| 비교 | Δ | 필요 문항 | 보유 |
|---|---:|---:|---:|
| 우연 대비(절대 하한) | +6.7 ~ +14.8 %p | ★**약 48** | 300 ✅ |
| 계열 **간**(`d12`−`mC`) | 10.7 %p | **97 ~ 246** | 300 ✅ |
| 계열 **안**(`d12`−`d14`) | ~1 %p | ★**984 ~ 10,800** | 300 🚫 |
| `arc_easy`(우리끼리) | 0.4 ~ 2.0 %p | **2,451 ~ 7,458** | 2,376 🚫 |

★**즉 막힌 것은 "계열 안" 하나**다. 그리고 그것이 **배포 후보를 고르는 자리**다.

## 2. ★★진단 — **문항의 대부분이 정보를 안 준다**

`paired` McNemar 의 **불일치 쌍 수**가 그 비교에 실제로 기여한 문항 수다.
결과 074 §23 의 15개 쌍에서:

| 비교 | 불일치 / 300 | ★**정보 0 인 문항** |
|---|---:|---:|
| `d12`s1 − `d16`s1 | 82 | **73%** |
| `d12`s1 − `d14`s1 | 98 | **67%** |
| `d14`s1 − `d16`s1 | 76 | **75%** |
| `d16`s1 − `d16`s2 | 60 | ★**80%** |
| (전체 범위) | 60 ~ 103 | **66 ~ 80%** |

> ★★**300문항을 샀는데 실제로 일하는 것은 60~103개다.**
> 나머지는 **둘 다 맞히거나 둘 다 틀린 문항** — 너무 쉽거나 너무 어렵다.
> 🚫**문항을 3배로 늘리는 것(⚙비싸다)과 무변별 문항을 걸러 내는 것(⚙0.2h)이 같은 효과**를 낸다.

## 3. 네 갈래 — **N 을 늘리지 않고 검정력을 올리는 법**

| 갈래 | 원리 | 우리 후보 | ⚙ | 예상 이득 |
|---|---|---|---:|---|
| ★**A. 분산을 줄인다** | 이산화 손실을 없앤다 | ✅**`gold_margin`**(완료) · paired 설계(완료) | 0 | ⚙**2~4배**(미측정) |
| ★★**B. 효과를 키운다** | 변별도 높은 문항만 | ★**무변별 문항 census + 선별** | **0.2h** | ⚙**1.5~3배** |
| ★**C. 문항당 정보를 늘린다** | 답 하나 대신 **순위** | ★**4지선다 → 4개 전체 순위** | **0.3h** | ★**2.3배**(정보량 log₂4! / log₂4) |
| **D. 반복 측정** | 시드·표본을 쌓는다 | ✅**시드 pooling**(결과 074 §23) | 학습 3.0h/시드 | **시드 수에 선형** |

### 3.1 ✅A — **이미 값을 냈다**

`gold_margin` 은 정확도의 **연속판**이고, 첫 실전에서 **정확도 순위와 ρ +0.943**
(정답CE 는 −0.371). ★**계산 비용 0** 이다.

⚠️**그런데 "필요 문항이 몇 배 줄었는가" 를 아직 안 쟀다** — 도구가 `gold_ce` 기준 필요N 만 인쇄한다.
→ ★**측정 E5**: `eval_bench_suite` 가 **마진 기준 필요N** 을 함께 인쇄하게 한다(⚙**0.1h**).
🚫**이 수 없이 *"마진이 검정력을 올린다"* 라고 쓰지 않는다.**

### 3.2 ★★B — **가장 큰 미개봉 레버. 그리고 가장 싸다**

**census 로 시작한다**(학습 0 · GPU 0):

| # | 세는 것 | 무엇이 나오나 |
|---|---|---|
| **B1** | 6개 체크포인트가 **전부 맞힌** 문항 수 | **너무 쉽다** — 정보 0 |
| **B2** | **전부 틀린** 문항 수 | **너무 어렵다**(또는 결함 문항) — 정보 0 |
| ★**B3** | 나머지의 **정답률 분포** | ★**변별 대역(0.2~0.8)에 몇 개** 있나 |
| ★**B4** | 문항별 **정오 상관**(모델 6개 벡터) | 서로 **같은 것을 재는 문항** 묶음 |

★**그 다음이 선별**인데 ⚠️**여기에 함정이 있다**:

> 🚫★★**선별에 쓴 데이터로 평가하면 안 된다.** 변별력 높은 문항만 골라 남기면
> **그 선별에 쓰인 모델들 사이의 차이가 자동으로 과장**된다(선택 편향).
> ✅**해법 둘**: ①**선별은 다른 모델 집합으로** 한다 ②**선별 규칙을 문항 생성 지침에 넣어**
> **새 문항**을 만든다(2B 의 held-out 증보 요청서와 묶인다).

### 3.3 ★C — **순위 응답: 같은 문항에서 2.3배**

4지선다에서 우리는 **argmax 하나**만 쓴다(정보 log₂4 = **2 bit**).
그런데 우리 채점기는 **후보 4개의 점수를 전부** 구한다 — **순위 전체**를 쓰면 log₂4! = **4.58 bit**.

| 지표 | 정보량 | 구현 |
|---|---:|---|
| 정오(현행) | 2.00 bit | 완료 |
| ★**정답 순위**(1~4위 중 몇 위인가) | ⚙**~3.0 bit** | ⚙**0.2h** — 점수는 이미 있다 |
| ★**전체 순위 상관**(켄달 τ, 정답을 1위로 둔 기준 순위와) | ⚙**4.58 bit** | ⚙0.3h |

★**정답 순위(mean reciprocal rank 계열)가 값어치 대비 가장 싸다** — 정답이 2위인 모델과
4위인 모델을 **현행 지표는 똑같이 "틀림"** 으로 센다.

### 3.4 D — **시드 pooling: 이미 작동을 봤다**

결과 074 §23 이 두 시드를 합쳐 `d12−d16` **z +3.30**, `d14−d16` **+2.81** 을 살렸다.
⚠️**단 비용이 학습 3.0h/시드**라 A·B·C 를 다 쓴 뒤의 수단이다.
★**그리고 시드 pooling 은 "계기의 시드 노이즈" 문제도 함께 다룬다**(같은 아키텍처 z +2.21).

## 4. ★그 밖의 후보 — **검토했고 지금은 안 한다**

| 후보 | 무엇 | 왜 지금 아닌가 |
|---|---|---|
| **IRT**(항목반응이론) | 문항 난이도·변별도를 추정해 능력 θ 를 잰다 | ⚠️**모델 6개로는 문항 파라미터를 못 맞춘다**(문항 300 × 응답자 6). ★**응답자가 수십은 돼야** — 우리 체크포인트가 그만큼 쌓이면 열린다 |
| **최소대조쌍**(BLiMP 형식) | 한 토큰만 다른 두 문장의 우도 비교 | ✅**분산이 매우 작다**(문맥 공유). 🚫**한국어 판이 없다** — 만들면 2B 소관 |
| **자유생성 + 자동채점** | 실사용에 가깝다 | 🚫**채점 타당성이 선결**(2B §4). 그리고 **분산이 커서 검정력이 더 나쁘다** |
| **온도 샘플링 분산** | 실사용의 랜덤 요인(§8.4) | ★**다른 양을 잰다** — 검정력 도구가 아니라 **위험도 도구**다 |
| **로그우도 자체를 순위로** | 정답CE | 🚫**이미 안 된다** — ρ −0.371(공통 유창성 항) |

## 6. ⚠️정직한 한계 — **넷**

1. 🚫★**§3 의 "예상 이득" 은 전부 ⚙추정**이다. **B·C 는 우리 데이터에서 한 번도 안 쟀다.**
2. ⚠️**B 의 선택 편향**(§3.2)이 이 조사에서 가장 위험하다 — **문항을 고르는 순간 평가가 오염**된다.
3. 🚫**어떤 계기도 "이것이 지능이다" 를 답하지 않는다.** 전부 **같은 과제를 더 정밀하게** 재는 법이다.
   ★**과제가 틀렸으면 정밀도를 올릴수록 틀린 답을 확신하게 된다.**
4. ⚠️**초소형 특유의 문제 하나** — 우리 모델은 **우연 근처**에 있다(27~40%).
   ★그 대역에서는 **정확도의 분산이 최대**(p≈0.5 에서 최대에 가깝다)라 **구조적으로 불리**하다.
   → ★**모델이 좋아지면 같은 문항 수로 더 잘 갈린다** — 계기만의 문제가 아니다.
