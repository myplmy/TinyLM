# 현재 연구 모델 6종을 직접 질문하는 방법

이 메뉴는 2026-10-21에 실제 완료된 6종만 지원합니다. 번호는 품질 순위가 아니며 모두 안정적인 일반 대화능력은 아직 확보하지 못했습니다. [결과101 §422](../test_result/101_20260927_P106B-번역9건으로-문턱미달-학생학습0.md)와 [실제 GPU 대조](../handoff/audit/WIP_20261021_RESEARCH_INFER_GPU_PARITY.json)가 검증 범위를 소유합니다.

```bash
cd /home/uranus/tinyLM
./research_infer.sh
```

|번호|이름|학습 이력|
|---:|---|---|
|1|native595-q|무부모 native595M 삼진|
|2|native595-f|동일 초기값/기초학습 실수|
|3|old299-broad-q|이전299M 삼진 부모+Broad704|
|4|old299-broad-f|이전299M 실수 부모+Broad704|
|5|new595-broad-q|새595M 삼진 부모+같은 Broad704|
|6|new595-broad-f|새595M 실수 부모+같은 Broad704|

모델 번호를 고른 뒤 `질문>`에 입력하세요. `:quit` 또는 `:q`로 종료하고 다른 모델을 선택하려면 다시 실행합니다. 기본은 질문마다 독립 입력입니다. 실제 자신의 답변 이력을 이어가려면 다음과 같이 실행하세요.

```bash
./research_infer.sh --model 6 --history
```

`:reset`은 현재 이력만 초기화합니다. 학습하거나 원본 대화를 수정하지 않습니다. 이력이 문맥1024에 들어가지 않으면 조용히 앞부분을 자르지 않고 거부합니다.

한 번만 질문하거나 목록만 보려면:

```bash
./research_infer.sh --list
./research_infer.sh --model new595-broad-f --prompt '문맥: 민수는 사과 3개, 영희는 사과 5개입니다. 영희는 몇 개입니까?' --max-new 64
```

이 도구는 GPU 전용입니다. FP32-MATH/TF32off/KVon/MTPoff/greedy·기본 생성128토큰을 사용합니다. 다른 GPU compute 프로세스나 조회 오류가 있으면 실행하지 않습니다. 메모리 점조회는 장기 OOM 안전 보장이 아닙니다.

실제 체크포인트·본체·토크나이저·실수/삼진 경로를 검증하며 향후 소스나 원형이 바뀌면 추측해서 열지 않습니다. 그때는 새 root 검증/manifest가 필요합니다. 잘못된 답도 바꾸거나 숨기지 않고 종료 이유·토큰 수와 함께 표시합니다. STOP_SEQUENCE/EOS는 정답 판정이 아닙니다.

실험 큐에 넣지 마세요. 사람의 TTY 수동 입력 전용이며 비대화 실행에는 `--model`과 `--prompt`가 모두 필요합니다. 기본적으로 로그·체크포인트를 저장하지 않습니다. 공용 추론기/기존 dirty 메뉴는 수정하지 않았습니다. 이 인터페이스의 존재가 GPT의 GPU 실행 권한을 자동 부여하지 않습니다.
