# Hadamard 회전·삼진화 선행연구와 TinyLM 적용성 조사

> 작성 2026-09-25 · 문헌/설계 조사 `DESIGNED` · TinyLM 새 회전 구현·품질·속도 실험 `NOT_RUN`
> 직접 근거: [Bonsai 2 백서 판독 §7](methods/08_paper_review2.md), [P014D 결과069](../test_result/069_20260902_P014D-디코드-프로파일이-경로이름을-양자화형식으로-넘겨-두-팔-다-죽었다.md), [P025B 결과082](../test_result/082_20260913_P025B-import-실패로-2대4-게이트는-미실행이다.md). 이 보고서는 다른 모델의 수치를 TinyLM 예측치로 옮기지 않는다.

## 0. 결론

가장 먼저 시험할 것은 회전의 도입 자체가 아니라 **현재 TinyLM의 층별 outlier·삼진 재구성 오차·패킹/변환 wall 병목을 같은 checkpoint에서 계측**하는 것이다. 그 뒤 고정 부호-Hadamard를 TLinear의 단일 선형층에만 적용하고, 추가 런타임 변환·padding 비용이 손실/속도 이득보다 작을 때에만 구조 통합을 논의한다. 민감 텐서 일부의 고정밀 보존과 새 PTQ threshold 최적화는 별도 독립변수다. 백서의 회전·1.76bpw·20벤치 평균은 우리 약100M QAT·CLA·g128 모델의 개선 보증이 아니다.

## 2. TinyLM 구조에 맞춘 수학·구현 경계

현재 [`TLinear`](../tinylm/model/ternary.py)은 `weight[O,I]`를 입력축 g128로 잘라 절댓값 평균 임계와 선택된 값의 alpha를 계산하고 STE로 gradient를 보낸다. `sparse34`는 별도 3:4 패턴이며 2:4·Bonsai 삼진 pack과 동일하지 않다. 배포 `_wq`/int8/LUT 및 타잉 재사용은 학습 master와 또 다른 계층이다.

- 한 선형층의 실수 산술 동치는 `y=Wx`, `RᵀR=I`일 때 `x'=Rx`, `W'=WRᵀ`, `W'x'=Wx`다. **`Q(WRᵀ)`로 삼진화한 뒤에는 일반적으로 같지 않다.** 기존 g128 alpha·threshold와 회전은 교환되지 않아 원 TLinear와 동치라는 주장을 금지한다.
- 현재 유용한 입력축 K=768은 1024의 거듭제곱 크기가 아니다. Bonsai block1024를 그대로 쓰면 256 padding 차원과 추가 회전/메모리가 생긴다. TinyLM 후보는 `3×256` 독립 블록, `1024` zero-pad, 회전 없음 세 군을 별도로 비교한다. K=2048은 `2×1024`와 맞지만 group128 경계를 넘는 회전에서 기존 alpha의 의미가 바뀐다.
- 오프라인에서 이웃 선형층에 회전을 흡수할 수 있는 위치와 **매 토큰 온라인 transform**이 필요한 위치를 분리한다. Residual/RMSNorm/임베딩·head tying, CLA의 공유 KV owner, RoPE·GQA는 행렬 곱 동치 한 줄로 자동 보존되지 않는다. M=1 decode에서 transform `O(K log K)`와 pack decode 비용이 작은 GEMM 이득을 압도할 수 있다.
- 선형 가중치만 회전해 저장 파일이 작아져도 CUDA/CPU **상주**, KV, scale/회전 메타, 런타임 작업 버퍼는 따로 센다. 회전 seed·부호를 학습·pack과 함께 고정하고, 반복 호출 중 매번 packing하면 speedup이 아니다.

## 3. 우리 실측에 붙인 후보 아이디어 — 방법·순서 비교

| 안 | 독립변수와 질문 | 장점 | 위험·비용 | 지금 판정 |
|---|---|---|---|---|
| A. 현 packed 직접 실행 분해 | P014D scalar LUT, P025B 2:4와 별개로 TLinear의 unpack·입력변환·GEMM·whole-step wall을 같은 shape에서 분리 | 기존 코드·로그 재사용, 신규 구조 없음 | P014D 실제 decode native/int8 1.314×/1.231×는 사전1.50× 미달; P025B M8192 CUDA event1.334×/1.377×이어도 동기 wall0.959×/0.926× 음성 | **첫 측정 기준**. packed GPU primitive를 CPU decode 승자로 승격 금지 |
| B. 고정 회전 PTQ·부위별 고정밀 예외 | 동일 checkpoint의 TLinear 한 층에 R 없음/3×256/zero-pad1024, 예외 tensor 없음/사전선정만 비교 | 회전·예외 효과를 분해, 기존 모델 불변 | 입력 transform, 추가 scale·예외 상주, seed variance, 언어 품질 하락 | A의 실제 병목·층별 민감도 후 조건부 |
| C. 학습 가능한 회전·threshold/soft ternarization | SpinQuant/CAT-Q 영감으로 새 learnable 계수·anneal 일정 비교 | 장기 연구 여지 | 기존 Muon/WD/STE와 교락, optimizer state·학습비용·기본 경로 파급 큼 | B의 같은 부모 양성·정식 품질이 나온 뒤 별도 승인 |

**권장 A→B→C**: 정확한 병목과 민감도 없이 회전·예외·softening을 한 팔에 넣으면 무엇이 효과인지 모른다. P014D/P025B는 서로 다른 포맷/하드웨어이므로 결과를 합산하지 않고 각자 역사 음성을 대조군으로 둔다.

## 4. 조건부 실험 설계·사전등록할 값

1. **계측 gate(모델/GPU 사용자 실행 전)**: 고정 checkpoint·토크나이저·shape/seed·dtype·g128를 선택하고, 층별 alpha/zero율·weight/activation outlier·회전 전후 FP64 수학동치·FP32 차·삼진 재구성 NRMS를 별도 출력한다. 합성 fixture는 입력축/출력축 방향과 pad/역회전만 검증한다.
2. **같은 모델의 재구성 gate**: no-rotation 대 fixed-sign/3×256 대 fixed-sign/1024-pad를 동일 부모·같은 평가 crop에서 비교한다. 회전 seed 최소 3개를 사전 고정하고, 고정밀 예외는 별도 arm으로 열어 정확한 tensor 이름·bytes를 기록한다. 정식 근거 없이는 0.0976% 같은 타 모델 비율을 문턱으로 복사하지 않는다.
3. **배포 비용 gate**: packed bytes, 가중치 상주 MiB, KV+컨텍스트, RSS, CPU 1-thread decode/prefill p50·p95, GPU M1/M128/M8192 event·동기 wall·전체 모델을 분리한다. P014D 기존 1.50× 실제 CPU 채택선과 현재 기준표의 품질 자를 해당 조건에서 재사용하되, 측정 환경·반복·온도/클럭을 묶는다.
4. **학습 gate**: B에서 순효과가 관찰된 경우에만 C를 별도 계획으로 연다. from-scratch QAT와 FP32 부모→삼진 전환은 같은 부모·draw·pool·seed·optimizer state 규칙을 맞추고, 새 회전 계수·threshold·anneal을 한 번에 바꾸지 않는다.

동일 raw corpus/tokenizer가 아니면 val/perplexity 직접 비교를 거절한다. 본 보고서의 gate 설계는 `DESIGNED`; 실제 checkpoint·GPU·CPU 모델 실행은 모두 사용자 소유 `NOT_RUN`이다. 실험 번호·런처·비용 상한은 제안 승인과 기존 frontier/기준표 preflight에서 정한다.

## 5. 채택하지 않는 주장과 결론

- Hadamard가 outlier를 퍼뜨린다는 문헌 결과는 **TinyLM g128 삼진화의 품질 개선**을 보장하지 않는다. 우리 STE/scale·QAT와 회전의 상호작용이 미측정이다.
- PTQ 성능과 native ternary-from-scratch 성능은 시작 모델·학습량·계측 단위가 다르다. CAT-Q의 512 calibration·대형 모델 성과를 우리 새 300M 부모의 성과로 해석하지 않는다.
- 저장 bpw와 실제 상주·CPU p95는 서로 대체하지 않는다. direct packed CUDA event 양성도 host wall·배포 CPU 채택의 증거가 아니다.
- 사용자 2026-09-25 권장 B안 승인으로 **기존 P014D/P025B 음성을 보존하는 조건부 [실험제안서](../proposal/20260925_회전-삼진-민감도와-직접패킹-단계검증-제안서-approved-on-going.md)**를 [P014E G0 계획](../test_plan/P014E_회전삼진-민감도와-직접패킹-단계게이트.md)으로 열었다. 기본 TLinear·데이터·optimizer·checkpoint는 바꾸지 않았고 실제 모델 품질·배포 이득은 `NOT_RUN`이다.
