## 정제문 작성 지침

2026-11-19 보완. 참고문헌과 분류에서 살릴 정보는 관련 본문에 평서문으로 통합한다.

- **참고문헌과 각주.** 본문의 주장, 수치, 직접 인용에 연결되는 출처는 그 대목에 적는다. 예를 들어 해당 수치와 조사 기관이 원문에서 명확히 연결되어 있으면 “○○ 기관의 2020년 조사에서는 …로 보고했다.”처럼 적고, 근거를 찾는 데 필요한 저자·제목·발행 연도·쪽수는 보존한다. `참고문헌`, `참고 문헌`, `각주` 표제와 본문에 연결되지 않은 서지·외부 자료 목록은 정제문에서 제거한다. 단순히 가까이 배치되어 있다는 이유로 서지를 특정 주장에 연결하지 않는다.
- **분류.** 유효한 분류 정보가 본문에 이미 있으면 한 번만 남긴다. 빠진 사실 중 해당 문서의 주제와 관계가 명확한 것은 연혁, 학력, 활동 등 알맞은 본문에 평서문으로 넣는다. 예를 들어 원문에서 회원 관계가 확인되면 “그는 교황청 과학원의 회원이었다.”라고 적는다. 분류 표제와 분류명 나열은 정제문에서 제거한다. 분류명만으로 소속, 업적, 날짜를 추정해서 문장을 만들지 않는다.
- **수록 범위.** 평서문에는 주어와 역할, 시점이 원문에서 확인되는 정보만 담는다. 같은 문구를 쓰더라도 인물, 단체, 회차가 다른 문서는 각각 보존한다. 같은 분할에서 두 TXT의 문서 전체가 같고 처음이나 끝의 빈 줄만 다르면 한 부를 수록한다. 학습·검증 사이에서 본문이 크게 겹치는 위치는 실제 겹친 범위를 기록하고 학습 채택을 보류한다. v1.1에는 원문과 연결되고 독립적으로 읽을 수 있는 본문을 수록한다. 확인이 필요한 부분은 기존 TXT와 작업 위치표에서 이어서 검토한다.
- **자동 처리 범위.** 묶음 조회에서 빈 말미 표제와 속성 없는 빈 각주 태그를 정리한 초안을 보여 준다. 기존 규칙으로 내용이 비었음이 확인되는 절과 서지 항목, 이름 병기의 빈 구분자도 정리한다. 자연수 문서는 주제와 정렬 표식의 수가 일치하고 작성된 줄이 모두 확인되는 형태에서 빈 절과 정렬 표식을 자동 정제한다. 본문이 주장하는 생몰 연도를 그대로 반복하는 말미 분류는 그 관계와 연도가 확인될 때 정리한다. 코드·인용·표의 표기가 있거나 원문 구간이 불완전하면 원문을 그대로 보여 준다. 같은 문장 줄 번호와 `[일부 표시]`는 조회 화면에서만 사용한다. 필요한 문서나 줄은 `--document`와 `--lines`로 읽어 출처가 뒷받침하는 주장과 분류가 가리키는 관계를 판단한다.
- **병렬 작업 모델.** 실제 원문 정제에 위임하는 작업자는 **GPT-6 Luna max** (`gpt-6-luna`, 추론 강도 `max`)를 최대 다섯 개 사용한다. 총괄은 조회 도구로 겹치지 않는 묶음을 배정한다. 각 작업자는 `--first`에 묶음의 첫 문서 번호를 줘 자기 원문을 조회한다. 여러 문서에서 필요한 정확한 줄은 `--excerpt`를 반복해 한 번에 확인할 수 있다. 정제한 줄은 같은 번호로 저장 도구에 한 번 제출한다. 판독 후 따로 수정할 부분이 없는 문서는 `--keep-remaining`에 실제 개수를 명시해 유지할 수 있다. 뒤 묶음의 입력은 기존 작업 메타데이터에 접수했다가 저장 차례가 되면 원문 순서대로 반영한다. 총괄은 접수 건수와 실제 정제 TXT에 저장한 건수를 구분해 확인한다.

## 전량 처리의 판정

대상 범위는 로컬 scope manifest로 동결한다. 각 입력의 모든 EOS 구간과 불완전 경계를 원장에 남긴다. KEEP/EDIT/EXCLUDE/HOLD의 합이 입력 구간 수와 맞고 원천 토큰 구간에 설명되지 않은 틈이 없어야 한다. 새 train/val은 기존 split을 보존하고 HOLD·평가자료를 편입하지 않는다. exact 문서·가능한 구간 누설과 중복을 다시 검사하되 원 URL 기준 누설을 확인했다고 주장하지 않는다.

위험·언어 대리값·문서 종류별 판독과 무신호 KEEP의 독립 판독을 수행한다. 탐지기 재계측만으로 의미 보존을 확정하지 않는다. 발견한 오삭제·깨진 문맥은 별도 수정 또는 HOLD로 조치한다. 이 계약 작성이나 시험 묶음 종료만으로 goal을 완료하지 않는다.
