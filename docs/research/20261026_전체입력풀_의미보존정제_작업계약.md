2026-10-26 사용자 goal 첨부를 수행한다. 세션은 `01a17740-f435-7243-874c-2b5d58181c4c`이며 [현재 원장](../../handoff/WIP_20261026_작업원장.md)이 지시 원문과 진행을 소유한다. [직전 인계](../../handoff/202610261536_HANDOFF.md)와 [대표 판독](20261026_실제학습노출과_원문맥락_정제판독.md)을 계승한다. 기존 5문서/5,218토큰은 전체 처리량이나 새 고유 자료가 아니다.

## 접근 비교와 선택

| 안 | 실제 처리 | 장점 | 비용과 위험 |

## 착수 전 영향도

| 축 | 영향과 근거 |
|---|---|
| 코드 | 새 조정 도구만 추가한다. 기존 `clean_text`, `signals`, `tail_proposal`, `ByteCodec`, `Holds`, `ShardWriter`의 역할을 재사용하며 기존 학습 호출부/모델 기본값을 바꾸지 않는다. 기존 format pair는 원문/형식 비교와 과거 마감 계약에 묶여 있으므로 의미 채택·새 분할 캐시 기능만 별도 소유한다. |

| 시험 | 기존 code fence/EOS/문서 경계·HOLD 회귀를 먼저 실행한다. 신규 시험은 오삭제 반례·실패 후 재개·분할/직렬화·누설 제외를 검증한다. GPU 스모크는 이번 범위 밖이다. |

## 전량 처리의 판정

대상 범위는 로컬 scope manifest로 동결한다. 각 입력의 모든 EOS 구간과 불완전 경계를 원장에 남긴다. KEEP/EDIT/EXCLUDE/HOLD의 합이 입력 구간 수와 맞고 원천 토큰 구간에 설명되지 않은 틈이 없어야 한다. 새 train/val은 기존 split을 보존하고 HOLD·평가자료를 편입하지 않는다. exact 문서·가능한 구간 누설과 중복을 다시 검사하되 원 URL 기준 누설을 확인했다고 주장하지 않는다.

위험·언어 대리값·문서 종류별 판독과 무신호 KEEP의 독립 판독을 수행한다. 탐지기 재계측만으로 의미 보존을 확정하지 않는다. 발견한 오삭제·깨진 문맥은 별도 수정 또는 HOLD로 조치한다. 이 계약 작성이나 시험 묶음 종료만으로 goal을 완료하지 않는다.
