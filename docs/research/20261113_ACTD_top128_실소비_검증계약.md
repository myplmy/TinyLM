## 1. 왜·질문·예측

기존128 TRAIN export에는 ALM 스칼라 확률만 있고 ACTD의 top-k 분포는0개다.
이 신호를 만들고 원래 assistant/EOT 위치에서 전체 학생 어휘분모를 거친 미분이
유한하게 연결되는지 확인해야 원장60의 실제 소비 구현으로 진행할 수 있다.
어휘의 정적 대응률이 높아도 실제 top128에 미매핑 ID가 끼면 수락 위치가 적거나0일 수 있다.
가까운 교사 문자경계는 학생보다 미래일 수 있으므로 그 양과 left-only 변형을 구분한다.
작은 학습이나 벤치마크 성과를 이 단계에서 판정하지 않는다.

## 4. 단계·게이트

1. Stage8af: 원 q.hybrid_canary bytecode와 원래 문자열을 그대로 호출한다. LM 위임 proxy의
   model 호출만 기존 fixed.logits로 연결해 실제 B1×1024/full-vocab, native mask, FP32,
   cache OFF를 유지한다. 원 lm.model·class·module globals를 바꾸지 않는다. CPU proxy
   회귀/봉인 뒤 GPU 약1~3분 추정. 기존8경계의 다른 prefix canary와 이 검사는 별도다.
2. Stage7i CPU: 기존128 source/record를 원 pack_student로 재생성하고 양쪽 전체 UTF-8
   ByteStream을 같은 text에 맞춘다. prefix raw index=j-1, supervised next target=j로
   딱 한 번 대응한다. owner가 같은 유효 문자경계만 최근접 단조/left-only로 정렬한다.
   문자 중간 경계는 ACTD에서 HOLD지만 원 CE target을 지우지 않는다. 교사1024 초과는
   원문 절단 없이 입력 HOLD다. 원 corpus index는 미상으로 남기고 frozen index와 섞지 않는다.
3. Stage7j 교사: 정확 legacy fixed 게이트와 실제 exit0 뒤 같은 Qwen FP32 고정 폭에서
   정렬에 필요한 predictor 위치의 native top128 ID/logit·전체 logsumexp를 채취한다.
   교사의 정답 logit을 강제 삽입하거나 미매핑 token을 빼고 다시 top-k를 만들지 않는다.
   128문장/합집합 위치를 한 번만 계산하고 raw를 샤드화한다. source/core/객체/정리0 검산.
4. Stage7k 학생: 새 strict 캐시의 완전성·원형·정렬·top-k를 확인한 뒤 같은93M의 원래
   assistant CE와 ACTD 전체 어휘분모의 실제 gradient/시간/메모리를 연결한다. 비교는
   동일 초기화/records/정밀도/checkpoint/전역 target 분모를 보존한 CE-only와 CE+ACTD
   기술 경로다. optimizer/새 체크포인트/품질·일반지능 판정0. 실제 계산량·수락/보류는 보고한다.

CPU 단계는 모델/GPU0이고 단일 thread다. 실제 GPU 수집은 잔여 위임시간·여유 VRAM을
확인해 입장하며 최소15분 정리 여유를 남긴다. 모든 신규 파일은20MB 미만이다.

## 5. 새 매핑 정책과 엄격 캐시

v1 added33 보수적 매핑과509 HOLD 배열은 바꾸지 않는다. 새 정책은 HF special=True21개
중 명시 native EOS248044→Tiny EOS2, im_start248045→3, im_end248046→4만 허용한다.
False12개는 metadata.content를 literal UTF-8로 복원하고 실제 tokenizer 단독 decode와
대조한 다음 첫 학생 subtoken으로 매핑한다. 의미가 비슷하다고 think/tool 의미 ID로 합치지 않는다.
나머지 True18·미공유 불완전 UTF-8·미선언 head ID는 HOLD다. top128 하나라도 HOLD면
그 전체 위치를 거부하고 원128 ID/logit·거부이유를 보존한다.

top128은 unique native IDs, K=128, 범위/유한값/내림차순을 검사한다. softmax는 원128
logit만 재정규화하고 학생은 전체32768 분모를 쓴다. literal 중복 edge와 고유 잔여집합을
분리한다. top128 원확률 질량·anchor 충돌·언어별 수락/거부·정렬 lookahead를 기록한다.
nearest_monotonic과 causal_left_variant를 같은 방법으로 재명명하지 않는다.
