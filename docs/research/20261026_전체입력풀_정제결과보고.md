# 전체 입력 풀의 의미 보존 정제 결과

2026-10-26 사용자 goal에 따라 총괄 Codex가 범위·계보·코드·채택 판정·CPU 검산을 맡고, 사전 명세된 `gpt-6-luna` max 다섯 역할이 실제 문맥 판독과 새 txt 수정을 맡았다. 대표 다섯 초안에서 멈추지 않고 확정한 **2,154,912개 입력 구간 전부**를 처리했다. 별도 캐시 생성과 독립 전량 재생성 검산 모두 실제 종료0을 회수했다. **919,243개 채택 문서 전부**의 바이트·EOS·문서 경계·전체 SHA가 일치했다. [독립 검산 영수증](../../handoff/audit/source_cleanup_20261026_goalc/cache_verify_receipt.json)이 실제 상태와 원형 재해시를 소유한다.

결과 수치 정본은 [결과101 §554](../../test_result/101_20260927_P106B-번역9건으로-문턱미달-학생학습0.md), 기계 원형은 `data_cache/p106b_corpus_cleanup_v1_20261026_goalc/cache_v1/built.json`이다. Git에 선별한 [생성 영수증](../../handoff/audit/source_cleanup_20261026_goalc/cache_build_receipt.json)은 원형 SHA와 필요한 수치·계보를 연결한다. [작업 계약](20261026_전체입력풀_의미보존정제_작업계약.md)에 대안과 권한·영향 분석을 남겼다.

## 확정 범위와 분모

| 입력 | 원형 경로 | 입력 ID 수(EOS 포함) | 처리 구간 수 |
|---|---|---:|---:|
| 확장 TRAIN | `data_cache/p106b_native_expansion_v1_s1337/train.bin` | 1,191,116,192 | 1,441,175 |
| 과거 601M TRAIN | `data_cache/ko-en_601000000_chat32/train.bin` | 597,995,000 | 709,977 |

| 합계 | `scope.json`의 세 원형 | **1,792,116,192** | **2,154,912** |

원형 전체 SHA, metadata SHA, tokenizer SHA, 구간 정의와 제외 계보는 `data_cache/p106b_corpus_cleanup_v1_20261026_goalc/scope.json`에 고정했다. 토크나이저는 기존 chat32, uint16 little endian, EOS ID2다. 과거 TRAIN의 215-ID 말미, VAL의 알 수 없는 첫 조각과 43-ID 말미도 처리 수에 포함하고 HOLD했다. 원형을 문서 경계까지 잘라 놓은 것으로 가정하지 않았다.

이 구간 수는 원 URL 기사 수가 아니다. 정확 원문 본문 SHA로 합친 값은 **1,442,835개**이며, 첫 등장 본문의 EOS 제외 ID 합계는 **1,190,537,781**이다. 서로 다른 토큰 분할이 같은 본문을 표현할 가능성과 잘린 구간을 포함하므로 이를 원 기사 고유량으로 부르지 않는다. 과거 TRAIN은 확장 풀과 겹치며 별도 새 자료량으로 더하지 않았다. 기존 1.2B 원형·이전 format 파생본은 계보 참조이며 중복 입력으로 다시 넣지 않았다. 번역·교사 생성·SFT·공식 평가 문제와 정답은 이번 입력에 추가하지 않았다.

지난 학습의 실제 노출은 별도 [원문 맥락 판독](20261026_실제학습노출과_원문맥락_정제판독.md)과 결과101 §547이 소유한다. 두 모델이 같은 292,992개 중첩/복원추출 창에서 각각 300,023,808 target을 보았으며 같은 target 스트림 SHA다. 두 모델의 처리 토큰을 새 고유 코퍼스로 합산하지 않는다. 고정 epoch 완주로 해석하지도 않는다.

metadata는 혼합 풀에 Wikipedia/FineWeb이라는 집계 이름만 남긴다. 원문별 URL·ID가 없어 전부 `UNKNOWN_MIXED_NATIVE_CACHE`로 기록했다. 문체나 분류 꼬리로 출처를 추정하지 않았다.

## 전량 판정과 별도 채택 집합

| 최종 상태 | 입력 구간 수 | 해당 원형 입력 ID 수 |
|---|---:|---:|

| EDIT | 40,004 | 4,740,374 |
| EXCLUDE | 418,175 | 358,025,415 |
| HOLD | 817,494 | 632,318,138 |
| 합계 | **2,154,912** | **1,792,116,192** |

각 행은 원형 source/ID 범위·바이트 SHA·본문 SHA, 최종 상태, 규칙 버전, 사유, 중복/검증 겹침 근거와 채택 캐시 위치를 연결한다. 설명되지 않은 미처리 구간은0이다. EXCLUDE는 정확 정제 본문 중복 **418,159**구간과 알려진 TRAIN/VAL 내용 겹침 **16**구간이다. HOLD는 불량률이나 거짓 판정이 아니다. 제목·표·참고자료·반복의 문맥을 자동으로 확정하지 못한 자료, 알려진 기존 HOLD, 경계 조각을 안전하게 분리한 상태다.

| 입력 | KEEP | EDIT | EXCLUDE | HOLD |
|---|---:|---:|---:|---:|
| 확장 TRAIN | 877,131 | 39,964 | 1,959 | 522,121 |
| 과거 TRAIN | 0 | 0 | 416,216 | 293,761 |
| VAL | 2,108 | 40 | 0 | 1,612 |

과거 TRAIN에서 추가 채택0은 미처리가 아니다. 보존 가능한 본문은 먼저 채택한 확장 TRAIN과 정확히 겹쳐 제외됐고, 나머지는 HOLD에 남았다. 이미 알려진 HOLD 3,586개 명시 항목도 전부 hit를 확인했다. 수동 판정 미적용 목록8개는 모두 앞선 HOLD/불완전 경계 가드에 이미 걸린 HOLD이며, 긍정 채택 누락0을 [별도 대조](../../handoff/audit/source_cleanup_20261026_goalc/manual_match_reconciliation.json)로 확인했다.

|---|---:|---:|---:|---:|

전체 원형에서 빠진 **990,343,553 ID**는 HOLD/중복/겹침 선택의 효과다. 같은 채택 문서의 실제 편집 감소는 **121,120 ID**(TRAIN121,003·VAL117)다. 선택 효과를 편집 제거량으로 설명하지 않는다. 이전5초안5,218토큰은 원형의 대표 파생본일 뿐이며 위 수치에 새 고유량으로 더하지 않았다. 이번에는 40,004구간 편집과 전량 결정·실제 별도 캐시까지 진행했다.

## 실제 문맥 판독과 의미 손실 조치

각 token shard는 완전한 EOS 문서 단위이며 전체 순서·연결 SHA·전역 ID offset을 manifest가 연결한다. `ShardedTokens`는 shard 경계를 넘는 연속 CPU 창을 읽으며 실제 모델 연결·학습 실행은0이다. 기존 단일 train.bin 소비자에 자동 연결하지 않았다. 독립 소비자가919,243문서 모두를 원형 또는 정제문에서 재생성했고 전체 연결 SHA·decode·예약토큰/EOS·문서/구조 재계수와 일치했다. 채택 split 내부 exact 본문 중복0·TRAIN/VAL exact 본문 겹침0이다. 검산 후 세 입력 전체와 tokenizer를 다시 해시해 불변을 확인했다.

TRAIN 토큰 연결SHA는 `1F971E4B9006131EA4B1606D8B780DB12077BE28E3BEBF3949AFBEA83299F62C`, VAL은 `87A04244993354054932E1FB00C253515CD240B753CF452F047AD4E447956F94`다. 모든 새 로컬 파생파일1,683개/17,706,707,318바이트이며 최대19,999,993바이트로 개별20,000,000바이트 미만이다. 스캔/원문 판독/중간본/원장도 포함한 디스크 크기이며 최종 토큰 캐시만의 크기가 아니다.

생성은 원형/정제 본문 exact SHA, 기존 VAL EOS/경계 부분문서, 원형·정제 VAL의256-ID 창(stride128)을 TRAIN 제외 참조로 쓴다. HOLD된 VAL도 TRAIN 재편입하지 않았다. 문서 식별자가 없어 이동된 비정렬 부분구간·근사 중복·URL 단위 누설0은 미확인이다. 검증 split은 계승했지만 HOLD 뒤 문항/내용 구성이 달라져 과거 VAL 손실과 동등 비교할 수 없다. 공식 Core6는 이번 자료에 추가하지 않았다.

## 학습 재개 판단과 다음 선택

TRAIN799.624M은 기존300M 대비2배 풀의 **수량 선결만** 만족한다(2.665배). 원형 처리·HOLD 분리·별도 캐시 검증은 데이터 처리 증거이며 학습 승인이나 모델 반복 개선 증거가 아니다. 한국어 문자 구성 변화, 권리·원 기사 누설·전량 사실/의미 검토의 한계, 기존 trainer의 shard 입력 연결과 같은 평가 조건이 남아 있다. 추가300M 금지는 그대로 유지하고 자동 실행하지 않는다.

| 선택 | 얻는 것/남는 것 | 다음 작업 비용·자원 |
|---|---|---|
| A. 현재 캐시를 잠근 기준 파생본으로 보존 | 지금의 전량 추적·의미 예외와 모든 HOLD를 보존. 새 학습 증거는 얻지 않음 | 추가 계산0, 별도 사용자 실행 없음 |
