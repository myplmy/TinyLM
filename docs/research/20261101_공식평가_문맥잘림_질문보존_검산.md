# 공식 평가의 문맥 잘림과 실제 질문 보존 검산

현재 공식1024 문맥 제한에서 MMLU와 GSM8K의 입력 절단량은 이미 기록했다. 추가로
잘린 부분이 앞선 예시인지 실제 평가 질문/선택지인지 구분한다. 사용자104의 정제 외 CPU
연구이며 새 모델 실행·학습이나 평가 설정 변경이 아니다.

| 안 | 방법 | 장점 | 한계 |
|---|---|---|---|
| A | 동결 공식 요청과 실제 tokenizer offset으로 질문 시작점·보존 구간을 전량 대조 | GPU 재실행 없이 실제 질문 손실과 예시 손실을 분리 | 길이를 늘렸을 때의 성능 변화는 알 수 없음 |
| B | 문맥을 늘려 전체 모델 평가를 다시 실행 | 실제 문맥 효과를 비교할 수 있음 | 현재 동결 비교/시간·메모리 조건을 바꾸고 추가 GPU 비용 발생 |
| C | 총 잘림량만 보고 | 추가 비용 작음 | 질문이 사라졌는지와 예시가 사라졌는지를 혼동 |

A를 적용한다. 원 공식 task의 doc_to_text와 원 요청을 재사용하고, tokenizer offset의 ID가
실제 CPU 요청 계약의 ID와 같음을 먼저 검사한다. MMLU는1024개 score 입력에 실제 질문과
선택지가 남는지, GSM8K는256 생성 예산을 뺀768개 prefix에 실제 질문이 남는지 확인한다.
모델 간 tokenizer는 각각 고유한 것을 사용한다. Falcon 가중치는 로딩하지 않으며 새 다운로드/
설치도0이다. 원 질문/정답은 계속 평가 전용이고 실패를 교사/학습 자료로 보내지 않는다.

최종 산출물은 소유 감사 폴더의 새 JSON이며, 질문 손실 건수와 정확 문항 ID만 작은 목록으로
보존한다. 전량 완료 전 수치를 최종 결과로 쓰지 않는다. 질문 보존 확인은 내용 이해나
정답성 증명이 아니며, 정제 완료나 추가300M 허가로 해석하지 않는다.


## 실제 회수와 해석

CPU 실제 부모0·302.845748초로 전량을 닫았다. MMLU는 문항당 첫 선택지 context의 실제
encoder ID와 offset을56,168회, GSM8K는 원profile의1,319 prefix를 대조했다. 모델 로딩/
순전파/GPU/학습은0이며 source 불변이다. 두 Tiny 모델은 같은 tokenizer를 쓰므로
Tiny 행은 양쪽의 같은 공식 문맥 조건에 적용하며 서로 다른 가중치의 답을 재생성한 것이 아니다.

| 입력 조건 | 문항 | 전체 문맥 잘림 | 질문도 잘림 | 예시/표제만 잘림 |
|---|---:|---:|---:|---:|
| Tiny MMLU0 | 14042 | 3 | 3 | 0 |
| Tiny MMLU5 | 14042 | 2675 | 3 | 2672 |
| Falcon MMLU0 | 14042 | 5 | 5 | 0 |
| Falcon MMLU5 | 14042 | 2682 | 5 | 2677 |
| Tiny GSM8K5/생성prefix768 | 1319 | 1186 | 0 | 1186 |

MMLU에서 질문까지 잘린 것은 모두 college_medicine이며 Tiny의 최대79자/Falcon339자다.
정확 doc_id와 문자 경계는 JSON에 보존했다. 질문을 잃은3/5건만의 수정 효과는 다른 답을
고정하면 최대0.0214/0.0356퍼센트포인트다. 이 값은 긴 문맥의 전체 이득 상한이 아니다.
5-shot에서는 수천 문항의 예시도 줄어들어 예시 복구의 효과가 별도로 남는다.

GSM8K는 실제 질문1,319개가 모두 보존됐지만1,186개는5개 예시의 일부를 잃었다. 따라서
점수는 공식5-shot 요청을1024 문맥에 제한한 결과로 표시하고,5개 예시가 모두 남은 공개
설정과 같다고 표현하지 않는다. 질문 보존이 내용 이해·정답성을 뜻하지 않는다.
짧은 독립 첫답400개의 무잘림 조건에서도 실패가 많았다는 기존 관찰과 함께 보면, 짧은
문맥만이 현재 답변 문제의 전부라는 설명은 성립하지 않는다. 긴 문맥의 효과를 없다고
판정하거나 구조/자료/학습 중 하나의 단일 원인을 확정하지 않는다.

원 실행은 CONTEXT_QUESTION_RETENTION_CPU_v1.log, 정본은
handoff/audit/nov01_independent/context_question_retention_v1.json과
context_question_retention_actual_v1.json이다. 공식 점수와 분모·실행 조건은 바꾸지 않았다.
