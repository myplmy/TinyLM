# P107 명시 문서 원천·스케줄·디스크 재개

원장59의 실제30갱신과 메모리 재개는 완료했지만 문서 로더·스케줄·디스크 전체 복원은 남아 있다. 사용자105의 정제 외 미완 구현 범위에서 이 경계부터 닫는다. 다른 세션의 정제 자료나 실제 코퍼스는 읽지 않는다.

| 안 | 범위 | 이득 | 비용·한계 | 선택 |
|---|---|---|---|---|
| A | 기존 AdaptiveMNTPTrainer를 감싸는 명시 문서 원천·세션·분할 저장 라이브러리 | 평가에 동결된 기존 파일을 그대로 두고 전체 재개를 검증 | 생산 CLI·실제 코퍼스·causal KD는 아직 미완 | 채택 |
| B | 공용 trainer/CLI를 한 번에 고침 | 최종 제품 연결까지 직접 진행 | loader 의미·기본 경로·frozen source와 충돌하고 회귀 범위 큼 | 전량 평가 종료 후 별도 판단 |
| C | 정제 완료까지 모든 준비 보류 | 추가 구현 없음 | 이미 허가된 독립 선결도 지연 | 비채택 |

예를 들어 A문서의 토큰35·36·37과 B문서의40·41·42를 전달받아 서로 다른 문서로 유지한다. PAD는-1문서ID로 표시하고 EOS나 특정 문자열에서 문서 경계를 추측하지 않는다. 짧은 문서의 나머지는PAD이며 임의 타깃을 채우지 않는다. 샘플러는 명시한 문서 균일 복원추출이고, 기존 연속 토큰 무작위 크롭과 같은 분포라고 주장하지 않는다. 향후 본실험에서는 같은 source의 uniform/adaptive를 비교해야 한다.

| 파일·경로 | 동작 | 권한 | 제외 |
|---|---|---|---|
| tinylm/train/document_source.py | 전달된 CPU token 문서의 상태형 로더 | 사용자105 구현·CPU 검증 | 코퍼스 파일 읽기·경계 추정0 |
| tinylm/train/hybrid_session.py | 기존 trainer·기존 LR식·완료 경계 연결 | 같은 범위 | 기존 학습 본체/기본값 변경0 |
| tinylm/train/boundary_store.py | 새 디렉터리 전용 분할 checkpoint 저장·복원 | 같은 범위 | 이전CP 덮어쓰기·삭제0 |
| scripts/test_p107_session_boundary.py | CPU 반례·중단·디스크·dropout 재개 | 같은 범위 | 실제 지능/학습효과 판정0 |
| 새 진단/SH/profile | 나중 실제 GPU 비용·재개 검증 | 현재15시 연구 허가 | 동결 평가 종료 전 GPU 중복 실행0 |

데이터 형식은 사용자 정제본을 변환하는 생산 포맷이 아니다. 호출자가 이미 승인한 문서를 CPU tensor로 전달하는 내부 인터페이스다. 토큰·문서 식별자·샘플러 형상은 source SHA에 묶고 난수/cursor를 저장한다. 짧은 문서·고유량·PAD 실행량은 별도로 보고하며 반복 노출을 고유 자료로 세지 않는다.

세션은 매 완료 갱신의 원래 LR식과 각 optimizer group의 기준 LR을 사용한다. 전체 checkpoint는 모델·optimizer·통계·source/RNG·스케줄 계약과 cursor를 포함한다. scheduler 실패는 전체 복원 전 재사용을 금지한다. 저장은 새 디렉터리의 각16MB이하 조각을 먼저 fsync하고 마지막 manifest로 완료를 표시한다. 파일별·전체 SHA를 검산하고 weights_only=True로 복원한다. 기존 폴더·이름 충돌·부분/변형/다른source 상태는 거부하며 실패 산출물을 자동 삭제하지 않는다.

CPU에서는 알려진 작은 문서와 dropout 모델의 중단 없는 경로 대 디스크 복원 후 경로를 비교한다. 업데이트·LR·loss·model/optimizer/policy/source/RNG가 같아야 한다. 외부 corpus·학습CLI·teacher·일반 지능은 이 결과로 완료하지 않는다. 실제 Native 모델 GPU 복원은 별도 새 비용/시간/자원 프로필을 닫은 뒤에만 수행한다.

작은 기술 시험은 품질 연구가 아니며 추가300M·정제 편입 금지를 유지한다. CPU 검산 비용은 수초~수분, 실제 Native 전체 상태는 기존 메모리직렬화781MB를 참고하되 디스크 비용은 실측 전 미확정이다.
