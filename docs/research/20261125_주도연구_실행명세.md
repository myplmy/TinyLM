# 2026-11-25 TinyLM 주도 연구 실행명세

처음 승인 시한은 11월 25일 13:00 KST였다. 이후 사용자가 346.316M R2·R1→R2 대조와 공통 평가를 같은 날 15:00 KST까지 명시적으로 승인했다. WSL CPU 0–14와 GPU 0 한 장을 사용하며 디스플레이를 포함한 카드 한도는 13,312 MiB다. 두 학습 팔과 공식 평가의 GPU 점유는 직렬이다. [작업원장](../../handoff/WIP_20261124j_작업원장.md)

각 실험의 방법 선택, 결과와 후조치, 로컬 커밋 복구 내역은 [주도 실험 회고](20261125_주도실험_회고.md)에 연결한다.

1. P109C의 새 규칙 판단과 답변 표현을 개선할 방법을 찾고, 공통 한영 평가에서 얻는 이득과 기존 능력의 손실을 함께 확인한다.
2. P109의 원문 초반 R1 이후 R2 전환을 더 긴 대조에서 검증한다. 같은 입력과 교과, 동일 GPU 조건의 직접 시간과 서로 맞춘 평가를 요구한다.
3. 이미 보유한 G4 컨텍스트 경로에서 기준 품질과 상주 예산을 유지하며 처리 길이를 늘릴 방법을 검증한다. 고정 컨텍스트 다중 위치와 생성, 실제 장치 비용을 분리해 측정한다.

계획과 조건은 실행 전에 각 소유 P계획과 원장에 고정한다. 기존 승인이 별도로 유보한 1.23B 전량 학습, 보호 원본, 패키지와 신규 환경, 대규모 운영 변경은 승인 대기로 남긴다. 보유 파일의 기록과 해시, 결과 원본을 보존하고, 승인된 로컬 커밋에는 선별한 파일만 담는다. PreCompact는 비활성 상태로 두고 새 전체 프로젝트 스모크는 별도 승인을 기다린다.

## 보조 검토 배정

세 역할의 코드·문서 쓰기와 모델·GPU·실험 실행 권한은 모두 0이다. 사용자가 지정한 모델군에서 정·반 검토에 GPT-6.2 Sol high, 문헌·후보 대조에 GPT-6 Luna high를 배정한다. 동시 한도는 보조 3명이다. 읽기 셸은 CPU 0–14 안에서 사용하며, 사용량이 큰 분석·설치·다운로드·Git 변경·삭제를 실행하지 않는다. `datasets/TinyDataset`, 타 환경 지침, 다른 작업의 출력은 접근하지 않는다. 총괄이 소스·실행·결과 파일과 GPU를 소유한다.

초기 회신 목표는 02:00 KST다. 근거로 결정할 수 있는 사항은 총괄이 바로 진행하고, 특히 소스 봉인이나 전량 판정이 바뀌는 근거를 우선 반영한다. 보조는 정적 검토와 실제 수행이 구분되도록 회신한다. 이 시간 동안 총괄은 새 승인과 실행 원장을 결합하고 GPU 입장 상태 및 보존 후보를 회수한다.
