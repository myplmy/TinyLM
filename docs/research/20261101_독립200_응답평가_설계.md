# 독립 KO100/EN100 응답 평가 — 기존 본학습 모델의 현재 상태

원장52의 독립200문항은 아직 착수하지 않았다. 기존 DEV64·공개 user8·학습 자료를 새
평가셋으로 바꾸지 않는다. 사용자104가 허가한 정제 외 독립 미완 연구/11시/8GB 범위다.
본학습 전 소규모 학습으로 성과를 판정하지 말라는 지시는 유지한다. **새 학습은0**이며,
과거 본학습이 실제 끝난 두 모델을 그대로 평가한다. 이번 연구가 새 지능을 만들었다고
보고하지 않는다. 이후 학습·교사 교정·오답 증강에 이200문항과 정답을 보내지 않는다.

## 평가 계약

- 모델은 사전에 `native595-q`와 `new595-broad-q`로 고정한다. 전자는 실제595M NTP,
  후자는 같은 삼진 부모에서 기존 Broad704 학습까지 완료한 배포본이다. 기존 보고서/activity/
  checkpoint·core·tokenizer SHA를 CPU 동결 manifest에 결합한다.
- 언어별 지문QA20·추출/변환20·명시형식20·산수/논리20·일상요청20이다. FINAL은 고정 seed와
  별도 허구 정보로 만들고 DEV20은 다른 seed/ID/내용이다. 새 원천 권리 문제나 사실 검색을
  평가에 섞지 않는다. 규칙 문제의 정답은 코드로 계산하되 가상 지문/일상 요청은 총괄이 읽는다.
- 각 질문은 독립 단일턴, 같은 ChatML 경로, 첫 greedy 답만 수집한다. 생성 상한은96토큰,
  입력+생성1024 초과는 자동 절단 없이 실패다. 이 결과는 해당 기본 대화 경로의 응답 평가이며
  base 모델의 모든 completion 형식 능력이나 공식 벤치마크를 대신하지 않는다.
- 두 언어는 같은 유형별 분모의 서로 다른 작성 사례이며 완전히 대응하는 평행 번역이 아니다.
  언어별 차이를 언어 하나만의 인과효과로 해석하지 않는다. 그러한 비교는 별도 대응 지문이
  고정된 Belebele 결과와 구분한다.
- 세 축은 독립 판독한다. **안정성**은 빈 답/파손/불필요 반복·질문 나열/역할노출/절단을,
  **대응성**은 요구 언어·주제·형식을, **정확성**은 제시한 사실·규칙·요청의 핵심 충족을 본다.
  세 축 모두 충족한 usable 비율과 언어/유형별 실패를 보고한다. 정답 문자열 exact와 정상
  종료만으로 나머지 축을 자동 통과시키지 않는다.
- `똑똑을 세 번` 같은 요구된 반복은 실패가 아니다. 반복 신호는 검토 후보이며 검증되지 않은
  단어 목록으로 답을 자동 불량 처리하지 않는다. 열린 일상 답은 명시 rubric의 총괄 판독이며
  외부 독립 인간 판독/확정 정답과 구분한다.
- FINAL을 보고 loss/모델/예산/임계값을 조정하지 않는다. 이 두 모델 외 새 후보는 후속 연구로
  구분한다. 현재 고유 문항이라도 과거 웹 학습과의 전역 의미 오염0은 증명하지 못한다.
- 별도 공식 KoBEST는 의존성 부재로 미실행이다. 이200응답 수치를 공식 KoBEST나 기존
  Core6 평균/경쟁 모델 점수와 같은 표의 동등한 척도로 합치지 않는다.

## 비용과 미측정

CPU 준비/시험 뒤 현재 소스 정적을 닫고 각 GPU 프로세스를 최대1,800초·외부1,920초+kill20초,
마감120초 여유·allocator6GiB/공유 표본 증가8,000,000,000B 감시로 제한한다. 같은 GPU에
동시에 두 모델을 올리지 않는다. 원소스/부모 불변·후행CUDA0·전체200개 완료가 성공 신호다.
내용 오답은 실험 오류가 아니며 실패 답도 원형 그대로 보존한다. 부분 실행은 전체 점수로
보정하지 않는다. 새 학습·새 체크포인트·추가300M·설치/다운로드·정제 접근·Git·삭제0이다.

모델 실행 전 실제 문항 판독에서 받침 이름 뒤 `가/는`을 고정한 초안의 조사 오류를 발견했다.
v1은 CPU 동결/정적까지만 수행했고 두 GPU 런처는 미실행이다. v1 원문/manifest/source는
보존하고 한국어 조사 선택과 회귀를 보완해 새 v2/Stage12aWb·Stage12bWc/Wd에서만 진행한다.
정답 내용·언어별 분모·영어 질문·모델·생성 조건을 유지한다. 이는 모델 답을 보고 고치는
튜닝이 아니라 모델 실행 전 입력 언어품질 수리다.

채택하지 않는다. 새학습/새지능향상0, 공식 benchmark와 외부 인간 판독은 별개다. 원답을
학습·교사·오답 교정에 재사용하지 않는다. 원수집 report의 판독 NOT_RUN은 덮지 않고
별도 summary/packet의 후행 판독 상태와 연결한다.
