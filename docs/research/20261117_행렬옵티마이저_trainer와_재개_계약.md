# 행렬 optimizer의 명시 trainer 선택과 재개 계약

사용자161이 필요한 구현을 허가한 기존55/56 후속이다. [078§21](../../test_result/078_20260911_P005b-RMS4는-jordan20을-이겼지만-한-형상이다.md#p005b-author-bf16-gloo-resume)의 새 BF16/Gloo2는 실제 통과했지만 trainer에는 연결되지 않았다. 기본 Muon RMS4를 유지하며 별도 선택으로 연결한다.

1. 새 선택은 `muon_matched`, `normuon_tinylm`, `adamuon_fp32v`, `adamuon_author_bf16`다. Nor는 기존 TinyLM 적응판이며 공식전체 이식으로 부르지 않는다. 기본값은 `muon`이다.
2. 모든 새 선택은 같은 고유 FP32 2D 본체행렬 집합을 사용한다. nn.Embedding·lm_head/get_output_embeddings·TinyLM emb_up/mtp_up 출력 projection·1D 및 scale/shift/gates/gain/bias/LRM·GSQ/code-selection logits는 AdamW로 남긴다. alias는 한 번만 처리한다.
3. AdamW는 `model.param_groups(lr)`의 기존 LR/WD/특수metadata·그룹 순서를 유지하고 본체행렬만 뺀다. 새행렬WD 기본0이며 명시 override도 이 집합에만 적용한다. 기본legacy grouping을 새 비교군과 같다고 쓰지 않는다.
4. 새 선택에는 양의 유한 `--matrix-lr-mult`가 필수다. 기존 `--muon-lr-mult` 기본4를 자동승계하지 않는다. Muon/Nor는 명시 `muon_scale`을 사용하고 Ada 두 종류는 해당 인자 RMS 기본만 허용하되 중복 shape/RMS 배율을 적용하지 않는다. 새방법은 opt_dtype=fp32만 지원한다.
5. state는 Muon momentum, Nor FP32 row EMA, 기존Ada FP32 V, 저자정렬Ada BF16 flat V/통신scratch를 구분한다. 단일 trainer는 저자Ada world1만 연결하며 Gloo2 증거를 NCCL trainer로 승격하지 않는다.
6. 새 checkpoint에는 method·역할별 이름/shape/dtype·원group LR/WD·nominal LRmult·state 규약 hash를 저장한다. 다른방법/역할/인자/누락manifest는 model/AdamW load 전에 거절한다. 저장 optimizer key `opt_muon`은 호환 컨테이너일 뿐 실제method는 manifest로 검증한다.
7. 새경로도 기존 warmup/WSD 계수와 gradient clipping/skip/step/저장을 사용한다. 부분 산술오류는 전역rollback을 보장하지 않으며 원optimizer의 stop/정상CP 복구 경계를 유지한다.
8. 검증은 CPU의 실제 신규 optimizer 업데이트/저장재개와 기본 recipe·CLI 전달이다. 모델학습/검증·현재여러GPU/NCCL·품질/전체wall은 NOT_RUN이다. TinyDataset·설치/새환경0이다.

## 2026-11-17 Stage21W — 저자 NorMuon의 명시 행렬 선택

새Nor는 양수 matrix-lr-mult/FP32 master·별도 source shape scale을 사용한다. legacy muon-scale의 기본rms를 추가 배율로 적용하지 않으며 임의override는 거부한다. None gradient는 원규약대로0과모멘텀꼬리·현재WD생략이며 실제step이gradient를바꾼다는사실을manifest에기록한다. 입력NaN/잘못된state는AdamW step전, 저장matrix schema/모든소유state누락은model/AdamW load전에검사한다. 이 선검사는 공통 checkpoint의 모든 AdamW tensor를 검증한다는 뜻이 아니다. 후반 산술 오류는 rollback하지 않는다.

CPU만의 단계이므로 자연어학습토큰0·풀/품질통계판정N/A다. 새태그 p005b_normuon_author_matched_v1_20261117_s1337은 조회 후 사용한다. Native실행 명령/새학습SH는 이 단계에서 작성하지 않는다. 검증 전이며 실제로 그런지는 돌려봐야 안다.
