# 주도 실험의 채택 재검토와 마감 뒤 정리

**판정:** 운영·정확성·평가·교사 생산 경로에는 실제 채택한 것이 있다. 그러나 이번까지의
근거로 새 TinyLM의 범용 지능과 안정적 일상 대화를 개선했다고 추가 기본 채택할 모델은 없다.
구현한 옵션, 좁은 과제의 관측 이득, 전체 모델의 기본 채택을 구분한다.

이 보고는 2026-11-13 사용자119~123의 런처·체크포인트 정리, KoBEST 설치, 역대 채택 재검토,
한국어 로컬커밋 요청을 처리한다. 17시까지였던 GPU 연구 허가를 연장한 것이 아니다.
새 모델 로딩·학습·GPU·전체 스모크는0이다. 타 정제 세션과 보호 TinyDataset은 제외했다.

## 1. 검토 범위와 판정 방법

총괄 GPT가 기존 WSL 저장소에서 단독 수행했다. [방법론 원장](../METHODS.md)의13개 분권
(논문 분권 포함), [현재 기준표](../EXPERIMENT_BASELINES.md), P093B/P101A/P102A/P106B/P106D/
P107/P108/P078 결과와 실제 코드·실행 경로를 대조했다. 방법론 상태 재고는
`handoff/audit/postresearch_cleanup_20261113/METHOD_REGISTRY_CENSUS_v1.json`이다.
427개 상태행에는 중복·역사·문헌행이 섞여 있으므로 독립 실험427건으로 세지 않는다.
모든 원시 로그를 새로 재현·재계산한 전수 실험이라는 뜻도 아니다.

판정 기준은 다음과 같다.

- **기존 기본/구조:** 이전에 채택되어 현재 코드·recipe가 유지하는 것. 이번 주도 연구의 새 성과와 분리한다.
- **경로에 실제 적용:** 특정 교사·도구·자료·평가에 실제 사용한다. 모든 모델의 기본값이나 지능 개선을 뜻하지 않는다.
- **실험옵션:** 구현·일부 실행은 있으나 기본 recipe로 승격하지 않았다.
- **비채택/미완:** 원래 문턱을 못 넘었거나 본학습·독립 품질을 아직 확인하지 않았다. 미실행과 실패를 구분한다.

## 2. 이미 채택해 유지하는 것

| 대상 | 실제 채택 수준 | 근거와 범위 |
|---|---|---|
| prelude/coda 독립·QK-norm·SwiGLU·factorized/tied embedding | 기존 구조 | 오래전부터의 모델 구성이다. 최신 모든 프리셋이 MLP 공유를 쓴다는 뜻은 아니다. dense/float 대조는 별도 경로다. |
| CLA2·MLP 공유·g128 삼진 STE | 지원 구조/선택 프리셋 | 메모리와 손실의 교환비를 연구하는 구조다. 단순히 존재한다는 이유로 최신 범용 대화 모델의 승자로 세지 않는다. |
| Muon RMS4·일반 행렬 WD0·기본 KD off | 기존 사용자 recipe 유지 | 2026-09-18 결정과 기준표§1이 정본이다. CLI의 LR/cosine/accum 기본과 연구 recipe 전체가 같다고 하지 않는다. |
| WSD·조건부 compile/checkpoint | 기존 명시 연구 설정 | WSD의 과거 동일조건 측정과 checkpoint의 메모리/재계산 교환비를 유지한다. 모든 새 구조의 가속을 보장하지 않는다. |
| ChatML 단일 역할표지·assistant-only 지도·shift/owner/EOS 검사·엄격 loader | 실제 후속 연구 경로 | 사용자 입력·사고·옛 오답을 무조건 정답 target으로 만들지 않는 계약과 tokenizer/route 불일치 방어다. 답변 정답성 자체를 해결한 것은 아니다. |
| 교사 시작 라벨+코드 래핑·단순 answer/복잡 출력 분리 | 실제 생산 계약 | 교사는 내용, 코드는 JSONL/ChatML과 알려진 단순 답 형식을 맡는다. 복잡 JSON을 단순 포장으로 추정하지 않는다. 형식 정상과 사실 정상은 별개다. |
| Gemma4-12B 교사 MTP ON·draft2 | 실제 생산 분기에서 사용 | 결과101§92의12대응 요청은 같은 sampler/사고1024/출력3072/context8192였다. 유효자료 공급률은 두 순서에서1.6406/1.7157배였다. 실제 사고깊이와 의미 정답성이 같다는 보장은 없다. 이후 ON 생산 경로가 실제 사용됐다. |
| 원답·사고·거부·출처·명시 증분 재개·제한 telemetry 재시도 | 실제 운영 경로 | 데이터 유실과 예산 보류/오류 혼동을 줄인다. 조회 누락 구간은 GAPPED로 공개하고 peak/OOM 안전을 주장하지 않는다. |
| 공개자료와 번역·증강의 명시 편입 | 부분 자료 채택 | 기존 승인60원천·158변형은 TRAIN 계보에 연결했다. 뒤의 의미검토 통과 후보나75M 후보 전체를 자동 편입한 것은 아니다. 학술용어를 임의 동의어로 바꾸지 않는다. |
| 공식 평가 고정 source·native tokenizer·실제 첫답/반복/질문복사 분리 | 실제 평가 경로 | 기존 모델 점수와 새 외부 교사 점수를 분리한다. Qwen3.5의 고정B1×1024 경로는 해당 수치/인과 검사 뒤 사용했고 원가변형상 음성은 보존했다. |
| 모델 선택용 추론 메뉴·결과 로그·명령/체크포인트 정리 도구 | 운영 도구 | 사용자가 실제 질문과 원답을 볼 수 있고, 원본·실패·복구 및 디스크 자원을 추적한다. 모델 지능 향상률로 세지 않는다. |

특히 **교사 MTP ON은 미채택 목록에 넣으면 잘못이다.** 반대로 같은 이름의 **학생 학습용 MTP**는
아직 범용 품질 기본 채택이 아니다. 교사 생성 가속과 학생 학습 목적·추론 검증을 분리한다.

**현재는 A를 우선하고 B를 자원 경로에 연결하는 편이 타당하다.** 이 검토는 새 본학습 허가가

다시 돌려 결론을 기대하지 않으며, 본학습 전에 작은 학습 성과로 방법을 채택하지 않는다.
소규모 실행은 수치·자원·입출력 계약을 확인하는 데 한정한다.
