# DVLM 입력 가시성의 하이브리드 교사 호환 선결

원장63의순증분검토다. 기존10월23일문헌검토와달리실제설치된Qwen3.5 fallback 함수에
합성CPU텐서를넣어제어하는범위를검사한다. 교사체크포인트/모델은로드하지않는다.
DVLM전체구현·실제언어행동·성능의검증으로승격하지않는다.

| 안 | 내용 | 이득 | 한계·영향 |
|---|---|---|---|
| A, 선택 | 실제gated-delta recurrence/chunk·prefix state fork·padding mask의CPU검사 | 설치/새모델/GPU없이스택제약을가른다 | 한층primitive·합성텐서이며전체HPA는미구현 |
| B | 기존순수attention Qwen0.6 교사로PTS/HPA를별도구현 | 단순branch mask경로부터접근가능 | 새교사경로/어휘head학습·수치검증이필요 |
| C | 현재hybrid교사에4D mask만붙여완료처리 | 변경량은작음 | recurrent/conv상태의이전분기유입이남을수있어채택하지않음 |

기존DSKD는native hidden과head에접근할수있게됐으나DVLM의PTS/HPA입력계약은별개다.
논문의입력정렬/학생어휘head목적은 [저자초록](https://arxiv.org/abs/2609.33816)에있다.
이번현재웹에서전체HTML/PDF의열람은실패했고기존로컬문헌검토의전문확보범위와구분한다.
현재저자공식실행repo를확정하지못했으며개념을복제한코드를저자재현이라고부르지않는다.

Stage7akW는같은원prefix16·다른private분기16·다음분기16의실제torch recurrence를비교한다.
이전private분기를바꿔다음출력이달라지는지, 원prefixstate를복제해자기분기만흘리면독립성과
원prefix+자기분기의직렬계산이유지되는지검사한다. chunk/recurrent는원atol1e-5/rtol1e-4로
대조한다. padding helper의4Dmask동작도읽는다. 이는그함수의원래padding용도를버그라고
규정하는것이아니며일반HPA마스크로사용할수있는지의검토다. 실제모델에서는conv state와
attention KV도함께분기해야하므로recurrent state하나의복제로완료됐다고하지않는다.

소유영향은새CPU진단/SH·계획/결과/WIP뿐이다. 사용자115 CPU위임으로실행하며예상수초,
모델/원CP읽기/GPU/optimizer/학생교육/설치/원native라이브러리수정/타정제/추가300M/Git0이다.
행동원인이나일반지능개선판정은하지않고원소스전후SHA와CUDA미초기화를확인한다.
