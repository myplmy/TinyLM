## 권한과 영향

새 `scripts/p106b_dwa_cma.py`·독립 시험·전용 진입기/새 evidence와 소유 계획/결과/목록/원장을 사용한다. 제품/기존 DWA helper·GPU DP·원 model/CP·원로그·타정제·보호 데이터·설치/전역설정/Git/삭제는 변경하지 않는다. caller 영향은 새 명시 경로에 한정한다. 기존 CPU1 동결 소스는 수정하지 않는다.

데이터 축은 원 target/turn owner의 선택을 유지하고 teacher/student의 서로 다른 길이를 구분한다. 검사 축은 실제 concat query·scalar std·양방향 가시성·detach/head gradient·두 표현/공유 투영·비연속 mask와 unequal microbatch 분모를 대조한다. 문서 축은 계획→원로그/JSON→결과101/두 목록/기준표/방법론/COMPASS다. 부채 축은 source-aligned 구성과 TinyLM adapter의 차이를 숨기지 않는 것이다. GPU/동시작업 축은 CPU1 종료 후 단일GPU 직렬이고 비교 축은 같은 입력/초기값/교사/손실계수와 각 방법의 추가 비용이다.

## 첫 수치 계약

새 core는 미리 감독 위치를 선택한 한 sequence의 input/target embedding과 final hidden, native 전체어휘 logits와 동결 head를 받는다. CE target과 native input은 한 번만 shift하며 gather 전에 native causal 문맥을 보존한다. sequence가 비거나 std/가중질량이0이면 HOLD다. query 경로의 학생 embedding은 detach하지만 DTW embedding 경로의 학생 미분은 유지한다. 교사 tensor/head는 동결하고 projector·학생 hidden의 미분을 별도 검사한다.

band는 저자0기반 cross/unbanded-self 정책으로 명시한다. 이를 대칭 거리라고 부르지 않는다. GPU DP는 기존 검증된 FP64 v2를 그대로 사용하고 그 cast를 통해 원 FP32 표현에 미분을 연결한다. 느린 CPU DP는 작은 독립 대조만 수행한다. gamma/계수/warmup은 후속 profile에서 사전 고정하고 source 기본값을 기억에서 자동 복사하지 않는다.

수학/미분 게이트 통과가 본학습 품질을 뜻하지 않는다. 정식 교과/전체 학습과 독립 평가의 기존 선결을 유지한다. 새 외부 코드 설치 없이 준비 가능한 부분부터 수행하며16:40 새 모델 계산 중지·17시 기록 회수를 지킨다.
