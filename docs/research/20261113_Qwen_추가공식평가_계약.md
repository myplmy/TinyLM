# Qwen3.5 고정 폭 경로의 남은 독해·단어복원 평가

2026-11-13 사용자115의 미완 원장 우선 연구 위임으로 총괄이 설계한다.
현재 Core6 full은 중단하지 않는다. 정확 legacy 입력 확인과 ACTD 실신호/학생 미분을
먼저 회수한 뒤, 잔여시간의 측정 입장조건이 맞을 때만 추가 전량 평가를 수행한다.

## 1. 왜·질문·예측

원장45/47의 기존7모델은 Belebele 한국어/영어 각900과 LAMBADA5153을 이미 끝냈다.
Qwen3.5는 길이별 수치음성 때문에 이7모델에 포함되지 않았다. 새 qualified fixed1024
경로의 Core6와 정확 legacy 보완이 닫히면 같은 공식 평가를 연결할 수 있다.
완료한7모델을 다시 실행하거나 새 TinyLM 학습성과를 주장하지 않는다.
이 비교는 다른 사전학습/어휘/규모의 모델 비교이며 TinyLM 구조·양자화의 단일효과가 아니다.
Qwen의 정확한 성능은 미지수이며 새 고정 폭의 비용 때문에 시간이 부족할 수도 있다.

## 2. 영향과 권한

| 경로 | 동작 | 권한 근거 | 제외 |
|---|---|---|---|
| 새 qwen35 extra helper/driver/test·Stage8ag~8aj SH | 기존 공식 task/계산 bytecode를 새 fixed runtime에 연결 | 사용자115 구현·CPU/GPU 미완작업 위임 | 기존 evaluator/모델/library/공식 정의 변경0 |
| 새 p106b_qwen35_extra_official_v1_20261113 | token-only 봉인·cost·full 원답/정리 영수증 | 같은 증거 기록 위임 | 원7모델/기존자료 덮어쓰기·새 다운로드0 |
| P106B·결과101·기준표·방법론·목록·COMPASS·자기WIP45/47/115 | 계획/실측/미실행 동기화 | 같은 원장/기록 위임 | 타정제/TinyDataset/추가300M/설치·새환경/Git/삭제0 |

코드는 기존 Belebele requests/token_plan/freeze/read_frozen/evaluate/recount와 LAMBADA
load_task/evaluate/recount를 재사용한다. LAMBADA task의 CACHE는 private function globals의
저장 경로만 새 namespace로 바꿔 기존 runtime cache에 쓰지 않는다. bytecode는 그대로다.
새 cache는 평가 자료 저장이며 새 Python 환경이 아니다. import/호출부·공식 source SHA를 봉인한다.
회귀는 전역 불변, 원 함수 bytecode 재사용, 모든 target 보존·token-only 실행 차단,
완전한 task별 비용/입장, 실제 종료/원복/원형 검산을 확인한다.

## 4. 단계·판정·비용

1. Stage8ag CPU: 원 local 자료 byte/버전/원문을 확인하고 공식 zero-shot task를 생성한다.
   Qwen tokenizer만 로딩해 Belebele1800×4선택지와 LAMBADA5153의 전체 token plan을
   출력 전 동결한다. 원 YAML prompt/target/metric은 그대로다. 원7모델 공통 무절단 교집합과
   새 Qwen의 교집합을 구분한다. 모델/GPU0, CPU 약1~5분 예상이다.
2. Stage8ah cost: 원 Core6 full과 exact legacy 보완의 실제 종료0/소스/자산·CUDA0 뒤,
   같은 B1×1024 FP32/eager/TF32 OFF·cache OFF로 세 task 각32의 비용을 측정한다.
   LAMBADA 기존 boundary_canary도 사용한다. 이 소표본 점수는 모델 성능으로 보고하지 않는다.
3. Stage8ai Belebele full: KO/EN 각900·선택지7200 전체, 기존 token plans와 매문항 대응,
   공식/독립 metric과 raw 전량 검산, 원몸체·tokenizer·소스·객체/CUDA0와 실제 exit를 닫는다.
4. Stage8aj LAMBADA full: 공식 default5153·마지막 단어의 모든 native subtoken 우도/greedy를
   평가한다. 새 token plan과 대응시키며 전체 raw/공식 acc·perplexity를 독립 검산한다.

cost의 task별 초/32에 전체 분모를 곱해1.5배 여유와 준비·정리시간을 더한다. 마감17시 전
최소15분을 유보한다. 새 모델 동시 상주나 패키지 설치·자료 다운로드는 없다. 파일당20MB 미만이다.
기술 오류·부분 결과·전량완료·독립검산/실제종료를 구분하며 report0만으로 채택하지 않는다.

## 5. 한계·이력

Belebele는 보기 A/B/C/D의 전체 우도를 비교하는 독해 평가이며 자유 대화가 아니다.
LAMBADA는 조건부 마지막 단어 복원이고 reasoning·thinking 대화의 증명이 아니다.
공식 context1024/왼쪽절단·전체 target 유지·0shot·문자길이 정규화·집계는 고정한다.
Qwen의 물리 실행 폭1024는 수치 일관성을 위한 runtime 정책으로 별도 표시한다.
원7모델과의 공동 무절단 보조 표본이 달라지면 원표를 그대로 새 교집합의 결과로 쓰지 않는다.
평가 정답과 원답은 train/편집 선택에 넣지 않는다. 초기 설계 단계이며 실제 실행은 미완이다.
