## 사전 계약

Stage6aW는 CUDA를 초기화하지 않는다. 저장된 key/gradient/margin/value/factor·profile·capture/search 보고서 SHA를 고정하고 full ridge 정상 방정식·기존 residual을 다시 검산한다. 첫/끝 quantile·body452/EOT128·정답 대 기존 경쟁토큰의 1차 margin을 보고한다. CPU FP64 재구성과 실제 GPU FP32 덧셈의 byte 일치를 주장하지 않는다. 상한0.25%/1%/4%는 기존 dev에서 사용한 값 그대로이며 새 선택을 하지 않는다.

Stage6bW는 A의 근거가 진단 가치가 있을 때만 준비한다. 첫4개 calibration ID와 실제 주입 조건을 GPU 전에 봉인한다. 정답별 직접 활성값은 내용 oracle로 표시하고 원래 경쟁 토큰을 고정한 margin과 매번 바뀌는 최대 오답 margin을 함께 읽는다. 동일 prefix의 teacher forcing으로 제한하며 자유 생성·정답률 개선을 주장하지 않는다. no-op·동일 원본/원복·유한값·최종 CUDA 해제를 검사한다. 최대300초와 마감120초 예비를 적용하고 원 CP 저장/새 학습 update/삭제0이다.
