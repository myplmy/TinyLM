## 실제 실행 메모리와 남은 일

숫자가 저장된 실행 메모리는 GPT2의0.5초 간격8285개 표본뿐이다. GPU 전체 사용량의
표본 최대1531MiB,소유 worker RSS 표본 최대425.777MiB다. 전역 GPU 사용량을 모델만의
VRAM으로 부르지 않는다. 누락·정리 구간과 표본 사이 peak는 보장하지 않는다. root 감사는
`handoff/audit/WIP_20261024_GPT2_FULL_ROOT_CLOSURE.json`이다. 단조 wall4458.609초와
달력4679.119초의 차이 원인은 미확인이다.

다른 모델의 GPU 유휴 point 확인은 메모리량 측정이 아니다. paired CPU 통계의
`peak_rss_bytes`도 통계 프로세스 메모리이지 모델 메모리가 아니다. 전체8모델의 실제
tensor storage·weights+cache·peak RAM/RSS/VRAM·TTFT·전체 자유응답 시간·tok/s·
chars/s·길이·상한 도달률 행렬은 아직 미완이다. 별도 고정 생성 조건의 실제 측정 없이는
우도 평가 wall로 빈 칸을 채우지 않는다.

모델별 사전학습량·어휘·Base/PT/IT·정밀도·batch가 다르므로 이 표만으로 학습효율이나
일반지능·40MB 배포 목표의 우열을 확정하지 않는다. 새 본학습 전에 작은 학습 점수로
성공을 채택하지 않는 사용자 원칙도 그대로 유지한다.

## 별도 Qwen3.5 HF 관찰: 전량 비교 행렬과 구분

결과101절500의 독립 관찰에서 상주 등록parameter320개와buffer2개의CUDA storage는
3,009,572,352B였고 allocator allocated는3,009,589,248B였다. 종료 뒤 모두CPU이며
Python 추적CUDA0인데8,519,680B가 남았고 일반 반복 정리의 감소0,cuBLAS workspace
clear1회 뒤0이었다. 실제 부모 종료9와 원 cleanup false는 유지했다. 이는 단일 시점
관찰이며 peak VRAM,모델 단독RAM,TTFT나전체 Core6 평가 자원값이 아니다. 위8모델
행렬의 미계측 칸을 이9번째 진단 모델의 수치로 채우지 않는다. GC의 CPU 목록과
강참조 및프로세스RSS 비용도 관찰에 포함될 수 있다.
