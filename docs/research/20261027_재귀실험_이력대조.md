# 2026-10-27 재귀·층공유 실험 이력과 재사용 경계

원장66의 기존 실험 대조다. 현재 사용자96/97에 따라 데이터 정제는 다른 세션에 맡겼으며, 이 문서를 위해 추가300M 학습이나 정제 원문 접근을 하지 않았다. 과거 수치는 기존 결과의 재판독이고 새 증거는 명시7개 학습 JSON과 체크포인트의 바이트 해시/CPU meta 헤더다. 보조 에이전트는 읽기 검토만, 총괄은 정본 대조와 문서화를 수행했다.

## 1. 서로 다른 여섯 축

| 축 | 바꾸는 것 | 구별할 사항 |
|---|---|---|
|MLP 공유|여러 논리 층이 같은 gate/up/down 파라미터 사용|동일 객체 수와 물리 층 수는 다름|

현재 [설정](../../tinylm/config.py)과 [방문 구현](../../tinylm/model/transformer.py)을 읽었다. 학습 TR과 추론 IR은 동시에 켜지 않으며 eval에서 명시 IR 변경이 없으면 학습 TR 경로를 계승한다. 과거 TR2 학습을 R1로 평가한 결함은 현재 동작이 아니다. 캐시 재사용 기본값과 owner/방문차수 슬롯도 구별한다.

## 4. 미확인과 정정

`opt_dtype=fp32`는 optimizer 알고리즘을 뜻하지 않는다. 헤더의 state/param_groups만으로 AdamW/Muon을 확정하지 않는다. 과거 결과가 소유한 조건 설명과 새 헤더의 확인 범위를 분리한다. 원학습 코드 commit과 tokenizer 파일 SHA는7개 헤더에 없고, V32768만으로 현재 chat32와 같다고 판단하지 않는다. nominal600M pool은 실제300M draw나 고유량과 다르다.

- P070의 `m100R1d=중간 MLP1개`를 실제2개로 정정했다. 한 객체 모듈 교환과 전체 층순서를 구별했다.
- P049 머리말의 `gate 미측정`은 [041 §15](../../test_result/041_20260813_P049-깊이가-산것은-MLP고-어텐션은-꺼졌다.md)의 완료 기록으로 정정했다. attention move −49.52%/MLP +43.80%와 당시 요약의 부호 오독을 보존한다. gate 크기만으로 전체 품질의 인과 기여를 확정하지 않는다.
- P070B 머리말의 `실제 checkpoint NOT_RUN`은 실제 Wa9/Wb 제한 진단으로 갱신했다. 전체 학습/품질 성공으로 바꾸지 않는다.

담당은 [MoDr](https://github.com/zhangxjohn/MoDr), [CDB](https://github.com/kschwethelm/continuous-depth-batching), [xLLM-Loop](https://github.com/ifm-ai/xllm-loop), [STARS](https://github.com/njuyxw/STARS), [TaH2](https://github.com/thu-nics/TaH), [LTO](https://github.com/ninglab/LTO)의 README/진입점도 확인했다. STARS의 학습 본문은 이번 조회에서 차단돼 VJP 구현을 새로 검증했다고 쓰지 않는다. 논문 spectral-radius와 README Frobenius 설명의 차이도 미해결이다. CDB는 기존 문헌표의v1 뒤 v2를 확인했고, LTO v3의 일반LM 전체실험 범위는 초기 참고요약보다 넓다. 이 차이를 로컬 성능 증가로 바꾸지 않는다.

현재 권장 순서는 기존 정확한 경로/실제답·정제/학습가속·chat32 증류를 먼저 재사용하는 것이다. 구조 확장은 그 뒤에만 별도 변수를 정한다. 상태에 유용한 정보가 남는다는 근거가 생기면 LoopCD, R 외삽의 실제 붕괴라면 STARS, token별 낭비라면 TaH2, 다중요청 서빙이면 CDB, 후보선택이면 LTO로 연결한다. 이력 정리와9문헌 연결은 완료했지만 각 방법의 새 TinyLM 구현·본학습 효과는 NOT_RUN이다.
