## 수식과 사전 조건

각 지도 위치의 margin은 정답 로짓에서 가장 높은 다른 토큰의 로짓을 뺀다. 현재 margin을 m, 마지막 down 출력에 대한 gradient를 g라 하면 원하는 출력 변화는 v = clip(1-m,0,10) g / max(||g||²,1e-12)다. 이미 margin≥1이면0 목표로 포함한다. 입력 key와 v를 같은 key norm으로 나눠 과도한 활성 크기 영향을 줄인다.

행으로 모은 K,V에 대해 ||K deltaW^T - V||² + lambda ||deltaW||²를 최소화한다. lambda=.01, CPU FP64 해 deltaW = V^T (K K^T + lambda I)^-1 K를 쓰며 SVD의 nominal rank16만 남긴다. 현재 모델의 down weight Frobenius 대비0.25%/1%/4% 상한 세 개를 dev에서 비교한다. 실제 delta SHA가 같으면 중복 평가하지 않는다. 선택은 정확 일치→보호 복사/요청반복→빈 답/질문 echo/반복→작은 norm 순이다.

원래 TLinear의 추론 캐시를 고정한 실제 함수에서 activation gradient만 측정한다. parameter.grad·optimizer는 사용하지 않고, 원본 CP와 등록 가중치를 바꾸지 않는다. 계산 캐시를 수정하므로 현재는 연속 보정이며 삼진 배포·master 복원의 증거가 아니다. 제한적인 지도 보정이므로 정답 노출량·원래/보정 후 정답 우도와 실제 자유 생성의 차이를 모두 남긴다.
