# 저장된 긴 이력의 KV 계산 정합성 — P106B Stage15aW

사용자104가 허용한 11월1일11시까지 정제 외 독립 연구다. GPU 전량 평가와 별도로 CPU2스레드,
내부600초·외부660초 안에서 기존 답변의 토큰을 강제로 재생한다. 새 학습·새 답변 생성은0이다.

## 1. 목적과 기존 근거

현재 GSM8K의 KV 검사는 10~12토큰의 같은 이력 세 점을 확인했다. Native 전량의 반복 답변이
길어졌을 때 캐시와 전체 재계산이 다른지는 그 검사로 닫히지 않았다. 완료 모델을 다시 학습하거나
벤치마크 전량을 다시 생성하지 않고 저장된 prefix/생성ID로 이 구현 의심만 분리한다.

## 2. 세 방법 비교와 결정

| 안 | 예시·방법 | 장점 | 한계·비용 |
|---|---|---|---|
| A | 기존 짧은 세 점만 재사용 | 새 계산0 | 긴 실제 반복 이력은 미확인 |
| B 권장 | 저장문항0/149/509의 생성위치0·8·64·128·255에서 CPU 캐시와 재계산 비교 | 현재 GPU 큐를 건드리지 않고 같은 긴 이력 확인 | 최대10분 CPU, GPU 수치 동등성은 미측정 |
| C | 같은 질문을 새 GPU에서 cache on/off로 다시 생성 | 실제 GPU 경로 비교 가능 | 현재 전량 큐 비용과 별도 출력을 추가하며 첫 차이 뒤 이력이 달라짐 |

B를 이번 기술 진단으로 선택한다. 같은 저장 토큰을 넣으므로 답변이 달라진 뒤의 이력 차이를
캐시 차이로 오해하지 않는다. 세 문항은 첫 실패/숫자 적중의 문맥 오독/정답 진술과 반복을 본
뒤 고른 구현 진단 사례이며 무작위 성능 표본이 아니다. 정답·필터를 바꾸거나 학습에 보내지 않는다.

## 4. 고정 조건과 판정

같은 Native595-Q CP/원 SHA·실제32768어휘·1024문맥·FP32/MATH·원삼진 route·MTP OFF·
방문1/비공유 MLP를 유지한다. 세 저장이력을 각각255개 강제 토큰까지 잇고 다섯 위치의 마지막
전체32768 로짓과 모든 KV owner의 K/V shape/dtype/값을 전체 재계산과 비교한다.

기존 canary와 같은 atol/rtol=1e-4를 고정한다. float close, argmax 동일성, KV close를 별도
기록하며 세 가지가15점 모두 참일 때에만 선택한 CPU 경로 정합으로 판정한다. 근접 동률에서
float close지만 argmax가 달라도 따로 음성으로 남긴다. 저장 GPU의 다음ID와 CPU argmax도
기록하되 CPU/GPU 차이를 캐시 차이로 합치거나 숨기지 않는다. 실패 뒤 기준을 완화하지 않는다.

## 5. preflight와 한계

새 학습토큰0, 학습 풀/배치/LR/seed 우열 판정은 해당없음이다. 기존 짧은 canary 및 P101A의
다른 CP parity shadow와 겹치는 도구는 재사용하지만 같은 Native 긴 이력15점의 기록은 없었다.
새 namespace/원형 보존·CPU8·정확 입력ID 및 실제 source 불변을 확인한 뒤 수행한다.

통과해도 GPU 전체 이력 정합, 반복의 단일 원인, 공유 MLP/재귀 구조의 안전, 일반지능 향상을
보증하지 않는다. 실제 세 모델 중 하나의 CPU 구현 의심만 좁힌다. 큰 공식 점수/400첫답과 별도로
기술 근거로 기록한다. 전체 본학습 전 작은 품질 승자를 고르는 실험이 아니다.

## 6. 실행과 갱신

`bash run_P106B_Stage15aW_gsm8k_longkv_cpu.sh`

실행 전 CPU8/SH구문/고정3이력 경계 검사는 통과했다. 실제15점 모델 대조는56.219375초/코드8이며 로짓/argmax는 같고 일부V가 엄격 기준을 넘었다. 추가 규모 관찰도18.307446초/코드8을 보존했다. 결과101§574와 LONGKV_ACTUAL_ROOT_v1.json이 실제 판정 정본이다. 현재 SH는 명령 원형 보존 뒤 -done으로 분리했다.
완료 뒤 원로그/본체·입력·소스 불변/CPU 자원/15점 수치와 음성 여부를 같은 P106B 결과문서의
새 절에 시간순으로 추가한다. 현11시 마감 뒤의 추가 실행은 허가하지 않는다.

이 점검은 알려진 설계 실수만 걸러낸 것이고, 실제로 그런지는 돌려봐야 압니다.
