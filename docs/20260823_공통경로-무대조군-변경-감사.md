# ★★모든 학습이 지나는 길 — **대조군 없이 넣은 것 전수 감사** (2026-08-23)

> **사용자 지시**: *"모든 실험이 지나는 길에 대해서 코드상에 문제가 없는지와 **대조군 실험 없이
> 모든 실험이 지나는 길(학습시 옵션?)로 추가한 내용은 뭐가 있는지** 확인하고 문제가 될 것으로
> 보이는 부분들을 판단하여 실험계획으로 대조군 실험 수행해야하는 경우 실험계획 작성해서
> 실험 수행 준비할 것."*

---

## 0. ★감사 기준 — **"공통 경로" 를 정의한다**

| 구분 | 정의 | 위험 |
|---|---|---|
| ★★**A. 무조건 실행** | 플래그와 무관하게 **매 스텝 돈다** | ★**최고.** 틀리면 **모든 런**이 틀린다 |
| ★**B. 기본값이 켜짐** | 플래그가 있지만 **기본이 on** | 높음. 안 끄면 전부 걸린다 |
| **C. 기본 off** | 명시해야 켜진다 | 낮음. 켠 런만 |
| **D. 도구·평가** | 학습 경로 밖 | 낮음(단 판정을 바꾼다) |

★**A·B 만이 이 감사의 대상**이다.

---

## 1. ★★A — 무조건 실행되는 지점 (학습 루프 본문)

```python
with torch.autocast(device, dtype=torch.bfloat16, enabled=(device == "cuda")):
    logits = model(x)
    ce = _ce_chunked(logits.reshape(-1, cfg.vocab_size), y.reshape(-1), ce_chunk)   # ★신설
    ...
    loss = ce / accum
loss.backward()
gn = torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
opt.step()
```

| 지점 | 언제 들어왔나 | 대조군 | 판정 |
|---|---|---|---|
| ★**`_ce_chunked`** | **2026-08-22**(결과 051 §단계2b 대응) | ✅★**있다 — P071** | ✅**E1 완전 일치, E2·E3 상대차 0** |
| ★**`_kd_kl(fp32=...)`** | 2026-08-22 | ✅★**있다 — P071 E4** | ✅**상대차 0.** 1차 수정이 깰 뻔한 것을 되돌림 |
| `autocast(bf16)` | 오래됨 | ⚠️**대조 없음** | §3.1 |
| `clip_grad_norm_(1.0)` | 오래됨 | ⚠️**대조 없음** | §3.2 |

### 1.1 ✅**`_ce_chunked` 는 안전하다 — 검증됨**

`chunk<=0` 이면 **종전과 문자 그대로 같은 호출**이고, P071 E1 이 **완전 일치**를 확인했다.
✅**기본값 0** 이므로 **명시하지 않으면 종전 경로**다.

⚠️★**단 하나 남은 가정**: `reduction="mean"` 의 분모는 **무시되지 않은 타깃 수**다.
`ignore_index` 가 들어오면 `sum/N ≠ mean`. ✅**단언으로 박아 뒀다**(패딩이 들어오면 즉사).

## 2. ★★B — 기본값이 켜진 것

| 항목 | 기본 | 대조군 | 판정 |

| `cla_group = 2` | **켜짐** | ⚠️★**부분적** — 결과 033 이 VRAM(−35.3%)은 쟀으나 **품질 단독 귀속은 없다** | ⚠️**§3.3** |

## 3. ⚠️**대조군이 없는 것 — 그리고 그것이 문제인가**

### 3.1 `autocast(bf16)` — 🚫**대조 불가. 그러나 안전하다**

**fp32 로 학습하면 VRAM 이 2배**가 되어 **우리 16GB 에 안 들어간다.**
→ 🚫**대조군을 만들 수 없다**(대조군이 OOM 이다).
✅**대신 간접 증거가 있다**: `docs/20260821_학습-dtype-지도` 가 **master·gradient·Adam 산술이
전부 fp32** 임을 확인했고, **bf16 은 GEMM·활성에만** 걸린다.
→ ⏸**대조군 실험 불필요.** ★**단 "우리는 bf16 학습이다" 를 결과문서에 항상 명시**한다.

### 3.2 `clip_grad_norm_(1.0)` — ⚠️**대조 없음. 그리고 값이 근거 없다**

| | |
|---|---|
| 🚫**문제** | **1.0 이라는 값의 출처가 문서에 없다.** 관례값으로 보인다 |
| ⚠️**영향** | 결과 030: `grad_max` **19.32** 를 본 적이 있다 — **클리핑이 실제로 자주 작동**한다는 뜻 |
| ★**그런데** | **클리핑이 없으면 발산**했을 수 있고, **강하면 학습이 느려진다.** 둘 다 미측정 |
| ✅**판정** | ⏸**대조군 실험 후보.** ⚙**우선순위 낮음** — 현재 모든 런이 안정적이고 **바꾸면 전 런과 비교가 끊긴다**(함정 2) |

### 3.3 ★**`cla_group = 2` — 품질 대가가 단독 귀속된 적이 없다**

| | |
|---|---|
| ✅**아는 것** | VRAM **−35.3%**(결과 033), KV 캐시 절반 |
| 🚫**모르는 것** | ★**품질 대가.** `cla_group=1` 대조군이 **한 번도 없었다** |
| ⚠️**왜 중요한가** | ★**P057(어텐션 타잉)이 CLA 와 겹친다** — 결과 044 가 *"대가를 귀속하려면 `cla_group=1` 대조가 필요"* 라고 이미 적어 뒀다 |
| ✅**판정** | ★★**대조군 실험 필요.** → **P073 §1** |

### 3.4 `anneal_end` 가 tied 0.80 / dense 0.60 — ⚠️**근거가 흩어져 있다**

두 값이 다른 이유가 **한 문서에 없다.** 🚫**그런데 이것은 대조군 문제가 아니라 문서 문제**다.
✅**조치**: `docs/EXPERIMENT_BASELINES.md` 에 **왜 다른가**를 한 줄로 못 박는다. ⏸**실험 불필요.**
