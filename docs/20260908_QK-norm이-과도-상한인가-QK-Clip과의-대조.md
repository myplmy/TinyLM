# 우리 QK-norm 은 QK-Clip 의 상위호환인가, 과도하게 상한하고 있나

> **작성** 2026-09-08(2차) · **사용자 지시 2A** · 분류 **조사 보고서**(실험 아님)
> 🚫**이 문서는 런을 0건 돌렸다.** 산술과 코드 판독과 논문 대조뿐이다.
> ★**결론 한 줄**: **둘 다 아니다** — 안정성에서는 상위호환이 맞고,
> ★**표현력에서는 우리가 참조 구현들보다 2.5배 좁게 잠가 두었으며 그것을 한 번도 측정한 적이 없다.**
> 그리고 그 과정에서 ★★**Muon 천장의 가장 유력한 기계적 원인**을 하나 찾았다(§6).

## 0. 세 줄

1. ✅**안정성**: 외부 대조 실험이 있다 — 400M·100B 토큰에서 **QK-Norm 이 QK-Clip 을 이긴다**
   (arXiv:2606.16310, ⚠️초록만 읽었다). Kimi 의 QK-Clip 은 τ=100 사후 클립이고 우리 것은 사전 정규화다.
   **우리에게 QK-Clip 은 불필요하다**는 종전 판정은 유지된다.
2. ⚠️★**표현력**: 우리 유효 스케일은 **g = √head_dim = 8**(고정·비학습)이다.
   원 논문(arXiv:2010.04245)이 우리 문맥길이에 권하는 초기값은 **g₀ = log₂(L²−L) = 20.0**,
   그리고 그것을 **학습 가능**하게 둔다. ★**우리는 그 2.5배 좁은 곳에 못을 박았다.**
3. 🚫★★**그런데 우리는 실제 로짓 분포를 한 번도 안 쟀다.** 상한이 8인 것과 8에 닿는 것은 다른 말이다.
   → ★**측정 하나(⚙0.2h)가 이 물음을 닫는다**(§7).

## 1. 우리 구현이 정확히 무엇인가 (코드 판독)

`tinylm/model/modules.py`:

| 무엇 | 값 |
|---|---|
| 정규화 | `RMSNorm(cfg.head_dim, cfg.norm_eps)` — ★**학습 파라미터가 없다**(`__init__` 이 `eps` 만 저장) |
| 적용 위치 | q·k **각각**, `head_dim` 축, ★**RoPE 앞** |
| `head_dim` | **64**(dim 768 / n_q_heads 12). ⚠️폭 프리셋도 **64 고정**(`_m100w`) |
| 소프트맥스 스케일 | `F.scaled_dot_product_attention(...)` 에 `scale` 인자 **없음** → 기본 `1/√head_dim = 1/8` |

### 1.1 그래서 로짓의 상한은 얼마인가 — **산술**

RMSNorm 뒤 각 원소의 RMS 가 1 이므로 `‖q‖₂ = ‖k‖₂ = √head_dim = 8`.
RoPE 는 쌍별 회전이라 **노름을 보존**한다.

```
logit = (q·k) / √head_dim
      = ‖q‖‖k‖cosθ / √head_dim
      = 64·cosθ / 8
      = 8·cosθ            ∈ [−8, +8]
```

★**즉 우리 어텐션 로짓은 하드하게 [−8, 8] 이고, 유효 스케일 g 는 정확히 `√head_dim = 8` 이다.**

⚠️**이 값은 폭을 바꿔도 안 변한다** — `head_dim` 을 64 로 고정했기 때문이다(P089 프리셋 넷 포함).

## 2. 원 논문은 무엇을 권했나 (arXiv:2010.04245, ★전문 판독)

**Henry, Dachapally, Pawar, Chen — "Query-Key Normalization for Transformers", EMNLP 2020 Findings.**
(★본문 5쪽 + 참고문헌을 실제로 열어 읽었다.)

| 논문 | 우리 |
|---|---|
| 식 (2): `q̂ᵢ = qᵢ / ‖qᵢ‖` — **ℓ2 정규화**, head 차원 | RMSNorm(=ℓ2 를 √head_dim 로 나눈 것) — **같은 방향** |
| 식 (5): `softmax(g · Q̂K̂ᵀ)V` — ★**학습 가능한 스칼라 g** | 🚫**g 가 없다**(고정 1/√head_dim) |
| 식 (3): `g₀ = log₂(L² − L)`, L = 학습 시퀀스 길이의 97.5 분위 | — |

### 2.1 ★우리 문맥에 그 규칙을 적용하면

| L | `g₀ = log₂(L²−L)` |
|---:|---:|
| 512 | 17.99 |
| ★**1024**(우리 표준) | ★**20.00** |
| 2048 | 22.00 |

★★**우리 g = 8 은 논문이 권하는 초기값 20.0 의 40%** 다. 그리고 논문은 그것을 **학습시킨다.**

### 2.2 ★★논문이 직접 경고한 것 — **바로 이 문제다**

> 논문 §3: 코사인 유사도는 [−1,1] 로 묶여 있어 *"소프트맥스와 반대의 문제"* 를 만든다 —
> 값들의 차이가 너무 작아 모델이 **주의하지 말아야 할 연결을 효과적으로 무시하지 못한다**.
> (그래서 `1/√d` 로 나누는 대신 **학습 가능한 g 로 곱한다**.)

★**즉 "과도 상한" 은 우리가 지어낸 걱정이 아니라 이 기법의 원저자가 명시한 실패 모드**이고,
그들의 해법이 **정확히 우리가 안 넣은 부품**이다.

## 3. ⚠️그러나 산술로 반박도 된다 — **일방적인 이야기가 아니다**

상한이 8 이어도 **원-핫 어텐션은 도달 가능하다.** 로짓 격차가 최대 16 이므로 T 위치에서

```
max attention weight  =  e⁸ / (e⁸ + (T−1)·e⁻⁸)  =  1 / (1 + (T−1)·e⁻¹⁶)
```

| T | 도달 가능한 최대 어텐션 가중치 |
|---:|---:|
| 1,024 | **0.99988** |
| 4,096 | 0.99954 |
| 65,536 | 0.99265 |

→ 🚫**"우리 구조는 날카로운 어텐션이 불가능하다" 는 틀린 말이다.**

★**진짜 물음은 "가능한가" 가 아니라 "얼마를 지불해야 하는가"** 다.
로짓 격차 16 은 **`cosθ` 가 −1 과 +1 을 오갈 때만** 나온다. 실제 학습된 q·k 의 코사인이
예컨대 ±0.3 이라면 격차는 4.8 이고, T=1024 에서 최대 가중치는 **0.106** 으로 **꽤 퍼진다.**
같은 코사인에 g=20 을 주면 격차가 12 로 **2.5배**가 된다.

> ★★**그래서 이 물음은 산술로 못 닫는다. `cosθ` 의 실측 분포가 있어야 닫힌다.**
> 🚫**우리에게 그 측정이 없다.**

## 4. 외부 대조 — **QK-Norm vs QK-Clip 은 이미 겨뤄졌다**

| 근거 | 무엇 | 우리에게 |
|---|---|---|
| **Kimi K2**(`article/kimi/…pdf` §2.1~2.4, ★전문 판독) | **QK-Clip** — 로짓이 τ=**100** 을 넘으면 `W_q`·`W_k` 를 사후 리스케일 | ★우리 상한 **8** 은 τ 의 **1/12.5**. **우리 로짓은 100 에 닿을 수 없다** → 🚫**QK-Clip 불필요**(종전 판정 유지) |
| **arXiv:2606.16310**(⚠️**초록만**) "QK-Normed MLA" · 400M · 100B 토큰 | ★*"QK-Normed MLA achieves lower training loss and better downstream accuracy than **QK clipping**"* | ✅**같은 축의 직접 대조에서 QK-Norm 이 이긴다** |
| 같은 초록 | RMSNorm 을 *"**static affine weight** + dynamic scalar RMS statistic"* 로 분해 | ⚠️★**그 구현의 RMSNorm 에는 affine weight 가 있다** — 우리 것에는 없다 |

### 4.1 ⚠️**미확인 목록** (R31 — 초록·2차자료만 봤다. 요약하지 않는다)

- Gemma 3 · OLMo 2 · Qwen3 의 QK-norm 이 **학습 가능한 gain 을 갖는지**
  — 2차자료(검색 요약·블로그)는 *"RMSNorm(head_dim) 을 쓴다"* 고만 말하고,
  그 `RMSNorm` 이 파라메트릭인지는 **원문에서 확인하지 않았다.**
  🚫**따라서 "모두가 gain 을 쓴다" 고 쓰지 않는다.** 확인된 것은 **둘**이다:
  Henry 2020(학습 가능 스칼라 g) · arXiv:2606.16310(static affine weight).
- arXiv:2511.21377 "Controlling changes to attention logits" · arXiv:2410.16682
  "Methods of improving LLM training stability" — **제목만 봤다.**

## 6. ★★★부수 발견 — **Muon 천장의 가장 유력한 기계적 원인**

이 조사 중에 나온 것이고, ★**QK-norm 보고서보다 이쪽이 더 중요할 수 있다.**

### 6.1 `W_q`·`W_k` 는 **스케일 불변**이다 — 그것도 이중으로

`q = RMSNorm(W_q x)` 이므로 `W_q → c·W_q` 를 해도 **q 가 정확히 같다.**
그리고 우리 `TLinear` 는 삼진화한다 — 임계값도 α 도 `mean(|w|)` 에서 나오므로
**`c` 배를 하면 부호 패턴은 그대로이고 α 만 `c` 배**가 된다. 그것마저 RMSNorm 이 나눈다.

> ★★**즉 `q_proj`·`k_proj` 의 손실은 그 가중치의 스케일에 대해 정확히 불변**이다.
> **오직 방향만 함수를 바꾼다.**

### 6.2 그래서 무슨 일이 일어나나

| 조건 | `W_q`·`W_k` 에 걸리는 것 | 결과 |
|---|---|---|
| **AdamW 팔** | `param_groups()` 의 **dense wd 0.1** | 노름이 눌려 **유효 학습률이 유지**된다 |
| ★**Muon 팔** | 🚫**wd 0**(`Muon(_mats, lr=lr*mult)` — 기본값) | 업데이트가 직교화돼 들어오므로 **‖W‖ 가 단조 증가**하고, 스케일 불변 파라미터에서 **유효 학습률은 대략 `1/‖W‖²` 로 감쇠**한다 |

★★**가설**: **배수를 키울수록 `W_q`·`W_k` 노름이 빨리 부풀고, 방향 학습률이 빨리 죽는다.**
그래서 ×15 가 이기고 ×30 이 나빠지고 ×45 가 진다 — **발산이 아니라 조기 정지**다.
✅**이 가설은 관측과 맞는다**: `n_skip` 이 **전 배수에서 0**(발산 아님)인데
`grad_max` 는 ×5 부터 **단조 증가**했다(기준표 B.21). 🚫종전에 *"천장의 원인은 모른다"* 라고 적었다.

### 6.3 ★**싸게 검정할 수 있다**

우리에게 **배수별 최종 체크포인트가 있다**(×1 · ×5 · ×15 · ×30 · ×45).
→ **`‖W_q‖_F`·`‖W_k‖_F` 를 배수별로 재기만 하면 된다.** 🚫학습 0 · GPU 0(CPU 로드로 충분).
**가설이 맞으면 노름이 배수에 따라 단조 증가**해야 하고, 특히 **×30·×45 에서 `q/k` 가
`v/o`·MLP 보다 훨씬 더 부풀어야** 한다(뒤엣것들은 스케일 불변이 아니다).

⚠️**반증 가능하다** — 노름이 배수와 무관하면 이 가설은 죽는다. 그게 이 시험의 가치다.

## 8. 🚫이 보고서가 하지 않은 것

- **런 0건.** 로짓도 노름도 **안 쟀다.** §3 의 표는 전부 **산술**이다.
- **`g` 를 구현하지 않았다.** 코드는 한 줄도 안 바뀌었다.
- **Gemma·OLMo2·Qwen3 의 구현 세부를 확인하지 않았다**(§4.1 미확인 목록).
- ⚠️**`head_dim` 을 바꾸는 경로는 검토하지 않았다.** 상한이 `√head_dim` 이므로
  `head_dim` 128 이면 상한이 11.3 이 된다 — 🚫**그러나 그것은 KV 회계를 통째로 바꾼다.**
