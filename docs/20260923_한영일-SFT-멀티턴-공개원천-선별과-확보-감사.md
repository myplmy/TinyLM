## 1. 결론과 상태 구분

공개 원본 3종을 고정 revision으로 확보했다. 한국어 공감형 자료는 실제
`multi_2/multi_3` 표지가 있는 18,568행을 포함하지만 **GPT 합성·평문
`질문:/답변:` 직렬화**이고 역할·문맥·사실 품질은 아직 미감사다.
한국어 지시 자료 7,040행은 단일턴 후보지만 중복과 합성 출처 때문에
`HOLD_QUALITY`다. OASST2는 사람 참여·평가된 대화 tree로 영어
다회전 대체 원천에 가장 적합하나, 엄격한 동언어 best-rank 경로에서는
영어 2,377개/일본어 24개 다회전 **후보**만 남는다.
이 수는 현재 변환 휴리스틱 결과이지 전체 dataset의 품질 또는
학습 가능 건수 확정값이 아니다.

**아직 canonical train/val corpus 0건, 실제 SFT 학습 0건,
사람 품질검토 0건, PII·평가 오염 검사 0건**이다.
원천 보유 `ACQUIRED`와 학습 승인 `TRAIN_READY`를 혼동하지 않는다.

## 5. 사용 전 선결 — 다운로드와 학습을 분리한다

1. 원천별 README/라이선스의 원문·하위 출처 조건을 사람이 확인한다.
   `ACQUIRED`는 법적 사용권이나 배포 가능성의 최종 판정이 아니다.
2. 한국어 공감형 `instruction`의 `질문:/답변:`을 역할 경계로
   **조건부** 분해한다. 마커가 본문 인용에 있거나 예상 턴 개수와
   다르면 reject하며 단일턴으로 억지 변환하지 않는다.
3. OASST2는 tree와 normalized 첫 사용자 질문을 함께 그룹화한다.
   OASST1·Aya 공개 v3와 source·질문·근접 중복을 검사한다.
   CarrotAI의 187 exact duplicate는 원본을 지우지 않고 파생본에서만 처리한다.
4. 각 source와 유형에서 20~50건씩 한국어 자연성, factuality,
   응답 관련성, 무의미한 공감/질문 반복, 번역 난이도와 PII를 사람이
   기록한다. 학습 가능 수량은 이 이후 재계수한다.
5. 영어/일본어 번역 pilot은 원문·번역문을 병렬로 보존하고
   **대화 tree 단위**로 train/val을 분리한다. 내용·역할·고유명사·
   숫자·근거를 보존했는지 한국어 사람이 50건 이상 확인한다.
   GPT Luna/로컬 LLM 번역은 **이번 세션에 실행하지 않았다**.
6. `train/val` 첫 질문과 benchmark·보호 held-out 오염검사,
   assistant-only mask·context 길이·parent/tokenizer 계보가
   모두 통과하기 전에는 P090 공식 한국어 멀티턴 학습을 열지 않는다.
   보호 자료 검사는 정확 경로 승인 전 `NOT_RUN`이다.

Aya Collection 약 974 MB 한국어 분할은 [P090 §13](../test_plan/P090_SFT-경로.md)의
별도 단일턴 확대 후보다. HF 다운로드 허용은 받았지만
**전량의 출처·품질 적격성은 미확정**이므로 이 턴에는 취득하지 않았다.
허용과 과학적 채택은 다른 결정이다.

[출처 감사 manifest](../HF/sft_ready/p090_aya_collection_ko_audit_20260923_manifest.json)은 한국어 train 후보 3,605,618행, 빈 질문/답 276행, 출처 21종·세부 그룹 29개와 출처당 20개씩 총 420개 검토 표본을 기록했다. 큰 출처는 SODA-inst (T) 1,191,582, Wiki-split-inst (T) 989,944, Xlel_wd-inst (T) 522,837, HotpotQA (T) 355,476이다. 사람 주석 `Aya-Dataset`은 이 한국어 train에서는 **361행**이다. 이 수는 적격·고유·고품질 행 수가 아니라 문자열·언어·split·source 기초조건을 통과한 **후보** 수다.

[Cohere Labs 공식 카드](https://huggingface.co/datasets/CohereLabs/aya_collection_language_split)는 전체 컬렉션을 Apache-2.0으로 배포하고, 유창 화자 템플릿·기계번역·사람 주석 Aya Dataset을 구분하며 **사람이 전체 주석한 출처는 Aya Dataset뿐**이라고 설명한다. 프로젝트는 카드 수준 라이선스를 확인했지만 각 원천의 재이용 조건·개별 레코드 권리/PII를 독립 검증하지 않았다. 표본의 자동 한글 비율도 출처별 차이가 있어(예: NTX-LLM-inst 20개 답안의 한글 문자 비율 평균 약 0.008) 한국어 태그만으로 자연 한국어 품질을 보증할 수 없다. 420개 원문은 [비보호 검토 파일](../HF/sft_ready/p090_aya_collection_ko_audit_20260923_review.jsonl)에만 있고 이 문서·콘솔에 복제하지 않는다.

**현재 상태: 원천 취득·출처 계수 완료 / SFT 학습 채택 보류.** 검토 표본의 사실성·자연성·PII·라이선스, 전체 근접중복과 기존 SFT/벤치 오염, 목표 tokenizer에서의 assistant-only mask/길이, train/val 그룹 분리를 거쳐야 한다. `SODA-inst (T)`라는 이름도 진짜 한국어 다회전 대화라는 증거가 아니다. Aya Collection은 기본적으로 단일 prompt-completion이며 P090 다회전 train/val 결손을 이 취득으로 닫지 않는다. GPU·모델·학습은 `NOT_RUN`이다.

## 6. 2026-09-23 실제 권장 원천 선정 — 목적별 pilot, 정식 학습 승인과 분리

**판정부터 명확히 한다.** Aya Collection 한국어 train 전체는 3,605,618개 기초조건 통과 행 중 사람 주석 `Aya-Dataset`이 361개(약 0.010%)이고, 나머지는 여러 템플릿·번역 계열을 크게 포함한다. [공식 카드](https://huggingface.co/datasets/CohereLabs/aya_collection_language_split)도 사람 전체 주석은 Aya Dataset뿐이라고 구분한다. 개별 출처의 사실성·권리·중복·PII와 멀티턴 구조가 검증되지 않았으므로 **한국어 멀티턴 기본 SFT 데이터로 전량 직접 투입하는 것은 부적합**하다. 이는 검수된 특정 subset까지 영구 기각한다는 뜻은 아니다.

### 6.1 현재 확보한 원본에서 무엇을 우선 쓰나

| 필요 능력 | 1순위 원천·현재 실물 | 채택 이유 | 정확한 상태·선결 |
|---|---|---|---|
| 한국어 멀티턴 **직접** pilot | [공감형 한국어](https://huggingface.co/datasets/ohilikeit/empathetic_dialogues_mutli_turn_ko)의 `HF/sft_sources/p090_empathetic_ko_9847cd2/Empathetic_data.jsonl` | 보유한 공개 원천 중 한국어 `multi_2/multi_3` 표지가 있는 18,568행으로, 역할 복원 가능성을 검정할 최소 규모가 있다. 카드 표기는 Apache-2.0 | **조건부 1순위·TRAIN_READY 아님**. GPT 합성·고정 공감→질문 문체·평문 `질문:/답변:`의 오파싱 가능성을 감수한다. `multi_2/multi_3` 각 50건 사람 QA, 마커·역할·첫 질문 그룹분할·중복·PII·target mask/길이 gate 뒤 소량 pilot만 |
| 한국어 멀티턴 **번역** pilot 및 영어 직접 대조 | [OASST2](https://huggingface.co/datasets/OpenAssistant/oasst2)의 `HF/sft_sources/p090_oasst2_179dd21/2023-11-05_oasst2_ready.trees.jsonl.gz` 영어 tree | 보유한 원천 중 사람 참여·review/rank·role/tree 구조가 가장 명시적이다. 엄격한 동언어 best-rank 경로에서 영어 다회전 후보 2,377개, 카드 Apache-2.0 | **고품질 대체 1순위·TRAIN_READY 아님**. 원문·번역 병렬 보존, tree 단위 split, OASST1/기존 SFT 중복 제거 후 100~300 tree 번역 pilot. 한국어 사람이 최소 50건의 숫자·고유명사·맥락·답안 사실성·PII 확인. 번역/외부 송신은 이번 작업에서 하지 않음 |
| 한국어 단일턴 지식/질문 보충 | 이미 확보한 [Aya Dataset 사람 원주석](https://huggingface.co/datasets/CohereLabs/aya_dataset)만 별도 소규모 후보 | Collection 한국어 train의 `Aya-Dataset` 361행과 기존 공개 v3의 한국어 train 175/val 9는 대량 템플릿과 구분할 근거가 있다 | **보조용·주 corpus 아님**. 샘플 사실성·첫 질문/벤치 중복·권리 확인 전 train 혼합 금지; 한국어 멀티턴 결손을 해결하지 못함 |

**OASST2 한국어 경로 재계수**: 보유한 pinned ready tree를 원문 비출력 스트리밍으로 검사했다. root `ko` 5개 중 동일 언어·역할 교대·review 통과 best-rank 유효 경로는 4개이고, 4메시지 이상 한국어 다회전은 **0개**다(`en` root 5,401→유효 3,700→다회전 2,377; `ja` root 85→유효 55→다회전 24). 따라서 OASST2의 한국어 원본을 직접 다회전 1순위로 쓰지 않는다. 일본어 24개는 일→한 번역 품질 대조에는 쓸 수 있어도 주 공급원이 아니다. 이 계수는 지정한 **한 경로 정책**의 결과이지 다른 branch 전체의 품질 확정이 아니다.

### 6.2 이번에 선정하지 않은 원천

- CarrotAI 한국어 7,040행은 Apache-2.0 표기지만 WizardLM-2-8x22B 합성, 정확 쌍 중복 187과 출력 품질 경보가 있다. **한국어 단일턴 예비 후보**로만 두고 이번 1순위에서는 제외한다.
- OpenLab 425만 `context/prompt/answer`는 대화 ID·역할 연결 및 하위 출처가 검증되지 않았다. 행 수를 다회전 수로 읽거나 지금 다운로드·채택하지 않는다.
- KoAlpaca RealQA는 실제 한국어 질문 가능성이 있으나 HF 접근 동의와 CC BY-SA 조건·PII 검토가 남아 **접근/권리 게이트**이지 현 확보·학습 원천이 아니다.
- 일본어 OASST2 24개와 llm-jp-instructions 300 train은 번역기 검정용 소차 대조이고, 비상업/하위 모델 조건이 있는 자료는 permissive-first 기본 조합에서 제외한다.

따라서 현재 실행 가능한 결정은 **한국어 공감형의 엄격 복원·소량 품질 pilot + OASST2 영어의 사람검수 번역 pilot을 서로 다른 계보로 준비**하는 것이다. P100의 형식·단기기억·지식 부족을 분리한 뒤에만 SFT 효과를 귀속한다. 이 선택은 데이터 **원천 우선순위**이며 정식 한국어 SFT용 `TRAIN_READY` 원천은 아직 **0건**이다. GPU·모델·번역·새 다운로드·보호 held-out 검사도 `NOT_RUN`이다.
