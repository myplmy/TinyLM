# (a) ★**"볼록하다" · "볼록성"**

## a.1 무슨 뜻으로 쓰고 있나

**레버를 한 칸 더 밀 때 드는 값이 앞칸보다 비싸지는 것**이다. 수학의 볼록함수에서 가져온 말이지만
우리가 쓰는 뜻은 좁다 — ★**"한계비용이 증가한다"** 다.

```
  품질 손실(누적)
    ^                                       ★볼록: 갈수록 가팔라진다
    |                              ,-'
    |                        ,--'
    |                 ,---'
    |          ,----'
    |  ,-----'
    +-------------------------------> 레버를 민 정도 (g8 -> g16 -> g32)

    같은 "한 칸" 인데 뒤로 갈수록 세로로 더 많이 올라간다 = 볼록
```

## a.2 어디서 나온 말인가 — 실측 두 건

| 근거 | 무엇 |
|---|---|
| **결과 032 §8.3** | ★**같은 `g16` 이 더 작은 기반(`p1c1`) 위에서 1.57배 비쌌다** |
| **결과 041 §14.3** | 더할 때 0.00118 vs 뺄 때 0.00342~0.00443 nats/유니크삼진100만 |

## a.3 🚫★**2026-08-26 — 이 말을 좁혀야 한다** (결과 029 §11)

| 축 | 한 칸 더 밀었을 때 | 볼록한가 |
|---|---|---|
| 임베딩 랭크 E=192 → 128 | **2.18배** | ✅ |
| 어텐션 ag4 → ag8 → ag16 | **4.6 → 6.0배** | ✅ |
| ★**MLP g16 → g32** | ★**0.91배**(0.00312 vs 0.00342) | 🚫★**아니다 — 오히려 싸졌다** |

★★**네 축 중 하나가 반례다.** → 🚫**"볼록성" 을 근거로 안 잰 점을 예측하지 않는다.**
그건 **관찰된 패턴**이지 법칙이 아니다.

## a.4 실무에서 쓰는 법

| ✅ | 🚫 |
|---|---|
| *"세 점이 볼록했다"* (관찰 보고) | *"볼록하니 다음 점은 더 비쌀 것이다"* (예측) |
| *"평균가격으로 예측 금지"*(032 §8.3) | *"평균가격 × 2 = 두 칸 비용"* |

# (b) ★**"어텐션이 꺼진다" · "안 깨어났다"**

## b.1 무슨 값을 말하는가 — **게이트**

`modules.py` 의 `Layer` 는 층마다 **게이트 두 개**를 갖는다:

```python
g0 = 1.0 / math.sqrt(cfg.n_layers)
self.gates = nn.Parameter(torch.tensor([g0, g0]))   # [어텐션 게이트, MLP 게이트]
```

층의 출력은 대략 `x = x + gate_attn · attn(ln1(x))` 그리고 `x = x + gate_mlp · mlp(ln2(x))` 다.
★**게이트가 그 층의 어텐션·MLP 가 잔차에 얼마나 섞이는지를 정한다.**

★**초기값이 `1/√n_layers`** 이므로 학습 시작 시점에는 전부 같다.
→ ★**학습 후 게이트가 초기값보다 커졌으면 "깨어났다", 작아졌으면 "꺼졌다"** 고 부른다.

## b.2 어디서 나온 말인가 — 결과 041 §15

`mC_d36`(20층 → 36층 깊이 확장)에서 **복제된 층**의 게이트가 학습 뒤 어떻게 변했나:

| | 게이트 변화 | 우리가 쓴 말 |
|---|---:|---|
| ★**어텐션** | ★**×0.279** (초기값의 28%) | 🚫**"꺼졌다"** |
| ★**MLP** | ★**×1.434** (초기값의 143%) | ✅**"깨어났다"** |

★**같은 층 안에서 두 게이트가 반대로 움직였다.**

## b.3 ★그래서 무엇을 뜻했나

> **"이식이 어텐션 깊이를 못 살렸다"** (041 §15)

깊이 확장은 교사(20층)의 층을 복제해 36층을 만든다. 학습이 그것을 **어떻게 쓰기로 했는지**를
게이트가 말한다: ★**복제층의 MLP 는 쓰기로 했고(1.43배), 어텐션은 안 쓰기로 했다(0.28배).**

🚫**"어텐션이 쓸모없다" 가 아니다.** *"이 이식 방식으로 만든 복제 어텐션이 쓸모없었다"* 다.

## b.4 ⚠️혼동하기 쉬운 두 가지

| 말 | 실제 대상 |
|---|---|
| ★**"게이트가 꺼졌다"** | **학습이 정한 값**(게이트 파라미터). 관찰 |
| ★**"게이트를 0 으로 한다"**(U2, 결과 057) | **우리가 강제로** 0 을 넣어 손실 변화를 본다. 개입 |

★**둘은 다르다.** b.2 는 *"학습이 스스로 껐다"*, U2 는 *"우리가 꺼 보았다"* 다.
⚠️**그리고 결과 057 §11.2 가 U2 의 함정을 밝혔다** — `cla_group=2` 에서 게이트를 0 으로 하면
**K/V 사슬까지 끊겨** 그 층의 중요도가 아니라 사슬 효과를 재게 된다.

# (c) ★**"MLP 가 깨어난다"**

## c.1 (b)와 같은 지표의 반대편

`gates[1]`(MLP 게이트)이 **초기값보다 커진 것**이다. 결과 041 §15 에서 **×1.434**.

## c.2 ★왜 이것이 결론이 됐나

**같은 복제층**에서 어텐션은 0.279, MLP 는 1.434 로 갈렸다는 사실이 다음을 말한다:

| # | 읽은 것 |
|---|---|
| 1 | 🚫*"복제층 전체가 죽었다"* 가 **아니다** — MLP 는 오히려 더 쓰인다 |
| 2 | ★**이식의 문제는 어텐션 쪽에 있다** — 그래서 P057(어텐션 타잉)로 이어졌다 |
| 3 | ★**깊이는 값어치가 있다** — 다만 어텐션을 늘리는 형태로는 아니다 |

## c.3 ★이 말이 지금 어디에 서 있나

★**결과 044 가 그 판단을 확증했다**: `mC_d36_ag4`(36층 + 어텐션 4층 공유)가
**상주 −15.9%** 이면서 품질 **+0.0072** 였다 — ★**어텐션을 줄이고 깊이를 얻는 것이 맞았다.**

## (d) ★**"어휘로 접는다" · "접는다"**

| | |
|---|---|
| **일상어에는 없다** | 종이를 접는다는 말은 있어도 *"어휘로 접는다"* 는 없다 |
| ★**무슨 뜻인가** | **여러 개의 다른 이름을 정해진 소수의 이름으로 대응시킨다**(수학의 *사영*·*몫집합*에 가깝다) |
| ★**왜 이 말을 썼나** | *"통일한다"* 는 **원본을 덮어쓰는 느낌**이고, *"매핑한다"* 는 영어다. **접으면 원래 것이 안쪽에 남아 있다** 는 뉘앙스를 쓰고 싶었다 |

**실제 사례** — held-out 벤치마크의 관계 이름:

```
접기 전 (자유 어휘, 81종)          접은 뒤 (통제 어휘, 13종)
  concept_boundary        ─┐
  classification_boundary ─┼──>  boundary
  temporal_boundary       ─┤
  entity_boundary         ─┘
  subtype                 ─┬──>  subclass_of
  subclass_of             ─┘
  function_or_role        ───>  function  또는  role  (사람이 고른다)
  (그 밖 60여 종)          ───>  other
```

★**"접는다" 가 맞는 말인 이유**: `other` 로 간 60여 종은 **사라진 게 아니라 한 칸에 모였다.**
원본 필드를 남겨 두면 언제든 펼 수 있다. 🚫**"통일한다" 로 썼으면 원본을 덮어쓴 것처럼 읽힌다.**

★**앞으로 쓸 때**: 처음 등장 시 *"통제 어휘로 접는다(여러 이름을 정해진 13개에 대응시킨다)"* 로 푼다.

## (e) ★**"자" · "자를 잰다" · "빌린 자"**

| | |
|---|---|
| ★**무슨 뜻인가** | **자 = 분해능(2σ)**. *"이 차이가 진짜인가 노이즈인가"* 를 가르는 문턱 |
| **일상어와 다른 점** | 일상에서 *"자"* 는 도구다. 여기서는 **그 도구의 눈금 간격**을 뜻한다 |

**사례 셋**:

| 표현 | 뜻 | 실제 |
|---|---|---|
| *"자를 다시 쟀다"* | 같은 조건을 **시드만 바꿔 여러 번 학습**해서 노이즈 폭을 측정했다 | 타잉 3.6762 / 3.6768 / 3.6765 → **2σ = 0.0006** |
| ★*"빌린 자"* | **그 계열에서 안 쟀고 다른 계열의 값을 대신 쓰는 중** | 재귀 판정에 dense 자 0.0042 를 쓰던 시기 |
| *"자의 5.7배"* | 차이가 문턱의 5.7배 = **확실히 진짜** | `--repeat-kv-reuse` 대가 +0.0591 |

⚠️★**"자 아래" 는 "차이가 없다" 가 아니다** — *"이 실험 설계로는 못 가른다"* 는 뜻이다.
그래서 이 저장소는 **"실무상 동급, 통계적으로는 유의"** 라고 둘을 나눠 적는다.

## (f) ★**"교환비가 나쁘다"** vs 🚫**"기각"**

★**이 둘을 구분하는 것이 이 저장소의 규약**이다.

| 말 | 뜻 | 다시 열리는가 |
|---|---|---|
| 🚫**기각** | **효과가 없거나 해롭다.** 다시 제안하지 않는다 | ❌ |
| ⚠️**교환비가 나쁘다** | **효과는 있는데 대가가 더 크다** | ✅**대가가 싸지면 다시 연다** |

**사례**: 방문 20 → 28 은 품질 **−0.0036**(자의 6.0배 = 진짜 이득)인데 속도가 **−24.6%** 다.
🚫*"R=6 기각"* 이라고 적었더니 **LUT 커널로 속도가 싸져도 아무도 다시 안 볼 상태**가 됐다.
→ ★*"교환비가 나쁘다"* 로 고쳤다.

## (g) ★**"축" · "축을 연다/닫는다"**

| | |
|---|---|
| ★**축** | **바꿀 수 있는 설계 변수 하나**(예: 타잉 그룹 크기, 재귀 횟수, KV dtype) |
| **축을 연다** | 그 변수를 실험 대상으로 삼기 시작한다 |
| **축을 닫는다** | 더 안 건드리기로 한다(기각이든 종결이든) |

**사례**: *"어텐션 타잉은 `ag4` 에서 끝난다"* = **`attn_group` 축을 4 이상에서 닫았다.**
🚫*"모델을 바꾼다"* 가 아니라 **"그 변수 하나만 움직인다"** 는 뜻이다.

## (h) ★**"상주" vs "저장" vs "패킹"**

★**이 셋을 섞어 쓰면 이 저장소에서 가장 자주 나는 사고**(함정 1·24)다.

| 말 | 영어 | 무엇 | 이 모델의 예 |
|---|---|---|---|
| **저장(packed)** | packed | **디스크에 담기는 크기.** 비트폭이 식에 있다 | 8.2 MB |
| ★**상주(runtime)** | resident | **돌아가는 동안 램에 붙들려 있는 크기** | 16.8 MB |
| **KV** | KV cache | 문맥 길이에 **선형으로 자라는** 별도 항 | 15.0 MB @ seq 1024 |

★**"저장 8.2 인데 상주 16.8" 이 이상하지 않은 이유**: 삼진 가중치를 **계산 직전에 fp32 로
펼치기** 때문이다. 그래서 **비트폭을 줄여도 상주는 그대로**일 수 있다.
→ ★**인용할 때 반드시 어느 쪽인지 적는다.** 상주는 **(모델, KV dtype, 컨텍스트)** 셋을 함께.

## (i) ★**"~ 가 조용하다" · "조용한 실패"**

| | |
|---|---|
| ★**뜻** | **에러도 안 나고 종료코드도 0 인데 결과가 틀린 상태** |

**사례 셋**:

| 무엇 | 어떻게 조용했나 |
|---|---|
| 메모리 스필 | 종료코드 0, 손실 정상, **그런데 26% 느렸다** |
| `--mlp-film` | 학습이 정상 종료됐는데 **로그에 그 플래그가 켜졌다는 기록이 없었다** |
| HF 캐시 | 다운로드 성공, 에러 0, **그런데 작업폴더 밖에 받았다** |

★**그래서 이 저장소는 "게이트" 를 만든다** — 조용한 실패는 **소리를 내게 만들어야** 보인다.

## (j) ★**"게이트"**

| | |
|---|---|
| ★**뜻** | **통과하지 못하면 다음으로 못 가게 막는 자동 검사** |
| 일상어와 차이 | 문(gate)이 아니라 **검문소**에 가깝다 |

**두 층이 있다**:

| 층 | 무엇을 보나 | 예 |
|---|---|---|
| **정적** | *"이름이 있는가"* — torch·GPU 를 안 쓴다 | `check_static_all.py`(20종) |
| **동적** | *"그 경로가 실제로 도는가"* | `run_smoke_check.bat` |

🚫★**정적이 동적을 대체하지 않는다.** `mlp_film` 사고가 정확히 그 틈이었다.

## (k) ★**"~ 를 산다" · "메모리를 사서 품질을 판다"**

| | |
|---|---|
| ★**뜻** | **한 자원을 내주고 다른 자원을 얻는다**(경제학의 trade-off) |

**사례**: *"`mC_cla2_ag4` 는 상주 −17.3% 를 샀는데 속도를 안 잃었다"*
= 메모리를 줄였고(얻음) 속도는 그대로(대가 없음).
★**"공짜"** 라는 말은 이 저장소에서 **"대가가 자 아래"** 라는 뜻이다.

## (l) ★**"교락(交絡)된다"**

| | |
|---|---|
| ★**뜻** | 통계 용어 confounding. **두 원인이 같이 움직여서 어느 쪽 몫인지 못 가른다** |

**사례**: `attn_group` 실험을 전부 `cla_group=2` 에서 돌렸는데 **`cla_group=2` 자체가 −0.0268 의
대가**가 있었다. → *"`attn_group` 결과 전부가 교락됐다"* = **어텐션 타잉의 몫과 CLA 의 몫을
분리할 수 없다.**

## (m) ★**"~ 로 귀속한다"**

| | |
|---|---|
| ★**뜻** | **관측된 차이의 원인을 무엇으로 돌리는가** |

**사례**: *"cla1 의 t1 −20% 를 아키텍처로 귀속하지 않는다"*
= 그 −20% 를 **모델 구조 탓으로 적지 않는다**(기준 행이 외부 부하 한계를 넘었으므로).

## (n) ★**"⚙" 표시**

| 표시 | 뜻 |
|---|---|
| ⚙ | ★**추정값이다. 재지 않았다.** ⚙8.8시간 = *"환산해 보니 8.8시간일 것"* |
