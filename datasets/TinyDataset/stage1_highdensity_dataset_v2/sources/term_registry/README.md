# Term registry 준비 규약

이 폴더는 v2 primary의 용어·정의·출처·검토 판정을 보관할 예정인 source-side 영역이다. 아직 registry record는 없다.

registry record는 하나의 primary가 자연어 용어인지, 검증 가능한 기술 용어인지, 명시적으로 정의된 내부 시나리오인지 판정하는 증거다. 학습 입력에는 기존 원칙대로 `text`만 사용하며, registry metadata를 자동으로 tokenizer 입력에 넣지 않는다.

실제 registry 형식과 필수 검토자·출처 규칙은 v2 범위와 schema 승인 뒤 확정한다.
