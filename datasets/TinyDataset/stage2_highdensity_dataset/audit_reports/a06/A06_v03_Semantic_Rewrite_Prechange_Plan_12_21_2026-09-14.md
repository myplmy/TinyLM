## 반영 예정 text

1. 베드 관측이 없을 때 차광 모터 출처를 보류하는 절차는 재배 베드의 온도 기록이 끊긴 동안 차광 모터가 작동했을 때, 모터 작동을 특정 베드의 온도 변화에서 비롯된 명령으로 연결하지 않는 과정이다. 출처 연결 불명이면 온실 운영자는 모터 작동 시각과 남아 있는 베드 기록을 따로 보관하고, 출처가 확인될 때까지 자동 차광 명령을 다시 보내지 않아 다른 구역의 빛 조절을 방해하지 않는다.
2. 수동 전환 중 순환팬과 압력 조절기의 상태 분류는 작업자가 순환팬을 수동으로 켠 뒤 압력 조절기 값이 바뀌었을 때, 두 장치를 하나의 자동 제어 상태로 분류하지 않는 기준이다. 관리자는 수동 조작 시각과 압력값을 기록하고, 인과 연결이 확인되기 전까지 팬 가동과 압력 조정을 별도 상태로 구분해 오작동 경보를 막는다.
3. 차광 모터 표본이 부족할 때 배수관 연결을 보류하는 기준은 모터 전류 기록과 배수관 유량 기록이 서로 다른 주기에 수집됐을 때, 두 변화가 같은 복구 상태에서 일어났다고 비교하지 않는 판단이다. 식별 기록 상충이 있으면 운영자는 장치 번호와 배관 구간 번호가 일치한 기록만 남기고, 일치하지 않는 연결은 현장 점검 전까지 보류해 불필요한 배수 운전을 막는다.
4. 기상 예보가 없는 수분 측정의 연결 경계는 함수율 센서가 낮은 수분값을 보냈지만 같은 시간대의 기상 예보가 수신되지 않았을 때, 그 수치를 강수나 일사 변화의 결과로 설명하지 않는 기준이다. 운영자는 센서 측정 시각과 관수 밸브 기록을 먼저 대조하고, 예보가 들어오기 전에는 수분값을 독립 관측으로 처리해 불필요한 관수 중단을 막는다.
5. 관수 밸브 기록만 있을 때 배수관 관계를 보류하는 기준은 밸브의 개폐 시각이 남아 있어도 배수관 유량과 탱크 수위가 동시에 확인되지 않으면, 밸브를 특정 배수관 흐름의 일부라고 판정하지 않는 상태 기준이다. 동시 개입 분리 불가가 있으면 담당자는 밸브가 연결된 재배 구역만 기록하고, 배수관 경로는 추가 유량 측정까지 보류해 잘못된 배관 수리를 막는다.
6. 제어기 관측이 끊긴 양액 탱크 상태의 구분은 환경 제어기의 보충 명령이 사라진 뒤 탱크 수위만 변했을 때, 그 변화를 정상 보충 상태와 구분해 미확인 상태로 두는 판단이다. 후속 검증 누락이면 관리자는 탱크 수위와 현장 작업표를 다시 확인하고, 확인 전에는 자동 보충을 재개하지 않아 과다 공급을 막는다.
7. 대체 배관에서 압력 조정과 작업 승인을 분리하는 절차는 압력 조절기의 값이 바뀌고 작업 기록에는 우회 배관 점검만 남았을 때, 압력 조정을 예외 승인과 같은 단계로 묶지 않는 과정이다. 예외 승인 시각 미상인 경우 관리자는 조절기 로그와 작업자의 인계 시각을 따로 확인하고, 승인 시각이 확인될 때까지 대체 배관을 정규 운전 경로로 등록하지 않아 책임 범위를 보존한다.
8. 환기창 표본이 부족할 때 양액 탱크 연결을 보류하는 상태 분류는 환기창 개방 기록이 드문데 양액 탱크 수위가 낮아졌을 때, 두 변화를 저부하 운전의 한 상태로 분류하지 않는 기준이다. 운영자는 환기 시간과 탱크 수위 변화를 구분하고, 표본이 더 모일 때까지 환기 제어와 양액 보충을 별도 상태로 두어 잘못된 절전 조치를 막는다.
9. 작업 기록이 없을 때 압력 조절의 비교 범위는 압력 조절기의 값이 바뀌었지만 작업자의 조정 기록이 남지 않았을 때, 이전 교대의 압력값과 현재 값을 같은 작업 결과로 비교하지 않는 상태 기준이다. 센서 채널 불일치가 있으면 관리자는 압력 센서별 시각과 값을 대조하고, 일치하지 않는 기록은 자동 경보 해제에서 제외해 실제 이상 신호를 지킨다.
10. 양액 탱크 기록만 있을 때 제어기 작동을 보류하는 판단은 탱크 수위와 양액 농도는 남아 있지만 환경 제어기의 실행 로그가 없을 때, 수위 감소를 제어기 작동의 결과로 연결하지 않는 절차다. 운영자는 수위 변화 시각과 농도 값을 확인한 뒤 실행 로그가 복구될 때까지 수동 보충과 자동 보충을 구분해 잘못된 배합 명령을 막는다.
