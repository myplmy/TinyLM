# Stage1 held-out v3.0 생성·감사 보고서

## 1. 판정 범위

- 산출물: 4,500문항 JSON 및 JSONL, 변경 ID 원장, SHA-256 목록
- 증거 수준: `STATIC_ONLY`
- 독립 파일럿 및 D9: `NOT_RUN`
- v2.9 진단 census의 6개 체크포인트는 실패 유형과 재작성 우선순위를 정하는 데만 사용했다. 체크포인트별 출력에 맞춰 정답 위치나 문구를 고르지 않았다.
- v3.0의 최종 D9, 실제 난이도 단조성, 모델 변별력 합격은 주장하지 않는다. TinyLM 측이 다른 seed 또는 이후 독립 체크포인트 3개 이상으로 별도 측정해야 한다.

## 2. 생성 설계

v2.9의 ID, gold, difficulty_target은 그대로 두고 모든 4,500문항의 ctx와 choices를 새로 작성했다. v2.9 문구를 일부 유지하면 v2.9 금지집합과 토큰 8-gram이 겹치므로 문항 본문은 전면 재작성했다. 각 문항은 동일한 두 대상을 네 후보에서 반복하고, 네 후보가 서로 배타적인 관계 상태 하나씩을 나타내도록 구성했다. 모든 후보에 붙는 공통 꼬리문장은 사용하지 않았다.

v2.9 census의 `ids`와 `per_item_rate`를 같은 인덱스로 읽었다. 6개 진단 체크포인트에서 정답률이 0 또는 1인 정보 0 문항은 2,208개(전부 오답 1,656개, 전부 정답 552개)였다.

## 8. 파일럿 모델과 최종 검증 분리

v2.9 진단 census에 사용된 모델은 다음 6개다.

1. `d12_cla2_norecur_muon15`
2. `d12_cla2_r20_muon15`
3. `d14_cla2_norecur_muon15`
4. `d16_cla2_norecur_muon15`
5. `d16_cla2_r20_muon15`
6. `d18_cla2_norecur_muon15`

이 모델들은 v2.9의 정보 0 진단 문항을 고르는 데만 사용했다. v3.0의 후보 문구, gold, 의미형을 체크포인트 출력에 맞춰 사후 선택하지 않았다.

생성 측이 v3.0에 실행한 파일럿 모델은 없다(`NOT_RUN`). 따라서 v3.0의 D9, easy/mid/hard 실제 단조성, McNemar, 문항당 정보량은 모두 미판정이다. 최종 검증은 위 6개와 분리된 다른 seed 또는 이후 체크포인트 최소 3개로 수행해야 한다.
